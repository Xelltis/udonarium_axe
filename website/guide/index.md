# 設置の流れ

このページは、Udonarium Axe（以下Axe）を自分の場所に置いて、仲間うちや公開の場で使いたい人のための案内です。
置くまでの流れと、どのページをどの順に読めばよいかを説明します。
すでに動いているAxe（[デモサイト](https://axe.xelltis.com)や、誰かが置いた場所）で遊ぶだけなら、設置は要りません（→ [はじめに](/start/)）。

## 置くもの

Axeを自分の場所で動かすには、次の2つを置きます。

| 置くもの | 中身                                                                       | 置く場所の例                                  |
| -------- | -------------------------------------------------------------------------- | --------------------------------------------- |
| Axe本体  | リリースのzipを展開したファイル（HTML・JavaScript・画像など）              | Cloudflare Pages、レンタルサーバー、Amazon S3 |
| サーバー | 参加者どうしをつなぐためのサーバー。方式によって、置くサーバーが変わります | Vercel、Cloudflare Workers、レンタルサーバー  |

Axe本体は、ファイルを置くだけで動きます。
ソースからビルドし直す必要はありません。
サーバーは、[udonarium_axe_backend](https://xelltis.github.io/udonarium_axe_backend/)の文書の手順で置きます。
このサイトでは、Axe本体を置く手順と、Axeとサーバーをつなぐ設定を説明します。

## 2つの方式

Axeには、参加者のつなぎかたが2つあります。
どちらにするかで、置くサーバーが変わります。

| 方式       | 参加者のつながりかた                                                             | 置くサーバー         |
| ---------- | -------------------------------------------------------------------------------- | -------------------- |
| SkyWay版   | 参加者どうしが、[SkyWay](https://skyway.ntt.com/)を使って直接つながる（P2P）     | トークン発行サーバー |
| サーバー版 | 全員が部屋のサーバーにつながる。部屋のサーバーが卓と画像と音声を預かる（ベータ） | 部屋のサーバー       |

参加者から見た違いと選びかたは、[方式を選ぶ](/guide/choose)にあります。
はじめて置くなら、SkyWay版から試すのが手軽です。
トークン発行サーバーは、Vercelのボタンを押すだけでも置けます。

## 置くまでの流れ

<SetupSteps />

1. **方式を選ぶ** — SkyWay版かサーバー版かを決めます（→ [方式を選ぶ](/guide/choose)）
2. **サーバーを置く** — 方式に合ったサーバーを、バックエンドの文書の手順で置きます（→ [サーバーを置く](/guide/backend)）
3. **Axeを置く** — リリースのzipを展開し、静的ホスティングに置きます（→ [Axeを置く](/guide/quickstart)）
4. **つないで確かめる** — `assets/config.json`にサーバーのURLを書き、部屋を作って確かめます（→ [config.jsonを書く](/guide/configuration)）

手順1から順に進めてください。
用意するアカウントと、作業の前に確かめておくことは[設置の準備](/guide/requirements)にまとめてあります。

## かかる時間と費用

かかる時間は、アカウント作りを含めたおおよその目安です。

| 組み合わせ                                         | サーバー    | Axe本体  | 費用                                          |
| -------------------------------------------------- | ----------- | -------- | --------------------------------------------- |
| SkyWay版（Vercel）＋Cloudflare Pages               | 30分ほど    | 30分ほど | 無料の範囲に収まることがほとんど              |
| SkyWay版（レンタルサーバー）＋同じレンタルサーバー | 30分〜1時間 | 30分ほど | 契約中のサーバー代だけ                        |
| サーバー版（Cloudflare）＋Cloudflare Pages         | 1時間ほど   | 30分ほど | 1日5〜7卓ほどまで無料。支払い方法の登録が要る |

サーバーの費用と上限は、バックエンドの文書の[どれを置くか](https://xelltis.github.io/udonarium_axe_backend/guide/choose)と[費用と上限](https://xelltis.github.io/udonarium_axe_backend/operate/costs)にあります。

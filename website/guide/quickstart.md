# Axeを置く

このページは、Axe本体（リリースのzip）を静的ホスティングに置いて、ブラウザで開けるようにする手順です。
いちばん詳しく書いているのはCloudflare Pagesで、Cloudflareのアカウントを作るところから、コマンドで上げるところまで順に案内します。
コマンドは、ターミナルに書き写して`Enter`を押すだけです。
画面の操作だけで上げる方法と、レンタルサーバーなどほかの置き場所は、後ろに要点を書いています。
かかる時間は、Node.jsを入れるところとCloudflareのアカウント作りを含めて30分ほどです。

## 0. 用意するもの

- 置き終えたサーバーのURL（→ [サーバーを置く](/guide/backend)）
- メールアドレス（Cloudflareのアカウントを作るのに使います）
- WindowsかMacのパソコンと、Chromeなどのブラウザ
- テキストエディター（メモ帳やテキストエディットなど）

Cloudflare Pagesは、無料のプラン（Free）のままで使えます。
支払い方法の登録も要りません。

この手順で使う値は、次のとおりです。

| 値                 | 手に入る場所                           | 使う手順 |
| ------------------ | -------------------------------------- | -------- |
| `axe_x.y.z.zip`    | GitHubのReleases                       | 手順1    |
| サーバーのURL      | [サーバーを置く](/guide/backend)の最後 | 手順2    |
| プロジェクトの名前 | 自分で決める（AxeのURLになる）         | 手順6、7 |
| AxeのURL           | 手順6で出る                            | 手順7、8 |

::: warning httpsで配ってください
Axeは、`https://`で始まるURLで配ります。
`http://`のページ（自分のパソコンの`localhost`を除く）では、部屋や画像を見分けるのに使うブラウザの機能が使えず、Axeは正しく動きません。
Cloudflare Pagesは、最初から`https://`で配ります。
:::

## 1. zipを取ってくる

1. [GitHubのReleases](https://github.com/Xelltis/udonarium_axe/releases)を開きます。
2. いちばん上にある最新の版の**Assets**を開き、`axe_x.y.z.zip`（`x.y.z`は版の番号）を押してダウンロードします。
3. ダウンロードしたzipを展開します。Windowsでは、zipを右クリックして**すべて展開**を選びます。

展開したフォルダの中に、`index.html`と`assets`のフォルダがあれば正しく展開できています。
このフォルダを、以下では「展開したフォルダ」と呼びます。

## 2. config.jsonを書く

展開したフォルダの`assets/config.json`を、テキストエディターで開きます。
最初は、次のような中身になっています。

```json
{
  "transport": "skyway",
  "backend": {
    "url": "バックエンドサーバーのURLを指定してください。http://localhost:3000"
  }
}
```

`url`の値を、置いたサーバーのURLに書き換えます。
サーバー版で配るときは、`transport`も`"server"`に書き換えます。

```json
{
  "transport": "skyway",
  "backend": {
    "url": "https://backend.example.com"
  }
}
```

`"`（ダブルクォート）や`,`（カンマ）は消さずに、文字だけを書き換えます。
書き換えたら、文字コードはUTF-8のまま保存します。
項目の意味は[config.jsonを書く](/guide/configuration)にあります。

::: tip 置く前に書き換えます
Cloudflare Pagesに上げたファイルは、その場では書き換えられません。
`config.json`は、上げる前に書き換えておきます。
あとで書き換えたくなったときは、書き換えたフォルダをもう一度上げます（→ [更新するとき](/guide/update)）。
:::

## 3. Cloudflareのアカウントを作る

すでにCloudflareのアカウントがあれば、手順4に進みます。
サーバーをCloudflareに置いたときのアカウントを、そのまま使えます。

1. [Cloudflareの登録ページ](https://dash.cloudflare.com/sign-up)を開きます。
2. **Email**にメールアドレスを、**Password**にパスワードを入れます。パスワードは8文字以上にし、数字と記号（`$`・`!`・`@`など）を1つずつ以上含めます。
3. その下の、人間であることを確かめる枠（「私はロボットではありません」）にチェックを入れて、**Sign up**を押します。
4. Cloudflareから、確認のメールが届きます。メールの中のリンクを押して、メールアドレスを確かめます。届かないときは、迷惑メールのフォルダも見てください。
5. ログインすると、ダッシュボード（Cloudflareの管理画面）が開きます。

Google・Apple・GitHubのアカウントで登録するときは、手順2の代わりに、上に並ぶ**Continue with**のボタンを押します。
登録ページの言葉は、右上の**English**から日本語に切り替えられます。

ダッシュボードには、ドメインを追加する案内なども並んでいます。
Axeを置くだけなら、ドメインは要りません。
ここでは何も追加せずに、手順4に進みます。

## 4. Node.jsを入れる

Cloudflare Pagesへは、CloudflareのコマンドラインツールWrangler（ラングラー）で上げます。
Wranglerは、Node.jsの上で動きます。
Wrangler自体は、手順5で初めて使うときに自動で入るので、ここではNode.jsだけを入れます。

1. [Node.jsのダウンロードページ](https://nodejs.org/ja/download)を開きます。版は、**LTS**の付いたものを選びます。
2. **Windows インストーラー (.msi)**（Macでは**macOS インストーラー (.pkg)**）を押して、ダウンロードします。
3. ダウンロードしたファイルを開き、画面に従って入れます。途中の設定は変えずに進めて構いません。
4. ターミナルを開きます（開きかたは下の表）。すでに開いていたターミナルは、閉じて開き直します。
5. `node --version`と打って`Enter`を押し、`v22`以上の番号（`v24.22.0`など）が出ることを確かめます。

| パソコン | ターミナルの開きかた                                                                 |
| -------- | ------------------------------------------------------------------------------------ |
| Windows  | スタートメニューの検索欄に`cmd`と入れ、出てきた**コマンド プロンプト**を開きます     |
| Mac      | Finderで**アプリケーション**の中の**ユーティリティ**を開き、**ターミナル**を開きます |

すでにNode.jsが入っているときは、上の5のとおりに版だけを確かめます。
`v22`より古いときは、入れ直します。

## 5. Wranglerでログインする

ターミナルに次の1行を打ち（このページから貼り付けて構いません）、`Enter`を押します。

```sh
npx wrangler login
```

1. 初めてのときは、Wranglerを入れてよいかを聞かれます（`Ok to proceed? (y)`）。そのまま`Enter`を押します。
2. ブラウザにCloudflareの画面が開きます。ログインしていなければ、手順3のアカウントでログインします。
3. Wranglerにアカウントの操作を許すかを聞かれるので、許可します。
4. ターミナルに`Successfully logged in.`と出れば、ログインできています。

ログインは、このパソコンに残ります。
次からは、この手順を飛ばせます。

## 6. プロジェクトを作る

プロジェクトは、Cloudflare Pagesの中の、サイト1つ分の単位です。
プロジェクトの名前が、そのまま`https://<プロジェクトの名前>.pages.dev`の形で、AxeのURLになります。
名前は、次のように決めます。

- 英小文字・数字・`-`（ハイフン）で付けます（例：`my-axe`）
- ほかの人がすでに使っている名前だと、URLは名前のあとに英数字が少し付いた形になります
- `pages.dev`のURLは、あとから変えられません。変えたくなったときは、プロジェクトを作り直します

ターミナルに次の1行を打ちます。
`my-axe`のところは、決めた名前に変えます。

```sh
npx wrangler pages project create my-axe --production-branch main
```

次のように出れば、プロジェクトができています。

```text
✨ Successfully created the 'my-axe' project. It will be available at https://my-axe.pages.dev/ once you create your first deployment.
```

`https://`から`/`の手前までが、AxeのURLです。
名前に英数字が付いていたら、付いたほうのURLを控えます。
このURLの部分がAxeのOriginで、サーバーの`ACCESS_CONTROL_ALLOW_ORIGIN`に書く値です。
[設置の準備](/guide/requirements#axeのoriginを決める)で決めたOriginと違っていたら、サーバーの`ACCESS_CONTROL_ALLOW_ORIGIN`をこのOriginに書き換えます。

`--production-branch main`は、本番として配る先に`main`という名前を付ける指定です。
手順7でも、同じ`main`を使います。

## 7. 上げる

上げるコマンドは、次の形です。

```sh
npx wrangler pages deploy <展開したフォルダ> --project-name my-axe --branch main
```

`<展開したフォルダ>`は、手で打たずに、フォルダをドラッグして入れます。

1. ターミナルに`npx wrangler pages deploy `まで打ちます（最後に空白を1つ入れます）。
2. エクスプローラー（MacではFinder）で、手順2で`config.json`を書き換えたフォルダ（`index.html`のあるフォルダ）を表示し、ターミナルの窓にドラッグします。フォルダの場所が入ります。
3. 続けて、空白を1つ空けてから`--project-name my-axe --branch main`を打ちます。`my-axe`は、手順6の名前に変えます。
4. `Enter`を押します。

`Uploading... (839/839)`のように数が進み、最後に`✨ Deployment complete!`と出れば上がっています。

::: warning 最後に出るURLは、この回だけのURLです
`Take a peek over at`のあとに出るURLは、`https://1a2b3c4d.my-axe.pages.dev`のように、頭に英数字が付いています。
これは、上げた回ごとに変わるURLです。
参加者に配るURLと、サーバーに書くOriginは、手順6で出た`https://my-axe.pages.dev`のほうです。
:::

## 8. 確かめる

1. AxeのURL（手順6で出たURL）を、パソコンのChromeで開きます。
2. ロビー（部屋の一覧）が出ることを確かめます。サーバー版では、ロビーの上に**Discordでログイン**のボタンが出ます。
3. 部屋を作って入ります。サーバー版では、先にDiscordでログインします。
4. 別のブラウザ（ほかの人のパソコンや、Chromeのシークレットウィンドウ）で同じURLを開き、作った部屋に入れることを確かめます。

| 見えるもの                                                            | 原因と直しかた                                                                                                                                                                                   |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 部屋を作れて、別のブラウザからも入れる                                | できあがりです                                                                                                                                                                                   |
| 上げた直後に、サイトにアクセスできないと出る                          | 初めて上げた直後は、URLがまだ行き渡っていないことがあります。数分待ってから開き直すか、別の端末やネットワークで開きます                                                                          |
| ページが真っ白、または開けない                                        | 展開したフォルダの中身ではなく、フォルダごと1段深く上げていないか確かめます（`index.html`がURLのすぐ下にあるか）                                                                                 |
| ロビーは出るが、部屋を作れない・入れない                              | 頭に英数字の付いたURL（この回だけのURL）で開いていないか確かめます。`config.json`か、サーバーの`ACCESS_CONTROL_ALLOW_ORIGIN`が違うこともあります（→ [設置で困ったとき](/guide/troubleshooting)） |
| サーバー版なのに**Discordでログイン**が出ない                         | `config.json`の`transport`が`"server"`になっていません                                                                                                                                           |
| 「'npx' は、内部コマンドまたは外部コマンド…として認識されていません」 | Node.jsが入っていないか、入れる前から開いていたターミナルです。手順4のとおりに入れ、ターミナルを開き直します                                                                                     |
| 「このシステムではスクリプトの実行が無効になっているため…」           | PowerShellで打っています。**コマンド プロンプト**を開き直して打つか、`npx`の代わりに`npx.cmd`と打ちます                                                                                          |
| `Wrangler requires at least Node.js v22.0.0.`                         | Node.jsが古い版です。手順4のとおりに、LTSの版を入れ直します                                                                                                                                      |
| プロジェクトを作るときに、作れないと出る                              | 作ったばかりのアカウントは、最初の48時間に作れるプロジェクトの数が限られています。前に作ったプロジェクトに上げ直すか、48時間待ちます                                                             |

## 画面から上げる

Cloudflareのダッシュボードで、展開したフォルダをドラッグ＆ドロップして上げることもできます。
ただしCloudflareは、新しく作るサイトにはWorkersを勧めていて、ダッシュボードのPagesの入口は目立たない所にあります。
画面が下の説明と違うときは、手順4から7のコマンドで上げてください。
ボタンやメニューの名前は、英語の表示のものです。

1. ダッシュボードの左のメニューから、[Workers & Pages](https://dash.cloudflare.com/?to=/:account/workers-and-pages)を開きます。
2. **Create application**を押し、Pagesの**Get started**を押して、**Drag and drop your files**を選びます。
3. **Project name**に名前を入れて進み、出てきた枠に、展開したフォルダをドラッグします。
4. 上がり終えたら、**Deploy site**を押します。

ドラッグ＆ドロップで上げられるのは1,000ファイルまで、1つのファイルは25MiBまでです。
Axeのファイル（800個あまり、いちばん大きいもので2MBほど）は、どちらにも収まります。
画面から作ったプロジェクトにも、手順7のコマンドで上げられます。

## ほかの置き場所

どこに置いても、展開したフォルダの中身をそのまま、`https://`で配れる場所に置けば動きます。

| 置き場所              | 要点                                                                                                                                                                                             |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| レンタルサーバー      | FTPなどで、公開フォルダ（`public_html`など）の下に、展開したフォルダの中身を上げます。サブフォルダに置いても動きます。サーバーがhttpsで配っているかを確かめてください                            |
| GitHub Pages          | 展開したフォルダの中身をリポジトリに入れ、そのブランチを配信元に選びます                                                                                                                         |
| Amazon S3＋CloudFront | 展開したフォルダの中身をバケットに上げ、CloudFrontで`https://`で配ります。フォークしたリポジトリから自動で配る方法は[config.jsonを書く](/guide/configuration#github-actionsで配るとき)にあります |

どの置き場所でも、`assets/config.json`は上げる前に書き換えておきます。

# なぜバックエンドが要るのか

自分の場所を持つときだけ、バックエンドが1つ要ります。
すでに動いているAxe（[デモサイト](https://axe.xelltis.com)や、誰かが立てた場所）で遊ぶぶんには、何も要りません。

## ブラウザ同士をつなぐ許可証を発行する役

ゲームデータ自体はブラウザ同士のP2Pでやり取りしますが、そのP2P接続を張るにはSkyWayの**認証トークン**が要ります。
トークンはSkyWayのApp ID / Secretで署名して発行するもので、Secretをブラウザに置くわけにはいきません。
そのため、**トークンを発行する小さなバックエンドを1つ**用意します。

卓の中身はここを通りません。バックエンドが渡すのは入室の許可証だけです。

## 用意するもの

1. **SkyWayアカウント**（App ID / Secret。無料枠あり）
2. **バックエンド**（トークン発行用。[バックエンドの選択肢](/guide/backend)から1つ選んでデプロイ）
3. **フロントエンド本体**（リリースのzipを静的ホスティングに配置）

ビルドは要りません。zipを展開して置き、設定を1行書き換えるだけです。

ここまでで、要るものが3つに決まりました。
次の[クイックスタート](/guide/quickstart)は、その3つをどの順で置いていくかの手順です。

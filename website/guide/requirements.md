# なぜバックエンドが要るのか

自分の場所を持つときだけ、バックエンドが 1 つ要ります。
すでに動いている Axe（[デモサイト](https://axe.xelltis.com)や、誰かが立てた場所）で遊ぶぶんには、何も要りません。

## ブラウザ同士をつなぐ許可証を発行する役

ゲームデータ自体はブラウザ同士の P2P でやり取りしますが、その P2P 接続を張るには SkyWay の **認証トークン** が要ります。
トークンは SkyWay の App ID / Secret で署名して発行するもので、Secret をブラウザに置くわけにはいきません。
そのため、**トークンを発行する小さなバックエンドを 1 つ**用意します。

<NetworkDiagram />

卓の中身はここを通りません。バックエンドが渡すのは入室の許可証だけです。

## 用意するもの

1. **SkyWay アカウント**（App ID / Secret。無料枠あり）
2. **バックエンド**（トークン発行用。[バックエンドの選択肢](/guide/backend) から 1 つ選んでデプロイ）
3. **フロントエンド本体**（リリースの zip を静的ホスティングに配置）

ビルドは要りません。zip を展開して置き、設定を 1 行書き換えるだけです。

ここまでで、要るものが 3 つに決まりました。
次の [クイックスタート](/guide/quickstart) は、その 3 つをどの順で置いていくかの手順です。

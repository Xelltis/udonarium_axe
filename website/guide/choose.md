# 方式を選ぶ

このページは、自分の場所に置くAxeを、SkyWay版とサーバー版のどちらで動かすかを決めるためのものです。
参加者から見て何が変わるかを並べ、向いている使いかたを説明します。
サーバーの置き場所（Vercel・Cloudflare・レンタルサーバー）の比べかたは、バックエンドの文書の[どれを置くか](https://xelltis.github.io/udonarium_axe_backend/guide/choose)にあります。

## 早見表

| 項目                 | SkyWay版                                           | サーバー版（ベータ）                                                                    |
| -------------------- | -------------------------------------------------- | --------------------------------------------------------------------------------------- |
| 置くサーバー         | トークン発行サーバー                               | 部屋のサーバー                                                                          |
| 卓のやりとり         | ブラウザ同士で直接                                 | 部屋のサーバーを通る                                                                    |
| 卓の保管             | 参加者が0人になると部屋ごと消える                  | 最後の1人が抜けてから、既定では24時間サーバーに残る                                     |
| 参加者が用意するもの | なし                                               | GMとPLはDiscordのアカウント。ログインしない人は見学になる                               |
| 役割（ロール）       | 各自が選ぶ                                         | サーバーが決める。GMが割り当てる                                                        |
| ダイス               | 振った人のブラウザで振る                           | チャットのダイスはサーバーが振る。ダイス表と4,000字を超える行は振った人のブラウザで振る |
| 見えない情報         | 全員のブラウザに届き、各自の画面で隠す             | 見てよい人にしか届けない。ただし全員に届くものもある（下の注意）                        |
| 画像と音声           | ブラウザ同士で送る。持っている人が抜けると届かない | 部屋ごとにサーバーに置き、その部屋の参加者だけが受け取る。部屋と一緒に消える            |
| 使えるAxe            | どの版でも                                         | v1.68.0から                                                                             |
| SkyWayのアカウント   | 要る                                               | 要らない                                                                                |

::: warning サーバー版でも全員に届くもの
画像と音声のファイル、公開範囲を絞ったキャラクター・カード・ダイスの詳細、名前を隠したキャラクターと持ち主のいないダイスの名前、GMにだけ見せるスイッチ・地形・エフェクト、スイッチで伏せた物、暗闇や霧で隠したコマは、サーバー版でも全員のブラウザに届きます。
どれも各自の画面で隠したり動かしたりしているためです。
画面には出ませんが、改造したブラウザなら読めます。
くわしくは、バックエンドの文書の[わざと隠さないもの](https://xelltis.github.io/udonarium_axe_backend/server/#わざと隠さないもの)にあります。

ログインしていない見学の人のIDは、ほかの見学の人でも名乗れます。
そのためAxeは、見学の人を、見せる相手・オーナー・秘話の相手に選ばせません。
見学の人が送った秘話（あとから秘話にした発言を含む）と、振ったシークレットダイスの結果は、同じIDを名乗った人にも届きます。
:::

## SkyWay版が向いているとき

- 参加者にアカウントを作ってもらわずに、すぐ入ってもらいたい
- 身内の卓で、毎回最後に保存して続きを遊ぶ
- サーバーに卓を預けたくない。預かるものを増やしたくない

SkyWay版のトークン発行サーバーは、許可証を渡すだけで、卓の中身を預かりません。
その代わり、卓を残すのは参加者の[保存](/manual/save-load)だけです。

## サーバー版が向いているとき

- 全員が抜けても、卓をしばらくサーバーに残しておきたい
- 裏向きのカードや秘話を、見てはいけない人のブラウザに届けたくない
- GMが役割を決め、ログインしない人は見学にしたい
- 人数が多い卓で、つながりかたを軽くしたい

サーバー版は、まだベータです。
SkyWay版にある機能はすべて動くように作っていますが、実際の卓で使った数はまだ多くありません。
不具合を見つけたら、[Issue](https://github.com/Xelltis/udonarium_axe/issues)で知らせてください。

身内の外にも開いて運営するなら、預かるものと消えるときを、バックエンドの文書の[運営の方針](https://xelltis.github.io/udonarium_axe_backend/operate/policies)で確かめてください。
プライバシーポリシーと利用規約のひな形も、そこから開けます。

## あとから変えられるか

変えられます。
方式は、Axe本体の`assets/config.json`の`transport`で決まります（→ [config.jsonを書く](/guide/configuration)）。
書き換えて置き直せば、次に開いた人から新しい方式になります。

- 1つの配信先で使えるのは、どちらか片方です。部屋ごとには選べません
- 両方を使いたいときは、Axe本体を2か所に置き、それぞれの`config.json`で方式を変えます
- 方式を変えても、部屋そのものは移りません。続きを遊ぶときは、GMの保存を新しい方式の部屋で読み込みます

SkyWay版の卓をサーバー版の部屋で読み込むと、前の参加者の手札や秘話を見学の人がのぞけることがあります。
GMの手直しが要ります（→ [保存と読み込み](/manual/save-load)）。

## サーバーの選択肢

方式を決めたら、置くサーバーを選びます。
手順は、どれもバックエンドの文書にあります。

| 方式       | 置き場所                   | 向いている人                          | 手順                                                                                              |
| ---------- | -------------------------- | ------------------------------------- | ------------------------------------------------------------------------------------------------- |
| SkyWay版   | Vercel                     | まず手軽に置きたい人                  | [Vercelに置く](https://xelltis.github.io/udonarium_axe_backend/skyway/vercel)                     |
| SkyWay版   | 借りているレンタルサーバー | PHPが動くサーバーをすでに借りている人 | [レンタルサーバーに置く](https://xelltis.github.io/udonarium_axe_backend/skyway/php)              |
| SkyWay版   | Cloudflare Workers         | ターミナルでコマンドを打てる人        | [Cloudflareに置く（SkyWay版）](https://xelltis.github.io/udonarium_axe_backend/skyway/cloudflare) |
| サーバー版 | Cloudflare                 | 迷ったらこちら                        | [Cloudflareに置く](https://xelltis.github.io/udonarium_axe_backend/server/cloudflare)             |
| サーバー版 | Vercel                     | Vercelにまとめたい人                  | [Vercelに置く](https://xelltis.github.io/udonarium_axe_backend/server/vercel)                     |

サーバー版でCloudflareとVercelのどちらにするかは、[サーバー版：Cloudflare版かVercel版か](https://xelltis.github.io/udonarium_axe_backend/guide/choose#サーバー版-cloudflare版かvercel版か)にあります。
Vercel版は数分ごとにつなぎ直し、使っているVercelのWebSocketはまだベータです。

本家ユドナリウムのトークン発行サーバー（[TK11235/udonarium-backend](https://github.com/TK11235/udonarium-backend)）も、SkyWay版でそのまま使えます。
すでに本家用に立てているなら、`config.json`の`backend.url`をそこへ向けるだけで済みます。

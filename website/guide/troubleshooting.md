# 設置で困ったとき

このページは、自分で置いたAxeで、ページが開けない・部屋を作れない・入れないときに確かめることをまとめたものです。
出ている表示ごとに、原因と直しかたを並べています。
遊んでいる最中のつまずき（音が出ない、画像が見えないなど）は[困ったとき](/help/)にあります。

## まず確かめること

上から順に確かめると、どこで止まっているかが分かります。

1. **サーバーが動いているか** — [サーバーを置く](/guide/backend)の「動いているかを確かめる」の手順で確かめます。ここで止まっているときは、Axeの側を直しても、つながりません
2. **`config.json`が読めているか** — AxeのページをChromeで開き、開発者ツール（Windowsは`F12`、Macは`⌘`＋`⌥`＋`I`）の**Network**（日本語の表示では**ネットワーク**）タブを開いてから、ページを読み込み直します。一覧の`config.json`を選び、Statusが`200`で、**Response**（**レスポンス**）に自分の書いた値が出ているかを見ます
3. **Axeの表示を見る** — ロビー（部屋の一覧）と、チャットの**システム**タブに出ている文を、下の表で探します

`config.json`のStatusが`404`のときは、`assets/config.json`の置き場所が違います。
`index.html`と同じフォルダに`assets`のフォルダがあるかを確かめてください。
Responseに前の値が出ているときは、書き換えたファイルが上がっていないか、古いファイルがキャッシュに残っています（→ [更新するとき](/guide/update#_3-置き直す)）。

開発者ツールの開きかたは、バックエンドの文書の[開発者ツールを開く](https://xelltis.github.io/udonarium_axe_backend/guide/prepare#開発者ツールを開く)にもあります。

## ページが開けない・真っ白になる

| 見えるもの                                 | 原因と直しかた                                                                                                            |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------- |
| `404`や「ページが見つかりません」          | URLが違うか、展開したフォルダを1段深く置いています。`index.html`が、AxeのURLのすぐ下にあるかを確かめます                  |
| 真っ白のまま何も出ない                     | `http://`で配っていないかを確かめます。Axeは`https://`のページでしか正しく動きません（自分のパソコンの`localhost`は除く） |
| 真っ白のまま何も出ない（`https://`なのに） | 一部のファイルが上がっていません。展開したフォルダの中身を、まるごと上げ直します                                          |

## ロビーに出る表示

| 表示                                                                                 | 原因と直しかた                                                                                                                                                                           |
| ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| まだサーバーにつながっていません。しばらく待ってから「一覧を更新」を押してください。 | つなぎに行っている途中です。数秒待ってから**一覧を更新**を押します。何度押しても変わらないときは、下の表示に変わるのを待ちます                                                           |
| サーバーにつながっていません。少し置いてから、ページを再読み込みしてください。       | 何度か試してもサーバーにつながらず、あきらめた状態です。[まず確かめること](#まず確かめること)の1と2を確かめます                                                                          |
| ルーム一覧の取得に失敗しました。「一覧を更新」で再検索できます。                     | 部屋の一覧を受け取れませんでした。**一覧を更新**を押します。サーバー版で続くときは、`backend.url`の部屋のサーバーに届いていません。URLが合っているか、サーバーが動いているかを確かめます |
| 接続先（config.json の backend.url）が設定されていません                             | サーバー版で、`config.json`の`backend.url`が空か、URLとして読めません（→ [config.jsonを書く](/guide/configuration#backend-url)）                                                         |
| このサーバーにはログインが用意されていないため、部屋を使えません                     | 部屋のサーバーに、ログインの設定（Discordの2つと`SESSION_SECRET`）が入っていません。サーバーの設定を見直します                                                                           |
| サーバー版なのに、ロビーの上に**Discordでログイン**が出ない                          | `config.json`の`transport`が`"server"`になっていないか、書き換えたファイルが上がっていません                                                                                             |

## チャットに出る表示（SkyWay版）

チャットの**システム**タブに出ます。
最初はメインタブが開いているので、**システム**のタブを押して切り替えます。
読んでいない表示があると、タブに数が付きます。

<Shot src="guide-chat-skyway-error" alt="チャットウィンドウのシステムタブ。「再接続を試みます...」が2回続いたあとに「SkyWayのバックエンドサーバに接続できません。ネットワーク設定を確認して、ページを再読み込みしてください。」と出ている" width="640" caption="トークン発行サーバーに届かないとき。開いてから30秒ほどで、この表示になります" />

| 表示                                                                                                     | 原因と直しかた                                                                                                                                                                                                                       |
| -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 再接続を試みます...                                                                                      | トークン発行サーバーから許可証をもらえず、少し置いて試し直しています。続けて下の表示が出るかを待ちます                                                                                                                               |
| SkyWayのバックエンドサーバに接続できません。ネットワーク設定を確認して、ページを再読み込みしてください。 | 試し直しても許可証をもらえませんでした。`config.json`の`backend.url`がトークン発行サーバーを指しているか、サーバーの`ACCESS_CONTROL_ALLOW_ORIGIN`がAxeのOriginになっているか、`SKYWAY_APP_ID`と`SKYWAY_SECRET`が正しいかを確かめます |
| ネットワークエラーが発生しました。(…)                                                                    | SkyWayとのつながりでエラーが起きました。自動でつなぎ直します。かっこの中はエラーの種類です。開いてすぐ`(TypeError)`が出て、続けて「再接続はこれで最後です。…」が出るときは、`backend.url`がひな形の文のままか、URLとして読めません   |
| 再接続はこれで最後です。つながらないときは、少し置いてからページを再読み込みしてください。               | つなぎ直しが続けて失敗しています。回線を確かめ、少し置いてから読み込み直します                                                                                                                                                       |
| 別のタブでこの部屋に入っているか、前の接続がまだ切れていません。…                                        | 同じ人が、別のタブや前の接続でまだ部屋にいます。別のタブを閉じるか、1分ほど待ってから入り直します                                                                                                                                    |
| SkyWayの認証トークンが期限切れになりました。再接続します。                                               | 長く部屋にいて、許可証の期限が切れました。自動でつなぎ直すので、そのまま待ちます                                                                                                                                                     |

参加者どうしが直接つながれない回線では、SkyWayの中継サーバーを通ります。
そのときは、接続の品質の表示に「中継サーバー経由の接続があります。…」と出ます。
遅くなりやすいだけで、つながってはいます。

## チャットに出る表示（サーバー版）

| 表示                                                                                     | 原因と直しかた                                                                                                                                                     |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 部屋のサーバーにつながりません                                                           | 部屋のサーバーに届かないか、つなぎ直しをあきらめました。[サーバーを置く](/guide/backend#room-server)の確かめかたで、サーバーが動いているかを見ます                 |
| 接続先（config.json の backend.url）が設定されていません                                 | `backend.url`が空か、URLとして読めません                                                                                                                           |
| 新しい版のAxeが公開されています。ページを再読み込みしてください                          | 部屋のサーバーが、この画面の版を受け付けません。Axe本体が古いときは、新しい版に置き換えます（→ [更新するとき](/guide/update)）                                     |
| ログインの期限が切れたか、別のアカウントでログインし直しました。部屋に入り直してください | ログインが切れました。ロビーでログインし直してから、部屋に入り直します                                                                                             |
| 部屋が満員です（32人まで）                                                               | 1つの部屋に入れるのは32人までです                                                                                                                                  |
| 部屋のサーバーに接続を断られました（…）                                                  | 部屋のサーバーが、この画面のやりとりを受け付けませんでした。かっこの中のコードを添えて、[Issue](https://github.com/Xelltis/udonarium_axe/issues)で知らせてください |

パスワードの違い、部屋が見つからない、GMが部屋を削除した、といった表示は、遊ぶ人の操作で出るものです。
設置の問題ではありません（→ [部屋とロビー](/manual/rooms)）。

## ログインできない（サーバー版）

ロビーの上のログインの欄に出ます。

| 表示                                                                      | 原因と直しかた                                                                                                                                                                                                      |
| ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Discordの画面に「Invalid OAuth2 redirect_uri」と出る                      | Discordのアプリに、部屋のサーバーの戻り先（`https://<部屋のサーバーのURL>/v1/login/discord/callback`）が入っていません（→ [Discordのアプリを作る](https://xelltis.github.io/udonarium_axe_backend/server/discord)） |
| ログインがキャンセルされました                                            | Discordの画面で、許可を取り消しました。もう一度**Discordでログイン**を押します                                                                                                                                      |
| Discordとのやりとりに失敗しました。しばらくしてからもう一度試してください | 部屋のサーバーとDiscordのやりとりが失敗しました。Discordのアプリの`DISCORD_CLIENT_SECRET`が正しいかを確かめます                                                                                                     |
| ログインの試行が続いたため、しばらく受け付けられません                    | 短いあいだにログインを何度も試しました。少し置いてから試します                                                                                                                                                      |
| ログインのサーバーにつながりません                                        | 部屋のサーバーに届きません。`backend.url`と、サーバーが動いているかを確かめます                                                                                                                                     |
| ログインをやり直してください                                              | ログインのやりとりが途中で途切れました。もう一度**Discordでログイン**を押します                                                                                                                                     |
| ログインしたあとAxeに戻らない                                             | 部屋のサーバーの`ACCESS_CONTROL_ALLOW_ORIGIN`が`*`になっていないかを確かめます。AxeのOriginを名前で書きます                                                                                                         |
| 部屋を作るにはログインが要ります                                          | ログインせずに部屋を作ろうとしました。先にログインします                                                                                                                                                            |

## 更新のあと

| 表示                                                                     | 原因と直しかた                                                                                                         |
| ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| Udonarium Axe が更新されました                                           | 開いていた画面より新しい版に置き換わりました。**再読み込み**を押します（→ [更新するとき](/guide/update#参加者の画面)） |
| 画面の一部を読み込めませんでした。ページを再読み込みしてください         | 同じ理由です。部屋を保存してから、読み込み直します                                                                     |
| 保存できませんでした。ページを再読み込みしてから、もう一度お試しください | 保存に使うファイルが新しい版に置き換わっていました。読み込み直してから、もう一度保存します                             |

## それでも直らないとき

[Issue](https://github.com/Xelltis/udonarium_axe/issues)で知らせてください。
次のことを書いてもらえると、早く調べられます。

- Axeの版（ブラウザのタブの題に出ています）と、方式（SkyWay版かサーバー版か）
- 置いた場所（Cloudflare Pagesなど）と、サーバーの置き場所
- 出ている表示と、そこまでにした操作
- 開発者ツールの**Console**（**コンソール**）タブに出ている赤い行

サーバーのシークレットキーや`SESSION_SECRET`などの秘密の値は、書かないでください。
`config.json`の中身（サーバーのURL）は、書いても構いません。

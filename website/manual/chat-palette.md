# チャットパレット

このページは、キャラクターごとに、よく使う発言や判定のコマンドを並べておく「チャットパレット」を説明します。
行を押すだけで入力欄に入り、もう一度押すと送れるので、判定のたびにコマンドを打つ手間がなくなります。
GMとPLが使えます。

## 開く

キャラクターのコマを右クリックし、**チャットパレットを表示**を押します。
PLツールバーの[所有キャラクター一覧](/manual/pl-tools#所有キャラクター一覧)からも開けます。

## 行をクリックして送る

パレットの行を**クリック**すると、その内容が入力欄に入ります。修正値を書き足してからEnterで送れます。
書き足すものがなければ、同じ行をすぐに**もう一度クリック**するだけで送信されます。タッチ操作ではタップと2回タップです。

行を**右クリック**して **「ホットバーに入れる」** を選ぶと、パレットを開かなくても[ホットバー](/manual/hotbar)から送れます。

どのタブに送るかは、いちばん上のタブで選びます。タブの上でマウスホイールを回すと、チャットウィンドウと同じく
隣のタブへ移ります。並ぶのは自分のロールで読めるタブだけで、発言できないタブを選ぶと入力欄は閲覧のみに
なります。

発言の色は、入力欄の右上にある調整ボタンの中にしまってあります。押すと色の丸と**色設定**が出ます。
[卓上ディスプレイ](/manual/tabletop#tabletop-display)で外周ティッカーを使っているときは、ティッカーへ流す
切り替えも同じ場所にあります。

立ち絵を何枚も登録したキャラクターは、立ち絵の下の帯で表情を切り替えられます。左右の矢印で1枚ずつ送り、
名前を押すと一覧から選べます。

## 行を探す

入力欄の下のボタンの行には、目当ての行を探す道具が2つあります。

| 道具   | 使いかた                                                                                                                 |
| ------ | ------------------------------------------------------------------------------------------------------------------------ |
| 検索欄 | 言葉を打つと、それを含む行が検索欄のすぐ下に並びます。上下キーで選んで`Enter`を押すと入力欄に入り、`Esc`で検索を消します |
| 見出し | 見出しの一覧から選ぶと、その見出しの位置まで一覧を送ります                                                               |

パネルの幅を狭めると、この行のボタンは文字が消えてアイコンだけになります。

## 編集する

1. **編集**を押します。「編集中」になり、パレットの中身をそのまま書き換えられます。
2. 1行に1つの発言を書きます。
3. 書き終えたら、**確定**を押します。

`◆基本判定`や`//---基本判定`のように書いた行は見出しになり、見出しの一覧に載ります。

**キャラ情報**を押すと、そのキャラクターのデータを読むだけの表示に切り替わります。**パレットに戻る**で戻ります。

登録したコマンドはキャラクターに紐づいて保存され、ダイスボットのコマンド（例: `2d6`）もそのまま使えます。
ダイスの記法は[ダイスボット](/manual/dicebot)に、リソース操作（`:HP-5`）や変数（`{HP}`・`//変数=値`）などの記法は[チャットの特殊記法](/manual/chat-syntax)にあります。

## うまくいかないとき

| 見えるもの                             | 原因と直しかた                                                                                                                   |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 入力欄が閲覧のみになって、送れない     | いちばん上のタブで、発言できないタブを選んでいます。書けるタブに切り替えます                                                     |
| 行を押しても、見出しのまま送られない   | `◆`や`//---`で始まる行は見出しで、送る行ではありません                                                                           |
| `{HP}`が数字にならず、そのまま送られる | そのキャラクターに、その名前の項目がありません。名前を確かめます（→ [チャットの特殊記法](/manual/chat-syntax#項目と変数の参照)） |
| 書き換えたのに、パレットが元のまま     | **確定**を押していません                                                                                                         |

# ジュークボックス（音楽）

BGM や効果音（SE）を再生・管理します。FAB メニューの **メディア** にある「ジュークボックス」から開きます。

<Shot src="jukebox" alt="ジュークボックスパネル。試聴・BGM・SE・全体の音量スライダーが並んでいる" width="380" caption="BGM と SE を分けて管理し、音量も個別に調整します" />

## 音源を追加する

ドロップゾーンに音楽ファイルをドラッグ＆ドロップ、またはクリックして選択します。
**ライブラリ** と **再生リスト** のタブで表示を切り替えられます。

## 再生と音量

- 再生・停止・シーク（再生位置の移動）・リピート
- **試聴 / BGM / SE / 全体** など複数の音量スライダー
- 「全体音量の変更を有効化」で部屋全体の音量も操作可能

## 効果音（SE）

各音源のタグを **SE** にすると、効果音として扱われます。

- SE は **BGM を止めずに、その上に重ねて** 鳴ります。複数の SE を同時に重ねることもできます。
- ライブラリの各行のボタンで **▶ 再生 ↔ ■ 停止** を切り替えられます（再生中の行には再生インジケータが表示されます）。
- 再生・停止はどちらも参加者全員に同期されます。音量は **SE スライダー** で個別に調整できます。

## 同期とミニプレイヤー

- BGM はシーク位置を含めて参加者間で同期されます（必要に応じてクロスフェード）
- 再生中の曲の操作だけを切り出した**ミニプレイヤー**が卓上に浮かびます。ドラッグで移動でき、丸いボタンに畳めます
- 表示の切り替えは FAB メニューの[ウィジェット](/manual/#ウィジェット)で行います。**隠しても BGM は流れ続けます**

BGM と独立して鳴らす演出は [カットイン](/manual/cut-in) を参照してください。

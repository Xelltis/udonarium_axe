# 部屋設定

<Shot src="room-settings" alt="部屋設定パネル。ラウンド・ダイス・コマの向き・移動範囲の設定が縦に並んでいる" width="560" caption="テーブルをまたいで効く設定はここにまとまっています" />

卓の決めごとは、地図ではなく部屋のものです。移動範囲や ZOC はこれまで [テーブル設定](/manual/table-setting) にあったので、テーブルを 1 枚増やすたび同じ値を入れ直すことになっていました。ここはその置き場です。

FAB メニューの **部屋のアイコン** から開きます。編集できるのは GM と PL で、見学者は開けても書き換えられません（どの見出しも読むことはできます）。

中身は 5 つに分かれています。

| 見出し         | 入っているもの                         |
| -------------- | -------------------------------------- |
| 一般           | 既定のダイスボット、コマの向きの示し方 |
| 戦闘           | ラウンドの進め方、陣営、バフの減り方   |
| 移動           | 移動範囲、ZOC、1 マスの距離と単位      |
| 自動保存       | この端末に残す部屋のひかえ（下記）     |
| ユーティリティ | キャラクターの取り込み                 |

初めて使うなら「ラウンド」の節だけ読めば足ります。残りは必要になったときに引いてください。

## ラウンドは 1 体ずつか、陣営ごとか

**進行のしかた** で選びます。

- **1 体ずつ（並び順どおり）** — これまでどおり。インベントリの並び順で手番が回ります
- **陣営ごと（フェイズ制）** — 味方が全員動いてから敵が全員動く、スーパーロボット大戦のような進み方になります

陣営ごとを選ぶと、ラウンドは「陣営のフェイズ」を順に開いていく形になります。ひとつ閉じれば次が開き、最後まで行けばラウンドが終わります。

同じ欄の **ラウンドが進むとバフの残りを減らす** は、どちらの進め方でも効きます。外すとバフの残ラウンドは自動では減らなくなり、[バフ](/manual/buff)は手で管理することになります。

### 陣営には[パーティ](/manual/party)がそのまま使われる

陣営を別に作る必要はありません。すでに編成してあるパーティが、そのまま 1 つの陣営になります。どのパーティにも入っていないコマは「無所属」という 1 つの陣営に集まります。

**陣営の順番** の一覧で、上下の矢印を押して回る順を入れ替えます。上にあるものから順にフェイズが来ます。無所属を先攻にしたければ一番上へ動かせますし、**パーティに入っていないコマは行動しない** を入れれば行動順から外れます。

順番を書き留めるのは、あなたが矢印を押したときだけです。誰かが戦闘中にパーティを増やしても、そのパーティは黙って末尾に加わります。逆にフェイズの途中でパーティを解散しても、ラウンドはそこで固まらず、まだ動いていない陣営へ移ります。

### フェイズの中は自由か、並び順どおりか

**フェイズ内の順番** で決めます。

- **自由** — フェイズが開いても手番は誰にも渡りません。動かしたいコマをクリックするとその手番になり、直前に動いていたコマは行動済みになります
- **並び順どおり** — フェイズが開いた時点で先頭のコマに手番が渡り、インベントリの並び順に 1 体ずつ回ります

どちらでも **次へ** の働きは同じで、その陣営のまだ動いていないコマへ手番が渡ります。陣営の全員が動き終えて初めて、次の陣営のフェイズが開きます。

行動順ウィジェットは、陣営ごとに区切って表示されます。詳しくは [行動順](/manual/turn-order#陣営ごとに動かす) を参照してください。

## 移動範囲と ZOC は、触るまでテーブルのまま

コマが何マス歩けるか、敵の周りのマスが移動をどう妨げるかを決めます。項目そのものの意味は [移動範囲](/manual/move-range) にあります。

ひとつだけ癖があります。**この部屋がまだ答えていない項目は、テーブル側の設定がそのまま使われます。** 今どちらが決めているかは、各セクションの上に出ています。

- **いまはテーブルごとの設定です** — 触っていない状態。テーブルを切り替えると、そのテーブルの値で動きます
- **部屋全体の設定です** — 一度でもここで変えた状態。どのテーブルを出しても同じルールになります

戻したくなったら **テーブルごとに戻す** を押してください。そのセクションの項目がまとめてテーブル側へ返ります。

以前から使っている部屋を新しい版で開いても、このパネルを触らないかぎり挙動は変わりません。

## コマの向きの示し方

俯瞰では絵が常にこちらを向くので、どちらを向いているか分かりません。**示さない / コマごと回す / 矢尻で示す** の 3 つから選びます。見え方の違いは [テーブル設定](/manual/table-setting#コマの見せ方) に表があります。

これも移動範囲と同じ扱いで、触るまではテーブル側の設定が使われます。

## 既定のダイスボット

部屋に入ったとき、最初に選ばれているダイスボットです。入ったあとはチャット欄で選び直せます（[ダイスボット](/manual/dicebot)）。

## 自動保存

卓の変化が落ち着いたころに、部屋のひかえを**この端末の中へ**取ります。ひかえは他の参加者には渡らず、外にも出ません。

**この端末で部屋を自動保存する** を外すと、新しいひかえを取らなくなります。すでにあるひかえはそのまま残り、復元にも使えます。設定はこの端末に覚えるので、同じ部屋を別の端末で開いても、そちらの設定は変わりません。

世代の一覧・復元・削除も同じ見出しの中にあります。詳しくは[保存と読み込み](/manual/save-load#自動保存と復元)を参照してください。

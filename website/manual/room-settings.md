# 部屋設定

このページは、部屋全体の決めごと（ラウンドの進めかた・移動のルール・ダイス・吹き出し・スタンプなど）と、この画面だけの表示の設定をまとめた「部屋設定」を説明します。
テーブルを何枚作っても、ここで決めたことは部屋の全員とすべてのテーブルに効きます。
誰が変えられるかは、タブごとに違います（下の表）。

<Shot src="room-settings" alt="部屋設定パネル。上に一般・戦闘・移動・UI・スタンプ・自動保存・ユーティリティのタブが並び、移動のタブに移動範囲の設定が入っている" width="560" caption="テーブルではなく部屋全体に効く決めごとを、ここで決めます" />

## 開く

FABメニューの**部屋設定**を押します。
見学でも開けて、どのタブも読めます。

| タブ           | 入っているもの                                                            | 変えられる人                   |
| -------------- | ------------------------------------------------------------------------- | ------------------------------ |
| 一般           | 既定のダイスボット、ダイスの演出、吹き出し、リモコンに出す数値とリソース  | GM                             |
| 戦闘           | ラウンドの進めかた、陣営、バフの減りかた                                  | GMとPL（手番の効果音はGMだけ） |
| 移動           | 移動範囲と移動の種類、ZOC、通り抜け、跳躍、マスの距離、交戦エリア、乗り物 | GMとPL                         |
| UI             | 画面の見えかた。**共通**・**スキン**・**卓上**の3つ                       | 共通はGM。スキンと卓上は各自   |
| スタンプ       | スタンプを発言やリアクションに使えるかどうか                              | GM                             |
| 自動保存       | この端末に残す部屋のひかえ                                                | 各自（見学は除く）             |
| ユーティリティ | キャラクターの取り込み、リプレイ、画面の実測、このブラウザのデータの消去  | 各自                           |

GMだけのタブは、ほかの人の画面では、中身は見えても操作できません。
初めて使うなら、[ラウンドの進めかた](#ラウンドの進めかた)だけ読めば足ります。
残りは、必要になったときに引いてください。

## ラウンドの進めかた

**戦闘**のタブの**進行のしかた**で選びます。

| 選択肢                   | 進みかた                                              |
| ------------------------ | ----------------------------------------------------- |
| 1 体ずつ（並び順どおり） | インベントリの並び順で、1体ずつ手番が回ります（既定） |
| 陣営ごと（フェイズ制）   | 味方が全員動いてから、敵が全員動く進みかたになります  |

陣営ごとを選ぶと、ラウンドは「陣営のフェイズ」を順に開いていく形になります。ひとつ閉じれば次が開き、最後まで行けばラウンドが終わります。

同じ欄の**ラウンドが進むとバフの残りを減らす**は、どちらの進めかたでも効きます（既定は入り）。
外すと、バフの残りラウンドは自動では減らなくなり、[バフ](/manual/buff)は手で管理することになります。

### 陣営と[パーティ](/manual/party)

陣営を別に作る必要はありません。すでに編成してあるパーティが、そのまま1つの陣営になります。どのパーティにも入っていないコマは「無所属」という1つの陣営に集まります。

**陣営の順番**の一覧で、上下の矢印を押して回る順を入れ替えます。上にあるものから順にフェイズが来ます。無所属を先攻にしたければ一番上へ動かせますし、**パーティに入っていないコマは行動しない**を入れれば行動順から外れます。

順番を書き留めるのは、あなたが矢印を押したときだけです。誰かが戦闘中にパーティを増やしても、そのパーティはそのまま末尾に加わります。逆にフェイズの途中でパーティを解散しても、ラウンドはそこで固まらず、まだ動いていない陣営へ移ります。

### フェイズの中の順番

**フェイズ内の順番**で決めます。

| 選択肢                     | 進みかた                                                                                                                 |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 自由（誰から動いてもよい） | フェイズが開いても、手番は誰にも渡りません。動かしたいコマを押すとその手番になり、直前のコマは行動済みになります（既定） |
| 並び順どおり               | フェイズが開いた時点で先頭のコマに手番が渡り、インベントリの並び順に1体ずつ回ります                                      |

どちらでも**次へ**の働きは同じで、その陣営のまだ動いていないコマへ手番が渡ります。陣営の全員が動き終えて初めて、次の陣営のフェイズが開きます。

行動順のウィジェットは、陣営ごとに区切って表示されます。くわしくは[行動順](/manual/turn-order#陣営ごとに動かす)にあります。

## 手番の効果音

**戦闘**のタブの「手番の効果音」で、手番が始まったときに鳴らす音を決めます。切り替えられるのはGMだけで、ほかの参加者には今の設定だけが見えます。

| 項目                             | 鳴る場面                                                                            | 既定値 |
| -------------------------------- | ----------------------------------------------------------------------------------- | ------ |
| 自分の手番でシグナルを鳴らす     | 自分のキャラクターの手番が始まると、その持ち主の画面でだけ鳴ります                  | 入り   |
| ほかの人の手番でティックを鳴らす | ほかの人のキャラクターやNPCの手番が始まると、ほかの全員の画面で控えめに一音鳴ります | 切り   |

鳴る場面と鳴らない場面は[行動順](/manual/turn-order#手番の効果音)にまとめてあります。

## 移動範囲とZOC

**移動**のタブでは、コマが何マス歩けるか、敵の周りのマスが移動をどう妨げるか、ほかのコマが立っているマスを通れるかを決めます。
項目の意味は[移動範囲](/manual/move-range)にあります。
主な項目と既定値は、次のとおりです。

| 項目                                              | 既定値                               |
| ------------------------------------------------- | ------------------------------------ |
| コマを持ち上げたら移動できるマスを表示する        | 入り                                 |
| 選んだコマの移動範囲を出したままにする            | 切り                                 |
| 厳密な移動                                        | 切り                                 |
| グリッドなしの卓では、経路を折れ線で引く          | 切り                                 |
| 斜め移動                                          | 1 マスとして数える                   |
| 参照する項目                                      | `移動,移動力,Speed,速度`             |
| マスの単位・1 マスの距離                          | マス・1                              |
| 同じマスに複数のコマを置ける                      | 入り                                 |
| サイズが 2 マス以上違う相手のマスは通り抜けられる | 切り                                 |
| 通り抜けの追加コスト                              | 1                                    |
| 大きなコマを、通れない隙間に押し込めるようにする  | 切り                                 |
| 跳躍の距離                                        | 0（移動力いっぱい）                  |
| 掴んで運んだときも、通り道の仕掛けを発動させる    | 切り                                 |
| ZOC（支配領域）                                   | テーブルの値（新しいテーブルはなし） |
| 敵味方の分け方                                    | NPC かどうかで分ける                 |
| ZOC の広さ                                        | 1                                    |

ほかのコマの通り抜けは、**同じパーティのコマ**・**別のパーティのコマ**・**未所属のコマ**の3つに分かれていて、どれも触るまでは**同じマスに複数のコマを置ける**に従います。味方の脇をすり抜けさせたい卓だけが触れば足ります。

同じところに、卓の細かい決めごとも並んでいます。**大きなコマを、通れない隙間に押し込めるようにする**、**跳躍の距離**（一度の跳躍が何マスまでか）、**掴んで運んだときも、通り道の仕掛けを発動させる**（手で運んだコマが通った道の罠を作動させるかどうか）の3つです。どれも、切ってある状態や0のままなら今までと同じ動きで、入れたときだけ変わります。

::: warning この部屋でまだ決めていない項目は、テーブルの設定がそのまま使われます
いまどちらが決めているかは、**移動範囲**と**ZOC（支配領域）** の欄の上に出ています。

| 出ている文                      | 状態                                                                   |
| ------------------------------- | ---------------------------------------------------------------------- |
| いまはテーブルごとの設定です。… | 触っていない状態。テーブルを切り替えると、そのテーブルの値で動きます   |
| 部屋全体の設定です。…           | 一度でもここで変えた状態。どのテーブルを出しても、同じルールになります |
| :::                             |

一度この画面で決めた項目は、以後その部屋の決めごとになります。テーブルごとの値へ戻すボタンはありません。

以前から使っている部屋を新しい版で開いても、このパネルを触らないかぎり挙動は変わりません。

同じ**移動**タブには、[交戦エリア](/manual/engagement-zone)と[乗り物](/manual/ride)の設定もあります。どちらもテーブルごとの値を持たず、部屋全体で決めます。

## UI

画面の見えかたをまとめたタブです。
中は、さらに**共通**・**スキン**・**卓上**の3つに分かれています。

### 共通

部屋の全員に効き、変えられるのはGMだけです。GM以外の画面では操作できない見た目になります。

| 見出し     | 入っているもの                                                                                     |
| ---------- | -------------------------------------------------------------------------------------------------- |
| コマの向き | キャラクターの向きの示し方                                                                         |
| 2D表示     | コマ画像をマス内に収める（真上から見ているあいだだけ効きます）                                     |
| 3D表示     | コマ画像を常にカメラに向ける（斜めから見ているあいだだけ効きます。いま見ているテーブルに入ります） |

### スキン

画面の配色です。この画面にだけ効きます（[テーマ](/manual/theme#skin)）。

### 卓上

この画面にだけ効きます。
大きなディスプレイを何人かで囲んで見る、対面のセッション向けの設定です。
1人で2Dで見ているだけなら、ここは触らなくて構いません。

先頭の**卓上ディスプレイ用の推奨設定をオン**で、下の項目がまとめて推奨値になり、この画面が2D表示になります。
切ると項目は既定に戻り、視点はそのままです。

| 見出し                | 入っているもの                                         |
| --------------------- | ------------------------------------------------------ |
| メニューの出し方      | コンテキストメニューの形（通常 / 四方向 / 回転）       |
| コマの見せ方          | コマの詳細表示、コマ名の周回、リソースバフ、文字サイズ |
| 外周ティッカー        | 表示と速度                                             |
| 画面とウィンドウ      | 遠近をなくす、ウィンドウの90°回転                      |
| 1マスの実寸と実寸表示 | 1マスの実寸、1マスを実寸で表示、ビューを固定する       |

2Dで見ることと、画面を寝かせて囲むことは別です。
視点を2Dにしただけでは、ここの設定は何も入りません。

## 既定のダイスボット

**一般**のタブの**ダイス**で、部屋に入ったときに最初に選ばれているダイスボットを決めます。
既定は「DiceBot」（ゲームシステムを選んでいない状態）です。
入ったあとは、チャット欄で選び直せます（→ [ダイスボット](/manual/dicebot)）。
変えられるのはGMだけです。

## ダイスの演出

チャットで振ったダイスを3Dで転がすかどうかと、どこで転がすかです。
**出さない**（既定）・**セリフの枠**・**卓の上**・**両方**から選びます。
変えられるのはGMだけです。見え方は[ダイス](/manual/dice#roll-in-3d)にまとめてあります。

## 吹き出し

キャラクターの発言を、そのコマの頭上に吹き出しで数秒出すかどうかです。既定では出します。**キャラクターの発言を頭上の吹き出しに出す**を外すと、部屋の全員の画面で吹き出しが出なくなります。変えられるのはGMだけです。

吹き出しに出るのは、卓上のキャラクターとして話した公開の発言です。「」があれば、その中だけが出ます。秘話・シークレット・ダイスやコマンドの行には出ません。[ノベルモード](/manual/visual-novel)を開いている画面にも出ません。

自分の画面でだけ隠したいときは、ツールバーの吹き出しのアイコンを押します（[PLツールバー](/manual/pl-tools#リソースバーとバフを隠す)）。部屋で止めているあいだは、ツールバーで表示にしても出ません。

## リモコンに出す数値とリソース

部屋のコマが持つ数値とリソースを名前ごとにまとめて並べ、そのうちどれを[リモコン](/manual/character)に出すかを
選べます。ここで外した名前は、リモコンのリソース操作のボタンからも、右のコマの欄からも消えます。
シートの項目そのものは何も変わりません。

触っていない部屋では全部出します。1つでも外すと「選んだものだけを出す」状態になり、あとからシートに足した
項目は、ここで選ぶまで出ません。元の全部出す状態に戻すには**すべて出す**を、一度空にするなら
**すべて外す**を押します。

変えられるのはGMだけで、選んだ内容は部屋の全員に効きます。

## スタンプ

**スタンプ**タブでは、部屋で[スタンプ](/manual/chat)をどう使えるかを決めます。使い道は次の2つで、それぞれに欄があります。

- **スタンプの発言** — スタンプを発言として送る使い方
- **リアクション** — 発言にスタンプを付ける使い方

どちらの欄でも、使い道をまるごと止めることも、スタンプを選んで使えなくすることもできます。

まるごと止めるには、**スタンプを発言として送れるようにする**、**発言にリアクションを付けられるようにする**のチェックを外します。発言のほうを止めると入力欄のスタンプボタンが、リアクションのほうを止めると発言の**リアクション**のボタンとメニューの項目が出なくなります。

スタンプを選んで使えなくするときは、チェックの下の一覧を使います。一覧は、描き文字・判子・判定・戦闘・探索・気持ち・会話の系統ごとと、部屋のスタンプのセットごとに分かれています。まとまりの名前の横には、使えるスタンプの数と全体の数が出ます。

- スタンプを押すと、使える・使えないが切り替わります。使えないスタンプは薄く表示され、印が付きます
- **すべて使える**と**すべて使えない**で、そのまとまりのスタンプをまとめて切り替えます
- 使えなくしたスタンプは、スタンプを選ぶ一覧に出ません

使い道をまるごと止めているあいだは、一覧が出ません。選んで使えなくした分は残っていて、チェックを入れ直すとその状態に戻ります。

決まりが効くのは、これから使う分だけです。決まりを変える前に送ったスタンプの発言や付けたリアクションは、そのまま表示されます。自分が付けたリアクションは、あとから使えなくなったスタンプでも外せます。

変えられるのはGMだけで、決めた内容は部屋の全員に効きます。GM以外の画面でも中身は見られますが、操作はできません。

## 自動保存

テーブルの変化が落ち着いたころに、部屋のひかえを、この端末の中へ取ります。ひかえは他の参加者には渡らず、外にも出ません。

**この端末で部屋を自動保存する**を外すと、新しいひかえを取らなくなります。すでにあるひかえはそのまま残り、復元にも使えます。設定はこの端末に保存されるので、同じ部屋を別の端末で開いても、そちらの設定は変わりません。

世代の一覧・復元・削除も、同じタブの中にあります。
くわしくは[保存と読み込み](/manual/save-load#自動保存)にあります。
見学のときは、このタブは操作できません。

## このブラウザのデータをすべて消す

**ユーティリティ**タブのいちばん下にある**危険な操作**の欄から、このブラウザに残っているデータをまとめて消せます。表示や動きがおかしいままで、読み込み直しても直らないときに試してください。

消えるのは次のデータです。消したデータは元に戻せません。

- 自分の設定（表示・音量・スキン・ウィジェットの配置など）
- 部屋の自動保存とリプレイの記録
- マイダイスとスキンの画像
- 部屋のサーバーへのログインと、読み込み直したときに同じ席へ戻るための記録

ボタンを押すと、確かめるダイアログが出ます。**すべて消して読み込み直す**を選ぶとページを読み込み直し、アプリが動き出す前にデータを消すので、初めて開いたときと同じ状態から始まります。

読み込み直すと、いまの部屋からはいったん抜けます。招待リンクで入っていたときは、そのリンクから入り直します。SkyWayでは別の参加者として入り、前の席の手札とGMの役割は引き継がれません。部屋のサーバーでは、ログインし直すまで見学になります。ロビーから入っていたときは部屋の外に戻るので、ロビーから入り直してください。部屋のコマやチャットはほかの参加者の画面か部屋のサーバーに残りますが、SkyWayやオフラインでひとりで遊んでいるときは、保存していない部屋の内容も消えます。部屋のサーバーとの接続が切れているとき、大きな削除や読み込みをまだ送っているとき、まだサーバーに上がっていない画像や音声があるときは、確認にそのことも出ます。残したい部屋は、先に[保存](/manual/save-load)してください。同じブラウザのほかのタブでも開いているときは、そちらを先に閉じてください。

見学を含め、どのロールでも使えます。消えるのはこのブラウザのデータだけで、ほかの参加者のブラウザのデータは消えません。

## うまくいかないとき

| 見えるもの                                              | 原因と直しかた                                                                                                               |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 設定が薄く出ていて、変えられない                        | そのタブはGMだけが変えられるか、見学です。上の表で、変えられる人を確かめます                                                 |
| 移動範囲の設定を変えたのに、別のテーブルで効かない      | その項目を、この部屋でまだ一度も変えていません。欄の上が「いまはテーブルごとの設定です」なら、一度変えると部屋全体になります |
| テーブルごとの設定に戻したい                            | 一度部屋で決めた項目は、テーブルごとの値へ戻せません                                                                         |
| 部屋設定に「移動範囲の「交戦」もオンになっています。…」 | ZOCの近接状態と交戦エリアの両方が入っています。どちらか一方にします（→ [交戦エリア](/manual/engagement-zone)）               |
| 吹き出しが出ない                                        | **一般**の**キャラクターの発言を頭上の吹き出しに出す**が外れているか、自分のツールバーで吹き出しを隠しています               |
| 部屋に入ると、思ったダイスボットになっていない          | **既定のダイスボット**が「DiceBot」のままです。GMが**一般**のタブで選びます                                                  |

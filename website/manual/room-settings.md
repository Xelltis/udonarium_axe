# 部屋設定

<Shot src="room-settings" alt="部屋設定パネル。上に一般・戦闘・移動・UI・自動保存・ユーティリティのタブが並び、移動の見出しに移動範囲と ZOC の設定が入っている" width="560" caption="テーブルをまたいで効く設定はここにまとまっています" />

卓の決めごとは、地図ではなく部屋のものです。移動範囲や ZOC はこれまで [テーブル設定](/manual/table-setting) にあったので、テーブルを 1 枚増やすたび同じ値を入れ直すことになっていました。ここはその置き場です。

FAB メニューの **部屋のアイコン** から開きます。編集できるのは GM と PL で、見学者は開けても書き換えられません（どの見出しも読むことはできます）。

中身は 5 つに分かれています。

| 見出し         | 入っているもの                                     |
| -------------- | -------------------------------------------------- |
| 一般           | 既定のダイスボット、コマの向きの示し方             |
| 戦闘           | ラウンドの進め方、陣営、バフの減り方               |
| 移動           | 移動範囲、ZOC、1 マスの距離と単位                  |
| UI             | 画面の見え方。共通設定とこの画面だけの設定（下記） |
| 自動保存       | この端末に残す部屋のひかえ（下記）                 |
| ユーティリティ | キャラクターの取り込み、画面の実測                 |

初めて使うなら「ラウンド」の節だけ読めば足ります。残りは必要になったときに引いてください。

## ラウンドは 1 体ずつか、陣営ごとか

**進行のしかた** で選びます。

- **1 体ずつ（並び順どおり）** — これまでどおり。インベントリの並び順で手番が回ります
- **陣営ごと（フェイズ制）** — 味方が全員動いてから敵が全員動く、スーパーロボット大戦のような進み方になります

陣営ごとを選ぶと、ラウンドは「陣営のフェイズ」を順に開いていく形になります。ひとつ閉じれば次が開き、最後まで行けばラウンドが終わります。

同じ欄の **ラウンドが進むとバフの残りを減らす** は、どちらの進め方でも効きます。外すとバフの残ラウンドは自動では減らなくなり、[バフ](/manual/buff)は手で管理することになります。

### 陣営には[パーティ](/manual/party)がそのまま使われる

陣営を別に作る必要はありません。すでに編成してあるパーティが、そのまま 1 つの陣営になります。どのパーティにも入っていないコマは「無所属」という 1 つの陣営に集まります。

**陣営の順番** の一覧で、上下の矢印を押して回る順を入れ替えます。上にあるものから順にフェイズが来ます。無所属を先攻にしたければ一番上へ動かせますし、**パーティに入っていないコマは行動しない** を入れれば行動順から外れます。

順番を書き留めるのは、あなたが矢印を押したときだけです。誰かが戦闘中にパーティを増やしても、そのパーティは黙って末尾に加わります。逆にフェイズの途中でパーティを解散しても、ラウンドはそこで固まらず、まだ動いていない陣営へ移ります。

### フェイズの中は自由か、並び順どおりか

**フェイズ内の順番** で決めます。

- **自由** — フェイズが開いても手番は誰にも渡りません。動かしたいコマをクリックするとその手番になり、直前に動いていたコマは行動済みになります
- **並び順どおり** — フェイズが開いた時点で先頭のコマに手番が渡り、インベントリの並び順に 1 体ずつ回ります

どちらでも **次へ** の働きは同じで、その陣営のまだ動いていないコマへ手番が渡ります。陣営の全員が動き終えて初めて、次の陣営のフェイズが開きます。

行動順ウィジェットは、陣営ごとに区切って表示されます。詳しくは [行動順](/manual/turn-order#陣営ごとに動かす) を参照してください。

## 移動範囲と ZOC は、触るまでテーブルのまま

コマが何マス歩けるか、敵の周りのマスが移動をどう妨げるかを決めます。項目そのものの意味は [移動範囲](/manual/move-range) にあります。

ひとつだけ癖があります。**この部屋がまだ答えていない項目は、テーブル側の設定がそのまま使われます。** 今どちらが決めているかは、**移動範囲**と **ZOC** の欄の上に出ています。

- **いまはテーブルごとの設定です** — 触っていない状態。テーブルを切り替えると、そのテーブルの値で動きます
- **部屋全体の設定です** — 一度でもここで変えた状態。どのテーブルを出しても同じルールになります

一度この画面で決めた項目は、以後その部屋の決めごとになります。テーブルごとの値へ戻すボタンはありません。

以前から使っている部屋を新しい版で開いても、このパネルを触らないかぎり挙動は変わりません。

## UI

画面の見え方をまとめた見出しです。中は **共通設定** と **個人設定** に分かれています。

共通設定は部屋の全員に効き、変えられるのは GM だけです。ここにあるのは **コマの向きの示し方** と、
3D表示の **コマ画像を常にカメラに向ける** の 2 つです。

個人設定はその画面にだけ効きます。誰でも変えられ、ほかの参加者には伝わりません。先頭に画面の配色を選ぶ
**スキン** があり（[テーマ](/manual/theme#skin)）、その下は卓を真上から見ているあいだに効くものです。

| 入っているもの                                                                                                                                                              |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ウィンドウを 90° 回転できるようにする、遠近をなくす、1 マスの実寸、1 マスを実寸で表示、ビューを固定する、コマの詳細表示、メニューの出し方、コマの多方向表示、外周ティッカー |

ここにある個人設定は、FAB の **卓上ディスプレイ** にも同じものが並んでいます。視点そのものやテーブルの推奨と
一緒に見たいときはそちらが早いです（[視点とテーブル操作](/manual/tabletop#tabletop-display)）。

**画面を寝かせて囲む使い方はオフラインのセッションのものなので、部屋には配りません。** オンラインとオフラインが
混ざるセッションでも、離れた席から参加している人の見え方は変わりません。卓上の画面で入れた設定は卓上の画面に
だけ残ります。まだ何も触っていない項目は、いま出ているテーブルの値が使われます。**この画面の設定を消す** を
押すと全部テーブルへ戻ります。

外周ティッカーを入れると、[チャット](/manual/chat)の入力欄の色設定の横に **ティッカー** ボタンが出ます。
入れたまま投稿した発言が外周を流れます。カットインの多方向表示は[カットイン](/manual/cut-in)の一覧か、
卓上ディスプレイから設定します。カットインもその画面だけの設定です。

### コマの向きの示し方

俯瞰では絵が常にこちらを向くので、どちらを向いているか分かりません。**示さない / コマごと回す / 矢尻で示す**
の 3 つから選びます。見え方の違いは [テーブル設定](/manual/table-setting#コマの見せ方) に表があります。

これも移動範囲と同じ扱いで、触るまではテーブル側の設定が使われます。

### 画面の実測

測るのは **ユーティリティ** です。ブラウザは画面の 1 ピクセルが実際に何ミリかを知りません。そこで、
大きさが国際規格で決まっている **ID-1 規格のカード** を物差しに使います。ISO/IEC 7810 ID-1 は
85.60 × 53.98mm と定められていて、クレジットカード・キャッシュカード・運転免許証・保険証などが同じ大きさです。
手元のどれでも構いません。

カードを当てる画面は **実寸再調整** から開きます。カードを画面へ直接当て、破線の枠がカードの外形と重なるまで
幅を変えて **合った** を押すだけです。カードの番号や名義を読み取ることも、どこかへ送ることもありません。

測った値は、その画面のそのセッションにだけ残ります。別のディスプレイへ移すと測り直しの案内が出ます。
1 マスを何ミリで見せるかは、個人設定の **1 マスの実寸** です。

## 既定のダイスボット

部屋に入ったとき、最初に選ばれているダイスボットです。入ったあとはチャット欄で選び直せます（[ダイスボット](/manual/dicebot)）。

## 自動保存

卓の変化が落ち着いたころに、部屋のひかえを**この端末の中へ**取ります。ひかえは他の参加者には渡らず、外にも出ません。

**この端末で部屋を自動保存する** を外すと、新しいひかえを取らなくなります。すでにあるひかえはそのまま残り、復元にも使えます。設定はこの端末に覚えるので、同じ部屋を別の端末で開いても、そちらの設定は変わりません。

世代の一覧・復元・削除も同じ見出しの中にあります。詳しくは[保存と読み込み](/manual/save-load#自動保存)を参照してください。

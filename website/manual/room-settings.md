# 部屋設定

<Shot src="room-settings" alt="部屋設定パネル。上に一般・戦闘・移動・UI・自動保存・ユーティリティのタブが並び、移動の見出しに移動範囲とZOCの設定が入っている" width="560" caption="テーブルをまたいで効く設定はここにまとまっています" />

卓の決めごとは、地図ではなく部屋のものです。移動範囲やZOCはこれまで[テーブル設定](/manual/table-setting)にあったので、テーブルを1枚増やすたび同じ値を入れ直すことになっていました。ここはその置き場です。

FABメニューの**部屋のアイコン**から開きます。編集できるのはGMとPLで、見学者は開けても書き換えられません（どの見出しも読むことはできます）。

中身は6つに分かれています。

| 見出し         | 入っているもの                                                           |
| -------------- | ------------------------------------------------------------------------ |
| 一般           | 既定のダイスボット、ダイスの演出、コマの向きの示し方                     |
| 戦闘           | ラウンドの進め方、陣営、バフの減り方                                     |
| 移動           | 移動範囲、ZOC、他のコマの通り抜け、跳躍の距離、1マスの距離と単位         |
| UI             | 画面の見え方。共通設定とこの画面だけの設定（下記）                       |
| 自動保存       | この端末に残す部屋のひかえ（下記）                                       |
| ユーティリティ | キャラクターの取り込み、リプレイ、画面の実測、このブラウザのデータの消去 |

初めて使うなら「ラウンド」の節だけ読めば足ります。残りは必要になったときに引いてください。

## ラウンドは1体ずつか、陣営ごとか

**進行のしかた**で選びます。

- **1体ずつ（並び順どおり）** — これまでどおり。インベントリの並び順で手番が回ります
- **陣営ごと（フェイズ制）** — 味方が全員動いてから敵が全員動く進み方になります

陣営ごとを選ぶと、ラウンドは「陣営のフェイズ」を順に開いていく形になります。ひとつ閉じれば次が開き、最後まで行けばラウンドが終わります。

同じ欄の**ラウンドが進むとバフの残りを減らす**は、どちらの進め方でも効きます。外すとバフの残ラウンドは自動では減らなくなり、[バフ](/manual/buff)は手で管理することになります。

### 陣営には[パーティ](/manual/party)がそのまま使われる

陣営を別に作る必要はありません。すでに編成してあるパーティが、そのまま1つの陣営になります。どのパーティにも入っていないコマは「無所属」という1つの陣営に集まります。

**陣営の順番**の一覧で、上下の矢印を押して回る順を入れ替えます。上にあるものから順にフェイズが来ます。無所属を先攻にしたければ一番上へ動かせますし、**パーティに入っていないコマは行動しない**を入れれば行動順から外れます。

順番を書き留めるのは、あなたが矢印を押したときだけです。誰かが戦闘中にパーティを増やしても、そのパーティはそのまま末尾に加わります。逆にフェイズの途中でパーティを解散しても、ラウンドはそこで固まらず、まだ動いていない陣営へ移ります。

### フェイズの中は自由か、並び順どおりか

**フェイズ内の順番**で決めます。

- **自由** — フェイズが開いても手番は誰にも渡りません。動かしたいコマをクリックするとその手番になり、直前に動いていたコマは行動済みになります
- **並び順どおり** — フェイズが開いた時点で先頭のコマに手番が渡り、インベントリの並び順に1体ずつ回ります

どちらでも**次へ**の働きは同じで、その陣営のまだ動いていないコマへ手番が渡ります。陣営の全員が動き終えて初めて、次の陣営のフェイズが開きます。

行動順ウィジェットは、陣営ごとに区切って表示されます。詳しくは[行動順](/manual/turn-order#陣営ごとに動かす)を参照してください。

## 移動範囲とZOCは、触るまでテーブルのまま

コマが何マス歩けるか、敵の周りのマスが移動をどう妨げるか、他のコマが立っているマスを通れるかを決めます。項目そのものの意味は[移動範囲](/manual/move-range)にあります。

他のコマの通り抜けは**同じパーティのコマ / 別のパーティのコマ / 未所属のコマ**の3つに分かれていて、どれも触るまでは**同じマスに複数のコマを置ける**に従います。味方の脇をすり抜けさせたい卓だけが触れば足ります。

同じところに、卓の細かい決めごとも並んでいます。**大きなコマを、通れない隙間に押し込めるようにする**、**跳躍の距離**（一度の跳躍が何マスまでか）、**掴んで運んだときも、通り道の仕掛けを発動させる**（手で運んだコマが通った道の罠を作動させるかどうか）の3つです。どれも、切ってある状態や0のままなら今までと同じ動きで、入れたときだけ変わります。

ひとつだけ癖があります。**この部屋でまだ決めていない項目は、テーブル側の設定がそのまま使われます。** 今どちらが決めているかは、**移動範囲**と**ZOC**の欄の上に出ています。

- **いまはテーブルごとの設定です** — 触っていない状態。テーブルを切り替えると、そのテーブルの値で動きます
- **部屋全体の設定です** — 一度でもここで変えた状態。どのテーブルを出しても同じルールになります

一度この画面で決めた項目は、以後その部屋の決めごとになります。テーブルごとの値へ戻すボタンはありません。

以前から使っている部屋を新しい版で開いても、このパネルを触らないかぎり挙動は変わりません。

## UI

画面の見え方をまとめた見出しです。中はさらに**共通 / スキン / 卓上**の3つに分かれています。

### 共通

部屋の全員に効き、変えられるのはGMだけです。GM以外の画面では操作できない見た目になります。

| 見出し     | 入っているもの                                                     |
| ---------- | ------------------------------------------------------------------ |
| コマの向き | キャラクターの向きの示し方                                         |
| 2D表示     | コマ画像をマス内に収める（真上から見ているあいだだけ効きます）     |
| 3D表示     | コマ画像を常にカメラに向ける（斜めから見ているあいだだけ効きます） |

### スキン

画面の配色です。この画面にだけ効きます（[テーマ](/manual/theme#skin)）。

### 卓上

**この画面にだけ効きます。** 大きなディスプレイを何人かで囲んで見る、オフラインのセッション向けの設定です。
1人で2Dで見ているだけなら、ここは触らなくて構いません。

先頭の**卓上ディスプレイ用の推奨設定をオン**で、下の項目がまとめて推奨値になり、この画面が2D表示になります。
切ると項目は既定に戻り、視点はそのままです。

| 見出し                | 入っているもの                                         |
| --------------------- | ------------------------------------------------------ |
| メニューの出し方      | コンテキストメニューの形（通常 / 四方向 / 回転）       |
| コマの見せ方          | コマの詳細表示、コマ名の周回、リソースバフ、文字サイズ |
| 外周ティッカー        | 表示と速度                                             |
| 画面とウィンドウ      | 遠近をなくす、ウィンドウの90°回転                      |
| 1マスの実寸と実寸表示 | 1マスの実寸、実寸で表示、ビューを固定する              |

**2Dで見ることと、画面を寝かせて囲むことは別です。** 視点を2Dにしただけでは、ここの設定は何も入りません。

## 既定のダイスボット

部屋に入ったとき、最初に選ばれているダイスボットです。入ったあとはチャット欄で選び直せます（[ダイスボット](/manual/dicebot)）。

## ダイスの演出

チャットで振ったダイスを3Dで転がすかどうかと、どこで転がすかです。**出さない**（既定）・**セリフの枠**・**卓の上**・**両方**から選びます。見え方は[ダイス](/manual/dice#roll-in-3d)にまとめてあります。

## リモコンに出す数値とリソース

部屋のコマが持つ数値とリソースを名前ごとにまとめて並べ、そのうちどれを[リモコン](/manual/character)に出すかを
選べます。ここで外した名前は、リモコンのリソース操作のボタンからも、右のコマの欄からも消えます。
シートの項目そのものは何も変わりません。

触っていない部屋では全部出します。1つでも外すと「選んだものだけを出す」状態になり、あとからシートに足した
項目は、ここで選ぶまで出ません。元の全部出す状態に戻すには**すべて出す**を、一度空にするなら
**すべて外す**を押します。

変えられるのはGMだけで、選んだ内容は部屋の全員に効きます。

## 自動保存

卓の変化が落ち着いたころに、部屋のひかえを**この端末の中へ**取ります。ひかえは他の参加者には渡らず、外にも出ません。

**この端末で部屋を自動保存する**を外すと、新しいひかえを取らなくなります。すでにあるひかえはそのまま残り、復元にも使えます。設定はこの端末に保存されるので、同じ部屋を別の端末で開いても、そちらの設定は変わりません。

世代の一覧・復元・削除も同じ見出しの中にあります。詳しくは[保存と読み込み](/manual/save-load#自動保存)を参照してください。

## このブラウザのデータをすべて消す

**ユーティリティ**タブのいちばん下にある**危険な操作**の欄から、このブラウザに残っているデータをまとめて消せます。表示や動きがおかしいままで、読み込み直しても直らないときに試してください。

消えるのは次のデータです。消したデータは元に戻せません。

- 自分の設定（表示・音量・スキン・ウィジェットの配置など）
- 部屋の自動保存とリプレイの記録
- マイダイスとスキンの画像

ボタンを押すと、確かめるダイアログが出ます。**すべて消して読み込み直す**を選ぶとページを読み込み直し、アプリが動き出す前にデータを消すので、初めて開いたときと同じ状態から始まります。

読み込み直すと、いまの部屋からはいったん抜けます。部屋のコマやチャットはほかの参加者の画面に残りますが、ひとりで遊んでいるときは、保存していない部屋の内容も消えます。残したい部屋は、先に[保存](/manual/save-load)してください。同じブラウザのほかのタブでも開いているときは、そちらを先に閉じてください。

見学を含め、どのロールでも使えます。消えるのはこのブラウザのデータだけで、ほかの参加者の画面には何も起きません。

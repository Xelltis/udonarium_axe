# 部屋とロビー

このページは、ほかの人と遊ぶための部屋を作る・入る・出る手順と、部屋がいつ消えるかを説明します。
部屋は、参加者どうしをつなぐ入れ物です。
テーブルそのものは部屋がなくても動くので、部屋を作るのは人を呼ぶときだけで足ります。
部屋は誰でも作れます（[部屋のサーバー](#room-server)では、Discordでログインした人だけ）。

## 部屋に入らずに使う

Axeを開いた時点で、サンプルのテーブルが読み込まれています。
コマを動かす、地形を置く、ダイスを振る、[保存](/manual/save-load)して書き出す、といったことは、部屋がなくてもできます。

接続パネルにルーム名が出ていなければ、いま見ているものは自分の画面だけのものです。

## 部屋を作る

1. FABメニューの**接続**を押して、接続パネルを開きます。
2. ニックネームを入れます。
3. **ロビー（ルーム一覧）を表示**を押して、ロビーを開きます。
4. **新しいルームを作成する**を押して、次の2つを決めます。

   | 項目       | 決めかた                                       |
   | ---------- | ---------------------------------------------- |
   | ルーム名   | 必須。255文字まで。ロビーの一覧に並びます      |
   | パスワード | 12文字まで。空にすると、鍵のない部屋になります |

5. **新しいルームを作成**を押します。

接続パネルにルーム名が出れば、部屋ができています。
作った人は、その部屋の[GM](/manual/roles)になります。
ほかの人を呼ぶときは、接続パネルの招待リンクを渡します（→ [招待リンクで参加者を招く](/manual/roles#招待リンクで参加者を招く)）。

<Shot src="connection-panel" alt="接続パネル。アイコンとニックネーム、役割の選択、オンラインとオフラインの切り替え、ロビーを開くボタンが並んでいる" width="430" caption="接続パネル。ロビーはここから開きます" />

すでにほかの参加者とつながっているあいだは、部屋を作れません。
別の部屋へ移るときは、ロビーの**部屋を出る**で、いまの部屋を出てからにします。

## 部屋に入る

入りかたは、招待リンクとロビーの2つです。
入る前に、接続パネルでニックネームと役割を決めておけます。

### 招待リンクで入る

1. 渡された招待リンクを開きます。
2. 画面の上に「（ルーム名）に参加しています…」と出て、入室が始まります。
3. パスワードの要る部屋で、リンクにパスワードが入っていないときは、パスワードを聞かれます。入れて**入室**を押します。

ロビーを探す必要も、部屋の名前やパスワードを教えてもらう必要もありません（→ [ロール](/manual/roles#招待リンクで参加者を招く)）。
招待リンクで入った人がページを読み込み直すと、同じ部屋に入り直します。

### ロビーから入る

1. FABメニューの**接続**を押して、接続パネルを開きます。
2. **ロビー（ルーム一覧）を表示**を押して、ロビーを開きます。
3. **一覧を更新**を押します。ルームID・ルーム名・パスワードの有無・参加者の数が並びます。
4. 入りたい部屋の行の**接続**を押します。
5. パスワードの要る部屋では、続けてパスワードを聞かれます。入れて**入室**を押します。

接続パネルにルーム名が出れば、入れています。

### 入るときの役割

見学のつもりなら、入る前に**見学**を選んでおくと、最初から読み取り専用で入れます。
役割は、あとから自分で変えられます（→ [見学（読み取り専用）](/manual/roles#見学-読み取り専用)）。

GMを選んでおいても、ほかの人の部屋にはプレイヤーとして入ります。
自分のいた部屋でGMだったなら、読み込み直して戻っても、GMのままです。

[部屋のサーバー](#room-server)では、ここで選んだ役割は使わず、サーバーが決めます。

### 読み込み直した直後の待ち時間 {#reload-wait}

ページを読み込み直しても、それまでの接続は、すぐには部屋から消えません。
最長1分ほどは、部屋に残ったままです。
そのあいだに同じ部屋へ入ろうとすると、前の接続が切れるのを待ってから入ります。
待っているあいだは、ロビーと、招待リンクを開いたときの画面の上に「前の接続が切れるのを待っています（最長1分ほど）」と出るので、そのまま待ってください。

待っても前の接続が切れないときは、入室を取りやめ、チャットにその知らせが出ます。
タブを複製するなどして、同じ部屋を別のタブでも開いているときが、これに当たります。
別のタブを閉じるか、少し待ってから入り直してください。
招待リンクから入ろうとしていたときは、画面の上の**ロビーを開く**からロビーへ移れます。

この待ち時間は、SkyWay版だけのものです。
[部屋のサーバー](#room-server)では待たずに入れ、前の接続は新しい接続に置きかわって切れます。

ひとりで部屋にいたGMも、読み込み直したあと、自分の部屋へ戻れます。
前の接続が残っているあいだは部屋がロビーの一覧に出ているので、その行の**接続**を押してください。
一覧から消えたあとは、部屋は[解散しています](#gone)。

## 部屋を出る

1. 接続パネルから**ロビー（ルーム一覧）を表示**を押して、ロビーを開きます。
2. **部屋を出る**を押します。
3. 「部屋を出ますか？」と確認が出るので、出ることを選びます。

ほかに誰もいなければ、部屋はそこで解散します。

::: tip 読み込み直しても、テーブルは消えません
編集できる役割なら、[自動保存](/manual/save-load#自動保存)にひかえが残っています。
部屋につながずに開き直すと、復元を促すバナーが出ます。
確実に残したいときは、出る前に**保存**でzipを書き出してください。
:::

## 部屋が消えるとき {#gone}

部屋は、誰かがつないでいるあいだだけあります。
最後の1人が抜けた時点で解散します。
同じ名前で作り直しても、中身は戻りません。
[部屋のサーバー](#room-server)の部屋だけは、最後の1人が抜けてからしばらく（既定では24時間）残ります。

続きを遊ぶなら、解散する前に、FABメニューの**セーブ&ロード**から**保存**を押して、zipを書き出してください。
書き出したzipは、ブラウザの画面へドロップすれば読み込めます。

押し忘れても、[自動保存](/manual/save-load#自動保存)が動いています。
ただし、次の3つのときは、自動保存に頼れません。

- ブラウザがIndexedDBを使えないとき（プライベートウィンドウなど）は、自動保存そのものが動きません。パネルにその旨が出ます
- [部屋設定](/manual/room-settings#自動保存)の**この端末で部屋を自動保存する**を外していれば、新しいひかえは取られません
- 残るのはそのブラウザの中だけです。別の端末からも、ほかの参加者のところからも開けません

## 部屋のサーバーでの部屋の扱い {#room-server}

[部屋のサーバー（ベータ）](/guide/choose)を使う配置先では、部屋の扱いがいくつか変わります。

| 項目                | SkyWay版                 | 部屋のサーバー                                                                        |
| ------------------- | ------------------------ | ------------------------------------------------------------------------------------- |
| 部屋を作れる人      | 誰でも                   | **Discordでログイン**した人                                                           |
| 入るときの役割      | 自分で選ぶ               | サーバーが決める。ログインしていない人は見学（→ [ロール](/manual/roles#room-server)） |
| 参加者が0人になると | すぐ解散する             | 一定の時間（既定では24時間。設置する人が変えられます）残る                            |
| パスワード          | 各自のブラウザで確かめる | 部屋のサーバーが確かめる                                                              |
| 部屋を消す          | 全員が抜けると消える     | GMが削除できる。残る時間がたっても消える                                              |

ログインしていなければ、ロビーのボタンが**ログインして部屋を作る**に変わり、押すとログインの画面が開きます。
ログインしなくても、ほかの人の部屋には見学として入れます。

### 部屋に残る時間

最後の1人が抜けてから一定の時間は、部屋がサーバーに残ります。
そのあいだに入り直せば、テーブルはそのままです。
その時間がたつと、部屋ごと消えます。

3時間のあいだ画面を操作しなかった人は、部屋から抜けます。
開いたまま忘れたタブが、いつまでも部屋を残さないためです。
数えるのはマウス、キー、ホイール、タッチの操作で、抜ける5分前に知らせが出ます。
そのとき画面を少し動かせば、そのまま残れます。
抜けたあとは、知らせか、接続パネルの**部屋に戻る**で、同じ席に戻れます。

### 部屋を削除する

部屋のGMは、残る時間を待たずに部屋を削除できます。

- 部屋の中からは、接続パネルの**部屋を削除**を押します
- 部屋の外からは、ロビーの一覧で、自分がGMの部屋に出るゴミ箱のボタンを押します

削除すると、部屋にいた人は全員が待機に戻り、チャットのシステムタブに理由が出ます。
サーバーに残っていたテーブルと、部屋に置いた画像と音声は消え、元には戻せません。
それぞれの画面に映っているテーブルは、そのまま残ります。
GM以外の人の画面に残ったテーブルには伏せた形の物が入っているので、そのままほかの部屋に入ると確認が出ます（→ [保存と読み込み](/manual/save-load#保存)）。

### 部屋を出入りするとき

部屋に入っているあいだは、ロビーからほかの部屋に入ることも、部屋を作ることも、一覧から部屋を削除することもできません。
ロビーの**部屋を出る**で、いったん部屋を出てからにしてください。
部屋を出ても、テーブルは部屋のサーバーに残ります。
ただし、次のときは、出る前に確認が出ます。

- サーバーとの接続が切れているとき
- 大きな削除や読み込みを、まだ送っているとき
- まだサーバーに上がっていない画像や音声があるとき

同じDiscordアカウントで、別のタブや端末から同じ部屋に入ると、前の画面は部屋から抜けて待機に戻ります。
1つのアカウントで使える席は、1つの部屋に1つです。

## 通信を切って使う（オフライン） {#offline}

接続パネルの**接続**で**オフライン**を選ぶと、SkyWayにもサーバーにもつながらなくなります。
そのブラウザの中だけで、テーブルが動く状態です。

::: warning 切り替えると、いまの部屋から抜けます
オンラインとオフラインを切り替えると、ページが読み込み直されます。
卓の最中には押さないでください。
:::

オフラインのあいだは、部屋名・招待リンク・参加者の一覧など、通信にかかわる項目は接続パネルに出ません。
オフラインのままでも、保存と読み込みはできます。
次のセッションの地図を仕込む、コマを並べておく、といった下ごしらえに向いています。
ほかの人と遊ぶときは、**オンライン**に戻してください。
こちらも読み込み直しが入ります。

オフラインかオンラインかは、そのブラウザに残ります。
誰ともつながらないときは、まずここがオフラインのままになっていないか確かめてください。

## 招待リンクのパスワード

招待リンクにパスワードを載せても、文字列がそのまま書き込まれることはありません。
部屋ごとに異なる形へ変えてから載せるので、URLを目で読んでも、チャットのプレビューやスクリーンショットからも、そのままでは分かりません。

::: warning リンクを持っている人は、パスワードを取り出せます
この変換は目隠しで、暗号ではありません。
変換に使う鍵は、同じリンクの中に入っています。
そのため、次の2つに気をつけてください。

- ほかのサービスで使っているパスワードを、部屋のパスワードに使い回さない。リンクが流れれば、その文字列も一緒に流れます
- 公開の場で募集するときは、合言葉を含めないリンクを配り、パスワードは別の経路で渡す

リンクを持っている人は、その部屋に入れます。
SNSなど、不特定多数の目に触れる場所には貼らないでください。
:::

## うまくいかないとき

| 見えるもの                                                         | 原因と直しかた                                                                                                                                      |
| ------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| ロビーに、入りたい部屋が出ない                                     | **一覧を更新**を押します。それでも出ないときは、部屋が解散していないか、部屋を作った人と同じURLのAxeを開いているかを確かめます                      |
| 「まだサーバーにつながっていません。…」                            | つなぎに行っている途中です。数秒待って**一覧を更新**を押します                                                                                      |
| 「サーバーにつながっていません。少し置いてから、…」                | Axeがサーバーに届いていません。少し置いて読み込み直します。続くときは、配置先を設置した人に伝えます（→ [設置で困ったとき](/guide/troubleshooting)） |
| 「他の参加者とつないだままではルームを作成できません。」           | ほかの部屋に入っています。ロビーの**部屋を出る**で出てから作ります                                                                                  |
| 「部屋を作るにはログインが要ります」                               | 部屋のサーバーでは、先に**Discordでログイン**します                                                                                                 |
| 「パスワードが違います」                                           | 大文字と小文字、全角と半角を確かめて、入れ直します。招待リンクをもらい直すと、入力せずに入れます                                                    |
| 「（ルーム名）が見つかりませんでした」                             | 招待リンクの部屋が、もう解散しています。部屋を作った人に、新しいリンクをもらいます                                                                  |
| 「部屋が見つかりません。閉じられたか、保持期間が過ぎて消えました」 | 部屋のサーバーで、部屋が削除されたか、残る時間がたって消えました                                                                                    |
| 「部屋が満員です（N人まで）」                                      | 部屋のサーバーで、部屋の人数が上限に達しています。誰かが抜けるのを待ちます                                                                          |
| 「前の接続が切れるのを待っています（最長1分ほど）」から進まない    | 同じ部屋を別のタブでも開いていないか確かめます。閉じて、少し待ってから入り直します                                                                  |
| 「オフラインのため（ルーム名）に入れません。…」                    | 接続パネルの**接続**が**オフライン**になっています。**オンライン**に切り替えます                                                                    |
| 部屋に入ったのに、ほかの人のコマが動かない                         | 接続が切れかけています（→ [接続が切れたとき](/manual/connection)）                                                                                  |

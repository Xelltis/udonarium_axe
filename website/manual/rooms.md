# 部屋とロビー

部屋は「他の人とつなぐ」ための入れ物です。
卓そのものは部屋がなくても動くので、作るのは人を呼ぶときだけで足ります。

## 部屋がなくても卓は動く

アプリを開いた時点で、サンプルの卓が読み込まれています。
コマを動かす、地形を置く、ダイスを振る、[保存](/manual/save-load)して書き出す。ここまでは部屋がなくてもできます。

接続パネルにルーム名が出ていなければ、いま見ているものは自分の画面だけのものです。

## 部屋を作る

画面左のFABメニュー（丸いハンバーガーボタン）の**接続**から接続パネルを開き、**ロビー（ルーム一覧）を表示**を押します。
ロビーの**新しいルームを作成する**で、次の2つを決めます。

| 項目       | 決めかた                                     |
| ---------- | -------------------------------------------- |
| ルーム名   | 必須。255文字まで。ロビーの一覧に並びます    |
| パスワード | 12文字まで。空にすると鍵なしの部屋になります |

作成した人は自動的に[GM](/manual/roles)になります。

すでに他の参加者とつながっている状態では、部屋を作れません。
別の部屋へ移るには、ページを再読み込みして接続を切ってからになります。
**再読み込みで盤面は消えません**。編集できる役割なら[自動保存](/manual/save-load#自動保存)にひかえが残っており、部屋につながずに開き直したときに復元を促すバナーが出ます。
確実に残したいなら、抜ける前に**保存**でzipを書き出してください。

## 部屋に入る

入り口は2つあります。

**招待リンク**を渡されているなら、開くだけで入室が始まります。
ロビーを探す必要も、部屋名やパスワードを伝えてもらう必要もありません（→ [ロール](/manual/roles#招待リンクで参加者を招く)）。

**ロビー**から探すなら、**一覧を更新**を押します。
一覧にはルームID・ルーム名・パスワードの有無・参加者の数が並びます。目当ての行の**接続**を押してください。
パスワードつきの部屋では、続けて入力を求められます。

入る前にニックネームと役割を決めておけます。
見学のつもりなら先に**見学**を選んでおくと、最初から読み取り専用で入れます（役割は後から自分で変えられます → [見学は自分で外せます](/manual/roles#見学-読み取り専用)）。
GMを選んでおいても、ほかの人の部屋にはプレイヤーとして入ります。再読み込みして自分のいた部屋へ戻るときはGMのままです。
[部屋のサーバー](#room-server)では、ここで選んだ役割は使わず、サーバーが決めます。

### 再読み込みの直後は、前の接続が切れるのを待ちます

ページを再読み込みしても、それまでの接続はすぐには部屋から消えません。最長1分ほどは部屋に残ったままです。
そのあいだに同じ部屋へ入ろうとすると、前の接続が切れるのを待ってから入室します。
待っているあいだは、ロビーと、招待リンクを開いたときの画面上部に「前の接続が切れるのを待っています（最長1分ほど）」と出るので、そのまま待ってください。

待っても前の接続が切れないときは、入室を取りやめ、チャットにその知らせが出ます。
タブを複製するなどして、同じ部屋を別のタブでも開いているときがこれに当たります。
別のタブを閉じるか、少し待ってから入り直してください。
招待リンクから入ろうとしていたときは、画面上部の**ロビーを開く**からロビーへ移れます。

この待ち時間はSkyWay版だけのものです。[部屋のサーバー](#room-server)では待たずに入れ、前の接続は新しい接続に置きかわって切れます。

ひとりで部屋にいたGMも、再読み込みのあと自分の部屋へ戻れます。
前の接続が残っているあいだは部屋がロビーの一覧に出ているので、その行の**接続**を押してください。
一覧から消えたあとは、部屋は[解散しています](#gone)。

## 参加者が0人になると部屋は消える {#gone}

部屋は誰かがつないでいる間だけ存在します。
最後の1人が抜けた時点で解散します。同じ名前で作り直しても、中身は戻りません。
[部屋のサーバー](#room-server)の部屋だけは、最後の1人が抜けてから24時間残ります。

続きをやるなら、解散する前にFABメニューの**セーブ&ロード → 保存**でzipを書き出してください。
書き出したzipは、ブラウザの画面へドロップすれば読み込めます。

押し忘れても[自動保存](/manual/save-load#自動保存)が効いています。
ただし当てにしきらないでください。効かない条件が3つあります。

- ブラウザがIndexedDBを使えないとき（プライベートウィンドウなど）は、自動保存そのものが動きません。パネルにその旨が出ます
- [部屋設定](/manual/room-settings#自動保存)の**この端末で部屋を自動保存する**を外していれば、新しいひかえは取られません
- 残るのは**そのブラウザの中だけ**です。別の端末からも、他の参加者のところからも開けません

## 部屋のサーバーの部屋 {#room-server}

[部屋のサーバー（ベータ）](/guide/backend#room-server)を使う配置先では、部屋の扱いがいくつか変わります。

部屋を作れるのは、ロビーの上で「Discordでログイン」した人だけです。
ログインしていなければロビーのボタンが「ログインして部屋を作る」に変わり、押すとログインの画面が開きます。
ログインしなくても、ほかの人の部屋には見学として入れます（→ [ロール](/manual/roles#room-server)）。

部屋は参加者が0人になっても消えません。
最後の1人が抜けてから24時間はサーバーに残り、そのあいだに入り直せば卓はそのままです。
24時間たつと、部屋ごと消えます。

部屋のGMは、24時間を待たずに部屋を削除できます。
部屋の中からは接続パネルの「部屋を削除」で、部屋の外からはロビーの一覧で、自分がGMの部屋に出るゴミ箱のボタンで削除します。
削除すると、部屋にいた人は全員が待機に戻り、システムタブに理由が出ます。
サーバーに残っていた卓と、部屋に置いた画像と音声は消え、元には戻せません。それぞれの画面に映っている卓は、そのまま残ります。

パスワードは部屋のサーバーが確かめます。
違っていればロビーに戻り、システムタブに理由が出ます。

同じDiscordアカウントで、別のタブや端末から同じ部屋に入ると、前の画面は部屋から抜けて待機に戻ります。
1つのアカウントで使える席は、1つの部屋に1つです。

## 通信を切って使う（オフライン） {#offline}

接続パネルの**接続**で**オフライン**を選ぶと、接続の中継役（SkyWayとバックエンド）にどちらもつながらなくなります。
そのブラウザの中だけで卓が動く状態です。

**切り替えるとページが再読み込みされ、いまの部屋からは抜けます**。卓の最中には押さないでください。

オフラインのままでも保存と読み込みはできます。
次のセッションの地図を仕込む、コマを並べておくといった下ごしらえに向いています。
他の人と遊ぶときは**オンライン**に戻してください。こちらも再読み込みが入ります。

オフラインかオンラインかの選択は、そのブラウザに残ります。
誰ともつながらないときは、まずここがオフラインのままになっていないか確かめてください。

## 招待リンクのパスワードは、リンクを持つ人には読める

招待リンクにパスワードを載せても、文字列がそのまま書き込まれることはありません。
部屋ごとに異なる形へ変換されるので、URLを目で読んでも、チャットのプレビューやスクリーンショットからも、そのままでは分かりません。

ただしこれは目隠しであって、暗号ではありません。
変換に使う鍵は同じリンクの中に入っているため、**リンクを持っている人はパスワードを取り出せます**。

そのため、気をつけることが2つあります。
ひとつ、他のサービスで使っているパスワードを部屋のパスワードに流用しないこと。リンクが流れれば、その文字列も一緒に流れます。
ふたつ、公開の場で募集するときは「合言葉を含めない」リンクを配り、パスワードは別の経路で渡すこと。
リンクを持っている人はその部屋に入室できるので、SNSなど不特定多数の目に触れる場所には貼らないでください。

# 部屋とロビー

部屋は「他の人とつなぐ」ための入れ物です。
卓そのものは部屋がなくても動くので、作るのは人を呼ぶときだけで足ります。

## 部屋がなくても卓は動く

アプリを開いた時点で、サンプルの卓が読み込まれています。
コマを動かす、地形を置く、ダイスを振る、[保存](/manual/save-load)して書き出す。ここまでは部屋がなくてもできます。

接続パネルにルーム名が出ていなければ、いま見ているものは自分の画面だけのものです。

## 部屋を作る

画面左の FAB メニュー（丸いハンバーガーボタン）の **接続** から接続パネルを開き、**ロビー（ルーム一覧）を表示** を押します。
ロビーの **新しいルームを作成する** で、次の 2 つを決めます。

| 項目       | 決めかた                                      |
| ---------- | --------------------------------------------- |
| ルーム名   | 必須。255 文字まで。ロビーの一覧に並びます    |
| パスワード | 12 文字まで。空にすると鍵なしの部屋になります |

作成した人は自動的に [GM](/manual/roles) になります。

すでに他の参加者とつながっている状態では、部屋を作れません。
別の部屋へ移るには、ページを再読み込みして接続を切ってからになります。
**再読み込みで盤面は消えません。** 編集できる役割なら[自動保存](/manual/save-load#自動保存)にひかえが残っており、部屋につながずに開き直したときに復元を促すバナーが出ます。
確実に残したいなら、抜ける前に **保存** で zip を書き出してください。

## 部屋に入る

入り口は 2 つあります。

**招待リンク** を渡されているなら、開くだけで入室が始まります。
ロビーを探す必要も、部屋名やパスワードを伝えてもらう必要もありません（→ [ロール](/manual/roles#招待リンクで参加者を招く)）。

**ロビー** から探すなら、**一覧を更新** を押します。
一覧にはルーム ID・ルーム名・パスワードの有無・参加者の数が並びます。目当ての行の **接続** を押してください。
パスワードつきの部屋では、続けて入力を求められます。

入る前にニックネームと役割を決めておけます。
見学のつもりなら先に **見学** を選んでおくと、最初から読み取り専用で入れます。

## 参加者が 0 人になると部屋は消える {#gone}

部屋は誰かがつないでいる間だけ存在します。
最後の 1 人が抜けた時点で解散します。同じ名前で作り直しても、中身は戻りません。

続きをやるなら、解散する前に FAB メニューの **保存** で zip を書き出してください。
書き出した zip は、ブラウザの画面へドロップすれば読み込めます。

押し忘れても[自動保存](/manual/save-load#自動保存)が効いています。
ただし当てにしきらないでください。効かない条件が 3 つあります。

- ブラウザが IndexedDB を使えないとき（プライベートウィンドウなど）は、自動保存そのものが動きません。パネルにその旨が出ます
- [部屋設定](/manual/room-settings#自動保存)の **この端末で部屋を自動保存する** を外していれば、新しいひかえは取られません
- 残るのは**そのブラウザの中だけ**です。別の端末からも、他の参加者のところからも開けません

## 通信を切って使う（オフライン） {#offline}

接続パネルの **接続** で **オフライン** を選ぶと、接続の中継役（SkyWay とバックエンド）にどちらもつながらなくなります。
そのブラウザの中だけで卓が動く状態です。

**切り替えるとページが再読み込みされ、いまの部屋からは抜けます。** 卓の最中には押さないでください。

オフラインのままでも保存と読み込みはできます。
次のセッションの地図を仕込む、コマを並べておくといった下ごしらえに向いています。
他の人と遊ぶときは **オンライン** に戻してください。こちらも再読み込みが入ります。

オフラインかオンラインかの選択は、そのブラウザに残ります。
誰ともつながらないときは、まずここがオフラインのままになっていないか確かめてください。

## 招待リンクのパスワードは、リンクを持つ人には読める

招待リンクにパスワードを載せても、文字列がそのまま書き込まれることはありません。
部屋ごとに異なる形へ変換されるので、URL を目で読んでも、チャットのプレビューやスクリーンショットからも、そのままでは分かりません。

ただしこれは目隠しであって、暗号ではありません。
変換に使う鍵は同じリンクの中に入っているため、**リンクを持っている人はパスワードを取り出せます**。

そこから 2 つ決まります。
ひとつ、他のサービスで使っているパスワードを部屋のパスワードに流用しないこと。リンクが流れれば、その文字列も一緒に流れます。
ふたつ、公開の場で募集するときは「合言葉を含めない」リンクを配り、パスワードは別の経路で渡すこと。
リンクを持っている人はその部屋に入室できるので、SNS など不特定多数の目に触れる場所には貼らないでください。

# シーン

このページは、テーブルの見た目と部屋の音をひとまとめにして、ボタン1つで切り替える「シーン」を説明します。
シーンには、床・背景・壁・前景・天候・暗闇・霧、流すBGMと環境音、反映したときに流すカットイン、ゲーム内時間の時間帯、チャットに出す文を入れられます。
ひとつの地図のまま「昼の村」「夜の村」「燃える村」を切り替えたり、見せるテーブルごと場面を替えたりできます。

シーンを作って使えるのはGMだけです。FABメニューの**テーブル関連**から**シーン**を選ぶか、GMツールバーのボタンからパネルを開きます。

## シーンを作る

1. テーブルの床や背景、BGMなどを、シーンにしたい状態に整えます。
2. パネルの**今の盤面から作る**を押します。

見せているテーブルと、その見た目のすべて（床・背景・壁・前景・天候・暗闇・霧）がシーンに入ります。BGMと環境音は、そのとき流れているものだけが入ります。
作ったシーンは一覧のいちばん下に並び、下の欄で組み立てられます。

## シーンを組み立てる

一覧の行を押すと、そのシーンの項目が下に並びます。チェックを入れた項目だけが、反映したときに変わります。チェックのない項目は「変えない」です。チェックを入れると、いまの盤面の値から始まります。

| 項目                 | 変えるもの                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------------ |
| 見せるテーブル       | 部屋の全員の表示を、選んだテーブルに切り替えます                                           |
| 床・背景・壁・前景   | 画像を選びます。**なしにする**を押すと、反映したときに画像を外します                       |
| 天候・暗闇・戦場の霧 | テーブル設定と同じ選択肢です                                                               |
| BGM                  | 止める・曲を流す・再生リストを最初から流す、から選びます                                   |
| 環境音               | 選んだ環境音だけを流し、ほかは止めます。何も選ばないと、環境音をすべて止めます             |
| ゲーム内時間の時間帯 | ゲーム内時間を、選んだ時間帯にします。24時間の表し方のときは変わりません                   |
| 暗転                 | 反映するあいだ、全員の画面を一瞬暗くします                                                 |
| カットイン           | 反映したときに流します。いくつか選ぶと、そのうち1つを選んで流します                        |
| 切り替えのテキスト   | 反映したときに、システムの発言としてチャットに出します。チャットと同じ装飾の記法が使えます |

見せるテーブルを入れたシーンは、テーブル自身に設定した切り替え時のカットインとBGMを鳴らしません。シーンの設定が優先します。
同じ曲や同じ再生リストがすでに流れているときは、頭から流し直さずにそのまま流し続けます。
音楽つきのカットインは、流れるとBGMを止めます。シーンのBGMと一緒に選ぶと、編集欄に注意が出ます。

## 反映する

行の右の▶を押すと、シーンを反映します。反映したシーンには、一覧で印が付きます。
行を右クリック（スマートフォンでは長押し）すると、次の操作が出ます。

| 操作                         | すること                                                                     |
| ---------------------------- | ---------------------------------------------------------------------------- |
| BGMを変えずに反映            | BGMはそのままにして、ほかの項目を反映します                                  |
| テキストを送らずに反映       | 切り替えのテキストを出さずに反映します                                       |
| 今の盤面で上書き             | チェックの入った項目を、いまの盤面と流れている音で書き直します。確認が出ます |
| 複製                         | 同じ中身のシーンを「（名前）のコピー」として作ります                         |
| フォルダへ移す               | ほかのフォルダか、フォルダなしへ移します                                     |
| いちばん上へ・ひとつ上へなど | 同じフォルダの中で並べ替えます                                               |
| 削除                         | シーンを削除します。確認が出ます                                             |

## フォルダに分ける

**今の盤面から作る**の横のボタンで、フォルダを作ります。フォルダは4段まで入れ子にでき、名前の横のボタンで、中にフォルダを作る・名前を変える・削除ができます。
行をフォルダの見出しへドラッグすると、そのフォルダに入ります。ほかの行へドラッグすると、その行の前か後ろに並びます。
フォルダを削除すると、中のシーンはフォルダなしに戻ります。シーンそのものは消えません。

## ホットバーとスイッチから反映する

[ホットバー](/manual/hotbar)の枠の種類**シーン**で、選んだシーンを反映できます。この枠はGMだけが使えます。
[盤面のスイッチ](/manual/switch)の動作**シーンを反映**は、押した人の画面でシーンを反映します。PLが押しても反映されます。罠や仕掛けで場面を変えるときに使います。
どちらも、**BGMを変えずに反映**を選べます。

## 保存と部屋のサーバー

シーンは部屋の保存データに入り、読み込むと部屋のシーンと入れ替わります。シーンが使う画像も、保存のzipに入ります。

[部屋のサーバー](/guide/choose)では、シーンは全員に届きます。スイッチのシーンを、押したPLの画面で反映するためです。画面にはGMにしか出ませんが、改造したAxeならシーンの名前と切り替えのテキストを読めます。見せたくない文は、[シナリオテキスト](/manual/scenario-text)に書きます。

古い版のAxeを使っている参加者には、シーンのパネルが出ません。反映した結果のテーブルや音は、古い版の画面にも届きます。前景は古い版には描かれません。

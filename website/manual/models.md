# 3Dモデル

このページはコマや地形を3Dモデルで描き、見た目・動き・表情を決める方法を説明します。
3Dモデルで描くのは、3Dで描く卓だけです。

## モデルを読み込む

メニューの**3Dモデル**で、glTFのモデル（.glb）かVRM（.vrm）を部屋に読み込みます。VRMに足す動き（.vrma）も同じように読み込みます。
1つのファイルは10MBまでです。
VRoidで書き出したVRMは10MBを超えることが多いので、書き出すときにテクスチャの解像度を下げてください。

読み込んだモデルを卓のコマや地形へドラッグすると、そのモデルで描きます。
コマや地形のシートの**3Dモデル**からも選べます。

## 見た目と動きを設定する

コマのシートの**設定**タブにある**3Dモデル**で、**見た目と動きを設定**を開きます。
上にプレビューが出て、変えたことがすぐ描かれます。
プレビューは左右にドラッグすると回ります。

### 見た目

**プリセット**で、鋼・黄金・石像・幽霊・影・氷・光などの見た目にまとめて変えられます。
**仕上げ**は作られたとおり・つや消し・アニメ調から選びます。
作られたとおりでは金属の光り方や表面の凹凸も描きます。

色合い・金属感・粗さ・発光・不透明度は、モデル全体にも、素材ごとにも決められます。
素材を選んで**この素材を描かない**にすると、その部分だけを消せます。
**見た目を元に戻す**で、作られたとおりに戻ります。

卓の画質を**軽量**にしているときは、設定によらず色と絵だけで描きます。

### 動き

立っているとき・歩くとき・攻撃・魔法と射撃・被弾・撃破に流す動きを、モデルが持つ動きから選びます。
**モデルにまかせる**のままにすると、動きの名前から選びます。
▶を押すと、プレビューでその動きを試せます。

動きを持たないモデル（同梱のフィギュアなど）は、モデルごと動かして演じます。
歩くときは小さく跳ね、攻撃では踏み込み、被弾ではのけぞり、撃破では倒れます。
これを止めるには、**動きを持たない役は、フィギュアのようにモデルごと動かす**を外します。

卓では、エフェクトを撃ったコマが攻撃か魔法を、当たったコマが被弾を、撃破されたコマが撃破を演じます。
立っている間の動きは、卓の画質が**高**か**標準**のときに流れます。

### VRMに動きを足す

VRMは両腕を水平に広げたTポーズで作る決まりのモデルで、立ち姿や動きを持っていません。
動きはVRMアニメーション（.vrma）のファイルで足します。
VRoidの公式から、全身を見せる・挨拶・Vサインなど7種の.vrmaが無料で配られています（[VRMアニメーション7種セット](https://booth.pm/ja/items/5512385)）。

1. .vrmaのファイルを卓か**3Dモデル**の一覧に落とします。一覧では「動き」と印が付き、コマのモデルには選べません。
2. VRMで描いているコマの**見た目と動きを設定**を開き、動きの節の「動き（.vrma）を足す…」から選びます。

足した動きはそのVRMを使う全部のコマで、モデル自身の動きと同じに使えます。
立っているとき・歩くときなどの選択肢、**モデルの動き**のメニュー、チャットの`《動き:名前》`に、ファイルの名前で出ます。
立っているときの動きを選ばなければ、足した動きのうち、攻撃や歩きなどほかの役と分かる名前でない最初の動きで立ちます。そういう動きがなければ、最初の動きの最初の姿勢で止まって立ちます。
足した動きは×で外せます。
.vrmaの表情と視線の動きは使いません。

### 表情

形（ブレンドシェイプ）を持つモデルでは、まばたき・口・呼吸に使う形と、保つ表情、立っている間にゆらす形を決められます。
まばたきと口は何も選ばなくても名前から選んで動きます。
動きを持たないモデルでも、形をゆらすと立っている間に動きます。
ノベルモードで話している間は口が動きます。

## 動きを流す

コマを右クリックして**バフ・演出**の**モデルの動き**を選ぶと、全員の画面でそのコマのモデルが動きを1回流します。

チャットでは`《動き:名前》`と書きます。
名前に「攻撃」「魔法」「被弾」と書くと、その役の動きを流します。
秘話の行では、送った人の画面でだけ流します。

```
《動き:Wave》手を振る
```

## 立ち絵に加える

プレビューの下の**この見た目を立ち絵に加える**を押すと、プレビューの絵を立ち絵に加え、コマの絵にします。
チャットのアイコンや一覧にも、設定した見た目のモデルが出ます。
元の立ち絵は残るので、シートの立ち絵から選び直せます。

## ほかの画面のモデル

戦闘カットイン・カットイン・ノベルモードでも、3Dモデルで描くコマはモデルで出ます。
戦闘カットインでは歩いて入り、攻撃と被弾と撃破を演じます。
カットインでは編集画面の**3Dモデル**でモデルと、表示したときの動きを選べます。
モデルを持っていない参加者の画面では、これまでどおり画像で出ます。

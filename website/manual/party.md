# 同行（パーティ）

このページは、キャラクターをパーティにまとめて、おたがいの視界を分け合わせる「同行」を説明します。
[暗闇](/manual/vision-lighting)を使ったダンジョン探索で、「隣を歩いているはずの仲間のコマが自分には見えない」という状態をなくすための仕組みです。
編成できるのはGMだけで、PLは誰と同行しているかを確かめられます。

<Shot src="party" alt="同行パネル。未所属のキャラクターに同行先を選ぶプルダウンが並んでいる" width="560" caption="パーティを作り、キャラクターを同行先へ割り当てます" />

同じパーティに入ったキャラクターどうしで、次の2つを分け合います。

| 分け合うもの | 内容                                                                                 |
| ------------ | ------------------------------------------------------------------------------------ |
| 視界         | 同行者が見ている範囲（照らされた範囲・暗視・真視）も、自分の見える範囲に合わさります |
| コマ         | 暗闇の中でも、同行者のコマは見えたままになります                                     |

編成できるのは、GMだけです。
暗闇は情報を遮るための機能なので、PLが自分の操作でほかの人の視界を手に入れる方法は用意していません。

## パーティを編成する

1. [GMツールバー](/manual/roles#gmツールバー)の**同行**（重なった円のアイコン）を押して、「同行」パネルを開きます。
2. **パーティ追加**を押して、パーティを作ります。
3. 下の**未所属**に並ぶキャラクターの**同行先を選択**から、入れるパーティを選びます。

パネルでできることは、次のとおりです。

| したいこと         | 操作                                                                                                 |
| ------------------ | ---------------------------------------------------------------------------------------------------- |
| パーティを作る     | **パーティ追加**を押します。色は、ほかのパーティと重ならないように自動で選ばれます                   |
| 名前を変える       | 名前の欄を、その場で書き換えます。名前は色の丸と一緒に一覧に出ます                                   |
| 色を変える         | 6色から選びます                                                                                      |
| メンバーを入れる   | **未所属**の行の**同行先を選択**から、パーティを選びます                                             |
| メンバーを外す     | メンバーの行の**パーティから外す**（→のアイコン）を押します                                          |
| パーティを解散する | **パーティを削除**（ゴミ箱）を押します。入っていたキャラクターは未所属に戻るだけで、コマは消えません |

メンバーの名前を押すと、そのコマへ視点が移ります。二手に分かれたとき、どちらの班がどこにいるかを確かめるのに使えます。

## 同盟（別のパーティを味方として扱う） {#allies}

パーティ名の下に「同盟:」と並ぶチェックを入れると、その2つのパーティは、移動について同じパーティとして扱われます。

- 味方NPCの一団を、敵とは別の扱いにできます
- 3すくみの戦闘で「AとBは手を組んだ、Cは敵」を表せます

同盟が影響するのは[移動範囲](/manual/move-range)の2か所です。**他のコマの前を通る**（同盟相手のマスは「同じパーティのコマ」の設定に従う）と、**ZOCの敵味方**（部屋設定で敵味方をパーティで決めているとき、同盟相手は敵になりません）。視界を分け合うのは別の話で、同盟を結んでも分け合いません。共有したいなら同じパーティに入れてください。

どちらか片方がチェックすれば成立します。両方に入れる必要があると、片側だけ入れたときに、気づかないまま何も起きない状態になってしまうからです。外すときは両方から外れます。パーティを削除すると、そのパーティを指していた同盟も消えます。

## この地点に集める

1. テーブルの何もない場所を右クリックします。
2. **この地点を中心にパーティを配置**から、パーティを選びます。

そのパーティのコマが、その地点の周りへ集まります。
GMだけに出る項目です。

- 押した升目から近い順に、空いている升目へ詰めて並びます。ヘクスでも同じです
- ほかのコマが立っている升目は避けます。大きいコマは、必要な広さが空いている場所に入ります
- テーブルに出ていないメンバーがいるパーティは、「（卓上のN体）」と「（卓外のN体も出す）」の2つに分かれて並びます。どちらも体数が添えてあるので、押す前に何体動くか分かります

## キャラクター単位の所属

パーティに入るのは、プレイヤーではなくキャラクターです。これにより次のような使い分けができます。

- **斥候を出す** — 1人のプレイヤーが2体受け持っているとき、片方だけを別のパーティに移して単独行動させる
- **二手に分かれる** — パーティを2つ作って振り分けると、それぞれの班の中だけで視界が共有されます
- **NPCを同行させる** — GMのNPCをパーティに入れると、そのNPCの視界もプレイヤーへ渡ります。道案内やたいまつ持ちの演出に使えます

未所属のキャラクターは誰とも共有しません。単独行動のあいだは未所属に戻しておくのが素直です。

## プレイヤーからの見え方

PLは編成を変えられませんが、いま誰と同行しているかは確かめられます。

[PLツールバー](/manual/pl-tools#所有キャラクター一覧)の所有キャラクター一覧で、各キャラクターの名前の右にパーティの色と名前が並びます。
その札にマウスを乗せると、同じパーティにいるほかのキャラクターの名前が出ます。自分のコマは含まれません。

未所属のキャラクターには何も表示されません。単独行動中であることがそのまま分かります。

## 見学との違い

[見学](/manual/roles)は、パーティ編成に関係なく、全プレイヤーの視界を合わせた範囲を見ます。観戦のための仕組みなので、同行の編成では変わりません。

## 保存されるもの

- パーティは部屋全体の設定で、テーブルを切り替えても続きます
- 名前・色・所属は[保存データ](/manual/save-load)に含まれ、ZIPを読み込み直しても復元されます
- パーティを削除すると、そのパーティを指していたキャラクターは未所属として扱われます

## 補足

- GMは同行の編成に関係なく常にすべてを見られます。プレイヤーからどう見えているかは、GMツールバーの**ペルソナ**で確認できます
- 同行者の視界は「その人が今いる場所から見えている範囲」です。壁の裏は同行していても見えません（[真視](/manual/vision-lighting#キャラクターの視界)は例外です）
- 手札やシークレット情報は同行では共有されません。共有の範囲を決めるのは[情報の公開範囲](/manual/disclosure)の側です

## うまくいかないとき

| 見えるもの                                                     | 原因と直しかた                                                                                              |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| 暗闇で、隣の仲間のコマが見えない                               | 2体が同じパーティに入っていません。GMが「同行」パネルで同じパーティに入れます。同盟では視界を分け合いません |
| 同じパーティなのに、仲間の見ている壁の向こうが見えない         | 分け合うのは、その仲間がいまいる場所から見えている範囲です。壁の裏は、同行していても見えません              |
| **同行**のボタンがない                                         | GMツールバーはGMにだけ出ます。PLは編成を変えられません                                                      |
| 「すべてのキャラクターがいずれかのパーティに所属しています。」 | 未所属のキャラクターがいません。別のパーティへ移すときは、いまのパーティから外してから選びます              |
| **この地点を中心にパーティを配置**が出ない                     | GMだけに出る項目です。パーティがないときも出ません                                                          |

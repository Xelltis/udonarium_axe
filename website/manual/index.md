# 操作マニュアル

Udonarium Axe の画面構成と基本操作をまとめた操作マニュアルです。
機能ごとの引きかたで並べているので、頭から読むより、必要になったところを開いてください。

はじめて開いたところなら [遊びはじめる](/play/) から、卓を回す側なら [はじめてのセッション](/play/first-session) から読むと流れが掴めます。

## 画面の見かた

ルームを開くと、3D のテーブルを中心に、左側へ接続パネルとチャットウィンドウが自動で開いた状態になります。

<ScreenTour />

ツールバーはロールに応じて [GM ツールバー](/manual/roles#gm-ツールバー) または
[PL ツールバー](/manual/pl-tools) が出ます。見出しの横の矢印で畳めるほか、FAB メニューの[ウィジェット](#ウィジェット)で隠すこともできます。

## FAB メニュー

左端のハンバーガーボタンを押すと、機能パネルを開くメニューが縦に展開します。
近い機能は 1 つの項目にまとめてあり、押すとその項目の高さで横に小窓が開きます。小窓のアイコンは、マウスを乗せると名前が出ます。

<Shot src="fab-menu" alt="FAB メニューを開いた状態。アイコンが縦に並んでいる" width="300" caption="ハンバーガーボタンを押すと、アイコンが縦に並びます" />

| 項目           | 内容                                                                                      |
| -------------- | ----------------------------------------------------------------------------------------- |
| 接続           | ニックネーム・アイコン・ロビー（接続パネル）                                              |
| チャット       | チャットウィンドウ                                                                        |
| 部屋設定       | 卓をまたいで効く決めごと（[部屋設定](/manual/room-settings)）。リプレイもここから開きます |
| テーブル関連   | テーブル設定・マップエディター・マップ生成・卓上ディスプレイ・ノベルモード                |
| ゲームリソース | インベントリ・バフマネージャー・状態異常・ダイス表設定・手札                              |
| メディア       | 画像・ジュークボックス・カットイン・エフェクト                                            |
| セーブ&ロード  | ルームの保存・ZIP 読込・キャラ取り込み（[保存と読み込み](/manual/save-load)）             |
| ウィジェット   | 卓の上に浮かぶ小物とツールバーの出し入れ（[下記](#ウィジェット)）                         |
| 表示           | 視点・テーマ・スキン・アニメーション・描画・言語。この端末だけの設定です（[下記](#表示)） |

並びは、押す場面の近いものが隣り合うようにしてあります。上から「誰がいるか」「何を話しているか」「部屋と卓」「遊ぶのに使うもの」「卓の前に出す演出」と続き、その下が保存と読み込み、最後がこの端末だけの設定です。

小窓の中身はロールで変わります。マップエディターとマップ生成は GM のときだけ出ます。バフマネージャー・手札・エフェクトは、見学のときには出ません。

リプレイは[部屋設定](/manual/room-settings)の**ユーティリティ**から開きます。自動保存の一覧も部屋設定にあります。

### ウィジェット

卓の上に浮かぶ小物を、1 つずつ出したりしまったりします。出ているものはアイコンが点灯します。どれもこのブラウザに覚えられ、次に開いたときも同じ状態です。

- **PL ツール / GM ツール** — いまのロールのツールバーだけが並びます。隠したあとで出し直すと、ドラッグで置いた位置に戻ります
- **時計** — 現在時刻（時:分:秒）。ドラッグで動かせ、ホバーで出る × からも閉じられます
- **録画** — [リプレイ](/manual/replay)を記録する録画ピル
- **通信品質** — [いまの通信品質](/manual/connection#いまの通信品質を見る)を示すウィジェット
- **ミニプレイヤー** — [ジュークボックス](/manual/jukebox)の再生だけを操作する小さなプレイヤー。隠しても BGM は流れ続けます
- **ホットバー** — 数字キーで操作を撃つ[ホットバー](/manual/hotbar)。見学のときは出ません

### 表示

この端末の見た目を変える設定で、部屋のほかの人には影響しません。スキン以外のボタンは、押すたびに次の選択肢へ移ります。マウスを乗せると、「テーマ: ダーク」のようにいまの設定が名前と一緒に出ます。

- **視点** — 自動 / 3D / 2D。自動のあいだは[テーブル設定](/manual/table-setting)の推奨ビューに従います
- **テーマ** — 自動 / ダーク / ライト（[テーマ](/manual/theme)）
- **スキン** — 配色を選ぶパネルを開きます（[スキンを選ぶ](/manual/theme#skin)）
- **アニメーション** — 演出の動きを 自動 / 常に再生 / 停止 から選びます（[アニメーションの表示](/manual/theme#animation)）
- **描画** — 自動 / 軽くする / 通常
- **言語** — 日本語 / English / 한국어（ボタンには JA / EN / KO と出ます）

狭い画面でパソコン版の画面を使っているときは、[スマートフォン版に戻す](/manual/mobile#パソコン版の画面を使いたいとき)ボタンもここに出ます。

部屋の作り方とロビーの使い方は [部屋とロビー](/manual/rooms) にあります。

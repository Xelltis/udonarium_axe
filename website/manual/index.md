# 操作マニュアル

このマニュアルは、Udonarium Axe（以下Axe）の機能ごとに、できることと操作のしかたをまとめたものです。
遊んでいる途中で「これはどうやるのか」と思ったときに、その機能のページを開いてください。
各ページの冒頭に、何ができるか、誰が使えるか（GM・PL・見学）、どこから開くかを書いています。

はじめて開いたところなら[遊びかたの案内](/play/)から、卓を回す側なら[はじめてのセッション](/play/first-session)から読むと流れがつかめます。
言葉の意味は[遊びかたの案内の用語](/play/#用語)にあります。

## 画面の見かた

Axeを開くと、3Dのテーブルを中心に、左側に接続パネルとチャットウィンドウが開いた状態になります。
画像の番号は、下の一覧の番号と対応しています。

<ScreenTour />

ツールバーには、ロールに応じて[GMツールバー](/manual/roles#gmツールバー)か[PLツールバー](/manual/pl-tools)が出ます。
見出しの横の矢印で畳めます。FABメニューの[ウィジェット](#ウィジェット)で隠すこともできます。

## FABメニュー

画面左上の丸いハンバーガーボタンがFABメニューです。
押すと、機能のパネルを開くボタンが縦に並びます。
近い機能は1つの項目にまとめてあり、押すとその項目の高さで、横に小窓が開きます。
小窓のアイコンにマウスを乗せると、名前が出ます（全部まとめて出す方法は[ボタンの名前をまとめて見る](#ボタンの名前をまとめて見る)）。

<Shot src="fab-menu" alt="FABメニューを開いた状態。アイコンが縦に並んでいる" width="300" caption="ハンバーガーボタンを押すと、アイコンが縦に並びます" />

初期配置の項目は次のとおりです。

| 項目           | 開くもの                                                                                                                             |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 接続           | 接続パネル。ニックネーム・アイコン・役割・ロビー（→ [部屋とロビー](/manual/rooms)）                                                  |
| チャット       | チャットウィンドウ（→ [チャットの基本](/manual/chat)）                                                                               |
| 部屋設定       | 部屋全体の決めごと。リプレイと自動保存の一覧もここから開きます（→ [部屋設定](/manual/room-settings)）                                |
| テーブル関連   | テーブル設定・マップエディター・マップ生成・卓上ディスプレイ・ノベルモード・ダンジョンドリィマスターモード                           |
| ゲームリソース | インベントリ・バフマネージャー・状態異常・ダイス表設定・手札                                                                         |
| メディア       | 画像・ジュークボックス・カットイン・エフェクト                                                                                       |
| セーブ&ロード  | 部屋の保存・ZIP読込・キャラ取り込み（→ [保存と読み込み](/manual/save-load)）                                                         |
| ウィジェット   | テーブルの上に浮かぶ小物とツールバーの出し入れ（→ [ウィジェット](#ウィジェット)）                                                    |
| 表示           | 視点・テーマ・スキン・音の設定・アニメーション・描画・言語・メニューの編集。この端末だけの設定です（→ [表示](#表示)）                |
| ?              | FABメニューとツールバーのボタンの名前と、キー操作の一覧をまとめて出す（→ [ボタンの名前をまとめて見る](#ボタンの名前をまとめて見る)） |

上から順に、誰がいるか、何を話しているか、部屋とテーブル、遊ぶのに使うもの、卓の前に出す演出、と並びます。
その下に保存と読み込み、この端末だけの設定が続き、いちばん下がボタンの名前をまとめて出すボタンです。
これは初期配置で、並びも中身も自分で組み替えられます（→ [メニューを自分で組む](#メニューを自分で組む)）。

小窓の中身は、ロールで変わります。

| 項目                                                               | 出るロール |
| ------------------------------------------------------------------ | ---------- |
| マップエディター・マップ生成                                       | GMだけ     |
| バフマネージャー・手札・エフェクト・ダンジョンドリィマスターモード | GMとPL     |
| 上のほかの項目                                                     | 全員       |

### ウィジェット

**ウィジェット**の小窓では、テーブルの上に浮かぶ小物を1つずつ出したりしまったりします。
出ているものは、アイコンが点灯します。
どれを出しているかはこのブラウザに残り、次に開いたときも同じです。

| 項目               | 内容                                                                                               |
| ------------------ | -------------------------------------------------------------------------------------------------- |
| PLツール・GMツール | いまのロールのツールバーだけが並びます。隠したあとで出し直すと、ドラッグで置いた位置に戻ります     |
| 時計               | いまの時刻（時:分:秒）。ドラッグで動かせ、マウスを乗せると出る × からも閉じられます                |
| 方位磁石           | テーブルのどちらが北かを示すコンパス（下の説明）                                                   |
| 録画               | [リプレイ](/manual/replay)を記録する録画ピル                                                       |
| 通信品質           | [いまの通信品質](/manual/connection#いまの通信品質を見る)を示す表示                                |
| ミニプレイヤー     | [ジュークボックス](/manual/jukebox)の再生だけを操作する小さなプレイヤー。隠してもBGMは流れ続けます |
| ホットバー         | 数字キーで操作を呼び出す[ホットバー](/manual/hotbar)。見学のときは出ません                         |

方位磁石は、視点を回すと文字盤も一緒に回り、その下に画面の上が向いている方角（`350° 北`など）が出ます。
「北の壁に扉がある」と決めた部屋で、視点を回したあとに向きを取り戻すのに使います。
テーブル設定で[磁場異常](/manual/table-setting#view)を入れたテーブルでは、針が北を指さずに振れ続けます。
右クリック（スマートフォンでは長押し）で、文字盤を**現代風**・**ファンタジー風**・**SF 風**から選べます。

### 表示

**表示**の小窓には、この端末の見た目と音を変える設定が並びます。
部屋のほかの人には影響しません。
**スキン**・**音の設定**・**メニューの編集**はパネルが開き、ほかのボタンは押すたびに次の選択肢へ移ります。
マウスを乗せると、「テーマ: ダーク」のように、いまの設定が名前と一緒に出ます。

| 項目           | 選択肢                  | 既定値                                       | 内容                                                                                     |
| -------------- | ----------------------- | -------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 視点           | 自動・3D・2D            | 自動                                         | 自動のあいだは、[テーブル設定](/manual/table-setting)の推奨の見かたに従います            |
| テーマ         | 自動・ダーク・ライト    | 自動                                         | 自動のあいだは、OSの設定に従います（→ [テーマ](/manual/theme)）                          |
| スキン         | パネルで選ぶ            |                                              | 配色を選びます（→ [スキンを選ぶ](/manual/theme#skin)）                                   |
| 音の設定       | パネルで決める          |                                              | 自分の端末で鳴る音の大きさを、種類ごとに決めます（→ [音の設定](/manual/sound-settings)） |
| アニメーション | 自動・常に再生・停止    | 自動                                         | 演出の動き（→ [アニメーションの表示](/manual/theme#animation)）                          |
| 描画           | 自動・軽くする・通常    | 自動                                         | 軽くすると、パネルの後ろのすりガラスをやめ、天候などの動きを間引きます                   |
| 言語           | 日本語・English・한국어 | ブラウザの言語（日本語と韓国語のほかは英語） | ボタンには`JA`・`EN`・`KO`と出ます                                                       |
| メニューの編集 | パネルで組む            |                                              | FABメニューとツールバーを組み替えます（→ [メニューを自分で組む](#メニューを自分で組む)） |

描画の「自動」は、Firefoxのとき、またはCPUのコアかメモリが2以下のパソコンのときに軽くします。

狭い画面でパソコン版の画面を使っているときは、[スマートフォン版に戻す](/manual/mobile#パソコン版の画面を使いたいとき)ボタンも、ここに出ます。

### ボタンの名前をまとめて見る

アイコンを見ても、どれが何のボタンか分からないときは、`?`キーを押します。
FABメニューとツールバーのボタンに、名前が一斉に出ます。
小窓にしまってある項目も名前つきで横に並ぶので、見つけたらそこで押せば済みます。
盤面の[スイッチ](/manual/switch)の名前も、このとき一緒に出ます。

キーボードを使わないときは、FABメニューのいちばん下にある`?`のボタンか、ハンバーガーボタンの右クリックメニューからも出せます。

名前と一緒に、いまの画面で使えるキー操作の一覧も出ます。
一覧は、ボタンの名前に重ならない場所に出ます。
画面ごとの全部のキーは、[キー操作の一覧](/manual/shortcuts)にまとめてあります。

名前と一覧は、どれかのボタンを押すか、画面のどこかをクリックすると消えます。
`?`をもう一度押しても、`Esc`を押しても消えます。
セッション中にプレイヤーから「そのボタンはどこ？」と聞かれたら、まず`?`を押してもらうのが早道です。

ノベルモードの`?`は別の機能で、ノベルモードのキーの一覧が開きます。
ボタンの名前の表示は、スマートフォン版の画面には出ません。

## メニューを自分で組む

卓ごとに、使う道具は違います。
**表示**の中の**メニューの編集**を開くと、FABメニューと自分のツールバーを組み替えられます。
パネルの上のタブで、組み替えるメニューを選びます。
FABメニューは、タブでは「**Fav メニュー**」と出ます。

| したいこと                 | 操作                                                                                                                                                                            |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 項目を足す                 | **項目を足す**で一覧を開き、選びます。名前で絞り込めます。メニューの末尾に付き、一覧は開いたままなので続けて足せます。ふだんFABの奥にあるパネルも、よく使うなら一番上に置けます |
| 項目を外す                 | 行のゴミ箱を押します                                                                                                                                                            |
| 名前を変える               | 名前の欄を書き換えます                                                                                                                                                          |
| アイコンを変える           | 左端のマークを押して一覧を開き、選びます。名前で絞り込めます。「既定に戻す」で元のマークに戻ります                                                                              |
| 並べ替える                 | 左端の取っ手をつかんで上下に運びます。タッチでは、取っ手を長押しすると、上下の移動と移す先を選ぶメニューが出ます                                                                |
| 小窓に入れる・小窓から出す | 小窓の見出しのすぐ下に落とすと、その中へ入ります。メニュー直下の項目の隣に落とすと、外へ出ます。小窓の中に小窓は作れません                                                      |
| 小窓を作る                 | **小窓を作る**で空の小窓ができます。名前はその行で書き換えます。空の小窓はメニューに出ません                                                                                    |
| 元に戻す                   | **初期配置に戻す**で、そのメニューだけ元に戻ります。**すべてのメニューを初期配置に戻す**では、FABメニューとGMツール・PLツールがまとめて戻ります                                 |
| 別の端末に持っていく       | **書き出す**でファイルに保存し、向こうの端末で**読み込む**を押します                                                                                                            |

組んだ並びは、この端末だけのものです。
部屋の保存ファイルには入らず、同じ部屋のほかの人にも影響しません。

編集できるメニューは、ロールで変わります。
GMツールはGMのとき、PLツールはプレイヤーのときだけタブに出ます。
一覧に出る項目も、そのロールが使えるものだけです。
並びを書き換えても、GMだけの機能は現れません。

## うまくいかないとき

| 見えるもの                                 | 原因と直しかた                                                                                                                                  |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| マニュアルに書いてある項目がメニューにない | ロールで出ない項目か、メニューを組み替えて外しています。`?`を押して名前で探すか、**メニューの編集**の**初期配置に戻す**で戻します               |
| ツールバーが出ない                         | **ウィジェット**でPLツール・GMツールを隠しているか、見出しの矢印で畳んでいます。**ウィジェット**で出し直します                                  |
| 方位磁石の針が止まらない                   | テーブル設定で磁場異常が入っています。そのテーブルの仕掛けです                                                                                  |
| 画面の文字が英語や韓国語になった           | **表示**の**言語**が切り替わっています。押して日本語（`JA`）に戻します                                                                          |
| `?`を押しても名前が出ない                  | チャット欄などに文字を入力しているあいだは、キーがテーブルに届きません。入力欄の外を押してから`?`を押します。スマートフォン版の画面では出ません |

# 操作マニュアル

Udonarium Axeの画面構成と基本操作をまとめた操作マニュアルです。
機能ごとに引けるように並べているので、頭から読むより、必要になったところを開いてください。

はじめて開いたところなら[遊びはじめる](/play/)から、卓を回す側なら[はじめてのセッション](/play/first-session)から読むと流れが掴めます。

## 画面の見かた

ルームを開くと、3Dのテーブルを中心に、左側へ接続パネルとチャットウィンドウが自動で開いた状態になります。

<ScreenTour />

ツールバーには、ロールに応じて[GMツールバー](/manual/roles#gmツールバー)または
[PLツールバー](/manual/pl-tools)が出ます。見出しの横の矢印で畳めるほか、FABメニューの[ウィジェット](#ウィジェット)で隠すこともできます。

## FABメニュー

左端のハンバーガーボタンを押すと、機能パネルを開くメニューが縦に展開します。
近い機能は1つの項目にまとめてあり、押すとその項目の高さで横に小窓が開きます。小窓のアイコンは、マウスを乗せると名前が出ます（全部まとめて出す方法は[下記](#ボタンの名前をまとめて見る)）。

<Shot src="fab-menu" alt="FABメニューを開いた状態。アイコンが縦に並んでいる" width="300" caption="ハンバーガーボタンを押すと、アイコンが縦に並びます" />

| 項目           | 内容                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------ |
| 接続           | ニックネーム・アイコン・ロビー（接続パネル）                                               |
| チャット       | チャットウィンドウ                                                                         |
| 部屋設定       | 卓をまたいで効く決めごと（[部屋設定](/manual/room-settings)）。リプレイもここから開きます  |
| テーブル関連   | テーブル設定・マップエディター・マップ生成・卓上ディスプレイ・ノベルモード                 |
| ゲームリソース | インベントリ・バフマネージャー・状態異常・ダイス表設定・手札                               |
| メディア       | 画像・ジュークボックス・カットイン・エフェクト                                             |
| セーブ&ロード  | ルームの保存・ZIP読込・キャラ取り込み（[保存と読み込み](/manual/save-load)）               |
| ウィジェット   | 卓の上に浮かぶ小物とツールバーの出し入れ（[下記](#ウィジェット)）                          |
| 表示           | 視点・テーマ・スキン・アニメーション・描画・言語。この端末だけの設定です（[下記](#表示)）  |
| ボタンの名前   | FABメニューとツールバーのボタンの名前をまとめて出す（[下記](#ボタンの名前をまとめて見る)） |

並びは、押す場面の近いものが隣り合うようにしてあります。上から「誰がいるか」「何を話しているか」「部屋と卓」「遊ぶのに使うもの」「卓の前に出す演出」と続き、その下が保存と読み込み、この端末だけの設定で、いちばん下がボタンの名前をまとめて出すボタンです。ただしこれは初期配置で、**並びも中身も自分で組み替えられます**（→ [メニューを自分で組む](#メニューを自分で組む)）。

小窓の中身はロールで変わります。マップエディターとマップ生成はGMのときだけ出ます。バフマネージャー・手札・エフェクトは、見学のときには出ません。

リプレイは[部屋設定](/manual/room-settings)の**ユーティリティ**から開きます。自動保存の一覧も部屋設定にあります。

### ウィジェット

卓の上に浮かぶ小物を、1つずつ出したりしまったりします。出ているものはアイコンが点灯します。どの小物の状態もこのブラウザに記憶され、次に開いたときも同じです。

- **PLツール / GMツール** — いまのロールのツールバーだけが並びます。隠したあとで出し直すと、ドラッグで置いた位置に戻ります
- **時計** — 現在時刻（時:分:秒）。ドラッグで動かせ、ホバーで出る × からも閉じられます
- **方位磁石** — 卓のどちらが北かを示すコンパス。卓を回すと文字盤も一緒に回り、その下に、画面の上が向いている方角（`350° 北`など）が出ます。「北の壁に扉がある」と決めた部屋で、視点を回したあとに向きを取り戻すためのものです。テーブル設定で[磁場異常](/manual/table-setting#コマの見せ方)を入れた卓では、針が北を指さず振れ続けます。右クリック（長押し）で文字盤を**現代風 / ファンタジー風 / SF風**から選べます
- **録画** — [リプレイ](/manual/replay)を記録する録画ピル
- **通信品質** — [いまの通信品質](/manual/connection#いまの通信品質を見る)を示すウィジェット
- **ミニプレイヤー** — [ジュークボックス](/manual/jukebox)の再生だけを操作する小さなプレイヤー。隠してもBGMは流れ続けます
- **ホットバー** — 数字キーで操作を撃つ[ホットバー](/manual/hotbar)。見学のときは出ません

### 表示

この端末の見た目や音を変える設定で、部屋のほかの人には影響しません。スキン・音の設定・メニューの編集はパネルが開き、ほかのボタンは押すたびに次の選択肢へ移ります。マウスを乗せると、「テーマ: ダーク」のようにいまの設定が名前と一緒に出ます。

- **視点** — 自動 / 3D / 2D。自動のあいだは[テーブル設定](/manual/table-setting)の推奨ビューに従います
- **テーマ** — 自動 / ダーク / ライト（[テーマ](/manual/theme)）
- **スキン** — 配色を選ぶパネルを開きます（[スキンを選ぶ](/manual/theme#skin)）
- **音の設定** — 自分の端末で鳴る音の大きさを、種類ごとに決めるパネルを開きます（[音の設定](/manual/sound-settings)）
- **アニメーション** — 演出の動きを「自動 / 常に再生 / 停止」から選びます（[アニメーションの表示](/manual/theme#animation)）
- **描画** — 自動 / 軽くする / 通常
- **言語** — 日本語 / English / 한국어（ボタンにはJA / EN / KOと出ます）
- **メニューの編集** — Favメニューとツールバーを組み替えます（→ [メニューを自分で組む](#メニューを自分で組む)）

狭い画面でパソコン版の画面を使っているときは、[スマートフォン版に戻す](/manual/mobile#パソコン版の画面を使いたいとき)ボタンもここに出ます。

### ボタンの名前をまとめて見る

アイコンを見てもどれが何のボタンか分からないときは、`?`キーを押します。FABメニューとツールバーのボタンに、名前が一斉に出ます。盤面の[スイッチ](/manual/switch)の名前もこのとき一緒に出ます。小窓にしまってある項目も名前つきで横に並ぶので、見つけたらそこで押せば済みます。キーボードを使わないなら、FABメニューのいちばん下にある **?** のボタンか、ハンバーガーボタンの右クリックメニューからも出せます。

名前は、どれかのボタンを押すか画面のどこかをクリックすると消えます。`?`をもう一度押しても、Escでも同じです。セッション中にプレイヤーから「そのボタンはどこ？」と聞かれたら、まず`?`を押してもらうのが早道です。

ノベルモードの`?`は別の機能で、ノベルモードのショートカット一覧が開きます。ボタンの名前の表示は、スマートフォン版の画面には出ません。

部屋の作り方とロビーの使い方は[部屋とロビー](/manual/rooms)にあります。

## メニューを自分で組む

卓ごとに使う道具は違います。**表示**の中の**メニューの編集**を開くと、Favメニューと自分のツールバーを好きに組み替えられます。

- **項目を足す・外す** — 下の「項目を足す」で一覧が開きます。名前で絞り込めます。選ぶとメニューの末尾に付き、一覧は開いたままなので続けて何個でも足せます。外すのは行のゴミ箱です。部屋パネルは20枚以上あり、ふだんFABの奥にあるものも、よく使うなら一番上に置けます
- **名前とアイコンを変える** — 名前の欄を書き換えると、その名前で出ます。アイコンは左端のマークを押すと一覧が開き、名前で絞り込んで選べます。「既定に戻す」でもとのマークに戻ります
- **並べ替える・小窓に出し入れする** — 左端の取っ手をつかんで上下に運びます。小窓の見出しのすぐ下に落とすとその中へ入り、メニュー直下の項目の隣に落とすと外へ出ます。小窓の中に小窓は作れません
- **タッチのとき** — 取っ手を長押しすると、上下の移動と移す先を選ぶメニューが出ます
- **小窓を作る** — 「小窓を作る」で空の小窓ができます。名前はその行で書き換えます。空の小窓はメニューに出ません
- **初期配置に戻す** — そのメニューだけ元に戻ります

組んだ並びは**この端末だけのもの**です。部屋の保存ファイルには入らず、同じ部屋のほかの人にも影響しません。別の端末で同じ並びを使いたいときは「書き出す」でファイルに保存し、向こうで「読み込む」を押します。

編集できるメニューはロールで変わります。GMツールはGMのとき、PLツールはプレイヤーのときだけタブに出ます。一覧に出る項目もそのロールが使えるものだけです。並びを書き換えたところでGM専用の機能は現れません。

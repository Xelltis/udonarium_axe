# 操作マニュアル

Udonarium Axe の画面構成と基本操作をまとめた操作マニュアルです。
機能ごとの引きかたで並べているので、頭から読むより、必要になったところを開いてください。

はじめて開いたところなら [遊びはじめる](/play/) から、卓を回す側なら [はじめてのセッション](/play/first-session) から読むと流れが掴めます。

## 画面の見かた

ルームを開くと、3D のテーブルを中心に、左側へ接続パネルとチャットウィンドウが自動で開いた状態になります。

<ScreenTour />

ツールバーはロールに応じて [GM ツールバー](/manual/roles#gm-ツールバー) または
[PL ツールバー](/manual/pl-tools) が出ます。時計・ミニプレイヤーの表示切り替えもここです。

## FAB メニュー

左端のハンバーガーボタンを押すと、機能パネルを開くメニューが縦に展開します。

<Shot src="fab-menu" alt="FAB メニューを開いた状態。アイコンが縦に並んでいる" width="300" caption="ハンバーガーボタンを押すと、アイコンが縦に並びます" />

| 項目             | 内容                                                                                             |
| ---------------- | ------------------------------------------------------------------------------------------------ |
| 接続             | ニックネーム・アイコン・ロビー（接続パネル）                                                     |
| チャット         | チャットウィンドウ                                                                               |
| 部屋設定         | 卓をまたいで効く決めごと（[部屋設定](/manual/room-settings)）                                    |
| テーブル設定     | テーブルの作成・グリッド・背景などの設定                                                         |
| インベントリ     | コマやオブジェクトの一覧管理                                                                     |
| 画像             | 画像のアップロードと管理                                                                         |
| ジュークボックス | BGM / SE の再生と管理                                                                            |
| カットイン       | カットイン演出の作成・再生                                                                       |
| ノベルモード     | ノベルゲーム風の表示に切り替え                                                                   |
| 卓上ディスプレイ | 真上から見て遊ぶための設定を 1 か所に（[視点とテーブル操作](/manual/tabletop#tabletop-display)） |
| スキン           | 画面の配色を選ぶ・作る（[テーマ](/manual/theme#skin)）                                           |
| リプレイ         | セッションの記録を読み返す                                                                       |
| ZIP 読込         | 保存データ（zip / xml）の読み込み                                                                |
| 保存             | ルーム全体を zip で書き出し                                                                      |
| 視点             | 自動 / 3D / 2D の切り替え（クリックで循環）。自動は卓の推奨ビューに従う（この端末だけの設定）    |
| テーマ           | 自動 / ダーク / ライト の切り替え（クリックで循環）                                              |
| エフェクト       | 演出の動きを止めるかどうかの切り替え                                                             |
| 言語             | 表示言語の切り替え                                                                               |

並びは、押す場面の近いものが隣り合うようにしてあります。上から順に「誰がいるか」「何を話しているか」「部屋と卓」「卓に出すもの」「卓に出し入れするもの」、最後にこの端末だけの設定です。

自動保存の一覧は[部屋設定](/manual/room-settings#自動保存)へ、キャラクターの取り込みは同じパネルの**ユーティリティ**へ移りました。

部屋の作り方とロビーの使い方は [部屋とロビー](/manual/rooms) にあります。

# 操作マニュアル

このマニュアルは、Axeの機能ごとに、できることと操作のしかたをまとめたものです。
遊んでいる途中で「これはどうやるのか」と思ったときに、その機能のページを開いてください。
はじめて使う人は、先に[はじめに](/start/)を読むと、流れがつかめます。

## ページの組み立て

どのページも、次の順に書いています。

1. 冒頭に、何ができるか、誰が使えるか（GM・PL・見学）
2. 開きかたと、操作の手順
3. 設定の項目と、その既定値
4. うまくいかないときの、見えるものと原因・直しかた

言葉の意味は[用語集](/start/glossary)に、症状からの探しかたは[困ったとき](/help/)にあります。

## 探しかた

- 左のサイドバーは、使う場面ごとの群に分けてあります。下の[ページの一覧](#pages)も同じ順です
- 右上の検索欄で、ページの中の言葉を探せます
- Axeの画面で`?`キーを押すと、ボタンの名前がまとめて出ます（→ [ボタンの名前をまとめて見る](/manual/screen#ボタンの名前をまとめて見る)）

# 投票・点呼

このページは、参加者に点呼を取ったり、選択肢で投票してもらったりする機能を説明します。
準備ができたかの確認や、次の行き先の多数決に使います。
GMとPLが始められます。部屋のサーバーでは、見学は始められません。

<Shot src="vote" alt="点呼／投票設定パネル" width="520" caption="点呼と投票を切り替えて送信します" />

## 開く

チャットウィンドウの上の**点呼・投票**（人の形のアイコン）を押すと、**点呼/投票設定**のパネルが開きます。
**点呼**（既定）と**投票**を切り替えます。

## 点呼を取る

1. **点呼**を選びます。
2. 呼びかける相手にチェックを入れます。
3. **送信**を押します。

チャットに「点呼開始！」と出て、相手の画面に答えるためのウィジェットが出ます。

## 投票する

1. **投票**を選びます。
2. 下の項目を入れます。
3. 呼びかける相手にチェックを入れます。
4. **送信**を押します。

| 項目                     | 内容                                                                                          | 既定値                  |
| ------------------------ | --------------------------------------------------------------------------------------------- | ----------------------- |
| タイトル                 | 投票の議題（例：`次の行き先`）                                                                | 空                      |
| 選択肢                   | 空白で区切って並べます（例：`北 南 戻る`）                                                    | 空のときは「賛成 反対」 |
| 自分を含める             | 自分も答える側に入ります                                                                      | 入り                    |
| 締め切るまで中身を伏せる | 誰が何に入れたかを、締め切るまで見せません（→ [中身を伏せて投票する](#中身を伏せて投票する)） | 切り                    |

パネルの下に、答える人数が「対象 N人」と出ます。

## 答える

点呼・投票が始まると、対象者の画面に**投票ウィジェット**が出ます。
ドラッグで好きな位置に置けます（置いた位置は次回も覚えています）。

| ボタン             | すること                                                                         |
| ------------------ | -------------------------------------------------------------------------------- |
| 選択肢のボタン     | 押した時点で答えが決まります。そのあとは、集計だけが見えます                     |
| 棄権する・欠席する | 答えないことを、はっきり伝えます。このボタンを押さないかぎり、棄権にはなりません |
| 折りたたむ（∨）    | 見出しだけの帯になります。畳んでも、参加は続きます。押し直すと元に戻ります       |

帯の状態でも「確認2/5」のように進み具合が見えます。
途中でページを読み込み直しても、同じタブで同じ部屋に戻れば、終わっていない点呼のウィジェットが出てきます。

## 締め切る（始めた人だけ）

答えていない人が残っていても、点呼・投票を始めた人は、ウィジェットの下の**締め切る**で集計を決められます。
このとき集計には`未回答:2`のように、答えなかった人数が出ます。

自分を対象に含めずに始めた場合も、始めた人には集計だけが見えます。

## 中身を伏せて投票する

投票を始めるときに**締め切るまで中身を伏せる**にチェックを入れると、締め切るまでは、誰が何に入れたかと選択肢ごとの票数が誰にも見えません。始めた人にも見えません。見えるのは、何人が回答したかと、誰が回答を済ませたかだけです。先に入った票に引っ張られずに選んでほしいときに使います。チェックを入れなければ、これまでどおり票が入るたびに見えます。

- ウィジェットでは、ほかの人の回答が「回答済み」と出ます。自分の回答は自分にだけ見えます
- 棄権した人も「回答済み」と出て、棄権の数も伏せられます
- チャットには`投票：回答しました(3/5)`とだけ出ます
- 締め切ると、いつもどおり選択肢ごとの票数が集計としてチャットに出ます

点呼には、このチェックはありません。

::: warning 伏せるのは画面に出すところだけです
答えそのものは、参加者の画面どうしで送り合っています。
v1.67.0以前のAxeを使っている人が部屋にいると、その人の画面には中身が見え、その人が投票すると、チャットに選んだ選択肢が出ます。
:::

## ログの出る場所

点呼・投票にまつわる発言は、**それを始めたチャットタブ**に出ます。

| 出るもの                 | 例                              |
| ------------------------ | ------------------------------- |
| 開始                     | `点呼開始！`                    |
| 回答                     | `点呼：準備完了(3/5)`           |
| 棄権                     | `点呼：棄権しました(4/5)`       |
| 回答（中身を伏せた投票） | `投票：回答しました(3/5)`       |
| 集計                     | `点呼終了(3/5) 棄権:1 未回答:2` |

::: tip 全員に見せたいときは、共通のタブから始めます
読める人が限られたタブから始めると、そのタブを見られない参加者には、ログが見えません。
部屋のサーバーでは、見学が発言できないタブで始めると、見学の回答と棄権の発言はそのタブに出ません。見学の回答は、集計には入ります。
:::

集計の文は、始めた人の画面の言語で全員に届きます（発言としてそのまま配られるためです）。

## うまくいかないとき

| 見えるもの                       | 原因と直しかた                                                          |
| -------------------------------- | ----------------------------------------------------------------------- |
| **送信**が押せない               | 答える人が0人です。**自分を含める**を入れるか、相手にチェックを入れます |
| 「自分しか部屋にいません」       | 部屋にほかの参加者がいません                                            |
| ウィジェットが見当たらない       | 畳んで帯になっているか、ドラッグで画面の端へ動かしています              |
| 答えた人のログがチャットに出ない | 読めないタブから始めた点呼です。共通のタブから始め直します              |
| **締め切る**が出ない             | 締め切れるのは、始めた人だけです                                        |

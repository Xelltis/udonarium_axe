# 投票・点呼

参加者に点呼を取ったり、選択肢で投票してもらったりする機能です。

<Shot src="vote" alt="点呼／投票設定パネル" width="520" caption="点呼と投票を切り替えて送信します" />

## 開く

チャットウィンドウ上部の **「点呼・投票」** ボタン（人型アイコン）から開きます。
モードは**点呼**（既定）と**投票**を切り替えられます。

## 点呼

その場にいる参加者へ呼びかけ、応答を集めます。

## 投票

「投票」モードに切り替えると、入力欄が現れます。

- **タイトル** — 投票の議題（例: `夜長テスト`）
- **選択肢** — スペース区切りで入力（例: `はい いいえ 棄権`）
- **自分を含める** — 自分も対象に含めるか
- **送信** — 参加者へ送る

> 対象が0人（自分しか部屋にいない、かつ自分を含めない）の場合、送信ボタンは押せません。
> 自分しか部屋にいないときは案内文が表示されます。

## 答える

点呼・投票が始まると、対象者の画面に**投票ウィジェット**が出ます。
ドラッグで好きな位置に置けます（置いた位置は次回も覚えています）。

- **選択肢のボタン** — 押した時点で回答が確定します。以降は集計だけが見えます
- **棄権する / 欠席する** — 答えないことをはっきり伝えます。**このボタンを押さない限り棄権にはなりません**
- **折りたたむ（∨）** — 見出しだけの帯になります。**畳んでも参加は続きます**。押し直せば元に戻ります

帯の状態でも「確認2/5」のように進み具合が見えます。
途中でブラウザを再読み込みしても、**同じタブで同じ部屋に戻れば、終わっていない点呼のウィジェットは出てきます**。

## 締め切る（始めた人だけ）

未回答の人が残っていても、点呼・投票を始めた人はウィジェット下部の **「締め切る」** で集計を確定できます。
このとき集計には`未回答:2`のように、答えなかった人数が出ます。

自分を対象に含めずに始めた場合も、始めた人には集計だけが見えます。

## ログの出る場所

点呼・投票にまつわる発言は、**それを始めたチャットタブ**に出ます。

| 出るもの | 例                              |
| -------- | ------------------------------- |
| 開始     | `点呼開始！`                    |
| 回答     | `点呼：準備完了(3/5)`           |
| 棄権     | `点呼：棄権しました(4/5)`       |
| 集計     | `点呼終了(3/5) 棄権:1 未回答:2` |

> 閲覧できる人が限られたタブから始めると、そのタブを見られない参加者にはログが見えません。
> 全員に見せたいときは、共通のタブから始めてください。

集計の文は**始めた人の言語**で全員に届きます（発言としてそのまま配られるためです）。

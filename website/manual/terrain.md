# 地形

このページは、壁・段差・坂・梁のような立体の地形を、テーブルに置いて組む方法を説明します。
地形は高さを持ち、コマの移動・視線・光を遮ります。
置いて直すのはGMとPLです。

<Shot src="terrain" alt="テーブルに置かれた木箱の地形" caption="地形は高さを持ち、コマの視界や移動の目印になります" />

## 地形を置く

1. テーブルの何もない場所を右クリックします。
2. **地形を作成**を選びます。

2×2マス・高さ2マスの木箱の地形が置かれます。
大きさと画像は、右クリックの**地形設定を編集**で開く地形シートで変えます。

## 操作

地形を右クリックすると、操作のメニューが開きます。

| 項目                 | すること                                                                                                                                         | 既定値 |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| 傾斜                 | 坂にする辺を選びます（→ [傾斜をつける](#傾斜をつける)）。「壁を非表示」で壁面を隠せます                                                          | 平ら   |
| テクスチャを繰り返す | 画像を面いっぱいに引き伸ばす代わりに、1マスに1枚ずつ並べます。同梱のタイルは繰り返して使う素材なので、大きな地形ではこちらのほうが縮尺が合います | 切り   |
| 暗闇（視界・発光）   | 暗闇を使うとき、地形で視界や光を遮る・地形自体を光らせる（→ [暗闇・視界・光源](/manual/vision-lighting)）                                        |        |
| 登れない             | よじ登れない地形にします（→ [登れない地形](#登れない地形)）                                                                                      | 切り   |
| 地形設定を編集       | 地形シートを開きます（→ [面ごとの画像](#faces)）                                                                                                 |        |

移動・回転・コピー・削除などの共通の操作は、[オブジェクトの基本操作](/manual/objects)と同じです。
ヘクスのテーブルでは、地形はヘクスの角柱の壁として描かれます。

地形の上にコマを乗せて高さを表現したい場合は、[オブジェクトの基本操作](/manual/objects)の「高度」も合わせて使います。

## 傾斜をつける

右クリックメニューの**傾斜**から、**どの辺に向かって下るか**を選びます。辺は何本でも選べて、選んだ辺では地面まで下りきります。四角いテーブルは北・東・南・西の4辺、ヘクスのテーブルはそのマスの6辺から選びます。

- **1辺だけ** — 向かいの辺で天面の高さになる坂です。これまでの傾斜と同じ形です
- **向かい合う2辺** — 真ん中が尾根になり、両側へ下ります
- **隣り合う2辺** — 遠い角がいちばん高くなります
- **全方向** — 真ん中を頂点にした角錐です。四角いテーブルなら四角錐、ヘクスのテーブルなら六角錐になります
- **なし** — 平らな天面に戻します

高さは、辺からいちばん遠い場所でブロックの高さいっぱいになるように決まります。1辺だけのときに向かいの辺が高さいっぱいになるのも、全方向のときに真ん中が頂点になるのも、同じ決め方から出てきます。

坂が下りきる辺には壁が立ちません。残りの壁は坂の断面で切られるので、坂の下をのぞいても壁が飛び出しません。

## 坂の上のコマ

坂の上では、コマは**自分が立っている場所の高さ**に置かれます。ドラッグしているあいだも坂に沿って上り下りし、離したところの高さで止まります。歩かせたときも、[移動範囲](/manual/move-range)の経路に沿って坂を登ります。

足元の台座と、平置きのコマ画像は地面の傾きに沿って傾きます。立ち絵・名前・リソースバーは直立のままです。
坂に立つ人は坂と直角に立つわけではないので、傾けるのは地面に接するところだけにしています。

真上から見る[卓上ディスプレイ](/manual/tabletop#tabletop-display)では、傾けても潰れて見えるだけなので傾きません。

## 登れない地形

右クリックのメニューの「登れない」を入れると、その地形はよじ登れないものになります。崖、ガラス、堀といった「向こう側へ行けない」ものを表すためのものです。

既定は切です。入れると次のように変わります。

- コマは天面に乗りません。地形の**脇の地面に留まります**
- ドラッグすると、コマは**手前の面で引っかかって**止まります。1マスの隙間はそのまま通れます
- [移動範囲](/manual/move-range)では、壁のない平たいブロックでも越えられないマスとして数えます
- **扉は開いていれば通れます。** 閉じているあいだだけ壁と同じです

GMだけは例外で、そのまま越えて動かせます。地形そのものをドラッグしているとき（マップを組んでいるとき）も引っかかりません。

同じ設定は[マップエディター](/manual/map-editor)の機能塗りのチェックからも、[ダンジョン生成](/manual/map-generator)の「壁を登れなくする」からも入れられます。

## 壁に貼り付けて「梁」にする

地形を**壁へドラッグ＆ドロップ**（または右クリックメニューから面を切り替え）すると、その壁に貼り付き、壁から室内へ突き出した **「梁」** になります。壁は[テーブル設定](/manual/table-setting)で表示します。

- **床のキャラクターを梁の上に乗せられます。** 床のコマを梁へドラッグ＆ドロップすると梁の天面に乗り、離すとそのまま固定されます（重力で保持）。ドラッグ中も天面に追従するので、置きたい位置で離してください。
- 北・東・南・西いずれの壁の梁にも対応します。

## 面ごとの画像（6面） {#faces}

右クリックの**地形設定を編集**で開く地形シートでは、面ごとに別の画像を設定できます。

| 画像           | 使われる面                                                       |
| -------------- | ---------------------------------------------------------------- |
| 床画像・壁画像 | まとめての設定。上面と底面には床画像、側面には壁画像が使われます |
| 面ごとの画像   | 上面・底面・北・南・東・西に、1枚ずつ割り当てます                |

面ごとの画像を設定しない面には、床画像か壁画像が使われます。

## グリッド貫通表示

地形シートの**床グリッド**を入れると、テーブルのグリッドが地形を貫いて表示されます。
テーブル設定の**グリッドを常に表示**が入っているときに出ます。

- **床の地形** — 天面に、その位置の**床座標**が表示されます。
- **梁（壁の地形）** — 歩ける**天面に床座標**、室内側の**外側面に壁座標**（`N-…`など）が表示され、背後の壁グリッドと連続します。梁の上にコマをグリッドへ合わせて置くときの目安になります。

## 透明な壁

どの面にも画像を指定していない地形は、透明な壁になります。
通れず、視線も光も遮ります。
テーブルに見えるのは、GM向けの点線の枠だけです。

見えない仕切りを作りたいときに使えます。[マップエディターの機能塗り](/manual/map-editor#機能塗り)で範囲だけ先に決めておく、という手もあります。画像を1つでも指定すれば、これまでどおり描かれます。

置いたあとの地形を透明にするなら、右クリックの**テクスチャを外して透明にする**が早いです。6面と共通の2枚をまとめて外します。外した画像は戻りません。
元に戻すには、**テクスチャを選ぶ（透明をやめる）** から選び直してください。

枠は2つ出ます。壁の高さのところに破線、足元に点線です。見えない壁と天面があるものとして扱うので、**枠で囲まれたところならどこを掴んでも動かせます**。マウスを乗せると、地形全体がうっすら色づきます。床だけの地形には足元の枠しか出ません。

画像を指定してあるのに手元へ届いていないだけの地形は、透明にはなりません。透明にするかどうかは指定の有無で決まるので、他の参加者から画像が届く途中で壁が消えることはありません。

## うまくいかないとき

| 見えるもの                       | 原因と直しかた                                                                                          |
| -------------------------------- | ------------------------------------------------------------------------------------------------------- |
| コマが地形の上に乗らない         | 地形が「登れない」になっています。右クリックで外します。GMだけは、そのまま越えて動かせます              |
| 地形が見えず、点線の枠だけが出る | どの面にも画像がない、透明な壁です。**テクスチャを選ぶ（透明をやめる）** で画像を選びます               |
| 画像がぼやける・縮尺が合わない   | 大きな地形に1枚の画像を引き伸ばしています。**テクスチャを繰り返す**を入れます                           |
| 地形の上にグリッドが出ない       | 地形シートの**床グリッド**と、テーブル設定の**グリッドを常に表示**の両方を入れます                      |
| 坂が平らに見える                 | 真上から見る卓上ディスプレイでは、坂は傾けません                                                        |
| 梁にしたいのに、壁に貼り付かない | テーブルの壁が表示されていません。[テーブル設定](/manual/table-setting)で壁を表示してからドラッグします |

# ホットバー

このページは、よく使う操作を枠に入れておき、数字キー1つで呼び出すためのバー（ホットバー）の使いかたを説明します。
攻撃の判定、開幕の効果音、射程範囲の設置のように、卓の最中に何度も繰り返すものを、パネルを開かずに手元に置けます。
GMとPLが使えます。見学では出ません。

初めて使うときは、手順1から3を順に読んでください。
種別ごとの細かい設定は、必要になったときに引けば足ります。

## 1. バーを出す

1. FABメニューの**ウィジェット**を押します。
2. **ホットバー**（格子のアイコン）を押します。

画面の下にバーが出ます。
もう一度押すと、しまいます。

バーは10枠×5ページです。
10個の枠は、数字キーの`1`〜`0`にそのまま対応します。
ドラッグで、好きな位置へ動かせます。

## 2. 枠に登録する

1. 破線の空き枠を押します。すぐ隣に**スロットの設定**のパネルが開きます。
2. **種別**で、何をする枠かを選びます（→ [枠の種別](#kinds)）。
3. 種別ごとの設定を埋めます。
4. **保存**を押します。

パネルの項目は、上から次の順に並びます。
要るところだけ埋めれば足ります。

| 項目     | 内容                                                 | 空のとき                       |
| -------- | ---------------------------------------------------- | ------------------------------ |
| 種別     | 何をする枠か                                         | 選んでください                 |
| 内容     | 種別ごとの設定（送る文字、エフェクト、射程の形など） |                                |
| 誰として | その枠がどのキャラクターとして動くか                 | チャットの発言者として動きます |
| ラベル   | 枠の下に出る名前                                     | 内容から自動で付きます         |
| アイコン | 枠の絵。アイコンの名前で書きます                     | 内容から自動で決まります       |
| 色       | 枠の色。色の名前（赤・青など）か`#rrggbb`            | 種別の色になります             |

**試す**を押すと、保存せずに、その場で動かして確かめられます。

**チャット／ダイス**の枠には、**パレットから**という欄が出ます。
そのキャラクターのチャットパレットに書いてある行が、見出しごとにまとまって並ぶので、選べばそのまま枠の内容になります。
コメントの行や変数の行は出ません。
欄に収まらない長い行は、末尾を「…」で切って出します。欄に文字を打つと、その文字を含む行だけに絞れます。

### ほかの場所から登録する

次の場所の右クリックのメニューにある**ホットバーに入れる**からも、登録できます。

- エフェクト集のエフェクト
- チャットパレットの行
- FABメニューの項目（小窓の中の項目も）

登録した操作は、空いている枠に自動で入ります。
バーをしまっていれば、バーも出てきます。

## 3. 呼び出す

| したいこと           | 操作                                                    |
| -------------------- | ------------------------------------------------------- |
| 枠を動かす           | `1`〜`0`を押す。または枠を押す                          |
| ページを変える       | `Shift`＋数字。または`[`・`]`。または上のページのボタン |
| 枠を空にする         | `Ctrl`＋クリック（Macでは`⌘`＋クリック）                |
| 枠の場所を入れ替える | 枠を別の枠へドラッグする                                |
| 枠の設定を開く       | 枠を右クリックして**編集**を押す                        |

チャットの入力欄などに文字を打っているあいだは、数字キーはそのまま文字として入ります。
バーが横取りすることはありません。

動かせなかったときは、枠が赤く光り、理由がバーの上に数秒出ます（→ [うまくいかないとき](#うまくいかないとき)）。

### ダイスボットの決まりかた

ダイスを振る枠が、どのダイスボットで振るかは、コマに近いほうから決まります。

| 順  | どこの設定か                                                    | 使われるとき                   |
| --- | --------------------------------------------------------------- | ------------------------------ |
| 1   | 枠そのもの                                                      | 枠にダイスボットを選んだとき   |
| 2   | そのコマの[チャットパレット](/manual/chat-palette)              | パレットで系統を選んでいるとき |
| 3   | [部屋設定](/manual/room-settings)の**一般**の既定のダイスボット | 部屋で系統を選んでいるとき     |
| 4   | チャットウィンドウでいま選んでいるもの                          | 上のどれも選ばれていないとき   |

「DiceBot」は、選んでいないものとして扱います。
パレットも部屋の既定も、作ったときには`DiceBot`が入っています。
これを選んだものとして数えると、その先の設定がいつまでも使われなくなるためです。

たとえば、キャラクターを取り込むと、そのコマのパレットにはゲームシステムの系統が入ります。
チャットウィンドウを別の系統にしていても、そのコマの枠は、パレットの系統で振ります。
逆に、パレットを既定のままにしてあるコマは、部屋やチャットの選択に従います。

## 枠の種別 {#kinds}

| 種別                                 | 内容                                                       | 備考                                                                                                                                              |
| ------------------------------------ | ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| チャット／ダイス                     | 送る文字                                                   | ダイス（`2d6+3`）・リソース操作（`:HP-5`）・バフ（`&!毒/継続/3`）・エフェクト（`《炎》`）もそのまま書けます                                       |
| エフェクト                           | テーブルのエフェクト                                       | **動作**で、**発動**・**設置**・**自分だけ**を選べます。**設置**は、もう一度押すと片付きます                                                      |
| 範囲を置く／消す                     | 射程の形                                                   | 名前・大きさ・長さ・幅・色・不透明度・塗り方まで、枠が持ちます。もう一度押すと、その枠が置いた範囲を消します                                      |
| 所持ダイスを出す／しまう             | なし                                                       | キャラクターが持っているダイスをテーブルに出します。出ているときは、もう一度押すとシートに戻します                                                |
| 所持ダイスを振り直す                 | なし                                                       | キャラクターがテーブルに出している所持ダイスを、まとめて振り直します。シートにしまってあるダイスは振りません                                      |
| パネルを開く                         | チャットパレット・キャラクターシート・リモートコントローラ | もう一度押すと閉じます                                                                                                                            |
| メニューの項目                       | FABメニューやツールバーの項目                              | メニューでその項目を押したのと同じことが起きます。いまのロールで使えない項目は、押しても動きません                                                |
| コマへ視点を移す                     | なし                                                       | そのキャラクターのコマへ視点を寄せます                                                                                                            |
| ダンジョンドリィマスターモード／戻る | なし                                                       | そのキャラクターの目線で[ダンジョンドリィマスターモード](/manual/dungeondry-master)に入ります。そのコマで見ているときに押すと、テーブルに戻ります |
| 効果音                               | テーブルの音                                               | **自分の画面だけで鳴らす**も選べます                                                                                                              |
| カットイン                           | テーブルのカットイン                                       | **音だけ再生**も選べます                                                                                                                          |
| シーン                               | 部屋の[シーン](/manual/scene)                              | GMだけが使えます。**BGMを変えずに反映**も選べます                                                                                                 |
| 見た目を変える                       | コマ画像・立ち絵・大きさ                                   | 空欄の項目はそのままです。画像はキャラクターが持つ画像の番号（1から数える）、大きさはマス数です。立ち絵は自分の画面だけに効きます                 |
| チャット欄に下書きする               | 文字                                                       | 入力欄に文字を置くだけで、送りません。長い呪文や定型文の下書きに使います                                                                          |
| 行動順                               | **次へ**・**前へ**・**リセット**                           |                                                                                                                                                   |
| マルチアクション                     | ほかの枠をいくつか                                         | 選んだ順に動かします。順番と間隔は枠ごとに決められます                                                                                            |

### マルチアクション

効果音、エフェクト、攻撃の判定のような開幕の流れを、1回押すだけで続けて動かすための枠です。
ほかのマルチアクションの枠は選べません。

1. **順に撃つ枠**で、続けて動かしたい枠にチェックを入れます。
2. チェックを入れた枠は、下の**実行順と間隔**に並びます。**上へ**・**下へ**で順番を入れ替えます。
3. 各行の**間隔**に、その1つ前からの待ち時間をミリ秒で入れます。

1つ目は押すとすぐに動くので、待ち時間はありません（「すぐ」と出ます）。
あとから足した枠の待ち時間は、300ミリ秒から始まります。
**外す**で、列から外せます。
前の版の「まとめて1つの間隔」で作った枠は、その値が2つ目からの待ち時間として入ります。

### エフェクトの枠

**エフェクト**の枠の**内容**は、テーブルのエフェクトを印と名前で並べた一覧です。
印は、[エフェクト集](/manual/map-effects)の一覧と同じく、エフェクトの形をその色で描いたものです。
押したものが縁取られ、その枠の内容になります。
枠が覚えるのはエフェクトの名前なので、前から使っている枠も、保存しておいたバーも、そのまま動きます。

**設置**を選んだ枠は、範囲と同じく、押すたびに置く・片付けるを繰り返します。
押すとコマの足元にエフェクトを置き、もう一度押すと、その枠が置いたものを片付けます。
片付くのは、自分のその枠が置いたものだけです。
同じエフェクトを別の枠や別のコマから置いていても、巻き込みません。

**ターゲットを無視して自分に**は、**発動**のエフェクトだけの設定です。
誰かをターゲットにしたままでも、その枠は必ず自分のコマに出ます。
防御や強化の演出を、狙っている相手に飛ばさずに済みます。

## 「誰として」のキャラクターの探しかた

枠は、指定したキャラクターを、内部の識別子と名前の両方で覚えます。
識別子で見つからないときは、自分が動かせるコマの中に同じ名前がちょうど1体だけあれば、それを使い、以後はその新しいコマを指します。
同じ名前が2体いるときは、追いかけません。

部屋を読み込み直したときや、別の卓に同じ名前のキャラクターを用意したときに役立ちます。
カットインも、同じように名前で探し直します。
効果音は、音源そのものから識別子が決まるので、同じ音が入っている卓なら、そのまま鳴ります。

## バーの保存と読み込み

バーは自分のもので、ほかの参加者の画面には出ず、部屋の保存ファイルにも入りません。
ゲームシステムやキャラクターが変われば別のバーを使うことになるので、卓ごとに1本ずつ、ファイルにして持っておけます。

| したいこと     | 操作                                                                                               |
| -------------- | -------------------------------------------------------------------------------------------------- |
| 保存する       | バーの右端の保存のアイコンを押します。`hotbar_ルーム名_日時.zip`がダウンロードされます             |
| 読み込む       | バーを右クリックして**ホットバーを読み込む**を押します。ファイルをテーブルにドロップしても同じです |
| 読み込みを戻す | 右クリックの**読み込む前のバーに戻す**を押します（ページを開いているあいだだけ）                   |

読み込むと、いまのバーは入れ替わります。

## 固定と見た目

右端の鍵のアイコンを押すと、**位置を固定**します。
固定しているあいだは、ドラッグで動きません。

右クリックのメニューで、次を切り替えます。

| 項目                       | 内容                                                                                   |
| -------------------------- | -------------------------------------------------------------------------------------- |
| ラベルを表示               | 枠のアイコンの下に名前を出す                                                           |
| ショートカットの説明を表示 | バーの上の小さな説明（スマートフォンでは自動で隠れます）                               |
| 最前面に固定               | ほかのパネルより手前に出す。固定していても、バー自身のメニューはバーより手前に開きます |
| 位置をリセット             | 画面の下の中央に戻す                                                                   |
| ホットバーを隠す           | バーをしまう                                                                           |

枠を右クリックすると、**コピー**・**貼り付け**・**空にする**も出ます。
空にした枠は、**消したスロットを戻す**で戻せます。

## うまくいかないとき

| 見えるもの                             | 原因と直しかた                                                                                                                                 |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 「操作対象のキャラクターがいません」   | 「誰として」動くかが決まっていません。枠の設定で**誰として**を選ぶか、チャットの発言者を決めます。枠が薄く出ているときも同じです               |
| 「登録されているものが見つかりません」 | 枠に入れたエフェクト・効果音・カットインが、いまの卓にありません。卓に足すか、枠の内容を選び直します                                           |
| 「コマが卓上にありません」             | 「誰として」のキャラクターが、テーブルに置かれていません。テーブルに出してから押します                                                         |
| 「チャットタブがありません」           | 送り先のチャットタブがありません。チャットウィンドウでタブを作ります                                                                           |
| 「今の役割では使えない項目です」       | メニューの項目の枠で、いまのロールでは使えない項目を選んでいます                                                                               |
| 「この枠には何も入っていません」       | 空の枠です。枠を押して登録します                                                                                                               |
| 読み込み直したら、バーが空になった     | バーは部屋のデータとして同期されるので、同じ部屋にほかの参加者がいれば戻ります。一人で使っているときは、保存しておいたファイルから読み込みます |
| 範囲が消えない                         | 枠で消せるのは、その枠が置いた範囲だけです。ほかの方法で置いた範囲は、右クリックの**削除**で消します                                           |
| 数字キーを押しても動かない             | 入力欄に文字を打っているあいだは、数字は文字として入ります。テーブルの何もない所を一度押してから押します                                       |

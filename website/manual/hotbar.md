# ホットバー

よく使う操作を枠に入れておき、数字キーひとつで撃つための盤面上のバーです。攻撃のマクロ、開幕の効果音、射程の設置——卓の最中に何度も繰り返すものを、パネルを開かずに手元へ置けます。

初めて使うときは「出す」から「撃つ」までを順に読んでください。種別ごとの細かい設定は必要になったときに引けば足ります。

## 出す — PL ツールバーの格子アイコン

PL ツールバー（GM のときは GM ツールバー）の **格子のアイコン（apps）** を押すと、画面下にバーが出ます。もう一度押すとしまいます。見学のロールでは出ません。

バーは 10 枠 × 5 ページ。10 枠は数字キーの `1`〜`0` とそのまま対応します。ドラッグで好きな位置へ動かせます。

## 枠に登録する — 空き枠を押す

破線の空き枠を押すと、その枠の設定パネルがすぐ隣に開きます。上から **種別 → その種別の設定 → 誰として → ラベル・アイコン・色** の順で、必要なところだけ埋めれば足ります。

- **種別** — 何をする枠か（下の一覧）
- **誰として** — その枠がどのキャラクターとして動くか。未指定ならチャットの発言者になります
- **ラベル** — 空ならば内容から自動で付きます
- **試す** — 保存せずにその場で撃って確かめられます

チャット／ダイスの枠には **パレットから** という欄が出ます。そのキャラクターのチャットパレットに書いてある行が、見出しごとにまとまって並ぶので、選べばそのまま枠の内容になります。コメント行や変数行は出ません。

エフェクトライブラリの右クリックメニューと、チャットパレットの行の右クリックからも **「ホットバーに入れる」** で登録できます。空いている枠を自分で探して入り、バーがしまってあれば出てきます。

## 撃つ — 数字キー、または枠を押す

| したいこと           | 操作                                              |
| -------------------- | ------------------------------------------------- |
| 枠を撃つ             | `1`〜`0`、または枠をクリック                      |
| ページを変える       | `Shift` ＋ 数字、または `[` `]`、上のページボタン |
| 枠を空にする         | `Ctrl` ＋ クリック（macOS は `⌘` ＋ クリック）    |
| 枠の場所を入れ替える | 枠を別の枠へドラッグ                              |
| 枠の設定を開く       | 枠を右クリック → 編集                             |

チャット入力欄などに文字を打っている間、数字キーはそのまま文字として入ります。バーが横取りすることはありません。

撃てなかったときは枠が赤く光り、理由がバーの上に数秒出ます。「登録されているものが見つかりません」ならエフェクトやカットインが今の卓に無く、「操作対象のキャラクターがいません」なら誰として撃つかが決まっていない状態です。

ダイスを振る枠は、**チャットウィンドウで選んでいるダイスボット**で振ります。卓のシステムを切り替えれば、ホットバーの枠も一緒に切り替わります。

## 枠の種別 — 何を入れられるか

| 種別                     | 内容                                 | 備考                                                                                             |
| ------------------------ | ------------------------------------ | ------------------------------------------------------------------------------------------------ |
| チャット／ダイス         | 送る文字列                           | ダイス（`2d6+3`）・リソース操作（`:HP-5`）・バフ（`&!毒/継続/3`）もそのまま書けます              |
| エフェクト               | 卓のエフェクト名                     | 発動・場に置く・プレビューを選べます。**場に置く**はもう一度押すと片付きます                     |
| 範囲を置く／消す         | 射程の形                             | 名前・長さ・幅・色・不透明度・塗り方まで枠が持ちます。もう一度押すとその枠が置いた範囲を消します |
| 所持ダイスを出す／しまう | —                                    | 卓上に出ていれば、もう一度押すとシートに戻します                                                 |
| パネルを開く             | チャットパレット / シート / リモコン | もう一度押すと閉じます                                                                           |
| コマへ視点を移す         | —                                    |                                                                                                  |
| 効果音                   | 卓の音                               | 自分の画面だけで鳴らすこともできます                                                             |
| カットイン               | 卓のカットイン                       | 音だけ再生も選べます                                                                             |
| 見た目を変える           | コマ画像・立ち絵・大きさの番号       | 空欄の項目はそのまま。マルチアクションでエフェクトと並べると変身の演出になります                 |
| チャット欄に下書きする   | 文字列                               | 送信はしません。長い呪文や定型文に                                                               |
| 行動順                   | 進める / 戻す / リセット             |                                                                                                  |
| まとめて撃つ             | 他の枠をいくつか                     | 並べた順に撃ちます。**順番と間隔は枠ごとに決められます**                                         |

**マルチアクション** の枠は、ほかのマルチアクションを選べません。効果音 → エフェクト → 攻撃ロールのような開幕を 1 押しにするための枠です。

チェックを入れた枠は下の一覧に並び、そこで**上へ／下へで順番を入れ替え**、**その 1 つ前からの待ち時間**を
ミリ秒で決められます。1 つ目は押した瞬間に走るので待ち時間はありません（後から足した枠は 300ms が初期値）。
✕ で列から外せます。以前の「まとめて 1 つの間隔」で作った枠は、その値が 2 つ目以降の待ち時間として入ります。

**場に置く**を選んだ枠は、範囲と同じトグルです。押すとコマの足元にエフェクトを置き、もう一度押すと
その枠が置いたものを片付けます。片付くのは自分のその枠が置いたものだけなので、同じエフェクトを
別の枠や別のコマから置いていても巻き込みません。

**ターゲットを無視して自分に**は、発動モードのエフェクトだけの設定です。誰かをターゲットしたままでも、
その枠は必ず自分のコマに出ます。防御や強化の演出を、狙っている相手に飛ばさずに済みます。

## 「誰として」は名前でも追いかける

枠は、指定したキャラクターを識別子と名前の両方で覚えます。識別子で見つからないときは、自分が動かせるコマの中に**同じ名前がちょうど 1 体だけ**あればそれを採り、以後はその新しいコマを指します。同名が 2 体いるときは追いかけません。

ルームを読み込み直したり、別の卓に同じ名前のキャラクターを用意したときに効きます。カットインも同じように名前で探し直します。効果音は音源そのものから識別子が決まるので、同じ音が入っている卓ならそのまま鳴ります。

## バーはファイルで持ち歩く

バーは**自分のもの**で、他の参加者には見えず、ルームの保存ファイルにも入りません。システムやキャラクターが変われば別のバーを使うことになるので、卓ごとに 1 本ずつファイルにして持っておけます。

- **保存** — バー右端の保存アイコン。`hotbar_ルーム名_日時.zip` が落ちます
- **読み込み** — バーを右クリック → **ホットバーを読み込む**。ファイルを卓にドロップしても同じです
- 読み込むと**今のバーは入れ替わります**。間違えたときは右クリック → **読み込む前のバーに戻す**（ページを開いているあいだ有効）

## 固定・見た目

右端の鍵アイコンで**位置を固定**します。固定中はドラッグで動きません。

右クリックのメニューでは次を切り替えられます。

- **ラベルを表示** — 枠のアイコンの下に名前を出す
- **ショートカットの説明を表示** — バーの上の小さな説明文（スマートフォンでは自動で隠れます）
- **最前面に固定** — モーダルより手前に出します。ピン留め中でも、バー自身のメニューはバーより手前に開きます
- **位置をリセット** — 画面下中央に戻します

## 困ったとき

**枠を押しても何も起きない** — 枠が薄く表示されていれば、その枠は「誰として」動くかが決まっていません。枠の設定でキャラクターを指定するか、チャットの発言者を設定してください。

**リロードしたら空になった** — バーはルームのデータとして同期されるので、同じルームに他の参加者がいれば戻ります。一人で使っているときは、保存しておいたファイルから読み込んでください。

**範囲が消えない** — 消せるのは、その枠が置いた範囲だけです。ほかの手段で置いた範囲は右クリック → 削除で消します。

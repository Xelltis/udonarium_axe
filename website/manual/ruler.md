# 物差し

このページは卓の上の2点のあいだを測る「物差し」を説明します。高さの違う点のあいだも直線の距離・水平の距離・高さの差で測れます。
物差しを使えるのはGMとPLです。

## 物差しを持つ

[PLツールバー](/manual/pl-tools)かGMツールバーの**物差し**を押すと、物差しを持ちます。卓で`M`キーを押しても持てます。もう一度押すか`Esc`を押すと、しまいます。

コマの右クリックの**視界と視点**から**ここから測る**を選ぶと、そのコマから測り始めます。先の端はマウスについて動き、クリックした所で決まります。

## 測る

物差しを持っているあいだは、卓をドラッグすると、押した所から離した所までを測ります。コマを押しても、コマを選んだり動かしたりはしません。

コマの上から引いた端はそのコマの足元の中心につながり、コマの高度も測る高さに入ります。つながったコマが動くと、測り直します。

卓の上の端はマスの中心に寄ります。`Alt`を押しているあいだと、[テーブル設定](/manual/table-setting)のスナップがなしのテーブルでは寄せません。引いているあいだにホイールを回すと、先の端が1マスずつ上下します。タッチの画面では、画面の下の帯の↑と↓で同じことができます。

## 読み

線の真ん中の上と、画面の下の帯に、次の数字が出ます。

| 読み   | 内容                                                                                                                        |
| ------ | --------------------------------------------------------------------------------------------------------------------------- |
| 直線   | 2点を結ぶ距離                                                                                                               |
| 水平   | 高さを除いた距離                                                                                                            |
| 高さ   | 先の端が始めの端より高い分。低ければマイナスです                                                                            |
| マス数 | 部屋設定の**斜め移動**の数え方で数えたマス数。高さの1マスも、斜めと同じ決まりで数えます。グリッドなしのテーブルでは出ません |

直線・水平・高さは、ふだんはマスで出ます。[部屋設定](/manual/room-settings#移動範囲とzoc)の**マスの単位**をメートルかフィートにすると、3つとも**1マスの距離**から求めた長さで出ます。マスの単位がメートルで1マスの距離が1.5なら、5マスの直線は「直線 7.5m」と出ます。マス数は単位を変えてもマスで数えます。**マスの単位**は、移動範囲の[単位の換算](/manual/move-range#単位の換算)にも使われます。

[テーブル設定](/manual/table-setting)の**移動と射程の1マス**を2×2以上にしたテーブルでは、まとめたマスを1マスとして数えます。

## ほかの人にも見える

引いている物差しは同じテーブルを見ているほかの人にも見えます。ほかの人の画面では、引いている人の名前が付き、自分の物差しとは別の色で出ます。離したあとも、画面の下の帯を閉じるまで残ります。

端のどちらかが自分から見えないコマにつながっているか、霧で隠れた場所にある物差しは、自分には見えません。

## 卓に置く

画面の下の帯の**置く**を押すと、その物差しを卓に置いて残せます。置いた物差しはそのテーブルを見ている全員に見え、部屋の保存にも入ります。見えない端を持つ物差しが見えないのは、引いているときと同じです。コマにつながった端は、コマが動くと付いていきます。

端にマウスを載せると、丸が出ます。丸をドラッグするとその端を置き直せ、ドラッグしているあいだにホイールを回すと、その端が1マスずつ上下します。線をドラッグすると両端ごと動き、コマとのつなぎは外れます。右クリックすると、**固定する**・**コマとのつなぎを外す**・**コピーを作る**・**削除する**を選べます。

## うまくいかないとき

| 見えるもの                       | 原因と直しかた                                                                                                     |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `M`を押しても物差しを持てない    | 文字を入力している欄にカーソルがあります。卓の何もない場所をクリックしてから押します。見学では使えません           |
| 卓をドラッグしても、卓が動かない | 物差しを持っています。`Esc`でしまうと、卓をドラッグで動かせます                                                    |
| ほかの人の物差しが見えない       | 端が自分から見えないコマにつながっているか、霧で隠れた場所にあります。その人が別のテーブルを見ていることもあります |
| マス数が出ない                   | グリッドなしのテーブルです                                                                                         |
| 長さがメートルやフィートで出ない | 部屋設定の**マスの単位**がマスか、**1マスの距離**が0です                                                           |

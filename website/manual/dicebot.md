# ダイスボット

このページは、チャット欄にコマンドを打ってダイスを振る「ダイスボット」と、自作のダイス表を説明します。
ダイスを振るのは[BCDice](https://github.com/bcdice/BCDice)で、ゲームシステムを選ぶと、そのシステムの判定や表のコマンドも使えます。
チャットで発言できる人なら誰でも振れます。

## 基本コマンド

| 書きかた    | 振りかた                     |
| ----------- | ---------------------------- |
| `2d6`       | 6面ダイスを2個振ります       |
| `1d100<=50` | 目標値以下なら成功の判定です |
| `(2d6+3)*2` | 四則演算も書けます           |

コマンドの前に`s`を付けると、結果を伏せたシークレットダイスになります（→ [チャットの特殊記法](/manual/chat-syntax)）。

## ゲームシステムを選ぶ

1. チャット入力欄の上の、ゲームシステムの選択（はじめは「DiceBot」）を押します。
2. 遊ぶゲームシステムを選びます。名前を打つと絞り込めます。

そのシステムの判定式や表のコマンドが使えるようになります。
選択の横の **?** を押すと、そのシステムのコマンドの説明が出ます。
既定は、ゲームシステムを選んでいない汎用の「DiceBot」です。部屋に入った人が最初にどれを選んだ状態にするかは、[部屋設定](/manual/room-settings#既定のダイスボット)で決めます。

## ダイス表

自分で作ったランダム表を登録して、コマンドで呼び出せます。

1. チャットウィンドウの右上の歯車（チャット設定）を押し、**ダイス表設定**を押します。
2. **新しい表を作る**を押します。
3. **表タイトル**・**ダイス**（例：`1d6`）・**コマンド**を決めます。
4. 表の中身を、`出目:結果`の形で1行ずつ書きます（例：`1:森`）。
5. **保存**を押します。

チャットに**コマンド**に決めた文字を打って送ると、**ダイス**を振って、出た目の行が返ります。
作ったばかりの表には、6行の入力例が入っています。

## 卓上のダイスと連動させる

コマンドに`dice:コマ名`を書き添えると、振った出目がそのコマの持っている卓上のダイスに反映されます。記法は[チャットの特殊記法](/manual/chat-syntax#卓上ダイスと連動)にあります。

## 部屋のサーバーで振るダイス

[部屋のサーバー（ベータ）](/guide/choose)を使う配置先では、チャットのダイスは部屋のサーバーがBCDiceで振ります。
振った人のブラウザでは振らないので、出目を書き換えて送ることはできません。
サーバーが振った結果には、名前の横に盾の印が付きます。

ダイス表とリソースの操作は、これまでどおり振った人のブラウザで処理します。
4000字を超える行は部屋のサーバーが受け付けないので、振った人のブラウザで振ります。この結果に盾の印は付きません。
[リプレイの盤面](/manual/replay)を映している間に振ったダイスも、部屋のサーバーには届かないので、ブラウザで振ります。
保存データを読み込んだ部屋や、削除して「元に戻す」で戻したタブでは、サーバーが振った結果も盾の印が外れて、ふつうの発言になります。

サーバーが振らなかったときや、1分たっても結果が届かないときは、その発言をしたタブに理由が出ます。知らせは振った人の画面にだけ出ます。
見学者が発言できないタブで振ったときだけは、そのタブに書けないので、理由が画面の下に出ます。
ダイスのコマンドでない行は、ブラウザで振ったときと同じく何も出ません。

対象をいくつも選んで振ると、対象ごとに1回ずつ頼みます。サーバーが受け付けるのは1人につき10秒に20回までなので、それを超える分は少し待ってから順に頼みます。
接続が切れてつなぎ直したときや、同じ部屋に入り直したとき（「再接続」・ログイン・ロビーから）は、結果の届いていないダイスをもう一度頼みます。サーバーは同じダイスを2回振りません。

テーブルに置いて振るダイスは、[ダイス](/manual/dice)にあります。

## うまくいかないとき

| 見えるもの                                 | 原因と直しかた                                                                                                                               |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| コマンドを送っても、ダイスが振られない     | ゲームシステムのコマンドが、いまのシステムで使えません。ゲームシステムの選択を確かめます。ダイスのコマンドでない行は、ふつうの発言になります |
| ゲームシステムが、部屋に入るたびに戻る     | 部屋の**既定のダイスボット**が選ばれます。GMが[部屋設定](/manual/room-settings#既定のダイスボット)で変えます                                 |
| ダイス表のコマンドで、表が返らない         | コマンドの文字が違うか、表の行が`出目:結果`の形になっていません                                                                              |
| 部屋のサーバーで、ダイスの理由がタブに出る | サーバーが振らなかったか、1分たっても結果が届きませんでした。理由を読んで振り直します                                                        |

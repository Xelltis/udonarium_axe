# ダイス

テーブル上にダイスシンボルを置いて振ったり、チャットからダイスボットを呼び出したりできます。

<Shot src="dice" alt="テーブルに置かれた D6・D10・D20 のダイス" caption="振ると出目が卓上に浮かび、結果はチャットにも流れます" />

## ダイスシンボルを置く

テーブルの何もない場所を右クリックし、「ダイスを作成」から種類を選びます。

- D4 / D6 / D8 / D10 / D12 / D20 などに対応
- **まとめて置く** — 種類の一覧の最後にある **個数を指定して作成…** で、種類と個数を選んで一度に置けます。5 個ごとに折り返して並ぶので、重なりをほどく手間もありません
- **持ち主と伏せるかも、その場で決められます** — 同じダイアログで **所有者**（どのコマの持ち物にするか。`dice:コマ名` の連動や「コマにしまう」がすぐ効きます）と **自分だけ見る**（伏せて置く）を選べます。どちらも既定は「なし」「全員に見える」です
- 置いたダイスはドラッグで移動でき、振った出目は参加者間で共有されます
- 名前・所有者のラベルはカメラの向きに追従します

## 振った結果は読んでいるタブに残る

ダイスをダブルクリックするか、右クリックの **ダイスを振る** を選びます。ダイスは卓の上を転がって止まり、出た面が大きく浮かび上がって消えます。結果はチャットにも流れます。行き先は**そのとき開いているタブ**です。卓上で振っただけの目も、後から読み返せます。

複数のダイスを選んでから右クリックすると、**ダイス（個数）個をまとめて振る** が出ます。選んだぶんが同時に回り、結果は 1 行にまとまります。面がすべて数字なら、合計も添えます。

```
わたし が ダイス3個を振りました → 3, 5, 18（合計 26）
```

他の人が「自分だけ見る」にしたダイスは、まとめて振っても回りません。振らなかったダイスの数は、振った本人にだけ伝わります。

## 自分だけ見るダイスは、名前も出目も隠れる

ダイスを右クリックして **自分だけ見る** を選ぶと、他の人の画面からはラベルごと消えます。読めるのは自分と GM だけです。振った結果はチャットに「（シークレットダイス）」としてだけ流れます。**ダイスを公開** で開くと、最後に振ったときの行がその場で開き、チャットの末尾に並びます。それより前に振った目は伏せたままです。

ただし、この秘匿はブラウザの表示のうえでのものです。出目そのものは参加者全員に配られているので、開発者ツールを開けば読めてしまいます。不正をしない相手への目隠しと考えてください。

## コマに預けて、必要なときだけ盤に出す

ダイスは**キャラクターシートに預けられます**。預けたダイスは面の絵柄と個数がシートに残り、部屋の保存にもキャラクターの持ち出しにも一緒に付いていきます。

- **預ける** — 盤上のダイスを右クリックし、**コマにしまう** を選びます（持ち主を決めたダイスにだけ出ます）。盤からダイスは消え、持ち主のシートの「所持ダイス」に加わります。同じ名前のダイスは個数が増えるだけです
- **まとめて預ける** — 複数のダイスを選んで右クリックし、**ダイス（個数）個をコマにしまう** から預け先のコマを選びます。持ち主を決めていないダイスも、ここでまとめて預けられます
- **出目も残る** — しまったときに出ていた面を 1 個ずつ覚えていて、展開するとその目のまま並びます。場を片付けて次の日に開いても、置いていったとおりです
- **出す** — キャラクターを右クリックし、**ダイスを展開する（3個）** を選ぶと、預けたぶんがコマの隣に並びます。並んだダイスは最初からそのコマの持ち物なので、`dice:コマ名` の連動もそのまま効きます
- **1 個のダイスは 1 か所にだけ** — 展開したダイスはシートから減ります。盤に出ているあいだは「所持ダイス」に残らないので、続けて押しても増えません。戻すときは **コマにしまう** です
- **中身を見る・直す** — 詳細画面の「所持ダイス」に、ダイス 1 種類が 1 行の表として出ます。行には個数・出目・面ごとの絵柄が並び、その場で書き換えられます。絵柄はキャラクターの持ち出し（zip）にも一緒に入ります

## コマに持たせると、チャットのロールと連動する

ダイスを右クリックし、**コマに持たせる** から選びます。これで、そのダイスは選んだコマのものになります。「自分だけ見る」の所有者とは別物です。公開したまま誰かのダイスにできますし、外すときは同じメニューの **持ち主を外す** を選びます。

持たせたあとは、チャットのコマンドに `dice:コマ名` を書き添えます。

```
2d6 dice:ゴブリンA
```

ダイスボットが `2d6` を振ります。出た 3 と 5 が、そのままゴブリンAのダイス 2 個の面になります。埋まるのは面の数が合うダイスからで、余った出目は捨てます。その目を出せないダイス（10 の位しか持たない D10 に 3 が来た場合など）は動きません。

コマが喋っている行なら `dice:` だけでも構いません。発言者のダイスが対象になります。

## ダイスシンボルシート

ダイスシンボルは、面ごとに画像を割り当てた**シート**として設定・保存・複製できます。
オリジナルの目（アイコンや記号など）を使ったダイスを用意したいときに利用します。

## コイン

表か裏かだけを決めたいときは、ダイスの代わりにコインを使えます。

テーブルの何もない場所を右クリックして **コインを作成** を選ぶと、その位置に金色のコインが置かれます。

- **投げる** — コインを**ダブルクリック**するか、右クリックの **コインを投げる** を選びます。コインが浮き上がって 5 回転し、着地した面が結果です
- **結果はチャットへ** — 「（誰が）コインを投げました → 表」がシステムメッセージとして流れます。アニメーションは参加者全員の画面で同時に再生されるので、後から出目を書き換えたように見えることはありません
- **面を決め打つ** — 右クリックの **表にする** / **裏にする** で、投げずに向きだけ変えられます
- **絵柄を変える** — 右クリックの **コインを編集** でシートが開きます。表面・裏面それぞれに画像を割り当てられ、**画像を外す**と金色のコインに戻ります。名前と大きさもここで変えられます

コインはテーブルのオブジェクトなので、ドラッグで動かしたり、固定・コピー・削除したり、[部屋の保存](/manual/save-load)に含めたりできます。

## チャットでダイスを振る

チャット欄にコマンド（例: `2d6`）を打ち込んで振る方法は、[ダイスボット](/manual/dicebot) を参照してください。

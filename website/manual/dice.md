# ダイス

テーブル上にダイスシンボルを置いて振ったり、チャットからダイスボットを呼び出したりできます。

<Shot src="dice" alt="テーブルに置かれたD6・D10・D20のダイス" caption="振ると出目が卓上に浮かび、結果はチャットにも流れます" />

## ダイスシンボルを置く

テーブルの何もない場所を右クリックし、「ダイスを作成」から種類を選びます。

- D4 / D6 / D8 / D10 / D12 / D20などに対応
- **まとめて置く** — 種類の一覧の最後にある**個数を指定して作成…** で、種類と個数を選んで一度に置けます。5個ごとに折り返して並ぶので、重なりをほどく手間もありません
- **持ち主と伏せるかも、その場で決められます** — 同じダイアログで**所有者**（どのコマの持ち物にするか。`dice:コマ名`の連動や「コマにしまう」がすぐ使えます）と**自分だけ見る**（伏せて置く）を選べます。どちらも既定は「なし」「全員に見える」です
- 置いたダイスはドラッグで移動でき、振った出目は参加者間で共有されます
- 名前・所有者のラベルはカメラの向きに追従します

## 振った結果は読んでいるタブに残る

ダイスをダブルクリックするか、右クリックの**ダイスを振る**を選びます。ダイスは卓の上を転がって止まり、出た面が大きく浮かび上がって消えます。結果はチャットにも流れます。行き先は**そのとき開いているタブ**です。卓上で振っただけの目も、後から読み返せます。

複数のダイスを選んでから右クリックすると、**ダイス（個数）個をまとめて振る**が出ます。選んだぶんが同時に回り、結果は1行にまとまります。面がすべて数字なら、合計も添えます。

```
わたし が ダイス3個を振りました → 3, 5, 18（合計 26）
```

他の人が「自分だけ見る」にしたダイスは、まとめて振っても回りません。振らなかったダイスの数は、振った本人にだけ伝わります。

## 自分だけ見るダイスは、名前も出目も隠れる

ダイスを右クリックして**自分だけ見る**を選ぶと、他の人の画面からはラベルごと消えます。読めるのは自分とGMだけです。振った結果はチャットに「（シークレットダイス）」としてだけ流れます。**ダイスを公開**を選ぶと、最後に振ったときのシークレットの行が公開され、チャットの末尾へ移ります。それより前に振った目は伏せたままです。

ただし、この秘匿はブラウザの表示のうえでのものです。出目そのものは参加者全員に配られているので、開発者ツールを開けば読めてしまいます。不正をしない相手への目隠しと考えてください。

## コマに預けて、必要なときだけ盤に出す

ダイスは**キャラクターシートに預けられます**。預けたダイスは面の絵柄と個数がシートに残り、部屋の保存にもキャラクターの持ち出しにも一緒に付いていきます。

- **預ける** — 盤上のダイスを右クリックし、**コマにしまう**を選びます（持ち主を決めたダイスにだけ出ます）。盤からダイスは消え、持ち主のシートの「所持ダイス」に加わります。同じ名前のダイスは個数が増えるだけです
- **まとめて預ける** — 複数のダイスを選んで右クリックし、**ダイス（個数）個をコマにしまう**から預け先のコマを選びます。持ち主を決めていないダイスも、ここでまとめて預けられます
- **出目も残る** — しまったときに出ていた面を1個ずつ覚えていて、展開するとその目のまま並びます。場を片付けて次の日に開いても、置いていったとおりです
- **出す** — キャラクターを右クリックし、**ダイスを展開する（3個）** を選ぶと、預けたぶんがコマの隣に並びます。並んだダイスは最初からそのコマの持ち物なので、`dice:コマ名`の連動もそのまま使えます
- **1個のダイスは1か所にだけ** — 展開したダイスはシートから減ります。盤に出ているあいだは「所持ダイス」に残らないので、続けて押しても増えません。戻すときは**コマにしまう**です
- **中身を見る・直す** — 詳細画面の「所持ダイス」に、ダイス1種類が1行の表として出ます。行には個数・出目・面ごとの絵柄が並び、その場で書き換えられます。絵柄はキャラクターの持ち出し（zip）にも一緒に入ります

## コマに持たせると、チャットのロールと連動する

ダイスを右クリックし、**コマに持たせる**から選びます。これで、そのダイスは選んだコマのものになります。「自分だけ見る」の所有者とは別です。公開したまま誰かのダイスにできます。外すときは同じメニューの**持ち主を外す**を選びます。

持たせたあとは、チャットのコマンドに`dice:コマ名`を書き添えます。

```
2d6 dice:ゴブリンA
```

ダイスボットが`2d6`を振ります。出た3と5が、そのままゴブリンAのダイス2個の面になります。埋まるのは面の数が合うダイスからで、余った出目は捨てます。その目を出せないダイス（10の位しか持たないD10に3が来た場合など）は動きません。

コマが喋っている行なら`dice:`だけでも構いません。発言者のダイスが対象になります。

## ダイスシンボルシート

ダイスシンボルは、面ごとに画像を割り当てた**シート**として設定・保存・複製できます。
オリジナルの目（アイコンや記号など）を使ったダイスを用意したいときに利用します。

## コイン

表か裏かだけを決めたいときは、ダイスの代わりにコインを使えます。

テーブルの何もない場所を右クリックして**コインを作成**を選ぶと、その位置に金色のコインが置かれます。

- **投げる** — コインを**ダブルクリック**するか、右クリックの**コインを投げる**を選びます。コインが浮き上がって5回転し、着地した面が結果です
- **結果はチャットへ** — 「（誰が）コインを投げました → 表」がシステムメッセージとして流れます。アニメーションは参加者全員の画面で同時に再生されるので、後から出目を書き換えたように見えることはありません
- **面を決め打つ** — 右クリックの**表にする** / **裏にする**で、投げずに向きだけ変えられます
- **絵柄を変える** — 右クリックの**コインを編集**でシートが開きます。表面・裏面それぞれに画像を割り当てられ、**画像を外す**と金色のコインに戻ります。名前と大きさもここで変えられます

コインはテーブルのオブジェクトなので、ドラッグで動かしたり、固定・コピー・削除したり、[部屋の保存](/manual/save-load)に含めたりできます。

## チャットでダイスを振る

チャット欄にコマンド（例: `2d6`）を打ち込んで振る方法は、[ダイスボット](/manual/dicebot)を参照してください。

## チャットのロールを3Dのダイスで転がす {#roll-in-3d}

チャットで振ったダイスを、3Dで転がして見せられます。ダイスは、ダイスボットが出した目のとおりの面で止まります。演出を決めるのはGMで、**部屋設定**の**一般**にある**ダイスの演出**から選びます。設定は部屋の全員に共通です。

- **出さない** — 既定です。前からある部屋も、選び直すまではこのままです
- **セリフの枠** — ダイスボットの答えの吹き出しの下に細長いトレイが開き、その中を転がります。[ノベルモード](/manual/visual-novel)のダイス結果の枠にも同じものが出ます
- **卓の上** — 振ったコマの手前に転がります。コマが卓に出ていないときや、そのコマが自分から見えないときは、画面の真ん中です。止まったダイスはしばらく残ってから消えます
- **両方** — セリフの枠と卓の上の両方で転がります。転がり方はそれぞれ違いますが、止まる目は同じです

<Shot src="dice-3d-frame" alt="ダイスボットの答えの吹き出しの下にトレイが開き、赤いD6 2個とD20が出目を上にして止まっている" caption="セリフの枠では、答えの吹き出しの下でダイスが転がります" />

<Shot src="dice-3d-table" alt="卓の上で、モンスターBの手前に赤いD6 2個とD20が止まっている" caption="卓の上では、振ったコマの手前にダイスが転がります" />

ダイスは画面の左から飛び込んで跳ね、上を向いた面の数字が読む人に向けて立つように止まります。卓を回していても同じです。

- **シークレットのロール**は、振った本人の画面でだけ転がります。GMの画面にも出ません
- **クリティカル**は金、**ファンブル**は赤の輪が、ダイスが止まると足元で光ります。光るのは、ダイスボットがクリティカルやファンブルと判定したロールだけです
- **転がる種類**はD4・D6・D8・D10・D12・D20です。D100は十の位と一の位のD10を2個、D3は1〜3を2回ずつ書いたD6で振ります。D2のようにそれ以外の面数は転がりません
- **[アニメーション](/manual/theme#animation)を止めている画面**では、セリフの枠に目を上にしたダイスが並ぶだけになり、卓の上には何も出ません

卓の上のダイスは、コマや壁よりも手前に重ねて描きます。コマの陰には隠れません。

### 51個以上は枠を分けて転がす

1つの枠に入るのは50個までです。それより多いロールは、枠をいくつかに分けて転がします。たとえば120個なら40個ずつ3枠です。50・50・20と詰めずに均等に割るのは、枠の広さが個数で決まり、少ない枠だけダイスが大きく映ってしまうからです。

枠は4つ、ダイスは200個までです。残りは最後の枠の隅に「+5」のように数だけ添えます。ダイスボットは1つの項で200個までしか振らないので、200個を超えるのは`150d6+100d6`のように項を分けたときです。

並び方は場所で変わります。

- **チャット欄**では、枠が縦に並びます
- **ノベルモード**では、2枠ずつ横に並べて画面に収め、吹き出しもその幅まで広がります
- **卓の上**では、振ったコマの手前に枠を横に並べます。盤の端では並び全体を内側に寄せます。最後の枠のダイスが止まってから、全部の枠がそろって消えます

### 同時に転がるのは6件まで

いくつものロールが続けて来たとき、同時に転がるのは6件までで、動いているダイスは合わせて400個までです。これを超えたロールは、転がさずに目を上にして並べます。ほかに何も転がっていなければ、200個のロールでも転がります。

描画を軽くしている画面では、動いているダイスは200個までです。描画はFABメニューの**表示**の小窓で切り替えます。自動のときは、Firefoxや性能の低い端末で軽くなります。

### 前の行にも、止まった姿で出る

その場で振られたロールは転がります。それより前の行には、目を上にしたダイスが並びます。部屋を読み込み直したとき、途中から入ったとき、ダイスの演出を「出さない」にしていたころに振った行も同じです。3Dダイスに対応していない古い版の人が振ったロールも、転がらずにこの形で出ます。

描くのは画面に見えている枠だけです。チャット欄を遡って行が見えたところで並べます。[リプレイ](/manual/replay)の再生中は出ません。

### 自分のダイスの見た目を選ぶ {#my-dice}

自分が振るダイスの材質と色を選べます。部屋がダイスを出す設定になっていると、チャット入力の**色設定**の隣にサイコロのボタンが出ます。押すと**マイダイス**のパネルが開きます。

- **材質** — 樹脂・マーブル・金属・半透明の4つです。マーブルは1個ずつ渦の入り方が違います。半透明は向こう側の面や下に敷いたマットが透けて見えます
- **ダイスの色** — 既定では、ロールを書き込んだ発言と同じ色です。チェックを外すと好きな色を選べます
- **数字の色** — 既定では、ダイスの色から読みやすい色を自動で選びます。チェックを外すと好きな色を選べます

パネルを開いたときと、何かを変えるたびに、D4からD20まで1個ずつその見た目で振って見せます。

#### ダイスに画像を貼る {#my-dice-picture}

**画像**の**画像を選ぶ**から、手元の画像をダイスに貼れます。石や木目の写真、自分で描いた模様、ロゴなどが使えます。貼り方は2通りです。

- **巻き付ける** — 模様が面の境目をまたいでつながります。1個ずつ画像の違う部分が出るので、同じ画像でもダイスごとに表情が変わります。石・木目・星空のような模様に向いています
- **各面に貼る** — どの面にも画像が丸ごと入り、その上に数字が載ります。ロゴや紋章に向いています

画像を貼っているあいだ、材質は樹脂だけになります。マーブルの渦や金属の照り返しが、画像の模様とぶつかるからです。画像を外すと、貼る前に選んでいた材質に戻ります。

透過PNGの透けた部分には、ダイスの色が出ます。数字の色を自動にしているときは、画像の色合いから読みやすい色を選びます。画像は長い辺が512ピクセルになるまで縮めて使い、8MBを超えるファイルは受け付けません。

貼った画像は部屋の全員に送られます。届くまでのあいだ、ほかの人の画面では画像のないダイスが転がり、届いた時点で画像付きに描き直されます。部屋を保存すると、画像もセーブデータに入ります。画像はこのブラウザにも保存されるので、次に部屋へ入ったときも貼ったままです。

選んだ見た目は、部屋の全員の画面で同じように見えます。見た目は発言に記録されるので、部屋を読み込み直しても、セーブデータを開いても、そのロールは同じ見た目で出ます。設定そのものはこのブラウザに保存され、キャラクターを替えても変わりません。

- 描画を軽くしている画面では、半透明のダイスを樹脂として描きます。ほかの人の画面では半透明で見えます
- マイダイスに対応していない古い版の人には、いつもの樹脂のダイスに見えます

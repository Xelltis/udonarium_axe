# ココフォリアのルーム取り込み

このページは、ココフォリアで書き出したルームデータのzipをAxeに読み込み、盤面ごと再現する「ルーム取り込み」を説明します。
コマを1体ずつ移す[キャラクターの取り込み](/manual/character-import)と違い、こちらは卓そのものを持ち込みます。
GMとPLが使えます。見学は取り込めません。

::: danger 実験的機能です
ココフォリアのルームデータには公開された仕様がなく、配布されている実物を解析して対応しています。
**ココフォリア側の更新で、予告なく読み込めなくなる可能性があります。**
また、下記のとおり再現できない要素があります。大事な卓は、取り込み後に必ず目で確認してください。
:::

## 使い方

1. ココフォリアで書き出したルームデータのzipを、テーブルにドラッグ＆ドロップします。FABメニューの**セーブ&ロード**の**ZIP読込**から選んでも同じです。
2. 中身がココフォリアのルームデータだと分かると、ふつうの[ZIP読込](/manual/save-load#zip読込)ではなく、取り込みに回ります。
3. 取り込みが終わると、最初のシーンのテーブルに切り替わります。

結果は、チャットの「システム」タブに流れます。
テーブルとパネルとコマがいくつ入ったか、何が取り込めなかったかが、そこに出ます。

::: tip 取り込めるのは、テーブルを編集できる人だけです
見学では取り込めません（→ [ロール（GM / PL / 見学）](/manual/roles)）。
:::

::: warning ルームデータの書き出しはココフォリアPROの機能です
読み込みはAxe側の機能なので誰でも使えますが、**zipを書き出す側**にはココフォリアのPROプランが必要です。
配布されているルームデータzipを読み込むだけなら、PROは不要です。
:::

## シーンとテーブル

ココフォリアの**シーン1つが、Axeのテーブル1枚**になります。テーブル名はシーン名がそのまま入るので、[テーブル設定](/manual/table-setting)のテーブル一覧が**そのままシーン切り替え**として使えます。
取り込み直後は、ココフォリアで最後に表示していたシーンのテーブルが選ばれます。

ココフォリアではシーンを切り替えてもパネルとコマが残るので、Axeでも同じになるようにしています。

- **パネル**は全シーンのテーブルに複製されます
- **コマ**はAxeではテーブルをまたいで残るため、1体ずつだけ作られます

::: tip 今の卓はそのまま残ります
取り込みは常に**テーブルを新しく作って**行われます。いま使っているテーブルは残るので、いつでも戻れます。
:::

::: warning 盤面の広さはルームの設定に揃えます
ココフォリアではシーンごとに盤面の広さを変えられますが、Axeのコマはテーブル共通の座標を持つため、テーブルごとに広さが違うとコマの位置がずれます。そのため**全シーンをルームの盤面サイズに揃えます**。
絵はテーブルに合わせて引き伸ばされます（ココフォリアも同じ表示です）。
:::

## 取り込まれる内容

| ココフォリアの要素                                               | Axeでの扱い                                              |
| ---------------------------------------------------------------- | -------------------------------------------------------- |
| シーン                                                           | テーブル（名前はシーン名）                               |
| 前景画像（盤面の絵）                                             | テーブルの画像                                           |
| 背景画像（盤面のまわり）                                         | テーブルの背景画像                                       |
| 盤面のマス数                                                     | テーブルの幅・高さ                                       |
| 盤面に置いた画像パネル                                           | [地形](/manual/terrain)（床のみ・視界と光は遮らない）    |
| コマ（名前・ステータス・能力値・チャットパレット・発言色・メモ） | [キャラクターコマ](/manual/character)                    |
| コマのアイコン・立ち絵差分                                       | コマ画像と立ち絵のギャラリー                             |
| コマの位置・向き                                                 | テーブル上の位置と回転                                   |
| 秘匿・非表示のコマ                                               | [公開範囲](/manual/disclosure)をGMのみに設定             |
| zip内の画像すべて                                                | 「ココフォリア」タグを付けて[画像](/manual/images)に登録 |

パネルの移動ロックはそのまま引き継がれます。取り込んだあとは、通常のテーブル・コマと同じように編集できます。

## 取り込まれないもの

| 要素               | 理由                                                                                            |
| ------------------ | ----------------------------------------------------------------------------------------------- |
| **BGM・音源**      | ココフォリアの仕様上、ルームデータzipに音源が含まれません（ココフォリア同士でも復元されません） |
| **カード**         | Axeに相当する機能はありますが、実データで構造を確認できていないため見送っています               |
| **カットイン**     | 音源がzipに含まれないため、再現できるのが画像だけになります                                     |
| **非表示のパネル** | 伏せてあるものを勝手に見せないため、取り込みません                                              |

取り込めなかったものは、**件数がチャットに出ます**。「カットイン1件は未対応のため取り込んでいません」のように表示されるので、何が欠けたかはその場で分かります。

## 盤面の外に置かれたもの

ココフォリアでは、説明パネルやコピー用のコマを**盤面の外側**に並べる作りがよく使われます。
Axeでも位置関係をそのまま再現するため、これらは**テーブルの外に置かれます**。
テーブルの外にはマス目も台座も出ないので、見た目はココフォリアと少し異なります。

盤面の中に入れたいときは、取り込んだあとに手で移動してください。

## うまくいかないとき

| 見えるもの                                                 | 原因と直しかた                                                                                                                                          |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 「ココフォリアのルームデータとして読めませんでした。」     | zipが壊れているか、ココフォリアのルームデータではありません。ルーム設定の「ルームデータ」から書き出したzipか確かめます                                  |
| 「卓の編集権限がないため、ルームデータを取り込めません。」 | 見学のときは取り込めません。接続パネルで役割を確かめます                                                                                                |
| 「画像が見つからなかった要素が N 件あります。」            | zipに画像が入っていない要素があります。その要素は、画像なしで置かれます                                                                                 |
| 「ルームデータの取り込みに失敗しました。」                 | 取り込みの途中で失敗しました。読み込み直してからもう一度試し、続くときは[不具合として報告](https://github.com/Xelltis/udonarium_axe/issues)してください |
| コマの位置がおかしい                                       | ココフォリア側の仕様が変わった可能性があります。[不具合として報告](https://github.com/Xelltis/udonarium_axe/issues)していただけると助かります           |

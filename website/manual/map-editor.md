# マップエディター

マップエディターは、セル・図形・スタンプ・フリーハンドなどを組み合わせてマップ画像を描き起こす **GM 専用ツール**です。GM ツールバーの **マップエディター** ボタンから開きます（[ロール](/manual/roles)が GM のときのみ表示されます）。

## 画面構成

パネルは 4 列 2 行のレイアウトで構成されています。

| 領域                   | 内容                                                   |
| ---------------------- | ------------------------------------------------------ |
| ツールバー（左列）     | 描画ツール選択ボタン（12 種）                          |
| プロパティ（左2列目）  | 選択ツールに応じた設定・塗り・線・スタンプなど         |
| キャンバス（中央）     | 実際の描画エリア。ホイールでズーム（Ctrl+ホイール）    |
| レイヤー（右列）       | レイヤーの管理（表示・ロック・不透明度・並び替え）     |
| ステータスバー（下段） | アンドゥ/リドゥ・ズーム・セーブ/ロード・書き出しボタン |

## マップ設定

「設定」ツール（ショートカットなし）を選ぶとプロパティパネルにマップ設定が表示されます。変更はすぐにキャンバスに反映されます。

| 設定           | 範囲 / 選択肢                            |
| -------------- | ---------------------------------------- |
| 横マス数       | 1 ～ 100                                 |
| 縦マス数       | 1 ～ 100                                 |
| マスサイズ     | 16 ～ 256 px                             |
| グリッドタイプ | スクエア / ヘクス（縦） / ヘクス（横）   |
| 背景色         | カラーピッカー（透明チェックで透過背景） |
| グリッド色     | カラーピッカー                           |
| グリッド表示   | チェックボックス                         |
| スナップ       | チェックボックス                         |

グリッドタイプはスクエア・ヘクス縦・ヘクス横の 3 種類から選択できます。「テーブル背景に設定」を実行すると、グリッドタイプを含む全設定がテーブルに反映されます。

## 塗り（フィル）

ペン・塗りつぶし・図形・線（閉じ曲線）ツールでは塗りモードを選べます。

- **単色** — カラーピッカーで色を指定
- **テクスチャ** — 黒土・レンガ・砂漠・床板・森林・砂利・溶岩・岩・岩（苔）・砂地・海・浅瀬・草原・石畳（大）・石畳（小）・石タイルの 16 種（継ぎ目なくループします）。拡大率と回転も調整可能
- **画像テクスチャ** — 「テクスチャ」タグの付いた画像がパレットに並びます。**「＋」タイル**から画像をアップロードでき、正方形に切り抜く画面（ドラッグで移動・ホイールで拡大縮小）を経て自動で「テクスチャ」タグが付き、メディアとして保存されます
- **線（ストローク）**にもテクスチャを選択できます（図形・線・多角形のストローク）

## 図形ツール

「図形」ツールでは描く形を選択できます。

| 形状   | 説明              |
| ------ | ----------------- |
| 矩形   | 長方形            |
| 楕円   | 楕円・円          |
| 三角形 | 正三角形（3頂点） |
| 五角形 | 正五角形          |
| 六角形 | 正六角形          |
| 五芒星 | 5 点の星形        |
| 六芒星 | 6 点の星形        |

塗りは単色またはテクスチャ（拡大率・回転付き）、線は単色またはテクスチャ（拡大率・回転付き）に加えて**線種**（実線 / 破線 / 点線 / 一点鎖 / 長破線）を選べます。**影**（色・ぼかし・オフセット）も設定でき、線種と影は線（直線/折れ線/曲線/閉じ曲線）・多角形ツールにも適用されます。各図形は配置のたびに独自のシェイプレイヤーに追加されます。

多角形ツールで頂点を 2 点以上クリックすると、閉じた半透明のプレビューが表示されます。

## 計測 HUD

ドラッグ・クリック中にカーソル近くに計測情報が表示されます。

- **図形ツール（ドラッグ中）** — 幅×高さ（マス単位、例: `3.0 × 2.0`）
- **線（折れ線/曲線/閉じ曲線）/ 多角形（クリック中）** — 最後の区間の長さ（マス）と角度（度）

## 画像ツール

「画像を選択」ボタンで保存済みの画像ライブラリから画像を選択します。選択後はカーソルに半透明プレビューが追従し、キャンバスをクリックした位置に配置されます。配置時に最長辺が 8 マスに収まるようリサイズされます。各画像は独自の画像レイヤーに配置されます。

選択ツールで配置済み画像を選ぶと、**四隅のハンドルをドラッグしてリサイズ**できるほか、幅・高さ・回転・不透明度を変更できます。**「マス目でクリップ」**を有効にすると、画像がその下のマス（ヘクスマップではヘクス形）の形に切り抜かれて描画されます。Delete/Backspace で削除します。

## スタンプ

6 カテゴリ 49 種のスタンプが用意されています。

| カテゴリ   | 主な内容                                     | 種類数 |
| ---------- | -------------------------------------------- | ------ |
| 扉         | 片扉・両扉・開いた扉・格子扉・隠し扉・アーチ | 6      |
| 階段       | 上り・下り・螺旋・はしご・スロープ           | 5      |
| 家具       | テーブル・椅子・ベッド・宝箱など             | 10     |
| 自然       | 樹木・岩・泉・池・キノコなど                 | 9      |
| ダンジョン | 柱・祭壇・かがり火・罠・ケージなど           | 9      |
| マーカー   | ピン・旗・スカルなどの目印                   | 10     |

配置時にプロパティパネルでサイズ・回転・X/Y 反転・色を調整できます。**色**行の「自動」チェックボックスをオフにするとカラーピッカーで色を指定できます（チェックボックスがオンの間もカラーピッカーは表示されます）。

選択ツールで配置済みのスタンプを選ぶと、サイズ・回転・反転に加えて**色**もあとから変更できます（同じ自動チェックボックス付き）。

## レイヤー

各レイヤーは右列で管理します。

- **表示** — 目のアイコンで表示/非表示を切り替え
- **ロック** — 鍵アイコンでロック。ロック中はそのレイヤーに描画できません
- **不透明度** — スライダーで 0～100% を調整
- **並び替え** — 上下矢印ボタンで描画順を変更
- **名前変更** — レイヤー名をダブルクリックして編集
- **削除** — ゴミ箱アイコン。確認ダイアログあり

「＋」ボタンから追加できるレイヤーの種類: セル・図形・スタンプ・フリーハンド・テキスト・**画像**

図形ツールおよび画像ツールで配置した要素は 1 つごとに独自のレイヤーが自動作成されます。

## スナップとグリッド

- **スナップ** — 有効にすると図形の頂点やスタンプがグリッドに吸着します（設定ツールのプロパティパネル）
- **グリッド表示** — キャンバスにグリッドを表示するかどうかを切り替えます
- **グリッド色** — グリッドの線色を変更できます

## スマートフォンで使う

狭い画面では、左のツールと**キャンバスの 2 段組**になります。ツール名は消えません。

- **設定**（つまみのアイコン）と **レイヤー** は、下の操作バーのボタンで引き出しとして開きます。キャンバス側を叩けば閉じます
- キーボードが要る操作は、操作バーとキャンバス上のボタンで代替できます
  - **削除** — 操作バーのごみ箱（選択中のみ押せます）
  - **確定 / 取消** — 折れ線・多角形を描いている間と、文字を入力している間に出るボタン

## セーブ / ロード

- **セーブ** — 現在のマップを `map.zip`（マップ JSON とアップロード画像テクスチャ・配置画像を同梱）としてダウンロードします
- **ロード** — zip を読み込んでマップを復元します。同梱された画像はメディアに自動登録され、テクスチャ画像には「テクスチャ」タグが付きます。旧 `map.json` ファイルもそのまま読み込めます

## 機能塗り

絵ではなく、卓のはたらきを塗るツールです。

立入禁止だけを塗りたいなら、[GM ツールバー](/manual/roles#gm-ツールバー) の **立入禁止を塗る**（⊘）が近道です。マップエディターが開き、まっさらな状態なら卓を取り込んだうえで、立入禁止の塗りを持った状態になります。描きかけの内容があるときは取り込まず、筆だけ渡します。
塗ったマスは**書き出す画像には入りません**。入れてしまうと、立入禁止の網掛けが床の絵に焼き付いてしまうからです。

3 種類あります。ツールを選ぶと左のプロパティで切り替えます。

| 種類         | 卓に置かれるもの | 設定できること             |
| ------------ | ---------------- | -------------------------- |
| 立入禁止     | 通れないマス     | なし                       |
| 地形（壁）   | 地形オブジェクト | 地形と同じもの一式（下記） |
| マップマスク | マップマスク     | 色、濃さ                   |

種類ごとに別のレイヤーへ溜まります。壁を消しても、同じマスに塗った立入禁止はそのまま残ります。

### 地形塗りで決められること

置かれるのは地形オブジェクトそのものです。手で置く地形とできることは変わりません。

見せ方は壁と床・壁だけ・床だけの 3 つから選び、壁の高さはマス数で決めます。0 にすると床だけになります。

テクスチャは 8 面ぶん指定できます。壁・床・上面・底面・北面・南面・東面・西面で、このうち「壁」と「床」は、指定のない面が代わりに着るものです。北面だけ壁画にする、といった塗り分けができます。

残りはチェックひとつずつ。視線を遮る、光を遮る、テクスチャを敷き詰める、グリッドを描く、影を落とす、面ごとに陰影をつける。

テクスチャをひとつも指定しなければ、[透明な壁](/manual/terrain#テクスチャのない地形は透明な壁)になります。通れず視線も遮りますが、卓に見えるのは GM 向けの枠だけです。見えない仕切りを作るのに使えます。

### 見た目ごとにレイヤーが分かれます

同じ地形塗りでも、石の壁と木の柵は別のレイヤーに溜まります。設定を変えてから塗ると新しいレイヤーが立ち、前に塗った壁はそのまま残ります。

レイヤーを選ぶと、そのレイヤーを塗ったときの設定がそっくり手元に戻ります。取り込んだ地形も同じで、選べばテクスチャも高さも見えるので、そこから 1 面だけ張り替える、といった直し方ができます。**選んでいる間の変更は、そのレイヤーの見た目そのものを変えます。** 別の見た目で塗り足したいときは、レイヤーの選択を外してから設定を変えてください。

機能消しは、その種類のレイヤーを分け隔てなく消します。見た目が違うレイヤーが重なっていても、そのマスからは残らず消えます。

### 塗った範囲はひとつの地形にまとまります

10 マス塗れば、1 マスの地形が 10 個ではなく、10 マス分の地形が 1 つ置かれます。卓が描くもの・動かすもの・光を計算する相手が、それぞれ 1 つで済みます。

まとめ方は左上から順に、そのつど入る限りいちばん広い矩形を取る、という決め方です。同じ塗りからは必ず同じ形が出るので、反映を繰り返しても壁が建て直されることはありません。

### テーブルへ反映する

ステータスバーの **機能だけ反映** を押すと、塗った 3 種類がテーブルに置かれます。**床画像には触りません。** すでにあるマップに立入禁止を足したいだけのとき、床を焼き直すと画質も画像の同一性も失われるためです。

いっぽう「テーブル背景に設定」は、床を焼いたうえで機能も一緒に反映します。

マス目がテーブルと合っていないときは断られます。先に **テーブルを取り込む** を押してください。

## テーブルを取り込む

ステータスバーの **テーブルを取り込む** で、いま出ているテーブルをエディターへ読み込みます。編集中の内容は捨てられるので、確認を挟みます。

読み込まれるのは次の 3 つです。

- **マス数・マスサイズ・グリッドタイプ** — テーブルのものに揃います
- **床画像** — ロックした画像レイヤーとして最背面に入ります。すでに焼かれた 1 枚の絵なので、図形には戻せません
- **地形・マスク・立入禁止** — 卓上にあるものはすべて読み込まれ、以後はエディターの管理下になります

見た目の違う地形は、見た目ごとに別のレイヤーになります。石の壁と木の柵を混ぜて 1 枚にすると、次の反映でどちらかの見た目に揃ってしまうためです。

回した地形、マス目からずれた地形、扉、スロープ、光を持つ地形も読み込まれます。塗りのマス目としては外接する矩形として扱われますが、名前・位置・向き・大きさ・8 面のテクスチャ・高さ・扉やスロープの設定・光は、そのブロックが丸ごと覚えています。マスクなら削った跡と削りかけの跡もそのままです。触らずに反映すれば、まったく同じものが戻ります。

::: warning 読み込んだものは、以後エディターのものになります
取り込んだ地形とマスクは、エディターで消して反映すれば卓からも消えます。

塗り直したブロックは作り直されます。姿はブロックが丸ごと覚えているので、向きも扉もテクスチャもマスクの削り跡も同じものが戻ります。戻らないのは、そのオブジェクトの詳細欄に自分で足した項目です。
:::

## 画像書き出しと「テーブル背景に設定」

ステータスバー右側で**書き出し倍率**（1x または 2x）を選んでから実行します。グリッド線は書き出し画像には含まれません（テーブルが自前のグリッドを描画するため、常にずれなく重なります）。

- **画像として保存** — 設定に従ってレンダリングした画像をファイルストレージに追加します
- **テーブル背景に設定** — 画像を書き出してファイルストレージに追加し、現在のテーブルの背景画像・幅・高さ・グリッドサイズ・グリッドタイプを自動設定します

背景を透明にすると書き出し画像も透過 PNG になります。

::: tip マップをテーブルに反映するには
「テーブル背景に設定」を使うと、マス数・マスサイズ・グリッドタイプがそのままテーブル設定に引き継がれるため、テーブル設定を別途変更する手間がありません。
:::

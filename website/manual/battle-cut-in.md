# 戦闘カットイン

このページは、攻撃する側と受ける側のコマを左右に並べ、エフェクト・ダメージの数字・撃破までを画面いっぱいに見せる「戦闘カットイン」を説明します。
FABメニューの**メディア**から**戦闘カットイン**を選ぶと、設定と再生のパネルが開きます。
再生すると、部屋の全員の画面に同時に出ます。

## 画面に出るもの

画面いっぱいに帯が開き、攻撃する側が一歩踏み込んでエフェクトを放ちます。背景には、部屋で選んだ舞台の絵が出ます。当たった瞬間に受けた側が揺れ、ダメージや回復の数字が飛び出して、下の欄のバーが減ります。

- コマの絵と名前。絵は、そのコマが卓でいま表示している立ち絵です。受ける側は4体まで並びます
- コマの頭上に出しているリソースのバー。頭上に出していないリソースも、数字が動いたものはバーで並べます
- 撃破の演出。部屋で決めたリソース（既定はHP）が0以下になったコマは、崩れて消え、「撃破」の文字が出ます

数字は、コマの頭上のバーと同じ決まりで伏せます。シートを見られないコマのバーは`???/???`です。シークレットの行（`st:`）から出したときは、全員の数字を伏せます。バーの動きは伏せません。

全画面のときは、画面をクリックするかEscキーを押すと、途中で閉じます。続けて再生したときは、前のカットインが終わってから次が始まります。表示メニューのアニメーションを停止にしている画面では、終わったときの様子を静止画で2秒半ほど出します。

## 自分の画面に出さない

パネル上部の**この画面で戦闘カットインを出す**を外すと、自分の画面にだけ出なくなります。ほかの人の画面には影響しません。

出さない設定の画面では、攻撃のエフェクトと撃破の演出を、テーブルの上のコマに出します。設定はブラウザに保存されます。

## 窓で見る {#window}

パネル上部の**表示の大きさ**で、**全画面**のほかに**大きな窓**・**中くらいの窓**・**小さな窓**を選べます。カットインの右上のボタンを押しても、全画面・大・中・小の順に切り替わります。

窓で見るときは、窓の外の卓やパネルを、再生中もそのまま操作できます。窓の中は全画面と同じ場面を縮めたもので、窓の上の縁をつかむと好きな場所へ動かせます。窓を押したりEscキーを押したりしても閉じないので、操作の途中で消えることはありません。閉じるときは、窓の右上の閉じるボタンを押します。

大きさと窓の場所は、この画面だけの設定で、ブラウザに保存されます。スマートフォンのように幅の狭い画面では、窓は画面の上の端に出て、動かせません。

## 出し方

スイッチは、GM・PL・見学者のだれでも押して出せます。リモコン、コマの右クリック、パネルの「全員に再生」で全員に出せるのは、GMとPLです。見学者は、パネルの「自分だけで見る」で自分の画面にだけ再生できます。

| 出し方                                                     | 攻撃する側             | 攻撃を受ける側                                     |
| ---------------------------------------------------------- | ---------------------- | -------------------------------------------------- |
| チャットの`《vs》`                                         | 発言したキャラクター   | `t:`の対象と同じ（ターゲット中のコマ）             |
| リモコンの戦闘カットインボタン                             | リモコンのキャラクター | チェックしたターゲット。いなければ左右の組の反対側 |
| コマの右クリックの「戦闘カットイン」から「このコマで攻撃」 | そのコマ               | ターゲット中のコマ。いなければ左右の組の反対側     |
| スイッチの動作「戦闘カットイン」                           | 左右の組で決めます     | 左右の組で決めます                                 |
| パネルの「全員に再生」                                     | 左右の組で決めます     | 左右の組で決めます                                 |

パネルの「自分だけで見る」は、自分の画面にだけ再生します。背景や演出を確かめるときに使います。

### チャットから出す

リソースを減らす行の末尾に`《vs》`を書くと、発言したキャラクターがターゲットを攻撃するカットインが出ます。

```
2d6+3 t:HP-10 《vs》
2d6+3 t:HP-10 《爆炎》《vs》
```

ダイスとリソースの処理が終わるのを待ってから、減ったあとの数字で再生します。`《エフェクト名》`を一緒に書くと、そのエフェクトで攻撃します。書かなければコマに設定した攻撃演出、それもなければダメージや回復の量に合った演出を使います。

`《vs》`の行では、エフェクトはテーブルの上ではなくカットインの中に出ます。`《vs》`は全角でも大文字でも構いません。

### リモコンから出す

[リモコン](/manual/character)の変更量の欄の下に、**戦闘カットイン**ボタンと**戦闘カットインでも見せる**のチェックがあります。

- 戦闘カットインボタンは、リソースを動かさずに再生します
- 戦闘カットインでも見せるにチェックを入れておくと、**操作**でリソースを動かしたときに、その変化をカットインで見せます

どちらも、リモコンのキャラクターがチェックしたターゲットを攻撃します。チェックの状態はブラウザに保存されます。

## 左右の組（GM）

GMは、卓のコマを左右に分けておけます。パネルの**左右の組**で「左へ」「右へ」を押すか、コマの右クリックの「戦闘カットイン」から「左の組に入れる」「右の組に入れる」を選びます。外すときは、パネルの×か「組に入れない」を選びます。

スイッチとパネルから組で再生するときは、組にいるコマのうち、次の順で最初に当てはまるコマが攻撃します。

1. 手番のコマ（[行動順](/manual/turn-order)）
2. スイッチを押した人のキャラクター
3. 左の組の先頭

攻撃を受けるのは、反対側の組のコマ（4体まで）です。パネルの再生の欄に、いま再生したときの組み合わせが出ます。

リモコンとコマの右クリックからターゲットなしで出したときは、手番に関係なく、そのキャラクターが反対側の組を攻撃します。そのキャラクターが組に入っていなければ再生しません。

組はコマに保存されるので、部屋を保存して読み込んでも残ります。チャットやリモコンから出したときも、組の左右に立ちます。どちらも組に入っていなければ、攻撃する側が左に立ちます。

### 陣営ごとの位置

[パーティ](/manual/party)を陣営として、陣営ごとに左右を決めておくこともできます。パネルの**左右の組**にある**陣営の位置**で、陣営ごとに「左」「なし」「右」を選びます。左右を決めた陣営のコマは、コマごとに組を決めていなければ、その側に並びます。変えるまで、その位置のままです。PCの陣営を右に置けば、PCはいつも右に立ち、PCを攻撃してくる敵は左に立ちます。

陣営の位置で並んだコマには、組の中に「陣営」と出ます。コマごとに「左へ」「右へ」を選ぶと、そちらが優先されます。×や「組に入れない」で外したコマは、陣営が左右に並んでいても外れたままです。卓のコマの欄の「陣営に戻す」を押すと、陣営の位置に戻ります。

## コマの攻撃演出

コマごとに、攻撃に使うエフェクトを決めておけます。パネルの**コマの攻撃演出**でコマと演出を選ぶと、下に見本が繰り返し流れます。コマの右クリックの「戦闘カットイン」から「攻撃演出を選ぶ…」を選ぶと、そのコマを選んだ状態でパネルが開きます。

シートを見られるコマなら、PLも設定できます。GMだけのエフェクトをGMが設定したコマは、PLが再生してもそのエフェクトで攻撃します。

同じ欄の**絵の向き**で、コマの絵が左右のどちらを向いているかを選べます。左向きの絵を左に立たせると、相手に背を向けてしまいます。そこで舞台では、絵が相手のほうを向くように左右を反転します。右向きの絵を右に立たせたときも同じです。「そのまま」なら反転しません。撃破の演出で絵が崩れるときも、反転した向きのまま崩れます。

## 部屋の設定（GM）

パネルの部屋の設定は、GMだけが変更できます。

| 項目         | 内容                                                                                                                                    |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| 舞台         | 背景の絵を選びます。ファンタジー・現代・ホラー・サイバーパンク・ロボットSFの5つに、それぞれ夜と昼があります。既定はファンタジーの昼です |
| 登録した画像 | 「画像を登録」で選んだ画像を、舞台の絵の代わりに使えます。24枚まで登録でき、右上の「×」で登録を外します                                 |
| 撃破         | チェックを入れると、指定したリソースが0以下になったコマに撃破の演出を出します。既定ではチェックが入っています                           |
| リソース     | 撃破を判定するリソースの名前です。既定はHPです                                                                                          |
| 撃破の演出   | エフェクト集から選びます。既定は「崩壊」です。「崩壊」と「両断」はコマの絵そのものを崩し、ほかの演出ではコマの絵が薄れていきます        |

ホラーの昼は、晴れた空だと怖く見えないので、曇った午後の廃村にしてあります。登録した画像を背景にしたときは、帯の縁と名前欄を銀・青・赤の決まった色で描きます。登録した画像は部屋のセーブに入るので、読み込み直しても舞台の並びに残ります。

撃破になるのは、0より大きかった値がその攻撃で0以下になったときです。もともと0以下だったコマは、もう一度倒れません。狂気度のように増えるほど悪いリソースは、最大値に達したときを撃破とします。

## 古い版の参加者

戦闘カットインがない版の参加者の画面には、カットインもテーブルの上の演出も出ません。
左右の組と攻撃演出の設定は、古い版で部屋を保存し直しても消えません。陣営の位置と絵の向きも同じです。

古い版の参加者が再生したときは、陣営の位置を読まず、コマごとの組だけで並べます。新しい版が再生した場面は、古い版の画面でも同じ左右に並びますが、絵は反転しません。

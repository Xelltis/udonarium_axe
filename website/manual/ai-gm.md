# AI GM

このページはClaudeにゲームマスターを任せる「AI GM」を説明します。
AI GMはGMの席でClaudeを動かし、プレイヤーの発言やダイス、NPCの手番に応えて場面を進めさせます。

[AI連携（MCP）](/manual/ai-link)では、Claude CodeなどのAIのアプリが、いつ何をするかを自分で決めます。
AI GMでは、ClaudeとのやりとりをAxeの手元のブリッジが受け持ち、AIの番をいつ回すか、いくらまで使うかをAxeのパネルで決めます。

## しくみ

1. ブリッジ（`axe-mcp.mjs`）を`gm`を付けて起動します。ClaudeのAPIキーは起動するときの環境変数に入れ、ブリッジだけが持ちます。
2. FABメニューの**AI GM**を開き、**つなぐ**を押してから**始める**を押します。
3. プレイヤーが話したり、AIが動かすコマの手番が来たりすると、ブリッジがClaudeに番を回します。Claudeは発言し、ダイスを振り、コマを動かして応えます。

Claudeが使う道具はAI連携と同じで、つないだ席の権限でタブの中で動きます。APIキーはブラウザに入らず、部屋にも送られません。
Claude APIの利用料はAPIキーの持ち主にかかります。

## 用意する

Node.js 22以上と、Claude APIのキーが要ります。

1. [リリースのページ](https://github.com/Xelltis/udonarium_axe/releases/latest)から`axe-mcp.mjs`を落とし、好きな場所に置きます。AI連携と同じファイルです。
2. [Claude Console](https://platform.claude.com)でAPIキーを作ります。使いすぎを防ぐため、AI GM用のワークスペースを作り、[使用額の上限](https://platform.claude.com/settings/spend-limits)を付けておくことをおすすめします。

キーをチャットやAxeの画面に貼らないでください。

## ブリッジを起動する

macOSとLinuxでは、端末で次を実行します。キーとパスは自分のものに書き換えます。

```sh
ANTHROPIC_API_KEY=sk-ant-... node /path/to/axe-mcp.mjs gm
```

WindowsのPowerShellでは、次のとおりです。

```powershell
$env:ANTHROPIC_API_KEY="sk-ant-..."; node C:\path\to\axe-mcp.mjs gm
```

止めるときは、端末でCtrl+Cを押します。自分のサーバーに置いたAxeとつなぐときは、AI連携と同じく`--allow-origin`とそのページのアドレスを足します（[自分で置いたAxeとつなぐ](/manual/ai-link#自分で置いたaxeとつなぐ)）。
パネルの**ブリッジの起動のしかた**には、開いているページに合わせたコマンドが出ます。

## 始める

1. GMの席で、FABメニューの**AI GM**を押してパネルを開きます。
2. **つなぐ**を押します。「止まっています」と出れば、ブリッジにつながっています。
3. **AI GMへの指示**に、世界観・口調・使うルール・シナリオの流れ・秘密などを書きます。
4. **始める**を押します。Claudeが場面を開き、プレイヤーに語りかけます。

AI GMを始めると、AI連携の**AIに許すこと**は**書くことも許す**に変わります。始めたときと止まったときは、「システム」タブに全員向けの行が出ます。
Claudeが送った発言には、AI連携と同じくAIの印（<span class="material-icons">smart_toy</span>）が付きます。

## 出番

パネルの**出番**で、Claudeに番を回すときを選びます。

| 選ぶもの         | Claudeが動くとき                                                                                   |
| ---------------- | -------------------------------------------------------------------------------------------------- |
| 発言に応える     | 聞くタブでプレイヤーが話したとき。続けての発言やダイスの結果を待って、数秒静かになってから応えます |
| 呼ばれたときだけ | 呼び名を含む発言、AIの席への秘話、AIが動かすコマの手番、パネルの**進めてもらう**のときだけ動きます |

どちらでも、AIが動かすコマの手番が来ると、Claudeはそのコマで行動してから手番を渡します。
呼び名は初めは「GM」で、大文字と小文字を区別しません。**聞くタブ**を選ばなければ、すべてのタブを聞きます。
GMの席の人がチャットに書いた行では、Claudeは動きません。次の番に、その行も読みます。

### AIが動かすコマ

NPCの印があるコマと、AIの席が[オーナー](/manual/disclosure)のコマを、Claudeが動かします。NPCの印はコマの右クリックの**NPC にする**で付けます。
パネルの**AIが動かすコマ**に一覧が出ます。どちらでもないコマの手番では、Claudeは動かずにプレイヤーを待ちます。

## 進め方を伝える

- **AI GMへの指示**は動いている間に書き換えても、次の番から効きます。
- **AIに進めてもらう**の欄に一言を書いて**進めてもらう**を押すと、すぐにClaudeの番になります。一言はClaudeにだけ届き、プレイヤーには見えません。
- **AIのメモ**は、Claudeが場面を覚えておくために書くメモです。人が直してもかまいません。
- **AIの独り言**には、Claudeが道具を使わずに書いた文が出ます。チャットには出ません。

会話が長くなると、ClaudeはAIのメモを書き直してから、それまでの会話を置き、メモと最近のチャットから続けます。

## 止める

**止める**を押すと、考えている途中の番も取り消して止まります。もう一度動かすときは、**続きから始める**で同じ会話を続けるか、**最初から始める**で会話を新しくします。
ブリッジを起動したままなら、ページを開き直してつなぎ直しても、会話の続きから動きます。ブリッジを止めると会話は消え、次に始めたときはAIのメモと最近のチャットから続けます。

次のときは、Claudeは自分で止まります。

- 使った額が**使用額の上限**に届いたとき
- APIキーが使えないとき
- 番の失敗が3回続いたとき

## 設定

| 項目         | 内容                                                             |
| ------------ | ---------------------------------------------------------------- |
| モデル       | Claude Opus 5.5（初めの値）・Claude Sonnet 5.5・Claude Haiku 5.5 |
| 考える深さ   | 速く・ふつう・じっくり。深いほど応えるまでに時間がかかります     |
| 出番         | 発言に応える・呼ばれたときだけ                                   |
| 呼び名       | この言葉を含む発言でClaudeを呼びます。初めは「GM」です           |
| 使用額の上限 | 始めてから止めるまでに使える額（米ドル）。初めは5ドルです        |
| 聞くタブ     | 「発言に応える」で聞くチャットのタブ                             |

指示・メモ・設定はこのブラウザにだけ保存します。部屋に同期せず、部屋の保存にも入りません。部屋の[シナリオテキスト](/manual/scenario-text)は、Claudeが読めます。

## 費用の目安

パネルの**使った額**は、Claude APIが返す使用量と料金表から出した見積もりです。実際の請求額はClaude Consoleで確かめます。
3時間ほどの卓で、Claude Opus 5.5なら10〜15ドルほど、Claude Sonnet 5.5ならその半分ほど、Claude Haiku 5.5なら1ドルに届かないほどが目安です。発言が多い卓ほど高くなります。

## うまくいかないとき

| 見えるもの                                      | 原因と直しかた                                                                       |
| ----------------------------------------------- | ------------------------------------------------------------------------------------ |
| 「つながっているブリッジはAI GMを動かしません」 | ブリッジが`gm`を付けずに起動しています。`gm`を付けて起動し直します                   |
| 「APIキーが使えないので止まりました」           | キーが違うか、無効になっています。環境変数のキーを確かめて、ブリッジを起動し直します |
| **始める**が押せない                            | GMの席でないと始められません                                                         |
| プレイヤーが話してもClaudeが応えない            | **出番**が「呼ばれたときだけ」か、**聞くタブ**にそのタブが入っていません             |
| NPCの手番でClaudeが動かない                     | そのコマにNPCの印がありません。コマの右クリックの**NPC にする**で付けます            |
| プレイヤーのコマの手番でClaudeが動く            | そのコマにNPCの印が付いているか、AIの席がオーナーになっています                      |
| ブリッジが起動しない                            | `ANTHROPIC_API_KEY`が空です。キーを入れて起動します                                  |

## 気をつけること

AI GMは部屋の内容（チャット・シート・コマの名前・指示・シナリオテキストなど）をAnthropicのClaude APIに送ります。AI GMを使うことを参加者に知らせてから使います。
Claudeが判定やルールを間違えることもあるので、GMの席の人はパネルとチャットを見て、必要なら止めて引き取ります。

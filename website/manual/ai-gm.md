# AI GM

このページはAIにゲームマスターを任せる「AI GM」を説明します。初めはClaudeで動き、[ほかのAIでも動かせます](#claude以外のaiで動かす)。
AI GMはGMの席でAIを動かし、プレイヤーの発言やダイス、NPCの手番に応えて場面を進めさせます。

[AI連携（MCP）](/manual/ai-link)では、Claude CodeなどのAIのアプリが、いつ何をするかを自分で決めます。
AI GMでは、AIとのやりとりをAxeの手元のブリッジが受け持ち、AIの番をいつ回すか、いくらまで使うかをAxeのパネルで決めます。
AI GMは**AI連携**のパネルの**GMを任せる**のタブから動かします。AI連携でつないだAIのアプリにも、同じタブからAI GMをさせられます（[AIのアプリにAI GMをさせる](#aiのアプリにai-gmをさせる)）。

## はじめての人の手順

パソコンに詳しくない人が、最初の1回を通すための手順です。
ここでは、自分のパソコンで「ブリッジ」という小さなプログラムを動かします。ブリッジはAxeとClaudeのあいだでやりとりを受け渡します。くわしい説明はこのあとの各節にあります。

### 用意するもの

- パソコン（Windows・macOS・Linux）と、Axeを開くブラウザ
- Claude APIの利用料を払う手段。Claudeを動かした分だけ料金がかかります。目安は[費用の目安](#費用の目安)にあります
- 自分がGMの席にいる部屋。自分で作った部屋では、作った人がGMです（[ロール](/manual/roles)参照）

### 1. Node.jsを入れる

Node.jsはブリッジを動かすために要る無料のソフトです。

1. [Node.jsのサイト](https://nodejs.org/ja)を開き、「LTS」と書かれたインストーラーを落とします。
2. 落としたファイルを開き、画面の案内のとおりに最後まで進めます。設定は初めのままでかまいません。
3. 「端末」を開きます。端末は文字で命令を打ってパソコンを動かす画面です。Windowsではスタートメニューで「PowerShell」と打って開き、macOSでは「ターミナル」というアプリを開きます。
4. 端末に`node -v`と打ってEnterを押します。`v22.3.0`のように、22以上の数字が出れば入っています。

### 2. ブリッジを落とす

1. [リリースのページ](https://github.com/Xelltis/udonarium_axe/releases/latest)を開きます。
2. 「Assets」の一覧から`axe-mcp.mjs`を押して落とします。
3. 落としたファイルはダウンロードのフォルダに置いたままにします。

### 3. Claude APIのキーを作る

APIキーはClaudeを使うための合言葉です。知られると他人に料金を使われるので、人に見せず、チャットやAxeの画面にも貼りません。

1. [Claude Console](https://platform.claude.com)を開き、アカウントを作ってログインします。
2. 支払いの設定を済ませます。
3. [使用額の上限](https://platform.claude.com/settings/spend-limits)を、払ってもよい額にしておきます。
4. APIキーを作り、出てきた`sk-ant-`で始まる文字をコピーして、自分だけが見られる場所に控えます。

### 4. ブリッジを起動する

手順1で開いた端末に、次の2行を1行ずつ打ち、行ごとにEnterを押します。`sk-ant-...`のところは控えたAPIキーに置き換えます。

Windowsでは次のとおりです。

```powershell
cd $HOME\Downloads
$env:ANTHROPIC_API_KEY="sk-ant-..."; node axe-mcp.mjs gm
```

macOSとLinuxでは次のとおりです。

```sh
cd ~/Downloads
ANTHROPIC_API_KEY=sk-ant-... node axe-mcp.mjs gm
```

`waiting for a tab of Axe`を含む行が出れば、ブリッジが動いています。遊んでいるあいだ、この端末は閉じません。

### 5. AxeでAI GMを始める

1. Axeで、自分がGMの席にいる部屋を開きます。
2. 画面左上の丸いボタン（FABメニュー）を押し、並んだボタンから**AI連携**を押してパネルを開き、**GMを任せる**のタブを押します。
3. **つなぐ**を押します。「止まっています」と出れば、ブリッジにつながっています。
4. **モデル**を選びます。はじめて試すときは、料金の安いClaude Haiku 5.5をおすすめします。
5. **AI GMへの指示**に、どんな卓にしたいかを書きます。下の例を写して、自分の卓に合わせて書き換えてもかまいません。
6. Claudeに動かしてもらう敵や村人のコマを右クリックし、**NPC にする**を押します。
7. **始める**を押します。Claudeが場面を開き、チャットでプレイヤーに語りかけます。

指示の例です。

```text
あなたはファンタジーの冒険のゲームマスターです。
舞台は、森のそばの小さな村です。村人が夜ごとに消える事件が起きています。
口調はていねいに、1回の発言は3行までにしてください。
判定が要るときは、プレイヤーに2d6を振ってもらい、7以上で成功にしてください。
事件の犯人は森の奥の洞窟にいるゴブリンです。プレイヤーが突き止めるまで明かさないでください。
```

### 6. 遊ぶ

- プレイヤーがチャットに書くと、数秒おいてClaudeが応えます。
- GMの席の人、つまり自分がチャットに書いても、Claudeは動きません。1人で試すときは、パネルの**AIに進めてもらう**に「場面を進めてください」のように書いて、**進めてもらう**を押します。
- 進め方を変えたいときも、**AIに進めてもらう**に一言を書いて伝えます。この一言はプレイヤーには見えません。
- パネルの**使った額**に、ここまでの料金の見積もりが出ます。**使用額の上限**（初めは5ドル）に届くと、Claudeは自分で止まります。

### 7. 終わる

1. パネルの**止める**を押します。
2. 端末でCtrlキーを押しながらCを押して、ブリッジを止めます。端末は閉じてかまいません。

次に遊ぶときは、手順4から始めます。

## しくみ

1. ブリッジ（`axe-mcp.mjs`）を`gm`を付けて起動します。AIのAPIキーは起動するときの環境変数に入れ、ブリッジだけが持ちます。
2. FABメニューの**AI連携**を開いて**つなぐ**を押し、**GMを任せる**のタブで**始める**を押します。
3. プレイヤーが話したり、AIが動かすコマの手番が来たりすると、ブリッジがAIに番を回します。AIは発言し、ダイスを振り、コマを動かして応えます。

AIが使う道具はAI連携と同じで、つないだ席の権限でタブの中で動きます。APIキーはブラウザに入らず、部屋にも送られません。
APIの利用料はAPIキーの持ち主にかかります。

## 用意する

Node.js 22以上と、Claude APIのキーが要ります。

1. [リリースのページ](https://github.com/Xelltis/udonarium_axe/releases/latest)から`axe-mcp.mjs`を落とし、好きな場所に置きます。AI連携と同じファイルです。
2. [Claude Console](https://platform.claude.com)でAPIキーを作ります。使いすぎを防ぐため、AI GM用のワークスペースを作り、[使用額の上限](https://platform.claude.com/settings/spend-limits)を付けておくことをおすすめします。

キーをチャットやAxeの画面に貼らないでください。

## ブリッジを起動する

macOSとLinuxでは、端末で次を実行します。キーとパスは自分のものに書き換えます。

```sh
ANTHROPIC_API_KEY=sk-ant-... node /path/to/axe-mcp.mjs gm
```

WindowsのPowerShellでは、次のとおりです。

```powershell
$env:ANTHROPIC_API_KEY="sk-ant-..."; node C:\path\to\axe-mcp.mjs gm
```

ブリッジが起動している間にClaudeが使える額は、初めは20ドルまでです。何度始め直しても合わせて数えるので、パネルの上限より先に届くことがあります。変えるときは`--max-usd 50`のように足します。届いたら、ブリッジを起動し直します。

止めるときは、端末でCtrl+Cを押します。自分のサーバーに置いたAxeとつなぐときは、AI連携と同じく`--allow-origin`とそのページのアドレスを足します（[自分で置いたAxeとつなぐ](/manual/ai-link#自分で置いたaxeとつなぐ)）。
パネルの**ブリッジの起動のしかた**には、開いているページに合わせたコマンドが出ます。
起動のときに足せる指定の一覧は、[AI連携の道具とブリッジの設定](/manual/ai-link-reference#起動のときに足せる指定)にあります。

## Claude以外のAIで動かす

AI GMは初めはClaudeで動きます。ブリッジの起動のしかたを変えると、OpenAI互換のAPIを持つほかのAIでも動かせます。OpenAIのほか、同じ形のAPIを出しているサービスや、自分のパソコンで動かすモデル（Ollama・LM Studioなど）が当たります。
モデルは道具の呼び出し（function calling）に対応したものが要ります。対応していないモデルは発言もコマの移動もできません。

起動の行に、次の指定を足します。

| 指定                  | 意味                                                                                           |
| --------------------- | ---------------------------------------------------------------------------------------------- |
| `--provider openai`   | OpenAI互換のAPIで動かします                                                                    |
| `--base-url アドレス` | APIのアドレス。省くとOpenAI（`https://api.openai.com/v1`）です                                 |
| `--model 名前`        | 使うモデルの名前。そのサービスでの呼び名を書きます。何度でも足せ、足した名前がパネルに並びます |
| `--price 入力,出力`   | モデルの料金。100万トークンあたりの米ドルを、読む分と書く分の順に書きます。省けます            |
| `--max-tokens 数`     | 料金を書かなかったときに、ブリッジが動いている間に使えるトークン数の上限。初めは200万です      |

APIキーは環境変数`AXE_GM_API_KEY`に入れます。キーの要らない手元のモデルでは、入れなくてかまいません。

OpenAIで動かす例です。macOSとLinuxの書き方で、WindowsのPowerShellでは先頭を`$env:AXE_GM_API_KEY="sk-..."; `に替えます。

```sh
AXE_GM_API_KEY=sk-... node axe-mcp.mjs gm --provider openai --model モデル名 --price 2.5,10
```

自分のパソコンのOllamaで動かす例です。キーは要りません。

```sh
node axe-mcp.mjs gm --provider openai --base-url http://127.0.0.1:11434/v1 --model モデル名
```

起動したら、パネルの**モデル**で、`--model`に書いた名前を選んでから**始める**を押します。

### 料金と上限の数え方

- `--price`を書いたモデルはClaudeと同じく使った額をドルで数え、**使用額の上限**と`--max-usd`で止まります。料金はサービスの料金表で確かめて書きます。
- `--price`を書かなかったモデルは、料金が分からないので、使ったトークン数で数えます。パネルには額の代わりにトークン数が出て、`--max-tokens`に届くと止まります。パネルの**使用額の上限**は効きません。

### Claudeと違うところ

- パネルの**考える深さ**はClaudeにだけ効きます。
- 応えの質と速さは、選んだモデルで大きく変わります。小さいモデルは道具を正しく呼べなかったり、進め方の手引きを守れなかったりすることがあります。
- 部屋の内容は指定したアドレスのサービスに送られます。手元のモデルなら、パソコンの外には出ません。

## AIのアプリにAI GMをさせる

Claude CodeなどのAIのアプリを[AI連携（MCP）](/manual/ai-link)でつないでいるときは、そのAIにAI GMをさせられます。Claude APIのキーも`gm`を付けて起動したブリッジも要りません。AIを動かす料金はAIのアプリの契約にかかります。

1. [AI連携の手順](/manual/ai-link#はじめての人の手順)のとおりに、GMの席でAIのアプリとAxeをつなぎます。
2. **AI連携**のパネルの**GMを任せる**のタブで、指示・出番・聞くタブを決めて**始める**を押します。AIに書くことを許す設定は、始めるとAxeが切り替え、止めると元に戻します。
3. AIのアプリで、AIにAI GMを始めさせます。Claude Codeでは`/mcp__axe__run_ai_gm`と打ちます。プロンプトを選べないアプリでは、AIに「axe://guide/run-ai-gmを読んでAI GMをして」と頼みます。

2と3はどちらが先でもかまいません。AIは`wait_for_turn`という道具で自分の番を待ち、番が来ると、そのあいだに起きたことと番が来た理由を受け取って動きます。指示とメモは、新しいときと変わったときに一緒に届きます。
[出番](#出番)、聞くタブ、呼び名、[進めてもらう](#進め方を伝える)、[止める](#止める)は`gm`のブリッジで動かすときと同じに効きます。AIが書いたメモもパネルに届きます。

`gm`のブリッジで動かすときとは、次の点が違います。

- モデル、考える深さ、使用額の上限はパネルでは決められません。AIのアプリの側で決めます。パネルに使った額は出ません
- AIのアプリを閉じたり、AIが待つのをやめたりすると、番が来てもAIは動きません。AIが番を待つのも道具を呼ぶのもやめてから2分たつと、パネルに「AIが番を待っていません」と出ます。AIが長く考えているあいだに出ることもありますが、番はAIに残り、AIが次の番を待ちに来れば消えます。そのときは、AIのアプリでもう一度AI GMを始めさせます
- 「AIの独り言」には何も出ません。AIの独り言はAIのアプリの画面に出ます
- 会話が長くなったときの区切り直しは、AIのアプリのものを使います

## 始める

1. GMの席で、FABメニューの**AI連携**を押してパネルを開き、**GMを任せる**のタブを押します。
2. **つなぐ**を押します。「止まっています」と出れば、ブリッジにつながっています。`gm`のブリッジにつながると、パネルは**GMを任せる**のタブに切り替わります。
3. **AI GMへの指示**に、世界観・口調・使うルール・シナリオの流れ・秘密などを書きます。
4. **始める**を押します。AIが場面を開き、プレイヤーに語りかけます。

AI GMを始めると、AI連携の**AIに許すこと**は**書くことも許す**に変わり、止まると元に戻ります。始めたときと止まったときは、「システム」タブに全員向けの行が出ます。
AIが送った発言には、AI連携と同じくAIの印（<span class="material-icons">smart_toy</span>）が付きます。

## 出番

パネルの**出番**で、AIに番を回すときを選びます。

| 選ぶもの         | AIが動くとき                                                                                       |
| ---------------- | -------------------------------------------------------------------------------------------------- |
| 発言に応える     | 聞くタブでプレイヤーが話したとき。続けての発言やダイスの結果を待って、数秒静かになってから応えます |
| 呼ばれたときだけ | 呼び名を含む発言、AIの席への秘話、AIが動かすコマの手番、パネルの**進めてもらう**のときだけ動きます |

どちらでも、AIが動かすコマの手番が来ると、AIはそのコマで行動してから手番を渡します。
呼び名は初めは「GM」で、大文字と小文字を区別しません。**聞くタブ**を選ばなければ、すべてのタブを聞きます。選んだタブがこの部屋にないときも、すべてのタブを聞きます。
聞くタブを選ぶと、ほかのタブの発言はAIに届きません。雑談のタブで呼び名を書いてもAIは動かず、次の番にその発言を読むこともありません。AIの席への秘話は、どのタブのものでも届きます。卓が知らせを出す「システム」タブの行も届きます。聞かないタブで振ったダイスの結果や、そこで操作したリソースの結果は、そのタブの発言と同じく届きません。AIが自分でチャットを読み返すときも、読めるのは同じ行だけです。
GMの席の人がチャットに書いた行では、AIは動きません。次の番に、その行も読みます。

### AIが動かすコマ

NPCの印があるコマと、AIの席が[オーナー](/manual/disclosure)のコマを、AIが動かします。NPCの印はコマの右クリックの**NPC にする**で付けます。
パネルの**AIが動かすコマ**に一覧が出ます。どちらでもないコマの手番では、AIは動かずにプレイヤーを待ちます。

## 進め方を伝える

- **AI GMへの指示**は動いている間に書き換えても、次の番から効きます。
- **AIに進めてもらう**の欄に一言を書いて**進めてもらう**を押すと、すぐにAIの番になります。一言はAIにだけ届き、プレイヤーには見えません。
- **AIのメモ**は、AIが場面を覚えておくために書くメモです。人が直してもかまいません。
- **AIの独り言**には、AIが道具を使わずに書いた文が出ます。チャットには出ません。

会話が長くなると、AIはAIのメモを書き直してから、それまでの会話を置き、メモと最近のチャットから続けます。

## 止める

**止める**を押すと、考えている途中の番も取り消して止まります。もう一度動かすときは、**続きから始める**で同じ会話を続けるか、**最初から始める**で会話を新しくします。
ブリッジを起動したままなら、ページを開き直してつなぎ直しても、会話の続きから動きます。ブリッジを止めると会話は消え、次に始めたときはAIのメモと最近のチャットから続けます。

次のときは、AIは自分で止まります。

- 使った額が**使用額の上限**か、ブリッジの`--max-usd`に届いたとき
- APIキーが使えないとき
- 番の失敗が3回続いたとき
- その席がGMでなくなったとき、またはAI連携が**読むだけ**になったとき

## 設定

| 項目         | 内容                                                             |
| ------------ | ---------------------------------------------------------------- |
| モデル       | Claude Opus 5.5（初めの値）・Claude Sonnet 5.5・Claude Haiku 5.5 |
| 考える深さ   | 速く・ふつう・じっくり。深いほど応えるまでに時間がかかります     |
| 出番         | 発言に応える・呼ばれたときだけ                                   |
| 呼び名       | この言葉を含む発言でClaudeを呼びます。初めは「GM」です           |
| 使用額の上限 | 始めてから止めるまでに使える額（米ドル）。初めは5ドルです        |
| 聞くタブ     | AIに届くチャットのタブ。選ばなければすべてのタブ                 |

指示・メモ・設定はこのブラウザにだけ保存します。部屋に同期せず、部屋の保存にも入りません。部屋の[シナリオテキスト](/manual/scenario-text)は、Claudeが読めます。

## 費用の目安

パネルの**使った額**は、Claude APIが返す使用量と料金表から出した見積もりです。実際の請求額はClaude Consoleで確かめます。
3時間ほどの卓で、Claude Opus 5.5なら10〜15ドルほど、Claude Sonnet 5.5ならその半分ほど、Claude Haiku 5.5なら1ドルに届かないほどが目安です。発言が多い卓ほど高くなります。

## うまくいかないとき

| 見えるもの                                           | 原因と直しかた                                                                                                                                                    |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 「AIが番を待っていません」                           | AI連携のブリッジにつないでいて、AIが番を待っていません。AIのアプリで`/mcp__axe__run_ai_gm`を実行します（[AIのアプリにAI GMをさせる](#aiのアプリにai-gmをさせる)） |
| 「APIキーが使えないので止まりました」                | キーが違うか、無効になっています。環境変数のキーを確かめて、ブリッジを起動し直します                                                                              |
| 「選んでいたモデルは、このブリッジでは動かせません」 | 前に選んだモデルを、いまのブリッジが扱っていません。**モデル**を選び直します                                                                                      |
| **始める**が押せない                                 | GMの席でないと始められません。GMの席なら、選んでいたモデルをいまのブリッジが扱っていないので、**モデル**を選び直します                                            |
| プレイヤーが話してもClaudeが応えない                 | **出番**が「呼ばれたときだけ」か、**聞くタブ**にそのタブが入っていません                                                                                          |
| NPCの手番でClaudeが動かない                          | そのコマにNPCの印がありません。コマの右クリックの**NPC にする**で付けます                                                                                         |
| プレイヤーのコマの手番でClaudeが動く                 | そのコマにNPCの印が付いているか、AIの席がオーナーになっています                                                                                                   |
| ブリッジが起動しない                                 | `ANTHROPIC_API_KEY`が空です。キーを入れて起動します                                                                                                               |
| 端末に`node`が見つからないと出る                     | Node.jsが入っていないか、入れる前から開いていた端末です。Node.jsを入れてから、端末を開き直します                                                                  |
| 端末に`Cannot find module`と出る                     | `axe-mcp.mjs`のあるフォルダにいません。`cd`の行から打ち直すか、ファイルがダウンロードのフォルダにあるかを確かめます                                               |

## 気をつけること

AI GMは部屋の内容（チャット・シート・コマの名前・指示・シナリオテキストなど）をAnthropicのClaude APIに送ります。AI GMを使うことを参加者に知らせてから使います。
Claudeが判定やルールを間違えることもあるので、GMの席の人はパネルとチャットを見て、必要なら止めて引き取ります。

# 水域と水中

卓に池や川、海辺を置けます。水域は[環境エフェクト](/manual/map-effects#環境エフェクト-—-マップそのものを毒沼や濃霧にする)の種類の1つ「水」で、水面の高さ・濁り・汚れ・浮き葉・流れを決められます。卓全体を水の中にする天候「水中」もあります。

## 水域を置く

盤面の何もないところを右クリックし、「環境エフェクトを置く」から「水」を選ぶと、4×4マスの水域が置かれます。動かし方、広さの変え方、見せる相手は、ほかの[範囲を区切る環境エフェクト](/manual/map-effects#範囲を区切る-毒沼・地面の噴出)と同じです。

水域をいくつか並べると、つなぎ目のない1つの水として描かれます。大きな池を何枚かに分けて置いても、境目は出ません。重なったところは、水面の高いほうになります。四角の卓でも、ヘクスの卓でも同じように描かれます。

## 水の設定

水域を右クリックし、「環境エフェクトの設定」を開くと、水だけの項目が並びます。

| 項目               | 決めること                                                                                                                     |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| 見た目             | 澄んだ水・濁った水・泥水・藻の浮いた水・よどんだ水・白く濁った水・蓮池から選びます。色・濁り・汚れ・浮き葉がまとめて変わります |
| 水面の高さ（マス） | 水域の床から水面までの高さです。0〜10マスで、0.1マス刻みです。既定は0.5マスです                                                |
| 濁り               | 0〜100%で、既定は15%です。濁っているほど、水底と水の中の駒が見えにくくなります。100%にすると、水の中はまったく見えません       |
| 汚れ               | 0〜100%で、水面に浮くよごれの量です                                                                                            |
| 浮き葉             | 0〜100%で、水面を覆う葉の量です                                                                                                |
| 流れの速さ         | 0〜100%で、0にすると止まった水です。速くするほど、水面の筋と浮いているものが速く流れます                                       |
| 流れの向き         | 上・右上・右・右下・下・左下・左・左上の8方向から選びます                                                                      |

見た目を選んだあとで濁りや色を変えると、見た目は「自分で調整」になります。

## 水底と岸

水の底は、水域の床とその下にある地形のうち、高いほうです。地形が水面まで届いているマスは陸になり、その縁に波が打ち寄せます。

水面の色は、マスごとの深さで変わります。浅いところは底が透け、深いところほど水の色が濃くなります。傾いた地形の上に、水面を高くした水域を置くと、浜から深みへ続く海辺になります。

水の側面は、隣にある地形の高さまで下りて描かれます。下の地形が傾いていれば、側面の下の縁も傾きに沿って斜めになります。

暗闇のある卓では、水面も、マスごとの明るさに合わせて暗くなります。暗闇の設定は[暗闇・視界・光源](/manual/vision-lighting)にあります。

## 水の中の駒

足元が水面より低い駒は、水面から下が水ごしに見えるように描かれます。深く沈んでいるほど、また水が濁っているほど薄れていきます。駒が水面を切るところには、波紋が広がります。水面より高い岩の上に立つ駒や、宙に浮いている駒は濡れません。

泳ぐ・浮かぶといった決まりはありません。水面に浮かべたい駒は、駒の高度を水面に合わせてください。水を渡るのにかかる手間は、[マップエディターで塗る](#マップエディターで水を塗る)ときの通りにくさで決めます。

## 天候「水中」

テーブル設定の[天候](/manual/table-setting#天候-マップ全体)で「水中」を選ぶと、卓全体が水の中になります。遠くほど水の色が濃くなり、上から光が差し込み、細かな粒が漂います。床には深みの色が敷かれ、その上を光の網が揺れます。

## ダンジョンドリィマスターモードで見る

[ダンジョンドリィマスターモード](/manual/dungeondry-master)でも、水域は水面の上からも中からも描かれます。

目が水の中に入ると、濁りに応じて見通せる距離が縮みます。澄んだ水ではおよそ31マス先まで見え、濁り100%では1マス先も見えません。見通せる距離より先にあるものは、水の色に沈みます。流れのある水では、漂う粒が流れに運ばれて目の前を横切ります。

天候「水中」のときは、天候の濃さを濁りとして扱います。

## マップエディターで水を塗る

[マップエディター](/manual/map-editor#危険地帯塗り-—-毒沼を一筆で置く)の機能塗りで、危険地帯の種類に「水（水面の高さまで浸かる）」を選ぶと、水を塗れます。塗るときに、見た目・色・水面の高さ・濁り・汚れ・浮き葉・流れの速さ・流れの向きを決められます。

卓に反映すると、塗ったところに水域と移動コストが置かれます。通りにくさは既定で+1マスです。ほかの値や「ふつう（置かない）」も選べます。水に入っても、ダメージや状態異常は起きません。

## 古い版を使っている参加者がいるとき

古い版の画面では、水域は毒沼として描かれ、天候「水中」は何も描かれません。

# 情報の公開範囲

このページは、キャラクター・[共有メモ](/manual/notes)・[カード](/manual/cards)・[ダイス](/manual/dice)の中身を「誰に見せるか」を決める公開範囲と、物の持ち主（オーナー）を説明します。
GMが用意したNPCや資料を、必要なときに必要な相手にだけ見せる、ハンドアウトのような使いかたができます。
公開範囲を変えられるのは、GMと、その物のオーナーです。

## 3つの公開範囲

<DisclosureMatrix />

GMとその物のオーナーは、公開範囲にかかわらず、いつでも中身を見られます。
公開範囲は[ロール](/manual/roles)と組み合わせて働き、部屋の全員に伝わります。

::: info 公開範囲で隠れるもの
SkyWay版では、公開範囲は画面の上の取り決めで、中身は参加者全員のブラウザに届いています。
[部屋のサーバー（ベータ）](/guide/choose)では、公開範囲を絞った共有メモの題と本文は、見てよい人のブラウザにしか届きません。
キャラクター・カード・ダイスの、公開範囲で絞った詳細は、部屋のサーバーでも全員に届きます（画面には出しません）。
:::

## 公開範囲を変える

| 誰が             | 変えられるもの                                   |
| ---------------- | ------------------------------------------------ |
| GM               | すべての物の公開範囲とオーナー                   |
| その物のオーナー | 公開範囲。シートからなら、オーナーも変えられます |
| PL               | オーナーのいない物を、自分のものにすること       |
| 見学             | 変えられません                                   |

### シートから変える

1. キャラクターは右クリックして**詳細を表示**を、共有メモは右クリックして**メモを編集**を押し、詳細（シート）を開きます。
2. 上のほうの**公開範囲**で、**全員**・**特定PL**・**GMのみ**のどれかを押します。
3. **特定PL**を選んだときは、接続している参加者の一覧が出るので、見せたい相手にチェックを入れます。

**オーナー**の欄で、持ち主を選べます。
この欄は、GMとその物のオーナーに出ます。
誰も持っていない物なら、PLにも出て、自分のものにできます。

### 右クリックのメニューから変える

1. キャラクターや共有メモを右クリックします。キャラクターでは**公開とオーナー**のグループの中、共有メモではメニューの中ほどに**公開範囲**があります。
2. **公開範囲**から、**全員**・**特定PL**・**GMのみ**のどれかを選びます。**特定PL**では、その中から見せたい相手にチェックを入れます。
3. 持ち主を変えるときは、**オーナー**から**なし**か参加者を選びます。

いまの選択には`☑`が付きます。
**オーナー**は、GMにはいつも出ます。
PLには、誰も持っていない物にだけ出て、自分のものにできます。

### まとめて切り替える

テーブルでコマを選んで`G`キーを押すと、選んだキャラクター・カード・ダイス・共有メモの公開範囲を、まとめて「全員」か「GMのみ」に切り替えます。
切り替えかたは[キー操作の一覧](/manual/shortcuts#gで公開範囲を切り替える)にあります。
複数のコマの選びかたは、[オブジェクトの基本操作](/manual/objects#select)にあります。

## 作ったときの公開範囲

| 作った人・物                                       | 公開範囲の初期値 |
| -------------------------------------------------- | ---------------- |
| GMが作ったキャラクターと共有メモ                   | GMのみ           |
| GM以外の人が作った物                               | 全員             |
| 公開範囲がなかったころに作った物（古い保存データ） | 全員             |

GMが作った物は、準備が整ったら、公開範囲を「全員」や「特定PL」に変えて見せます。

## 公開範囲の外の人からの見えかた

公開範囲に入っていない人からは、物があることは分かるが、中身は見えない状態になります。
テーブルから消えるわけではありません。

| 物                           | 見えるもの・できること                                     | 見えないもの・できないこと                                                                                                                                                                     |
| ---------------------------- | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| キャラクター・カード・ダイス | コマそのもの。ドラッグで動かすこと。リソースバーの伸び具合 | 詳細のウィンドウ・マウスを乗せたときのプレビュー・[リモコン](/manual/character)・[チャットパレット](/manual/chat-palette)・[バフの編集](/manual/buff)。リソースバーの数字は`???/???`になります |
| 共有メモ                     | メモがテーブルにあること                                   | 題と本文（伏せ字とぼかしで読めません）                                                                                                                                                         |
| インベントリ                 | 行（名前と🔒）                                             | データと操作                                                                                                                                                                                   |

右クリックのメニューにも、できない操作は出ません。
別のキャラクターのリモコンからも、公開範囲の外のキャラクターのデータは見えません。
リソースバーの伸び具合はそのままなので、残りの多い少ないはテーブルの向こうからでも見当が付きます。
隠れるのは、書き留められる数字のほうです。

::: tip 名前を隠す・シークレットとの違い
キャラクターの「名前を隠す」や、シークレットダイス・シークレットチャットは、GMだけが見られる仕組みです。
公開範囲では、そこに、特定のPLにだけ見せるという選びかたが加わります。
:::

## オーナー

物には、オーナー（持ち主）を付けられます。
オーナーになっているPLは、自分のキャラクターやメモの公開範囲を、自分で変えられます。

- キャラクターや共有メモを作ると、作った人が自動でオーナーになります
- オーナーを割り当てたり変えたりするのは、GMです。オーナーになっているPLも、シートからオーナーを変えられます
- オーナーのいない物は、PLが自分のものにできます
- [保存データを読み込んだ直後](/manual/save-load#zip読込)は、すべての物のオーナーが外れるので、各自が自分のコマを取り直せます。公開範囲を「特定PL」にしていた物は、選んでいた相手も外れます。[前回の卓を復元](/manual/save-load#前回の卓を復元する)したときも同じです

::: tip 入り直した人のオーナーがずれたとき
PLが一度部屋を出て入り直すと、内部のIDが変わり、前のコマのオーナーが「いない持ち主」のまま残ることがあります。
GMツールバーの**オフラインの所有を解放**を押すと、接続していないオーナーの所有だけがまとめて外れ、戻ってきた人が取り直せます。
接続している人の所有は、そのままです。
:::

### 部屋のサーバーでのオーナー

[部屋のサーバー（ベータ）](/guide/choose)では、オーナーの扱いが次のように変わります。

| 物           | 自分のものにできる人                                                                                                                                                             |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 共有メモ     | 中身が見える人だけ。オーナーになると隠れた中身も見えるので、「GMのみ」のメモや、自分が選ばれていないメモは取れません                                                             |
| キャラクター | SkyWay版と同じく、オーナーのいない物は誰でも。PLに取らせたくないキャラクターは、GMが自分をオーナーにしておきます                                                                 |
| ダイス       | オーナーは「自分だけ見ている人」です。GMがオーナーのダイスは、PLから出目と名前が隠れます                                                                                         |
| カード       | GMがオーナーでも、ほかの人が「表にする」「自分だけ見る」「手札に加える」で取れます（SkyWay版と同じ）。山札の中のカードにオーナーを付けられるのはGMだけで、引いたカードは取れます |

保存データの読み込みや復元をすると、ダイスとカードのオーナーも外れるので、そのあとで付け直します。

ログインしていない見学の人は、見せる相手にも、オーナーにも、秘話の相手にも選べません。
その人のIDは、ほかの人でも名乗れるためです。
選ぶ一覧には「ログインしていない人は選べません」と出ます。

## うまくいかないとき

| 見えるもの                                           | 原因と直しかた                                                                                                   |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **公開範囲**の項目が出ない                           | GMでもオーナーでもありません。GMにオーナーにしてもらうか、公開範囲を変えてもらいます                             |
| **特定PL**の一覧に、見せたい人が出ない               | その人がまだ部屋に入っていません。入ってから選びます。部屋のサーバーでは、ログインしていない見学の人は選べません |
| 「他の参加者がいません」                             | 部屋にほかの参加者がいません。部屋に入ってから選びます                                                           |
| 入り直したら、自分のコマを操作できない               | オーナーが前のIDのまま残っています。GMが**オフラインの所有を解放**を押し、自分のコマを取り直します               |
| 保存データを読み込んだら、誰のコマか分からなくなった | 読み込むとオーナーが外れます。各自が、右クリックの**オーナー**から自分のものにします                             |

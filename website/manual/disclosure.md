# 情報の公開範囲

キャラクター・[共有メモ](/manual/notes)・[カード](/manual/cards)・[ダイス](/manual/dice)には、**「誰に見せるか」** を表す公開範囲を設定できます。GMが用意したNPCや手元の情報を、必要なときに必要な相手だけへ開示する、いわゆるハンドアウトのような使い方ができます。

公開範囲は[ロール](/manual/roles)と組み合わせて働きます。設定は参加者全員で同期されます。

## 3つの公開範囲

<DisclosureMatrix />

GMとオブジェクトの**オーナー**は、公開範囲に関わらず常に閲覧できます。

::: info 公開範囲で隠れるもの
SkyWay版では、公開範囲は画面の上の取り決めで、中身は参加者全員のブラウザに届いています。
[部屋のサーバー（ベータ）](/guide/backend#room-server)では、公開範囲を絞った共有メモの題と本文は、見てよい人のブラウザにしか届きません。キャラクター・カード・ダイスの、公開範囲で絞った詳細は、部屋のサーバーでも全員に届きます（画面には出しません）。
:::

## オーナー

各オブジェクトには**オーナー（持ち主）** を設定できます。オーナーになっているプレイヤーは、自分のキャラクター／メモなどの公開範囲を自分で変更できます。

- キャラクターや共有メモを作成すると、**作成した人が自動的にオーナー**になります。
- **オーナーの割り当て・変更はGMが行います**（後述のコンテキストメニュー、またはシートから）。
- オーナーのいない（無主の）オブジェクトは、**プレイヤーが自分で取得**（クレーム）できます。[保存データを読み込んだ直後](/manual/save-load#zip読込)は全オブジェクトが無主になるので、各自が自分のコマを取り直せます。公開範囲を「特定PL」にしていたものは、選んだ人も外れます。[前回の卓を復元](/manual/save-load#前回の卓を復元する)したときも同じです。
- [部屋のサーバー（ベータ）](/guide/backend#room-server)では、共有メモを取得できるのは中身が見える人だけです。オーナーになると隠れた中身も見えるので、「GMのみ」にしたメモや、自分が選ばれていないメモは取得できません。キャラクター・ダイス・カードはSkyWay版と同じく取得できるので、プレイヤーに取らせたくないものは、GMが自分をオーナーにしておいてください。保存データの読み込みや復元をするとこのオーナーも外れるので、そのあとで付け直します。

::: tip 途中参加・復帰でオーナーが噛み合わないとき
プレイヤーが一度退室して入り直すと内部IDが変わり、以前のコマのオーナーが「不在の持ち主」のまま残ることがあります。GMツールバーの **「オフラインの所有を解放」** を押すと、接続していないオーナーの所有だけがまとめて解除され、復帰した人が取り直せます（接続中の人の所有はそのまま）。
:::

## 設定のしかた

公開範囲とオーナーは、**シートパネル**と**コンテキストメニュー**のどちらからでも設定できます（設定できるのはGMです。公開範囲は、そのオブジェクトのオーナーも設定できます）。

[部屋のサーバー（ベータ）](/guide/backend#room-server)では、ログインしていない見学の人は、見せる相手にもオーナーにも、秘話の相手にも選べません。その人のIDは、ほかの人でも名乗れるためです。

### シートから

キャラクターやメモの詳細（シート）を開くと、上部に**公開範囲**のコントロールが表示されます。

- `全員 / 特定PL / GMのみ`を選びます。
- **特定PL**を選ぶと、接続中の参加者の一覧が表示されるので、見せたい相手にチェックを付けます。
- **オーナー**の欄（GMのみ表示）で持ち主を選べます。

### コンテキストメニューから

キャラクターや共有メモを右クリックすると、**公開範囲**の項目が出ます。キャラクターでは**公開とオーナー**のグループの中、共有メモではメニューの中ほどにあります。

- **公開範囲** → `全員 / 特定PL ▸ / GMのみ`。`特定PL ▸`の中から見せたい相手をチェックします。
- **オーナー**（GMのみ）→ `なし`または参加者を選んで持ち主を割り当てます。
- 現在の選択には`☑`が付きます。

### まとめて切り替える

卓でコマを選んで`G`キーを押すと、選んだキャラクター・カード・ダイス・共有メモの公開範囲をまとめて切り替えます。選んだ中に「全員」でないものが1つでもあれば全部を「全員」にし、全部が「全員」なら「GMのみ」に戻します。「特定PL」には切り替えません。公開範囲を変えられないコマは数えません。複数のコマの選び方は[オブジェクトの基本操作](/manual/objects#複数選択・一括操作)にあります。

## 作成したときの初期値

- **GMが作成したキャラクター・共有メモは、初期状態が「GMのみ」** になります。準備が整ったら公開範囲を「全員」や「特定PL」に変えて開示します。
- それ以外の人が作成したものや、以前のデータは「全員」（公開）です。

## 公開範囲外の人からの見え方

公開範囲に含まれない参加者からは、**存在は分かるが中身は確認できない**状態になります。完全に消えるわけではありません。

### キャラクター・カード・ダイス

- コマ自体は卓上に表示され、**ドラッグでの移動はできます**。
- 詳細ウィンドウ・マウスオーバーのプレビュー・[リモコン](/manual/character)・[チャットパレット](/manual/chat-palette)・[バフ編集](/manual/buff)は開けません。
- 右クリックメニューにも、できない操作は表示されません。
- 別のキャラクターのリモコンからも、非公開キャラクターのデータは確認できません。
- [インベントリ](/manual/inventory)には行（名前と 🔒）だけが並び、データや操作は見えません。
- コマの上に出る**リソースバーの数字が`???/???`になります**。バーの伸び具合はそのままなので、残りの
  多い少ないは卓の向こうからでも見当が付きます。隠れるのは書き留められる数字のほうです。

### 共有メモ

- メモは卓上に残りますが、**本文とタイトルがモザイク（伏字＋ぼかし）** になり、何が書いてあるか読めません。

::: tip 隠し名・シークレットとの違い
キャラクターの「名前を隠す」やシークレットダイス／チャットはGMだけが見られる従来の仕組みです。公開範囲では、そこに**特定のプレイヤーにだけ見せる**という選び方が加わります。
:::

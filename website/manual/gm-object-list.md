# オブジェクト一覧（GM）

テーブル上のすべてのオブジェクトを一覧で確認・管理できる **GM 専用ツール**です。隠したコマや別エリア・壁面・隙間に紛れたオブジェクトもまとめて把握でき、その場から操作できます。

<Shot src="gm-object-list" alt="オブジェクト一覧。キャラクターが行ごとに並び、種類で絞り込むタブがある" caption="卓上の全オブジェクトを種類で絞り込んで一覧できます" />

[GM ツールバー](/manual/roles#gm-ツールバー)の **オブジェクト一覧** から開きます。ツールバーは[ロール](/manual/roles)が **ゲームマスター（GM）** のときだけ表示されます。

## 一覧に表示されるもの

次の種類を、**すべての場所を横断して**一覧します。

- キャラクター / カード / 山札 / ダイス / [共有メモ](/manual/notes) / [地形](/manual/terrain) / [射程範囲](/manual/range)
- 場所は **卓上・共通・墓場・個人・各サーフェス（床／壁）** をまたいで表示します。

各行のアイコンは、わかりやすいよう**実際の見た目**を使います。

- キャラクター … コマ画像
- カード … 表（中身）の画像
- 地形 … テーブルでの見え方（壁／床の画像）
- ダイス … 現在の出目の画像
- カスタム射程範囲 … セル形状のミニ図形
- それ以外・画像が無いものは種類アイコン

各行には **名前**、**場所（＋サーフェス）**、**公開範囲**、**オーナー**、固定（🔒）・インベントリ非表示の状態が並びます。

## 探す・絞り込む

- 上部の検索ボックスで **名前・オーナー名**で絞り込めます。
- 種類のチップで、表示する種類を切り替えられます。
- 検索ボックス右の数字は **「表示中の件数 / 全体の件数」** です。絞り込みの結果がひと目でわかります。

## 行から操作する（右クリック / ⋮）

各行の **⋮** ボタンまたは右クリックで、そのオブジェクトを直接操作できます。

- **フォーカス** — 卓上のオブジェクトを画面中央に表示します（行クリックでも実行）。卓上にあるオブジェクトのみ対象です（共通・墓場・個人にあるものは、先に「移動 → 卓上へ」で取り出します）。
- **詳細を表示** — シート／詳細を開きます。
- **移動** — 卓上へ / 共通へ / 墓場へ。
- **別の面へ移動** — 床・各壁のサーフェスへ移します（移動先に出るのは、テーブルで**表示中の壁**だけです）。
- **公開範囲 / オーナー** — [情報の公開範囲](/manual/disclosure)を設定します。
- **固定 / コピー / 削除**。

## サーフェスと座標を直接指定する

各行の **位置編集**ボタン（ピンのアイコン）を押すと、その場で

- **サーフェス**（床／表示中の壁）
- **X・Y 座標**

を直接設定できます。隙間に落ちて見つからないオブジェクトを、床へ戻して任意の座標に置き直す、といった復旧に使えます。

## 複数のコマの視界をまとめて設定する

キャラクターの行にはチェックボックスが付きます。チェックを入れたコマの**視界**を、一度の操作で設定できます。暗闇の卓を用意するとき、敵 20 体に暗視を配る、といった場面で使います。

1. 一覧でキャラクターにチェックを入れます。ひとつも入っていないときは **「表示中をすべて選択」** が出るので、絞り込んだ結果をまとめて選べます。
2. 上部に出るバーの **「視界を一括設定」** を押します。
3. 開いたパネルで値を変えると、チェックした全員に同じ値が入ります。

パネルの中身はコマ 1 体の[視界設定](/manual/vision-lighting)と同じで、光源の項目だけ出ません。

**触った項目だけが書き換わります。** 開いただけ、あるいは視界タイプだけを変えたなら、視界距離は各コマの値のまま残ります。全員を同じ設定に揃えたいときは、揃えたい項目を一度ずつ触ってください。

表示される初期値は、チェックしたうちの先頭のコマのものです。チェックしたコマどうしで設定が食い違っている場合は、バーに **「設定が揃っていません」** と表示されます。

::: tip チェックは絞り込みをまたいで残ります
検索語や種類のタブを切り替えても、チェックは外れません。「ゴブリン」で絞って選び、続けて「オーク」で絞って選び、最後にまとめて設定する、という進め方ができます。卓から消えたコマのチェックは自動的に外れます。
:::

::: tip 紛失オブジェクトの復旧
「保存前のセッションで隙間に落ちて見失った」ようなオブジェクトも、この一覧には必ず表示されます。**位置編集**で床・座標を指定するか、**移動 → 卓上へ**で取り出してから **フォーカス**すると見つけられます。
:::

::: tip 壁面の光源・コマもまとめて管理
[暗闇・視界・光源](/manual/vision-lighting)で壁に貼り付けた光源やコマも、この一覧に**サーフェス付き**で表示されます。どの壁にいくつ光源を置いたか把握したり、**別の面へ移動**・**位置編集**で配置をまとめて整えるのに便利です。
:::

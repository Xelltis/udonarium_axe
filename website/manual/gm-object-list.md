# オブジェクト一覧（GM）

このページは、テーブルの上の物をすべて一覧で見て、その場で直せるGMだけの道具を説明します。
隠したコマや、別の場所・壁面・隙間に紛れた物もまとめて見つけられ、そこから動かしたり、視界をまとめて設定したりできます。
使えるのはGMだけです。

<Shot src="gm-object-list" alt="オブジェクト一覧。キャラクターが行ごとに並び、種類で絞り込むタブがある" caption="テーブルの上の物を、種類で絞り込んで一覧できます" />

## 開く

[GMツールバー](/manual/roles#gmツールバー)の**オブジェクト一覧**を押します。
スマートフォン版の画面では、**メニュー**の**オブジェクト**から開きます。

GMでないときに開くと、「このツールはゲームマスター専用です」と出ます。

## 一覧に出るもの

次の物を、場所をまたいで一覧します。

| 項目 | 内容                                                                                                                                            |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 種類 | キャラクター・カード・山札・ダイス・コイン・[共有メモ](/manual/notes)・[地形](/manual/terrain)・[射程範囲](/manual/range)・光源・環境エフェクト |
| 場所 | 卓上・共通・墓場・個人（各参加者）・その他。卓上の物は、床と壁のどの面（サーフェス）にいるかも出ます                                            |

各行には、名前・場所（とサーフェス）・公開範囲・オーナーと、固定（🔒）・インベントリ非表示の状態が並びます。

行のアイコンには、見分けやすいように実際の見た目を使います。

| 種類                   | アイコン                             |
| ---------------------- | ------------------------------------ |
| キャラクター           | コマの画像                           |
| カード                 | 表の画像                             |
| 地形                   | テーブルでの見えかた（壁と床の画像） |
| ダイス                 | いまの出目の画像                     |
| マスで描いた射程範囲   | マスの形の小さな図                   |
| それ以外・画像がない物 | 種類のアイコン                       |

## 探す・絞り込む

- 上の検索欄（「名前・オーナーで検索」）に入れると、名前とオーナーの名前で絞り込めます
- 種類のチップで、出す種類を切り替えます
- 検索欄の右の数字は、「出ている件数 / 全体の件数」です

当てはまる物がないときは、「該当するオブジェクトがありません」と出ます。

## 行から操作する

各行の **⋮** のボタンか右クリックで、その物を直接操作します。

| 項目                   | すること                                                                                                                           |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| フォーカス             | テーブルの上の物を、画面の中央に映します。行を押しても同じです。共通・墓場・個人にある物は、先に**移動**の**卓上へ**で取り出します |
| 詳細を表示             | シートや詳細を開きます                                                                                                             |
| 移動                   | **卓上へ**・**共通へ**・**墓場へ**のどれかに移します                                                                               |
| 別の面へ移動           | 床や壁の面（サーフェス）へ移します。移す先に出るのは、テーブルで表示している壁だけです                                             |
| 公開範囲・オーナー     | [情報の公開範囲](/manual/disclosure)を変えます                                                                                     |
| NPCバーに登録          | キャラクターをGMツールバーのNPCバーに並べます。**NPC登録を解除**で外します                                                         |
| 固定・コピー・削除する | 物を固定する・複製する・消す                                                                                                       |

### サーフェスと座標を直接決める

各行の**サーフェス・座標を編集**のボタン（ピンのアイコン）を押すと、次の2つをその場で決められます。

- サーフェス（床か、表示している壁）
- X座標とY座標

隙間に落ちて見つからない物を、床に戻して好きな座標に置き直す、といった復旧に使います。

## 複数のコマの視界をまとめて決める

キャラクターの行には、チェックボックスが付きます。
チェックを入れたコマの視界を、1回の操作で決められます。
暗闇のテーブルを用意するときに、敵20体に暗視を配る、といった場面で使います。

1. 一覧で、キャラクターにチェックを入れます。1つも入っていないときは**表示中をすべて選択**が出るので、絞り込んだ結果をまとめて選べます。
2. 上に出るバーの**視界を一括設定**を押します。
3. 開いたパネルで値を変えます。チェックした全員に、同じ値が入ります。

パネルの中身は、コマ1体の[視界の設定](/manual/vision-lighting)と同じで、光源の項目だけが出ません。

::: warning 触った項目だけが書き換わります
開いただけのときや、視界のタイプだけを変えたときは、視界の距離は各コマの値のまま残ります。
全員を同じ設定にそろえたいときは、そろえたい項目を一度ずつ触ってください。
:::

パネルに出る値は、チェックしたうちの先頭のコマのものです。
チェックしたコマどうしで設定が食い違っているときは、バーに「設定が揃っていません」と出ます。
**選択を解除**で、チェックをまとめて外せます。

::: tip チェックは、絞り込みを変えても残ります
検索語や種類のタブを切り替えても、チェックは外れません。
「ゴブリン」で絞って選び、続けて「オーク」で絞って選び、最後にまとめて決める、という進めかたができます。
テーブルから消えたコマのチェックは、自動で外れます。
:::

## 壁面の光源とコマ

[暗闇・視界・光源](/manual/vision-lighting)で壁に貼り付けた光源やコマも、この一覧にサーフェス付きで出ます。
どの壁にいくつ光源を置いたかを確かめたり、**別の面へ移動**と**サーフェス・座標を編集**で、置き場所をまとめて整えたりできます。

## うまくいかないとき

| 見えるもの                                 | 原因と直しかた                                                                                                                                         |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| テーブルで見つからない物がある             | この一覧には、隙間に落ちた物も必ず出ます。**サーフェス・座標を編集**で床と座標を決めるか、**移動**の**卓上へ**で取り出してから**フォーカス**を押します |
| **フォーカス**を押しても映らない           | その物は、共通・墓場・個人にあります。**移動**の**卓上へ**で取り出してから押します                                                                     |
| **別の面へ移動**に、移したい壁が出ない     | その壁がテーブルで表示されていません。テーブル設定で壁を表示してから選びます                                                                           |
| 視界をまとめて変えたのに、距離が変わらない | 触った項目だけが書き換わります。距離の欄を一度触ってから値を入れます                                                                                   |
| 「このツールはゲームマスター専用です」     | GMではありません。接続パネルで役割を確かめます                                                                                                         |

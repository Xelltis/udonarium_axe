# ホワイトボード

その場で絵や図を描いて卓に立てるボードです。手描きの線、図形、文字、画像を重ねられます。コマを乗せることもできます。

テーブルの何もない場所を右クリックし、「ホワイトボードを作成」を選びます。**立った状態でマップの北へ1マス離して**置かれ、大きさはテーブルと同じです。2枚目からは1枚目の横に並びます。

## 描く

ボードを右クリックして **「ボードに書く」** を選ぶと、描画パネルが開きます。

### 道具

| 道具            | できること                                                    |
| --------------- | ------------------------------------------------------------- |
| 選択            | 掴んで動かす・大きさを変える・回す                            |
| 手のひら        | シートを滑らせる（タッチ環境ではこれが唯一の手段）            |
| ペン / マーカー | 手描きの線。マーカーは下が透ける                              |
| 消しゴム        | なぞったところだけ消す。線は残りが2本になる                   |
| 直線 / 矢印     | 2点を結ぶ                                                     |
| 図形            | 四角・円・三角・五角・六角・星・**吹き出し**                  |
| 折れ線          | 点を置いていって、ダブルクリックかEnterで確定。曲線にもできる |
| 文字 / ふせん   | シートに直接書く。ふせんは色のついた台紙つき                  |
| ステッカー      | 画像保管庫から貼る                                            |

### 文字の装飾

文字には**縁取り・影・下線・取り消し線**をつけられます。縁取りの太さは字の大きさに対する割合なので、拡大縮小しても比率が変わりません。

書いている最中の入力欄にも装飾がそのまま乗るので、確定してから違ったということが起きません。既存の文字をダブルクリックすると、装飾ごと引き継いで打ち直せます。

### 画像を貼る

- **クリップボードから貼り付け** — 切り取った画像をそのまま貼れます
- **原寸で入ります** — シートに収まらない画像だけ、収まる大きさまで縮みます
- **切り抜き・反転・不透明度** — 貼ったあとに調整できます。薄くして下敷きにもできます
- **動く画像はそのまま動きます** — APNG・GIF・アニメーションWebPは、卓に立てたボードの上でも動きます

### そろえる

複数を選んでいるときだけ、2段目のツールバーが出ます。

- **整列** — 左揃え / 左右中央 / 右揃え、上揃え / 上下中央 / 下揃え
- **等間隔** — 横に等間隔 / 縦に等間隔
- **シートの左右中央へ / シートの上下中央へ** — 選択物をひとかたまりのまま用紙の中心に置く（1つでも使えます）

「整列」は選択物どうしを揃えるもので、「シートの◯◯中央へ」は用紙に対して置くものです。別の操作なので使い分けてください。

### ガイド

方眼のオン・オフに関わらず、**整列ガイド**が出ます。動かしているものが他のものの辺や中心に近づくと吸着し、揃えた2つに届く長さだけ線が描かれます。用紙の中心線は常にあります。

上と左には**定規**があり、そこからドラッグすると**ガイド線**を引けます。ガイド線はボードに保存され、掴んで動かせます。

図形を引くときも同じガイドに乗ります。Shiftを押しながらだと直線・矢印・折れ線が45度刻みになります。

### レイヤー

右の欄がレイヤーです。作業中のレイヤーだけ2段目の操作が出ます。

- 1段目 — 表示 / 固定 / **名前** / 前面へ / 背面へ
- 2段目 — 不透明度 / グループ / このレイヤーを消去 / 削除

名前は直接編集できます。空にすると種別名に戻ります。グループでまとめられます。

### 書き出し

**画像として保存**で、ボード全体をPNGで書き出せます。方眼・ガイド・選択枠は写りません。

### 動く画像の扱い

卓の上のボードに表示されているのは、描いたものを1枚に焼いた絵です。焼いた絵は止まっているので、**動く画像だけは焼かずに、絵の上へ重ねて貼っています**。位置も大きさも回転も焼いた場合と同じところに出ます。

- 動く画像は焼いた絵の前に出るので、重ねて貼ると上の書き込みを覆ってしまいます。そのため、**その画像より上に何か描かれているときは重ね貼りをやめて焼き込みます**。動かしたい画像は、いちばん上のレイヤーに置いてください
- **切り抜き**を入れた画像と、**セルに合わせて切る**を入れた画像は焼いたままです（この2つは重ね貼りでは再現できないため）。動かしたい画像には切り抜きを使わないでください
- **画像として保存**で書き出すPNGは1枚の静止画なので、動く画像もその瞬間の1コマになります

## ボードの設定

描画パネルの中にまとまっています。

- **大きさ・傾き・向き** — 傾きを変えても手前に寄ってきません
- **色** — 板そのものの色
- **板を透過する** — 板を消して、描いたものだけが宙に浮きます。地図の上に図を重ねたいときに使います。元の色は覚えているので、戻せば色も戻ります
- **影を落とす**

::: tip 透過中の市松模様
描画パネルのシートの下には市松模様が敷かれます。「そこには何も無い」ことを示す編集画面だけの表示で、テーブル上のボードには出ません。
:::

## 回す

ボードは地形と同じ操作感で回せます。ロックしていなければ、**ボードの足元**（テーブルに接している部分）にカーソルを近づけるとつまみが出るので、それを掴んで回します。

## 乗せる

コマ・地形・カード・ふせん・ダイスをボードへドラッグすると、ボードの上に乗ります。乗ったものはボードと一緒に動き、傾けば一緒に傾きます。

まとめて降ろすには、ボードを右クリックして **「載っているものを降ろす」** を選びます。見えていた位置のままテーブルへ戻ります。

## ポップアップと拡大表示

テーブルのボードにマウスを乗せると、ポップアップにボードの絵と名前が出ます。絵は、ボードを傾きや向きによらず正面から見たものです。板の色、描いたもの、動く画像が入り、動く画像はここでも動きます。ボードに乗せたコマやカードは入りません。

絵の左下にある虫眼鏡のボタン（拡大して見る）を押すと、ボードの絵が画面いっぱいに広がります。カードを拡大するときと同じ表示で、どこかをクリックすると閉じます。

## 保存

ボードを右クリックして **「このボードを保存」** を選ぶと、ボード1枚をzipで書き出せます。描いた内容と、貼った画像も一緒に入ります。

乗っているコマは含まれません。ボードの上にあっても部屋のコマが置かれているだけなので、必要なら個別に保存してください。

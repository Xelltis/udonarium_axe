# アラーム

このページは、決めた秒数がたつと、選んだ参加者の画面で鳴るタイマー（アラーム）を説明します。
休憩の終わりや、戦闘のラウンドの持ち時間を知らせるのに使います。
GMとPLがセットできます。部屋のサーバーでは、見学はセットできません。

## セットする

1. チャットウィンドウの上の**アラーム**（鈴のアイコン）を押します。**アラームタイマ**のパネルが開きます。
2. タイトルと時間を決めます。
3. 知らせる相手にチェックを入れます。
4. **セット**を押します。

チャットに「アラームセット N秒」と、知らせる相手が出て、数えはじめます。
全員に知らせるときは、相手の代わりに「全員」と出ます。
時間がたつと、相手の画面で音が鳴り、知らせのポップアップが出ます。

| 項目         | 内容                                        | 既定値 |
| ------------ | ------------------------------------------- | ------ |
| タイトル     | アラームの名前（例：`戦闘ラウンド`）        | タイマ |
| 時間         | 何秒後に鳴らすか。0〜3600秒                 | 60     |
| 音           | 時間がたったときに音を鳴らします            | 入り   |
| ポップアップ | 時間がたったときに知らせを出します          | 入り   |
| 自分を含める | 自分の画面でも鳴らします                    | 入り   |
| 知らせる相手 | 部屋のほかの参加者に、1人ずつチェックします | 全員   |

パネルの下に、知らせる人数が「対象 N人」と出ます。

## うまくいかないとき

| 見えるもの                 | 原因と直しかた                                                                               |
| -------------------------- | -------------------------------------------------------------------------------------------- |
| **セット**が押せない       | 知らせる相手が0人です。**自分を含める**を入れるか、相手にチェックを入れます                  |
| 「自分しか部屋にいません」 | 部屋にほかの参加者がいません。自分にだけ鳴らすときは、**自分を含める**を入れます             |
| 時間がたっても音が鳴らない | **音**が外れているか、自分の[音の設定](/manual/sound-settings)で**通知音**を小さくしています |
| セットしても始まらない     | 部屋のサーバーの見学は、アラームを始められません                                             |

# 暗闇・視界・光源

テーブルを暗くして、キャラクターの視界と光源で照らされた範囲だけを見せる演出ができます。
ダンジョン探索やホラーセッションなど、「見えている範囲」を制御したい場面に使います。

<Shot src="darkness" alt="暗闇をオンにしたテーブル。光の届く範囲だけが明るい" caption="暗闇をオンにすると、視界と光源の届く範囲だけが見えます" />

おおまかな流れは次のとおりです。

1. **テーブル設定**で暗闇を有効化し、暗さや環境光を決める
2. 各**キャラクターに視界**（暗視・真視など）を持たせる
3. **たいまつなどの光源**を置いて、照らされる範囲をつくる

## テーブル全体の暗闇設定

FAB メニューの **テーブル関連 → テーブル設定** の中、**「暗闇（視界・照明）」** セクションで設定します。テーブルごとに保存され、参加者間で同期されます。

- **暗闇を有効化** — 暗闇システムの ON / OFF。OFF のときは従来どおり全体が明るく見えます
- **暗さ** — 暗闇の濃さ。高いほど、照らされていない場所が暗くなります
- **環境光** — 全体に薄く当たる最低限の明るさ。0 にすると光源の無い場所は真っ暗になります
- **暗闇の色** — 暗部の色味（夜＝紺、洞窟＝黒、など）
- **照明をマス目に沿わせる** — 照らされた範囲を **マス単位** に丸めます。四角マスなら正方形、ヘクスなら六角形の縁になり、「このマスは明るいのか」を目で数えられます。暗闇が有効なときだけ表示されます
- **壁の高さ** — 外周の壁・地形の壁の高さ（マス単位）。光や影の立体的な見え方に影響します

### 外周の壁

テーブル設定の **「壁」** で、四方（**北壁 / 東壁 / 南壁 / 西壁**）の表示と壁画像を個別に設定できます。
壁を表示した辺は光を遮り、表示していない辺は光がマップの外へ漏れて広がります。

## キャラクターの視界

キャラクターを**右クリック → 「視界・光源設定…」** を開き、**「視界」** セクションで設定します。

- **視界タイプ**
  - **通常視界** — 光源に照らされた範囲だけが見える
  - **暗視** — 視界範囲内なら、暗い場所も見える
  - **真視** — 視界範囲内なら、**壁などの遮蔽を無視して**見通せる
  - **盲目** — 何も見えない
  - **熱視界** — 視界範囲内を、熱を示す色味で見る
- **視界範囲(マス)** — そのコマが自力で見通せる距離。0 なら制限なしです
- **視界の形** — 見える範囲の形。既定は全方位の**ドーム**です
- **光を遮り影を落とす** — この駒が光をさえぎり、地面に影を落とす（既定でオン）
- **視界範囲を表示** — そのコマの視界の形を盤上に線で描きます

視界の形は 6 種類あります。ドーム以外は**コマの向き**を基準にするので、コマを回すと一緒に回ります。

| 形             | 見える範囲                                      |
| -------------- | ----------------------------------------------- |
| ドーム         | 全方位                                          |
| コーン         | 正面の扇形。角度を指定します                    |
| 複数コーン     | 同じ扇形を等間隔に複数。3 つなら 120 度おきです |
| 背面付きコーン | 正面の扇形に加えて、背後にも狭く短い扇形        |
| 周辺視         | 正面ははっきり、その外側は短い距離だけ          |
| カスタム       | 角度と距離の組を自分で並べます                  |

::: tip 視界範囲を「マス」で数えたいとき
テーブル設定の**照明をマス目に沿わせる**を入れると、照らされた範囲がマス単位に丸められます。視界範囲の表示と合わせると、「このコマはあと何マス進めば見えるか」を数えられます。
:::

見え方は [ロール](/manual/roles) によって変わります。

- **GM** — 常にすべてを見られます。
- **プレイヤー** — 自分が所有するキャラクターの視界と、照らされた範囲が合成されて見えます。[同行](/manual/party)しているキャラクターの視界も合わさります。
- **見学** — 自分の駒は持てませんが、**全プレイヤーの視界を合成した範囲**（パーティが見ている範囲）が見えます。未探索の暗闇は隠れたままです。

仲間どうしで視界を共有し、暗闇の中でもおたがいのコマを見えるようにするには [同行（パーティ）](/manual/party) を編成します。

卓に描かれていないコマは、名前が並ぶ一覧にも出ません。[インベントリ](/manual/inventory)のテーブル、[行動順](/manual/turn-order)、チャットとノベルモードの発言キャラクター、[バフマネージャー](/manual/buff#卓じゅうのバフを一覧する)が対象です。見えていない相手の手番は、ツールバーにもチャットのお知らせにも名前を出しません。

::: tip GM はプレイヤー視点で確認できる
GM ツールバーの **ペルソナ（プレイヤー視点でレビュー）** で、特定のプレイヤーや見学から卓がどう見えるかを切り替えて確認できます。**見学** は常に並んでいて、見学者が接続していなくても選べます（卓に居る PL 全員の視界を合わせた見え方です）。元に戻すときは「GM視点（自分）」を選びます。テーブル設定のプレビューにも同じ **見学** があります。
:::

## 光源

同じ **「視界・光源設定…」** の **「光源」** セクションで、キャラクター自身を発光させられます。
地形にも同様の設定があり、独立した「光源オブジェクト」も置けます。

- **点灯** — 発光の ON / OFF
- **プリセット** — たいまつ / ランタン / ろうそく / 太陽光 / 懐中電灯 / ネオン / スポットライト / カスタム。選ぶと各値が一括設定されます
- **明半径 / 薄明半径** — はっきり照らす範囲と、ぼんやり照らす範囲（マス単位）
- **色** — 光の色
- **照射角** — **360° で全方位（球状）**、それ未満で**円錐状（スポット）**になります
- **向き** — 円錐の水平方向
- **仰俯角** — 円錐の上下の傾き（−90°＝真下〜+90°＝真上）。**照射角が 360° 未満のときだけ**表示されます
- **アニメーション** — なし / ゆらめき（たいまつ）/ 明滅 / 色変化（ネオン）

### 演出向けの詳細設定

詳細設定では、さらに次を調整できます。

- **種別** — 物理光源 / 演出光源
- **壁で遮られない** — 壁を無視して照らす
- **全員に見せる** — 視界に関係なく、その光の範囲を全員へ見せる
- **影を落とす** — 光源が駒や地形の影を落とすかどうか

## 立体（高度）と光

キャラクター・地形・光源は**高度**を持てます（右クリックの「高度設定」）。視界と光はどちらも高度を 3D で解釈します。

- 光源は高度に追従して動きます
- **球状の光（たいまつなど）** は、高い位置にあるほど床を照らす円が小さくなります（高すぎると床に届きません）
- **円錐の光（懐中電灯など）** は、向きと仰俯角に沿って空間を進み、当たった床を照らします。手元から光の帯（ビーム）が伸びます
- **壁に配置した駒・光源**（壁掛けランプなど）は、壁の位置から室内へ向けて床を照らします

### 高い所からは見下ろせます

自分の目より低いものは、視界も光もさえぎりません。**建物の上に登ったコマは、その建物ごしに下を見下ろせます。**

「高度を設定して高い所に居る」のと「地形の上に乗って高い所に居る」のは、視界にとって同じことです。塔の上に立てば、塔と同じ高さまでの壁は越えて見えます。天端とちょうど同じ高さのものは越えられません（壁と同じ高さの目は、向こう側を見られない）。

光も同じで、塔の上まで持ち上げたランプは塔ごしに地面を照らします。

## 地形の壁

地形を**右クリック**すると、**「暗闇（視界・発光）」** のメニューから次を切り替えられます。

- **視界を遮る** — 向こう側が見えなくなる
- **光を遮る（窓ならOFF）** — 光をさえぎる。窓やガラスとして光を通したいときはオフ
- **壁を表示 / 非表示**、**影を表示 / 非表示**
- 駒や地形は、**北壁 / 東壁 / 南壁 / 西壁** に貼り付けて配置することもできます

## 独立した光源オブジェクト

テーブルの何もない場所を右クリックし、**「光源を作成」** で、駒に依存しない光源を置けます。右クリックメニューから次を操作できます。

- **光源設定…** — 上記と同じ光源設定
- **点灯する / 消灯する**
- **トークンに追従 / 追従しない** — 指定したキャラクターの位置・高度に光源を追従させる
- **高度設定**

## 戦場の霧（探索）

暗闇が「今どこが照らされているか」を描くのに対して、戦場の霧は **「パーティがどこまで踏み込んだか」** を描きます。誰も足を踏み入れていない場所は霧で覆われ、そこに置かれたコマも地形も見えません。ダンジョンを少しずつ明らかにしていく進め方に向いています。

テーブル設定の **「戦場の霧（探索）」** から設定します。暗闇とは独立していて、明るい屋外マップで霧だけ使うこともできます。

- **戦場の霧を有効化** — 霧の ON / OFF
- **霧の戻り方** — 下の 3 モードから選びます
- **霧の色** — 未踏破を覆う色。既定は薄い灰青で、夜のマップなら暗い色にすると馴染みます
- **霧をリセット** — 踏破の記録を捨てて、全体を未踏破に戻します

### 霧の戻り方は 3 段階

| モード   | 一度晴らした場所                 | 見つけた敵                       |
| -------- | -------------------------------- | -------------------------------- |
| イージー | 明るいまま固定される             | どこへ動いても位置がわかる       |
| ノーマル | 霧は戻らないが、離れると暗くなる | 踏破済みの場所にいる間だけ見える |
| ハード   | 視界から外れると霧に戻る         | 見失う                           |

既定は**ノーマル**です。

**イージー**は、探索の記録がそのまま地図になります。通った場所は光源が去っても明るいままで、一度出会ったモンスターは未踏破の霧の奥へ逃げても位置がわかります。「マップを埋めていく」感覚を出したいときや、探索の手間を軽くしたいときに選びます。

**ハード**は逆に、視界から外れた場所はすべて霧に戻ります。曲がり角の先を覚えていられないので、隊列や松明の管理が意味を持ちます。

なお **GM には常に盤面がそのまま見えます**。霧はうっすら掛かるだけで、モードによる見え方の違いもありません。

### 霧とコマ・地形

- 未踏破の場所に立つコマは表示されません。ノーマル以上では、踏破済みの場所へ出てきた時点で見えるようになります
- 地形は**マス単位で霧に隠れます**。長い壁の手前だけ踏破した場合、その部分だけが現れ、残りは霧のままです
- 壁の手前の面は、霧の向こうにあっても「そこに壁がある」ことがわかるように描かれます

::: tip 誰の視界で霧が晴れるか
霧はプレイヤーが所有するコマの視界で晴れます。[同行（パーティ）](/manual/party)を組んでいれば、仲間の誰かが通った場所は全員の地図に記録されます。GM が持つ NPC の視界では晴れません。
:::

モンスターを何体も置いてから 1 体ずつ視界を設定するのは手間です。[オブジェクト一覧（GM）](/manual/gm-object-list)でコマにチェックを入れると、視界をまとめて設定できます。

## 覚えておくと便利なこと

- 光源の発光（床の光だまり・ビーム・球状の光）は、**暗闇が OFF のときでも表示**されます。暗化や遮蔽の処理だけが暗闇 ON のときに働きます
- 壁の無いマップ端では、**光がマップの外へにじみ出る**演出になります
- 暗闇はマップの外形に沿って止まります。ヘクスマップでは外周のギザギザに合わせて覆われます
- **真視**は遮蔽を無視するため、壁の向こうの相手も視界範囲内なら見えます
- 壁に貼り付けた光源やコマが増えてきたら、[オブジェクト一覧（GM）](/manual/gm-object-list)でサーフェスごとに一覧・整理できます

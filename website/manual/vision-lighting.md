# 暗闇・視界・光源

このページは、テーブルを暗くして、キャラクターの視界と光源で照らされた範囲だけを見せる「暗闇」と、踏み込んでいない場所を覆う「戦場の霧」を説明します。
ダンジョン探索やホラーのセッションなど、見えている範囲を絞りたい場面に使います。
テーブルの暗闇はテーブル設定で入れ、キャラクターの視界と光源はコマごとに決めます。
どれもGMとPLが変えられます。

<Shot src="darkness" alt="暗闇をオンにしたテーブル。光の届く範囲だけが明るい" caption="暗闇をオンにすると、視界と光源の届く範囲だけが見えます" />

おおまかな流れは次のとおりです。

1. **テーブル設定**で暗闇を有効化し、暗さや環境光を決める
2. 各**キャラクターに視界**（暗視・真視など）を持たせる
3. **たいまつなどの光源**を置いて、照らされる範囲をつくる

## テーブル全体の暗闇設定

FABメニューの**テーブル関連**の**テーブル設定**を開き、**暗闇（視界・照明）** の節で決めます。
テーブルごとの設定で、そのテーブルを見ている全員に伝わります。

| 項目                   | 内容                                                                                                                                                   | 既定値     |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------- |
| 暗闇を有効化           | 暗闇を入れるか。切ってあるときは、全体が明るく見えます                                                                                                 | 切り       |
| 暗さ                   | 暗闇の濃さ。高いほど、照らされていない場所が暗くなります                                                                                               | 92%        |
| 環境光                 | 全体に薄く当たる明るさ。0にすると、光源のない場所は真っ暗になります                                                                                    | 0%         |
| 暗闇の色               | 暗いところの色味（夜は紺、洞窟は黒、など）                                                                                                             | 黒に近い紺 |
| 照明をマス目に沿わせる | 照らされた範囲をマス単位に丸めます。四角のマスなら正方形、ヘクスなら六角形の縁になり、「このマスは明るいか」を数えられます。暗闇が有効なときだけ出ます | 切り       |
| 壁の高さ               | 外周の壁の高さ（マス）。光と影の立体的な見えかたに効きます                                                                                             | 10         |

### 外周の壁

テーブル設定の**壁**で、北壁・東壁・南壁・西壁の表示と画像を、1つずつ決められます。
壁を表示した辺は光を遮り、表示していない辺からは光がマップの外へ漏れて広がります。

## キャラクターの視界

1. キャラクターを右クリックします。
2. **視界と視点**から**視界・光源設定…** を開きます。
3. **視界**の節で決めます。

| 項目                 | 内容                                         | 既定値   |
| -------------------- | -------------------------------------------- | -------- |
| 視界タイプ           | 見えかた（下の表）                           | 通常視界 |
| 視界範囲(マス)       | そのコマが自力で見通せる距離。0なら制限なし  | 0        |
| 視界の形             | 見える範囲の形（下の表）                     | 全周     |
| 光を遮り影を落とす   | このコマが光をさえぎり、地面に影を落とします | 入り     |
| 視界範囲を盤面に表示 | そのコマの視界の形を、テーブルに線で描きます | 切り     |

| 視界タイプ | 見えるもの                                             |
| ---------- | ------------------------------------------------------ |
| 通常視界   | 光源に照らされた範囲だけ                               |
| 暗視       | 視界範囲の中なら、暗い場所も                           |
| 真視       | 視界範囲の中なら、壁などの遮るものを無視して見通せます |
| 盲目       | 何も見えません                                         |
| 熱視界     | 視界範囲の中を、熱を示す色味で見ます                   |

視界の形は6種類です。
全周のほかは、コマの向きを基準にするので、コマを回すと一緒に回ります。

| 形             | 見える範囲                                                        |
| -------------- | ----------------------------------------------------------------- |
| 全周           | 全方位                                                            |
| 前方           | 正面の扇形。**視野角(度)** を決めます                             |
| 複数（等間隔） | 同じ扇形を等間隔に複数。3つなら120度おきです                      |
| 前後           | 正面の扇形に加えて、背後にも狭く短い扇形                          |
| 前方＋周辺視野 | 正面ははっきり、その外側は短い距離だけ                            |
| 任意           | 「向き/角度/距離比」の組を`;`で区切って並べます（**視野の指定**） |

::: tip 視界範囲を「マス」で数えたいとき
テーブル設定の**照明をマス目に沿わせる**を入れると、照らされた範囲がマス単位に丸められます。視界範囲の表示と合わせると、「このコマはあと何マス進めば見えるか」を数えられます。
:::

見え方は[ロール](/manual/roles)によって変わります。

- **GM** — 常にすべてを見られます。
- **プレイヤー** — 自分が所有するキャラクターの視界と、照らされた範囲が合成されて見えます。[同行](/manual/party)しているキャラクターの視界も合わさります。
- **見学** — 自分のコマは持てませんが、**全プレイヤーの視界を合成した範囲**（パーティが見ている範囲）が見えます。未探索の暗闇は隠れたままです。

仲間どうしで視界を共有し、暗闇の中でもおたがいのコマを見えるようにするには[同行（パーティ）](/manual/party)を編成します。

テーブルに描かれていないコマは、名前が並ぶ一覧にも出ません。[インベントリ](/manual/inventory)のテーブル、[行動順](/manual/turn-order)、チャットとノベルモードの発言キャラクター、[バフマネージャー](/manual/buff#卓全体のバフの一覧)が対象です。見えていない相手の手番は、ツールバーにもチャットのお知らせにも名前を出しません。

::: tip GMはプレイヤー視点で確認できる
GMツールバーの**ペルソナ（プレイヤー視点でレビュー）** で、特定のプレイヤーや見学からテーブルがどう見えるかを切り替えて確認できます。**見学**は常に並んでいて、見学者が接続していなくても選べます（卓に居るPL全員の視界を合わせた見え方です）。元に戻すときは「GM視点（自分）」を選びます。テーブル設定のプレビューにも同じ**見学**があります。
:::

## 光源

同じ **「視界・光源設定…」** の **「光源」** セクションで、キャラクター自身を発光させられます。
地形にも同様の設定があり、独立した「光源オブジェクト」も置けます。

- **点灯** — 発光のON / OFF
- **プリセット** — たいまつ / ランタン / ろうそく / 太陽光 / 懐中電灯 / ネオン / スポットライト / カスタム。選ぶと各値が一括設定されます
- **明半径 / 薄明半径** — はっきり照らす範囲と、ぼんやり照らす範囲（マス単位）
- **色** — 光の色
- **照射角** — **360°で全方位（球状）**、それ未満で**円錐状（スポット）** になります
- **向き** — 円錐の水平方向
- **仰俯角** — 円錐の上下の傾き（−90°＝真下〜+90°＝真上）。**照射角が360°未満のときだけ**表示されます
- **アニメーション** — なし / ゆらめき（たいまつ）/ 明滅 / 色変化（ネオン）

### 演出向けの詳細設定

詳細設定では、さらに次を調整できます。

- **種別** — 物理光源 / 演出光源
- **壁で遮られない** — 壁を無視して照らす
- **全員に見せる** — 視界に関係なく、その光の範囲を全員へ見せる
- **影を落とす** — 光源がコマや地形の影を落とすかどうか

## 立体（高度）と光

キャラクター・地形・光源は**高度**を持てます（右クリックの「高度設定」。キャラクターでは「表示と扱い」の中にあります）。視界と光はどちらも高度を3Dで解釈します。

- 光源は高度に追従して動きます
- **球状の光（たいまつなど）** は、高い位置にあるほど床を照らす円が小さくなります（高すぎると床に届きません）
- **円錐の光（懐中電灯など）** は、向きと仰俯角に沿って空間を進み、当たった床を照らします。手元から光の帯（ビーム）が伸びます
- **壁に配置したコマ・光源**（壁掛けランプなど）は、壁の位置から室内へ向けて床を照らします

### 高い所からの見下ろし

自分の目より低いものは、視界も光もさえぎりません。**建物の上に登ったコマは、その建物ごしに下を見下ろせます。**

「高度を設定して高い所に居る」のと「地形の上に乗って高い所に居る」のは、視界にとって同じことです。塔の上に立てば、塔と同じ高さまでの壁は越えて見えます。ただし、天端が目の高さとちょうど同じ壁は越えられません（壁と同じ高さの目からは、向こう側が見えません）。

光も同じで、塔の上まで持ち上げたランプは塔ごしに地面を照らします。

## 地形の壁

地形を**右クリック**すると、**「暗闇（視界・発光）」** のメニューから次を切り替えられます。

- **視界を遮る** — 向こう側が見えなくなる
- **光を遮る（窓ならOFF）** — 光をさえぎる。窓やガラスとして光を通したいときはオフ
- **壁を表示 / 非表示**、**影を表示 / 非表示**
- コマや地形は、**北壁 / 東壁 / 南壁 / 西壁**に貼り付けて配置することもできます

## 霧や煙で視線を切る

地形を置かずに視線を切りたいときは、[環境エフェクト](/manual/map-effects)の霧や煙を使います。テーブルに置いたエフェクトを右クリックして**視線を遮る**を入れると、その範囲の外枠が壁と同じように視線を止めます。向こう側は見えず、中に立ったコマは外から見えません。

止まるのは視線だけです。**光は通ります。** 石ではなく濃い空気なので、霧の中のランタンは霧ごしに光ります。

[マップエディター](/manual/map-editor#危険地帯塗り)の危険地帯塗りで**濃霧**を塗ると、この設定が入った状態で置かれます。

## 一区画だけ明るさを変える

テーブルの暗闇は盤ぜんたいの設定で、明るさは置いた灯りから計算されます。その間を埋めるのが、同じエフェクトの**明るさ**です。**暗闇 / 薄暗い / 明るい**から選ぶと、その範囲だけが卓の明るさと関係なく決まります。

- **明るい・薄暗い**は明るさの下限になります。灯りのない地下室に落ちる階段の光がこれです
- **暗闇**は上限になり、**最後に適用されます**。ランタンで照らしても、明るい区画を重ねても、そこは暗いままです。呪文で落とす闇だまりがこれです

効くのは、テーブルの**暗闇か戦場の霧が入っているとき**です。どちらも切ってある明るいテーブルでは、そもそも見えないものがないので、この設定も何もしません。

## 独立した光源オブジェクト

テーブルの何もない場所を右クリックし、**「光源を作成」** で、コマに依存しない光源を置けます。右クリックメニューから次を操作できます。

- **光源設定…** — 上記と同じ光源設定
- **点灯する / 消灯する**
- **トークンに追従 / 追従しない** — 指定したキャラクターの位置・高度に光源を追従させる
- **高度設定**

## 戦場の霧（探索）

暗闇が「今どこが照らされているか」を描くのに対して、戦場の霧は **「パーティがどこまで踏み込んだか」** を描きます。誰も足を踏み入れていない場所は霧で覆われ、そこに置かれたコマも地形も見えません。ダンジョンを少しずつ明らかにしていく進め方に向いています。

テーブル設定の **「戦場の霧（探索）」** から設定します。暗闇とは独立していて、明るい屋外マップで霧だけ使うこともできます。

- **戦場の霧を有効化** — 霧のON / OFF
- **霧の戻り方** — 下の3モードから選びます
- **霧の色** — 未踏破を覆う色。既定は薄い灰青で、夜のマップなら暗い色にすると馴染みます
- **霧をリセット** — 踏破の記録を捨てて、全体を未踏破に戻します

### 霧の戻りかた

| モード   | 一度晴らした場所                 | 見つけた敵                       |
| -------- | -------------------------------- | -------------------------------- |
| イージー | 明るいまま固定される             | どこへ動いても位置がわかる       |
| ノーマル | 霧は戻らないが、離れると暗くなる | 踏破済みの場所にいる間だけ見える |
| ハード   | 視界から外れると霧に戻る         | 見失う                           |

既定は**ノーマル**です。

**イージー**は、探索の記録がそのまま地図になります。通った場所は光源が去っても明るいままで、一度出会ったモンスターは未踏破の霧の奥へ逃げても位置がわかります。「マップを埋めていく」感覚を出したいときや、探索の手間を軽くしたいときに選びます。

**ハード**は逆に、視界から外れた場所はすべて霧に戻ります。曲がり角の先を覚えていられないので、隊列や松明の管理が意味を持ちます。

なお**GMには常に盤面がそのまま見えます**。霧はうっすら掛かるだけで、モードによる見え方の違いもありません。

### 霧とコマ・地形

- 未踏破の場所に立つコマは表示されません。ノーマル以上では、踏破済みの場所へ出てきた時点で見えるようになります
- 地形は**マス単位で霧に隠れます**。長い壁の手前だけ踏破した場合、その部分だけが現れ、残りは霧のままです
- 壁の手前の面は、霧の向こうにあっても「そこに壁がある」ことがわかるように描かれます

::: tip 誰の視界で霧が晴れるか
霧はプレイヤーが所有するコマの視界で晴れます。[同行（パーティ）](/manual/party)を組んでいれば、仲間の誰かが通った場所は全員の地図に記録されます。GMが持つNPCの視界では晴れません。
:::

モンスターを何体も置いてから1体ずつ視界を設定するのは手間です。[オブジェクト一覧（GM）](/manual/gm-object-list)でコマにチェックを入れると、視界をまとめて設定できます。

## 補足

- 光源の発光（床の光だまり・ビーム・球状の光）は、**暗闇がOFFのときでも表示**されます。暗化や遮蔽の処理だけが暗闇ONのときに働きます
- 壁の無いマップ端では、**光がマップの外へにじみ出る**演出になります
- 暗闇はマップの外形に沿って止まります。ヘクスマップでは外周のギザギザに合わせて覆われます
- **真視**は遮蔽を無視するため、壁の向こうの相手も視界範囲内なら見えます
- 壁に貼り付けた光源やコマが増えてきたら、[オブジェクト一覧（GM）](/manual/gm-object-list)でサーフェスごとに一覧・整理できます

## うまくいかないとき

| 見えるもの                                             | 原因と直しかた                                                                                                                                                                                                             |
| ------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| PLの画面で、光っているものが全部見えてしまう           | そのPLが、自分がオーナーのキャラクターを1体も持っていません。自分の目になるコマがないと、光っているものはすべて見えます。GMがオーナーを付けるか、PLが自分のものにします（→ [情報の公開範囲](/manual/disclosure#オーナー)） |
| PLの画面が真っ暗で、自分のコマのまわりも見えない       | 環境光が0%で、近くに光源がなく、視界タイプが通常視界です。光源を置くか、視界タイプを暗視にします                                                                                                                           |
| 仲間のコマが暗闇で見えない                             | 同じパーティに入っていません（→ [同行（パーティ）](/manual/party)）                                                                                                                                                        |
| 壁の向こうが見えてしまう                               | 視界タイプが真視です。真視は、壁などの遮るものを無視します                                                                                                                                                                 |
| 光がマップの外へ漏れる                                 | その辺の外周の壁を表示していません。テーブル設定の**壁**で表示します                                                                                                                                                       |
| GMの画面では見えるのに、PLにどう見えているか分からない | GMツールバーの**ペルソナ**か、テーブル設定の**視点プレビュー**で、PLの目線で確かめます                                                                                                                                     |

# 保存と読み込み

このページは、部屋の状態をzipに書き出す「保存」、それを読み込んで戻す「ZIP読込」、ブラウザの中に自動でひかえを取る「自動保存」を説明します。
部屋は参加者が0人になると消えるので、続きを遊ぶ卓は、終わる前に保存してください。
保存は誰でもできます。読み込みと自動保存は、GMとPLだけです。

<Shot src="room-snapshot" alt="自動保存パネル。世代数と保存操作のボタンがある" width="520" caption="自動保存された世代はこのブラウザの中だけに残ります" />

## 保存

1. FABメニューの**セーブ&ロード**を押します。
2. **保存**を押します。

部屋全体が、zipのファイルとしてダウンロードされます。
テーブル・コマ・カード・チャット・画像などが、まとめて入ります。

[部屋のサーバー](/guide/choose)では、GM以外の人の画面には、見えていない物が伏せた形で届きます（GMだけのメモや特定PLに絞ったメモの中身、表の見えないカードの表、ほかの人のダイスの目、シークレットダイスの中身、ほかの人どうしの秘話、見せないタブの発言）。GM以外の人が取った保存（自動保存も、部屋を出たあとに取ったものも）には、それらが欠けたり伏せたりした形のまま入ります。そうした保存を読み込んだ画面や、伏せた形の物を残したまま部屋に入った人の画面も、ページを読み直すか確認の出ない保存を読み込むまでは同じ扱いで、GMとして取った保存にも伏せた形のまま入ります。部屋のほかの人の画面で取った保存には、確認の出ないまま伏せた形が入ります。

そうした保存を読み込むと、伏せた形が本物として部屋に広がるので、読み込む前に確認が出ます。伏せた形の物がある卓のまま、ほかの部屋に入るときや部屋を作るときにも確認が出ます。続きは、確認の出ないGMの保存から読み込んでください。ただし、ほかの人どうしの秘話はGMにも届かないので、GMの保存にも入りません。動いている部屋に保存を読み込むと、部屋に残っていたそうした秘話も消えます。

## 自動保存

テーブルに変更があると、しばらく操作が落ち着いたタイミングで**ルームのスナップショットが自動で保存**されます。
ブラウザが落ちたりタブを閉じたりしても、次に開いたときに続きから再開できます。

| 項目         | 決まり                                                                                                                          |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| いつ取るか   | 変更が20秒止んだら取ります。操作が続くときも、3分に一度は必ず取ります                                                           |
| 取らないとき | コマをドラッグしているあいだと、[リプレイの盤面](/manual/replay#盤面も再生する)を映しているあいだ                               |
| 大きな部屋   | 保存に時間がかかる部屋では、間隔を自動で広げます（前回が1秒を超えたら3倍、3秒を超えたら6倍。最大で「2分止んだら・18分に一度」） |
| 取る人       | GMとPLのブラウザだけです。見学のブラウザには取りません                                                                          |
| 残る場所     | そのブラウザの中だけです。ほかの参加者には渡りません                                                                            |
| 残る数       | 直近の5世代、合計256MBまで。超えた分は、古いものから消えます                                                                    |
| 中身         | **保存**で書き出すzipと同じです                                                                                                 |

[部屋設定](/manual/room-settings#自動保存)の**この端末で部屋を自動保存する**を外すと、新しいひかえは取りません（既定は入り）。

### 前回の卓を復元する

部屋につながずにAxeを開くと、ひかえがあるときは、画面の上に「前回の卓データがこのブラウザに残っています」と出ます。
**復元する**を押すと、その状態が読み込まれます。
要らなければ、**あとで**で閉じます。

[部屋設定](/manual/room-settings#自動保存)の**自動保存**からは、保存された世代の一覧を開けます。

| ボタン     | すること                                                 |
| ---------- | -------------------------------------------------------- |
| 復元       | 選んだ世代を読み込みます。いまのテーブルは上書きされます |
| 削除       | 選んだ世代を消します                                     |
| 今すぐ保存 | いまの状態で、ひかえを1つ足します                        |
| すべて削除 | ひかえを、すべて消します                                 |

世代ごとに、日時・ルーム名・大きさが出ます。

::: warning ブラウザの中だけの保存です
スナップショットはブラウザのストレージ（IndexedDB）に置かれます。別の端末やブラウザからは参照できず、
閲覧データを消去すると一緒に消えます。セッションを確実に残したいときは、これとは別に
**「保存」でzipを手元に書き出して**ください。
:::

::: tip 大きなルームでも操作は止まりません
保存データの書き出し・読み込みは、圧縮も展開も**バックグラウンドで処理**します。画像が数百枚ある
数十MBのルームでも、保存中・読み込み中に画面が固まりにくくなっています。
:::

## ZIP読込

1. FABメニューの**セーブ&ロード**を押します。
2. **ZIP読込**を押して、書き出したzipか、コマ・コマ集のxmlを選びます。

部屋に反映されます。
配布されたキャラクターデータ（zip・xml）を取り込むときにも使います。
見学のときは押せません。
スマートフォンでは[メニューの **「読込」**](/manual/mobile#メニューから開けるもの)が同じ働きをします。

zipはテーブルに**ドラッグ&ドロップ**しても読み込めます。中に入っている画像はメディアに登録されるだけで、コマにはなりません
（コマを立てたいときは[画像そのものを落として](/manual/character#画像を落としてコマを作る)ください）。

キャラクター1体を書き出したzip・xmlを落としたときは、**落とした人がそのキャラクターの持ち主**になり、どの[パーティ](/manual/party)にも入りません。元の部屋で入っていたパーティは引き継ぎません。カード・山札・ダイスは持ち主なしで置かれます（持ち主がつくと他の人から表が隠れるため）。公開範囲で選んだ人も外れます。ルーム全体のzipは、パーティは保存したとおりに戻り、持ち主は解除されます（下の注意を見てください）。

ココフォリアのルームデータzipを落としたときだけは、この読み込みではなく
[ココフォリアのルーム取り込み](/manual/room-import)（実験的機能）として扱われます。

::: tip 読み込み時のオーナーについて
保存データには各オブジェクトの[オーナー](/manual/disclosure#オーナー)（当時の参加者）が記録されていますが、**読み込み時にオーナーは解除されます**。別セッションの持ち主情報が残って視界や操作が誰にも紐づかなくなるのを防ぐためです。読み込み後は、各自がコマやメモのオーナーを取り直してください。公開範囲を「特定PL」にしていたものも、選んだ人が外れて、GMとオーナーだけが見られる状態になります。見せたい人を選び直してください。部屋のサーバーでは、「GMのみ」や「特定PL」にしていた共有メモは、中身が見えないPLには取り直せません。GMがオーナーを付けるか、見せる人を選び直してください。

[部屋のサーバー（ベータ）](/guide/choose)でSkyWay版の卓を読み込むと、手札と、秘話とシークレットダイスの結果は、前の参加者のまま残ります。そのままにすると、見学の人が前の参加者になりすまして、これらをのぞけてしまいます。読み込んだら、GMが次のように直してください。

- 手札は、[退室した人の手札](/manual/cards#退室した人の手札を引き継がせる)として今の参加者に引き継がせます。前の参加者を名乗る見学の人が入っていても、見学は手札を持てないので、一覧に出ます
- 前の卓で秘話やシークレットダイスを使っていたなら、残したい発言の無いタブは、タブごと削除します。前の参加者どうしの秘話は、GMの画面にも出ないので、どのタブにあるかは分かりません。ログの消去では消えません
- 残したタブは、[タブの権限](/manual/chat#タブの権限-閲覧・発言)で見学の人が発言できないようにします。前の参加者を名乗った見学の人は、その人の昔の発言を書き換えたり、秘話を公開したりできるためです

:::

## 個別の書き出し

- キャラクターは、シートの保存からコマ単位でzip書き出しできます
- チャットのタブは、タブ設定の「保存」でタブごとzipに書き出せます。読み込むと、同じタブが部屋にあるときは別のタブとして並び、無いときは元のタブとして戻ります。消したタブも、これで戻せます。ただし[部屋のサーバー](/guide/choose)では、サーバーが振った結果は盾の印が外れてふつうの発言になり、保存した人の画面に届いていなかった秘話は戻りません。ほかの人のシークレットダイスは、本文が空のまま戻ります。部屋のサーバーでGMがPLに見せていないタブと同じタブをPLが読み込むと、読み込んだタブはPLの画面からすぐに消えます。保存したあとにGMがそのタブで消した発言は、部屋のタブに戻ります
- カットインは、カットインの一覧の「保存」で書き出せます。同じカットインが部屋にあるときは、別のカットインとして並びます
- チャットログは[チャットの基本](/manual/chat)のHTMLログ書き出しを利用します

::: warning セッションを残したいときは、保存で書き出します
SkyWay版では、ゲームデータは参加者どうしで共有されるだけで、どこのサーバーにも残りません。
[部屋のサーバー](/guide/choose)では、テーブルは、最後の1人が抜けてから保持期間（既定では24時間）がたつとサーバーから消えます。
自動保存は、各自のブラウザの中の保険です。
:::

## うまくいかないとき

| 見えるもの                                                                 | 原因と直しかた                                                                                                       |
| -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 「このブラウザでは自動保存を利用できません（IndexedDB が使用できません）」 | プライベートウィンドウなど、ブラウザがIndexedDBを使えません。ふつうのウィンドウで開くか、**保存**でzipを書き出します |
| 「前回の卓データがこのブラウザに残っています」が出ない                     | 部屋に入っているか、ひかえがありません。部屋設定の**自動保存**で、一覧を確かめます                                   |
| **ZIP読込**が押せない                                                      | 見学のときは押せません                                                                                               |
| 読み込んだら、自分のコマを動かせない                                       | 読み込むと、オーナーが外れます。各自が、右クリックの**オーナー**から取り直します                                     |
| 読み込む前に、伏せた形についての確認が出る                                 | 部屋のサーバーで、GM以外の人が取った保存です。続きは、確認の出ないGMの保存から読み込みます                           |
| ココフォリアのzipを落としたら、別の画面が開いた                            | ココフォリアのルームデータは、[ルーム取り込み](/manual/room-import)として扱います                                    |

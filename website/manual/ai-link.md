# AI連携（MCP）

このページは、AI（ClaudeなどのLLM）にAxeの部屋を読ませたり操作させたりする「AI連携」を説明します。
AIはつないだタブの席として動き、その席から見えるものだけを読み、その席の役割でできることだけをします。
AIにゲームマスターを任せる仕組みや、セッションの記録を読ませる仕組みを作るために使います。

## しくみ

AIとAxeのあいだには、手元のパソコンで動く小さなプログラム「ブリッジ」（`axe-mcp.mjs`）が入ります。

1. AIのアプリ（Claude Code・Claude Desktopなど）が、MCP（Model Context Protocol）でブリッジを起動します。
2. Axeの**AI連携**パネルで**つなぐ**を押すと、そのタブがブリッジにつながります。
3. AIが道具を呼ぶと、ブリッジがそれをタブへ渡し、タブがその席として実行します。

ブリッジはAIとタブをつなぐだけで、ダイスやシートの処理はAxeのタブの中で行います。SkyWay版の部屋でも、サーバー版の部屋でも使えます。

## 用意する

ブリッジを動かすには、Node.js 22以上が要ります。

1. [リリースのページ](https://github.com/Xelltis/udonarium_axe/releases/latest)から`axe-mcp.mjs`を落とし、好きな場所に置きます。
2. AIのアプリに、ブリッジを登録します。

Claude Codeでは、次を実行します。パスは`axe-mcp.mjs`を置いた場所に書き換えます。

```sh
claude mcp add axe -- node /path/to/axe-mcp.mjs
```

Claude Desktopでは、設定ファイル（`claude_desktop_config.json`）の`mcpServers`に次を足します。

```json
{
  "mcpServers": {
    "axe": { "command": "node", "args": ["/path/to/axe-mcp.mjs"] }
  }
}
```

AI連携パネルの**つなぎ方**には、開いているページに合わせた書き方が出ます。コピーして使えます。

### 自分で置いたAxeとつなぐ

ブリッジがつなぐのは、公式の配信先（`https://axe.xelltis.com`など）と手元の開発用のページからのタブだけです。
自分のサーバーに置いたAxeとつなぐときは、ブリッジの起動に`--allow-origin`とそのページのアドレスを足します。

```sh
claude mcp add axe -- node /path/to/axe-mcp.mjs --allow-origin https://example.com
```

AI連携パネルの**つなぎ方**は、このページが一覧にないときは`--allow-origin`を付けた形で出ます。

## つなぐ

1. AIのアプリを起動します（ブリッジもいっしょに起動します）。
2. FABメニューの**AI連携**を押して、パネルを開きます。
3. **AIに許すこと**を選びます。
4. **つなぐ**を押します。「つながっています」と出れば、AIが道具を使えます。

先に**つなぐ**を押してからAIを起動しても、パネルが数秒ごとにブリッジを探すので、ブリッジが動き出した時点でつながります。AIを起動し直したときも、そのままつなぎ直します。
止めるときは**切る**を押します。ページを開き直すと切れます。そのときは、もう一度**つなぐ**を押します。

### AIに許すこと

| 選ぶもの       | AIができること                                                                           |
| -------------- | ---------------------------------------------------------------------------------------- |
| 読むだけ       | 部屋の様子・コマ・チャット・行動順を読む。何も変えない                                   |
| 書くことも許す | 読むことに加えて、発言・ダイス・コマの移動・リソースの変更など、この席でできることをする |

見学の席では、**読むだけ**しか選べません。GMの道具（BGM・カットイン・エフェクト・シーンなど）は、GMの席で**書くことも許す**ときだけ使えます。
つないだあともパネルで切り替えられます。

## AIがしたことの見え方

- 席がAI連携をはじめた・終えた・許すことを変えたときは、「システム」タブに全員向けの行が出ます。送り先は部屋設定の[システム通知の送り先](/manual/room-settings#システム通知の送り先)で変えられます。
- AIが送った発言には、名前の横に全員の画面でAIの印（<span class="material-icons">smart_toy</span>）が付きます。
- AIの操作は、つないだ席のAI連携パネルの**AIがしたこと**に並びます。断られた操作には「断りました」と出ます。

## AIにGMを任せる

1. AI用の席を別のブラウザ（またはブラウザの別のプロファイル）で開き、名前を「AI GM」などにします。
2. その席を部屋のGMにします（[ロール](/manual/roles)）。
3. その席でAI連携をつなぎ、**書くことも許す**を選びます。
4. Claude Codeでは`/mcp__axe__run_session`と打ちます。プロンプトを選べないアプリでは、AIに「axe://guide/run-sessionを読んでGMをして」と頼みます。

`run_session`（`axe://guide/run-session`）は、ブリッジがAIに渡す進め方の手引きです。手引きに沿ってAIは部屋の様子を読み、プレイヤーの発言やダイスを待ち、発言・ダイス・コマの移動・演出で応えます。
プレイヤーのキャラクターの行動はAIが決めず、プレイヤーに尋ねます。

## AIが使える道具

| 種類             | 道具                                                                                                                                          |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 読む             | 部屋を見る・コマの一覧・コマを読む・行動順を読む・チャットを読む・使える物の一覧・起きたことを待つ                                            |
| チャットとダイス | 発言する・ダイスを振る                                                                                                                        |
| コマとシート     | コマを動かす・リソースを変える・シートに書く・バフを付ける/外す・ターゲットを選ぶ・行動順を進める・コマを置く・コマを下げる                   |
| GMの道具         | エフェクトを撃つ・音を鳴らす/止める・カットインを出す/止める・テーブルを切り替える・シーンを適用する・シナリオテキストを送る・射程を置く/消す |

**発言する**は、チャットの入力欄に打ったのと同じに扱います。[チャットの特殊記法](/manual/chat-syntax)（`:HP-5`・バフ・手番のコマンド・`《エフェクト》`など）も、そのまま使えます。
**リソースを変える**は、`:HP-5`のような行をそのコマとして送るので、チャットにいつもの変更の行が残ります。
マスは西の端から東へ1、2…、北の端から南へ1、2…と数えます。

## うまくいかないとき

| 見えるもの                                     | 原因と直しかた                                                                                                                    |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 「ブリッジが見つかりません」のまま             | AIのアプリが起動していないか、ブリッジの登録が違います。AIのアプリでMCPのサーバーの一覧に`axe`が出ているかを確かめます            |
| 「ブリッジには別のタブがつながっています」     | ブリッジにつなげるタブは1つです。ほかのタブやブラウザで**切る**を押してから、つなぎ直します                                       |
| 「……とこのAxeの版が合いません」                | ブリッジとAxeのリリースが違います。このAxeと同じリリースの`axe-mcp.mjs`に入れ替えます                                             |
| 自分で置いたAxeでつながらない                  | ブリッジがそのページを知りません。[自分で置いたAxeとつなぐ](#自分で置いたaxeとつなぐ)のとおり`--allow-origin`を足します           |
| ブラウザがローカルネットワークへの接続を尋ねる | ブリッジは同じパソコンの中で動いています。許可するとつながります                                                                  |
| AIが、書く道具を断られたと答える               | **読むだけ**になっています。パネルで**書くことも許す**に切り替えます                                                              |
| AIがBGMやカットインを使えない                  | GMの道具は、GMの席でだけ使えます                                                                                                  |
| ブリッジの番号を変えたい                       | 47610番がほかのプログラムに使われているときは、ブリッジの起動に`--port 47620`のように足し、パネルの**ブリッジの番号**も合わせます |

## 気をつけること

AIのアプリは読んだ部屋の内容（チャット・シート・コマの名前など）を、そのAIの提供元に送ります。ほかの参加者の発言も送られるので、AI連携を使うことを参加者に知らせてから使います。

# AI連携（MCP）

このページは、AI（ClaudeなどのLLM）にAxeの部屋を読ませたり操作させたりする「AI連携」を説明します。
AIはつないだタブの席として動き、その席から見えるものだけを読み、その席の役割でできることだけをします。
AIにゲームマスターを任せる仕組みや、セッションの記録を読ませる仕組みを作るために使います。

AI連携を使うと、ふだん使っているAIのアプリ（Claude CodeやClaude Desktopなど）に、たとえば次のように頼めます。

- 「いまの部屋の様子を教えて」
- 「ここまでのチャットをまとめて」
- 「ゴブリンとして『ギギッ』と発言して、2d6を振って」
- 「ゴブリンを3マス東へ動かして」

## AI GMとの違い

AIに部屋を触らせる方法は2つあります。どちらも同じブリッジのファイルを使います。

| 方法                   | 要るもの                                     | 向いている使い方                                           |
| ---------------------- | -------------------------------------------- | ---------------------------------------------------------- |
| AI連携（このページ）   | Claude CodeやClaude DesktopなどのAIのアプリ  | AIのアプリと話しながら、部屋を読ませたり、手伝わせたりする |
| [AI GM](/manual/ai-gm) | Claude APIのキー（使った分だけ料金がかかる） | Axeのパネルから、Claudeにゲームマスターの席を任せる        |

ゲームマスターを任せるだけなら、[AI GM](/manual/ai-gm)が使えます。Axeのパネルから始めたり止めたりでき、使う額の上限も決められます。
AI連携でつないだAIのアプリに、パネルの**GMを任せる**のタブからGMをさせることもできます。APIキーは要りません（[AIのアプリにAI GMをさせる](/manual/ai-gm#aiのアプリにai-gmをさせる)）。

## 言葉の説明

| 言葉     | 意味                                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------------------------ |
| MCP      | AIのアプリが外の道具を使うための共通の決まり（Model Context Protocol）。AIのアプリの側が対応している必要があります |
| ブリッジ | 自分のパソコンで動く小さなプログラム（`axe-mcp.mjs`）。AIのアプリとAxeのあいだでやりとりを受け渡します             |
| タブ     | Axeを開いているブラウザのタブ。AIはこのタブを通して部屋を読み、操作します                                          |
| 席       | 部屋に入っている1人分の参加者。AIは、つないだタブの席と同じものを見て、同じことができます                          |
| 道具     | AIがAxeにできる操作の1つ1つ（部屋を見る、発言する、コマを動かす、など）                                            |
| 端末     | 文字で命令を打ってパソコンを動かす画面。WindowsではPowerShell、macOSではターミナルです                             |

## はじめての人の手順

パソコンに詳しくない人が、最初の1回を通すための手順です。AIのアプリはClaude DesktopかClaude Codeのどちらかを先に入れて、ログインしておきます。

### 1. Node.jsを入れる

Node.jsはブリッジを動かすために要る無料のソフトです。

1. [Node.jsのサイト](https://nodejs.org/ja)を開き、「LTS」と書かれたインストーラーを落とします。
2. 落としたファイルを開き、画面の案内のとおりに最後まで進めます。設定は初めのままでかまいません。
3. 端末を開きます。Windowsではスタートメニューで「PowerShell」と打って開き、macOSでは「ターミナル」というアプリを開きます。
4. 端末に`node -v`と打ってEnterを押します。`v22.3.0`のように、22以上の数字が出れば入っています。

### 2. ブリッジを落とす

1. [リリースのページ](https://github.com/Xelltis/udonarium_axe/releases/latest)を開きます。
2. 「Assets」の一覧から`axe-mcp.mjs`を押して落とします。
3. 落としたファイルはダウンロードのフォルダに置いたままにします。

このあとの手順で、このファイルの場所（パス）を書きます。ダウンロードのフォルダに置いたときのパスは、次のとおりです。`名前`のところは自分のパソコンのユーザー名です。

| パソコン | パス                                  |
| -------- | ------------------------------------- |
| Windows  | `C:/Users/名前/Downloads/axe-mcp.mjs` |
| macOS    | `/Users/名前/Downloads/axe-mcp.mjs`   |
| Linux    | `/home/名前/Downloads/axe-mcp.mjs`    |

### 3. AIのアプリにブリッジを登録する

AIのアプリに「Axeのブリッジはこのファイルです」と教える手順です。使うアプリのほうだけを行います。

Claude Desktopでは次のとおりです。

1. Claude Desktopの設定を開き、「開発者」から設定ファイルを開きます。ファイルの名前は`claude_desktop_config.json`です。
2. ファイルの中身を次のとおりにします。パスは手順2の表のものに書き換えます。すでにほかの内容があるときは、`mcpServers`の中に`"axe"`の行だけを足します。
3. ファイルを保存し、Claude Desktopをいったん終了してから開き直します。

```json
{
  "mcpServers": {
    "axe": { "command": "node", "args": ["C:/Users/名前/Downloads/axe-mcp.mjs"] }
  }
}
```

設定ファイルはWindowsでは`%APPDATA%\Claude`のフォルダに、macOSでは`~/Library/Application Support/Claude`のフォルダにあります。

Claude Codeでは端末で次の1行を打ってEnterを押します。パスは手順2の表のものに書き換えます。

```sh
claude mcp add axe -- node C:/Users/名前/Downloads/axe-mcp.mjs
```

登録できたかは端末で`claude mcp list`と打つと確かめられます。一覧に`axe`が出ていれば登録できています。

### 4. Axeでつなぐ

1. AIのアプリを起動します。ブリッジは、AIのアプリがいっしょに起動します。自分で起動する必要はありません。
2. Axeで部屋を開きます。
3. 画面左上の丸いボタン（FABメニュー）を押し、並んだボタンから**AI連携**を押してパネルを開きます。
4. **AIに許すこと**で**読むだけ**を選びます。最初は、AIが部屋を変えない**読むだけ**で試すと安心です。
5. **つなぐ**を押します。「つながっています」と出れば、AIが部屋を読めます。

### 5. AIに頼んでみる

AIのアプリで、次のように頼みます。

```text
Axeの部屋の様子を教えてください。
```

AIが部屋の様子を答えれば、つながっています。はじめて道具を使うときに、AIのアプリが「この道具を使ってよいか」を尋ねることがあります。許可すると進みます。

AIに発言やコマの移動もさせたいときは、Axeのパネルで**AIに許すこと**を**書くことも許す**に切り替えてから、次のように頼みます。

```text
チャットで「こんにちは」と発言してください。
```

チャットに、AIの印（<span class="material-icons">smart_toy</span>）の付いた発言が出れば成功です。

### 6. 終わる

1. Axeのパネルで**切る**を押します。
2. AIのアプリを終了します。ブリッジもいっしょに止まります。

次に使うときは、手順4から始めます。登録は1回だけで済みます。

## しくみ

AIとAxeのあいだには、手元のパソコンで動く小さなプログラム「ブリッジ」（`axe-mcp.mjs`）が入ります。

1. AIのアプリ（Claude Code・Claude Desktopなど）が、MCP（Model Context Protocol）でブリッジを起動します。
2. Axeの**AI連携**パネルで**つなぐ**を押すと、そのタブがブリッジにつながります。
3. AIが道具を呼ぶと、ブリッジがそれをタブへ渡し、タブがその席として実行します。

ブリッジはAIとタブをつなぐだけで、ダイスやシートの処理はAxeのタブの中で行います。SkyWay版の部屋でも、サーバー版の部屋でも使えます。

## 用意する

ブリッジを動かすには、Node.js 22以上が要ります。

1. [リリースのページ](https://github.com/Xelltis/udonarium_axe/releases/latest)から`axe-mcp.mjs`を落とし、好きな場所に置きます。
2. AIのアプリに、ブリッジを登録します。

Claude Codeでは、次を実行します。パスは`axe-mcp.mjs`を置いた場所に書き換えます。

```sh
claude mcp add axe -- node /path/to/axe-mcp.mjs
```

Claude Desktopでは、設定ファイル（`claude_desktop_config.json`）の`mcpServers`に次を足します。

```json
{
  "mcpServers": {
    "axe": { "command": "node", "args": ["/path/to/axe-mcp.mjs"] }
  }
}
```

AI連携パネルの**つなぎ方**には、開いているページに合わせた書き方が出ます。コピーして使えます。

### 自分で置いたAxeとつなぐ

ブリッジがつなぐのは、公式の配信先（`https://axe.xelltis.com`など）と手元の開発用のページからのタブだけです。
自分のサーバーに置いたAxeとつなぐときは、ブリッジの起動に`--allow-origin`とそのページのアドレスを足します。

```sh
claude mcp add axe -- node /path/to/axe-mcp.mjs --allow-origin https://example.com
```

AI連携パネルの**つなぎ方**は、このページが一覧にないときは`--allow-origin`を付けた形で出ます。

## つなぐ

1. AIのアプリを起動します。ブリッジは、AIのアプリがいっしょに起動します。
2. FABメニューの**AI連携**を押して、パネルを開きます。
3. **AIに許すこと**を選びます。
4. **つなぐ**を押します。「つながっています」と出れば、AIが道具を使えます。

先に**つなぐ**を押してからAIを起動しても、パネルが数秒ごとにブリッジを探すので、ブリッジが動き出した時点でつながります。AIを起動し直したときも、そのままつなぎ直します。
止めるときは**切る**を押します。ページを開き直すと切れます。そのときは、もう一度**つなぐ**を押します。

### AIに許すこと

| 選ぶもの       | AIができること                                                                           |
| -------------- | ---------------------------------------------------------------------------------------- |
| 読むだけ       | 部屋の様子・コマ・チャット・行動順を読む。何も変えない                                   |
| 書くことも許す | 読むことに加えて、発言・ダイス・コマの移動・リソースの変更など、この席でできることをする |

見学の席では、**読むだけ**しか選べません。GMの道具（BGM・カットイン・エフェクト・シーンなど）は、GMの席で**書くことも許す**ときだけ使えます。
つないだあともパネルで切り替えられます。

## AIがしたことの見え方

- 席がAI連携をはじめた・終えた・許すことを変えたときは、「システム」タブに全員向けの行が出ます。送り先は部屋設定の[システム通知の送り先](/manual/room-settings#システム通知の送り先)で変えられます。
- AIが送った発言には、名前の横に全員の画面でAIの印（<span class="material-icons">smart_toy</span>）が付きます。
- AIの操作は、つないだ席のAI連携パネルの**AIがしたこと**に並びます。断られた操作には「断りました」と出ます。

## AIにGMを任せる

1. AI用の席を別のブラウザ（またはブラウザの別のプロファイル）で開き、名前を「AI GM」などにします。
2. その席を部屋のGMにします（[ロール](/manual/roles)）。
3. その席でAI連携をつなぎ、**書くことも許す**を選びます。
4. Claude Codeでは`/mcp__axe__run_session`と打ちます。プロンプトを選べないアプリでは、AIに「axe://guide/run-sessionを読んでGMをして」と頼みます。

`run_session`（`axe://guide/run-session`）は、ブリッジがAIに渡す進め方の手引きです。手引きに沿ってAIは部屋の様子を読み、プレイヤーの発言やダイスを待ち、発言・ダイス・コマの移動・演出で応えます。
プレイヤーのキャラクターの行動はAIが決めず、プレイヤーに尋ねます。

AIの番を回す時や聞くタブをAxeのパネルで決めたいときは、同じつなぎ方のまま[パネルの**GMを任せる**のタブから始めます](/manual/ai-gm#aiのアプリにai-gmをさせる)。AIには`run_session`の代わりに`run_ai_gm`を渡します。
Claude Codeなどのアプリを使わず、Claude APIのキーでAxeからGMを任せるときは、[AI GM](/manual/ai-gm)を使います。使う額の上限もAxeのパネルで決められます。

## AIが使える道具

| 種類             | 道具                                                                                                                                          |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 読む             | 部屋を見る・コマの一覧・コマを読む・行動順を読む・チャットを読む・使える物の一覧・シナリオテキストを読む・起きたことを待つ                    |
| チャットとダイス | 発言する・ダイスを振る                                                                                                                        |
| コマとシート     | コマを動かす・リソースを変える・シートに書く・バフを付ける/外す・ターゲットを選ぶ・行動順を進める・コマを置く・コマを下げる                   |
| GMの道具         | エフェクトを撃つ・音を鳴らす/止める・カットインを出す/止める・テーブルを切り替える・シーンを適用する・シナリオテキストを送る・射程を置く/消す |

頼むときに、道具の名前を言う必要はありません。したいことをふだんの言葉で頼めば、AIが合う道具を選びます。

| したいこと           | 頼み方の例                                              |
| -------------------- | ------------------------------------------------------- |
| 部屋の様子を知る     | 「いまの部屋の様子と、テーブルにいるコマを教えて」      |
| チャットを読ませる   | 「ここまでのチャットを読んで、あらすじを3行でまとめて」 |
| 発言させる           | 「ゴブリンとして『ここは通さないぞ』と発言して」        |
| ダイスを振らせる     | 「ゴブリンの攻撃として2d6を振って」                     |
| コマを動かす         | 「ゴブリンをアリスの隣のマスへ動かして」                |
| リソースを変える     | 「ゴブリンのHPを5減らして」                             |
| 演出を出す（GMの席） | 「戦闘のBGMを流して、ゴブリンに炎のエフェクトを撃って」 |

**発言する**は、チャットの入力欄に打ったのと同じに扱います。[チャットの特殊記法](/manual/chat-syntax)（`:HP-5`・バフ・手番のコマンド・`《エフェクト》`など）も、そのまま使えます。
**リソースを変える**は、`:HP-5`のような行をそのコマとして送るので、チャットにいつもの変更の行が残ります。
マスは西の端から東へ1、2…、北の端から南へ1、2…と数えます。

道具の1つ1つの名前と、ブリッジの起動のときに足せる指定は、[AI連携の道具とブリッジの設定](/manual/ai-link-reference)にあります。

## うまくいかないとき

| 見えるもの                                     | 原因と直しかた                                                                                                                    |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 「ブリッジが見つかりません」のまま             | AIのアプリが起動していないか、ブリッジの登録が違います。AIのアプリでMCPのサーバーの一覧に`axe`が出ているかを確かめます            |
| AIが「axeの道具がない」と答える                | ブリッジが登録されていないか、登録のあとにAIのアプリを開き直していません。登録を確かめ、AIのアプリを開き直します                  |
| AIのアプリがブリッジの起動に失敗したと出す     | Node.jsが入っていないか、登録したパスが違います。端末で`node -v`を確かめ、パスが`axe-mcp.mjs`の場所と合っているかを見直します     |
| 「ブリッジには別のタブがつながっています」     | ブリッジにつなげるタブは1つです。ほかのタブやブラウザで**切る**を押してから、つなぎ直します                                       |
| 「……とこのAxeの版が合いません」                | ブリッジとAxeのリリースが違います。このAxeと同じリリースの`axe-mcp.mjs`に入れ替えます                                             |
| 自分で置いたAxeでつながらない                  | ブリッジがそのページを知りません。[自分で置いたAxeとつなぐ](#自分で置いたaxeとつなぐ)のとおり`--allow-origin`を足します           |
| ブラウザがローカルネットワークへの接続を尋ねる | ブリッジは同じパソコンの中で動いています。許可するとつながります                                                                  |
| AIが、書く道具を断られたと答える               | **読むだけ**になっています。パネルで**書くことも許す**に切り替えます                                                              |
| AIがBGMやカットインを使えない                  | GMの道具は、GMの席でだけ使えます                                                                                                  |
| ブリッジの番号を変えたい                       | 47610番がほかのプログラムに使われているときは、ブリッジの起動に`--port 47620`のように足し、パネルの**ブリッジの番号**も合わせます |

## 気をつけること

AIのアプリは読んだ部屋の内容（チャット・シート・コマの名前など）を、そのAIの提供元に送ります。ほかの参加者の発言も送られるので、AI連携を使うことを参加者に知らせてから使います。

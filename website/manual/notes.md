# 共有メモ

テーブルに貼り付けて参加者と共有できるメモです。状況のメモやハンドアウトの掲示などに使えます。

<Shot src="notes" alt="テーブルに置かれた共有メモ。碑文の文面が書かれている" caption="クリックするとその場で本文を編集できます" />

## 共有メモを置く

テーブルの何もない場所を右クリックし、「共有メモを作成」を選ぶと、その位置にメモが現れます。

## 共有メモを操作する

共有メモを**右クリック**すると、操作メニューが開きます。主な操作は次のとおりです。

- **編集** — 本文を書き換える
- **コピー** — 複製を作る
- **寝かせる / 直立させる** — テーブルに対する向きを切り替える
- **固定** — 位置をロックする
- **削除** — メモを消す

## 固定について

固定したメモはドラッグで動かせなくなり、タイトルバーに鍵アイコンが表示されます。
誤って動かしたくない掲示物に向いています。固定中は編集もロックされるため、書き換えるときは固定を解除してください。

## 整形して表示する

本文に見出しやリストを付けて表示できます。メモを右クリックして「メモを編集」を選び、開いたシートの本文の下にある**表示**を「通常」から「整形」に切り替えます。

整形で読むのは、行の先頭に書いた次の記号です。`#`・`-`・`1.`のあとには空白を入れてください。

| 書き方                   | 表示                                                    |
| ------------------------ | ------------------------------------------------------- |
| `# 見出し`〜`### 見出し` | 見出し。`#`が少ないほど大きな字になります               |
| `- 項目`                 | 点の付いたリスト                                        |
| `1. 項目`                | 番号付きのリスト。番号は書いた数字によらず1から振ります |
| `> 文`                   | 引用                                                    |
| `` `コード` ``           | 行の中のコード。囲んだ文字は書いたとおりに出ます        |
| ` ``` `の行で前後を挟む  | コードの段落                                            |

- 改行はそのまま改行になります。空行を挟むと段落が分かれます
- [ルビ](/manual/chat-syntax#ルビ-ふりがな)はチャットと同じ`|漢字《かんじ》`で振れます。URLはリンクになります。コードの中ではどちらも効きません
- `*`や`_`で囲む強調は読みません。`2*3`のような式は、書いたとおりに出ます

表示を切り替えても、本文の文字は変わりません。「通常」に戻せば、書いたとおりの表示に戻ります。

整形を選ぶと、シートの切り替えの下に書き方の説明と見本が出ます。テーブルのメモ、シートの見本、マウスを乗せたときのポップアップは、どれも同じ見た目です。ただし、テーブルでメモをクリックして書き換えている間は、記号のまま表示されます。整形にしたメモはポップアップでは書き換えられないので、テーブルかシートで書き換えてください。

公開範囲の外の人には、整形にしたメモもモザイクで表示されます。

## 公開範囲

メモは、見せる相手を「全員 / 特定プレイヤー / GMのみ」から選べます。公開範囲外の参加者には、メモは卓上に残りますが、**本文がモザイク表示**になり内容は読めません。設定のしかたは[情報の公開範囲](/manual/disclosure)を参照してください。

他のオブジェクトについては[カード](/manual/cards)・[ダイス](/manual/dice)を参照してください。

# 共有メモ

このページは、テーブルに貼って参加者と共有するメモ（共有メモ）を説明します。
状況のメモ、ハンドアウトの掲示、地図の書き込みなどに使います。
置いて書き換えるのはGMとPLです。見学は読むだけです。

<Shot src="notes" alt="テーブルに置かれた共有メモ。碑文の文面が書かれている" caption="クリックすると、その場で本文を書き換えられます" />

## 共有メモを置く

1. テーブルの何もない場所を右クリックします。
2. **共有メモを作成**を選びます。

右クリックした位置に、幅4マス・高さ3マスのメモが出ます。
題は「共有メモ」、本文は「テキストを入力してください」から始まります。
GMが作ったメモの公開範囲は「GMのみ」から始まります（→ [情報の公開範囲](/manual/disclosure#作ったときの公開範囲)）。

## 書き換える

| したいこと           | 操作                                                                 |
| -------------------- | -------------------------------------------------------------------- |
| 本文をすぐ書き換える | テーブルのメモをクリックして、その場で書きます                       |
| 題や大きさも変える   | 右クリックの**メモを編集**で開くシート（**共有メモ設定**）で変えます |

シートで変えられる項目は、次のとおりです。

| 項目       | 内容                                                          | 既定値   |
| ---------- | ------------------------------------------------------------- | -------- |
| タイトル   | メモの題                                                      | 共有メモ |
| 本文       | メモの中身                                                    |          |
| 表示       | **通常**か**整形**（→ [整形して表示する](#整形して表示する)） | 通常     |
| 幅・高さ   | メモの大きさ（マス）                                          | 4・3     |
| 文字サイズ | 本文の字の大きさ                                              | 5        |
| 高度       | テーブルからの高さ                                            | 0        |

## そのほかの操作

共有メモを右クリックすると、次の操作も並びます。

| 項目                 | すること                                        |
| -------------------- | ----------------------------------------------- |
| 寝かせる・直立させる | テーブルに対する向きを切り替えます              |
| 固定する             | 位置と本文をロックします                        |
| コピーを作る         | 複製を作ります                                  |
| 公開範囲             | 見せる相手を決めます（→ [公開範囲](#公開範囲)） |
| 削除                 | メモを消します                                  |

固定したメモはドラッグで動かせなくなり、タイトルバーに鍵のアイコンが出ます。
誤って動かしたくない掲示物に向いています。
固定しているあいだは書き換えもロックされるので、書き換えるときは固定を外してください。

## 長い本文を枠に収める

**メモを編集**で開いたシートに、**height設定値に高さを制限**のチェックがあります。
入れると、メモの高さがシートの高さ（マス）で止まり、収まらない本文はメモの中でスクロールします。
外すと、メモは本文の長さに合わせて伸びます。

## 整形して表示する

本文に見出しやリストを付けて表示できます。
**メモを編集**で開いたシートの、本文の下にある**表示**を**通常**から**整形**に切り替えます。

整形で読むのは、行の先頭に書いた次の記号です。`#`・`-`・`1.`のあとには空白を入れてください。

| 書き方                   | 表示                                                    |
| ------------------------ | ------------------------------------------------------- |
| `# 見出し`〜`### 見出し` | 見出し。`#`が少ないほど大きな字になります               |
| `- 項目`                 | 点の付いたリスト                                        |
| `1. 項目`                | 番号付きのリスト。番号は書いた数字によらず1から振ります |
| `> 文`                   | 引用                                                    |
| `` `コード` ``           | 行の中のコード。囲んだ文字は書いたとおりに出ます        |
| ` ``` `の行で前後を挟む  | コードの段落                                            |

- 改行はそのまま改行になります。空行を挟むと段落が分かれます
- [ルビ](/manual/chat-syntax#ルビ-ふりがな)はチャットと同じ`|漢字《かんじ》`で振れます。URLはリンクになります。コードの中ではどちらも効きません
- `*`や`_`で囲む強調は読みません。`2*3`のような式は、書いたとおりに出ます

表示を切り替えても、本文の文字は変わりません。「通常」に戻せば、書いたとおりの表示に戻ります。

整形を選ぶと、シートの切り替えの下に書き方の説明と見本が出ます。テーブルのメモ、シートの見本、マウスを乗せたときのポップアップは、どれも同じ見た目です。ただし、テーブルでメモをクリックして書き換えている間は、記号のまま表示されます。整形にしたメモはポップアップでは書き換えられないので、テーブルかシートで書き換えてください。

公開範囲の外の人には、整形にしたメモもモザイクで表示されます。

## 公開範囲

メモは、見せる相手を「全員」「特定PL」「GMのみ」から選べます。
公開範囲の外の人には、メモはテーブルに残りますが、題と本文が伏せ字とぼかしになり、読めません。
決めかたは[情報の公開範囲](/manual/disclosure)にあります。

## うまくいかないとき

| 見えるもの                         | 原因と直しかた                                                                                 |
| ---------------------------------- | ---------------------------------------------------------------------------------------------- |
| クリックしても書き換えられない     | メモが固定されているか、見学です。右クリックで固定を外します                                   |
| 題と本文がぼやけて読めない         | 自分が公開範囲に入っていません。GMかメモのオーナーに、公開範囲を変えてもらいます               |
| 整形にしたのに、記号のまま出ている | テーブルでメモをクリックして書き換えているあいだは、記号のまま出ます。書き終えると整形されます |
| 長い本文がはみ出す                 | **height設定値に高さを制限**を入れると、メモの中でスクロールします                             |

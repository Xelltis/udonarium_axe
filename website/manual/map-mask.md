# マップマスク

このページは、テーブルの一部を覆って隠しておき、必要なときに削って見せる目隠し（マップマスク）を説明します。
まだ入っていない場所を伏せておき、探索が進むたびに少しずつ見せる、といった使いかたをします。
置いて削るのはGMとPLです（ふつうはGMが扱います）。

<Shot src="map-mask" alt="テーブルの一部を覆う黒いマップマスク" caption="伏せておきたい範囲をマスクで覆います" />

## マップマスクを置く

1. テーブルの何もない場所を右クリックします。
2. **マップマスクを作成**を選びます。

5×5マスの黒いマスクが置かれます。
ドラッグで動かせます。
大きさや色は、右クリックの**マスクを編集**で変えます（→ [見た目を変える](#見た目を変える)）。

マス目に沿ってまとめて覆いたいときは、[マップエディター](/manual/map-editor#機能塗り)の機能塗りで塗る方法もあります。
塗った範囲は矩形にまとめられ、10マス塗れば、10個ではなく1つのマスクが置かれます。

## 削って見せる（スクラッチ）

1. マスクを右クリックして、**スクラッチ開始**を選びます。削っている人がマスクの持ち主になり、マスクが少し薄く見えます。
2. マスクの上をドラッグして、見せたい部分を削ります。
3. もう一度右クリックして、**スクラッチ確定**を選びます。削った状態が決まります。

やめるときは、**スクラッチキャンセル**を選びます。
確定するまでは、削り途中の状態を編集できるのは自分だけです。
マスクそのものの移動・コピー・削除は、[オブジェクトの基本操作](/manual/objects)と同じです。

## 見た目を変える

マスクを右クリックして**マスクを編集**を選ぶと、**マップマスク設定**のシートが開きます。

| 節         | 項目                     | 内容                                                | 既定値 |
| ---------- | ------------------------ | --------------------------------------------------- | ------ |
| 基本設定   | 名前・幅・高さ           | 幅と高さはマスの数です                              | 5・5   |
| 基本設定   | 不透明度                 | 下げると、マスクの下が透けて見えます                | 100    |
| マスク     | 画像・色                 | マスクの面に貼る画像か、塗る色                      | 黒     |
| 削ったあと | 画像・色                 | 削って開けたマスに、テーブルの代わりに出す画像か色  | なし   |
| 文字       | 文章・大きさ・色・縁取り | マスクの上に出す文字（→ [文字を書く](#文字を書く)） |        |

「削ったあと」に画像を入れると、削った場所に別の絵を見せられます。
たとえば、覆いの下に、探索済みを示す色を敷いておけます。

## 文字を書く

マスクの上に文字を書いておけます。
「鍵のかかった扉」「未探索の部屋」のように、隠している場所の説明をマスクに直接載せられます。
**マップマスク設定**の**文字**の節で決めます。

| 項目           | 内容                                                                     | 既定値 |
| -------------- | ------------------------------------------------------------------------ | ------ |
| 文章           | マスクの上に出す文。改行もそのまま出ます                                 | 空     |
| 大きさ         | 字の大きさ。8〜200                                                       | 24     |
| 色             | 字の色                                                                   | 白     |
| 縁取りをつける | 字のまわりを黒く縁取ります。画像を貼ったマスクの上でも読みやすくなります | 入り   |

文字は太字で、マスクの中央に描きます。
長い文はマスクの幅で折り返し、マスクに収まらない分は切れます。
文章を空にすると、文字は消えます。

文字の描き先は、マスクそのものです。
スクラッチで削ったマスでは、文字もその部分だけ欠けます。
マスクの不透明度を下げると、文字も同じだけ薄くなります。

[リプレイの動画](/manual/replay#動画に映るもの)には、マスクの文字は映りません。

## うまくいかないとき

| 見えるもの                       | 原因と直しかた                                                                                               |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| マスクを動かせない               | 固定されています。右クリックのメニューで固定を外します                                                       |
| マスクが薄く見える               | スクラッチの途中です。確定するかキャンセルすると、元の濃さに戻ります。ずっと薄いときは、不透明度を確かめます |
| マスクの下のコマや地形を押せない | マスクが上にかぶさっています。削って開けるか、マスクを少しずらしてから押します                               |

# シナリオテキスト

このページは、描写や情報の開示、NPCの台詞のような長い文を前もって書いておき、セッション中にボタン1つでチャットへ送る「シナリオテキスト」を説明します。
チャットと同じ装飾の記法で書けるので、太字や色、ルビ、スタンプを付けたまま保存して、そのまま送れます。

シナリオテキストを書いて送れるのはGMだけです。FABメニューの**メディア**から**シナリオテキスト**を選んで、パネルを開きます。GMツールバーに置くときは、メニューの編集で足します。

## 書く

1. パネルの**新しいテキスト**を押します。
2. 下の欄に、タイトルと本文を書きます。

本文の欄は、チャットの入力欄と同じ書き方です。装飾のボタンで太字や色を付けられ、書いたとおりの見た目で表示されます。Enterキーで改行します。
書いた中身は、手を止めて少し経つと部屋に保存されます。

## 送る

一覧の行の右のボタンか、下の欄の**送る**を押すと、本文をチャットに送ります。
送った行には印が付き、マウスを乗せると送った時刻が出ます。この印は自分のブラウザだけの記録で、部屋のほかの人には見えません。

下の欄で、送り方を決められます。

| 設定   | 選択肢                                                                                                                                                       |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 送り方 | タイトルとして（タイトルが発言者の名前になります）・話しているキャラクターとして・システムとして                                                             |
| タブ   | 開いているタブか、決まったタブ。通知タブを開いているときは、システムとして送るとき以外、最初のタブに送ります                                                 |
| 色     | 発言の色。選ばないと、話し手の色で送ります。選んだ色は、横の**話し手の色に戻す**で外せます                                                                   |
| 秘話   | 送る相手のPLを選ぶと、下の欄の**秘話で送る**で、その人にだけ送ります。一覧の行のボタンは、いつも全員に送ります。ほかのテキストを選ぶと、秘話の相手は外れます |

本文は、書いたとおりに送ります。行頭にダイスの式（`1d100`など）があっても振らず、リソースの操作も読みません。長い文も1つの発言になります。
行を右クリック（スマートフォンでは長押し）すると、**送り方を変えて送る**から、ほかの送り方で1回だけ送れます。

## チャットの入力欄から呼び出す

GMがチャットの入力欄に2文字以上を打つと、その文字をタイトルに含むか、本文のどこかの行がその文字で始まるシナリオテキストが、入力欄の上に候補として出ます。行の途中にあるだけの文字では出ません。
候補を選ぶか、矢印キーで選んでEnterキーを押すと、本文が入力欄に入ります。そのまま送ると、いま話しているキャラクターの発言になります。
PLと見学には、候補は出ません。

## まとめて取り込む

台本の文章を貼り付けて、まとめて取り込めます。

1. パネル上部の取り込みのボタンを押します。
2. 開いた欄に文章を貼り付けて、**取り込む**を押します。

見出しの行（`#`か`■`で始まる行）ごとに、1件のテキストになります。見出しがタイトル、次の見出しまでの行が本文です。最初の見出しより前の文章は、タイトルのないテキストになります。
取り込んだテキストは、一覧で選んでいるテキストと同じフォルダに入ります。

```text
# 導入
雨が降っている。

# 屋敷
扉が**軋む**音がする。
```

## 整理する

フォルダと並べ替えは、[シーン](/manual/scene#フォルダに分ける)と同じです。上部の検索欄に文字を入れると、タイトルか本文にその文字を含むテキストだけが並びます。
行を右クリックすると、複製・フォルダへ移す・並べ替え・削除が出ます。

## 保存と見える範囲

シナリオテキストは部屋の保存データに入り、読み込むと部屋のテキストと入れ替わります。本文に入れたスタンプの画像も、保存のzipに入ります。

[部屋のサーバー](/guide/choose)では、シナリオテキストをGMにしか届けません。PLや見学のブラウザには、データも届きません。作る・書き換える・消すことも、GMにしか許しません。
SkyWay版では、ほかの部屋のデータと同じく全員のブラウザに届き、GM以外の画面に出さないだけです。改造したAxeなら読めるので、知られては困る文は、SkyWay版ではセッションの直前に書くか取り込みます。

# キャラクターの取り込み

ココフォリアや各種キャラクターシート管理サービスのデータから、AXE の [キャラクターコマ](/manual/character) を生成する機能です。

<Shot src="character-import" alt="キャラクター取り込みパネル。JSON または URL を貼り付ける入力欄がある" width="520" caption="対応サービスの JSON か URL を貼るだけでコマになります" />
他ツールで作ったキャラクターを、能力値・リソース・チャットパレットごと AXE に持ち込めます。

## 取り込みパネルを開く

FAB メニューの **部屋設定** を開き、**ユーティリティ** タブの **「キャラ取り込み」**（人物＋アイコン）を押すと、取り込みパネルが開きます。
スマートフォンでは下部メニューの **キャラ取り込み** からです。

パネルの入力欄に、取り込み元の **JSON テキスト** または **キャラクターの URL** を貼り付けて、**「取り込む」** を押すとテーブルにコマが追加されます。

::: tip 取り込めるのは編集できる人だけ
卓の編集権限がないロール（見学など）では取り込みできません。ロールについては [ロール（GM / PL / 見学）](/manual/roles) を参照してください。
:::

## 対応している取り込み元

| 取り込み元                                                 | 貼り付けるもの                       |
| ---------------------------------------------------------- | ------------------------------------ |
| **ココフォリア形式のコマ JSON**                            | 「ココフォリア用コピー」で得た JSON  |
| **キャラクター保管所**（charasheet.vampire-blood.net）     | JSON、またはキャラクターページの URL |
| **キャラクターシート倉庫**（character-sheets.appspot.com） | JSON、またはキャラクターページの URL |
| **ゆとシート**（ソード・ワールド2.5）                      | JSON、またはキャラクターページの URL |
| **CharaXiv**                                               | 「ココフォリア用コピー」で得た JSON  |

いあきゃら・Charaeno・ゆとシート・TRPG スタジオ・CharaXiv など多くの作成サービスは
「ココフォリア用コピー」を備えているため、その出力をそのまま貼り付けるのが最も確実です。

どのサービスのどのデータ種別・どのゲームシステムを取り込めるかの一覧は、
取り込みパネル内の **「対応状況」「対応ゲームシステム一覧」** で随時確認できます（下記の表はその要約です）。

## 使い方

### ココフォリア形式の JSON を貼り付ける（最も確実）

1. 取り込み元のサービスで **「ココフォリア用コピー」「ココフォリアにコピー」** などのボタンを押す
2. AXE の取り込みパネルに貼り付けて **「取り込む」**

名前・アイコン・ステータス・能力値・チャットパレットまでまとめて取り込めます。

### キャラクター保管所 / キャラクターシート倉庫

次のどちらでも取り込めます。

- **URL を貼り付ける** — キャラクターページの URL をそのまま貼り付けると、自動でデータを取得します。
- **JSON を貼り付ける** — 取得済みの JSON テキストを貼り付けます。

**キャラクターシート倉庫** と **キャラクター保管所** は、能力値・技能・コンボ・武器・アイテムなど、
そのゲームシステム固有のデータも**できる限り落とさず**取り込み、キャラクターシートのセクションとして展開します。
保管所のクトゥルフ（CoC）では、能力値（STR・CON…）や正気度（SAN）を見やすいラベルで取り込みます。
倉庫の**サイフィク系（シノビガミ・インセイン等）**は、習得特技を**ギャップ付きの特技表**としてサンプルキャラと同じ形で取り込みます。

::: warning 見出し名がサービス内部の名称になることがあります
これらのサービスはゲームシステムごとにデータの持ち方が大きく異なります。データ自体は保持しますが、
システムによっては見出しがサービス内部のキー（`combo`・`weapons`・`TKAD` など）のまま取り込まれたり、
技能名がデータに含まれず**行番号で並ぶ**ことがあります。取り込み後にキャラクターシートで
見出しを整えたり、不要な項目を削除したりして仕上げてください。
:::

### CharaXiv

CharaXiv は URL からの自動取得に対応していません。CharaXiv 側の **「ココフォリア用コピー」** で出力した JSON を貼り付けてください。

## 取り込まれる内容

| 取り込み元の項目                                     | AXE のキャラコマ                               |
| ---------------------------------------------------- | ---------------------------------------------- |
| 名前                                                 | コマ名                                         |
| アイコン画像                                         | コマ画像（取得できた場合のみ）                 |
| ステータス（現在値／最大値）                         | リソース（HP / MP など）                       |
| 能力値・パラメータ                                   | データ要素                                     |
| メモ・参照元 URL                                     | プロフィールのデータ要素                       |
| コマンド                                             | [チャットパレット](/manual/chat-palette)       |
| システム固有データ（能力値・技能・コンボ・武器など） | キャラクターシートのセクション（保管所・倉庫） |
| サイフィク系の習得特技                               | ギャップ付きの特技表（倉庫）                   |

取り込んだあとは通常のキャラクターコマと同じく、[キャラクターシート](/manual/character) で自由に編集できます。

## 対応状況と対応ゲームシステム

正確な最新の対応状況は、取り込みパネル内の **「対応状況」「対応ゲームシステム一覧」** に表示されます（アプリ内が正です）。以下は要約です。

凡例: ✅対応 / 🔸部分 / 🔁ココフォリア経由 / ✖非対応

| データ種別           | ココフォリア | 保管所 | 倉庫 | ゆとシート | CharaXiv |
| -------------------- | ------------ | ------ | ---- | ---------- | -------- |
| 名前                 | ✅           | ✅     | ✅   | ✅         | 🔁       |
| アイコン画像         | ✅           | 🔸     | ✖    | ✖          | 🔁       |
| リソース(現在/最大)  | ✅           | ✅     | 🔸   | ✅         | 🔁       |
| 能力値               | ✅           | 🔸     | ✅   | ✅         | 🔁       |
| 特技表（サイフィク） | ✖            | ✖      | ✅   | ✖          | 🔁       |
| システム固有データ   | ✖            | ✅     | ✅   | ✅         | 🔁       |
| チャットパレット     | ✅           | ✖      | ✖    | ✅         | 🔁       |
| ダイスボット         | ✖            | ✅     | ✅   | ✅         | 🔁       |
| 発言色               | ✅           | ✅     | ✖    | ✖          | 🔁       |
| メモ                 | ✅           | ✅     | 🔸   | ✅         | 🔁       |
| 外部URL              | ✅           | ✅     | ✖    | ✖          | 🔁       |

対応ゲームシステムは、**保管所が約 30 種・倉庫が約 70 種**におよびます。
倉庫・保管所は同一構造のため**全ホストシステムを汎用取り込み**でき、主要システム（クトゥルフ、ソード・ワールド、ダブルクロス、シノビガミ、インセイン、ステラナイツ、ビーストバインド ほか）は**専用プロファイル**で能力値・技能・特技表まで最適化して取り込みます。全リストは取り込みパネルの「対応ゲームシステム一覧」を参照してください。

## うまくいかないとき

- **画像が入らない** — 取り込み元の仕様や通信の制限により、アイコン画像を取得できないことがあります。コマは作成されるので、画像は [画像](/manual/images) パネルから手動で設定してください。
- **「取得に失敗しました」と出る** — 通信エラーか URL が正しくない可能性があります。取り込み元でデータ（JSON）を直接コピーして貼り付け直してみてください。
- **「対応していない」と出る** — その形式・URL には未対応です。取り込み元の「ココフォリア用コピー」で出力した JSON を貼り付けてください。

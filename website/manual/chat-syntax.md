# チャットの特殊記法

このページは、チャットの入力欄に書ける特殊な記法（リソースの操作・バフ・立ち絵・カットイン・ルビ・参照など）を一覧にまとめたものです。
ダイスのコマンドそのものは、[ダイスボット](/manual/dicebot)にあります。
記号は原則として**半角・全角どちらでも**入力できます。

| 記法                      | 機能                                             |
| ------------------------- | ------------------------------------------------ |
| `2d6+1`など               | ダイスロール（[ダイスボット](/manual/dicebot)）  |
| `S2d6`                    | シークレットダイス                               |
| `dice:コマ名`             | [卓上ダイスと連動](#卓上ダイスと連動)            |
| `:HP-5`                   | [リソース操作](#リソース操作)                    |
| `&猛攻撃/3/red`           | [バフ／デバフ操作](#バフ-デバフ操作)             |
| `@立ち絵名` / `@2`        | [立ち絵の切り替え](#立ち絵コマンド)              |
| `カットイン名` / `@同名`  | [カットイン起動](#カットイン起動)（文末）        |
| `《爆炎》`                | [演出の起動](#演出の起動)                        |
| `《vs》`                  | [戦闘カットインの起動](#戦闘カットインの起動)    |
| `\|漢字《かんじ》`        | [ルビ](#ルビ-ふりがな)                           |
| `**太字**` / `[明朝]…[/]` | [文字の装飾](#文字の装飾)                        |
| 行頭`>`                   | [引用スタイル](#引用)                            |
| `{HP}` / `//変数=値`      | [項目と変数の参照](#項目と変数の参照)            |
| `〔地の文・ゆれ〕`        | [ノベルモード演出](/manual/visual-novel)（文末） |
| `［了解:seal:ok］`        | [文中のスタンプ](#文中のスタンプ)                |

## 書式つきの入力欄

チャットの入力欄では、太字や色、ルビを、送ったあとと同じ見た目のまま書けます。`**`や`[赤]`などの記号は、書いている途中も出ません。送るときに、このページの記法の文字列に直して送ります。

送る文字列は、これまでと同じ記法です。古い版のUdonarium Axeでも、同じように読めます。入力欄で手を入れた行は、見た目が同じまま書き方がそろうことがあります。たとえば`[太字]`は`**`に、英語や韓国語の装飾の名前は表示している言語の名前になります。履歴から呼び戻した行など、手を入れていない行は1字も変わりません。

### 書式を付ける

入力欄の枠の上端には、太字（B）・斜体（I）・書式（Aa）・ルビと、記法の種類ごとのボタンが並びます。取り消し線・大きさ・書体・文字色は、書式（Aa）の中にあります。文字を選んでからボタンを押すと、選んだ部分の書式を付け外しします。何も選んでいないときは、これから打つ文字に付きます。カーソルの位置や選んだ部分に付いている書式は、ボタンの色が変わって分かります。

文字を選ぶと、選んだ部分の上にも小さなバーが出ます。太字・斜体・取り消し線・文字色・ルビは、このバーからも付けられます。キーでは、`Ctrl`＋`B`で太字、`Ctrl`＋`I`で斜体、`Ctrl`＋`Shift`＋`S`で取り消し線を付け外しします。

`**強く**`のように記法を打ち終えると、その場で書式に変わります。直後に`Backspace`を押すと、打ったとおりの記号に戻ります。

ルビは、ふりがなを振る文字を選んでから**ルビ**を押し、読みを入れます。付けたルビを押して選び、もう一度**ルビ**を押すと、読みを直したり、ルビを外したりできます。

### 部品

参照の`{HP}`、ルビ、演出の`《爆炎》`、立ち絵の`@笑顔`、文末のカットイン名、スタンプは、ひとかたまりの部品として出ます。部品は1つの単位で選び、消し、動かせます。参照の部品には、いまの値も出ます。部品のすぐ後ろで`Backspace`を押すと、記法の文字に戻って書き直せます。

立ち絵とカットインは、手で打っているあいだは色の付いた文字のままで、名前の候補や記法のボタンから入れたときに部品になります。どちらで書いても、送ったときの効き方は同じです。立ち絵とカットインは文末にあるときだけ効くので、文末にない部品は薄く出ます。ポインタを乗せると理由が出ます。

### 記法を入れる

入力欄の上端には、ダイス・参照・リソース操作・バフ・立ち絵・演出とカットイン・引用の種類ごとにボタンがあり、押すとその種類の一覧が上に開きます。項目には書き方が並び、選ぶと、その記法が読まれる場所に入ります。立ち絵とカットインは文末に、シークレットは行頭に入ります。ダイスのタブには、選んでいるダイスボットのコマンドの例も並びます。

`{`のあとにはステータスと変数、`《`のあとには演出、`@`のあとには立ち絵、語の頭の`:`のあとにはステータス、`&`のあとには付いているバフの名前の候補が、カーソルの上に出ます。`↑`・`↓`で選び、`Enter`か`Tab`で入れます。`Esc`で閉じます。候補が出ていないときの`Enter`は送信です。

貼り付けた文は記法として読み、書式と部品にして入れます。記法を文字のまま入れたいときは、`Ctrl`＋`Shift`＋`V`で貼り付けます。入力欄からコピーした文は、記法の文字列になります。

### 色分けと指摘

部品にならない記法には、種類ごとの色の帯が付きます。ダイスのコマンドは青、リソース操作はオレンジ、バフは紫、というように、送る前にどう読まれるかが分かります。文字そのものは、発言の色のままです。

このまま送ると効かない書き方には、波線が付きます。波線にポインタを乗せると、理由が出ます。たとえば、ダイスボットが振れないコマンド、発言者のコマにない項目、見つからない立ち絵、対象のコマがいない演出に付きます。入力欄の右下に指摘の数が出て、押すと一覧が上に開きます。一覧の行を押すと、その記法が選ばれます。

指摘があっても、送ることはできます。ダイスボットのコマンドは、選んでいるダイスボットで実際に振れるかを確かめます。ダイスボットを読み込むまでのあいだは、ダイスについての指摘は出ません。

### パレットの編集欄

チャットパレットの編集欄も、同じ入力欄で書きます。`//変数=値`と`◆◆`の行は、文字のまま色だけが付きます。`Enter`は改行です。手を入れていない行は、保存しても1字も変わりません。指摘は、パレットの行ごとに、そのコマから送ったときの読まれ方で確かめます。

### もとの入力欄に戻す

チャットの設定（歯車アイコン）の「書式つきの入力欄を使う」を外すと、記法をそのまま打つ入力欄になります。ツールバーはこちらでも使え、選んだ文字を記法で囲みます。色分けと指摘、部品、名前の候補は出ません。この設定は、その端末だけのものです。

## 文中のスタンプ

スタンプを文の中に入れると、`［了解:seal:ok］`のように、スタンプの名前とIDを括弧で囲んだ形で送られます。チャットでは、この形が文字と同じくらいの大きさのスタンプとして出ます。書式つきの入力欄ではスタンプが部品として出るので、この形を打つことはありません。記法をそのまま打つ入力欄では、スタンプのボタンで選ぶとこの形が入ります。IDは書き換えないでください。

部屋で止められているスタンプと、この版にないスタンプは、`［了解］`のように名前だけの文字で送られます。古い版のUdonarium Axeでは、この形のまま文字で出ます。

## ダイスロール

選択中のダイスボットのコマンド（`2d6+1`、`1d100<=50`など）をそのまま入力するとダイスを振ります。詳細は[ダイスボット](/manual/dicebot)を参照してください。

- **シークレットダイス** — コマンドの先頭に`S`を付けると（例: `S2d6`）、結果が他の参加者から伏せられます

## 卓上ダイスと連動

`dice:コマ名`を書き添えると、そのロールの出目が、コマに持たせた卓上のダイスに乗ります。

```
2d6 dice:ゴブリンA
```

出た目は、面の数が合うダイスから順に入ります。`dice:`だけを書いた場合は発言しているコマが対象です。ダイスをコマに持たせる手順は[ダイス](/manual/dice)を参照してください。

## リソース操作

`:`で始まる記法で、キャラクターのステータス（リソース）をチャットから直接操作できます。発言キャラクターのインベントリにある同名の項目が対象です。

```
:HP-5        HP を 5 減らす
:HP+1d6      HP をダイスの出目だけ増やす（ダイス式が使えます）
:MP=10       MP を 10 にする
:状態>毒     「状態」をテキスト「毒」に置き換える
:HP-3:MP-1   連結して複数同時に操作
```

### 特殊なダイスコマンドを式に混ぜる

`2d6`のような一般的なダイス式は、そのまま計算式の一部として書けます。一方で、ゲームシステムの固有のコマンド（威力表を引く`k10`や、`2dx`のような判定）は、ダイスボットが単独のコマンドとして解釈するため、足し算の項には置けません。角括弧で囲むと、その部分だけを先に振り、出た数値を式に戻してから残りを計算します。

```
t:HP-([k10]+5-t{防護})   威力表 10 の出目に 5 を足し、対象の防護点を引いた分だけターゲットの HP を減らす
:MP-[2dx]                振った結果のぶんだけ MP を減らす
:HP-([k10]+[k5])         2 つ振って合計する
```

振った内訳は、操作結果の下に`└ [k10] KeyNo.10c[10] ＞ …`の形で並びます。囲んだコマンドを部屋のダイスボットが解釈できなかった場合、その操作は行われず「計算できません」と表示されます。

### 対象サフィックス

リソース名の直後にサフィックスを付けると、現在値以外を操作できます。

| サフィックス | 対象             | 例               |
| ------------ | ---------------- | ---------------- |
| なし         | 現在値           | `:HP-5`          |
| `^`          | 現在の最大値     | `:HP^+10`        |
| `_MAX`       | 最大値（ベース） | `:HP_MAX+5`      |
| `_MAX_BUFF`  | 最大値の補正値   | `:HP_MAX_BUFF+3` |
| `_MIN`       | 最小値（ベース） | `:HP_MIN-1`      |
| `_MIN_BUFF`  | 最小値の補正値   | `:HP_MIN_BUFF+1` |

### オプション

値の末尾に付けると挙動を変えられます（大文字小文字どちらでも可）。

- `L` — 最小値・最大値の範囲内に収めます（例: `:HP+99L`）
- `Z` — 0を跨ぐ変化を0で止めます（例: `:HP-99Z`）

### プレフィックス

- `t:` — 発言キャラクターではなく、**ターゲット中のキャラクター**に適用します（対象ごとに`[名前]`付きで処理されます）
- `s:` — 結果を伏せて適用します（シークレット）。`st:`のように組み合わせ可能です。1行にいくつ書いても、すべて効きます

## バフ／デバフ操作

`&`で始まる記法で、キャラクターの[バフ／デバフ](/manual/buff)をチャットから操作できます。

```
&猛攻撃                 バフ「猛攻撃」を付与
&猛攻撃/攻撃+2          サブ情報付きで付与
&猛攻撃/攻撃+2/3        3 ラウンドの期限付きで付与（省略時 3R）
&毒/継続2/3/red         バッジの色を指定して付与
&毒/継続2/3/red/☠️      色と絵文字を指定して付与（順不同）
&練技/筋力+2/3/手番開始/@術者   術者の手番開始時に減るバフ
&!猛攻撃/命中/+/2/3     ステータスを実際に動かすバフ
&+猛攻撃/攻撃+2/3       すでに付いている「猛攻撃」に +2 を足す
&++猛攻撃/攻撃+2/3      +2 を足したうえで残ラウンドも 3 延ばす
&猛攻撃-                バフ「猛攻撃」を解除
&R+ / &R-               全バフのラウンドを増減
&D                      0 ラウンド以下のバフをまとめて消去
&&none-                 消えないバフを卓全体から解除（GM のみ）
&&2R-                   残り 2R のバフを卓全体から解除（GM のみ）
&&猛攻撃-               「猛攻撃」を卓全体から解除（GM のみ）
```

`&&`で始まる3つは、発言者やターゲットではなく**卓にいる全員**が対象です。GMだけが使えます。詳しくは[バフ／デバフ](/manual/buff#sweep)を参照してください。

色は`red` `orange` `yellow` `green` `blue` `purple` `pink` `gray`の英名、`赤` `青`などの和名、`#c62828`のような16進で指定できます。`既定`と書くと黒に戻ります。指定した色と絵文字は[コマの頭上のバッジ](/manual/buff)にそのまま出ます。

4つ目以降には、色と絵文字のほかに**消失タイミング**と**トリガー**も書けます。タイミングは`手番開始`
`手番終了` `ラウンド終了`（`turnStart` `turnEnd` `roundEnd`などの英名も可）、トリガーは`@名前`です。
指定しなければ、これまでどおりラウンド終了時に減ります。

`&!`で始めると、覚え書きではなく**ステータスを実際に動かす**バフになります。書く順番は
`&!バフ名/ステータス/操作/量/ラウンド/タイミング/トリガー`で固定です。操作は`+` `-` `=`の3つです。
ステータス名のうしろに`^`を付けると（`HP^`）、最大値側が対象になります。バフが切れると、動かした分だけ戻ります。
量には`(3+4)÷2`のような計算式も書けます。割り算は`÷`か全角の`／`で書き、端数は割るたびに切り捨てます（[量に計算式を書く](/manual/buff#量に計算式を書く)）。

```
&!猛攻撃/命中/+/2/3              命中を 2 上げ、3R 後に 2 戻す
&!鈍足/敏捷/=/1/2                2R のあいだ敏捷を 1 に留める
&!練技/筋力/+/2/3/手番開始/術者   術者の手番開始時に減る
&!変身/器用度/+/5~-1/5           器用度を 5 上げ、減るたびに 1 ずつ戻す
&!猛攻撃/命中/++/1/3             命中を 1 上げ、減るたびに 1 ずつ足す
&!全力攻撃/追D+4,回避-2/1        追加ダメージと回避を 1 つのバフで動かす
```

量のうしろの`~`と、2つ重ねた操作（`++` `--`）は、残ラウンドが減るたびにステータスをさらに動かします（[数えるたびに動かす](/manual/buff#数えるたびに動かす)）。
2つ目の欄に`追D+4,回避-2`のように並べると、1つのバフでいくつものステータスを動かします。そのときは、うしろにラウンド・タイミング・トリガーが続きます（[いくつものステータスを動かす](/manual/buff#いくつものステータスを動かす)）。

`!`を付けずに同じ並びで`&猛攻撃/命中/+/2/3`と書くと、覚え書きのバフとして読みます。効果欄は`命中+2`、ラウンドは3で、ステータスは動きません。

詳しくは[バフ／デバフ](/manual/buff#ステータスを動かすバフ)を参照してください。

`&`のすぐうしろに`+`を置くと、同じ名前のバフがすでに付いているとき、値を上書きせずに**足します**。
`&猛攻撃/攻撃+2/3`を2回打っても効果欄は`攻撃+2`のままですが、`&+猛攻撃/攻撃+2/3`なら`攻撃+4`に
なります。減らしたいときは`&+猛攻撃/攻撃-1/3`とマイナスで書きます。

`+`を2つ並べると、残ラウンドも足します。`&+`では残ラウンドの長いほうが残るので、持続を延ばしたいときは`&++`を使います。
効果欄を空にすれば、効果はそのままで持続だけ延ばせます。

```
&+猛攻撃/攻撃+2/3        効果欄を 攻撃+4 にする（残Rは長いほう）
&++猛攻撃/攻撃+2/3       効果欄を 攻撃+4 にして残Rを 3 足す
&++加護//3               効果欄はそのままで残Rを 3 足す
&+!猛攻撃/命中/+/2/3     命中をもう 2 上げ、外すと 4 戻る
```

詳しくは[バフ／デバフ](/manual/buff#重ねがけ)を参照してください。

リソース操作と同じく`t&`（ターゲットへ適用）、`s&`（シークレット）のプレフィックスが使えます。

## 立ち絵コマンド

文末に半角スペースを空けて`@～`を書くと、発言と同時に立ち絵を切り替えられます。一致する立ち絵が見つかった場合、コマンド部分は本文から取り除かれて送信されます。

| 記法    | 機能                                                 |
| ------- | ---------------------------------------------------- |
| `@hide` | 立ち絵を隠す                                         |
| `@2`    | 番号で切り替え（一覧の2枚目）                        |
| `@笑顔` | 名前で切り替え（完全一致を優先し、なければ前方一致） |

大文字小文字・全角半角は区別されません（`@HIDE`、`＠ｈｉｄｅ`も可）。

名前は[キャラクターシート](/manual/character#立ち絵に名前をつける)の立ち絵一覧でつけます。名前のない立ち絵と、名前に空白がある立ち絵は、番号でしか呼べません。入力欄の候補にも出ません。数字だけを書いたときは番号、それ以外は名前として扱うので、`@笑顔2`のように数字で終わる名前もそのまま使えます。

番号は一覧に並ぶ順で、`@1`が1枚目です。シートの立ち絵に添えてある番号と、リモコンやノベルモードに出る`2/3`の左側の数字が、そのまま書ける番号です。

## カットイン起動

「チャットから起動」を許可した[カットイン](/manual/cut-in)は、文末の単語が名前と完全一致すると再生されます。

- `見せ場だ カットイン名` — 映像つきでカットインを再生
- `見せ場だ @カットイン名` — **音声のみ**を再生

秘話で使うと相手にだけ再生されます。シークレットダイスなど伏せられた発言からは起動しません。

## 演出の起動

本文に`《エフェクト名》`と書くと、その行を送ったときに[マップ演出](/manual/map-effects)が出ます。

```
2d6+3 t:HP-10 《爆炎》
```

この1行で、ダイス → ダメージ処理 → 演出まで続けて実行されます。対象は`t:`と同じで、撃ち手はその行を喋ったコマです。書く名前はエフェクト集に登録したもので、記法そのものはエフェクトの右クリックから入力欄へ入れられます。

## 戦闘カットインの起動

リソースを減らす行に`《vs》`を書くと、発言したキャラクターが`t:`の対象を攻撃する[戦闘カットイン](/manual/battle-cut-in)が全員の画面に出ます。

```
2d6+3 t:HP-10 《爆炎》《vs》
```

ダメージの処理が終わってから、減ったあとの数字で再生します。`《エフェクト名》`を一緒に書くとそのエフェクトで攻撃し、カットインの中に出します。

## ルビ（ふりがな）

`|テキスト《ルビ》`でテキストにルビを振れます。`|`は全角`｜`でも構いません。

```
|招雷《しょうらい》ドラム・スタッカート！
```

この書き方は、親文字をひとまとまりにして、その上にルビを振ります（グループルビ）。「明日（あした）」のような熟字訓や当て字に向きます。

ルビを`|`で区切ると、親文字1文字ずつにルビを振ります（モノルビ）。区切りの数は親文字の文字数と同じにします。区切りの間を空にすると、その文字にはルビを振りません。区切りの数が親文字の文字数と合わないときは、区切りを外してグループルビとして振ります。

```
|漢字《かん|じ》
|東京都《とう|きょう|と》
```

親文字もふりがなも、まわりの本文と同じ文字色・太さで表示されます。[発言色](/manual/chat)を変えるとルビもその色に追従します。

親文字とルビの長さが違うときは、短い方の文字の間を「1：2：1」の割合で空けて、長い方にそろえます。ルビは親文字の中央に付けます（中付き）。この見え方は、[チャット設定](/manual/chat#chat-settings)の**ルビ**で読み手ごとに変えられます。

[ノベルモード](/manual/visual-novel)の吹き出しとバックログにも同じルビが付きます。文字送りの途中で記号が見えることはなく、親文字の1文字目が出た時点でふりがなも表示されます。

スペースを含めたいときは、`\s`と書くと半角スペースとして表示されます。

## 文字の装飾

発言の一部を太字にしたり、書体・大きさ・色を変えたりできます。入力欄の上のツールバーからも付けられます（→ [書式つきの入力欄](#書式つきの入力欄)）。

```
今日は**晴れ**です
[明朝]古の契約に従い、[/明朝]扉は開かれた。
[赤][大]危ない！[/大][/赤]
```

`**`で囲んだ部分は太字になります。`**`は、同じ行の中で2つそろったときだけ効きます。複数の行にまたがる太字は、1行ずつ`**`で囲んで送ります。

ほかの装飾は`[名前]`で始めて`[/名前]`で閉じます。閉じるほうは`[/]`だけでも構いません。その場合は、最後に開いた装飾が閉じます。装飾は重ねられ、内側の書体・大きさ・色が優先されます。

| 種類                   | 名前                                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------------------ |
| 太字・斜体・取り消し線 | `[太字]` `[斜体]` `[取消線]`                                                                           |
| 大きさ                 | `[小]` `[大]` `[特大]`                                                                                 |
| 書体                   | `[明朝]` `[丸ゴシック]` `[手書き]` `[ポップ]` `[ドット]` `[ゴシック]`                                  |
| 文字色                 | `[赤]` `[橙]` `[黄]` `[緑]` `[水色]` `[青]` `[紫]` `[桃]` `[灰]` `[白]` `[黒]`、`[#f80]`などの色コード |

`[白]`と`[黒]`は、明るい配色と暗い配色のどちらのチャットでも読めるよう、反対の色で細く縁取って表示します。白や黒に近い色コードも同じです。

名前は英語（`[bold]`・`[mincho]`・`[red]`など）と韓国語（`[굵게]`・`[명조]`・`[빨강]`など）でも書けます。ツールバーで付けた装飾は、表示している言語の名前で書かれます。

`[ゴシック]`は、いつもの書体に戻す名前です。明朝・丸ゴシック・手書き・ポップ・ドットの5つの書体はアックスに同梱していて、発言で使われたときに初めて読み込みます。ハングルなど、その書体に無い文字はいつもの書体で表示されます。

閉じていない`[赤]`や、知らない名前の`[注意]`は、書いたとおりの文字で表示されます。装飾になる記号をそのまま書きたいときは、`\**`や`\[赤]`のように前に`\`を付けます。装飾にならない記号の前にある`\`は、そのまま表示されます。

装飾は、共有メモ・カードの文面・ノベルモードの吹き出しとバックログ・配信用画面・HTML形式で保存したログにも付きます。HTML形式のログは書体を持たないので、その書体が入っている端末でだけ同じ書体になります。テキスト形式のログ・ティッカー・頭上の吹き出し・チャット検索・発言のコピーでは、記法を外した文字になります。旧版のアックスやほかのツールでは、記法がそのまま表示されます。

## 引用

行頭に`>`を付けると引用スタイルで表示されます。連続する`>`行はひとつの引用ブロックにまとまります。

```
> 昨日のセッションのログより
> 「あの扉は開けるな」
```

## 項目と変数の参照

`{名前}`と書くと、送信するときにコマの値へ置き換わります。読むのは[シートの項目](/manual/data-element)と、
そのコマの[チャットパレット](/manual/chat-palette)に書いた変数です。

```
//武器ボーナス=2
2d6+{武器ボーナス} 攻撃！
:HP-{HP^}
```

- `//名前=値` — 変数を定義します。定義を書く場所はチャットパレットの中だけです
- `{名前}` — 送信時に値へ置き換わります。変数が無ければ同じ名前のシート項目を読みます
- `{HP^}` — リソースの最大値を読みます。付けなければ現在値です
- `t{名前}` — ターゲット中のコマの値を読みます
- 変数の値にさらに`{...}`を含める入れ子も可能です

同じ名前の項目がシートに2つ以上あるときは、`{戦闘特技/最終能力/コスト}`のようにパスで書きます。
パスはシートの行から**参照名をコピー**で取れます。

コマに無い名前は、チャットパレットから送ると空になります。チャット欄に打ったときは、`やった{歓喜}`のように書いたまま送ります。
ただし、先頭のダイスの式に、数字や閉じかっこのすぐ後ろへ付けた参照は、チャット欄でも空になります。`2d+10{加護}`は、加護（効果`+10`）があれば`2d+10+10`、無ければ`2d+10`で振ります。

### 攻撃する側の値でターゲットを減らす

`t:`の操作の中でも、`{名前}`が読むのは発言者のコマです。ターゲットにしたコマの値は`t{名前}`で読みます。発言者のコマの値で、ターゲットのリソースを減らせます。

```
t:HP-{攻撃力}               発言者の攻撃力の分だけ、ターゲットのHPを減らす
t:HP-({攻撃力}-t{防護})     発言者の攻撃力から、ターゲットの防護を引いた分だけ減らす
```

`{名前}`にバフの名前を書くと、式の中では、バフの効果に書いた数を読みます。コマの頭上のバッジに出る数と同じです。効果が`攻撃+2`の練技なら、`t:HP-({攻撃力}+{練技})`は攻撃力に2を足した分だけ減らします。数が負のバフは`(-1)`のようにかっこ付きで入り、`2d+10{加護}`のように数のすぐ後ろへ付けたときは、符号ごと入ります。式の外に書いたときは、`{練技}`は効果の文字のまま入ります。式とは、行の先頭のダイスの式と、`:`の操作の量のことです。

### 参照するコマ

チャットパレットからでも、チャットウィンドウの入力欄からでも同じように展開されます。ただし入力欄から送る場合、
値を読む先は**発言者に選んだコマ**です。発言者が「プレイヤー（あなた）」のままだと読む先が無いため、
`{`と`}`は書いたまま送られます。

## ノベルモード演出

文末の`〔～〕`で吹き出しの形や立ち絵の動きを指定できます。詳細は[ビジュアルノベルモード](/manual/visual-novel)を参照してください。

## うまくいかないとき

| 見えるもの                                    | 原因と直しかた                                                                                                          |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `:HP-3`のような操作が効かない                 | 発言者のキャラクターに、その名前の項目があるかを確かめます。発言者がキャラクターでないときも効きません                  |
| リソースの操作が反映されない                  | 見学のときは、キャラクターとして話しても、リソースの操作・立ち絵の切り替え・テーブルのダイスへの反映は効きません        |
| `{HP}`が数字にならない                        | 発言者のコマに、その項目がありません（→ [チャット欄では発言者のコマを読む](#参照するコマ)）                             |
| `k10`のようなコマンドを式に混ぜると振られない | 固有のコマンドは、角括弧で囲んで式に混ぜます（→ [特殊なダイスコマンドを式に混ぜる](#特殊なダイスコマンドを式に混ぜる)） |
| 入力欄の記法に波線が付く                      | 波線にポインタを乗せると理由が出ます。入力欄の右下の数から一覧も開けます（→ [色分けと指摘](#色分けと指摘)）             |

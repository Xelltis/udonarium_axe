# チャットの特殊記法

このページはチャットの入力欄に書ける特殊な記法（リソースの操作・バフ・立ち絵・カットイン・ルビ・参照など）を一覧にまとめたものです。
ダイスのコマンドそのものは[ダイスボット](/manual/dicebot)にあります。
記号は原則として**半角・全角どちらでも**入力できます。

## 書式つきの入力欄

チャットの入力欄では、太字や色、ルビを、送ったあとと同じ見た目のまま書けます。`**`や`[赤]`などの記号は書いている途中も出ません。送るときに、このページの記法の文字列に直して送ります。

送る文字列はこれまでと同じ記法です。古い版のUdonarium Axeでも、同じように読めます。入力欄で手を入れた行は、見た目が同じまま書き方がそろうことがあります。たとえば`[太字]`は`**`に、英語や韓国語の装飾の名前は表示している言語の名前になります。履歴から呼び戻した行など、手を入れていない行は1字も変わりません。

### 書式を付ける

入力欄の枠の上端には、太字（B）・斜体（I）・書式（Aa）・ルビと、記法の種類ごとのボタンが並びます。取り消し線・大きさ・書体・文字色は、書式（Aa）の中にあります。文字を選んでからボタンを押すと、選んだ部分の書式を付け外しします。何も選んでいないときは、これから打つ文字に付きます。カーソルの位置や選んだ部分に付いている書式は、ボタンの色が変わって分かります。

文字を選ぶと、選んだ部分の上にも小さなバーが出ます。太字・斜体・取り消し線・文字色・ルビは、このバーからも付けられます。キーでは、`Ctrl`＋`B`で太字、`Ctrl`＋`I`で斜体、`Ctrl`＋`Shift`＋`S`で取り消し線を付け外しします。

`**強く**`のように記法を打ち終えると、その場で書式に変わります。直後に`Backspace`を押すと、打ったとおりの記号に戻ります。

ルビは、ふりがなを振る文字を選んでから**ルビ**を押し、読みを入れます。付けたルビを押して選び、もう一度**ルビ**を押すと、読みを直したり、ルビを外したりできます。

### 部品

参照の`{HP}`、ルビ、演出の`《爆炎》`、立ち絵の`@笑顔`、文末のカットイン名、スタンプは、ひとかたまりの部品として出ます。部品は1つの単位で選び、消し、動かせます。参照の部品には、いまの値も出ます。部品のすぐ後ろで`Backspace`を押すと、記法の文字に戻って書き直せます。

立ち絵とカットインは、手で打っているあいだは色の付いた文字のままで、名前の候補や記法のボタンから入れたときに部品になります。どちらで書いても、送ったときの効き方は同じです。立ち絵とカットインは文末にあるときだけ効くので、文末にない部品は薄く出ます。ポインタを乗せると理由が出ます。

### 記法を入れる

入力欄の上端には、ダイス・参照・リソース操作・バフ・行動順・立ち絵・演出とカットイン・引用の種類ごとにボタンがあり、押すとその種類の一覧が上に開きます。項目には書き方が並び、選ぶと、その記法が読まれる場所に入ります。立ち絵とカットインは文末に、ダイスのコマンドとシークレットは行頭に、行動順のコマンドは発言の先頭に入ります。リソース操作とバフは、前の文字に続くときは空白を挟んで入ります。ダイスのタブには選んでいるダイスボットのコマンドの例も並びます。リソース操作とバフの一覧には[値を既定値に戻す書き方とバフをまとめて外す書き方](#バフと値のリセット)も並び、卓の上の全コマを対象にする形はGMにだけ出ます。

`{`のあとにはステータスと変数、`《`のあとには演出、`@`のあとには立ち絵、語の頭の`:`のあとにはステータス、`&`のあとには付いているバフの名前の候補が、カーソルの上に出ます。発言の先頭の`&`のあとには、[行動順のコマンド](#行動順の操作)も並びます。`↑`・`↓`で選び、`Enter`か`Tab`で入れます。`Esc`で閉じます。候補が出ていないときの`Enter`は送信です。

貼り付けた文は記法として読み、書式と部品にして入れます。記法を文字のまま入れたいときは、`Ctrl`＋`Shift`＋`V`で貼り付けます。入力欄からコピーした文は、記法の文字列になります。

### 色分けと指摘

部品にならない記法には、種類ごとの色の帯が付きます。ダイスのコマンドは青、リソース操作はオレンジ、バフは紫、というように、送る前にどう読まれるかが分かります。文字そのものは発言の色のままです。

このまま送ると効かない書き方には、波線が付きます。波線にポインタを乗せると、理由が出ます。たとえば、ダイスボットが振れないコマンド、太字などの装飾の中に入ってしまったコマンド、発言者のコマにない項目、見つからない立ち絵、対象のコマがいない演出に付きます。入力欄の右下に指摘の数が出て、押すと一覧が上に開きます。一覧の行を押すと、その記法が選ばれます。

指摘があっても、送ることはできます。ダイスボットのコマンドは選んでいるダイスボットで実際に振れるかを確かめます。ダイスボットを読み込むまでのあいだは、ダイスについての指摘は出ません。

### パレットの編集欄

チャットパレットの編集欄も同じ入力欄で書きます。`//変数=値`と`◆◆`の行は、文字のまま色だけが付きます。`Enter`は改行です。手を入れていない行は保存しても1字も変わりません。指摘はパレットの行ごとに、そのコマから送ったときの読まれ方で確かめます。

### もとの入力欄に戻す

チャットの設定（歯車アイコン）の「書式つきの入力欄を使う」を外すと、記法をそのまま打つ入力欄になります。ツールバーはこちらでも使え、選んだ文字を記法で囲みます。色分けと指摘、部品、名前の候補は出ません。この設定はその端末だけのものです。

## 文中のスタンプ

スタンプを文の中に入れると、`［了解:seal:ok］`のように、スタンプの名前とIDを括弧で囲んだ形で送られます。チャットでは、この形が文字と同じくらいの大きさのスタンプとして出ます。書式つきの入力欄ではスタンプが部品として出るので、この形を打つことはありません。記法をそのまま打つ入力欄では、スタンプのボタンで選ぶとこの形が入ります。IDは書き換えないでください。

部屋で止められているスタンプと、この版にないスタンプは、`［了解］`のように名前だけの文字で送られます。古い版のUdonarium Axeでは、この形のまま文字で出ます。

文中のスタンプは空白と同じく語の区切りになります。`2d6`や`:HP-1`、`dice:ゴブリン`、文末の`@笑顔`やカットイン名のすぐ後ろにスタンプを入れても、コマンドや名前はそこで終わり、そのまま効きます。

## ダイスロール

選択中のダイスボットのコマンド（`2d6+1`、`1d100<=50`など）をそのまま入力するとダイスを振ります。詳細は[ダイスボット](/manual/dicebot)を参照してください。

- **シークレットダイス** — コマンドの先頭に`S`を付けると（例: `S2d6`）、結果が他の参加者から伏せられます

## 卓上ダイスと連動

`dice:コマ名`を書き添えると、そのロールの出目が、コマに持たせた卓上のダイスに反映されます。

```
2d6 dice:ゴブリンA
```

出た目は、面の数が合うダイスから順に入ります。`dice:`だけを書いた場合は発言しているコマが対象です。ダイスをコマに持たせる手順は[ダイス](/manual/dice)を参照してください。

## リソース操作

`:`で始まる記法で、キャラクターのステータス（リソース）をチャットから直接操作できます。発言キャラクターのインベントリにある同名の項目が対象です。

```
:HP-5        HP を 5 減らす
:HP+1d6      HP をダイスの出目だけ増やす（ダイス式が使えます）
:MP=10       MP を 10 にする
:状態>毒     「状態」をテキスト「毒」に置き換える
:属性=炎     テキストや選択肢の「属性」を「炎」に置き換える
:HP-3:MP-1   連結して複数同時に操作
```

テキストや選択肢の項目には、`=`でも文字を書けます。`:属性=炎`は`:属性>炎`と同じです。`=`のあとに数字が入っていれば、`3`や`1d6`のように今までどおり数の式として扱います。数字の入った文字（`第2形態`など）は`>`で書きます。

選択肢の項目には選択肢にある値だけを書けます。選択肢と同じ値なら、数字が入っていても`=`で書けます（`:段階=Lv2`）。選択肢にない値を書くと項目は変わらず、操作結果に選択肢が並びます（`構えに「突撃」はありません: 通常・攻勢・守勢`）。中身を隠したコマに書いたときは、全員への操作結果に`構え＞？`とだけ出て、選択肢は並びません。

### 特殊なダイスコマンドを式に混ぜる

`2d6`のような一般的なダイス式は、そのまま計算式の一部として書けます。一方で、ゲームシステムの固有のコマンド（威力表を引く`k10`や、`2dx`のような判定）は、ダイスボットが単独のコマンドとして解釈するため、足し算の項には置けません。角括弧で囲むと、その部分だけを先に振り、出た数値を式に戻してから残りを計算します。

```
t:HP-([k10]+5-t{防護})   威力表 10 の出目に 5 を足し、対象の防護点を引いた分だけターゲットの HP を減らす
:MP-[2dx]                振った結果のぶんだけ MP を減らす
:HP-([k10]+[k5])         2 つ振って合計する
```

振った内訳は操作結果の下に`└ [k10] KeyNo.10c[10] ＞ …`の形で並びます。囲んだコマンドを部屋のダイスボットが解釈できなかった場合、その操作は行われず「計算できません」と表示されます。

### 対象サフィックス

リソース名の直後にサフィックスを付けると、現在値以外を操作できます。

| サフィックス | 対象             | 例               |
| ------------ | ---------------- | ---------------- |
| なし         | 現在値           | `:HP-5`          |
| `^`          | 現在の最大値     | `:HP^+10`        |
| `_MAX`       | 最大値（ベース） | `:HP_MAX+5`      |
| `_MAX_BUFF`  | 最大値の補正値   | `:HP_MAX_BUFF+3` |
| `_MIN`       | 最小値（ベース） | `:HP_MIN-1`      |
| `_MIN_BUFF`  | 最小値の補正値   | `:HP_MIN_BUFF+1` |

### オプション

値の末尾に付けると挙動を変えられます（大文字小文字どちらでも可）。

- `L` — 最小値・最大値の範囲内に収めます（例: `:HP+99L`）
- `Z` — 0を跨ぐ変化を0で止めます（例: `:HP-99Z`）

### プレフィックス

- `t:` — 発言キャラクターではなく**ターゲット中のキャラクター**に適用します（対象ごとに`[名前]`付きで処理されます）
- `s:` — 結果を伏せて適用します（シークレット）。`st:`のように組み合わせ可能です。1行にいくつ書いても、すべて効きます

## バフ／デバフ操作

`&`で始まる記法で、キャラクターの[バフ／デバフ](/manual/buff)をチャットから操作できます。

```
&猛攻撃                 バフ「猛攻撃」を付与
&猛攻撃/攻撃+2          サブ情報付きで付与
&猛攻撃/攻撃+2/3        3 ラウンドの期限付きで付与（省略時 3R）
&毒/継続2/3/red         バッジの色を指定して付与
&毒/継続2/3/red/☠️      色と絵文字を指定して付与（順不同）
&練技/筋力+2/3/手番開始/@術者   術者の手番開始時に減るバフ
&毒霧/命中-2/3/デバフ   区分をデバフにして付与
&!猛攻撃/命中/+/2/3     ステータスを実際に動かすバフ
&+猛攻撃/攻撃+2/3       すでに付いている「猛攻撃」に +2 を足す
&++猛攻撃/攻撃+2/3      +2 を足したうえで残ラウンドも 3 延ばす
&猛攻撃-                バフ「猛攻撃」を解除
&R+ / &R-               全バフのラウンドを増減
&D                      0 ラウンド以下のバフをまとめて消去
&&none-                 消えないバフを卓全体から解除（GM のみ）
&&2R-                   残り 2R のバフを卓全体から解除（GM のみ）
&&猛攻撃-               「猛攻撃」を卓全体から解除（GM のみ）
```

`&&`で始まる3つは、発言者やターゲットではなく**卓にいる全員**が対象です。GMだけが使えます。ふたり乗りで自動で付いたバフは乗っているあいだ残り、報告の行から元に戻せます。詳しくは[バフ／デバフ](/manual/buff#sweep)を参照してください。
名前や残りラウンドにかかわらずまとめて外す`&*-`と、値を既定値へ戻す書き方は、[バフと値のリセット](#バフと値のリセット)にまとめています。

色は`red` `orange` `yellow` `green` `blue` `purple` `pink` `gray`の英名、`赤` `青`などの和名、`#c62828`のような16進で指定できます。`既定`と書くと黒に戻ります。指定した色と絵文字は[コマの頭上のバッジ](/manual/buff)にそのまま出ます。

4つ目以降には色と絵文字のほかに**消失タイミング**と**トリガー**も書けます。タイミングは`手番開始` `手番終了` `ラウンド終了` `消えない`（`turnStart` `turnEnd` `roundEnd` `none`などの英名も可）、トリガーは`@名前`です。
指定しなければ、これまでどおりラウンド終了時に減ります。ラウンド数の欄にタイミングを書くと（`&毒/継続2/none`）、ラウンド数を省いたものとして読みます。

同じ位置に`デバフ`（`debuff`）か`バフ`（`buff`）を書くと、バフの[区分](/manual/buff#バフとデバフの区分)が付きます。全角と半角、大文字と小文字は区別しません。
ラウンド数の欄に書いたときも（`&毒霧/命中-2/デバフ`）、ラウンド数を省いたものとして読みます。`&!`で始めるバフにもラウンド数のうしろに書けます。

`&!`で始めると、覚え書きではなく**ステータスを実際に動かす**バフになります。書く順番は`&!バフ名/ステータス/操作/量/ラウンド/タイミング/トリガー`で固定です。そのうしろに`発生:手番終了`（`tick:turnEnd`）のように書くと、減るたびに動かす量が動く時期を決められます。操作は`+` `-` `=`の3つです。
ステータス名のうしろに`^`を付けると（`HP^`）、最大値側が対象になります。バフが切れると、動かした分だけ戻ります。
量には`(3+4)÷2`のような計算式も書けます。割り算は`÷`か全角の`／`で書き、端数は割るたびに切り捨てます（[量に計算式を書く](/manual/buff#量に計算式を書く)）。

```
&!猛攻撃/命中/+/2/3              命中を 2 上げ、3R 後に 2 戻す
&!鈍足/敏捷/=/1/2                2R のあいだ敏捷を 1 に留める
&!練技/筋力/+/2/3/手番開始/術者   術者の手番開始時に減る
&!変身/器用度/+/5~-1/5           器用度を 5 上げ、減るたびに 1 ずつ戻す
&!猛攻撃/命中/++/1/3             命中を 1 上げ、減るたびに 1 ずつ足す
&!毒/:HP/+/0~-3/3                減るたびに HP を 3 減らし、切れても戻さない
&!再生/:HP/+/0~+3/none           消えないまま、ラウンドが終わるたびに HP を 3 回復する
&!再生/:HP/+/0~+3/none/発生:手番開始   自分の手番が始まるたびに HP を 3 回復する
&!全力攻撃/追D+4,回避-2/1        追加ダメージと回避を 1 つのバフで動かす
```

量のうしろの`~`と、2つ重ねた操作（`++` `--`）は、残ラウンドが減るたびにステータスをさらに動かします（[数えるたびに動かす](/manual/buff#数えるたびに動かす)）。
ステータス名の前に`:`を付けると（`:HP`）、切れても動いた分を戻しません（[切れても戻さない](/manual/buff#切れても戻さない)）。
減るたびに動かす量は、消えないバフではラウンドが終わるたびに動きます。`発生:ラウンド終了`・`発生:手番開始`・`発生:手番終了`を書いたバフは、バフを持っているコマのその時期にだけ動きます（[効果が動くタイミング](/manual/buff#効果が動くタイミング)）。
2つ目の欄に`追D+4,回避-2`のように並べると、1つのバフでいくつものステータスを動かします。そのときは、うしろにラウンド・タイミング・トリガーが続きます（[いくつものステータスを動かす](/manual/buff#いくつものステータスを動かす)）。

`!`を付けずに同じ並びで`&猛攻撃/命中/+/2/3`と書くと、覚え書きのバフとして読みます。効果欄は`命中+2`、ラウンドは3で、ステータスは動きません。

詳しくは[バフ／デバフ](/manual/buff#ステータスを動かすバフ)を参照してください。

`&`のすぐうしろに`+`を置くと、同じ名前のバフがすでに付いているとき、値を上書きせずに**足します**。
`&猛攻撃/攻撃+2/3`を2回打っても効果欄は`攻撃+2`のままですが、`&+猛攻撃/攻撃+2/3`なら`攻撃+4`になります。減らしたいときは`&+猛攻撃/攻撃-1/3`とマイナスで書きます。

`+`を2つ並べると、残ラウンドも足します。`&+`では残ラウンドの長いほうが残るので、持続を延ばしたいときは`&++`を使います。
効果欄を空にすれば、効果はそのままで持続だけ延ばせます。

```
&+猛攻撃/攻撃+2/3        効果欄を 攻撃+4 にする（残Rは長いほう）
&++猛攻撃/攻撃+2/3       効果欄を 攻撃+4 にして残Rを 3 足す
&++加護//3               効果欄はそのままで残Rを 3 足す
&+!猛攻撃/命中/+/2/3     命中をもう 2 上げ、外すと 4 戻る
```

詳しくは[バフ／デバフ](/manual/buff#重ねがけ)を参照してください。

リソース操作と同じく`t&`（ターゲットへ適用）、`s&`（シークレット）のプレフィックスが使えます。`s&`は小文字で書きます。大文字の`S&`は`S&W`のような言葉として読みます。名前だけのバフ（`s&名前`）も、`s&p`のような言葉と見分けがつかないため、シークレットとしては読みません。欄を付けるか（`s&毒/1/3`）、外す（`s&毒-`）などの形で書きます。

## バフと値のリセット

コマのバフを名前にかかわらずまとめて外す記法と、シートの値を[既定値](/manual/data-element#既定値)へ戻す記法です。
戦闘のあとに、付いたバフを消して値を戦闘の前に戻す、といった使い方をします。
使えるのはGMとPLです。見学が送っても何も起きず、報告も出ません。
ボタンでの操作と、外れるバフ・残るバフは[バフ／デバフ](/manual/buff#reset)を参照してください。

### バフをまとめて外す

| 書き方                           | 対象                             | すること                                                  |
| -------------------------------- | -------------------------------- | --------------------------------------------------------- |
| `&*-`                            | 発言者のコマと、その部位         | バフをすべて外す                                          |
| `&*バフ-`・`&*buff-`             | 同じ                             | [区分](/manual/buff#バフとデバフの区分)がバフのものを外す |
| `&*デバフ-`・`&*debuff-`         | 同じ                             | 区分がデバフのものを外す                                  |
| `t&*-`・`t&*バフ-`・`t&*デバフ-` | ターゲット中のコマごと（部位も） | 同じ3種類                                                 |
| `&&*-`・`&&*バフ-`・`&&*デバフ-` | 卓の上の全コマ（GMのみ）         | 同じ3種類                                                 |

`*`のうしろに`バフ`・`デバフ`・`buff`・`debuff`以外の語を書いたときは、これまでどおり、その名前のバフを1つ外す操作として読みます。

### 値を既定値に戻す

| 書き方                                   | 対象                     | すること                                   |
| ---------------------------------------- | ------------------------ | ------------------------------------------ |
| `:*=既定`                                | 発言者のコマと、その部位 | 既定値のある項目をすべて戻す               |
| `:HP=既定`                               | 同じ                     | HPの現在値だけを戻す                       |
| `:HP^=既定`                              | 同じ                     | HPの最大値だけを戻す                       |
| `:HP_MAX_BUFF=既定`・`:HP_MIN_BUFF=既定` | 同じ                     | HPの最大値・最小値の補正値だけを戻す       |
| `t:*=既定`・`t:HP=既定`・`t:HP^=既定`    | ターゲット中のコマごと   | 上と同じ操作を、ターゲットにしたコマに行う |

`既定`は`既定値`・`規定`・`規定値`・`default`とも書けます。全角と半角、大文字と小文字は区別しません。語のうしろには何も続けられません。
既定値のない項目は変わりません。`:HP_MAX=既定`のようにベースを指したときも、ベースは既定値を持たないので変わりません。

### バフを外して値も戻す

| 書き方                    | 対象                     | すること                          |
| ------------------------- | ------------------------ | --------------------------------- |
| `&リセット-`・`&reset-`   | 発言者のコマと、その部位 | `&*-`のあとに`:*=既定`を行う      |
| `t&リセット-`・`t&reset-` | ターゲット中のコマごと   | 同じ                              |
| `&&リセット-`・`&&reset-` | 卓の上の全コマ（GMのみ） | 同じ。コマを1体ずつリセットします |

卓の上の全コマの値を戻す書き方は`&&リセット-`だけです。`&&`で始まる形をGM以外が送ると、何も変わらず、GMだけが使えるとチャットに出ます。

どの形も前に`s`を付けると報告を伏せます（`s&*-`・`st&*-`・`s:*=既定`・`s&リセット-`・`s&&*-`）。

### 実行の順番

値を既定値へ戻す操作は、行のどこに書いても、その行のほかの操作がすべて済んだあとに行います。
`:*=既定 &*-`と書いても、バフを外してから値を戻します。
[ステータスを動かすバフ](/manual/buff#ステータスを動かすバフ)は外れるときに動かした分を戻すので、値を先に戻すと、その分が既定値からもう一度動いてしまうためです。

### 報告と取り消し

結果はほかの`:`や`&`の操作と同じ1行で報告されます。

```
すべてのバフを解除（4件）
すべてのバフを解除（本体と部位2・5件）
解除するデバフはありません
[ゴブリンA] デバフを解除（1件）
卓全体からすべてのバフを解除（3体・7件）
既定値に戻す 命中:5→3 回避:2→4
既定値のままです
既定値のある項目はありません
卓全体をリセット（3体・バフ7件・値5項目）
```

- バフの名前は報告に出ません。バフを隠しているコマの中身が分からないようにするためです
- [公開範囲](/manual/disclosure)で中身を伏せたコマの値は、全員には`既定値に戻す（2項目）`と項目の数だけが出ます。前後の値は中身を見られる人にだけ届きます
- 卓全体のリセットの報告は体数と件数だけです
- 報告の行には、送った本人の画面にだけ**元に戻す**のボタンが出ます（[リセットを元に戻す](/manual/buff#リセットを元に戻す)）

### 読み方が変わった名前

この記法と同じ形の名前は、これまでの読み方ができなくなりました。

| 名前                                                         | 変わったこと                                                                                                                                            |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `*`・`*バフ`・`*デバフ`・`リセット`・`reset`という名前のバフ | `&名前-`と`&&名前-`では外せません。まとめて外す操作として読みます。バフ編集のゴミ箱で外します。入力欄には、その名前のバフが付いているときに指摘が出ます |
| `*`という名前の項目                                          | `:*=既定`はすべての項目を指します。`:*+1`のようなほかの操作は、これまでどおり項目`*`を指します                                                          |
| アイコンに書いた`バフ`・`デバフ`・`buff`・`debuff`           | 区分として読むので、アイコンの文字になりません                                                                                                          |
| `&!`のタイミングのうしろに`@`なしで書くトリガーの名前        | この4語と同じ名前のコマは、トリガーとして読みません。`@`を付けて書きます                                                                                |

### 古い版のAxeで打ったとき

操作を実行するのは、行を送った人のブラウザだけです。新しい版から送られた行を古い版が受け取っても、何も起きません。
この記法に対応していない古い版の人が自分で打ったときは、次のように読まれます。どの形でも、シートの値が変わったり、ほかの名前のバフが外れたりすることはありません。

| 打った形                         | 古い版の読み方                                                          |
| -------------------------------- | ----------------------------------------------------------------------- |
| `&*-`・`&*デバフ-`・`&リセット-` | その名前のバフを1つ外す操作。その名前のバフがなければ何も起きません     |
| `&&*-`・`&&リセット-`            | 名前で選ぶ一括解除。「卓全体に「\*」はありません」と出ます              |
| `:*=既定`                        | `*`という項目がなければ読み飛ばします                                   |
| `:HP=既定`                       | 「計算できません」と出て、値は変わりません                              |
| `&毒霧/命中-2/3/デバフ`          | バフは付き、アイコンが「デバフ」の文字になります。区分は付きません      |
| `&毒霧/命中-2/デバフ`            | ラウンド数として読めないので3ラウンドのバフが付きます。区分は付きません |

古い版の人が同じ部屋にいても、新しい版が付けた区分と既定値は消えません。

## 行動順の操作

発言の先頭に次のコマンドを書くと、[行動順](/manual/turn-order)をチャットから操作できます。英字のコマンドと日本語のコマンドは同じ働きです。

| コマンド                   | すること                                                                 |
| -------------------------- | ------------------------------------------------------------------------ |
| `&T`・`&手番`              | 発言者のコマの手番を始めます                                             |
| `&TE`・`&手番終了`         | 手番を終えて、次へ渡します（陣営ごとの「自由」のフェイズでは渡しません） |
| `&TW`・`&待機`             | 手番のコマを待機させます                                                 |
| `&TI`・`&割り込み`         | 待機している発言者のコマが割り込みます                                   |
| `&TB`・`&前へ`             | 1つ前の状態へ戻します                                                    |
| `&RS`・`&ラウンド開始`     | ラウンドを始めます                                                       |
| `&RN`・`&次のラウンド`     | いまのラウンドを閉じて、次を開きます                                     |
| `&RB`・`&ラウンドを戻す`   | 前のラウンドが終わった時点まで戻します                                   |
| `&RR`・`&ラウンドリセット` | 手番とラウンドを最初の状態へ戻します                                     |

どのコマンドも、行動順ウィジェットのボタンを押せる人が使えます。GMとPLの全員で、誰のコマの手番でも、誰のコマを発言者にしていても同じです。見学の人はどのコマンドも使えません。

`&T`と`&TI`は発言者に選んだコマに効きます。発言者がコマでないときは効きません。

`&T`を使えるのは、[陣営ごと](/manual/turn-order#陣営ごとに動かす)でフェイズ内が「自由」の進め方のときです。そのコマの陣営のフェイズが開いていて、そのコマがまだ行動していなければ、手番が始まります。待機しているコマは`&TI`で割り込みます。

`&TE`は**次へ**のボタンと同じで、手番のコマがいないときもラウンドやフェイズを先へ進めます。ただし陣営ごとの「自由」のフェイズでは、手番のコマを行動済みにするだけで、次のコマには手番を渡しません。次に動くコマは陣営の中で選び、`&T`かコマのクリックで手番を始めます。陣営の全員が動き終えると、次の陣営のフェイズが開きます。このフェイズで手番のコマがいないときは、`&TE`は効きません。`&RS`はラウンドが始まる前か、ラウンドが終わったあとにだけ効きます。`&RN`を打ったとき、まだ手番を取っていないコマが残っていれば、[ラウンドを進めるときの確認](/manual/turn-order#ラウンドを進めるときの確認)が出ます。

コマンドは発言の先頭に書いたときだけ読みます。うしろに続けて書いた部分は、行動順を動かしたあとに、ふつうの発言として別の行で送ります。

```
&T 2d6+5 命中判定       手番を始めてから 2d6+5 を振る
&TE                     手番を終える
&RN 次のラウンドです    次のラウンドを開いてから発言する
```

コマンドを書いた行はチャットに残るので、誰が行動順を動かしたかが分かります。バフの残ラウンド、手番の知らせ、効果音、画面の移動は、ボタンで操作したときと同じです。コマンドで進めた分も**前へ**で戻せます。

使えない人が打ったときと、効かない場面で打ったときは、行動順は動きません。打った本人にだけ理由が出ます。うしろに続けて書いた部分は、そのときも送ります。

文の途中に書いた`&T`はコマンドとして読まず、これまでどおり「T」という名前のバフを付けます。発言の先頭でも、`&RS/効果`のように`/`で欄を続けたときと、`&RS-`のように`-`で終えたときは、バフの操作として読みます。`&R+`・`&R-`・`&D`と、`&&`で始まる操作もこれまでどおりです。

行動順を動かすのは、コマンドを打った人のブラウザだけです。このコマンドに対応していない版のAxeで打った`&T`は、「T」という名前のバフを付けます。

入力欄では、コマンドにポインタを乗せると説明が出ます。使えないときと効かない場面では波線が付き、理由が出ます（→ [色分けと指摘](#色分けと指摘)）。語の頭の`&`を発言の先頭に打つと、使えるコマンドが名前の候補に並びます。

## 立ち絵コマンド

文末に半角スペースを空けて`@～`を書くと、発言と同時に立ち絵を切り替えられます。一致する立ち絵が見つかった場合、コマンド部分は本文から取り除かれて送信されます。

| 記法    | 機能                                                 |
| ------- | ---------------------------------------------------- |
| `@hide` | 立ち絵を隠す                                         |
| `@2`    | 番号で切り替え（一覧の2枚目）                        |
| `@笑顔` | 名前で切り替え（完全一致を優先し、なければ前方一致） |

大文字小文字・全角半角は区別されません（`@HIDE`、`＠ｈｉｄｅ`も可）。

名前は[キャラクターシート](/manual/character#立ち絵に名前をつける)の立ち絵一覧でつけます。名前のない立ち絵と、名前に空白がある立ち絵は、番号でしか呼べません。入力欄の候補にも出ません。数字だけを書いたときは番号、それ以外は名前として扱うので、`@笑顔2`のように数字で終わる名前もそのまま使えます。

番号は一覧に並ぶ順で、`@1`が1枚目です。シートの立ち絵に添えてある番号と、リモコンやノベルモードに出る`2/3`の左側の数字が、そのまま書ける番号です。

## カットイン起動

「チャットから起動」を許可した[カットイン](/manual/cut-in)は、文末の単語が名前と完全一致すると再生されます。

- `見せ場だ カットイン名` — 映像つきでカットインを再生
- `見せ場だ @カットイン名` — **音声のみ**を再生

秘話で使うと相手にだけ再生されます。プレイヤーに見えないタブの行では、送った人の画面にだけ出ます。シークレットダイスなど伏せられた発言からは起動しません。

## 演出の起動

本文に`《エフェクト名》`と書くと、その行を送ったときに[マップ演出](/manual/map-effects)が出ます。

```
2d6+3 t:HP-10 《爆炎》
```

この1行で、ダイス → ダメージ処理 → 演出まで続けて実行されます。対象は`t:`と同じで、撃ち手はその行を喋ったコマです。書く名前はエフェクト集に登録したもので、記法そのものはエフェクトの右クリックから入力欄へ入れられます。
秘話の行と、プレイヤーに見えないタブの行では、演出は送った人の画面にだけ出ます。

## 戦闘カットインの起動

リソースを減らす行に`《vs》`を書くと、発言したキャラクターが`t:`の対象を攻撃する[戦闘カットイン](/manual/battle-cut-in)が全員の画面に出ます。

```
2d6+3 t:HP-10 《爆炎》《vs》
```

ダメージの処理が終わってから、減ったあとの数字で再生します。`《エフェクト名》`を一緒に書くとそのエフェクトで攻撃し、カットインの中に出します。
秘話の行と、プレイヤーに見えないタブの行では、送った人の画面にだけ出ます。

## ルビ（ふりがな）

`|テキスト《ルビ》`でテキストにルビを振れます。`|`は全角`｜`でも構いません。

```
|招雷《しょうらい》ドラム・スタッカート！
```

この書き方は親文字をひとまとまりにして、その上にルビを振ります（グループルビ）。「明日（あした）」のような熟字訓や当て字に向きます。

ルビを`|`で区切ると、親文字1文字ずつにルビを振ります（モノルビ）。区切りの数は親文字の文字数と同じにします。区切りの間を空にすると、その文字にはルビを振りません。区切りの数が親文字の文字数と合わないときは、区切りを外してグループルビとして振ります。

```
|漢字《かん|じ》
|東京都《とう|きょう|と》
```

親文字もふりがなも、まわりの本文と同じ文字色・太さで表示されます。[発言色](/manual/chat)を変えるとルビもその色に追従します。

親文字とルビの長さが違うときは、短い方の文字の間を「1：2：1」の割合で空けて、長い方にそろえます。ルビは親文字の中央に付けます（中付き）。この見え方は[チャット設定](/manual/chat#chat-settings)の**ルビ**で読み手ごとに変えられます。

[ノベルモード](/manual/visual-novel)の吹き出しとバックログにも同じルビが付きます。文字送りの途中で記号が見えることはなく、親文字の1文字目が出た時点でふりがなも表示されます。

スペースを含めたいときは、`\s`と書くと半角スペースとして表示されます。

## 文字の装飾

発言の一部を太字にしたり、書体・大きさ・色を変えたりできます。入力欄の上のツールバーからも付けられます（→ [書式つきの入力欄](#書式つきの入力欄)）。

```
今日は**晴れ**です
[明朝]古の契約に従い、[/明朝]扉は開かれた。
[赤][大]危ない！[/大][/赤]
```

`**`で囲んだ部分は太字になります。`**`は、同じ行の中で2つそろったときだけ効きます。複数の行にまたがる太字は、1行ずつ`**`で囲んで送ります。

ほかの装飾は`[名前]`で始めて`[/名前]`で閉じます。閉じるほうは`[/]`だけでも構いません。その場合は、最後に開いた装飾が閉じます。装飾は重ねられ、内側の書体・大きさ・色が優先されます。

| 種類                   | 名前                                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------------------ |
| 太字・斜体・取り消し線 | `[太字]` `[斜体]` `[取消線]`                                                                           |
| 大きさ                 | `[小]` `[大]` `[特大]`                                                                                 |
| 書体                   | `[明朝]` `[丸ゴシック]` `[手書き]` `[ポップ]` `[ドット]` `[ゴシック]`                                  |
| 文字色                 | `[赤]` `[橙]` `[黄]` `[緑]` `[水色]` `[青]` `[紫]` `[桃]` `[灰]` `[白]` `[黒]`、`[#f80]`などの色コード |

`[白]`と`[黒]`は、明るい配色と暗い配色のどちらのチャットでも読めるよう、反対の色で細く縁取って表示します。白や黒に近い色コードも同じです。

名前は英語（`[bold]`・`[mincho]`・`[red]`など）と韓国語（`[굵게]`・`[명조]`・`[빨강]`など）でも書けます。ツールバーで付けた装飾は、表示している言語の名前で書かれます。

`[ゴシック]`は、いつもの書体に戻す名前です。明朝・丸ゴシック・手書き・ポップ・ドットの5つの書体はAxeに同梱していて、発言で使われたときに初めて読み込みます。ハングルなど、その書体に無い文字はいつもの書体で表示されます。

閉じていない`[赤]`や、装飾にない名前の`[注意]`は、書いたとおりの文字で表示されます。装飾になる記号をそのまま書きたいときは、`\**`や`\[赤]`のように前に`\`を付けます。装飾にならない記号の前にある`\`は、そのまま表示されます。

装飾は、共有メモ・カードの文面・ノベルモードの吹き出しとバックログ・配信用画面・HTML形式で保存したログにも付きます。HTML形式のログは書体を持たないので、その書体が入っている端末でだけ同じ書体になります。テキスト形式のログ・ティッカー・頭上の吹き出し・チャット検索・発言のコピーでは、記法を外した文字になります。旧版のAxeやほかのツールでは、記法がそのまま表示されます。

## 引用

行頭に`>`を付けると引用スタイルで表示されます。連続する`>`行はひとつの引用ブロックにまとまります。

```
> 昨日のセッションのログより
> 「あの扉は開けるな」
```

## 項目と変数の参照

`{名前}`と書くと、送信するときにコマの値へ置き換わります。読むのは[シートの項目](/manual/data-element)と、そのコマの[チャットパレット](/manual/chat-palette)に書いた変数です。

```
//武器ボーナス=2
2d6+{武器ボーナス} 攻撃！
:HP-{HP^}
```

- `//名前=値` — 変数を定義します。定義を書く場所はチャットパレットの中だけです
- `{名前}` — 送信時に値へ置き換わります。変数が無ければ同じ名前のシート項目を読みます
- `{HP^}` — リソースの最大値を読みます。付けなければ現在値です
- `t{名前}` — ターゲット中のコマの値を読みます
- ターゲットに`相手の`のバフがあると、`{名前}`にその量が足されます（[狙う側の値に足す](/manual/buff#狙う側の値に足す)）
- `{目標値}` — このタブで振られたダイスの結果か、GMが示した目標値を読みます（[振られた結果を目標値にする](#振られた結果を目標値にする)）
- 変数の値にさらに`{...}`を含める入れ子も可能です
- 発言者の項目や変数の値に`t{名前}`があるときも、その行はターゲットに送ります。項目Cの値が`{項目A}+t{項目B}`なら、`{項目C}`はターゲットごとにそのコマの項目Bを読みます
- 参照の名前の中にも参照を書けます。内側から先に置き換わるので、武器が「ロングソード」なら`{{武器}威力}`は`{ロングソード威力}`を読みます

同じ名前の項目がシートに2つ以上あるときは、`{戦闘特技/最終能力/コスト}`のようにパスで書きます。
パスはシートの行から**参照名をコピー**で取れます。

コマに無い名前は、チャットパレットから送ると空になります。チャット欄に打ったときは、`やった{歓喜}`のように書いたまま送ります。
ただし、先頭のダイスの式に、数字や閉じかっこのすぐ後ろへ付けた参照は、チャット欄でも空になります。`2d+10{加護}`は、加護（効果`+10`）があれば`2d+10+10`、無ければ`2d+10`で振ります。

### 攻撃する側の値でターゲットを減らす

`t:`の操作の中でも、`{名前}`が読むのは発言者のコマです。ターゲットにしたコマの値は`t{名前}`で読みます。発言者のコマの値で、ターゲットのリソースを減らせます。

```
t:HP-{攻撃力}               発言者の攻撃力の分だけ、ターゲットのHPを減らす
t:HP-({攻撃力}-t{防護})     発言者の攻撃力から、ターゲットの防護を引いた分だけ減らす
```

`{名前}`にバフの名前を書くと、式の中では、バフの効果に書いた数を読みます。コマの頭上のバッジに出る数と同じです。効果が`攻撃+2`の練技なら、`t:HP-({攻撃力}+{練技})`は攻撃力に2を足した分だけ減らします。数が負のバフは`(-1)`のようにかっこ付きで入り、`2d+10{加護}`のように数のすぐ後ろへ付けたときは、符号ごと入ります。効果に数のないバフは、演算子の後ろでは`0`として入ります。式の外に書いたときは、`{練技}`は効果の文字のまま入ります。式とは行の先頭のダイスの式と、`:`の操作の量のことです。

### 振られた結果を目標値にする

`{目標値}`と書くと、送るときに、このタブで振られたダイスの結果に置き換わります。抵抗判定のように、相手が振った達成値を目標値にする判定を、数を打たずに振れます。

```
2d+{生命抵抗}+{生命抵抗修正}>={目標値}   自分に向けて振られた達成値を目標値にして抵抗する
```

置き換わる数は次の順に探します。

1. 発言者のコマに向けて振られた、いちばん新しい結果。ただし、目標値に固定した結果より前に振られたものは使いません
2. このタブで目標値に固定した結果（[結果を目標値に固定する](#結果を目標値に固定する)）
3. ほかの発言者がターゲットなしで振った、いちばん新しい結果。GMが「目標値13」と書いた発言も、ここに含みます（[GMが目標値を示す](#gmが目標値を示す)）

3では、`{目標値}`を置き換えて送った行の結果を使いません。抵抗の結果を次に抵抗する人の目標値にしないためです。ターゲットなしで振った範囲攻撃のあとにPCが続けて抵抗しても、2人目は1人目の抵抗の結果ではなく攻撃の結果を目標値にします。

ほかのコマに向けて振られた結果と、シークレットダイスの結果は使いません。向けた先は結果の末尾の名前で見分けるので、同じ名前のコマが何体もいると、どのコマにもその名前に向けた最新の結果が入ります。コピーしたコマは「ゴブリンA」「ゴブリンB」のように名前を分けてください。数は結果の矢印（`→`）の先にある最後の数です。シートの項目やパレットの変数に「目標値」があるときは、そちらを読みます。使える結果が無いときは`{目標値}`のまま送り、書式つきの入力欄に指摘が出ます。

コマに向けて振るには、行のどこかに`t:`だけを書きます。`2d+8 魔法行使 t:`は、ターゲットに選んだコマごとに振られ、結果にそのコマの名前が付きます。`t:`の文字は送られません。複数のPCへ別々に振っても、それぞれのPCの`{目標値}`には、そのPCに向けた結果が入ります。ターゲットなしで1回だけ振れば、全員がその結果を目標値にします。

範囲攻撃のように、ターゲットに選んだコマ全員へ1回だけ振るときは、`t:`の代わりに`t:範囲`と書きます（`t:area`でも同じです）。`2d+8 魔法行使 t:範囲`は1回だけ振られ、結果の末尾に`[ゴブリンA、ゴブリンB]`のように全員の名前が付きます。名前の付いたコマの`{目標値}`には、どれもこの結果が入ります。行の中の`t{名前}`は最初のターゲットの値を読みます。`t:HP-5`のようなリソースの操作は、これまでどおりターゲットごとに行います。

#### GMが目標値を示す

GMが「探索判定：目標値13」のように、目標値のあとに数を書いて発言すると、その数が`{目標値}`に入ります。数の前には`：`や`=`、「は」を挟めます。ターゲットなしで振った結果と同じ扱いで、そのあとに振られた結果があれば、新しいほうを使います。1つの発言に違う数が2つ以上あるときは、どちらも使いません。`目標値2倍`のように数のすぐあとに「倍」「つ」「回」「体」などが続くときと、`目標値10+2`や`目標値13〜15`、`目標値13から15`のように計算や範囲が続くときも使いません。数のあとに語を続けるときは、`目標値12 回避判定`や`目標値12／成功で情報`のように空白か`／`を挟みます。`目標値13→15に修正`のように矢印で直したときは、矢印の先の15を使います。PLの発言は自動では使いませんが、右クリックの「この目標値を固定する」で固定できます。GMが作った[スイッチ](/manual/switch)の台詞は、PLが押しても、GMの発言と同じように使います。押した人のコマの`{目標値}`にも入ります。PLが押した台詞は、押した人が目標値を書き直すと使わなくなります。GMが押した台詞の目標値を書き直したときは、GMの発言として扱います。押したコマが言った台詞なら、そのコマ自身には使いません。削除した発言も使いません。

#### 結果を目標値に固定する

ダイスの結果を右クリックして「この結果を目標値にする」を選ぶと、その結果がこのタブの目標値に固定されます。固定した結果には「目標値」の印が付き、外すまで、このタブの`{目標値}`にはこの結果が入ります。ただし、固定したあとで発言者のコマに向けて振られた結果があれば、そちらを使います。外すときは、同じ結果を右クリックして「目標値の固定を外す」を選ぶか、入力欄の上の表示（[送る前に目標値を確かめる](#送る前に目標値を確かめる)）の×を押します。別の結果を固定すると、前の固定は外れます。固定できるのは、そのタブで発言できるGMとPLです。シークレットダイスの結果、秘話の結果、数にならない結果は固定できません。目標値の数を書いた発言も、同じように固定できます。固定した発言が削除されると、その固定は使われなくなります。

#### 送る前に目標値を確かめる

`{目標値}`を含む行を入力欄に書くと、入力欄の上に、置き換わる数と、その数をどの結果から読んだかが出ます。一覧から、このタブで全員に見える新しい結果を8件まで選び直せます。選び直した数はその1回の送信だけに使い、送ると「自動」に戻ります。使える結果が無いときは「見つかりません」と出て、`{目標値}`のまま送ります。シートの項目やパレットの変数の「目標値」を読む行では、この表示は出ません。`{目標値}`を含む行があるチャットパレットでは、行を押したときに一覧がずれないように、この表示の場所をはじめから薄く取っておきます。

この書き方に対応していない古い版のAxeから送ると、`{目標値}`は置き換わらず、`t:`は書いたまま1回だけ振られます。v1.76.1以前の版から送ると、`t:範囲`は書いたまま、ターゲットなしで1回だけ振られます。v1.76.1以前の版は目標値の固定を読まず、`[ゴブリンA、ゴブリンB]`のように名前が並んだ結果も目標値に使いません。v1.76.1以前の版から`{目標値}`を置き換えて送った行には印が付かないので、その結果はこれまでどおり、ほかの人の目標値になります。v1.77.2以前の版は、GMが書いた目標値を読まず、目標値の数を書いた発言を固定しても使いません。

### 参照するコマ

参照はチャットパレットからでも、チャットウィンドウの入力欄からでも同じように展開されます。ただし入力欄から送る場合、値を読む先は**発言者に選んだコマ**です。発言者が「プレイヤー（あなた）」のままだと読む先が無いため、`{`と`}`は書いたまま送られます。

## ノベルモード演出

文末の`〔～〕`で吹き出しの形や立ち絵の動きを指定できます。詳細は[ビジュアルノベルモード](/manual/visual-novel)を参照してください。

## うまくいかないとき

| 見えるもの                                    | 原因と直しかた                                                                                                               |
| --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `:HP-3`のような操作が効かない                 | 発言者のキャラクターに、その名前の項目があるかを確かめます。発言者がキャラクターでないときも効きません                       |
| リソースの操作が反映されない                  | 見学のときは、キャラクターとして話しても、リソースの操作・立ち絵の切り替え・テーブルのダイスへの反映は効きません             |
| `{HP}`が数字にならない                        | 発言者のコマに、その項目がありません（→ [チャット欄では発言者のコマを読む](#参照するコマ)）                                  |
| `k10`のようなコマンドを式に混ぜると振られない | 固有のコマンドは、角括弧で囲んで式に混ぜます（→ [特殊なダイスコマンドを式に混ぜる](#特殊なダイスコマンドを式に混ぜる)）      |
| `&T`と打っても手番が始まらない                | 打った本人にだけ理由が出ます。発言者がコマか、陣営ごとの「自由」のフェイズかを確かめます（→ [行動順の操作](#行動順の操作）） |
| 入力欄の記法に波線が付く                      | 波線にポインタを乗せると理由が出ます。入力欄の右下の数から一覧も開けます（→ [色分けと指摘](#色分けと指摘)）                  |
| `:*=既定`と打っても値が戻らない               | 既定値のある項目がありません。シートで既定値を覚えさせます（→ [既定値](/manual/data-element#既定値)）                        |

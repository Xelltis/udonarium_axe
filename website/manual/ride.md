# 乗り物に乗る

駒をほかの駒に乗せて、一緒に動かせます。馬やバイクに乗り手がまたがる、後ろにもう1人を乗せる、荷物を積む、といった形を再現できます。乗っている駒は乗り物の上に重ねて描かれ、乗り物が動けば一緒に運ばれます。

## 乗り物にする

駒を右クリックし、**乗り物**のグループで「乗り物にする」に印を付けます。印を付けた駒のメニューには「乗り物の設定」が出て、次の4つを決められます。

| 設定                 | 決めること                                                                                   |
| -------------------- | -------------------------------------------------------------------------------------------- |
| 同乗できる           | 前に乗る駒の後ろに、もう1人を乗せられます                                                    |
| 積める数             | 荷物として積める駒の数です。1以上にすると、同乗はできなくなります                            |
| 技能がなくても乗れる | 乗り物を操る技能のない駒も、前に乗れます                                                     |
| 乗る高さ             | 乗っている駒が立つ高さを、乗り物の台座からのマス数で決めます。既定は乗り物の大きさの半分です |

印を外すと、乗っていた駒はその場で降ります。

## 乗る・降りる

乗り物と同じ点にいる駒のメニューの**乗り物**に、「〇〇に乗る」「〇〇に同乗する」「〇〇に積まれる」のうち、空いている席が出ます。前に乗る駒が乗り手で、乗り物を動かします。同乗できるのは、乗り手がもう乗っているときだけです。降りるときは、同じグループの「〇〇から降りる」を選びます。

同じ点とみなす距離には、[交戦エリア](/manual/engagement-zone#使えるようにする)の「同じ点とみなす距離」を使います。

乗り降りはチャットに出ます。乗り物を操れる乗り手の乗り降りと、積まれていた駒が降りるときは「手番の行動を使わない」、ほかは「手番の行動を使う」と添えます。Axeは手番の行動の数を数えないので、どちらの行動を使ったかは卓で扱ってください。

倒れている駒、転んでいる駒、その場から動けない駒、つかまれている駒は、乗り物に乗れません。倒れている乗り物、転んでいる乗り物、つかまれている乗り物、ほかの乗り物に乗っている乗り物にも乗れません。倒れているかどうかは、交戦エリアの[駒の状態](/manual/engagement-zone#駒の状態)で付けます。

## 乗り物を操る技能

[部屋設定](/manual/room-settings)の**移動**タブにある「乗り物」の節で、「乗り物を操る技能の欄」にシートの欄の名前を書くと、その値が1以上の駒だけが乗り物を操れます。空欄なら、前に乗る駒はみな操れます。操れない駒が前に乗れるのは、「技能がなくても乗れる」にした乗り物だけです。

「乗るのに要る値の欄」を書くと、乗り物のシートのその欄の値と、乗る駒の技能の値を比べます。技能の値が足りなければ乗れません。

## 一緒に動く

乗り手が移動の計画を開くと、乗り物の計画になります。数えるのは、乗り物の移動力と、選んだ移動の種類です。歩き終えると、乗っている駒をみな乗り物と同じ点へ運びます。同乗している駒と積まれている駒は、自分では動けません。乗り手のいない乗り物を動かせるのは、GMだけです。

乗り物を手で掴んで置いたときも、乗っている駒は一緒に運ばれます。乗っている駒だけを手で掴み、乗り物から離れたところに置くと、その駒はそこで[落ちます](#落ちる)。

3Dの卓では、乗っている駒は乗り物の上に立ちます。乗り物の名札には、乗っている駒の数が出ます。

## 手番

[行動順](/manual/turn-order)を回しているあいだ、乗られている乗り物と同乗している駒は、乗り手の手番に一緒に動きます。2つは行動順の一覧から外れ、ラウンド表示では乗り手の丸に小さな丸で重なります。手番の始まりと終わりのバフの減り方も、乗り手と同じです。積まれている駒は、自分の手番のままです。

手番を回しているあいだは、次の決まりもAxeが守らせます。行動順を回していないときは、どれも止めません。

- 乗り降りは、1つの手番に1回までです
- 乗り物が動けるのは、1つのラウンドに1つの手番だけです。ほかの手番で動いた乗り物には、乗っても動かせません
- 乗り手が自分の手番に降りると、乗り物と同乗している駒は、その手番を終えたことになります
- 手番に降りた駒が自分で動けるのは、乗り物を操れる乗り手か積まれていた駒で、乗り物がそのラウンドにまだ動いていないときだけです

## 交戦エリアとの組み合わせ

乗っている駒は、乗り物と一緒に[交戦エリア](/manual/engagement-zone)に入り、一緒に出ます。エリアの中でも、乗り物と同じところに描かれます。

移動の割り込みとエリアから離れる判定では、乗り物と乗り手を合わせて1つと数え、人数は2つの駒の分を足します。乗り物と乗り手が移動に割り込むときは、乗り手の名前で尋ねられ、乗り物の分も数えます。同乗している駒と積まれている駒は割り込みません。エリアの定員を数えるときは、一緒に入る駒をみな数えます。

## 転ぶ

駒のメニューの**乗り物**で「転んでいる」に印を付けると、その駒は転んだことになり、チャットにも出ます。転んでいる駒は乗り物に乗れず、転んでいる乗り物には誰も乗れません。自分の手番に転んだ駒は、その手番が終わるまで印を外せません。

## 落ちる

次のときは、乗っている駒が乗り物から自動で落ちます。

- 乗り物が転ぶか倒れると、乗っている駒がみな落ちます
- 乗り手が転ぶか倒れると、乗り手と積まれている駒が落ちます。同乗している駒は残ります
- 同乗している駒か積まれている駒が転ぶか倒れると、その駒だけが落ちます
- 乗っている駒を手で乗り物から離すと、その駒が落ちます

落ちた駒は転んでいる状態になり、チャットに落下距離が出ます。落下距離は、乗り物が動いていた長さの5分の1を切り上げた値です。部屋設定の「落ちるときの最低距離」（既定は2m）より短くはなりません。

動いていた長さには、その手番に乗り物が歩き出した経路の長さを使います。割り込みで途中で止まっても、歩き出した経路の長さのままです。その手番にまだ動いていなければ、乗り物が直前の手番に動いた長さを使い、その手番に動いていなければ0mとします。

部屋設定の「落ちたときに振る式」を書いておくと、落ちた駒の名前でその式を振ります。式の中の`{m}`は、落下距離の数に置き換わります。

## ふたり乗り

部屋設定の「ふたり乗りのバフ」に、チャットのバフと同じ書き方でバフを書いておきます。同乗している駒が乗ると、乗り手と同乗している駒の両方にそのバフが付きます。どちらかが降りるか落ちると、両方から外れます。

外れるのは、このとき付けたバフだけです。同じ名前のバフをもともと持っていた駒には付けず、持っていたバフもそのまま残します。たとえば`&ふたり乗り/判定-1/99`と書けます。書き方は[バフ／デバフ](/manual/buff)にあります。

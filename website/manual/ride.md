# 乗り物に乗る

このページは、コマをほかのコマに乗せて、一緒に動かす機能を説明します。
馬やバイクに乗り手がまたがる、後ろにもう1人を乗せる、荷物を積む、といった形を再現できます。
乗っているコマは乗り物の上に重ねて描かれ、乗り物が動けば一緒に運ばれます。
GMとPLが使えます。見学は乗り降りできません。

## 乗り物にする

<Shot src="ride" alt="モンスターBの右クリックメニュー。乗り物のグループが開き、「乗り物にする」に印が付いて、同乗できる・積める数・技能がなくても乗れる・乗る高さが並んでいる" width="450" caption="右クリックの「乗り物」で、乗り物にします" />

1. 乗り物にしたいコマを右クリックします。
2. **乗り物**のグループで、「乗り物にする」に印を付けます。

印を付けると、同じグループに次の4つの設定が出ます。

| 設定                 | 決めること                                                          |
| -------------------- | ------------------------------------------------------------------- |
| 同乗できる           | 前に乗るコマの後ろに、もう1人を乗せられます                         |
| 積める数             | 荷物として積めるコマの数です。1以上にすると、同乗はできなくなります |
| 技能がなくても乗れる | 乗り物を操る技能のないコマも、前に乗れます                          |
| 乗る高さ             | 乗っているコマが立つ高さを、乗り物の台座から測って決めます          |

乗る高さは、乗り物の高さに対する割合（1/4・半分・3/4・高さいっぱい）か、マス数で選びます。乗り物の高さは、コマの設定で「コマ高さを指定」をしているときは指定した高さで、していないときは大きさのマス数です。

ほかの高さにしたいときは「数値で指定…」を選びます。コマの詳細が設定タブで開き、コマ設定の「乗る高さ」に好きな数を入れられます。単位はpx・マス・%（乗り物の高さに対する割合）の3つです。単位を切り替えると、乗る位置はそのままで数値だけが換算されます。欄を空にすると既定に戻ります。

既定の乗る高さは、「コマ高さを指定」をしている乗り物では画像の上端です。たとえば500pxを指定した乗り物には、台座から500pxの高さ、つまり画像の上に乗ります。指定していない乗り物では、大きさの半分の高さに乗ります。

印を外すと、乗っていたコマはその場で降ります。

## 乗る・降りる

1. 乗るコマを掴んで、乗り物の上に置きます。画面の下に「〇〇は△△の上にいます」と出ます。
2. そこの**乗る**を押します。空いている席に合わせて、ボタンは**同乗する**や**積まれる**になります。

移動の計画で乗り物の上まで歩かせたときも、同じように出ます。
前に乗るコマが乗り手で、乗り物を動かします。
同乗できるのは、乗り手がもう乗っているときだけです。

乗り物の上にいるコマのメニューには、「〇〇に乗る」「〇〇に同乗する」「〇〇に積まれる」のうち、空いている席が**移動**の下に並びます。乗れない席には、乗れない理由が添えてあります。

降りるときは、乗っているコマを掴んで、乗り物から離れたところに置きます。メニューの「〇〇から降りる」でも降りられます。その手番にもう乗り降りしていて降りられないときは、乗り物の上に戻ります。

乗り物の上にいるとみなすのは、コマの真ん中が乗り物の台座の上にあるときです。[交戦エリア](/manual/engagement-zone#使えるようにする)の「同じ点とみなす距離」より近いときと、同じ交戦エリアに加わっているときも、乗り物の上にいるとみなします。コマどうしが同じマスに止まれない部屋でも、乗り物とそれに乗っているコマのマスには止まれます。

乗り降りはチャットに出ます。乗り物を操れる乗り手の乗り降りと、積まれていたコマが降りるときは「手番の行動を使わない」、ほかは「手番の行動を使う」と添えます。Axeは手番の行動の数を数えないので、どちらの行動を使ったかは卓で扱ってください。

倒れているコマ、転んでいるコマ、その場から動けないコマ、つかまれているコマは、乗り物に乗れません。倒れている乗り物、転んでいる乗り物、つかまれている乗り物、ほかの乗り物に乗っている乗り物にも乗れません。乗れないときも、メニューには乗る項目が理由を添えて出ます。倒れているかどうかは、コマのメニューの[コマの状態](/manual/engagement-zone#コマの状態)で付けます。

## 乗り物を操る技能

[部屋設定](/manual/room-settings)の**移動**タブにある「乗り物」の節で、「乗り物を操る技能の欄」にシートの欄の名前を書くと、その値が1以上のコマだけが乗り物を操れます。空欄なら、前に乗るコマはみな操れます。操れないコマが前に乗れるのは、「技能がなくても乗れる」にした乗り物だけです。

「乗るのに要る値の欄」を書くと、乗り物のシートのその欄の値と、乗るコマの技能の値を比べます。技能の値が足りなければ乗れません。

## 一緒に動く

乗り手が移動の計画を開くと、乗り物の計画になります。数えるのは、乗り物の移動力と、選んだ移動の種類です。歩き終えると、乗っているコマをみな乗り物と同じ点へ運びます。同乗しているコマと積まれているコマは、自分では動けません。乗り手のいない乗り物を動かせるのは、GMだけです。倒れている乗り手、その場から動けない乗り手、敵につかまれている乗り手は、乗り物を動かせません。計画を開こうとすると、そのことを知らせます。

乗り物を手で掴んで置いたときも、乗っているコマは一緒に運ばれます。乗っているコマだけを手で掴み、乗り物から離れたところに置くと、そのコマはそこで降ります。

敵につかまれているコマは、つかんでいるコマから離れないので、乗り物と一緒には運ばれません。乗り物が動くと、そのコマはその場で降ります。

3Dのテーブルでは、乗っているコマは乗り物の上に立ち、乗り物の絵の手前に描かれます。

乗り物と乗っているコマの名前・ゲージ・バフは、1枚の札にまとめて出ます。札は、乗り物と乗っているコマのうち背の高い方の絵より上に出るので、どちらの絵にも重なりません。札の中では、乗り物をいちばん下にし、その上に前に乗るコマから順に重ね、乗っているコマの名前の頭に席の印を付けます。乗り物の名前には、乗っているコマの数が出ます。真上から見る表示でコマの周りに名前を回しているときは、乗り物の名前の前に、乗っているコマの名前を並べます。

## 手番

[行動順](/manual/turn-order)を回しているあいだ、乗られている乗り物と同乗しているコマは、乗り手の手番に一緒に動きます。2つは行動順の一覧から外れ、ラウンド表示では乗り手の丸に小さな丸で重なります。手番の始まりと終わりのバフの減り方も、乗り手と同じです。積まれているコマは、自分の手番のままです。

前に乗るコマが[手番をもたない](/manual/turn-order#手番を持たないコマ)コマか、インベントリに出さないコマのときは、乗り物と同乗しているコマは行動順に残り、それぞれの手番で動きます。

手番を回しているあいだは、次の決まりもAxeが守らせます。行動順を回していないときは、どれも止めません。

- 乗り降りは、1つの手番に1回までです
- 乗り物が動けるのは、1つのラウンドに1つの手番だけです。ほかの手番で動いた乗り物には、乗っても動かせません
- 乗り手が自分の手番に降りると、乗り物と同乗しているコマは、その手番を終えたことになります
- 手番に降りたコマが自分で動けるのは、乗り物を操れる乗り手か積まれていたコマで、乗り物がそのラウンドにまだ動いていないときだけです

## 交戦エリアとの組み合わせ

乗っているコマは、乗り物と一緒に[交戦エリア](/manual/engagement-zone)に入り、一緒に出ます。エリアの中でも、乗り物と同じところに描かれます。

移動の割り込みとエリアから離れる判定では、乗り物と乗り手を合わせて1つと数え、人数は2つのコマの分を足します。乗り物と乗り手が移動に割り込むときは、乗り手の名前で尋ねられ、乗り物の分も数えます。同乗しているコマと積まれているコマは割り込みません。エリアの定員を数えるときは、一緒に入るコマをみな数えます。

## 転ぶ

コマのメニューの**コマの状態**で「転んでいる」に印を付けると、そのコマは転んだことになり、チャットにも出ます。転んでいるコマは乗り物に乗れず、転んでいる乗り物には誰も乗れません。自分の手番に転んだコマは、その手番が終わるまで印を外せません。

転んでいるコマを乗り物の上に置くと、画面の下のボタンは**起き上がって乗る**になります。押すと、起き上がってから乗ります。メニューにも「起き上がって〇〇に乗る」が出ます。乗り物から落ちたコマが、起きた乗り物に乗り直すときに使います。

## 落ちる

次のときは、乗っているコマが乗り物から自動で落ちます。

- 乗り物が転ぶか倒れると、乗っているコマがみな落ちます
- 乗り手が転ぶか倒れると、乗り手と積まれているコマが落ちます。同乗しているコマは残ります
- 同乗しているコマか積まれているコマが転ぶか倒れると、そのコマだけが落ちます

落ちたコマは転んでいる状態になり、チャットに落下距離が出ます。落下距離は、乗り物が動いていた長さの5分の1を切り上げた値です。部屋設定の「落ちるときの最低距離」（既定は2m）より短くはなりません。

動いていた長さには、その手番に乗り物が歩き出した経路の長さを使います。割り込みで途中で止まっても、歩き出した経路の長さのままです。その手番にまだ動いていなければ、乗り物が直前の手番に動いた長さを使い、その手番に動いていなければ0mとします。

部屋設定の「落ちたときに振る式」を書いておくと、落ちたコマの名前でその式を振ります。式の中の`{m}`は、落下距離の数に置き換わります。

## ふたり乗り

部屋設定の「ふたり乗りのバフ」に、チャットのバフと同じ書き方でバフを書いておきます。同乗しているコマが乗ると、乗り手と同乗しているコマの両方にそのバフが付きます。どちらかが降りるか落ちると、両方から外れます。

外れるのは、このとき付けたバフだけです。同じ名前のバフをもともと持っていたコマには付けず、持っていたバフもそのまま残します。たとえば`&ふたり乗り/判定-1/99`と書けます。書き方は[バフ／デバフ](/manual/buff)にあります。

## うまくいかないとき

| 見えるもの                                       | 原因と直しかた                                                                                                                                 |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 乗り物の上に置いても、画面の下に**乗る**が出ない | 乗り物にしていないか、コマの真ん中が乗り物の台座の上にありません。乗り物のコマで「乗り物にする」に印が付いているか確かめ、真ん中に置き直します |
| メニューの乗る項目に、理由が添えてあって選べない | 倒れている・転んでいる・その場から動けない・つかまれているコマは乗れません。席が埋まっているときや、乗り物を操る技能が足りないときも乗れません |
| 同乗できない                                     | 乗り手がまだ乗っていないか、乗り物の「積める数」が1以上です。積める乗り物には同乗できません                                                    |
| 降ろしたのに、乗り物の上に戻る                   | 手番を回しているあいだは、乗り降りは1つの手番に1回までです。次の手番に降ります                                                                 |
| 乗り物を動かせない                               | 手番を回しているあいだは、乗り物が動けるのは1つのラウンドに1つの手番だけです。ほかの手番で動いた乗り物は、次のラウンドまで動きません           |
| 乗っていたコマが勝手に降りた                     | 乗り物か乗り手が転んだか倒れて、落ちました。または、つかまれていたコマが、乗り物が動いたときにその場で降りました                               |

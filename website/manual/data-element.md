# シートの項目（データ要素）

このページはキャラクターシートの「ゲームデータ」に並ぶ1行1行（項目）の種別と、組み替えかたを説明します。
項目には種別があり、種別によって入力欄の形も、チャットから呼んだときに返る値も変わります。
GMとPLが組み替えられます。

種別は10種類です。ほとんどは名前のとおりですが、リソースと計算の2つは他と毛色が違うので、この2つだけ節を立てて説明します。
残りは一覧表で足ります。

## 項目を足す

シートを見ているだけのときでも、グループの見出しの右にある＋を押すと、そのグループの最後に項目を足せます。
押すと開く種別の一覧には、種別ごとに使い道の説明と見た目の見本が付いていて、選んだあとに名前を付けます。
この＋はシートを変えられる人にだけ出ます。

セクションを編集モードにしているあいだは、各グループの最後に**項目を追加**、各セクションの最後に**グループを追加**が出ます。
シートのいちばん下の**見出しを追加**は、セクションを1つ足し、その中にグループと項目を1つずつ作ります。

## 種別の変えかた

ゲームデータのセクション見出しの右にある鉛筆（**編集**）を押すと、そのセクションが編集モードになり、各行に種別のドロップダウンが出ます。
ここで選び直せばその行の種別が変わります。
編集モードはセクションごとに切り替わるので、触っていないセクションはそのままです。

<Shot src="data-element" width="640" alt="編集モードのゲームデータ。各行の右に種別のドロップダウンが開き、テキストから射程図形までの候補が並んでいる" caption="鉛筆を押すとそのセクションが編集モードになり、行ごとに種別を選べます" />

種別を変えても、入っていた値は消えません。
数値の`12`をテキストに変えれば文字列の`12`として残りますし、テキストに戻せばまた数値として扱えます。
ただし種別ごとの設定（選択肢や計算式）はその種別のときしか使われないので、行ったり来たりすると使われない設定が残ることはあります。

ドロップダウンの隣にはボタンが5つ並びます。
順に、[参照名](#項目を名前で呼ぶ)をコピー、[ポップアップ](#ポップアップに出す)に出す／出さない、**詳細設定**を開く、すぐ下に行を追加、この行を削除です。

詳細設定は種別ごとの追加設定です。
追加設定を持つ種別（選択・数値・リソース・計算・画像）と、テーブル表示の中の項目でだけ押せます。
チェックと、数だけが入っているテキストでも押せ、[既定値](#既定値)を決められます。

スマートフォンとタブレット、細くしたパネルでは、ドロップダウンとボタンの代わりに行の「⋯」が出ます。
押すと開く設定に、種別の一覧と詳細設定、上の5つのボタンと同じ操作がまとまっています。
詳しくは[スマートフォンで使う](/manual/mobile#項目を組み替える)を参照してください。

行やセクションを消すと、画面の下に通知が数秒出ます。通知の**元に戻す**を押すと、消したものが元の場所に戻ります。

## 種別の一覧

| 種別     | 入る値               | 詳細設定で決められること                  |
| -------- | -------------------- | ----------------------------------------- |
| テキスト | 1行の文字列          | 数だけが入っているときの[既定値](#既定値) |
| 数値     | 数値1つ              | 単位・最小・最大・[既定値](#既定値)       |
| リソース | 現在値と最大値の2つ  | [下の節](#リソースの現在値と最大値)を参照 |
| 長文     | 複数行の文字列       | —                                         |
| チェック | オン／オフ           | [既定値](#既定値)                         |
| 選択     | 選択肢から1つ        | 選択肢（1行1つ、またはカンマ区切り）      |
| 計算     | 式（結果は都度算出） | [下の節](#計算の項目)を参照               |
| 画像     | 画像1枚              | ポップアップで原寸表示                    |
| 射程図形 | 射程シェイプ         | —                                         |
| 演出     | エフェクト名         | —                                         |

長文欄は編集中、行のボタンの下に全幅で開きます。
はじめから10行分の高さがあり、文章に合わせて30行まで伸び、右下をつまめば手でも広げられます。

長文欄にURLだけを書くと、リンクとしての表示に切り替わります。
書き直したいときは、欄の上に出る**URL編集**のチェックを入れてください。

射程図形と演出は、値が文字列ではなく別の機能につながっています。
射程図形は行からそのまま[射程シェイプ](/manual/range)の編集と設置ができ、演出は選んだ[エフェクト](/manual/map-effects)をそのコマから撃てます。

## リソースの現在値と最大値

`HP 120 / 200`のように、今いくつかと上限がいくつかを1行で持ちます。
HP・MP・SAN・弾数のように増減するものはこれにします。

詳細設定では単位のほかに、上限と下限を**ベース＋補正**の2つに分けて置けます。
素の最大値を「最大値ベース」に、装備や状態異常による増減を「最大値補正値」に入れると、実際の上限は2つを足した値になります。
素の値を書き換えずに増減を出し入れできるので、バフが切れたときに元へ戻しやすくなります。

コマの上にバーとして出す設定（**コマにバーを表示**）と、増えると悪い値の意味を裏返す設定（**マイナスリソース**）、バーの色を決める設定（**バーの色**）も、リソースの詳細設定にあります。
この3つは[キャラクターコマ](/manual/character#コマにhpバーを出す)で説明しています。

増減したときに演出を出すかどうかも、ここで項目ごとに決めます（**増減でエフェクト**と**増減で効果音**）。
どちらも既定ではオフで、最初から入っているHPとMPだけ両方オンです。
効果音を入れた項目には**効果音のタイプ**が出ます。
**生身**と**メカ**があり、既定は生身です（[キャラクターコマ](/manual/character#項目ごとのエフェクトと効果音)で説明しています）。

**スライダー表示**を入れると、キャラクターシートと、コマにマウスを乗せると出る詳細の両方で、現在値の下にスライダーが出ます。
動かして離したところが現在値になり、最大値は変わりません。
スライダーの範囲は下限（置いていなければ0）から最大値までです。

**オーバーリソース**を入れると、現在値が最大値を超えられるようになります。
HPやMPのように入れていない項目は、これまでどおり最大値で止まります。
命中の補正を`命中V 1/1`のように持ち、戦闘中に`:命中V+2`で`3/1`へ上げ、戦闘が終わったら`:命中V={命中V^}`で`1/1`へ戻す、という使いかたができます。
このとき最大値は一時的な補正を外したときに戻る値です。
項目に[既定値](#既定値)を持たせておけば、`:命中V=既定`でも戻せます。`:*=既定`なら、既定値のあるほかの項目とまとめて戻せます。
オーバーリソースを入れただけで既定値のない項目は、リセットでは変わりません。
入れていても、最大値で止める指定（チャットの`L`や、リモコンの**最大値制限**）を付けた増減は最大値で止まります。
外すと、最大値を超えていた現在値は最大値に戻ります。

## 既定値

項目には既定値を持たせられます。既定値は[リセット](/manual/buff#reset)で戻る先の値です。
戦闘の前の値を既定値にしておくと、戦闘のあとに`:*=既定`や`&リセット-`の1行で、動かした値を元へ戻せます。
既定値のない項目はリセットでは変わりません。HPやMPも、既定値を持たせたときだけ戻ります。

### 既定値を持てる項目

| 種別     | 持てる既定値                                                               |
| -------- | -------------------------------------------------------------------------- |
| 数値     | 値                                                                         |
| リソース | 現在値と最大値。最大値の補正値と最小値の補正値も持てます                   |
| チェック | チェックあり、またはチェックなし                                           |
| テキスト | 数だけが入っている行の値。古い形式のシートは、数値もテキストの行に入れます |

長文・選択・計算・画像・射程図形・演出は、既定値を持てません。
[取り込んだシートのチェック表](#取り込んだシートに出る種別)のセルと、[GAP判定テーブル](#チェック表の距離から目標値を出す)のギャップ列のセルも持てません。テーブル表示の中のチェックはほかのチェックと同じく持てます。
立ち絵の位置と、コマに出す画像の番号も持てません。戦闘で動かす値ではないので、リセットで動かないようにしてあります。

テキストの行が数として読まれるのは、半角の数字だけが入っているときです。前に符号（`+`・`-`）、うしろに小数を付けられ、前後の空白は無視します。
空の行、全角の数字、`3点`のように単位や語が付いた行、`1e3`のような指数、`0x10`のような16進は、数として読みません。文章の行に既定値が付くことはありません。

### 項目ごとに決める

項目の**詳細設定**を開くと、**既定値**の欄があります。リソースには**既定の最大値**の欄もあります。
数を入れると既定値になり、空にすると既定値なしに戻ります。0を入れたときは、0が既定値です。
チェックの項目では「なし」「チェックあり」「チェックなし」から選びます。

テキストの項目では、数だけが入っているか、すでに既定値があるときに、この欄が出ます。

### いまの値をまとめて既定値にする

キャラクターシートの上部の**いまの値を既定値にする**を押すと、そのコマと部位の、既定値を持てる項目すべてに、いまの値を既定値として覚えさせます。
押すと、何項目が対象かを示した確認が出ます。戦闘の前に1回押しておく使い方を想定しています。

- 数値・チェック・リソースと、数だけが入っているテキストに付きます。リソースは現在値・最大値と、最大値・最小値の補正値を覚えます
- 補正値の既定値はこのボタンでだけ覚えます。**詳細設定**に補正値の欄はありません
- 値が空の項目と、数でない値の項目には付きません。前に付いていた既定値も外れます

隣の**既定値を消す**は、そのコマと部位のすべての項目から既定値を外します。こちらも確認が出ます。
スマートフォンや細くしたシートでは、2つとも右上の「⋮」に入っています。

新しく作ったコマと、[キャラクターの取り込み](/manual/character-import)で作ったコマには、既定値が付いていません。作ったあとに**いまの値を既定値にする**を押してください。

### 既定値と違う項目の印

既定値と違う値になっている項目には、名前の横に`↺`が出ます。
ポインタを乗せると`既定値 12`のように戻る先が出て、押すとその項目だけが既定値に戻ります。リソースは`既定値 120/200`のように、現在値と最大値の順で出ます。

- `↺`が出るのは、シートを変えられる人の画面だけです。見学には出ません
- 既定値と同じ値の項目と、既定値のない項目には出ません
- 押したときの確認と、チャットへの報告はありません。[元に戻す](/manual/buff#リセットを元に戻す)の対象にもなりません

### 戻すときの決まり

- リソースは補正値・最大値・現在値の順に戻します。最大値を先に戻すので、最大値を下げていた項目でも現在値が既定値まで戻ります
- 戻す値はその項目の最小と最大の範囲に収めます。[オーバーリソース](#リソースの現在値と最大値)を入れた項目は、最大値を超える既定値にも戻ります
- テキストの行にいったん付いた既定値は、あとで行に文章を入れても残り、リセットでその数に戻ります。戻したくない行は**詳細設定**で既定値を空にします
- 部屋設定の[項目の別名](/manual/room-settings#項目の別名)でつないだ項目は、片方だけに既定値があるとき、既定値のないほうも同じ値になります。両方に既定値があれば、それぞれの既定値に戻ります
- 既定値はコマと一緒に保存され、部屋データにも入ります。既定値ができる前に保存したコマは、既定値のないコマとして読み込みます

## 計算の項目

他の項目を参照して計算した結果を出す種別です。詳細設定の**計算式**に式を書きます。

```
筋力 + レベル * 2
floor(器用度 / 3)
```

使える演算子は`+` `-` `*` `/` `**`と括弧、関数は`floor` `ceil` `round` `abs` `min` `max`です。

項目は名前でそのまま呼べます。
同じ名前の項目がシート内に2つ以上あるときだけ、`[戦闘特技/最終能力/コスト]`のように角括弧でパスを書いてください。
パスは行の**参照名をコピー**ボタンで取れます。
コピーできると「「（パス）」をコピーしました」、ブラウザがクリップボードへの書き込みを断ったときは「「（パス）」をコピーできませんでした」と出ます。

読み取り方には決まりが3つあります。

- リソースは現在値のほうを読みます。`HP 4 / 20`を式から呼ぶと`4`です
- 計算項目から別の計算項目を呼べます。呼ばれたほうが先に計算されます
- 式が読めないと`?`が出ます。名前の打ち間違いか、計算項目どうしが互いを呼び合っている場合です

この種別で1つだけ覚えておいてほしいのは、**項目そのものが持っているのは式であって、計算結果ではない**ことです。
結果は表示のたびに算出されます。
参照元の値を変えれば、シートもポップアップも[チャットの参照](#項目を名前で呼ぶ)も、その場で新しい結果に切り替わります。

## 項目を名前で呼ぶ

チャットやチャットパレットから`{名前}`と書くと、送信時にその項目の値へ置き換わります。
`{HP^}`でリソースの最大値、`t{名前}`でターゲット中のコマの値を読めます。
記法の詳細は[チャットの特殊記法](/manual/chat-syntax#項目と変数の参照)を参照してください。

参照名をコピーするボタンで取れるのは`戦闘特技/最終能力/コスト`のようなパスだけで、`{}`は付きません。
チャットに貼るときは自分で`{`と`}`で囲んでください。

同じ名前の項目が複数あると、短い名前では呼べません。パスで呼ぶか、名前を分けてください。

名前の一部を別の項目から取ることもできます。`{{属性}耐性}`は、属性が「火」なら`{火耐性}`を読みます。

## ポップアップに出す

行の**ポップアップ表示**ボタンを押した項目は、コマにマウスを乗せたときのポップアップに出ます。
よく参照する能力値や、戦闘中に見たい残弾数などを選んでおくと、シートを開かずに済みます。

グループごと選ぶと、その下の項目がまとめて出ます。中の項目を個別に選ぶ必要はありません。

## 行の複製

編集モードのセクションとグループの見出しには、**複製**のボタンがあります。
押すと中の項目ごとコピーされ、すぐ下に入ります。
種別も詳細設定も写るので、同じ形の行を一から組み直さずに済みます。

隣に同じ名前があれば、コピーの名前には「義眼2」のように番号が付きます。中の項目の名前はそのままです。
[チェック表](#チェック表を作る)の行を増やすのに向いているのはこのためで、セルの名前がそろったまま行だけが増えます。

コピーは元とは別の部分として扱われます。片方の値を書き換えても、もう片方は変わりません。

## テンプレート

見出しの**テンプレートとして保存**を押すと、そのセクションやグループの写しがコマに残ります。
シートの見た目は変わりません。元の部分を消しても、テンプレートは残ります。

複製はすぐ下にしか入りませんが、テンプレートなら離れた表にも、消したあとのシートにも同じ形を持ち込めます。
武器の行を1つ作って取っておき、別の表にも足す、といった使い方です。

### 設定タブでの準備

取っておいたテンプレートは、キャラクターシートの**設定**タブの**テンプレート**欄に並びます。
中身は保存した時点の値のままです。

ここはシートと同じ編集画面なので、値を空にする、名前を使い回しやすいものに変える、選択の項目に選択肢を足す、といった手入れができます。
見出しの複製と削除もそのまま使えます。
**シートに追加**を押すと、シートの末尾に新しいセクションとして入ります。

同じ部分をもう一度保存すると、前のテンプレートは上書きされず、番号の付いた別のテンプレートが増えます。
設定タブで整えたテンプレートが、元の値で上書きされることはありません。

### 見出しから呼び出す

テンプレートが1つでもあると、編集モードの見出しに**テンプレートから追加**のボタンが出ます。
押すとテンプレートの名前が並び、選んだものがシートに入ります。
名前の右の × はそのテンプレートを消すボタンです。

入る場所は呼び出した見出しとテンプレートの深さで決まります。
シートの入れ子は、セクションの中にグループ、その中にもう一段グループまでで、この段数を超えないように置き場所を探します。

1. 呼び出した見出しの中に収まれば、その中の末尾に入る
2. 収まらなければ一段外へ出て、いま出てきた部分の直後に入る。そこでも収まらなければ、さらに外へ出る
3. 最後まで収まらなければ、新しいセクションとして、呼び出したセクションの直後に入る

グループのテンプレートがセクションとして入ったときは、直下の項目が「基本」というグループにまとめられます。
セクションの直下に置けるのはグループだけだからです。

### テンプレートの保存先

テンプレートはコマに付いていて、シートの外に置かれます。
コマと一緒に保存され、部屋データにもそのまま入ります。

シートの外にあるので、次の2つには加わりません。

- `{名前}`の[参照](#項目を名前で呼ぶ)。シートと同じ名前の項目をテンプレートが持っていても、名前が重なって呼べなくなることはありません
- コマの右クリックメニュー。テンプレートの中の演出や射程図形は、シートに戻すまでメニューに出ません

## 取り込んだシートに出る種別

[キャラクターの取り込み](/manual/character-import)や旧Udonariumのデータから来たシートには、ドロップダウンに出てこない種別が混じることがあります。
Markdownとチェック表の2つです。
どちらもシートには表示されますが、選び直す先としては出てきません。
一度ほかの種別に変えると**この2つには戻せない**ので、変える前にコピーを取っておくと安全です。

## チェック表を作る

技能表のようなチェックの並んだ表は、グループを**テーブル表示**に切り替えて作ります。
サンプルキャラクターに入っている「技能表」と「技能表タイプ2」がその形なので、実物を開いて確かめるのが早道です。

<Shot src="data-element-table" width="640" alt="表として描かれた技能表。左に2から12の行見出し、技巧・身体・隠密の列にチェックが並ぶ" caption="左が行の名前を見出しにした表、右が列グループで上段見出しをまとめた表" />

表になる条件は2階層きっかりであることです。
**セクションの子がすべてグループ（＝行）で、行の子がすべて項目（＝セル）** のときだけ表として描かれます。
行の中にさらにグループがあると、表示は普通の入れ子に戻ります。

作る順番はこうなります。

1. セクションの中に**下位グループを追加**して、行を作る
2. 行の中に項目を並べ、チェック欄にしたいものの種別を**チェック**にする
3. 行を必要なぶん増やす。同じ列に入れたいセルは**行をまたいで同じ名前**にする。1行作ってから[複製](#行の複製)で増やせば、名前はそろったままになる
4. セクション見出しの表アイコンを押して、テーブル表示に切り替える

列は名前で決まるので、見出しの文字を変えたいときは詳細設定の**列表示**に入れてください。
名前は`{技巧}`のような参照にそのまま使うため、表示だけ変えたい場面はよくあります。

上段にもう1段の見出しを重ねたいときは**列グループ**を使います。
隣り合う列に同じ文字を入れると、その範囲が1つの見出しにまとまります。
技能表タイプ2の「肉体技能」「機械技能」がこれで、名前と習熟度の2列を束ねています。

行の左端に出る見出しは表設定（セクション見出しの隣のつまみ）の**行見出し**で決まります。
空にしておくと行の名前がそのまま左端に出ます（技能表の2〜12がこれです）。
文字を入れると、代わりにその文字が縦書きで全行にまたがる1つの見出しになります。

## チェック表の距離から目標値を出す

チェック表には、習得済みの技能から判定したい技能までの遠さで難易度が決まる遊び方があります。
表の上でその距離を数えて目標値を出し、チャットに渡すところまでをAxeがやります。

### オンにする

表のセクションを編集モードにして、見出しの隣の**表設定**（つまみ）を開き、**GAP判定テーブル**にチェックを入れてください。
数え方の設定が4つ出ます。

<Shot src="gap-judgement-setting" width="640" alt="表設定の行。行見出し・GAP判定テーブルのチェック・基礎難易度5・GAP距離1・左右ループ・上下ループが並ぶ" caption="GAP判定テーブルにチェックを入れると、数え方の設定が出ます" />

- **基礎難易度** — 距離0のときの目標値。既定は5
- **GAP距離** — ギャップ列1つぶんの重さ。既定は1
- **左右ループ** — いちばん右の列といちばん左の列を隣として数えます
- **上下ループ** — いちばん下の行といちばん上の行を隣として数えます

### 2つのモードを行き来する

オンにすると、表の上にモードのボタンが出ます。押すたびに切り替わり、ボタンにはいまのモードが出ます。

- **技能習得モード** — チェックを付け外しします。習得した技能に印を付けるのはこちら
- **判定算出モード** — チェックは動かず、マスをクリックすると判定の候補が出ます

<Shot src="gap-judgement" width="640" alt="判定算出モードの技能表。静音移動をクリックして開いた候補一覧に、跳躍1・解錠2・工作3が距離順に並ぶ" caption="判定したい技能をクリックすると、習得済みの技能が近い順に並びます" />

### 判定する

判定算出モードで技能のマスをクリックすると、習得済みの技能が近い順に最大5件出ます。
数字がその技能からの距離です。
吹き出しのボタンを押すと、チャット入力欄にこの形が入ります。

```
2d6>=7 静音移動（解錠から2）
```

目標値は**基礎難易度 + 距離**です。
括弧の中は判定した技能と、距離を数えた起点の技能です。
ダイスボットは半角スペースまでを読むため、括弧の中はロールの邪魔になりません。
ログを後から読み返すときに、その目標値が何の判定だったかが残ります。

### 距離の数え方

行の差と列の差を足したものが距離です。
これに、途中で越えたギャップ列のうちチェックの入っているもの1つにつき、GAP距離の値が足されます。
チェックの入っていないギャップ列は0として数えます。

左右ループ・上下ループを入れると反対回りでも数え、近いほうを採ります。

## うまくいかないとき

| 見えるもの                                 | 原因と直しかた                                                                                                                 |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| 種別を変える欄が出ない                     | 編集モードに入っていません。セクションの鉛筆を押します（→ [種別を変えるには編集モードに入る](#種別の変えかた)）                |
| チャットから呼んだ値が、思った数にならない | 計算の項目の扱いは[計算に入るのは式で、数字ではない](#計算の項目)に、呼びかたは[項目を名前で呼ぶ](#項目を名前で呼ぶ)にあります |
| 消した行を戻したい                         | 消した直後に画面の下に出る通知の**元に戻す**を押します                                                                         |
| リセットしても値が戻らない項目がある       | その項目に既定値がありません。**詳細設定**で決めるか、**いまの値を既定値にする**を押します（→ [既定値](#既定値)）              |
| テキストの項目に既定値の欄が出ない         | 行に数以外の文字が入っています。半角の数字だけにすると欄が出ます（→ [既定値を持てる項目](#既定値を持てる項目)）                |

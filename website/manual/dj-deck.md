# DJデッキ

このページは、ジュークボックスで流している曲のテンポと拍、曲と曲のつなぎかた、エフェクト、キュー、パッドを扱う「DJデッキ」を説明します。
ミニプレイヤーの右上にある波形のボタンを押すと、ミニプレイヤーの下にDJデッキが開きます。流している曲のテンポと拍、曲と曲のつなぎ方、エフェクト、キュー、パッドをここで扱います。デッキを開いているかどうかはこのブラウザに残り、次にアプリを開いたときも同じ状態から始まります。スマートフォンの画面にはミニプレイヤーが出ないため、DJデッキも使えません。

## 誰が何を操作できるか

デッキの上には、スペクトルと、流している曲のBPMが出ています。その下の「デッキ」「パッド」「ミックス」のタブで、操作を切り替えます。

| 操作                                                     | 見学 | PL  | GM  |
| -------------------------------------------------------- | ---- | --- | --- |
| テンポと拍、キュー、エフェクト、ブレーキ、パッドを鳴らす | ×    | ○   | ○   |
| パッドに音源を割り当てる、ミックスの設定を変える         | ×    | ×   | ○   |

見学のときも、テンポや音量の表示は見られます。

## 曲の読み取り

部屋に追加した音源は、裏で1曲ずつ読み取られます。流している曲を最初に読み、再生リストの曲と流している環境音、ライブラリの残りの順に続けます。読み取るのは、曲全体の大きさ（ラウドネス）、いちばん大きい音、曲の前後の無音、テンポと拍の位置です。

読み取った結果は、部屋の全員に共有され、部屋の保存データにも入ります。このブラウザにも残るので、同じ音源を別の部屋で使うときは読み直しません。見学の参加者が読み取った結果は、その人の画面でだけ使われます。

リンクだけで追加した音源と、30MBを超えるファイルは読み取りません。メモリの少ない端末（2GB未満）でも読み取りません。そうした端末でも、ほかの参加者が共有した結果は使われます。

## テンポと拍

BPMの右の4つの点は、いま小節の何拍目にいるかを表します。拍の頭で点が光ります。持続音だけの曲のように拍が見つからない曲では、BPMの代わりに「拍が見つかりません」と出ます。ライブラリと再生リスト、ミニプレイヤーの一覧でも、曲名の横にBPMが出ます。

テンポや小節の頭がずれているときは、「デッキ」のタブで直します。直したテンポは部屋の全員に共有され、部屋の保存データに入ります。

- TAP：曲の拍に合わせて押します。4回目から、押した速さのテンポがその曲に設定されます。最後に押した位置が小節の何拍目にあたるかは、直す前の数え方を引き継ぎます。拍が分からなかった曲では、最後に押した位置が小節の1拍目になります
- ÷2・×2：テンポを半分や2倍にします。小節の頭の位置は変わりません
- 旗と「1」のボタン：いまの位置を小節の1拍目にします
- 右端の矢印：手で合わせたテンポをやめて、読み取ったテンポに戻します

## キュー

曲の中の位置を4つまで覚えておき、そこへすぐ移れます。空の枠を押すと、いまの位置が入ります。時刻の入った枠を押すと、部屋の全員の曲がその位置へ移ります。一時停止しているときは、次に再生を押したときにその位置から始まります。右クリックで枠を空けます。

キューは曲ごとに覚えておき、部屋の保存データにも入ります。入れたキューは、ミニプレイヤーのシークバーの上に印で出ます。

[クオンタイズ](#クオンタイズ)をオンにしているときは、キューへの移動が次の拍の頭まで待ちます。キューを入れる位置も、いちばん近い拍に合わせます。

## エフェクト

「デッキ」のタブの3つのつまみで、部屋の全員が聞いているBGMにエフェクトをかけます。つまみは上下にドラッグして回します。Shiftを押しながらドラッグすると細かく回せます。ホイールや矢印キーでも回せて、ダブルクリックで元の位置に戻ります。

- フィルター：真ん中では何もしません。左へ回すと高い音を削ってこもった音に、右へ回すと低い音を削って細い音にします
- エコー：曲の3/4拍ごとに音を返します。拍が分からない曲では0.375秒ごとです
- 残響：広い会場で鳴っているように響かせます

つまみの右上のボタンで、エフェクトをまとめて切ります。エフェクトの状態は部屋の保存データに入りません。

ブレーキのボタンを押すと、レコードを止めたように、音程を下げながら1.2秒かけて曲が止まります。曲は一時停止になり、再生を押すとブレーキをかけ始めた位置から続きます。

## パッド

「パッド」のタブに、8つのパッドが並びます。GMが空のパッドを押すと、ライブラリの音源の一覧が出て、そのパッドに割り当てる音源を選べます。GMが右クリックすると、パッドが空きます。パッドの割り当ては部屋の保存データに入ります。

パッドを押したときの動きは、音源のタグで決まります。

- SE：BGMに重ねて一度鳴らします
- 環境音：流していなければ流し始め、流していれば止めます
- BGM：その曲に切り替えます。クロスフェードとクオンタイズは、ほかの曲の切り替えと同じように効きます

鳴っているあいだは、そのパッドが光ります。

## ミックス

「ミックス」のタブには、流している曲のラウドネスと、自動音量で上げ下げしている量（dB）が出ます。その下の部屋の設定はGMだけが変えられ、変えると部屋の全員に効きます。部屋の保存データにも入ります。

### 自動音量

最初からオンです。曲ごとの大きさの差を、読み取った結果からそろえます。BGMとSEは-16LUFSに、環境音はBGMの下で鳴るように-24LUFSにそろえます。カットインの音楽と、場面に合わせて鳴る音にも効きます。

上げるのは12dBまでで、いちばん大きい音が-1dBFSを超えない範囲に限ります。下げるのは24dBまでです。曲を流している途中で読み取りが終わったときは、1.5秒かけて新しい大きさに寄せます。

### ダッキング

最初からオンです。効果音（SE）とカットインが鳴っているあいだだけ、BGMを9dB下げます。鳴り終わると、1秒ほどかけて元の大きさに戻ります。自分の[音の設定](/manual/sound-settings)で消した種類の音では下がりません。

### クオンタイズ

最初はオフです。オンにすると、曲の切り替えは流している曲の次の小節の頭まで、キューへの移動は次の拍まで待ってから動きます。小節の頭まで4秒より長く待つときは、次の拍で切り替えます。拍が分からない曲を流しているときは待ちません。待つ時間は、参加者それぞれの画面の再生位置で決まります。

### クロスフェード

曲を切り替えるとき、前の曲を何秒かけて次の曲に重ねるかを、なし・1・2・4・8・12秒から選びます。最初は2秒です。前の曲・次の曲のボタン、一覧からの選曲、再生リストの切り替え、パッド、ほかの参加者の操作のどれでも重なります。

なし以外にしているときは、曲の前後の無音も詰めます。0.3秒より長い無音で始まる曲は、無音を飛ばして始めます。曲の終わりは、最後の音が消える位置からクロスフェードの秒数だけ手前で、次の曲へ移り始めます。1曲リピートのときは、次の曲へ移りません。

一時停止と停止のフェードは、次の[一時停止のフェード](#一時停止のフェード)で決めます。

### 一時停止のフェード

一時停止と停止のとき、何秒かけて音を小さくしてから止めるかを、なし・0.4・1・2・4・8秒から選びます。最初は0.4秒です。一時停止した曲を再開するときも、同じ秒数をかけて音を大きくしていきます。なしにすると、すぐに止まり、すぐに鳴り始めます。

### ビートライト

最初はオフです。オンにすると、流している曲の拍に合わせて、部屋の全員の画面の縁がアクセント色でやわらかく光ります。小節の1拍目は少し強く光ります。画面の真ん中は変わりません。光るのは1秒に3回までで、180BPMより速い曲では2拍に1回にします。

ビートライトを自分の画面でだけ消すには、タブの下の「自分の画面ではビートライトを消す」にチェックを入れます。このブラウザにだけ残る設定です。[アニメーションの表示](/manual/theme#animation)を「停止」にしているときと、「自動」でOSが動きを減らしているときも光りません。

## 古い版を使っている参加者がいるとき

古い版の画面では、自動音量、ダッキング、クロスフェード、エフェクト、ビートライトは効きません。ブレーキはふつうの一時停止に、キューへの移動はふつうのシークになります。テンポ、キュー、パッドの割り当ては古い版の画面を通っても消えずに残ります。

## うまくいかないとき

| 見えるもの                                 | 原因と直しかた                                                                                        |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| テンポや拍が出ない                         | リンクだけで足した音源と、30MBを超えるファイルは読み取りません                                        |
| つまみやボタンを動かせない                 | 操作できる役割が決まっています（→ [誰が何を操作できるか](#誰が何を操作できるか)）。見学は見るだけです |
| 部屋を読み込み直したら、エフェクトが消えた | エフェクトの状態は、部屋の保存データに入りません                                                      |
| 古い版の参加者だけ、音が違う               | → [古い版を使っている参加者がいるとき](#古い版を使っている参加者がいるとき)                           |

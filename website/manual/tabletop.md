# 視点とテーブル操作

## 視点を動かす

テーブル（中央の 3D の場）は、次の操作で見回せます。

- **回転 / 移動** — テーブルの何もない場所をドラッグ
- **ズーム** — マウスホイール
- **2D 表示** — 画面左の FAB にある視点ボタン、または **卓上ディスプレイ** から真上視点に切り替え

## パネルを別のウィンドウで開く {#panel-window}

パネルのタイトルバーにある **別のウィンドウで開く**（斜め矢印）を押すと、そのパネルが OS のウィンドウとして出ます。
卓とチャットを 2 枚のディスプレイに分けたいときのためのものです。

- **部屋のパネルも、コマのシート・チャットパレット・リモコンも切り出せます**
- ウィンドウを閉じると、パネルは元の卓に戻ります
- 切り出したパネルには閉じる・最小化・回転のボタンが出ません。OS のウィンドウ側で操作します
- テーマとスキンは開いているすべてのウィンドウに反映されます
- 元の画面を再読み込みすると、切り出したウィンドウも閉じます

**押した瞬間にパネルは開き直されます。** 書きかけの入力や、どこまで読んでいたかは引き継ぎません。中身は同期しているものを映しているだけなので、卓の状態は失われません。

ブラウザのポップアップブロックに引っかかると開きません。その場合はこのサイトのポップアップを許可してください。

## 卓上ディスプレイ — 2D まわりを 1 か所で {#tabletop-display}

真上から見て遊ぶための設定は、置き場所が 3 か所に分かれています。どれを触ればいいのか分からなくなるので、FAB の **卓上ディスプレイ** にまとめてあります。

いちばん上の **卓上モード** を入れれば、あとは触らなくて構いません。視点が 2D になり、四方の席へ向ける設定（遠近をなくす、コマ名の周回、外周ティッカー、回転メニュー、コマの詳細を画面の縁へ、カットインを四方へ、ウィンドウの 90° 回転）がまとめて入ります。切ると視点だけ 3D に戻り、入った設定はそのまま残ります。3D では何もしない設定なので、消す必要がないからです。

| 大項目         | 中身                                                                       | 誰に効くか                           |
| -------------- | -------------------------------------------------------------------------- | ------------------------------------ |
| 視点           | 自分の視点（自動 / 3D / 2D）、テーブルの推奨、遠近をなくす                 | 自分の画面 / テーブル・GM            |
| コマの見せ方   | コマ画像をマス内に収める、キャラクターの向き、コマ画像を常にカメラに向ける | 自分の画面 / 部屋・GM / テーブル・GM |
| 多方向表示     | コマ名の周回、外周ティッカー、カットインの向き、文字サイズ                 | 自分の画面だけ                       |
| メニューと操作 | 回転メニュー、コマの詳細表示、ウィンドウの 90° 回転                        | 自分の画面だけ                       |
| 実寸表示       | 1 マスの実寸、実寸で表示、ビュー固定、画面の実測                           | 自分の画面だけ                       |

項目ごとに **誰に効くか** の札が付きます。自分の画面だけのものは誰でも変えられ、部屋やテーブルのものは GM だけです。**2D のとき** の札が付いた段は、真上から見ているあいだしか効きません。3D で見ているあいだは薄く表示されます。逆に **コマ画像を常にカメラに向ける** は 3D 専用です。真上から見れば絵は必ずこちらを向くので、そこでは意味がありません。

視点は上から決まります。自分の視点が **自動** のあいだだけテーブルの推奨に従い、3D か 2D を自分で選べばそちらが優先します。

**コマ画像をマス内に収める** は、背の高い絵をマスの大きさに収めます。コマの絵はマスの下端から上へ伸びるので、縦長の絵ははみ出して後ろのコマを隠します。真上から見ているとそれが特に響くため、卓上モードにも入れてあります。手で高さを決めたコマも、収めるあいだはマスに合わせます。

元の置き場所からは消していません。[テーブル設定](/manual/table-setting) と [部屋設定](/manual/room-settings#ui) に慣れている人はこれまでどおり使えます。

## グリッドとスナップ

グリッドの表示・種類（四角 / ヘクス）やスナップの効き方は [テーブル設定](/manual/table-setting) で調整します。これらはテーブルごとに参加者間で同期されます。

## オブジェクトを置く

テーブルの何もない場所を**右クリック**すると、作成メニューが開きます。

<Shot src="table-context-menu" width="620" alt="テーブルの何もない場所を右クリックしたときの作成メニュー" caption="何もない場所を右クリックすると、置けるものが並びます" />

- **キャラクターを作成** → [キャラクターコマ](/manual/character)
- **ダイスを作成** → [ダイス](/manual/dice)
- **共有メモを作成** → [共有メモ](/manual/notes)
- **トランプの山札を作成** → [カード](/manual/cards)
- **射程範囲を作成** → [射程範囲](/manual/range)
- **マップマスクを作成** → [マップマスク](/manual/map-mask)
- **地形を作成** → [地形](/manual/terrain)

置いたあとの移動・回転・複数選択など共通の操作は [オブジェクトの基本操作](/manual/objects) を参照してください。

# 視点とテーブル操作

このページは、テーブル（画面の中央の3Dの場）の見回しかたと、パネルの扱いかた、テーブルに物を置く入口を説明します。
視点とパネルの操作は、ロールにかかわらず誰でも使えます。
物を置くのは、GMとPLです。

## 視点を動かす

<Shot src="table" alt="森を俯瞰したテーブルにキャラクターとモンスターのコマが並んでいる" caption="ドラッグで視点を動かし、ホイールで寄り引きします" />

| したいこと         | マウス                                       | キーボード                                           | スマートフォン                         |
| ------------------ | -------------------------------------------- | ---------------------------------------------------- | -------------------------------------- |
| 平行に動かす       | 何もない所を左ボタンでドラッグ               | `←` `→` `↑` `↓`                                      | 1本の指でドラッグ                      |
| 回す・傾ける       | 何もない所を右ボタンでドラッグ               | `Shift`＋`←` `→`（回す）・`Shift`＋`↑` `↓`（傾ける） | 2本の指で回す                          |
| 近づく・離れる     | ホイール                                     | `Ctrl`＋`↑` `↓`                                      | 2本の指で広げる・つまむ                |
| 範囲で選ぶ         | 何もない所を少し押したままにしてからドラッグ | なし                                                 | 何もない所を長押ししてから指を滑らせる |
| 真上から見る（2D） | FABメニューの**表示**の**視点**を押す        | なし                                                 | **メニュー**の視点の切り替え           |

近づける近さと離れられる遠さは、テーブルのマスの大きさに合わせて少し変わります。
マスの大きいテーブルは遠くから全体を見渡しやすく、マスの小さいテーブルは近くまで寄れます。

キーは、チャット欄などに文字を入力しているあいだは効きません（→ [キー操作の一覧](/manual/shortcuts)）。
範囲で選んだあとの操作は、[オブジェクトの基本操作](/manual/objects)にあります。

## パネルを別のウィンドウで開く {#panel-window}

パネルのタイトルバーにある**別のウィンドウで開く**（斜め矢印）を押すと、そのパネルがOSのウィンドウとして出ます。
テーブルとチャットを、2枚のディスプレイに分けたいときのためのものです。

- 部屋のパネルも、コマのシート・チャットパレット・リモコンも切り出せます
- ウィンドウを閉じると、パネルは元の画面に戻ります
- 切り出したパネルには閉じる・最小化・回転のボタンが出ません。OSのウィンドウ側で操作します
- そこから開く小さなパネル（チャットの設定やダイス表など）と、セレクトボックスの一覧は、そのウィンドウの中に出ます
- テーマとスキンは開いているすべてのウィンドウに反映されます
- 元の画面を再読み込みすると、切り出したウィンドウも閉じます

::: warning 押すと、パネルは開き直されます
書きかけの入力や、どこまで読んでいたかは引き継ぎません。
[タブにまとめた](#panel-tabs)複数枚を出すときは移すだけなので、そちらは残ります。
中身は同期しているものを映しているだけなので、テーブルの状態は失われません。
:::

ブラウザがポップアップを止めると、開きません。
そのときは、このサイトのポップアップを許可してください。

## パネルをタブにまとめる {#panel-tabs}

パネルのタイトルバーを、別のパネルのタイトルバーへ重ねて離すと、2枚が1枚にまとまります。上に出るタブで切り替えます。チャット・キャラクターシート・チャットパレットを開くと画面が埋まるので、使う分をひとまとめにしておくためのものです。

中身は作り直しません。書きかけのチャットも、ログを読んでいた位置も、まとめた後にそのまま残ります。[別のウィンドウで開く](#panel-window)との違いはここです。

| したいこと           | 操作                                                       |
| -------------------- | ---------------------------------------------------------- |
| 切り替える           | タブを押します                                             |
| 1枚だけ閉じる        | タブの × を押します                                        |
| 並べ替える           | タブを列の中でドラッグします                               |
| 1枚のパネルに戻す    | タブを列の外へドラッグします。まとまる前の大きさに戻ります |
| まとめた全部を閉じる | タイトルバーの × を押します                                |

移動・リサイズ・最小化・全画面・90°回転は1枚のときと同じで、まとめた全部に効きます。透明度は、そのとき表示しているタブの種類の設定を使います。

別のウィンドウへも、まとめたまま出せます。複数枚のときは切り出しボタンが全部を1つのウィンドウへ移し、そのウィンドウを閉じると、同じ組で元の画面に戻ります。移すだけなので書きかけも残ります。1枚だけのときは開き直しになるので、そちらは残りません。

まとめられないものもあります。カットイン、ノベルモードのログや選択窓、枠のない表示は対象外です。スマートフォンのような幅の狭い画面ではパネルが全画面で開くため、この操作自体がありません。

まとめた組み合わせは、保存しません。
ページを読み込み直すと、パネルは元どおり1枚ずつ開きます。

## 卓上ディスプレイ（真上から見て遊ぶ設定） {#tabletop-display}

真上から見て遊ぶための設定は、置き場所が3か所に分かれています。どれを触ればいいのか分からなくなるので、FABメニューの**テーブル関連**にある**卓上ディスプレイ**にまとめてあります。

いちばん上の**卓上ディスプレイ用の推奨設定をオン**を入れれば、あとは触らなくて構いません。視点が2Dになり、四方の席へ向ける設定（遠近をなくす、コマ名の周回、外周ティッカー、回転メニュー、コマの詳細を画面の縁へ、カットインを四方へ、ウィンドウの90°回転）がまとめて入ります。切ると項目は既定に戻り、視点はそのままです。2Dで見ているだけでは、これらは入りません。
視点を2Dにしただけの画面は、メニューも表示も通常のままです。

| 大項目         | 中身                                                          | 誰に効くか                |
| -------------- | ------------------------------------------------------------- | ------------------------- |
| 視点           | 自分の視点（自動 / 3D / 2D）、テーブルの推奨、遠近をなくす    | 自分の画面 / テーブル・GM |
| コマの見せ方   | キャラクターの向き                                            | 部屋・GM                  |
| 多方向表示     | コマ名の周回、外周ティッカー、カットインの向き、文字サイズ    | 自分の画面だけ            |
| メニューと操作 | コンテキストメニューの形、コマの詳細表示、ウィンドウの90°回転 | 自分の画面だけ            |
| 実寸表示       | 1マスの実寸、実寸で表示、ビュー固定、画面の実測               | 自分の画面だけ            |

項目ごとに**誰に効くか**の札が付きます。自分の画面だけのものは誰でも変えられ、部屋やテーブルのものはGMだけです。**2Dのとき**の札が付いた段は、真上から見ているあいだしか効きません。3Dで見ているあいだは薄く表示されます。逆に**コマ画像を常にカメラに向ける**は3D専用です。真上から見れば絵は必ずこちらを向くので、そこでは意味がありません。

自分の視点が**自動**のあいだだけテーブルの推奨に従い、3Dか2Dを自分で選べばそちらが優先します。

**コマ画像をマス内に収める**は、背の高い絵をマスの大きさに収めます。コマの絵はマスの下端から上へ伸びるので、縦長の絵ははみ出して後ろのコマを隠します。真上から見ているとそれが特に問題になるため、卓上モードにも入れてあります。手で高さを決めたコマも、収めるあいだはマスに合わせます。

元の置き場所からは消していません。[テーブル設定](/manual/table-setting)と[部屋設定](/manual/room-settings#ui)に慣れている人はこれまでどおり使えます。

## グリッドとスナップ

グリッドの表示・種類（四角 / ヘクス）やスナップの効き方は[テーブル設定](/manual/table-setting)で調整します。これらはテーブルごとに参加者間で同期されます。

## うまくいかないとき

| 見えるもの                                   | 原因と直しかた                                                                                                          |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| ドラッグすると、視点が動かずに枠が出る       | 押したまま少し止まると、範囲選択になります。押してすぐに動かします                                                      |
| 右クリックしても作成のメニューが出ない       | 見学のときは出ません。コマの上で右クリックすると、そのコマのメニューが出ます。何もない場所で押します                    |
| **別のウィンドウで開く**を押しても開かない   | ブラウザがポップアップを止めています。アドレスバーの表示から、このサイトのポップアップを許可します                      |
| 別のウィンドウにしたら、書きかけの文が消えた | 1枚のパネルを切り出すと、開き直しになります。書きかけを残したいときは、先にほかのパネルとタブにまとめてから切り出します |
| 2Dにしたのに、メニューや表示が変わらない     | 視点を2Dにしただけでは変わりません。**卓上ディスプレイ**の**卓上ディスプレイ用の推奨設定をオン**を入れます              |

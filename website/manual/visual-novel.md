# ビジュアルノベルモード

チャットのやり取りを、立ち絵とメッセージウィンドウで構成された**ビジュアルノベル風の画面**として再生・進行できるモードです。FAB メニューの「ノベルモード」（本のアイコン）から開きます。もう一度押すか、右上の **終了** ボタン、`Esc` キーで閉じます。

<Shot src="visual-novel" alt="ノベルモード。左に立ち絵、上に発言のふきだし、下に再生コントロール" caption="立ち絵とメッセージウィンドウで、チャットをそのまま読み物として再生します" />

ノベルモードはオーバーレイとして重なって表示されるだけなので、**テーブルや他のパネルはそのまま操作できます**。表示・発言の対象タブは上段の**チャットタブ**セレクトで選べます（閲覧できるタブのみ。選択は記憶されます）。

## 画面の構成

- **立ち絵** — 発言したキャラクターの立ち絵がステージに並びます。発言中のキャラクターは明るく前面に、それ以外は少し暗くなります。最大 6 人まで同時に並びます。
- **メッセージウィンドウ** — 画面下に発言者名と本文が表示されます。文字は 1 文字ずつ表示（文字送り）されます。吹き出しのレイアウトでも、立ち絵がステージにいない発言（[立ち絵リセット](#立ち絵リセット)の後など）はここに出ます。吹き出しの尻尾は誰かを指すためのものなので、指す相手がいなければ吹き出しにしません。
- **背景** — 既定では現在のテーブルの背景画像がそのまま透けて見えます。GM は**ノベル専用の背景画像**に差し替えられます（後述）。
- **表示レイアウト** — 吹き出し / ADV（画面下の固定ウィンドウ）/ 全画面（NVL）から選べます。

## 進行のしかた

メッセージウィンドウや画面のクリック、`Enter` / `Space` / `→` / `↓`、マウスホイールで進みます。`←` / `↑` で戻れます。

- 文字送りの途中でクリックすると、**残りの本文を一気に表示**します。
- 最新の発言を表示しているときに新しい発言が届くと、自動でそれを表示します。
- 過去にさかのぼって読んでいる間は、新着が来ても表示位置は動きません。

読み進めるためのボタンは**画面の右上**にまとまっています。オートプレイと再生速度も同じ並びです。すぐ隣の角が **終了** で、場面の途中で押してしまう場所からは離してあります。

| ボタン     | 動作                     |
| ---------- | ------------------------ |
| ◀ / ▶      | 前 / 次のメッセージ      |
| n / m      | 現在位置 / 全件数        |
| 最新へ     | 最新の発言まで一気に移動 |
| ログ       | バックログ（後述）の開閉 |
| キーボード | ショートカットの一覧     |

### キーボード操作

右上の**キーボード**ボタン（`?` キー）で一覧を表示できます。

| キー                          | 動作                                      |
| ----------------------------- | ----------------------------------------- |
| `Enter` / `Space` / `→` / `↓` | 次へ進む / 全文表示                       |
| `←` / `↑`                     | 前に戻る                                  |
| `Ctrl`（押している間）        | スキップ（早送り）                        |
| `Home` / `End`                | 最古 / 最新へ                             |
| `A`                           | オートプレイ                              |
| `L`                           | ログの開閉                                |
| `S`                           | 立ち位置ガイド                            |
| `Esc`                         | 開いているウィンドウを閉じる / モード終了 |

## オートプレイ

右上の **▶ オートプレイ** を押すと、**いま表示している位置から**、文字送りと本文の長さに応じた間を取りながら最新まで自動で再生します。再生中は画面左上に **AUTO** バッジが表示されます。

- 最新を表示しているときは再生するものが無いためボタンは押せません。過去にさかのぼってから押してください。
- 隣の **↺ 最初から再生** を押すと、**最古のメッセージまでさかのぼってから**再生します。
- **再生速度スライダー**（×0.5〜×2）で待ち時間を調整できます。
- クリックやキー操作・ホイールなど、何か操作するとオートプレイは止まります。
- 最新まで再生し終えると自動で解除されます。

## 発言する

下段の入力欄に文字を入れて **送信** または `Enter` で発言します。発言は通常のチャットと同じく**選択中のチャットタブへ投稿**され、参加者全員に同期されます。

- **発言キャラクター**（上段）— 立ち絵を持つキャラクターから選びます。**名前を打てば絞り込めます**。プレイヤー本人は選択対象になりません（GM だけは[本人としても選べます](#gm-本人としての発言)）。GM ツールバーの [NPC バー](/manual/roles#gm-ツールバー)で NPC を選ぶと、その NPC が発言キャラクターになります。NPC バーと [所持キャラクター一覧](/manual/roles) でも名前で絞り込めます。
- **立ち絵パターン**（上段）— 立ち絵が複数あるキャラクターは、表示する絵柄を切り替えられます。
- **立ち位置スロット**（上段）— ステージ上の立ち位置（1〜12）を指定します。ボタンを押すと画面上に目安が出るので、直接クリックして置けます。
- **反転**（上段）— 立ち絵を左右反転します。状態はボタンに「反転中 / 通常」と表示されます。反転は発言ごとに記録されるので、過去をさかのぼっても当時の向きが再現されます。
- **ダイスボット**（上段）— チャットと共通のダイスボットを選びます。`2d6` などのダイスコマンドもそのまま使えます。
- **チャットパレット**（下段）— 選択中キャラクターのチャットパレットを開き、行をクリックして入力欄へ挿入できます。`{HP}` などのステータス参照は送信時に評価されます。
- **キャラクターシート参照**（下段）— 選択中キャラクターのシートをトグルで開閉します。
- **発言の流れ**（下段）— いま読んでいるタブの発言だけが並ぶ[別窓](/manual/chat#発言の流れを別窓で見る)を開きます。立ち絵の脇に置いておけます。

## 立ち位置

立ち位置は**何も指定しなければ、キャラクターシートの「チャット表示位置」に従います**。通常のチャットで立っている場所と同じところに立つので、ノベルモードのために置き直す必要はありません。

- 同じ場所に重なるときは、指定を尊重したまま**最小限だけ横にずらします**
- 誰も位置を触っていない部屋では、ステージ全体に散らして並べます
- スロットを選ぶと**そのキャラクターのノベルモード用の位置**になります。通常のチャットの立ち絵は動きません
- `link` ボタンで「チャット表示位置に従う」状態へ戻せます
- [バックログ](#バックログ)の編集からは、**その 1 行だけ**の立ち位置を決められます。行単位の指定が一番強く、次にキャラクター単位、最後にチャット表示位置の順で効きます

## 演出（エモート）

下段の **演出** ボタンから、次の発言に付ける演出を選べます。演出は発言そのものではなく**発言に添えて**記録されるので、**通常のチャットログには本文だけが並びます**。真面目な場面のログに「ぶるぶる」と書かれることはありません。

演出が付いているかどうかを一覧で確かめたいときは、[チャット設定](/manual/chat#chat-settings)の「ノベルモードの演出を表示」を入れてください。本文の隣に小さなラベルが出ます（既定はオフ）。演出は参加者全員に同期され、それぞれのノベルモードで同じように再生されます。

| 区分           | 選べる演出                                                             |
| -------------- | ---------------------------------------------------------------------- |
| 発言タイプ     | セリフ / 地の文 / ロケーション / 場面転換（GM のみ）                   |
| 吹き出しの形   | ふつう / もやもや / 叫び / ささやき                                    |
| 吹き出し演出   | なし / ゆれ / ぽよん / ドキドキ / ふわふわ                             |
| 立ち絵演出     | なし / ジャンプ / ぶるぶる / ズーム / うなずき / ゆらゆら / しょんぼり |
| 漫符           | ！ / ？ / 💢 / 💧 / ♥ / ♪ / …                                          |
| 立ち絵の出入り | この発言で退場する（後述）                                             |

選択は送信後も保持されます。**リセット**で一括解除できます。

### 発言タイプ

- **セリフ** — 立ち絵の上に吹き出しで表示される通常の発言。
- **地の文** — 画面中央に静かに表示されるナレーション。「一行は森の奥へ進んだ」のような描写に使います。
- **ロケーション** — 上下のラインに挟まれた大きなタイトル表示。場所の導入演出に使います。
- **場面転換**（GM 専用）— 区切りの演出。これより前の立ち絵・台詞が画面上から一掃されます（ログ自体は消えません）。GM が送ると全員の背景トランジションも同時に再生されます。

### 退場

演出パネルの**立ち絵の出入り**で「この発言で退場する」を選ぶと、その発言が**別れの台詞**になります。文字送りが終わったところで、**立ち絵と台詞がゆっくり消えていきます**。次の発言に進むと、そのキャラクターはもうステージにいません。再び発言すれば戻ります。

読み上げの途中で消えることはありません。フェードは本文がすべて出てから始まるので、長い台詞でも最後まで読めます。[演出の強さ](#設定)を「控えめ」にしている読み手には、フェードは起きません。

この指定も他の演出と同じく発言に添えて記録され、あとからログ編集で付け外しできます。

何も喋らせずにステージを片付けたいときは、GM の[立ち絵リセット](#立ち絵リセット)を使います。

## プレイヤーの雑談は読み飛ばす

ノベルモードは選んだタブを台本として読み進めますが、同じタブには卓の雑談も流れます。「ちょっと待って」「席を外します」が場面の台詞の合間に読み上げられると、それだけで芝居が切れます。

そこで、**キャラクター名義でない発言は本編に出しません**（既定）。表示設定パネルの **プレイヤーの雑談** で「そのまま読む」に戻せます。

- **GM の発言はそのまま出ます。** 進行の言葉は場面に向けられたものだからです
- **ダイスは振った行も結果もそのまま出ます**
- **入退室などの知らせもそのまま出ます**
- **ログには残ります。** [バックログ](#バックログ)を開けば読めますし、通常のチャットにも並びます
- 誰が言ったか記録のない発言は出します。古い部屋や他所から持ち込んだログが空にならないようにするためです

なお、ノベルモードの入力欄は原則としてキャラクターとしてしか発言できないので、ここで読み飛ばされるのは**通常のチャットウィンドウから本人名義で書かれたもの**だけです。

### GM 本人としての発言

GM が本人として書いた発言は、**画面上部**に出ます。位置はシステムメッセージと同じで、GM のアイコンと名前が添えられます。場面の中の台詞ではないので、立ち絵の吹き出しにはしません。

GM の発言キャラクター一覧には、先頭に**自分の名前**が並びます。これを選べば、ノベルモードを閉じてチャットウィンドウへ移らなくても、進行の言葉をそのまま送れます。プレイヤーの一覧には出ません。

## BGM / SE

下段の **SE再生** ボタンで、[ジュークボックス](/manual/jukebox)に登録した音声のパネルを開きます。上段が **BGM**、下段が **SE** です。

### BGM

- 曲名をクリックすると再生（切り替え）します。再生中の曲にはアイコンが付きます。
- 見出し右の **停止** で止められます。ジュークボックスと同期するため、参加者全員に反映されます。

### SE

**部屋に持ち込んだ音**（SE タグの音声）と、**プリセット**（Axe に同梱されている効果音）が別々の見出しで並びます。ドアや雷鳴といった音は、誰も用意しなくてもプリセットから鳴らせます。名前は[マップエフェクト](/manual/map-effects)で使われているものと同じです。

- そのまま押すと**すぐに再生**します。再生中はボタンが **■ 停止**に変わり、押すと止められます。
- 再生はジュークボックスと同期するため、参加者全員に鳴り、ジュークボックス側からも停止できます。
- クリップアイコンで**次の発言と同時に再生**するよう添付できます。
- 上部の検索欄で、部屋の音・プリセット・カットインをまとめて絞り込めます。プリセットは数が多いので、名前で引くのが早いです。

### カットイン

同じパネルの一番下に、部屋に登録した[カットイン](/manual/cut-in)が並びます。押すと**参加者全員の画面で再生**されます。場面の切り替えに一枚挟みたいときに、ノベルモードを閉じずに出せます。

## バックログ

右上の **ログ** ボタンで、これまでの発言を一覧できるパネルを開きます。

- アバター・発言者名・時刻・演出バッジ付きで一覧表示されます。
- 上部の検索欄で**本文・発言者名で絞り込み**できます。**自分のみ** / **演出付き**でも絞り込めます。
- **現在地へ**で、いま表示している発言の行までスクロールします。
- 発言が多い部屋では直近 200 件だけを描画し、**さらに読み込む**で過去へ伸ばせます。
- 行をクリックすると、その場面へジャンプします。ログは開いたままなので、続けて別の行へ移れます。
- 自分の発言は**編集**でき、本文だけでなく**演出・立ち位置スロット**も後から付け直せます。

ログは他のパネルと同じウィンドウです。**タイトルバーをドラッグして動かし、四隅と四辺を引っ張って好きな大きさにできます**。最小化と透明度もそのまま使えます。画面が狭くて立ち絵の頭に被るときは、脇へ寄せるか小さくしてください。演出パネルや表示設定と同時に開いたままにもできます。

## 設定

見え方の設定は、**表示設定** ボタン（つまみのアイコン）にまとめてあります（設定は記憶されます）。演出とは別のウィンドウなので、場面ごとに触る演出と、一度決めたら動かさない設定が混ざりません。

- **表示レイアウト** — 吹き出し / ADV / 全画面
- **文字の読みやすさ** — なし / 弱 / 中 / 強（背景を暗く・ぼかして本文を読みやすくします）
- **文字送り** — なし / ゆっくり / ふつう / はやい
- **立ち絵の登場演出** — なし / フェード / スライド / バウンド
- **文字サイズ** — 小 / 中 / 大
- **演出の強さ** — ふつう / 控えめ（揺れなどの繰り返しアニメーションを止めます。画面全体の[エフェクト表示](/manual/theme#エフェクトの表示)を止めているあいだも同じように止まります）
- **プレイヤーの雑談** — ノベルに出さない / そのまま読む（[前述](#プレイヤーの雑談は読み飛ばす)）

## 進行（GM）

GM だけが使う道具は、下段の **進行** ボタン（フィルムのアイコン）にまとめてあります。**上映モード**・**立ち絵リセット**・**背景**の 3 つで、いずれも参加者全員に届くものです。自分の画面だけの[設定](#設定)とは別のウィンドウにしてあります。

### 背景

GM は進行パネルの **背景を選ぶ** から、ノベルモード専用の背景画像を指定できます。

- 指定した背景は**参加者全員に同期**されます。**解除**するとテーブルの背景に戻ります。
- 切り替え時の演出（フェード / ワイプ）を選べます。
- 背景の上に重なる**読みやすさ**レイヤーは参加者ごとの設定です。

### 立ち絵リセット

シーンから抜けたキャラクターの立ち絵は、誰かが喋るまでステージに残ります。直前まで騒いでいたキャラが、そのままシリアスな場面の背後に立ち続けることになります。

GM 用の **進行** パネルにある **立ち絵リセット** を押すと、**いま表示しているチャットタブの立ち絵がすべて下がります**。発言は要りません。

- **ログは消えません。** 消えるのはステージの立ち絵だけです
- リセットしたことは**チャットログに 1 行の知らせ**として残ります。ただし**ノベルモードの本編には出ません**。読み進める途中で「立ち絵をリセットしました」を送らされることはなく、バックログにも並びません
- **さかのぼって過去を読むと、当時の立ち絵がそのまま出ます。** リセットは「ここから先は白紙」という線であって、過去を書き換えるものではありません
- 効くのは**そのタブだけ**です。別のタブのステージはそのまま残ります

場面転換との使い分けは、演出を伴うかどうかです。**場面転換**は区切りの演出として見せるもので、発言と背景トランジションを伴います。**立ち絵リセット**は静かな片付けで、画面には何も起きません。

### 上映モード

GM が進行パネルの **上映モード** を押すと、**GM がめくった位置に参加者全員の画面が追従**します。リプレイの読み合わせや、場面をそろえて見せたいときに使います。

- 参加者の画面右上に「上映に追従中」と表示されます。
- 参加者が **自分で読む** を押す、または自分で前後に動かすと追従を外れ、「追従に戻る」で復帰できます。
- GM がオートプレイを使えば、そのまま全員に配信されます。
- もう一度ボタンを押すと上映モードを終了し、全員の追従状態が戻ります。

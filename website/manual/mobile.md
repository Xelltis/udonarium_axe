# スマートフォンで使う

このページは、スマートフォンのような狭い画面でAxeを使うときの、画面の構成と操作のしかたを説明します。
画面の幅が狭い端末では、Axeが自動で専用の画面に切り替わります。
FABメニューやツールバーは出ず、テーブルとチャットを中心にした構成になります。
GM・PL・見学の誰でも使えます。

## 切り替わる条件

次のどちらかのとき、スマートフォン向けの画面になります。

- 画面の幅が768px未満のとき
- 指で操作する端末で、画面の高さが500px以下のとき

スマートフォンを横向きにしても、切り替わったままです。
タブレットのように大きい画面では、パソコン版の画面になります。
自分でどちらかに決めることもできます（→ [パソコン版の画面を使いたいとき](#パソコン版の画面を使いたいとき)）。

## 画面の構成

画面は、上から次の順に並びます。

| 場所             | 内容                                                                                                                        |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------- |
| テーブル         | 指でドラッグして視点を動かし、2本の指で広げて拡大、つまんで縮小、2本の指で回して回転します                                  |
| 上下の境目       | つまみを上下にドラッグすると、テーブルとチャットの広さが変わります。比率は次に開いたときも同じです                          |
| チャット         | いつも出ています。下に入力欄があります                                                                                      |
| **キャラクター** | [所有キャラクター一覧](/manual/pl-tools#所有キャラクター一覧)。HPやMPを増減でき、シートやチャットパレットもここから開けます |
| **メニュー**     | 下の[メニューから開けるもの](#メニューから開けるもの)が、画面の下から出てくるシートに並びます                               |

自分のキャラクターがまだないときは、**キャラクター**のタブに、オーナーのいないテーブル上のキャラクターが並びます。
**自分のものにする**を押すと、そのキャラクターを受け取れます。

見学のときは、**キャラクター**のタブが出ません。
**メニュー**にも、コマを作る・キャラ取り込み・操作中パレット・手札を開閉・読込・エフェクトは出ません。

## 操作のちがい

パソコンでのマウスの操作は、スマートフォンでは次のようになります。

| パソコン                                 | スマートフォン                                                                                                             |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| コマを右クリックしてメニューを開く       | コマを長押しします。指を動かさずに、0.4秒ほど押してください                                                                |
| 何もない所をドラッグして、範囲で選ぶ     | 何もない所を長押ししてから、指を滑らせます。指を止めたままなら、テーブルのメニューが開きます                               |
| 選んでいるコマに、範囲で選んだコマを足す | すでに選んでいるコマがあるときの範囲選択は、選択の追加と解除の切り替えになります                                           |
| 選択を外す                               | 選んでいるあいだはチャットの上に「N 個選択中 ✕」が出るので、それを押します                                                 |
| マウスを乗せてコマの詳細を見る           | コマをタップします。もう一度タップすると閉じます                                                                           |
| 手札のカードにマウスを乗せて拡大する     | カードをタップします。**表向きで場に出す**と**裏向きで場に出す**はカードの下に出ます。カードをもう一度タップすると畳めます |
| マウスを乗せたときに出る操作ボタン       | いつも出ています。キャラクターコマを縦に傾けるハンドルは、画像に重ならないよう、頭と足元ではなく画像の左右に出ます         |
| パネルを開く                             | パネルは画面全体で開きます。閉じると元の画面に戻ります。パネルを別のウィンドウに出すボタンは出ません                       |

文字を入力しているあいだは、画面がキーボードの上に収まるように縮みます。

## キャラクターシート

スマートフォンで開いたキャラクターシートは、狭い画面に合わせた並びになります。
横向きに持っても同じです。
パソコンでも、シートのパネルを細くすると、この並びに切り替わります。

### 読むとき

いちばん上には、コマの立ち絵を小さくした画像と名前が出ます。
画像を押すと、立ち絵の一覧が下から開きます。
立ち絵の追加や名前、チャットでの表示位置は、そこで変えます。
右上の「⋮」のボタンに入っているのは、**立ち絵**・**コピーを作る**・**保存**・**すべて畳む**・**すべて開く**です。
見学では画像を押せず、「⋮」には**保存**と**すべて畳む**・**すべて開く**だけが出ます。

その下には、セクションの名前が横に並び、押すとそのセクションへ飛びます。
この並びは読み進めても上端に残り、いま読んでいるセクションの名前に色が付きます。

セクションは、見出しを押すと畳めます。
もう一度押せば開きます。
畳んだ状態はこの端末に残るので、シートを開き直しても、別のキャラクターの同じ名前のセクションも、畳まれたままです。

数値とリソースの横には「−」と「＋」のボタンが付き、1ずつ増減できます。
リソースなら「− 180 / 180 ＋」の形で、現在値と最大値をはさむ並びです。
続けて押した分は、押し終えてから1回の変更として送られるので、コマの上の演出も1回分で済みます。
下限や上限まで来たボタンは、押せなくなります。

表になったセクションは、指で横に送れます。
行の見出しは左に残ります。

### 項目を組み替える

1. セクションの鉛筆を押して、編集に入ります。各行には、取っ手と名前、値、「⋯」だけが並びます。
2. 名前か「⋯」を押すと、その行の設定が下から開きます。
3. 名前と種別と[詳細設定](/manual/data-element#種別の変えかた)を変えます。種別はアイコンの一覧から選びます。

行の設定には、並び順の上下と端への移動、別のグループへの移動、ポップアップ表示、参照名のコピー、下への行の追加、複製、削除もあります。

グループとセクションの見出しにも「⋯」があります。
こちらでは、名前とアイコン、通常表示とテーブル表示の切り替え、項目やグループの追加、テンプレートの保存と呼び出しを扱います。

項目を足すときは、各グループの末尾にある**項目を追加**を押します。
種別を選ぶとその場で項目ができ、名前を打ち直せる状態で設定が開きます。

並び順は、行の左端の取っ手を指で押さえたまま、上下に動かしても変えられます。
置かれる場所に線が出ます。
指を画面の上端や下端に寄せると、シートがそちらへ送られます。
同じグループの中で動かすときに使い、別のグループへは行の設定から移します。

行やセクションを消すと、画面の下に通知が数秒出ます。
通知の**元に戻す**を押すと、消したものが元の場所に戻ります。
パソコンで消したときも同じです。

タブレットのように画面が広くても、指で操作する端末では、編集はこの「⋯」から開く設定で行います。
マウスで操作するパソコンでは、これまでどおり、行の横のボタンで編集します。

## リモコン

コマの[リモコン](/manual/character#コンテキストメニュー)は、スマートフォンでは3段に分かれます。

1. 上に**発言元**と発言先のタブ
2. **対象**・**バフ**・**リソース**の切り替え
3. その下に「対象2体：キャラA、キャラB」のように、次の操作が誰に効くかがいつも出ます

「対象」でコマを選んでから、「バフ」か「リソース」に切り替えて実行する、という順番になります。

## ノベルモード

[ノベルモード](/manual/visual-novel)は、画面全体を使います。
上下の分割はなくなり、演出を中心にした画面になります。

操作パネルには、メッセージ欄だけが出ています。
ダイスボットの選択・立ち絵の切り替え・ログ・パレットは、左のつまみ（⚙）から開きます。

## ホーム画面に追加する

1. ブラウザの共有メニューを開きます。
2. 「ホーム画面に追加」を選びます。

ホーム画面のアイコンから開くと、アプリのように単独のウィンドウで動きます。
アドレスバーが消えるぶん、テーブルを広く使えます。

## パソコン版の画面を使いたいとき

**メニュー**のいちばん下にある**パソコン版の画面を使う**を押すと、パソコンと同じ画面に切り替わります。
タブレットや大きな端末で、テーブルを広く使いたいときに向いています。

戻すときは、FABメニューの**表示**の小窓にある、スマートフォンのアイコン（**スマホ版の画面に戻す**）を押してください。
どちらを選んだかは、次に開いたときも同じです。

## うまくいかないとき

| 見えるもの                                     | 原因と直しかた                                                                                                 |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| スマートフォンなのに、パソコンと同じ画面が出る | **パソコン版の画面を使う**を選んでいます。FABメニューの**表示**から**スマホ版の画面に戻す**を押します          |
| 長押ししても、コマのメニューが開かない         | 押しているあいだに指が動くと、長押しになりません。指を止めたまま、0.4秒ほど押します                            |
| 範囲で選ぶと、選んでいたコマが外れる           | 選んでいるコマがあるときの範囲選択は、追加と解除の切り替えです。「N 個選択中 ✕」で選択を外してから選び直します |
| **キャラクター**のタブがない                   | 見学のときは出ません（→ [ロール](/manual/roles)）                                                              |
| 文字を打つと、テーブルが小さくなる             | キーボードの上に画面を収めるためです。入力を終えると戻ります                                                   |

# ダンジョンドリィマスターモード

卓の上のコマの目線で、ダンジョンの中を歩いて見るモードです。地形の壁と扉と床がそのまま通路や部屋になり、キーを1回押すごとにコマが1マス進みます。歩いた分は卓の上のコマも動くので、ほかの参加者の画面でもコマが進みます。

<Shot src="dungeondry-master" alt="石の通路の先にゴブリンが立っている一人称の画面。左下に移動のボタン、右下に方位磁針とミニマップがある" caption="生成したダンジョンを、コマの目線で歩きます" />

入っているあいだは、卓の代わりにコマから見た景色が画面いっぱいに出ます。チャットやパネル、ホットバーはそのまま使えます。どのコマで見ているかはこのブラウザに覚えられるので、ページを読み直してもモードは続きます。

## 入る

見られるのは、卓の床に立っているキャラクターコマです。マス目のある卓では、コマがマスの上にいることも条件です。壁や盤面に貼ったコマからは見られません。

入り口は4つあります。

| 入り口                                         | 使える人 | 入るコマ                                                       |
| ---------------------------------------------- | -------- | -------------------------------------------------------------- |
| FABメニューの**テーブル関連**                  | GM・PL   | 1体ならそのコマ。2体以上なら名前の一覧から選ぶ                 |
| [PLツールバー](/manual/pl-tools)の目のアイコン | PL       | FABメニューと同じ                                              |
| コマの右クリックの「このコマの視点で見る」     | GM・PL   | そのコマ                                                       |
| [ホットバー](/manual/hotbar)の枠               | GM・PL   | ホットバーの操作対象のキャラクター。もう一度押すと卓に戻ります |

FABメニューとPLツールバーの候補に出るのは、自分がオーナーのコマと、オーナーのいないコマです。GMの候補も同じなので、PLのコマから見るときは右クリックを使います。候補が1体もいないときは「ダンジョンドリィマスターモード（見られるコマがいません）」と出て、押せません。

見学のロールでは自分では入れません。GMが[全員の視点をそろえた](#全員の視点をそろえる-gm)ときだけ、その景色が出ます。

## 卓に戻る

画面の下の**卓に戻る**かEscキーで卓に戻ります。入るときに使ったFABメニューの項目やツールバーのボタン、ホットバーの枠をもう一度押しても戻ります。

エフェクトの対象を選んでいる最中のEscは、選ぶのをやめるだけです。モードからは出ません。[見回して](#見回す)正面以外を向いているときのEscも、正面に戻すだけです。

## 歩く・向きを変える

キーボードでは次のように動きます。画面の左下にも同じ働きのボタンが並ぶので、タッチ操作でも歩けます。

| したいこと   | 四角のマス・グリッドなし | ヘクス                       |
| ------------ | ------------------------ | ---------------------------- |
| 前へ・後ろへ | W・↑ / S・↓              | W・↑ / S・↓                  |
| 横へ         | A・Dで左右へ横歩き       | A・Dで斜め前、Z・Cで斜め後ろ |
| 向きを変える | Q・← / E・→              | Q・← / E・→                  |

向きは四角のマスで90°ずつ、ヘクスで60°ずつ、グリッドなしの卓で45°ずつ変わります。グリッドなしの卓の1歩は、マス1つ分の長さです。

チャットの入力欄に文字を打っているあいだや、パネルのモーダルが開いているあいだは、キーを押してもコマは動きません。

### 見回す

景色をマウスでドラッグすると、ドラッグした方へ見回せます。タッチ操作では指1本でなぞります。右へ動かせば右を向き、上へ動かせば見上げます。左右はぐるりと後ろまで、上下はほぼ真上・真下まで向けます。巨大なコマの真横に立って見上げる、といった見方ができます。

指やボタンを離しても、向いた方はそのまま残ります。巨大なコマを見上げたまま、手をチャットに移せます。コマが動いたり向きを変えたりすると、コマの正面・水平へゆっくり戻ります。その場で戻すときはEscキーを押します。卓の上のコマの向きは変わらず、見回しはこの画面の中だけのものです。GMが全員の視点をそろえているあいだも、自分の画面で見回せます。

ドラッグしている最中でも、キーで歩いたり向きを変えたりできます。このあいだは向きが手の動きに従ったままで、正面には戻りません。少し動かしただけの押し方はクリックとして扱うので、コマをクリックしてターゲットにする操作はこれまでどおりです。

### 歩けるとき

歩けるのは、GMならどのコマでも、PLなら自分がオーナーのコマかオーナーのいないコマです。ほかの人のコマから見ているとき、見学のとき、コマを「固定する」で固定してあるときは、見るだけになります。移動の計画を組んでいる最中と、[セッションログ](/manual/replay)を開いているあいだも歩けません。

マス目のある卓の1歩には、卓の上でコマを動かすときと同じ決まりが掛かります。地形の壁では止まり、1段までの段差は登れます。マップエディターで塗った立入禁止には入れず、ほかのコマを通り抜けられるかどうかは[部屋設定](/manual/room-settings)に従います。進めなかったときは失敗の音が鳴ります。

グリッドなしの卓では、移動を遮る地形と卓の端で止まります。見えているほかのコマには半マスより近づけません。部屋設定で同じマスに入れるようにしてあれば、そのまま重なれます。立入禁止の塗りはグリッドなしの卓では見ません。

### 歩くと卓で起きること

1歩ごとに卓の上のコマが動き、部屋の全員の画面に反映されます。段差は跳ねて越え、途中に[スイッチ](/manual/switch)の仕掛けがあれば踏んだときに起きます。向きを変えると、コマの向きも同じだけ回ります。足音や扉の音は部屋の全員に聞こえます。

## 扉と明かり

Spaceキーか「扉を開け閉めする」で、目の前のマスにある扉を開け閉めします。目の前に扉がなければ、足元のマスの扉が対象です。

Fキーか「明かりを灯す」で、コマ自身の明かりを点けたり消したりします。明かりの半径を決めていないコマには、光源の「松明」の設定が入ります。扉も明かりも、そのコマで歩ける人だけが使えます。

## 見えるもの

壁・扉・床は、卓に置いた[地形](/manual/terrain)から作られます。面に画像があればその画像で描き、画像のない地形は半透明のガラスのように描きます。閉じた扉は壁と同じように視線を遮り、開いた扉は描きません。テーブル設定の外周の壁も描きます。

描くのは目の前12マスまでです。6マスより先は、遠いほどぼかして暗くします。

壁と扉に囲まれていて、卓の端からつながっていない場所には天井を張ります。天井の高さは、卓でいちばん高い壁に合わせます。壁より背の高いコマが部屋に立っているときは、その部屋の天井だけをコマの頭より半マス上まで上げます。このとき壁の上と天井のあいだにはすき間ができます。囲まれていない場所の上には空が見えます。空には[テーブル設定](/manual/table-setting)のテーブル画像と奥のレイヤーを描き、奥のレイヤーは向きを変えると横へ流れます。どちらもない卓は夜空になり、暗闇がオンの卓では空は黒くなります。

### 暗闇と戦場の霧

[暗闇・視界・光源](/manual/vision-lighting)と戦場の霧がどちらもオフなら、壁で遮られない範囲がすべて見えます。どちらかがオンのとき、PLに見えるのは卓の上で自分に見えている範囲だけです。床や壁は、その場所の明るさに合わせて暗く描かれます。霧の戻り方がイージーかノーマルなら、前に通って今は見えていない場所も、薄暗くして描きます。ハードでは描きません。

GMには、明るさに関係なく、壁で遮られない範囲がすべて見えます。

### ほかのコマと卓の上の物

ほかのコマは、その席から見えているものだけが立ち絵のように立ちます。大きさは卓と同じで、幅はコマのサイズのマス数、高さは画像の縦横比で決まります。コマ画像の高さを指定したコマは、その高さで立ちます。大きなコマは、足元のマスのどこかが見えていれば描かれます。近くのコマほど大きく見え、足元が画面の下に切れるほど近いときは少し持ち上げて描きます。絵の上には卓と同じようにバフ、リソースバー、名前が並びます。名前を隠したコマは、GM以外には名前が出ません。

コマのほかに、床の[射程範囲](/manual/range)、カード、山札、ダイス、コイン、共有メモ、マップマスク、見えているスイッチ、ホワイトボードも描かれます。伏せたダイスの目や読めないメモの中身は、卓と同じく伏せたままです。外周の壁に貼った物は、その壁を表示しているときだけ描かれます。天候や空中の霧、[マップ演出](/manual/map-effects)のエフェクト、画面の揺れも出ます。

### 方位磁針とミニマップ

右下の方位磁針は、向きに合わせて回ります。赤い「N」が北です。スマートフォンでは右上に出ます。

その下のミニマップは、まわり5マスを北を上にして描きます。黄色の矢印が自分の位置と向きです。床・壁・扉と、立入禁止の場所（赤）を色で描き分けます。ほかのコマは出ません。暗闇か霧がオンなら、PLのミニマップには見えている場所と通った場所だけが出ます。

## ターゲットとエフェクト

コマをクリックすると、そのコマのターゲットを付けたり外したりします。Tキーは、正面から20°以内にいて視線の通るコマのうち、いちばん正面に近いコマを切り替えます。Shift+Tか「ターゲットを外す」で全部外れます。狙ったコマは、足元に赤い輪が付きます。

[エフェクト集](/manual/map-effects)でエフェクトをクリックすると、このモードの景色の中で対象を選べます。コマをクリックした順に番号が付き、上限まで選ぶとそのまま発動します。少ない数で撃つときはEnterキーか「対象に発動する」、やめるときはEscキーか「中止」を押します。エフェクトを撃つのは、いま見ているコマです。

## 全員の視点をそろえる（GM）

GMは、部屋の全員を同じコマの視点に入れられます。GMツールバーの目のアイコン**全員の視点を決める**を押し、一覧からコマを選びます。一覧には卓の上の見られるコマがオーナーに関係なく並び、PLのコマには「PL」と付きます。コマの右クリックの**全員をこのコマの視点にする**でも同じことができます。

そろえているあいだ、GM以外の全員はそのコマの視点になります。見学の人も入ります。画面には「GM の共有視点」と出て、卓に戻るボタンは消え、Escキーでも出られません。卓の上では、そのコマに琥珀色の輪が付きます。歩けるのは、そのコマのオーナーとGMです。オーナーのいないコマはGMだけが歩かせられます。

別のコマに替えるときは、同じボタン（**共有中の視点を変える**）から選び直します。やめるときは、一覧の先頭の**全員の共有視点を解除**か、コマの右クリックの**全員の共有視点を解除する**を押します。

そろえる効果があるのは、GMが部屋にいるあいだだけです。そろえたコマが卓から消えると、PLは自分で選んでいた視点か卓に戻ります。コマが卓に戻れば、全員の視点もそのコマにそろい直します。コマが消えているあいだ、GMツールバーのボタンは「共有中のコマが卓にいません（押すと解除）」に変わり、押すとそのまま解除できます。そろえた状態は、部屋を保存しても書き込まれません。

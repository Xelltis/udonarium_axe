# マップ演出（エフェクト）

このページはコマの上に斬撃や爆炎などの演出（エフェクト）を出す「マップ演出」と、テーブルそのものを毒沼や濃霧にする環境エフェクトを説明します。
FABメニューの**メディア**の**エフェクト**から、エフェクト集を開きます。
GMとPLが使えます。見学のときはメニューに**エフェクト**が出ません。見学の人がチャットに`《エフェクト名》`を書いても、エフェクトは出ません。

<Shot src="map-effects" alt="エフェクト集。左に系統の索引があり、右に物理・打撃・射撃などの系統ごとにエフェクトが並んでいる" caption="左の索引で系統を選ぶと、その系統まで一覧が送られます" />

再生は全員の画面で同時に走り、SEも一緒に鳴ります。

## エフェクト集を探す

エフェクト集は最初540×720の大きさで開きます。枠の端をドラッグして変えた大きさはこのブラウザーに保存され、次に開くときもその大きさで開きます。340×420より小さくはできません。

一覧の左には系統の索引があり、系統ごとの色と名前、いま一覧に出ている件数が並びます。系統を押すと、一覧がその系統の見出しまでスクロールします。押しても一覧からエフェクトは消えません。

パネル上部では次のように絞り込めます。

- **検索** — 名前・系統（炎・射撃など）・種類（ブレス・爆発など）で探せます。ひらがなとカタカナは区別せず、同梱のエフェクトは漢字の名前もひらがなの読みで探せます。一致した文字には色が付き、検索欄に件数が出ます
- **等級** — すべて / 初級 / 中級 / 上級
- **対象** — すべて / 単体 / 複数 / 範囲。範囲を選ぶと、範囲攻撃のエフェクトだけが残ります
- 絞り込むと索引の件数も変わり、0件の系統は薄く表示されます
- 1件も見つからないときは、「絞り込みを解除」で元に戻せます
- 絞り込みしていないときは、**最近使った**エフェクトが先頭に並びます
- 系統の見出しをクリックすると折りたためます。**メニュー**の「系統をすべて畳む」と「系統をすべて開く」で、まとめて切り替えられます

各行には、種類の印、名前、等級（★1〜3）、届く範囲、種類の名前が出ます。届く範囲は「単体」「3体まで」「範囲3マス」「自分」のように出て、範囲攻撃のものは色を変えて太字にしています。

スマホでは、等級と対象が2つの選択欄になります。行の右端の「⋮」から、右クリックと同じメニューを開けます。

### 一覧のプレビュー

行にマウスを載せて少し待つと、一覧の上にあるプレビューの枠でそのエフェクトが再生されます。キーボードで行にフォーカスを移したときも同じです。
プレビューは小さな盤の上で、代役のコマを相手に繰り返し再生します。音は鳴りません。

エフェクトを構えているあいだは、構えたエフェクトを再生します。マウスのない端末で再生するのは、構えたエフェクトだけです。
FABメニューの**表示**で**アニメーション**を止めているときは、エフェクトの途中の1コマを止めたまま映します。

### キーボードで選ぶ

Tabキーで一覧に入ると、エフェクトの行の1つにフォーカスが移ります。行は2列に並び、一覧の中は次のキーで動きます。

| キー          | 動き                                                             |
| ------------- | ---------------------------------------------------------------- |
| ← →           | 左の列、右の列、次の段の順に前後の行へ移る。系統の境目も越えます |
| ↑ ↓           | 上下の段にある行のうち、いちばん近いものへ移る                   |
| Home / End    | 最初の行、最後の行へ移る                                         |
| Space / Enter | フォーカスのある行のエフェクトを構える                           |

構えたエフェクトの行にフォーカスがあるときは、Enterで発動し、Spaceで中止します。

系統の索引にもTabキーで入れます。↑ ↓ とHome / Endで系統を移り、EnterかSpaceでその系統まで一覧を送ります。

## エフェクトを構えて発動する

エフェクト集の行をクリックしても、その時点では発動しません。選んだエフェクトは一覧の上の欄に入り、発動するか中止するまでそこに残ります。このページではこの状態を「構え」と呼びます。

1. 撃つコマをクリックして選択する
2. エフェクト集でエフェクトをクリックして構える
3. 盤面のコマをクリックして対象にする
4. 「対象に発動する」を押すか、Enterを押して発動する

発動すると構えは解け、パネルのいちばん下の行に、発動した相手の名前が出ます。

### 構えの欄

絞り込みのボタンと一覧のあいだにある欄です。左にプレビューの枠、右に3つの行があり、その下に「対象に発動する」と「中止」のボタンが並びます。

| 行         | 出るもの                                                                   |
| ---------- | -------------------------------------------------------------------------- |
| いちばん上 | 構えたエフェクトの名前と、選んだ数と上限（`2/6`のような表示）              |
| 撃ち手     | 撃つコマの名前と、撃ち手を変えるボタン、撃ち手をなしにするボタン           |
| 対象       | 対象にしたコマの名前。行に収まらないときは、行を横にスクロールして読みます |

構える前は、いちばん上の行に「エフェクトを選んでください」と出ます。撃ち手の行は「撃ち手（予定）」になり、いま選択しているコマの名前が入ります。対象の行には、すでにターゲット指定してあるコマが並びます。

2つのボタンは構える前から置いてあります。「対象に発動する」は対象が1体以上あるあいだ、「中止」は構えているあいだだけ押せます。
欄の大きさは構えても対象を増やしても変わらないので、下の一覧は動きません。

### 対象を選ぶ

選んだコマには、エフェクトの色の輪と順番の番号が付き、撃ち手からは線が伸びます。この番号順に演出が走ります。
**ずらし**を入れたエフェクトは1体ずつずれて発動します。

- 対象にしたコマをもう一度クリックすると、対象から外れます
- 上限まで選んでも発動はしません。上限に達した状態で別のコマを選ぶと、いちばん古い対象と入れ替わります。単体エフェクトは選び直しになります
- 構える前に[リモートコントローラ](/manual/character)でターゲット指定していたコマは、上限の数まで対象に引き継がれます
- 選択しているコマ自身が引き継がれる対象に入っているときは、そのコマを対象にして、撃ち手なしで始まります

対象が「自分」のエフェクトも、クリックした時点では発動せず、同じように構えます。撃つコマを選択していて、ターゲット指定したコマがないときは、撃つコマが対象に入った状態で始まるので、そのまま発動できます。

### 撃ち手を変える

撃ち手はエフェクトを構えた時点で選択していたコマです。対象を選んでいっても変わりません。コマを選択せずに構えたときは「なし」になります。
盤面では、撃ち手の足元に白い二重線のひし形が出ます。対象の輪とは色も形も違うので、見分けられます。

撃ち手の行の右端に、「変える」と「なしにする」のボタンがあります。パネルの幅が狭いときは、アイコンだけになります。

- 「変える」（指のアイコン）を押すと、行に「卓のコマを押してください」と出ます。次に押したコマが撃ち手になり、対象には入りません。対象にしてあったコマを押したときは、そのコマが対象から外れます。コマを押す前にもう一度ボタンを押すと、撃ち手は元のままです
- 「なしにする」（禁止マークのアイコン）を押すと、撃ち手なしで発動します

撃ち手のコマは、押しても対象になりません。範囲攻撃の範囲に入っていても巻き込まれません。撃ち手のコマを対象にしたいときは、先に撃ち手をなしにするか、別のコマに変えます。対象が「自分」のエフェクトだけは、撃ち手のコマが対象になります。

### 範囲攻撃

**範囲**を持つエフェクト（業火・地隆・絶対零度・竜巻・特異点など）では、コマを1回クリックするだけで、
そのコマを中心に範囲内のコマが近い順に、上限の数までまとめて対象になります。

クリックする前に、範囲と巻き込む相手を確かめられます。構えているあいだにコマへマウスを載せると、そのコマを中心にした範囲が点線の円で、巻き込むコマが破線の輪で出ます。マウスのない端末では、この表示は出ません。

クリックすると、範囲が破線の円で残り、巻き込んだコマに輪と番号が付きます。この時点ではまだ撃ちません。
別のコマをクリックすると中心が移ります。

範囲はヘクスのテーブルでも円です。
範囲の広さは編集画面の「範囲」（マス数）で変えられます。0にすると1体ずつ選ぶ普通の複数対象になります。

### 発動と中止

発動は次のどれかで行います。どれも、対象が1体以上あるときに使えます。

- パネルの「対象に発動する」
- Enterキー。文字を入力する欄にカーソルがあるあいだは効きません
- 画面の下の帯にある「発動」

中止するときは、パネルか帯の「中止」を押すか、Escキーを押します。構えたエフェクトの行をもう一度クリックしても中止になります。
中止すると、ターゲット指定は構える前の状態に戻ります。

構えているあいだは、対象が0体でも、画面の下に帯が出たままになります。帯には選んだ数と上限、「発動」と「中止」のボタン、× のボタンが並びます。
エフェクト集のパネルが盤面に重なっているときや、タッチで操作しているときは、パネルを動かさずにこの帯から発動と中止ができます。
× のボタンは構えを中止したうえでターゲットをすべて外します。Shift+Tキーでも同じことができます。

発動したあとも、対象にしたコマのターゲット指定は残ります。続けてチャットで`t:HP-10`と打てば、
同じ相手にそのままダメージを与えられます（[チャットの特殊記法](/manual/chat-syntax)）。
対象が「自分」のエフェクトでは、発動するとターゲット指定が構える前の状態に戻ります。

### 斬撃と打撃

**斬撃**は、撃ち手の立つ側から刃が大きな三日月を描いて対象を横切ります。横切った瞬間に光の線が対象を貫いて火花が散り、そのあと斬り口が開いて光を噴き、床に斬り跡が残ります。
**連斬**は向きを変えて5回斬り、残った三日月が花のように対象を囲みます。最後の一太刀から少しして、すべての斬り口が一度に開きます。
**一閃**は、あたりが暗くなったあと、撃ち手の後ろから対象の先まで一本の線が一瞬で走ります。線は細い光の筋になって残り、刃が鞘に収まると大きく裂けて光があふれます。
**大斬撃**は長い光の刃を横に引いて溜めてから水平に振り抜きます。斬撃は三日月の衝撃になって対象の先へ飛び、床を削ります。対象が何体いても、1本の刃が順に斬り抜けます。
**兜割り**は対象の頭上で光の刃を溜めて真上から振り下ろします。地面が刃の向きに裂けて光り、裂け目から岩が突き出します。

斬られたコマは刃が抜けた向きへ流されます。真上から振り下ろす**兜割り**では、上から押し込まれます。

**飛ぶ斬撃**は、刃から放った大きな三日月の衝撃が床に光る線を刻みながら飛び、対象を斬り抜けます。対象には交差した斬り跡が残ります。
**飛ぶ連斬**は角度を変えた三日月を続けて放ちます。最後の1つがいちばん大きくなります。

**打撃**は等級で殴り方が変わります。
**殴打**は拳の形をした力をまっすぐ打ち込み、当たった点から棘の星と圧力の輪が弾けます。
**強打**は頭上から重く振り下ろし、当たったコマは床に跡を引いて滑ります。
**崩拳**は拳に力を溜めてから打ち込みます。力は対象の背中から抜け、足元の床が網の目に割れて、割れた岩が宙に浮いてから落ちます。

### 射撃

**矢**は低い弧を描いて飛び、当たった物に刺さって震えながら残ります。**矢の連射**の矢は当たった所に並んで立ちます。
**貫通の矢**は引き絞って鏃に光を集めてから放ちます。矢は光に包まれてまっすぐ飛び、対象を貫いて先の地面に刺さり、通り道が白い線になって残ります。
**アローレイン**は、撃ち手が空へ矢を次々に撃ち上げ、対象とそのまわりへ撃ち手の側から斜めに降らせます。降るあいだは地面が暗くなり、矢の影が刺さる位置へ縮まっていきます。刺さった矢の半分は立ったまま残り、終わると1本ずつ消えます。

**銃弾**は、銃口が光って煙と薬莢を吐き、弾は目で追えない筋になって飛びます。当たると火花と破片が散って煙が上がり、後ろの地面がえぐれます。
**徹甲弾**は対象を貫き、後ろの地面に土を噴き上げます。
**サブマシンガン**は1発ごとに少しずつ向きのずれた弾を連射し、外れた弾は足元の土を跳ね上げます。
**重機関銃**は、着弾が地面を這って対象へ近づき、3発に1発は色の付いた曳光弾です。
**狙撃**は、撃つ前に赤い照準の線と点が対象に当たり、照準器が光ってから撃ちます。弾の通り道は一瞬で白く光って対象を貫き、そのあと白い航跡がしばらく漂います。

**光線銃**は、銃口に光の輪が開き、白い芯を色で包んだ長い光弾を撃ちます。当たると光が飛び散り、床に焦げ跡が残ります。**光線銃・連射**は1発ごとに少しずつずれて連射します。

**マイクロミサイル**は、小さなミサイルの群れがそれぞれ曲がりくねって飛び、太い煙の筋が編み込むように残ります。
**誘導弾**は大きな1発です。揺れながらゆっくり近づき、床の赤い輪で狙いを絞ってから一気に突っ込みます。
**弾道ミサイル**は撃ち手の足元から真上へ昇って見えなくなり、落ちてくる位置を地面の赤い輪が示します。最後は対象の上空で光り、真下へ落ちてきのこ雲になります。
**流星**は、対象の足元の床が赤く光り、空の高い所に光の点が現れます。そこから燃える岩が斜めに落ちてきて対象に当たり、溶けた穴が残って冷えていきます。

弾の見た目が魔法弾のエフェクトは、その属性の姿で飛びます。

| エフェクト              | 飛ぶもの                       | 当たると                             |
| ----------------------- | ------------------------------ | ------------------------------------ |
| 火の矢 / ファイアボルト | 炎の矢 / 尾を引く炎の球        | 火球が弾ける                         |
| 氷の矢                  | つらら                         | 砕けて、対象のまわりに氷の結晶が立つ |
| 雷弾                    | 稲妻をまとった紫の球           | 当たった所に短い稲妻が落ちる         |
| 風弾                    | 渦巻く空気の塊                 | 風の輪になって弾ける                 |
| 岩弾                    | 転がりながら飛ぶ岩             | 砕けて、破片が転がる                 |
| 気弾                    | 撃ち手の手元で溜めた光の球     | 破裂音とともに弾ける                 |
| 呪弾                    | 髑髏の顔を持つ黒い塊           | 黒い帯が巻き付き、毒霧が立つ         |
| 聖光弾                  | 光の輪をまとい、羽根を落とす槍 | 光の紋章と細い光の柱                 |

**極太ビーム**は撃ち手の前に光を溜め、一瞬だけ細い線で通り道を示してから放ちます。光は撃ち手から対象を抜けてその先まで一度に届き、通り道のコマを飲み込みながら床に焼け溝を刻みます。最後は撃ち手の側から細くなり、光の粒になって流れていきます。
**極彩ビーム**は白い芯のまわりに色とりどりの光の束を編み込んだビームです。束は回りながら流れ、先端で花のように開きます。
どちらのビームも、撃ち手は放つときに後ろへ押され、ビームを浴びたコマは押し戻されます。

**レーザー照射**は細い照準の線を対象の手前の床に当ててから光を灯し、床を焼き切りながら対象まで進みます。対象を捉えると照らし続け、途切れたあとも焼けた跡が光って煙を上げます。

### 炎

**火の粉**は、撃ち手から飛んだ火の粉がコマについて小さな炎になり、すぐに消えかかります。
**炎上**は、コマの足元を炎の舌が囲み、頭まで包んで燃え上がります。煙と火の粉が昇り、最後は炭火が赤く残ります。
**爆炎**は、熱が一点に集まって白く弾け、火球が膨らんで転がりながら赤い煙に冷えていきます。床を衝撃の輪が走り、焦げ跡が残ります。
**大爆発**は熱を吸い寄せてから卓を白く染めて弾け、低く広い炎のドームが膨らみます。衝撃の輪と炎の前線が範囲の端まで走って床に火を残し、巻き込まれたコマは衝撃が届いた順に爆ぜます。
**業火**は、足元の地面が赤く割れて炎が漏れ出し、白い閃光のあと、地を這う炎の上に炎の柱が立ちます。柱の上で笠が巻きながら広がって黒煙に変わり、まわりの地面は広く燃え続けます。

### 雷

**電撃**は、撃ち手の手元に火花が集まり、細い稲妻が道を変えて3度、対象へ走ります。撃ち手がいないときは、対象の頭の少し上から落ちます。
**落雷**は、対象のまわりの床が暗くなって光の輪が縮まり、空から稲妻の先導が枝分かれしながら降りてきます。対象から伸びた光と出会うと太い雷が走り、道を変えてさらに2度落ちます。
**雷帝**は、頭上で雲の輪が渦巻き、四方から稲妻が降りてきたあと、対象の上に雷の柱が立ちます。柱は巻き込んだほかのコマにも枝を伸ばし、最後にひときわ太い一撃で終わります。
**電流**と**連鎖雷**は、対象が1体なら、撃ち手と対象のあいだに電流がつながり続けます。2体以上なら、選んだ順にコマからコマへ雷が跳び移ります。最後のコマに届くと鎖全体が太く光り、撃ち手の側から順に切れます。

雷に打たれたコマは震えます。空から落ちる**落雷**と**雷帝**では跳ね上がります。

### 氷

**氷礫**は、大きな氷の塊が撃ち手の肩越しに3つ続けて対象へ叩きつけられて砕け、足元に小さな氷が転がります。
**氷結**は、床を霜が走って集まり、対象を冠のように囲む氷の結晶が一斉に突き出します。しばらく立ったあと、ひびが入って上から崩れます。
**氷棺**は、氷の板が樽の板のように対象を囲んで立ち、最後に大きな結晶が全体を閉じ込めます。対象は氷越しに見え、ひびが1本ずつ走ってから砕け散ります。
**絶対零度**は、範囲の空気が青く濁り、漂う水気が白く凍って止まります。中心から冷気が白く広がり、巻き込んだコマのまわりに氷の尖塔が立って、すべてが一度止まります。そのあとひびが走り、全体が一度に砕けます。
**吹雪**は、白い風の帯が対象のまわりを何重にも巻き、雪と氷片が舞って、床に霜が広がります。途中で冷気が強まって霜が輪になって広がり、やがて風がやんで雪が積もります。吹かれたコマは風に押されて震えます。

### 土

**衝撃波**は地面の一点を踏みつけた衝撃です。床に白い閃光が広がり、三日月の衝撃が床を走って敷石がめくれ、岩と砂利が扇形に飛んで土の柱が立ちます。中心にはへこみとひびが残ります。
**岩石破砕**は、対象の下の地面が3度隆起します。そのたびに対象とその両脇の地面が割れ、コマほどの岩と土砂が噴き上がって、落ちて転がります。
**地割れ**は、撃ち手が地面を踏み鳴らし、その前から対象まで地面がギザギザに裂けていきます。裂け目の奥は赤く光り、対象の足元で地面が弾けて岩が飛びます。
**地隆**は、撃ち手の足元から対象へ向かって、岩の牙が順に高くなりながら突き出し、対象の下から最も大きな岩の柱が噴き上がります。続いて範囲の端まで岩の牙が輪になって突き出し、巻き込んだコマの下にも柱が立ちます。柱はひびから光ったあと、上から崩れて沈みます。
**大地震**は、範囲の地面が細かく震えてから3度大きく揺れます。揺れるたびに砂煙の波紋が広がり、大きな亀裂が赤く光りながら走って、岩と土砂が噴き出します。

**岩石破砕**・**地割れ**・**地隆**・**大地震**に当たったコマは、後ろへ押されるのではなく、上へ突き上げられます。

### 風

**突風**は、撃ち手の足元に砂が吸い寄せられたあと、白い三日月を先頭にした風の壁が対象まで走ります。壁は対象に当たって左右に分かれ、木の葉と砂利を巻き上げます。当たったコマは大きく押し戻されます。
**竜巻**は、地面の渦から空へ伸びる漏斗形の竜巻が立ち、風の帯が巻き付いて回ります。巻き上げた物は上から放り出されます。真下のコマは持ち上げられ、まわりのコマは引き寄せられます。
**大嵐**は大きな竜巻で、その上に範囲全体を覆う雷雲が広がります。範囲のコマは風の帯に包まれて持ち上がり、雲から落ちる雷に順に打たれます。
**鎌鼬**は誰も持たない風の刃です。白い三日月がいろいろな向きから対象を斬り抜け、斬り跡が細い白線になって空中に残ります。最後の一太刀のあと、突風が斬り跡をまとめて吹き散らします。
**真空波**は、圧縮した空気の三日月が床に砂の溝を刻みながら飛びます。対象を斬り抜けると風の輪になって弾け、そのあともしばらく、風の刃が対象のまわりを回りながら斬り続けます。

### 闇

**影の棘**は、対象の影が暗く広がって縁が紫に燃え、影から黒い棘が対象を貫いて突き上がります。棘は先から折れ、煙になって沈みます。突き上げられたコマは浮き上がります。
**暗黒球**は、闇が流れ込んで黒い球が対象を飲み込みます。球はまわりの光を吸ってから一点へ縮み、黒い閃光とともに弾けて、黒い炎が床に広がります。対象が複数なら1体ずつ順に飲み込みます。
**奈落**は、床に黒い穴が開き、縁にちぎれた土が盛り上がります。穴から巨大な影の手が何本も伸び、巻き込んだコマをそれぞれつかんで引きずり込みます。最後に穴が閉じて黒い炎が噴き上がり、コマの立っていた所に染みが残ります。
**蝕**は、卓の上空の白い太陽を黒い円盤が覆い、卓全体が暗くなります。円盤の縁から細い光の針が巻き込んだコマへ次々に降り、最後にコロナが広がると、当たったコマはすべて黒い炎に包まれます。コマは上から押さえつけられます。
**生命吸収**は、撃ち手から伸びた3本の帯が対象に食い込み、紅い帯に沿って対象の光を撃ち手へ吸い上げます。最後に帯が切れて撃ち手に戻り、撃ち手が光ります。吸われるコマは撃ち手のほうへ引き寄せられます。
**呪い**は、足元に暗い円陣が回って影の触手が立ちのぼり、足から体へ黒い染みが這い上がります。呪いが掛かった瞬間、頭上に髑髏が浮かびます。

### 聖

**聖印**は、対象の頭上に光の紋章が浮かび、細い光の柱がそれを抜けて対象に落ちます。
**裁きの光**は、対象の足元に光の輪が縮まり、太い光の柱が落ちて、羽根が舞い降ります。対象が複数なら1体ずつ順に落ちます。
**光輪**は、対象の胴のまわりに光の輪が現れ、ゆっくりと、やがて速く締まって白く弾けます。
**聖域**は、床に大きな光の紋章が開いて回り、その縁から金色の光の壁が立ち上がります。巻き込んだコマの足元からは光が噴き上がり、コマを持ち上げます。
**天罰**は、雲が集まって割れ、その間から光が差し込んで、床に大きな紋章が広がります。続いて巨大な光の柱が範囲全体に落ち、巻き込んだほかのコマにも同時に小さな柱が落ちます。

光で打つエフェクトのあとには、床に光の染みが残ります。**聖印**・**裁きの光**・**天罰**では、コマは上から押さえつけられます。

### 時空

**転移**は、コマを縦に貫く光の裂け目が開き、コマから光の糸が裂け目へ吸い込まれます。裂け目が閉じると白い十字の光が走り、残像がほどけて消えます。
**召喚陣**は、金色の筆が床に文字の帯と五芒星を書き、陣が回り出すと光の柱が立って、呼ばれたコマが柱の中で持ち上がります。最後に陣は文字から順に燃え尽きます。
**重力崩壊**は、対象の頭上に黒いレンズが開き、床が井戸のようにへこみます。圧力の円錐が叩きつけられ、対象は穴の底へ押さえつけられます。
**特異点**は、範囲の中心で空中に黒い穴が開き、光の円盤をまとって回ります。床に焼け焦げた渦が描かれ、土砂と巻き込んだコマが穴へ引き寄せられます。穴は一点に縮んで消え、白い閃光とともに、吸い込んだものをすべて外へ吹き飛ばします。

### 回復・防御・強化

**治癒**は、足元に生命の輪が開いて芽が伸び、2本の光の帯が体を巻き上がって、頭上で花が咲きます。
**回復光**は、頭上に開いた光の輪から光の雫が降り注ぎます。
**大治癒**は、対象をまとめて囲む大きな紋章が床に開き、光のドームがそれを覆います。コマはそれぞれ光の柱に乗って浮き上がり、羽根と花びらが舞い降ります。
**状態治療**は、水の輪が足元から頭上へ昇り、体にまとわりついた濁りを泡に閉じ込めて追い出します。**状態回復**は、頭に落ちた光の雫から波が体を流れ落ち、濁りを床へ押し流して消します。

**障壁**は、六角形のガラス板が足元から順にはまり、蜂の巣のようなドームになります。
**反射障壁**は、輝く面が四方から飛んできて組み合わさり、結晶のような鏡になります。空中から飛んでくるものを3度、光らせて弾き返します。

**闘気**は、足元の床が割れ、金色の芯を持つ気の炎がコマを囲んで立ちのぼり、小石が宙に浮きます。
**超必殺**は、足元に紋章が開いて光を吸い寄せたあと、空へ届く気の柱となって弾けます。床が割れて岩が持ち上がり、柱は燃え続ける炎になって、その中を稲妻が這います。最後に炎がコマへ吸い込まれ、目の高さを一筋の光が横切ります。

### 状態異常

状態異常のエフェクトはその状態の姿をコマの上に描きます。印の付く状態では、コマをどの向きから見ても印が頭の横に出ます。

| エフェクト | 姿                                                                             |
| ---------- | ------------------------------------------------------------------------------ |
| 毒         | 体から泡が湧いて弾け、足元に毒の染みが広がる。肩のあたりに髑髏                 |
| 出血       | 3つの傷から血がにじみ、鼓動のたびに噴き出す。肩のあたりに血の滴                |
| 燃焼       | 体と頭に小さな炎がつき、鼓動のたびに燃え上がる                                 |
| 麻痺       | 体を小さな稲妻が這い、ときどき強くしびれて火花と星が散る                       |
| 睡眠       | 頭から「Z」が昇り、鼻の泡が息に合わせて膨らむ。コマは息に合わせて揺れる        |
| 石化       | 足元から灰色の殻が這い上がって頭まで覆い、ひびが走る                           |
| 混乱       | 頭の横で渦が回り、左右に「？」が飛び出す。コマはよろめく                       |
| 魅了       | 頭の横でハートが脈打ち、小さなハートが昇る                                     |
| 恐怖       | 細い目をした影が肩の後ろに立ち、鼓動のたびに迫る。コマは震えて縮こまる         |
| 暗闇       | 黒い帯が目を覆い、頭のまわりに暗い霧が巻く                                     |
| 沈黙       | 口から出る声の輪を×印がふさぎ、輪はそこで砕けて落ちる                          |
| 鈍足       | 足元と頭上に時計が現れ、針が重く1つずつ進む。足首に鉄の重りが落ちる            |
| 拘束       | 足元から蔓が伸びて体に巻き付き、一斉に締め付ける。コマは締め付けの合間にもがく |

状態異常が掛かった瞬間、演出は一瞬止まります。画面は揺れず、コマも押し戻されません。
**毒霧**は、毒の雲が対象のまわりを低く漂い、泡が浮いては弾けます。

新しい部屋に最初から登録してある12個の状態異常には、どれも同じ名前のエフェクトがあります。状態異常をコマに付けたとき、このエフェクトを自動で出せます（[状態異常を付けたときに出す](#状態異常を付けたときに出す)）。

### ブレス

**ブレス**は、撃ち手が息を吸い込んでから、口元から対象へ円錐形に吹き付けます。対象が何体いても円錐は1つで、いちばん遠い対象まで届きます。
流れは対象でないコマも含めて、途中に立つコマにぶつかって回り込み、跳ね返ります。吹かれた対象は風下へ押されて震え、撃ち手は吸い込むときに身を引きます。
ブレスと**生命吸収**は撃ち手から出るので、撃つコマを選択してから使ってください。

ブレスの属性は「道中の粒」で決まり、粒を選んでいないときは系統で決まります。回復と聖の系統では、粒にかかわらず光の息になります。
粒を「出さない」にしたブレスは、副色が炎の色なら炎、そうでなければ冷気になります。

| ブレス             | 道中の粒                             | 系統（粒を選んでいないとき） | 流れたあとに残るもの                     |
| ------------------ | ------------------------------------ | ---------------------------- | ---------------------------------------- |
| 炎（火炎のブレス） | 火の粉                               | 炎、ほかの行にない系統       | 小さな火と焦げ跡                         |
| 冷気（氷のブレス） | 氷晶                                 | 氷                           | 床を這う霜と、床に溜まる霧               |
| 雷（雷のブレス）   | 放電                                 | 雷                           | コマから床や隣のコマへ跳ねる稲妻と焦げ跡 |
| 風（風のブレス）   | 木の葉                               | 風                           | 風下へ飛ぶ砂と砂利                       |
| 闇（暗黒のブレス） | 黒い靄（系統が状態異常のときを除く） | 闇                           | 影の円と、立ちのぼる黒い燃えかす         |
| 毒（毒のブレス）   | 黒い靄（系統が状態異常のとき）       | 状態異常                     | 毒の染みと、まとわりつく霧               |
| 砂（砂塵のブレス） | —                                    | 土                           | 床の砂の帯と、足元の吹きだまり           |
| 光（聖なる吐息）   | —                                    | 回復、聖                     | 光の輪と、漂う光の粒                     |

冷気のブレスは低く沈んで流れ、光の息はやわらかく昇ります。

### 大剣

**光の大剣**などの大剣では、撃ち手が剣を頭上に掲げ、まわりから光を集めます。剣から何マスもの高さの光の刃が伸び、一瞬の溜めのあと、対象へ向けて振り下ろされます。
刃が水平になった瞬間に画面が白く光り、撃ち手から対象を抜けてその先まで、属性の奔流が床を走ります。奔流は通り道のコマを飲み込み、対象の所では、その属性の着弾演出が起きます。

撃ち手は振る前に身を引き、振り下ろしで前へ出て、奔流が流れるあいだ踏ん張ります。当たったコマは奔流の向きへ押し流され、流れているあいだ押さえられます。
対象が何体いても、剣は最初の対象へ向けて1本だけ振られ、ほかの対象にも順に着弾します。撃ち手がいないときは、対象の横で剣が掲げられます。

| 大剣       | 刃と奔流                                 | 通ったあと                 |
| ---------- | ---------------------------------------- | -------------------------- |
| 光の大剣   | 光。星と光の羽根が流れる                 | 星がまたたいて消える       |
| 炎の大剣   | 炎。火の粉が飛ぶ                         | 斬り跡に煙と小さな炎       |
| 氷の大剣   | 凍る風。氷片が舞い落ちる                 | 霜が張り、雪が舞い落ちる   |
| 雷の大剣   | 雷。稲妻が枝分かれする                   | 斬り跡を稲妻が這う         |
| 大地の大剣 | 石。岩と砂煙が飛ぶ                       | 岩が一列に突き出す         |
| 闇の大剣   | 影。黒い炎と煙が噴く                     | 黒い煙が低く漂う           |
| 風の大剣   | 横倒しの竜巻。風の帯がらせんを描いて進む | 風の渦と、舞い落ちる木の葉 |

### 既定のエフェクトを入れ直す

エフェクトは部屋のデータとして保存され、部屋を保存・読み込みすると一緒に戻ります。
前の版で作った部屋には、あとの版で増えた既定のエフェクトは入りません。足すときは、エフェクト集の**メニュー**から次のどちらかを選びます。

| 項目                   | すること                                                                                                           |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **足りない既定を追加** | 部屋にない既定のエフェクトだけを作ります。部屋にある既定のエフェクトは、手を加えたものも含めてそのまま残ります     |
| **既定を反映**         | 部屋にない既定のエフェクトを作り、ある既定のエフェクトを最新の内容で上書きします。名前を変えたものも上書きされます |

どちらでも、消してしまった既定のエフェクトは作り直され、自分で追加したエフェクトは変わりません。

前の版で作った部屋にある既定のエフェクトは、その版の設定のまま残ります。流星・極彩ビーム・光の大剣・睡眠などは、新しい版で設定が変わったので、**既定を反映**で最新の内容にするまで、このページの説明どおりの見た目になりません。

## 発射元を決める（射撃系）

射撃系のエフェクトは発射元から対象まで実際に飛び、着弾で爆ぜます。

発射元は構えの欄の「撃ち手」のコマです。

1. 撃つコマをクリックして選択する
2. エフェクト集から火の矢・ファイアボルト・流星などを選んで構える
3. 撃たれるコマをクリックして対象にし、発動する

構えの欄の「撃ち手」と「対象」に名前が出ていれば、撃ち手から対象へ飛びます。
撃ち手が「なし」のときは、対象の斜め上から飛んできます。撃ち手は構えたあとでも[変えられます](#撃ち手を変える)。
飛ぶものと当たり方はエフェクトごとに[射撃](#射撃)で説明しています。

効果音は系統と規模で分けてあります（炎・爆発・氷・雷・風・地・回復・毒・強化・斬撃・弓・銃）。
音は[効果音ラボ](https://soundeffect-lab.info/)と[On-Jin～音人～](https://on-jin.com/)の素材です。

## チャットやキャラクターシートから出す

エフェクト集を開かなくても、いつもの操作の流れで演出を出せます。

### チャット記法`《…》`

本文に`《エフェクト名》`と書くと、その行を送ったときに演出が出ます。

```
2d6+3 t:HP-10 《爆炎》
```

こう書いたパレット行を1回押すだけで、ダイス → ダメージ処理 → 演出 → HPバーの反応が続けて走ります。
対象は`t:`と同じくターゲット指定したコマで、撃ち手はその行を喋ったコマになります。

エフェクト集でエフェクトを右クリック →「チャット記法を入力欄へ」を選ぶと、記法がチャット入力欄に入ります。
そのままパレット行へ貼り付けてください。

### キャラクターシートの「演出」欄

キャラクターシートの欄の種類を **「演出」** にすると、エフェクトを選ぶ欄になります。
技能行や必殺技の行に付けておくと、

- シートの **「対象に発動する」** ボタン
- コマの**右クリック → バフ・演出 → 演出を発動**

のどちらからでも撃てます。撃ち手はそのコマです。押したあとの動きは[ターゲット指定とエフェクトの種類で決まります](#ターゲット指定の有無による違い)。

### ホットバーのエフェクト枠

[ホットバー](/manual/hotbar#エフェクトの枠)の枠にエフェクトを入れておくと、枠を押すだけで撃てます。撃ち手は枠を押したコマです。
動作が**発動**の枠は、シートやコマの右クリックと同じ動きをします。

### ターゲット指定の有無による違い

シートの演出欄、コマの右クリック、ホットバーの**発動**の枠は、押した時点のターゲット指定で動きが変わります。

| 押した時点の状態                                             | 動き                                     |
| ------------------------------------------------------------ | ---------------------------------------- |
| ほかのコマをターゲット指定している                           | そのコマへすぐ発動します                 |
| ほかのコマのターゲット指定がなく、相手が要るエフェクト       | 発動せず、そのコマを撃ち手にして構えます |
| ほかのコマのターゲット指定がなく、対象が「自分」のエフェクト | そのコマ自身にすぐ発動します             |

構えたあとは、エフェクト集から構えたときと同じです。盤面のコマをクリックして対象を選び、Enterか帯の「発動」で発動します。エフェクト集のパネルを開いていなくても、ここまでの操作ができます。
相手が要るエフェクトは、狙える数が単体か複数のものです。

### HPの増減に自動で出す

パネル上部の**メニュー**で「HPの増減に演出を出す（自分の画面だけ）」にチェックを入れると、HPなどが減ったときに打撃、回復したときに回復光が自動で出ます。
増減の大きさで演出の規模が変わります。

この設定は自分の画面だけに効き、他の人の画面には出ません。既定は切です。

どのリソースで出すかはシート側の[項目ごとの設定](/manual/data-element#リソースの現在値と最大値)で決まります。**増減でエフェクト**の入っていない項目では、メニューのチェックを入れても演出が出ません。最初からあるHPとMPは入りです。

### 状態異常を付けたときに出す

[状態異常](/manual/buff#状態異常を登録して表から付ける)のパネルで「付けたとき、同じ名前のエフェクトを再生する」にチェックを入れると、コマに状態異常を付けた瞬間、エフェクト集にある同じ名前のエフェクトがそのコマに1回流れます。
新しい部屋に最初から登録してある12個の状態異常（毒・麻痺・睡眠など）には、どれも同じ名前の既定のエフェクトがあります。

- 部屋ごとの設定で、部屋と一緒に保存されます。既定は切です
- 変えられるのは卓を編集できる人で、見学のときは変えられません
- インベントリのチェック欄、チャットの`&毒`、[機能塗り](/manual/map-editor#機能塗り)の与える状態異常のどれで付けても流れます
- 演出は全員の画面に出ます。1回の操作で何体かに付けたときは、1体ずつ重ねずにまとめて流れます
- 外したとき、卓に出ていないコマに付けたとき、同じ名前のエフェクトがない状態異常を付けたときは、何も流れません

## エフェクトを作る・直す

既定のエフェクトをそのまま使うだけでなく、色や長さを変えたり、自分の卓用のエフェクトを作ったりできます。

- パネル上部の**追加**を押すと編集画面が開き、白紙から作れます
- 行にマウスを載せると出る**鉛筆**、または行の**右クリック**から編集できます。スマホでは行の右端の「⋮」から開くメニューに**編集**があります
- 右クリックからは**試し撃ち**・**複製**・**削除**も選べます。既定のエフェクトを書き換えたくないときは、複製してから直します

編集できるのは次の項目です。

| 区分     | 項目                                                                                           |
| -------- | ---------------------------------------------------------------------------------------------- |
| 見た目   | 種類（斬撃・爆発・極太ビームなど37種）／系統／道中の粒／等級／主色・副色／大きさ／長さ／ずらし |
| 対象     | 狙える数（自分・単体・複数）／範囲と上限（複数のとき）／コマに追従するか／GMだけに見せるか     |
| 種類ごと | 弾の見た目・弾数・間隔・着弾演出（飛翔体）／太刀筋（斬撃）                                     |
| 音       | 発射音・着弾音（部屋にある音源から選べます）                                                   |

編集画面のいちばん上にはプレビューがあり、編集中のエフェクトを代役のコマの上で繰り返し再生します。
値を変えると、その内容で最初から再生し直します。項目の欄はプレビューの下でスクロールするので、下の項目を直しているあいだもプレビューは見えたままです。音は鳴りません。

**試し撃ち**は盤面のコマの上で自分の画面だけに再生し、他の人には見えません。音も鳴ります。コマを選択するかターゲット指定してから押してください。

**ずらし**を入れると、複数対象のときに1体ずつ遅れて発動します。対象選択で付けた番号順に走ります。

**GMだけに見せる**を付けたエフェクトは、PLのエフェクト集には名前も出ず、名前を知っていてもチャット記法やキャラクターシートからは撃てません。仕込みを隠したいときに使います。

### 系統と道中の粒で変わる見た目

同じ種類でも、系統や「道中の粒」で描き方が変わるものがあります。粒を選んでいないときは、系統で決まります。

| 種類       | 変わり方                                                                                                            |
| ---------- | ------------------------------------------------------------------------------------------------------------------- |
| ブレス     | 属性が変わります（[ブレス](#ブレス)）                                                                               |
| 竜巻       | 粒が氷晶か系統が氷なら吹雪になり、粒が放電なら雷雲を載せた大嵐になります                                            |
| 斬撃       | 粒が木の葉か系統が風なら、風の刃（鎌鼬）になります                                                                  |
| 飛翔体     | 弾の見た目が魔法弾なら、着弾演出・系統・道中の粒で、炎・氷・雷・風・岩・気・呪い・聖の弾になります（[射撃](#射撃)） |
| 呪印       | 粒の欄で状態異常の姿（毒・睡眠など12種）を選べます。粒が放電なら麻痺の姿です                                        |
| 極太ビーム | 粒の欄で「極彩（色とりどりの束）」を選ぶと、極彩ビームの姿になります                                                |

竜巻・地割れ・氷結などは、範囲を付けるかどうかでも描き方が変わります。たとえば初級の竜巻は範囲がなければ突風になり、上級の氷結は範囲があれば絶対零度、なければ氷棺になります。

## 段を組んだ演出

編集画面の **「演出の組み立て」** で、37種類の見た目を部品として並べられます。飛んで、着弾して、そこから分裂して、燃え跡を残す、といった一連の流れが1つのエフェクトになります。

段には4つの役割があります。

| 役割     | すること                                       | 選べる見た目                                         |
| -------- | ---------------------------------------------- | ---------------------------------------------------- |
| **運び** | 発射元から対象へ向かう                         | 飛翔体・極太ビーム・ブレス・光の剣など12種           |
| **着弾** | 対象のところで起こる                           | 爆発・氷結・落雷・斬撃など25種                       |
| **残留** | その場に残る                                   | 着弾と同じ25種                                       |
| **派生** | 着弾点から複数の方向へ投げ、それぞれを走らせる | 着弾と同じ25種。投げた先の段は、この段の中に持ちます |

運び・着弾・派生は順につながり、前の段が終わったところから次が始まります。残留だけは後ろの段を待たせず、その場で流れ続けます。

```
[運び] 飛翔体   520ms
[派生] 分裂4 広がり140°
   └ [運び] 飛翔体 320ms
   └ [着弾] 爆発   280ms
```

- 段は上下の矢印で並べ替えられます。並び順がそのまま時間順です
- 役割を変えると、その役割で使えない見た目は自動的に戻ります（「運び」に爆発は置けません）
- 段は最大6つ、派生は2〜8方向までです。派生の中でさらに派生することはできません
- 段を1つも置かなければ、これまでどおり「見た目」の1種類がそのまま再生されます

長さは段ごとのms指定で、演出全体の長さは段の合計になります。上の「長さ」欄は段を置いていないときだけ効きます。

段を置くと、下の「**見た目**」欄の見た目は盤面に出ず、一覧に並ぶときの印にだけ使われます。

音も画面の揺れも段に追随します。運びの段が始まるたびに発射音、着弾の段が始まるたびに着弾音が鳴ります。近すぎる音は間引かれます。爆発や斬撃のように当たる見た目を着弾の段に置くと、その段が当たる瞬間に画面が揺れます。着弾の段が1つも無いときは、運びが終わったところで着弾音が鳴ります。

見本として **「散弾の魔弾」「氷結の追撃」「着弾の絨毯」** の3つが「組み立て」系統に入っています。複製して中を見ると、組み方の当たりが付きます。

### エフェクト集を配る

**メニュー**の「エフェクト集を書き出す」で、いま部屋にあるエフェクトをまとめて1つのファイルにできます。
1つだけ渡したいときは、行を右クリックして**書き出す**を選びます。編集パネルの**書き出す**でも同じものが出ます。

読み込みはそのファイルをAxeの画面へドラッグ＆ドロップするだけです。ファイルにはエフェクトごとの識別子が入っているので、渡したものが戻ってきたときは元のエフェクトに重なります。こちらで名前を変えた後でも同じエフェクトとして扱われ、同じファイルを何度読み込んでも増えません。

識別子が部屋のどのエフェクトとも合わないときは、名前で照らし合わせます。同じ名前があればその中身が入れ替わり、無ければ追加されます。

戻ってきたエフェクトの名前を、卓の別のエフェクトが先に使っていたときは、戻ってきた側に「(2)」が付きます。先に呼ばれていた方をそのまま残すのは、チャット記法やシートの演出欄がエフェクトを名前で呼ぶためです。

部屋を保存すればエフェクトも一緒に保存されるので、同じ卓を続けるだけならこの操作は要りません。

## 倒したとき

**撃破**の演出は周りに何かを出すだけでなく、コマ自身にもかかります。

- **崩壊** … 光の帯が足元から頭へ駆け上がってひびが光り、コマの絵が白く光って破片に割れます。破片は風上の側から1枚ずつはがれて風に流され、光の粒になって消えます。最後に、立っていた所から光の粒が昇ります
- **両断** … 斬る角度に刃の光が走ったあと、太い一閃がコマを貫きます。コマの絵は斬り口で2つにずれ、斬り口から血が噴き出して、足元に血だまりが広がります
- **血しぶき** … 傷口から血が飛び散り、滴が落ちて床に跡を残します。血は脈打って噴き出し、足元に血だまりが広がります。コマはのけぞって戻ります

絵を設定していないコマでは絵は切れず、崩壊は光の欠片だけ、両断は斬り口の光と血だけが出ます。演出が終わるとコマは元に戻るので、倒れたコマを片づけるかどうかは今までどおり手で決められます。

## 盤面に置いたままにする（毒沼・炎の壁）

エフェクトを右クリック →「**この場に置く（残り続ける）**」で、選んでいるコマの位置に演出を置けます。
置いた演出は繰り返し再生され続け、部屋を保存すると一緒に残ります。
前の回が消えきる前に次の回が始まるので、炎は途切れずに燃え続けます。

毒霧を毒沼に、炎上を炎の壁に、といった「その場に残る危険地帯」を作るのに使えます。

片づけるときは、エフェクト集の一覧の最後に出る「**置いてある演出**」の見出しの下で × を押します。

## 環境エフェクト

環境エフェクトは「この一帯が毒沼」「この洞窟は霧が濃い」という場の状態を盤面に敷く仕組みです。戦闘用のエフェクトを繰り返すのとは別に、環境そのものを描く絵を用意しています。

置いた内容はテーブルに紐づきます。テーブルを切り替えれば演出も一緒に切り替わり、部屋を保存すればそのまま残ります。

範囲を区切って置く方法と、マップ全体に掛ける方法があります。

### 範囲を区切る（毒沼・地面の噴出）

盤面の何もないところを右クリック →「**環境エフェクトを置く**」から種類を選ぶと、4×4マスの領域が置かれます。用意してあるのは毒沼・地面の炎上・地面の噴出・濃霧・瘴気・溶岩・氷結・光苔・水の9種類です。水は水面の高さや濁り、流れを決められる水域です。詳しくは[水域と水中](/manual/water)を参照してください。

領域は2つの層で描かれます。地面に貼り付く**面**（沼の水面、溶岩の照り）と、そこから**立ち上るもの**（蒸気、瘴気、炎）です。立ち上るものは奥行き方向にも重ねて立てるので、広げても薄まらず厚みが出ます。

地面の噴出では、噴き出し口が数か所にまとまります。広く置くと蒸気が何本も上がります。

地面の炎上は、床に張りつく**火床**の上に炎の舌が立ち、その上を黒煙が昇り、火の粉が舞い上がります。炎の大きさは1本ずつ大きく散らしてあります。小さな舌と、その10倍ほどまで伸びる炎が同じ場所に混じるので、一帯が燃え広がって見えます。

濃霧と瘴気は、流れながらゆっくり回り、膨らんだり薄れたりします。同じ形のまま横へ流れるだけでは、板が動いているようにしか見えないためです。

置いたあとは右クリックから調整できます。

- **種類を変える** — 沼を溶岩に、といった置き換え
- **濃さを変える** — 薄い / ふつう / 濃い の3段
- **広さを変える** — 2×2から24×24まで。中心は動きません
- **見せる相手** — GMだけ / 視界に入ったら / 全員。既定は全員です。パーティが来る前に先回りして置いておきたい霧や毒沼は、**視界に入ったら**にしてください
- **視線を遮る** — 入れると、その範囲の外枠が壁と同じように視線を止めます。霧の向こうは見えず、中のコマは外から見えません。光は通ります
- **明るさ** — 暗闇 / 薄暗い / 明るい。その範囲だけ卓の明るさと関係なく決まります。詳しくは[視界と照明](/manual/vision-lighting)
- **環境エフェクトの設定** — 幅と高さを1マス単位（最大100マス）で決めたり、色を好きに変えたりする設定パネルが開きます。視線と明るさもここにあります。マップ全体を毒沼にすることもできます

領域はドラッグで動かせます。**ロック**すると動かなくなり、盤面のドラッグやクリックも領域を素通りします。

マップ全体を覆うほど広げたときは、ロックしてください。ロックしないと、盤面を掴んだつもりで領域を掴んでしまい、視点が動かせなくなります。

### マップ全体に掛ける（天候）

テーブル設定の**天候**から選びます。濃霧・雨・雷雨・雪・降灰・火の粉・砂塵・瘴気・光の粒・水中の10種類で、濃さと色もここで変えられます。詳しくは[テーブル設定](/manual/table-setting)を参照してください。

降るのはテーブルとその上空だけです。盤の外へ向かっては、輪郭を作らずに薄れていきます。

天候は画面へ貼り付けて描いています。盤面に寝かせると、視点を倒したときに雨が地面を這って見えてしまいます。

### 動きを止めているとき

OSの「視差効果を減らす」を有効にしていると、粒は動きません。ただし毒沼や溶岩の面の塗りだけは残ります。沼が沼に見えないと、盤面から情報が消えてしまいます。危険地帯の位置は動きを止めていても読み取れます。

## 画面の揺れと光

爆発・斬撃・落雷・打撃・地隆・極太ビームなど当たりのある演出では、当たった瞬間に演出が一瞬止まり、画面が短く揺れます。中級は軽く、上級は強く揺れ、初級はほとんど揺れません。
飛翔体で揺れるのは、銃弾・狙撃・ミサイル・流星・岩弾と、中級以上の飛ぶ斬撃と気弾、上級の矢です。飛ぶ斬撃・気弾・矢は軽く揺れるだけです。ほかの魔法弾と光線銃では揺れません。大剣は奔流を放った瞬間に揺れます。
回復・障壁・闘気では揺れず、超必殺だけは力が弾けた瞬間に軽く揺れます。

当たりの閃きや燃える炎は、その色の光で周りの床とコマを照らします。等級が上がるほど明るく、遠くまで届きます。

OSの「視差効果を減らす」を有効にしていると、揺れも光も演出ごと再生されず、SEだけが鳴ります。

## 表示されないとき

- **対象がいない** — 構えの欄の「対象」の行にコマの名前が出ているか確認してください
- **視界の外にいるコマ** — [視界・光源](/manual/vision-lighting)で見えていないコマには演出を出しません
- **OSの「視差効果を減らす」設定** — 有効にしていると演出は再生されず、SEだけが鳴ります

## うまくいかないとき

| 見えるもの                             | 原因と直しかた                                                                  |
| -------------------------------------- | ------------------------------------------------------------------------------- |
| メニューに**エフェクト**がない         | 見学のときは出ません                                                            |
| 行を押しても発動しない                 | 押した時点では構えるだけです。対象を選び、「対象に発動する」かEnterで発動します |
| エフェクトが動かず、止まって見える     | FABメニューの**表示**で、**アニメーション**を止めています                       |
| 段を組んだら、「見た目」が盤面に出ない | 段を置くと、「見た目」の欄は一覧の印にだけ使われます                            |
| エフェクトの音が聞こえない             | 自分の[音の設定](/manual/sound-settings)の**演出の効果音**を確かめます          |
| 既定のエフェクトの一部が一覧にない     | 前の版で作った部屋です。**メニュー**の**足りない既定を追加**で足します          |
| 状態異常を付けてもエフェクトが出ない   | 状態異常のパネルのチェックが切か、同じ名前のエフェクトがありません              |

# セッションログ（リプレイ）

卓で起きたことを**このブラウザの中に記録**し、あとから読み返したり、盤面ごと再生したり、編集して**MP4の動画**に書き出したりできる機能です。FABメニューの**部屋設定**を開き、**ユーティリティ**タブの「リプレイ」から開きます。

<Shot src="replay" alt="リプレイパネル。記録の一覧と読み込みボタンがある" width="640" caption="記録した卓を選んで読み込みます" />

::: tip 記録は共有されません
記録は**自分の端末の中だけ**に残ります。他の参加者には送られませんし、部屋を保存しても含まれません。
持ち出したいときは[書き出し](#持ち出す・読み込む)を使ってください。
:::

記録できるのは**編集権限のある人**（GM / PL）です。見学者は記録を始められません。

## 記録する

時計の脇に**録画ピル**が出ています。押すと開きます。

1. **記録の細かさ**を決める
2. **記録を始める**を押す

記録中はピルに**経過時間と件数**が出ます。**目印**に見出しを書いて押すと、そこに**章の区切り**が入ります（例: `第二幕`）。あとで読むときも動画にするときも、この目印が章立てになります。

| 記録の細かさ | 残るもの                                                     |
| ------------ | ------------------------------------------------------------ |
| チャットのみ | 発言とダイスだけ                                             |
| 標準（既定） | 発言・ダイスに加えて、コマの移動やリソース増減などの主な操作 |
| すべて       | 上記に加えて細かい編集まで                                   |

決めた細かさは**このブラウザに記憶され**、次の卓でも同じ設定から始まります。

- **部屋が無くても記録できます** — ひとりで開いた卓もそのまま記録できます（一覧では「ひとりの卓」と表示されます）
- **記録は始めた卓に紐づきます** — 部屋を移ると、そこでいったん記録を締めます。移った先で続けたいときは、もう一度始めてください
- **秘匿はそのまま残ります** — 内緒話・GM限定・非公開のコマは当時の見え方のまま記録され、読むときも自分のロールで絞られます。コマの中の数値（HPなど）の変化とコマの退場も、そのコマと同じ公開範囲で残ります
- **勝手に消えません** — 既定では**すべての記録を残します**。減らしたいときは録画ピルの「残す本数」で直近5 / 10 / 20本を選べます（記録中のものは消えません）。記録を始めるときに、ブラウザへ「空きが減っても消さないでほしい」と申請します。書き込めなくなったときはピルが知らせます

「表示を消す」でピルを隠せます。FABメニューの[ウィジェット](/manual/#ウィジェット)で**録画**を点けると戻ります。

## 読む・再生する

記録を選ぶと、その記録が開いて画面が2列になります。記録を開いていないあいだは、記録の一覧が全面に出ます。

| 場所   | 中身                                                                                                                                 |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| **上** | 開いている記録の名前（押すと記録の一覧が開き、別の記録に切り替えられます）と、動画プレビュー・まとめ・読み物にする・動画にする・編集 |
| **左** | いま表示している1件と、タイムライン・再生ボタン。**動画プレビュー**と**まとめ**もここに開きます                                      |
| **右** | 項目の一覧。押すとその時点へ飛びます                                                                                                 |

一覧は台本のように並びます。発言は話者名の下に本文、ダイスと演出は1行、目印は見出しです。盤面の操作は
「◯◯ が △△ を動かした」のように座標を省いた1行で出て、発言と発言のあいだに続いたものは
「盤面の動き ×12」のようにひとつに畳まれます。押すと開きます。

コマを1体出すと、中の数値（HPなど）ごとではなく、コマの登場として1行だけ出ます。退場も同じです。

一覧は**すべて / チャット / 盤面**、話者、**秘匿を隠す**で絞り込めます。次の2つは既定で隠れていて、
チェックを入れると出ます。

- **付随する音も出す** — 移動や判定に付いて鳴った効果音（[効果音の扱い](#効果音の扱い)）
- **入退室や設定の変更も出す** — 入退室・役割・持ち主・固定・見た目の変更など、部屋の運営にあたる出来事

システムの発言（接続エラー、ログの消去など）も運営の側に入り、読む人の言語で表示されます。

**タイムライン**は、その時点で起きたできごとの多さを山として描きます。掴んで動かすとその位置へ飛び、通り過ぎたところは色が変わります。目印は**しおり**として並び、押せばその章の頭へ飛びます。

再生ボタンで**自動送り**もできます。読み進めるだけなら、**卓には一切触れません**。

### 盤面も再生する

「盤面を映す」を押すと、**今の卓をいったん預かって**記録当時の盤面を映します。

- この間の操作は**同卓者には届きません**。他の人の卓を巻き込まずに、自分の画面だけで再現できます
- 「卓に戻す」で**元の状態に戻ります**
- 盤面を映しているあいだ、**記録は止まります**（卓に戻すと続きから記録します）

## 直す・書き足す

「編集」を押すと、記録を作り替えられます。**元の記録は変わりません**。編集した結果は「別の記録として保存」されます。
「全部戻す」で編集前に戻し、「取りやめ」で編集をやめます。編集中に別の記録を開こうとすると、変更を捨ててよいかを
確かめます。

編集中は、ファイルを選ぶ要領で行を選び、選んだ行にまとめて操作します。

| 操作     | やり方                                                                            |
| -------- | --------------------------------------------------------------------------------- |
| 選ぶ     | 行をクリック。Shiftで範囲、Ctrl（MacはCmd）で1行ずつ追加・解除。`Esc`で選択を外す |
| 消す     | `Delete` / `Backspace`                                                            |
| 動かす   | `Alt`+`↑` / `↓`、またはつまんで移動                                               |
| 書き直す | `Enter`（行をダブルクリックでも同じ）。書いたら`Enter`、やめるなら`Esc`           |
| 書き足す | 一覧の下の欄で、発言 / ダイス / 目印を選んで書く                                  |
| 取り消す | `Ctrl+Z`で1手ずつ                                                                 |

行を右クリックすると、同じ操作のメニューが出ます。

- **動かす**と、見えている隣の行の向こう側へ移ります。絞り込みで隠れている行は1つずつ数えず、
  畳まれた盤面の動きは1まとまりとして越えます
- **範囲選択**は見えている行だけにかかります。畳まれた中の行は、開かないかぎり選ばれません
- **書き足した行**は、選んでいる行のうち最後の行の後ろに入り、そのまま選ばれた状態になります。続けて書けば、
  書いた順に並びます。何も選んでいなければ末尾に入ります
- 複数行をまとめて消した・動かしたときも、`Ctrl+Z` 1回で元に戻ります
- 移した項目は、**移した先の時刻**を引き継ぎます（並べ替えても時間の辻褄が合います）

### 実際に操作して収録する

手で書く代わりに、**卓を操作した結果をそのまま差し込め**ます。行を選んで、一覧の下の**収録**を押すと、その行の
後ろへ入れる収録が始まります（右クリックメニューの**この後ろから収録**でも同じです）。

1. 卓をふだんどおり操作する（コマを動かす・ダイスを振る・演出を出す）
2. 上部のバナーに件数が出るので、よければ「◯件を差し込む」を押す

収録中の操作は**同卓者には届きません**。破棄すれば何も残りません。

## 持ち出す・読み込む

記録一覧から`.axe-replay.zip`として**書き出し**できます。「画像も含める」を付けると、コマや背景の絵と、BGM・効果音も同梱されるので、別の環境でも絵と音付きで開けます（そのぶんファイルは大きくなります）。音は追加したときの名前のまま入ります。URLで指定しただけの音は入りません。

**読み込み**は同じ一覧から行います。読み込んだ記録は、自分で録ったものと同じように読めます。

::: info 記録の形式
v1.57.0から、記録は形式3で保存されます。それより前の版の記録はそのまま読めますが、v1.57.0以降で録った記録や
書き出したzipは、それより前の版では読み込めません。
:::

## 動画（MP4）にする

「動画にする」から、記録を**MP4**に書き出せます。記録を1本のタイムラインに起こし、発言・ダイス・盤面の動きを
時間の上に並べて描きます。

書き出す前に、上の**動画プレビュー**で仕上がりを確かめられます。左の列がプレビューに変わり、再生とシークができ、
一覧で行を選ぶとその場面へ飛びます。プレビューと書き出しは同じ描き方なので、見た絵がそのままMP4になります。
編集中は、直した内容がすぐプレビューに反映されます。

| 選べるもの | 内容                                                                     |
| ---------- | ------------------------------------------------------------------------ |
| 見せ方     | **ノベル**（立ち絵と台詞枠）/ **卓**（盤面を映して字幕）                 |
| 見せる相手 | **公開用（見学者と同じ）**（既定）/ 自分（PLの視点）/ GM（秘匿もすべて） |
| 言語       | 日本語 / 英語 / 韓国語。UIの言語とは別に選べます                         |
| 字幕の速さ | ゆっくり / ふつう / はやめ / はやい                                      |
| 大きさ     | 720p / 1080p / 1440p / 2160p（4K）                                       |
| なめらかさ | 30fps / 60fps                                                            |
| 間の取り方 | 読める速さ / 当日と同じ間                                                |
| 冒頭       | 部屋の名前と日付を出す                                                   |
| 音         | 効果音を入れる / BGMと環境音を入れる（それぞれ個別に選べます）           |

見せる相手と見せ方、言語はプレビューと書き出しで共通です。見せる相手をPLかGMにすると、公開していない情報が
映るという警告が出ます。YouTubeなどに出すときは**公開用**のままにしてください。

**長さの上限はありません。** 記録した分は最後まで書き出します。保存先を選べるブラウザ（Chrome・Edge）では、
押したときに保存先を尋ね、**そこへ直接書き込みます**。保存先を尋ねる画面を閉じると、書き出しは取りやめになります。

書き出す前に「◯ 場面・およそ ◯ 分・◯◯ MB」の見込みが出ます。保存先を選べないブラウザは動画をすべてメモリに
溜めてから保存するため、1GBを超えそうなときは途中で失敗するおそれがあると警告します。書き出し中は進捗が出て、
「やめる」を押せば止まります。

### 動画に映るもの

- **ノベル** — 話したキャラが舞台に立ち、話している人だけ明るく、ほかは暗くなります。台詞は名札つきの台詞枠に
  文字送りで出て、長い台詞はページをめくって続きます。背景はそのとき出していたノベルの背景か、盤面です
- **卓** — 盤面を映したまま、話し手の顔の横に字幕を出します
- **字幕** — 日本語は禁則処理を守って折り、英語と韓国語は単語の途中で折りません。行数を超えた分は次のページに
  送ります。1ページは言語ごとの読む速さで表示し（日本語は1秒7文字の速さに0.8秒を足し、1.8〜9秒）、
  「字幕の速さ」で変えられます。章の扉やラウンドの帯などの決まり文句は、選んだ言語で出ます
- **ダイス** — 直前の宣言、何のための判定か、振った式、結果を札で出し、成功と失敗を色で分けます
- **章・手番・カットイン** — 目印は章の扉、ラウンドと手番は帯になります。カットインは組んだとおりに再生します
  （YouTubeのカットインは絵としては入りません）
- **盤面** — 卓と同じに描き分けます。カードは向いている面、山札はいちばん上と枚数、ダイスは出目、コインは出た面、
  地形・マスク・メモ・光源。ヘクスの卓はグリッドもマスクも六角形です。ダンジョンの壁は高さのあるブロックとして
  立ち、開いた扉は開いた形で描きます
- **盤面の動き** — 発言のあいだに起きたことは、ひとまとまりの動きとして流れます。移動は道筋に沿って滑り、
  登場と退場はフェードし、ダイスは揺れ、カードはめくれ、数値の増減はコマの上に浮かびます。1回の動きは
  最長4.5秒です
- **カメラ** — 話し手と、動いたコマへなめらかに寄ります
- **暗闇・視界・光源** — 暗闇は地面と壁の上にかかり、コマ・ダイス・光源はその上に出ます。灯りはそのとき届いていた
  範囲を照らします。どこまで見えるかは**見せる相手**で決まります（公開用は見学者と同じ、卓に居るPLの視界を合わせた範囲）
- **映らないもの** — 公開用では、GM限定や特定の人だけに公開したコマ、他人のシークレットダイスの出目、
  見学者から暗闇で見えないコマは映りません。入退室や設定の変更も映りません

字幕の字体は同梱のNoto Sans JP / KRです。端末のフォントに左右されません。初めてプレビューか書き出しをしたときに
約4MBを読み込みます。

### 画質

YouTubeの推奨に合わせてあります。H.264のレベルは大きさとフレームレートから選び、キーフレームは2秒ごと、
音声はAAC 192kbpsです。音の全体にリミッターがかかるので、BGMに効果音が重なっても割れません。

| 大きさ | 30fps   | 60fps     |
| ------ | ------- | --------- |
| 720p   | 6 Mbps  | 9 Mbps    |
| 1080p  | 10 Mbps | 15 Mbps   |
| 1440p  | 20 Mbps | 30 Mbps   |
| 2160p  | 45 Mbps | 67.5 Mbps |

::: warning 書き出しの制限

- 書き出しは、ページとは別のスレッド（Worker）で描いて符号化します。タブを裏に回しても遅くなりませんが、
  省エネ設定のブラウザはタブごと止めることがあります。止まっていたときはパネルがそう知らせ、タブを表に戻せば
  続きから進みます。長い書き出しのあいだは、タブを表示したままにしておくのが確実です
- **WebCodecsに対応していないブラウザ**でも書き出せますが、ブラウザ任せの録画になるため**尺と同じだけ時間がかかり**、
  書き出しているあいだはタブを開いたままにする必要があります。この場合、出来上がりがWebMになることがあります
- 音を混ぜられなかったときは、無音で書き出さずに止まります。効果音やBGMを外すと書き出せます

「書き出せませんでした」と出るときは、**大きさ**や**なめらかさ**を下げると通ることがあります。
:::

## 読み物にする

「読み物にする」から、記録を**小説**または**台本**のMarkdownとして書き出せます。目印が章の切れ目になります。

- **組み方** — 小説 / 台本
- **盤面の動きも入れる** — 既定では入れません（入れると読み物が操作ログになります）
- **章に経過時間を添える**

見えるものは書き出す人のロールで決まります。

## まとめと記念写真

「まとめ」を開くと、その記録を数え上げて1枚にまとめた画面が出ます。

| 節           | 中身                                                |
| ------------ | --------------------------------------------------- |
| 数字         | 経過・発言・ダイス・演出・ラウンド・話した人        |
| 今日の称号   | 不運王 / 賽の寵児 / よく喋った人 / いちばん削られた |
| ダイスの出方 | 人ごとの振り数・平均・最高・最低・会心・大失敗      |
| 受けた増減   | コマごとのダメージ・回復・最大の一撃                |

**まとめを書き出す**でMarkdownとして保存できます。数えるのは記録に残っているものだけなので、足りない欄は「出せません」と表示します。

- **与えた側は出しません** — 記録に残るのは「値を変えた人」で、攻撃した人ではないためです（GMが敵のHPを減らせばGMの名前になります）。受けた側だけを数えます
- **ダイスの出方はv1.33.0以降の記録だけ**です。それより前の記録には出目そのものが残っていません
- 見える範囲は読む人のロールに従います（読み物と同じです。動画は「見せる相手」で決まります）

**記念写真**を押すと、その卓に出ていたコマの立ち絵を1枚に並べ、部屋名と日付を焼き込んだPNGを保存します。盤に出ていたコマだけが並び、入りきらなかった人数は画面に出ます。立ち絵がこのブラウザに残っていないコマも、枠と名前は残ります。

## 効果音の扱い

効果音は移動や判定に**付いて鳴るもの**で、それ自体はできごとではありません。そのため、記録には残しますが、**一覧には既定で出しません**。編集のために見たいときは、一覧の「付随する音も出す」で表示できます。

動画では、効果音は字幕にせず、鳴った場面の時刻に音として入れます。判定の直後に鳴ったダイスの音は、その判定の札が出るのに合わせて鳴ります。BGMは鳴り始めから止まる（または曲が変わる）までを1本に混ぜて収録します。環境音は鳴り始めから止まるまでを1本ずつBGMに重ね、鳴り始めたときの音量で収録します。

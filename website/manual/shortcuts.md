# キー操作の一覧

このページは、キーボードと、キーを押しながらのクリックでできる操作を、画面ごとにまとめたものです。
誰でも使えますが、ロールで使えない操作は効きません（GMだけの画面のキーなど）。
マウスで探すより早く操作したいときや、`?`で出た一覧の続きを見たいときに開いてください。

::: tip Macでは
CtrlをCommand（`⌘`）に、AltをOption（`⌥`）に読み替えてください。
:::

## 画面に一覧を出す

テーブルで`?`キーを押すと、FABメニューとツールバーのボタンの名前と一緒に、キー操作の一覧が出ます（→ [ボタンの名前をまとめて見る](/manual/screen#ボタンの名前をまとめて見る)）。
FABメニューのいちばん下にある`?`のボタンからも出せます。
このボタンは、[ホットバー](/manual/hotbar#kinds)の「メニューの項目」の枠にも入れられます。

<Shot src="shortcuts-guide" alt="ボタンの名前の表示。FABメニューとツールバーのボタンに名前が付き、右側にいまの画面で使えるキー操作の一覧が出ている" caption="`?`キーを押したところ。ボタンの名前と、いまの画面で使えるキーが出ます" />

一覧に並ぶのは、いまの画面で使える操作だけです。

- ホワイトボード・マップエディター・カットインの編集画面を開いていれば、その画面の操作が先頭に来て、テーブルの操作がその下に続きます
- [ダンジョンドリィマスターモード](/manual/dungeondry-master)のあいだは、テーブルの操作の代わりに、このモードの操作が並びます。移動キーは、マス目が正方形かヘクスかに合わせて出し分けます
- 自分のロールで使えない操作は出ません

一覧は、ボタンの名前に重ならない場所を探して出ます。
画面が狭くて空きがないときは名前と重なりますが、名前のほうが手前に出るので、名前は隠れません。
どこかを押すか`Esc`を押すと、ボタンの名前と一緒に消えます。
一覧の上を押したときも、その下にあるものが押されます。

ノベルモードで`?`を押すと、ノベルモード自身のキー一覧が開きます（→ [ビジュアルノベルモード](/manual/visual-novel#キーボード操作)）。
スマートフォン版の画面には、どちらの一覧も出ません。

## 全体

| キー | すること                                   |
| ---- | ------------------------------------------ |
| ?    | ボタンの名前とキー操作の一覧を出す・しまう |

## 卓

チャット欄などに文字を入力しているあいだは、どのキーもテーブルには届きません。

| キー              | すること                                        |
| ----------------- | ----------------------------------------------- |
| ← → ↑ ↓           | 卓を動かす                                      |
| Shift+← / Shift+→ | 卓を回す                                        |
| Shift+↑ / Shift+↓ | 卓を傾ける                                      |
| Ctrl+↑ / Ctrl+↓   | 近づく・離れる                                  |
| T                 | 選んだキャラクターだけをターゲットにする        |
| Shift+T           | ターゲットを全部外す                            |
| G                 | 選んだコマの公開範囲を切り替える（GMのみ⇔全員） |
| Enter             | エフェクトの対象選びを決める                    |
| Esc               | 対象選びをやめる・選択を外す                    |

[移動の道すじ](/manual/move-range#道すじを決めて歩かせる)を決めているあいだは、Enterで歩かせ、Escでやめます。

### Tでターゲットにする

Tキーは、選んでいるコマのうち、キャラクターだけをターゲットにします。
それまでのターゲットは外れます。
Shift+Tを押すと、ターゲットが全部外れます。
Alt+クリックと同じく、ターゲットは押した人の画面にだけ付きます。

### Gで公開範囲を切り替える

Gキーは、選んでいるキャラクター・カード・ダイス・共有メモの[公開範囲](/manual/disclosure)を切り替えます。

- 選んだ中に「全員」でないものが1つでもあれば、全部を「全員」にします
- 全部が「全員」なら、「GMのみ」に戻します
- 「特定PL」には切り替えません

公開範囲を変えられないコマは数えないので、GMでない人が押したときは、自分がオーナーのコマだけが切り替わります。

どちらのキーも、押すと何体（何個）を変えたかが画面に出ます。
コマを選んでいないときは、選んでから押すよう知らせが出ます。

## コマの選択

マウスと組み合わせる操作です。

| 操作                    | すること                                                           |
| ----------------------- | ------------------------------------------------------------------ |
| Ctrl+クリック           | コマを選択に足す・外す                                             |
| 長押し＋ドラッグ        | 何もない所を少し押したままにしてからドラッグして、囲んだコマを選ぶ |
| 長押し＋ドラッグ＋Shift | 離すときにShiftを押していれば、囲んだコマを選択に足す              |
| 長押し＋ドラッグ＋Ctrl  | 離すときにCtrlを押していれば、囲んだコマの選択を入れ替える         |
| Alt+クリック            | コマをターゲットにする・外す                                       |
| Shift+Alt+クリック      | ターゲットを全部外す                                               |
| Alt+ドラッグ            | 回している間、45°ごと（ヘクスは30°ごと）にそろえる                 |

## ホットバー

[ホットバー](/manual/hotbar)を出しているときに使えます。

| キー          | すること           |
| ------------- | ------------------ |
| 1〜0          | その番号の枠を撃つ |
| Shift+1〜5    | ページを切り替える |
| [ / ]         | 前後のページへ送る |
| Ctrl+クリック | 枠を空にする       |

## チャット

| キー            | すること                           |
| --------------- | ---------------------------------- |
| Enter           | 送る                               |
| Shift+Enter     | 改行する                           |
| Ctrl+↑ / Ctrl+↓ | 送った発言を呼び戻す               |
| Ctrl+F          | チャット窓の上で押して、ログを探す |

## ダンジョンドリィマスターモード

移動のキーは、テーブルのマス目で変わります。
くわしくは[ダンジョンドリィマスターモード](/manual/dungeondry-master#歩く・向きを変える)にあります。

| キー        | すること                                   |
| ----------- | ------------------------------------------ |
| W A S D ↑ ↓ | 移動する（正方形のマス）                   |
| W S ↑ ↓     | 前後に動く（ヘクス）                       |
| A D         | 斜め前に動く（ヘクス）                     |
| Z C         | 斜め後ろに動く（ヘクス）                   |
| Q E ← →     | 向きを変える                               |
| Space       | 扉を開け閉めする                           |
| F           | 明かりを点ける・消す                       |
| T           | 前にいるコマをターゲットにする             |
| Shift+T     | ターゲットを全部外す                       |
| Enter       | エフェクトの対象選びを決める               |
| Esc         | 正面に向き直す・対象選びをやめる・卓に戻る |
| ドラッグ    | 見回す                                     |

| Esc                   | 引いている折れ線を捨てる                                                                 |
| Ctrl++ / Ctrl+-       | 拡大・縮小                                                                               |

| Ctrl+9                | 全体を収める                                                                             |
| Ctrl+A                | すべて選ぶ                                                                               |

GMだけが使います。

| キー                  | すること         |
| --------------------- | ---------------- |
| ツールの文字          | ツールを選ぶ     |
| Space+ドラッグ        | 見る場所を動かす |
| Ctrl+Z                | 元に戻す         |
| Ctrl+Y / Ctrl+Shift+Z | やり直す         |
| Delete / Backspace    | 選んだものを消す |
| Enter                 | 描きかけを決める |
| Esc                   | 描きかけをやめる |

## リプレイの編集

[リプレイ](/manual/replay#直す・書き足す)の記録を編集しているときの、一覧のキーです。

| キー                | すること                                        |
| ------------------- | ----------------------------------------------- |
| Shift / Ctrl（Cmd） | 行を範囲で選ぶ・1行ずつ足す                     |
| Esc                 | 選んだ行を外す。書き直しの途中ならやめる        |
| Delete / Backspace  | 選んだ行を消す                                  |
| Alt+↑ / Alt+↓       | 選んだ行を動かす                                |
| Enter               | 選んだ行を書き直す。書いたあとの`Enter`で決める |
| Ctrl+Z              | 1手ずつ取り消す                                 |

## カットインの編集

[カットイン](/manual/cut-in#タイムライン)のレイヤーとタイムラインを編集する画面のキーです。

| キー                  | すること                                      |
| --------------------- | --------------------------------------------- |
| Space                 | 再生・停止                                    |
| ← / →                 | 再生ヘッドを1目盛り戻す・進める               |
| Shift+← / Shift+→     | 前後のキーへ飛ぶ                              |
| Home / End            | 先頭・末尾へ                                  |
| ↑ / ↓、Alt+← / Alt+→  | 選んだレイヤーを少しずつ動かす（Altで大きく） |
| Ctrl+Z                | 元に戻す                                      |
| Ctrl+Y / Ctrl+Shift+Z | やり直す                                      |
| Ctrl+C / Ctrl+V       | その瞬間の姿をコピー・貼り付け                |
| Delete / Backspace    | 選んだレイヤーを消す                          |

## うまくいかないとき

| 見えるもの                                                  | 原因と直しかた                                                                                                                   |
| ----------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| キーを押しても、テーブルが動かない                          | チャット欄などの入力欄にカーソルがあります。テーブルの何もない所を一度押してから、キーを押します                                 |
| `?`を押しても一覧が出ない                                   | 入力欄にカーソルがあるか、スマートフォン版の画面です。スマートフォン版では一覧は出ません                                         |
| 「キャラクターのコマを選んでから T を押してください」       | キャラクターのコマを選んでいません。コマを押すか、範囲で選んでから押します                                                       |
| 「公開範囲を変えられるコマを選んでから G を押してください」 | 選んだ中に、公開範囲を変えられるコマがありません。下の行も見てください                                                           |
| Gを押しても、一部のコマが変わらない                         | 公開範囲を変えられないコマです。GMでない人は、自分がオーナーのコマだけ切り替えられます（→ [情報の公開範囲](/manual/disclosure)） |
| 数字キーを押しても、ホットバーが動かない                    | ホットバーを出していません。FABメニューの**ウィジェット**で出します（→ [ホットバー](/manual/hotbar)）                            |

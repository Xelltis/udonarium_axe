# バフ／デバフ

このページはキャラクターに付く一時的な強化と弱体（バフ／デバフ）の付けかたと、いつ切れるかの決めかたを説明します。
残りのラウンドは自動で減り、ステータスを動かすバフや、状態異常の表から付ける方法もあります。
GMとPLが付けて外せます。見学は見るだけです。

<Shot src="buff" alt="バフ編集パネル。毒と防御強化のバフが残ラウンド付きで並んでいる" width="560" caption="バフごとに名前・残ラウンド・タイミングを設定します" />

## バフ編集を開く

キャラクターコマを**右クリック** → **バフ・演出** → **バフ編集**を選ぶと、バフ編集ビューが開きます。
バフが1つも無いときは「バフ・デバフは登録されていません」と表示されます。

## 追加・編集・削除

1. バフ編集で**バフを追加**を押します。新しい行が足されます。
2. **名前**に、バフの名前（例：`猛攻撃`）を入れます。
3. 効果やラウンド数を入れます。
4. 名前の下の行で、いつ切れるかを決めます（→ [いつ切れるかを決める](#いつ切れるかを決める)）。

| したいこと           | 操作                                                                                                                                                                 |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| アイコンと色を決める | 名前の左の丸いボタンを押し、絵文字（☠️ 毒、🛡️ 防御、🔥 炎…）と背景色を選びます。ボタン自体がコマに出るバッジと同じ見た目です。同じものをもう一度押すと既定に戻ります |
| 画像をアイコンにする | 絵文字の下の**画像から選ぶ**で、部屋に取り込んだ画像をバッジに使います。バフマネージャーのチャートにも同じ画像が出ます                                               |
| バフを消す           | 行の**バフを削除**（ゴミ箱のアイコン）を押します                                                                                                                     |

登録したバフはテーブル上のコマの頭上に**丸いバッジ**として並びます。バッジは選んだ色の丸に絵文字を乗せたもので、左上に強度・右下に残ラウンドが重なります。強度は効果欄に書いた数値（`防+1`なら`+1`、`ダメージ2`なら`2`）を自動で拾います。バッジにポインタを乗せると、バフ名と効果の全文が出ます。

色は8色（赤・橙・黄・緑・青・紫・桃・灰）と既定の黒から選べます。強化は青、状態異常は赤、といった塗り分けをしておくと、コマを見ただけで卓の状況が読めます。

見せ方はコマを**右クリック** → **バフ・演出** → **バフの表示**から選べます。**アイコン**（既定）、同じバッジの横に名前・効果・残ラウンドを並べる**詳細**、`バフ3個`とだけ出す**個数**の3つで、いま選ばれているものにはチェックが付きます。コマの上には操作するものを置いていないので、頭上の表示を触ってコマが動いてしまうことはありません。

アイコンの大きさはPLツールバーの**バフアイコンの大きさ**を押すたびに、小（75%）・標準（100%）・やや大（125%）・大（150%）・特大（200%）と切り替わります。選んだ大きさは自分の画面だけのもので、次に開いたときも残ります。

## いつ切れるかを決める

バフ行の**消失タイミング**から、残ラウンドがいつ1減るかを選べます。

- **ラウンド終了時**（既定）— ラウンドが終わるたびに、卓の全員分がまとめて減ります
- **トリガーの手番開始時** — 指定したキャラクターの手番が回ってきたときに減ります
- **トリガーの手番終了時** — 指定したキャラクターの手番が終わったときに減ります
- **消えない** — 減りません。外すまで残ります

手番のどちらかを選ぶと、隣に**トリガーキャラクター**の選択欄が出ます。
卓にいるコマから選ぶ形なので、名前を打ち間違えて来ない手番を待ち続けることはありません。
選んだ相手はコマそのものを指すため、あとで改名しても外れません。

空欄のままなら、そのバフを持っているコマ自身の手番を待ちます。自分に掛けた呪文はこれで足ります。
術者の手番が回ってきたら切れる強化は、術者をトリガーに指定します。

手番に紐づいたバフはラウンド終了時にまとめて減る対象からは外れます。二重に減ることはありません。

**消えない**を選んだバフは、ラウンドが進んでも[リモコン](/manual/pl-tools)のラウンド操作でも減りません。
減るたびに動かす量を持つバフは、消えないままラウンドが終わるたびに動きます（[効果が動くタイミング](#効果が動くタイミング)）。
残ラウンドの数字はバッジから消え、**詳細**の表示では`∞R`と出ます。毒や麻痺のように、解除するまで続くものはこれにします。
チャットから付けるときは、タイミングに`消えない`か`none`を書きます（`&毒/継続2/none`、`&!石化/HP/=/0/1/none`）。

## バフとデバフの区分

バフには「バフ」か「デバフ」かの区分があります。
区分は[バフだけ、デバフだけを外す操作](#reset)が見分けるために使います。効果や残ラウンドの数え方は、区分では変わりません。

区分がデバフのバフには、バッジの丸の中の右下に小さな`▼`が出ます。

区分は次の順で決まります。

1. 区分を付けたバフは付けた区分になります
2. 区分を付けていないバフは、名前が部屋の[状態異常](#状態異常を登録して表から付ける)の一覧にあればデバフです
3. どちらにも当たらなければバフです

バッジの色や、ステータスを上げるか下げるかは、区分に関わりません。

区分は次の場所で付けます。

| 場所                 | 操作                                                                                                                                   |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| バフ編集             | バフの行の、上下の矢印の印が付いた選択欄で「バフ」か「デバフ」を選びます。欄にポインタを乗せると「区分」と出ます                       |
| バフマネージャー     | バーを押して開く欄の**区分**で選びます。**自動計算バフの記法を作る**の**区分**でデバフを選ぶと、組み立てる記法に`debuff`が入ります     |
| リモートコントローラ | バフ欄の**区分**で選んでから付けます。入力に`デバフ`か`バフ`を書いたときは、書いた区分になります                                       |
| チャット             | 色やアイコンと同じ位置に`デバフ`（`debuff`）か`バフ`（`buff`）を書きます。ラウンド数の欄に書くと、ラウンド数を省いたものとして読みます |

```
&毒霧/命中-2/3/デバフ       3ラウンドのデバフ
&毒霧/命中-2/デバフ         ラウンド数を省いたデバフ（3ラウンド）
&!衰弱/筋力/-/2/3/debuff    ステータスを動かすデバフ
```

- 状態異常の表やチャットの`&毒`で付けた状態異常には、付けたときにデバフの区分が付きます。あとで部屋の一覧から消しても、デバフのままです。`&毒/継続2/3/バフ`のように`バフ`と書いて付けると、バフになります
- リモートコントローラと記法の組み立ての**区分**は、選ぶまでは名前から決まる区分を表示します。名前が状態異常の一覧にあればデバフ、なければバフです。選ばずに付けたバフには区分が付きません
- 一覧にある名前のバフで「バフ」を選ぶと、バフの区分が付きます。組み立てる記法には`buff`が入ります
- [いくつものステータスを動かすバフ](#いくつものステータスを動かす)は、バフ全体で1つの区分を持ちます
- `バフ`・`デバフ`・`buff`・`debuff`の4語は区分として読むので、アイコンの文字には使えません

この書き方に対応していない古い版のAxeで`&毒霧/命中-2/3/デバフ`と打つと、アイコンが「デバフ」の文字になります。古い版で[行動順](/manual/turn-order#バフの残ラウンドを自動で減らす)の**前へ**を使うと、戻ったバフから付けた区分が消えます。

## ステータスを動かすバフ

「命中+2」と書いただけのバフは、あくまで覚え書きです。
実際に命中を上げるのも、切れたときに戻すのも自分でやることになります。

チャットの`&!`記法を使うと、バフがステータスを実際に動かし、切れたときに動かした分を戻します。

```
&!猛攻撃/命中/+/2/3
```

左から、バフ名・ステータス名・操作・量・ラウンド数です。
この1行で「猛攻撃」が付き、シートの命中が2上がり、3ラウンド後に切れると2下がります。

戻すのは**実際に動いた分**です。
シートの上限で頭打ちになって、`+30`のうち4しか動かなかったなら、返るのも4です。
掛けた値をそのまま引き算しないので、上限のあるリソースでもずれません。

- **操作** — `+`と`-`は増減、`=`はバフのあいだステータスをその値に留めます
- **ラウンド数** — 省略すると3ラウンドです
- **最大値を動かす** — ステータス名のうしろに`^`を付けます。`HP^`なら残量ではなく最大値が対象です
- **上限・下限そのものを動かす** — `HP_MAX`（最大値のベース）・`HP_MAX_BUFF`（その補正値）・`HP_MIN`・`HP_MIN_BUFF`も同じように書けます。リソース項目の詳細設定にある「最大値ベース／補正値」と同じ場所を指します
- **見た目・タイミング・トリガー** — ラウンド数のうしろに、ふつうのバフと同じく色・アイコン・タイミング・`@`付きのトリガーを、好きな順で書けます（`&!練技/筋力/+/2/3/blue/💪/手番開始/@術者`）。タイミングのすぐうしろに`@`なしで書いた名前も、これまでどおりトリガーとして読みます（`&!練技/筋力/+/2/3/手番開始/術者`）。`発生:手番終了`のように書くと、減るたびに動かす量が動く時期を決められます（[効果が動くタイミング](#効果が動くタイミング)）

バフの消え方は時間切れ・`&名前-`での削除・`&D`での一掃・[リセット](#reset)・[まとめて外す](#sweep)・ゴミ箱ですが、どの消え方でもステータスは同じように返ります。
同じバフをもう一度掛けたときは残ラウンドが振り出しに戻ります。
足し込みたいときは[重ねがけ](#重ねがけ)を使います。

### 量に計算式を書く

量には数のほか、計算式も書けます。`&!鼓舞/攻撃/+/(3+4)÷2/1`なら、攻撃が3上がります。

- 足し算・引き算・掛け算・割り算と括弧が使えます。掛け算は`*`か`×`、割り算は`÷`か全角の`／`で書きます。半角の`/`は欄の区切りなので、割り算には使えません
- 割り算の端数は割るたびに切り捨てます（`7÷2`は3）
- 切り上げや四捨五入にしたいときは`ceil(7÷2)`・`round(7÷2)`のように書きます。`floor`・`ceil`・`round`の括弧の中では端数を残したまま計算し、最後に丸めます。`abs`・`min`・`max`も使えます
- 式に空白は入れられません。チャットの命令は空白で区切られるためです

### 数えるたびに動かす

量のうしろに`~`と数を付けると、残ラウンドが減るたびに、ステータスをその分だけさらに動かします。

```
&!変身/器用度/+/5~-1/5         器用度を 5 上げ、減るたびに 1 ずつ戻す
&!猛攻撃/命中/++/1/3            命中を 1 上げ、減るたびに 1 ずつ足す
```

- 操作を`++`・`--`と2つ重ねると、量と同じだけ、減るたびに足し続けます（引き続けます）。`&!猛攻撃/命中/++/1/3`は`&!猛攻撃/命中/+/1~+1/3`と同じです
- 残ラウンドが自動で減ったときも、`&R-`で手で減らしたときも動かします。`&R+`で増やしたときは動かしません
- 消えないバフと、動く時期を別に決めたバフの動き方は[効果が動くタイミング](#効果が動くタイミング)にあります
- 切れたときは、最初の分と、減るたびに動かした分をまとめて戻します
- 効果欄はいま動いている量に書き換わります（`器用度+4~-1`）
- `=`で留めるバフには付けられません

### 切れても戻さない

ステータス名の前に`:`を付けると、バフが切れても、そのステータスは動いたままになります。毒のダメージやリジェネの回復のように、受けた分が残る効果はこう書きます。チャットの`:HP-3`がシートの値をそのまま変えるのと同じ印です。

```
&!毒/:HP/+/0~-3/3            減るたびに HP を 3 減らし、切れても戻さない
&!リジェネ/:HP/+/0~+5/3      減るたびに HP を 5 回復する
&!毒/回避-2,:HP+0~-3/3       回避は切れたら戻し、HP は戻さない
```

切れる回にも動くので、3ラウンドの毒ならHPは3回減ります。付けたときに動いた分も戻りません。`&!毒/:HP/--/3/3`なら、付けたときに3減り、そのあとも減るたびに3ずつ減ります。

- `&毒-`で外しても、同じバフを掛け直しても、動いた分はそのままです
- [行動順](/manual/turn-order#バフの残ラウンドを自動で減らす)の**前へ**や**待機**で減った回が取り消されたときは、その回に動いた分だけ戻ります
- バフマネージャーの**自動計算バフの記法を作る**では、**戻さない**にチェックを入れると、`:`を付けて組み立てます

この書き方に対応していない古い版のAxeで残ラウンドを減らしても、減るたびの分は動きません。外しても戻しません。

### 効果が動くタイミング

`~`や`++`・`--`で書いた、減るたびに動かす量は何も書かなければ次のときに動きます。

- 残ラウンドのあるバフは、残ラウンドが減るときに動きます
- **消えない**バフは、ラウンドが終わるたびに動きます。残ラウンドは減らず、バフは外すまで残ります

4つ目以降の欄に`発生:`と時期を書くと、その時期にだけ動きます。
書ける時期は`発生:ラウンド終了`・`発生:手番開始`・`発生:手番終了`の3つで、`tick:turnStart`のような英名でも書けます。
手番はそのバフを持っているコマ自身の手番です。トリガーに別のコマを指定していても変わりません。

```
&!再生/:HP/+/0~+3/none                          ラウンドが終わるたびに HP を 3 回復する
&!再生/:HP/+/0~+3/none/発生:手番開始             自分の手番が始まるたびに HP を 3 回復する
&!再生/:HP/+/0~+3/3/手番開始/@術者/発生:手番終了   術者の手番開始で残りが減り、自分の手番の終わりに回復する
```

1つ目の書き方は以前の版では一度も回復しませんでした。この版からは、すでに付いているバフも含めてラウンドが終わるたびに回復します。動かしたくないバフは`~`のない量で付け直します。

- `発生:`を書いたバフは、残ラウンドが減るときには動きません。切れるまでに来た時期の回数だけ動き、切れたあとは動きません。減るのと動くのが同じ時期に重なるバフは、動いてから減ります
- `&R-`やリモコンで手で減らすと、`発生:`を書いていないバフは動きます。消えないバフも、残ラウンドはそのままで1回動きます。`発生:`を書いたバフは動きません。`&R+`ではどのバフも動きません
- `:`を付けていない量は、消えないバフでも動いた分が積み上がり、`&名前-`などで外したときにまとめて戻ります。`:`を付けた量は外しても残ります
- [行動順](/manual/turn-order#バフの残ラウンドを自動で減らす)の**前へ**や**待機**で回が取り消されたときは、その回に動いた分だけ戻ります
- 行動順の砂時計アイコンで自動減少を切っているあいだは、どの時期にも動きません
- 手番をもたないコマと行動順に入っていないコマには手番が来ないので、`発生:手番開始`と`発生:手番終了`は動きません
- `=`で留めるバフと、減るたびに動かす量のないバフに`発生:`を書いても、何も動きません

バフ編集では、減るたびに動かす量を持つバフの行に**効果の発生タイミング**の欄が出ます。
バフマネージャーでバーを押して開く欄と、**自動計算バフの記法を作る**にも同じ欄があります。
コマの頭上の**詳細**の表示では時期を書いたバフの残ラウンドの横に`発生:手番終了`のように出ます。

この書き方に対応していない古い版のAxeで行動順を進めた回は、消えないバフは動かず、`発生:`を書いたバフは残ラウンドが減るときに動きます。

### いくつものステータスを動かす

2つ目の欄に、ステータス名・操作・量をつなげて`,`で並べると、1つのバフでいくつものステータスを動かします。

```
&!全力攻撃/追D+4,回避-2/1/手番開始
&!変身/器用度+5~-1,敏捷度+5~-1,HP^-20/5/手番開始
```

並べたあとは、ラウンド数を書き、そのうしろに色・アイコン・タイミング・トリガー・`発生:`の時期を書きます。1つだけ`&!猛攻撃/命中+2/3`と書いても、`&!猛攻撃/命中/+/2/3`と同じです。

- コマの頭上には1つのバッジとして出て、効果欄にはすべての変化が並びます（`追D+4,回避-2`）
- 中ではステータスごとに1行ずつ持ちます。2行目からは`全力攻撃（回避）`のように、ステータス名を添えた名前です。バフマネージャーやバフの詳細には、この行も並びます
- `&全力攻撃-`や[まとめて外す](#sweep)で名前を指定すると、すべての行をまとめて外し、動かした分をそれぞれ戻します
- 同じ名前でもう一度掛けると、今回並べたステータスだけで掛け直します。[重ねがけ](#重ねがけ)は行ごとに足します
- この書き方に対応していない古い版のAxeでは、行ごとに別々のバフに見えます。外せば、それぞれの行が動かした分を戻します

バフマネージャーの**自動計算バフの記法を作る**でも、**ステータスを足す**で行を増やすと、この書き方で組み立てます。

- `{筋力}÷2`のような項目の参照は値に置き換わってから計算されます

バフマネージャーの[記法の組み立て欄](#卓全体のバフの一覧)と、[状態異常](#シートの値を動かす状態異常)の動かす量にも、同じ式を書けます。組み立て欄では半角の`/`も割り算として読み、作る記法には`÷`で書き出します。

### 狙う側の値に足す

ステータス名の前に`相手の`を付けると、そのバフを付けたコマへ向けた行で、発言者の値にその量を足します。付けたコマ自身のステータスは動きません。敵ごとに違う、狙われたときだけの修正に使えます。

```
&!弱点/相手の物理特攻+2/none
&!弱点/相手の命中修正+1,相手の炎特攻+3/none
```

1行目のバフを付けた敵へ`2d6+{物理特攻} 物理 t:`を振ると、発言者の`{物理特攻}`に2を足して振ります。ほかの敵へ向けた行と、`t:`の無い行には足しません。

- 足すのは、行の先頭のダイスの式と、`:`の操作の量の中にある参照です。式の外の`{物理特攻}`は発言者の値のまま入ります
- 発言者のシートやパレットに無い名前は、バフの量だけが入ります。バフの無い敵へ向けたときに式が欠けないように、パレットに`//炎特攻=0`のような変数を書いておきます
- 同じ名前に`相手の`の効果が2つ以上あるときは、足し合わせます。`&弱点/相手の物理特攻+2`のような、効果を書くだけのバフでも同じです
- `t:範囲`で全員へ1回だけ振る行には、最初のターゲットの分を足します
- 書けるのは`+`と`-`で足す量です。`=`で決める書き方と、最大値（`HP^`）には使えません

この書き方に対応していない古い版のAxeで付けると、「相手の物理特攻が見つかりません」と出て、効果の文字だけのバフになります。古い版から振った行には足しません。

## 重ねがけ

`&猛攻撃/攻撃+2/3`を2回打つと、2回目が1回目を書き換えるので効果欄は`攻撃+2`のままです。
同じ強化を二重に受けたことにしたいなら、`&`のうしろに`+`を足して`&+猛攻撃/攻撃+2/3`と打ちます。
効果欄の数値が足し合わされ、`攻撃+4`になります。
弱体を重ねるときは`&+猛攻撃/攻撃-1/3`のようにマイナスで書きます。

残ラウンドは長いほうが残ります。
5Rのバフに2Rを重ねても5Rのままなので、短い重ねがけで先に切れてしまうことはありません。
ラウンド数を省略すれば、いま残っている数がそのまま続きます。
消えないバフに重ねたときは、消えないままです。

持続そのものを伸ばしたいときは、`+`を2つ並べて`&++猛攻撃/攻撃+2/3`と打ちます。
残2Rのバフに3Rを重ねると5Rになります。
効果欄を空にして`&++加護//3`と打てば、効果はそのままで3Rだけ延びるので、「重ねがけは効かないが掛け直せば持続する」ルールもこれで書けます。

| 書き方               | 効果欄   | 残ラウンド |
| -------------------- | -------- | ---------- |
| `&猛攻撃/攻撃+2/3`   | 書き換え | 3Rに戻す   |
| `&+猛攻撃/攻撃+2/3`  | 足す     | 長いほう   |
| `&++猛攻撃/攻撃+2/3` | 足す     | 3R足す     |
| `&++猛攻撃//3`       | そのまま | 3R足す     |

足し算になるのは、効果欄が同じ言い回しで同じ数値を指しているときだけです。
`攻撃+2`に`防御+1`を重ねても意味の通る答えは作れないので、その場合はこれまでどおり新しいほうで書き換えます。

`&+!`と書けば、[ステータスを動かすバフ](#ステータスを動かすバフ)も重ねられます。
`&+!猛攻撃/命中/+/2/3`を2回打つと命中は4上がり、バフを外すと4戻ります。
ただし`=`（その値に留める）だけは、二度留めても留める値は変わらないので掛け直しになります。
`=`で留めているバフに、留めているのと同じステータスを`&+!`や`&+`で重ねたときも、ステータスは留めた値のままで、残ラウンドだけが重ね方に従います。

リモートコントローラのバフ欄からも重ねられます。
バフ名の前に`+`を付けて`+猛攻撃 攻撃+2 3`と打つと、選んだコマ全員の「猛攻撃」に足されます。
`++猛攻撃 攻撃+2 3`なら残ラウンドも延びます。

## リモコンとチャットから付ける

同じ見た目の指定はバフ編集を開かなくてもできます。

- **リモートコントローラ** — バフ欄の入力は`バフ名 効果 ラウンド数 色 アイコン`の空白区切りです。入力欄の上に並ぶ**色の丸**を押しておけば、色を打たなくてもその色で付きます。バフ名の前に`+`を付けると[重ねがけ](#重ねがけ)、`++`なら残ラウンドも延びます
- **チャット** — `&毒/継続2/3/red/☠️`のように、4つ目以降に色と絵文字を書けます。順番は入れ替えてもかまいません

色の書き方は`red` `blue`などの英名、`赤` `青`などの和名、`#c62828`のような16進のいずれでも書けます。`既定`と書くと黒に戻ります。

消失タイミングとトリガーも、色やアイコンと同じ位置に順不同で書けます。
タイミングは`手番開始` `手番終了` `ラウンド終了`（`turnStart`などの英名も可）、トリガーは`@名前`です。

```
&練技/筋力+2/3/blue/💪/手番開始/@術者
```

チャット記法の詳細は[チャットの特殊記法](/manual/chat-syntax#バフ-デバフ操作)を参照してください。

## 残りラウンドの自動減少

[行動順](/manual/turn-order#バフの残ラウンドを自動で減らす)でラウンドを進めると、残ラウンドが1減り、0になったバフは自動で消えてチャットに通知されます。
自動減少は行動順の砂時計アイコンで切り替えられます。

手番タイミングのバフはラウンドではなく手番の切り替わりで減ります。
どちらの場合も、0になれば同じように消えて通知が流れます。

## 状態異常を登録して表から付ける

毒・麻痺・気絶のように何度も使うものは、部屋ごとに登録しておけます。
FABメニューの**ゲームリソース**、バフマネージャーの右上、[インベントリ](/manual/inventory#検索と表示設定)の絞り込みパネルのどれからでも**状態異常**のパネルを開けます。

新しい部屋には、毒・出血・燃焼・麻痺・睡眠・石化・混乱・魅了・恐怖・暗闇・沈黙・鈍足の12個が最初から入っています。
どのルールにも寄せていない見本なので、卓に合わせて書き換えて使ってください。
ラウンドで消えるもの・解除するまで続くもの・手番の開始や終了で減るものが一通り揃えてあります。
消したり書き換えたりした部屋には配り直されません。

1件ずつ、名前・色・アイコン・ラウンド・消失タイミング・効果メモを決めます。
名前にスペースは使えません。表示項目として名前で呼び出すためです。

### シートの値を動かす状態異常

効果メモは覚え書きなので、書いただけでは何も動きません。
**動かす項目**に項目名を書くと、その状態異常が[ステータスを動かすバフ](#ステータスを動かすバフ)になります。
付いているあいだシートの値が動き、外すと動いた分だけ戻ります。
動かし方は`=`（その値に留める）・`+`・`-`から選びます。
項目名の前に`:`を付けると（`:HP`）、外しても戻しません。量に`0~-3`と書けば、毒のように減るたびに3ずつ減ります（[切れても戻さない](#切れても戻さない)）。ラウンドを0にした消えない状態異常なら、ラウンドが終わるたびに減ります。

最初から入っている12個のうち、**麻痺・睡眠・石化**は`移動 = 0`を持っています。
行動できない状態なので、足も止まるという意味です。
付いているコマを持ち上げても[移動範囲](/manual/move-range)は出ません。
移動範囲はシートの「移動」を読むので、値が0なら動ける先が無いからです。

鈍足は覚え書きのままにしてあります。「移動が半分」は、`=`と`+`と`-`では書けないためです。

項目名は1語で書いてください。
状態異常は1行に空白区切りで書き出しているので、空白の入った項目名は読み戻せません。

アイコンは絵文字でも、部屋に取り込んだ画像でも構いません。
画像ボタンから選ぶと、コマの頭上のバッジも表の列見出しもその画像になります。

- ラウンドを0にすると「消えない」になります。数字を入れれば、その数だけ数えて自動で消えます
- 上下の矢印で並べ替えられます。この順番が表の列の並びになります
- 登録できるのは卓を編集できる人だけです。登録した内容は部屋の全員に共有されます

登録した名前を[インベントリの表示項目](/manual/inventory#簡略表示)に混ぜると、簡略表示の表にチェック欄の列が出ます。
チェックを入れると、そのコマにバフとして付きます。
シートにその項目を持たないキャラクターにも付けられるので、汎用のエネミーにも同じ手順で使えます。

付いたものは普通のバフで、区分はデバフです（[バフとデバフの区分](#バフとデバフの区分)）。
コマの頭上にバッジが出て、バフマネージャーのチャートにも並び、ラウンドを決めていれば自動で切れます。
登録を消しても、すでに付いているバフはそのまま残ります。

チャットやパレットの`&名前`でも、登録した名前なら同じものが付きます。
`t&転倒`のように名前だけを書くと、登録した色・アイコン・ラウンド・消失タイミング・効果メモと動かす項目が、そのまま付きます。
`&転倒/起き上がるまで/2`のように効果やラウンドを書いたときは、書いた値が使われます。
すでに付いているものに`&+`や`&++`で重ねるときは、ふつうのバフと同じ重ね方です。

## 卓全体のバフの一覧

FABメニューの**ゲームリソース**から**バフマネージャー**を開くと、卓にいる全員のバフが1枚のチャートに並びます。
コマごとにまとまり、バフ1つが1本のバーです。
バーは現在のラウンドから始まり、残っている数だけ右へ伸びるので、どれが先に切れるかがひと目で分かります。

色とアイコンはコマの頭上のバッジと同じものを使います。
手番で切れるバフには時計が付くので、ラウンドで減るものと見分けられます。

- **ズーム** — 右上の`−` `+`で1ラウンドの幅を変えられます。縮めれば長い戦闘を一望でき、広げればラウンドを1つずつ追えます
- **横スクロール** — チャートがパネルに収まらないときは横に流せます。左のコマ名とバフ名、上のラウンド見出しはその場に残ります
- **今に戻る** — 横に流したあと、現在のラウンドへボタン1つで戻ります

バーを押すと下が開いて、名前・効果・残ラウンド・消失タイミング・トリガーと削除が並びます。減るたびに動かす量を持つバフには、効果の発生タイミングも並びます。
ここで外したバフも、[ステータスを動かすバフ](#ステータスを動かすバフ)なら同じようにステータスが返ります。

いちばん下の **「自動計算バフの記法を作る」** を開くと、`&!`コマンドの組み立て欄が出ます。
項目を埋めていくと記法が組み上がり、そのバフがどう働くかも表示されるので、書式を覚えていなくても使えます。
欄の下にある**重ねがけ**にチェックを入れると`&+!`になり、同じバフに足す形の記法になります（[重ねがけ](#重ねがけ)）。
続けて**ラウンドも足す**にチェックを入れると`&++!`です。
操作が`=`のときは重ねても留める値は変わらないので、チェック欄自体が出ません。

## バフと値のリセット {#reset}

戦闘のあとなどに、コマに付いているバフをまとめて外し、シートの値を[既定値](/manual/data-element#既定値)へ戻せます。
バフの外し方は、すべて・バフだけ・デバフだけの3種類です。値を戻す操作は単独でも使え、バフをすべて外す操作と1つにまとめたものもあります。
GMとPLが使えます。見学は使えません。

| すること                           | チャット                   | コマの右クリック     |
| ---------------------------------- | -------------------------- | -------------------- |
| バフをすべて外す                   | `&*-`                      | **バフをすべて外す** |
| 区分がバフのものを外す             | `&*バフ-`（`&*buff-`）     | **バフだけ外す**     |
| 区分がデバフのものを外す           | `&*デバフ-`（`&*debuff-`） | **デバフだけ外す**   |
| 値を既定値に戻す                   | `:*=既定`                  | **値を既定値に戻す** |
| バフをすべて外し、値を既定値に戻す | `&リセット-`（`&reset-`）  | **すべてリセット**   |

### チャットからリセットする

```
&*-            発言者のコマのバフをすべて外す
&*デバフ-      発言者のコマのデバフだけ外す
t&*バフ-       ターゲットにしたコマのバフだけ外す
&リセット-     発言者のコマのバフをすべて外し、値を既定値に戻す
t&リセット-    ターゲットにしたコマをリセットする
```

- `&`で始めると発言者のコマ、`t&`で始めるとターゲットにしたコマが対象です。卓にいる全員を対象にする`&&`の形は、GMだけが使えます（[卓全体のバフをまとめて外す](#sweep)）
- 報告には`すべてのバフを解除（4件）`のように件数が出ます。バフの名前は出ません。外すものがないときは`解除するバフはありません`と出ます
- 先頭に`s`を付けると（`s&*-`）、報告を伏せます
- 値を戻す書き方と、項目を1つだけ戻す書き方は、[チャットの特殊記法](/manual/chat-syntax#バフと値のリセット)にあります

### コマの右クリックからリセットする

コマを**右クリック** → **バフ・演出**に、上の表の5つの項目が並びます。
そのコマに使っても何も変わらない項目は出ません。バフが1つもなく、値がすべて既定値のコマには、5つとも出ません。

項目を選ぶと、外すバフの件数と戻す項目の数を示した確認が出ます。
OKを押すと実行され、チャットに`[名前]リセットしました（バフ2件・値3項目）`のような行が流れます。
行が流れる先は、部屋設定の[システム通知の送り先](/manual/room-settings#システム通知の送り先)で「ラウンド・手番の進行」に選んだタブです。送り先を**送らない**にした部屋では、行は操作した本人の画面にだけ出ます。ほかの人の画面には出ません。[元に戻す](#リセットを元に戻す)は、この行からも使えます。

### 外れるバフと残るバフ

- 消えないバフも状態異常も外れます。[ステータスを動かすバフ](#ステータスを動かすバフ)は、ほかの外し方と同じく、動かした分を戻します
- [ふたり乗り](/manual/ride#ふたり乗り)で自動で付いたバフは、乗っているあいだは外れません
- [部位](/manual/ride#複数の部位を持つコマ)を持つコマは、本体をリセットすると部位も一緒にリセットされます。件数には部位の分も入り、報告は`すべてのバフを解除（本体と部位2・5件）`のようになります。本体と部位の両方をターゲットにしていても、部位を2回は数えません。部位を対象にしたときは、その部位だけがリセットされます
- バフを外してから値を戻します。1行に`:*=既定 &*-`の順で書いても、この順番です。ステータスを動かすバフは外れるときに動かした分を戻すので、値を先に戻すと、その分が既定値からもう一度動いてしまうためです

### リセットを元に戻す

リセットを報告した行には、リセットした本人の画面にだけ**元に戻す**のボタンが出ます。
押すと、外れたバフが付き直り、値がリセットの前の値に戻ります。

- 戻せるのは、その端末で最後に行った1回のリセットだけです。次のリセットをするか、ページを読み込み直すと、ボタンは消えます
- ボタンが出るのは、この節の操作と、[卓全体のバフをまとめて外す](#sweep)操作です。`&毒-`や`&D`のような外し方と、シートの`↺`には出ません
- リセットのあとでバフや値が変わったコマと、削除されたコマは戻しません。そのときは行に`2体を戻しました。1体は、そのあと変更されたため戻していません`のように出ます
- 戻すと、同じタブに`リセットを元に戻しました（2体）`と出ます
- [行動順](/manual/turn-order#バフの残ラウンドを自動で減らす)の**前へ**が戻すのはバフだけです。既定値へ戻した値は戻りません

## 卓全体のバフをまとめて外す（GM） {#sweep}

「消えない」にしたバフは時間では切れないので、戦闘が終わるたびに1つずつ外すことになります。
GMはこれを、条件を決めて卓にいる全員からまとめて外せます。条件は次の6つです。

| 条件                   | 外れるバフ                                                     | チャット                     |
| ---------------------- | -------------------------------------------------------------- | ---------------------------- |
| **消えないバフ**       | 消失タイミングが「消えない」のバフすべて                       | `&&none-`（`&&消えない-`）   |
| **残りラウンドで選ぶ** | 残りがちょうど指定したラウンドのバフ。消えないバフは含みません | `&&2R-`                      |
| **名前で選ぶ**         | 同じ名前のバフ                                                 | `&&毒-`                      |
| **すべて**             | すべてのバフ                                                   | `&&*-`                       |
| **バフだけ**           | [区分](#バフとデバフの区分)がバフのもの                        | `&&*バフ-`（`&&*buff-`）     |
| **デバフだけ**         | 区分がデバフのもの                                             | `&&*デバフ-`（`&&*debuff-`） |

バフマネージャーの**バフの一括解除（GM）** を開いて条件を選ぶと、何体の何件が対象かが出ます。
**卓全体から解除**を押し、確認でOKを押すと外れ、外した件数がチャットに流れます。
[ステータスを動かすバフ](#ステータスを動かすバフ)は、ほかの外し方と同じくステータスが戻ります。

**値も既定値に戻す**にチェックを入れると、バフを外したあとに、卓の上の全コマの[既定値](/manual/data-element#既定値)のある項目を戻します。
6つの条件のどれとも組み合わせられ、対象の表示は`3体・7件、値5項目が対象です`になります。
ここで数える項目は、いま既定値と違う項目です。バフが動かしている項目も数えるので、実行したあとの報告の項目数はこれより少ないことがあります。

チャットでは`&&`で始めて、最後に`-`を付けます。

```
&&none-        消えないバフを卓全体から外す（&&消えない- でも同じ）
&&2R-          残り 2R のバフを卓全体から外す
&&毒-          「毒」という名前のバフを卓全体から外す
&&*-           すべてのバフを卓全体から外す
&&*デバフ-     デバフだけを卓全体から外す
&&リセット-    すべてのバフを卓全体から外し、値を既定値に戻す（&&reset- でも同じ）
```

- 「すべて」「バフだけ」「デバフだけ」と`&&リセット-`は、コマを1体ずつ数えます。部位も1体です
- [ふたり乗り](/manual/ride#ふたり乗り)で自動で付いたバフは、6つの条件のどれで外しても、乗っているあいだは残ります。体数と件数にも入りません
- どの条件で外したときも、報告の行から[元に戻せます](#リセットを元に戻す)

GM以外が送っても何も外れず、GMだけが使える記法だとチャットに出ます。先頭に`s`を付けると結果を伏せて流せます。

## うまくいかないとき

| 見えるもの                                       | 原因と直しかた                                                                                                                                  |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 残りのラウンドが減らない                         | 消失タイミングが**消えない**か、部屋設定の**ラウンドが進むとバフの残りを減らす**が外れています（→ [部屋設定](/manual/room-settings)）           |
| 減るたびに動くはずの量が動かない                 | 砂時計で自動減少を切っているか、`発生:手番開始`・`発生:手番終了`を書いたバフを持つコマに手番が来ていません。行動順に入れるか、`発生:`を外します |
| 手番で切れるはずのバフが切れない                 | トリガーのキャラクターが、行動順に入っていないか、手番を持たない設定です。トリガーを選び直します                                                |
| ステータスを動かすバフを外したのに、値が戻らない | 手で値を書き換えていると、その分は戻りません。シートの値を確かめます                                                                            |
| コマの頭上にバフが出ない                         | **バフの表示**か、ツールバーのバフのボタンで隠しています（→ [PLツールバー](/manual/pl-tools#リソースバーとバフを隠す)）                         |
| `&&`の記法で外れない                             | まとめて外す記法は、GMだけが使えます                                                                                                            |
| **デバフだけ外す**で外れないバフがある           | そのバフの区分がバフです。バフ編集の行の選択欄でデバフにします（→ [バフとデバフの区分](#バフとデバフの区分)）                                   |

# バフ／デバフ

キャラクターに付く一時的な強化・弱体（バフ／デバフ）を管理します。

<Shot src="buff" alt="バフ編集パネル。毒と防御強化のバフが残ラウンド付きで並んでいる" width="560" caption="バフごとに名前・残ラウンド・タイミングを設定します" />

## バフ編集を開く

キャラクターコマを**右クリック** → **「バフ編集」** を選ぶと、バフ編集ビューが開きます。
バフが1つも無いときは「バフ・デバフは登録されていません」と表示されます。

## 追加・編集・削除

- **バフを追加** — 新しいバフ行を追加
- **名前** — バフ名（例: `猛攻撃`）を入力
- 効果やラウンド数などの値を編集
- **バフを削除**（ゴミ箱アイコン）— その行を削除
- **消失タイミングとトリガー** — 名前の下の行で、いつ切れるかを決めます（→ [いつ切れるかを決める](#いつ切れるかを決める)）
- **アイコンと色** — 名前の左にある丸いボタンを押すと、絵文字（☠️ 毒、🛡️ 防御、🔥 炎…）と**背景色**を選べます。ボタン自体がコマに出るバッジと同じ見た目なので、選びながら仕上がりが分かります。同じものをもう一度押すと既定に戻ります
- **画像をアイコンにする** — 絵文字の下の「画像から選ぶ」で、部屋に取り込んだ画像をバッジに使えます。バフマネージャーのチャートにも同じ画像が出ます

登録したバフは、テーブル上のコマの頭上に**丸いバッジ**として並びます。バッジは選んだ色の丸に絵文字を乗せたもので、**左上に強度・右下に残ラウンド**が重なります。強度は効果欄に書いた数値（`防+1`なら`+1`、`ダメージ2`なら`2`）を自動で拾います。バッジにポインタを乗せると、バフ名と効果の全文が出ます。

色は8色（赤・橙・黄・緑・青・紫・桃・灰）と既定の黒から選べます。強化は青、状態異常は赤、といった塗り分けをしておくと、コマを見ただけで卓の状況が読めます。

見せ方はコマを**右クリック** → **「バフの表示」** から選べます。**アイコン**（既定）、名前・効果・残ラウンドを並べる**詳細**、`バフ3個`とだけ出す**個数**の3つで、いま選ばれているものにはチェックが付きます。コマの上には操作するものを置いていないので、頭上の表示を触ってコマが動いてしまうことはありません。

## いつ切れるかを決める

バフ行の**消失タイミング**から、残ラウンドがいつ1減るかを選べます。

- **ラウンド終了時**（既定）— ラウンドが終わるたびに、卓の全員分がまとめて減ります
- **トリガーの手番開始時** — 指定したキャラクターの手番が回ってきたときに減ります
- **トリガーの手番終了時** — 指定したキャラクターの手番が終わったときに減ります
- **消えない** — 減りません。外すまで残ります

手番のどちらかを選ぶと、隣に**トリガーキャラクター**の選択欄が出ます。卓にいるコマから選ぶ形なので、
名前を打ち間違えて来ない手番を待ち続けることはありません。選んだ相手はコマそのものを指すため、
あとで改名しても外れません。

**空欄のままなら、そのバフを持っているコマ自身の手番**を待ちます。自分に掛けた呪文はこれで足ります。
術者の手番が回ってきたら切れる強化（ソードワールドの練技など）は、術者をトリガーに指定します。

手番に紐づいたバフは、ラウンド終了の一斉減少からは外れます。二重に減ることはありません。

**消えない**を選んだバフは、ラウンドが進んでも[リモコン](/manual/pl-tools)のラウンド操作でも減りません。
残ラウンドの数字もバッジから消えます。毒や麻痺のように、解除するまで続くものはこれにします。

## ステータスを動かすバフ

「命中+2」と書いただけのバフは、あくまで覚え書きです。実際に命中を上げるのも、切れたときに戻すのも
自分でやることになります。

チャットの`&!`記法を使うと、バフがステータスを**実際に動かし**、切れたときに動かした分を戻します。

```
&!猛攻撃/命中/+/2/3
```

左から、バフ名・ステータス名・操作・量・ラウンド数です。この1行で「猛攻撃」が付き、シートの命中が
2上がり、3ラウンド後に切れると2下がります。

戻すのは**実際に動いた分**です。シートの上限で頭打ちになって、`+30`のうち4しか動かなかったなら、
返るのも4です。掛けた値をそのまま引き算しないので、上限のある資源でもずれません。

- **操作** — `+`と`-`は増減、`=`はバフのあいだステータスをその値に留めます
- **ラウンド数** — 省略すると3ラウンドです
- **最大値を動かす** — ステータス名のうしろに`^`を付けます。`HP^`なら残量ではなく最大値が対象です
- **上限・下限そのものを動かす** — `HP_MAX`（最大値のベース）・`HP_MAX_BUFF`（その補正値）・`HP_MIN`・`HP_MIN_BUFF`も同じように書けます。リソース項目の詳細設定にある「最大値ベース／補正値」と同じ場所を指します
- **タイミングとトリガー** — 6つ目と7つ目に書けます（`&!練技/筋力/+/2/3/手番開始/術者`）

バフの消え方は、時間切れ・`&名前-`での削除・`&D`での一掃・[まとめて外す](#sweep)・ゴミ箱ですが、どれを通っても
ステータスは同じように返ります。同じバフをもう一度掛けたときは残ラウンドが振り出しに戻ります。足し込みたい
ときは[重ねがけ](#重ねがけ)を使います。

## 重ねがけ

`&猛攻撃/攻撃+2/3`を2回打つと、2回目が1回目を書き換えるので効果欄は`攻撃+2`のままです。同じ強化を
二重に受けたことにしたいなら、`&`のうしろに`+`を足して`&+猛攻撃/攻撃+2/3`と打ちます。効果欄の数値が
足し合わされ、`攻撃+4`になります。弱体を重ねるときは`&+猛攻撃/攻撃-1/3`のようにマイナスで書きます。

残ラウンドは**長いほうが残ります**。5Rのバフに2Rを重ねても5Rのままなので、短い重ねがけで先に切れて
しまうことはありません。ラウンド数を省略すれば、いま残っている数がそのまま続きます。消えないバフに重ねた
ときは、消えないままです。

持続そのものを伸ばしたいときは、`+`を2つ並べて`&++猛攻撃/攻撃+2/3`と打ちます。残2Rのバフに3Rを
重ねると5Rになります。効果欄を空にして`&++加護//3`と打てば、効果はそのままで3Rだけ延びるので、
「重ねがけは効かないが掛け直せば持続する」ルールもこれで書けます。

| 書き方               | 効果欄   | 残ラウンド |
| -------------------- | -------- | ---------- |
| `&猛攻撃/攻撃+2/3`   | 書き換え | 3Rに戻す   |
| `&+猛攻撃/攻撃+2/3`  | 足す     | 長いほう   |
| `&++猛攻撃/攻撃+2/3` | 足す     | 3R足す     |
| `&++猛攻撃//3`       | そのまま | 3R足す     |

足し算になるのは、効果欄が同じ言い回しで同じ数値を指しているときだけです。`攻撃+2`に`防御+1`を重ねても
意味の通る答えは作れないので、その場合はこれまでどおり新しいほうで書き換えます。

`&+!`と書けば、[ステータスを動かすバフ](#ステータスを動かすバフ)も重ねられます。`&+!猛攻撃/命中/+/2/3`を
2回打つと命中は4上がり、バフを外すと4戻ります。ただし`=`（その値に留める）だけは、二度留めても留め先が
変わらないので掛け直しになります。

リモートコントローラのバフ欄からも重ねられます。バフ名の前に`+`を付けて`+猛攻撃 攻撃+2 3`と打つと、
選んだコマ全員の「猛攻撃」に足されます。`++猛攻撃 攻撃+2 3`なら残ラウンドも延びます。

## リモコンとチャットから付ける

同じ見た目の指定は、バフ編集を開かなくてもできます。

- **リモートコントローラ** — バフ欄の入力は`バフ名 効果 ラウンド数 色 アイコン`の空白区切りです。入力欄の上に並ぶ**色の丸**を押しておけば、色を打たなくてもその色で付きます。バフ名の前に`+`を付けると[重ねがけ](#重ねがけ)、`++`なら残ラウンドも延びます
- **チャット** — `&毒/継続2/3/red/☠️`のように、4つ目以降に色と絵文字を書けます。順番は入れ替えてもかまいません

色の書き方は`red` `blue`などの英名、`赤` `青`などの和名、`#c62828`のような16進のいずれでも通ります。`既定`と書くと黒に戻ります。

消失タイミングとトリガーも、色やアイコンと同じ位置に順不同で書けます。タイミングは`手番開始` `手番終了`
`ラウンド終了`（`turnStart`などの英名も可）、トリガーは`@名前`です。

```
&練技/筋力+2/3/blue/💪/手番開始/@術者
```

チャット記法の詳細は[チャットの特殊記法](/manual/chat-syntax#バフ-デバフ操作)を参照してください。

## 残ラウンドは自動で減ります

[行動順](/manual/turn-order#バフの残ラウンドを自動で減らす)でラウンドを進めると、残ラウンドが1減り、
0になったバフは自動で消えてチャットに通知されます。自動減少は行動順の砂時計アイコンで切り替えられます。

手番タイミングのバフは、ラウンドではなく手番の切り替わりで減ります。どちらの場合も、0になれば同じように
消えて通知が流れます。

## 状態異常を登録して表から付ける

毒・麻痺・気絶のように何度も使うものは、部屋ごとに登録しておけます。FABメニューの**ゲームリソース**、バフマネージャーの右上、
[インベントリ](/manual/inventory#検索と表示設定は別のパネル)の絞り込みパネルのどれからでも**状態異常**のパネルを開けます。

新しい部屋には、毒・出血・燃焼・麻痺・睡眠・石化・混乱・魅了・恐怖・暗闇・沈黙・鈍足の12個が最初から
入っています。どのルールにも寄せていない見本なので、卓に合わせて書き換えて使ってください。ラウンドで
消えるもの・解除するまで続くもの・手番の開始や終了で減るものが一通り揃えてあります。
消したり書き換えたりした部屋には配り直されません。

1件ずつ、名前・色・アイコン・ラウンド・消失タイミング・効果メモを決めます。名前にスペースは使えません。
表示項目として名前で呼び出すためです。

### シートの値を動かす状態異常

効果メモは覚え書きなので、書いただけでは何も動きません。**動かす項目**に項目名を書くと、その状態異常が
[ステータスを動かすバフ](#ステータスを動かすバフ)になります。付いているあいだシートの値が動き、外すと
動いた分だけ戻ります。動かし方は`=`（その値に留める）・`+`・`-`から選びます。

最初から入っている12個のうち、**麻痺・睡眠・石化**は`移動 = 0`を持っています。行動できない状態なので、
足も止まるという意味です。付いているコマを持ち上げても[移動範囲](/manual/move-range)は出ません。
移動範囲はシートの「移動」を読むので、値が0なら動ける先が無いからです。

鈍足は覚え書きのままにしてあります。「移動が半分」は、`=`と`+`と`-`では書けないためです。

項目名は1語で書いてください。状態異常は1行に空白区切りで書き出しているので、空白の入った項目名は
読み戻せません。

アイコンは絵文字でも、部屋に取り込んだ画像でも構いません。画像ボタンから選ぶと、コマの頭上のバッジも
表の列見出しもその画像になります。

- **ラウンドを0にすると「消えない」** になります。数字を入れれば、その数だけ数えて自動で消えます
- 上下の矢印で並べ替えられます。この順番が表の列の並びになります
- 登録できるのは卓を編集できる人だけです。登録した内容は部屋の全員に共有されます

登録した名前を[インベントリの表示項目](/manual/inventory#簡略表示は1体1行の表)に混ぜると、簡略表示の表に
チェック欄の列が出ます。**チェックを入れると、そのコマにバフとして付きます。** シートにその項目を持たない
キャラクターにも付けられるので、汎用のエネミーにも同じ手順で使えます。

付いたものは普通のバフです。コマの頭上にバッジが出て、バフマネージャーのチャートにも並び、ラウンドを
決めていれば自動で切れます。登録簿から消しても、すでに付いているバフはそのまま残ります。

## 卓じゅうのバフを一覧する

FABメニューの**ゲームリソース**から**バフマネージャー**を開くと、卓にいる全員のバフが1枚のチャートに
並びます。コマごとにまとまり、バフ1つが1本のバーです。バーは現在のラウンドから始まり、残っている数
だけ右へ伸びるので、**どれが先に切れるか**がひと目で分かります。

色とアイコンはコマの頭上のバッジと同じものを使います。手番で切れるバフには時計が付くので、ラウンドで
減るものと見分けられます。

- **ズーム** — 右上の`−` `+`で1ラウンドの幅を変えられます。縮めれば長い戦闘を一望でき、広げれば
  ラウンドを1つずつ追えます
- **横スクロール** — チャートがパネルに収まらないときは横に流せます。左のコマ名とバフ名、上のラウンド
  見出しはその場に残ります
- **今に戻る** — 横に流したあと、現在のラウンドへボタン1つで戻ります

バーを押すと下が開いて、名前・効果・残ラウンド・消失タイミング・トリガーと削除が並びます。ここで外した
バフも、[ステータスを動かすバフ](#ステータスを動かすバフ)なら同じようにステータスが返ります。

いちばん下の **「自動計算バフの記法を作る」** を開くと、`&!`コマンドの組み立て欄が出ます。項目を埋めて
いくと記法が組み上がり、そのバフがどう働くかも表示されるので、書式を覚えていなくても使えます。
欄の下にある**重ねがけ**にチェックを入れると`&+!`になり、同じバフに足す形の記法になります（[重ねがけ](#重ねがけ)）。
続けて**ラウンドも足す**にチェックを入れると`&++!`です。操作が`=`のときは重ねても留め先が変わらないので、
チェック欄自体が出ません。

## 卓じゅうのバフをまとめて外す（GM） {#sweep}

「消えない」にしたバフは時間では切れないので、戦闘が終わるたびに1つずつ外すことになります。
GMはこれを、条件を決めて卓にいる全員からまとめて外せます。

- **消えないバフ** — 消失タイミングが「消えない」のバフすべて
- **残りラウンド** — 残りがちょうど指定したラウンドのバフ。消えないバフは含みません
- **名前** — 同じ名前のバフを全員から

バフマネージャーの**バフの一括解除（GM）** を開いて条件を選ぶと、何体の何件が対象かが出ます。
**卓全体から解除**を押し、確認でOKを押すと外れ、外した件数がチャットに流れます。
[ステータスを動かすバフ](#ステータスを動かすバフ)は、ほかの外し方と同じくステータスが戻ります。

チャットでは`&&`で始めて、最後に`-`を付けます。

```
&&none-      消えないバフを卓全体から外す（&&消えない- でも同じ）
&&2R-        残り 2R のバフを卓全体から外す
&&毒-        「毒」という名前のバフを卓全体から外す
```

GM以外が送っても何も外れず、GMだけが使える記法だとチャットに出ます。先頭に`s`を付けると結果を伏せて流せます。

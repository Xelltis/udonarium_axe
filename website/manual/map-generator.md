# マップ生成

このページはダンジョンやフィールドのテーブルを、ボタン1つで組み立てるマップ生成を説明します。
壁や木立は地形として置かれるので、生成した直後から、視線も光も地形どおりに通ります。
セッションの準備や、その場で次の場面を作るときに使います。
使えるのはGMだけです。

## 開く

FABメニューの**テーブル関連**を押し、**マップ生成**を押します。
GMでないときに開くと、「このツールはゲームマスター専用です」と出ます。

## 生成する

<Shot src="map-generator" alt="マップ生成のパネルの下側。マスの形・シード・テーブル名・扉を置くなどのチェックの下に、部屋と通路のプレビューと「地形 74 個・同期 約 888 件」の見積もり、生成するのボタンがある" width="420" caption="プレビューと見積もりを確かめてから生成します" />

1. **種類**で、**ダンジョン**か**フィールド**を選びます。
2. **マスの形**で、**四角**・**ヘクス（縦）**・**ヘクス（横）** のどれかを選びます。
3. **雰囲気**と素材を選び、部屋数や広さを決めます（→ [設定の一覧](#settings)）。
4. **テーブル名**を入れます。空のままでもかまいません。
5. プレビューと見積もり（「地形 N 個・同期 約 N 件」）を確かめて、**生成する**を押します。

「（テーブル名）を作成しました」と出れば、新しいテーブルができています。
生成しても、いま見ているテーブルは切り替わりません。
セッション中に次の場面を用意しても、プレイヤーが飛ばされずに済みます。
できたテーブルへはパネルの**このテーブルへ移動**で移ります。
要らなければ、**このテーブルを削除**で消せます。

::: warning 生成し直すと、前のテーブルは消えます
同じパネルからもう一度生成すると、新しいテーブルができたあとで、前に作ったテーブルを消します。
全員が前のテーブルを見ていたときは、新しいテーブルへ移ります。
残しておきたいときは、パネルを閉じて開き直してから生成してください。パネルが消すのは、開いてから作ったテーブルだけです。
:::

## 設定の一覧 {#settings}

| -------------------------------------- | ------------------------------------------ | ------------------ |
| 種類                                   | ダンジョン・フィールド                     | ダンジョン         |
| マスの形                               | 四角・ヘクス（縦）・ヘクス（横）           | 四角               |
| 雰囲気（ダンジョン）                   | 12種類（→ [雰囲気](#雰囲気)）              | 石造迷宮           |
| 雰囲気（フィールド）                   | 14種類（→ [雰囲気](#雰囲気-1)）            | 森林               |
| 部屋数（ダンジョン）                   | 3〜20                                      | 8                  |
| 壁の高さ（ダンジョン）                 | 0.5〜6マス                                 | 雰囲気の既定       |
| 通路の幅・扉の幅                       | 最小と最大を1〜4マス                       | 雰囲気の既定       |
| 両開きの割合                           | 0〜100%                                    | 雰囲気の既定       |
| 入口                                   | 階段（地下へ降りる）・坑道口（外へ通じる） | 雰囲気の既定       |
| 扉を置く                               | 入り・切り                                 | 入り               |
| 入口と出口を置く                       | 入り・切り                                 | 入り               |
| 壁を登れなくする                       | 入り・切り                                 | 切り               |
| 罠                                     | 0から                                      | 0                  |
| 戦場の霧をかけた状態にする             | 入り・切り                                 | 切り               |
| 入口に集めるパーティ                   | パーティ・集めない                         | 集めない           |
| マップの広さ（フィールド）             | 20〜60マス（縦は横の3/4）                  | 40                 |
| 茂みの多さ（フィールド）               | 0〜100%                                    | 50%                |
| 地面の起伏（フィールド）               | 0〜6マス（0.5刻み）                        | 2                  |
| 壁素材・床素材・障害物の素材・地面素材 | 同梱のテクスチャか、画像保管庫の画像       | 雰囲気の既定       |
| シード                                 | 数                                         | 開くたびにランダム |
| 灯りの動き                             | 雰囲気どおり・なし・ゆらめき・明滅         | 雰囲気どおり       |

雰囲気の既定に従う設定は、手で動かすと、そこで固定されます。
素材は**既定に戻す**で、雰囲気の既定に戻せます。

灯りの動きは生成する明かり（松明・ランタン・焚き火・ネオン管など）の動き方を揃えます。雰囲気どおりは明かりの種類ごとの動きで、ほとんどがゆらめきです。ちらつきが気になるときは「なし」にします。選んだ値はこのブラウザに残り、次に開いたときもその値から始まります。生成したあとの明かりは光源ごとの設定で変えられます。

## シードと振り直し

シードが同じなら、同じ形が出ます。
気に入った盤面の番号を控えておけば、あとから同じものを作り直せます。
別の形にしたいときは、シードの欄の**シードを振り直す**（サイコロのボタン）を押します。

## プレビューと上限

生成する前に、置かれるものの形と地形の個数が出ます。数が多いほど同期と視界計算が重くなるため、上限を設けています。

| 地形の個数    | 出るもの                                                                              |
| ------------- | ------------------------------------------------------------------------------------- |
| 200個を超える | 「地形が 200 個を超えています。生成に少し時間がかかります」                           |
| 400個を超える | 「地形が 400 個を超えます。部屋数を減らしてください」。**生成する**が押せなくなります |

部屋数や広さを減らすか、雰囲気を変えると数が下がります。

## マスの形

四角のほかに、**ヘクス（縦）** と **ヘクス（横）** でも生成できます。

ヘクスを選ぶと、盤面はひと回り小さくなります。四角のマスは隣り合うものをまとめて1つの地形にできますが、ヘクスは長方形に並ばないため、1マスにつき1つの地形を置くことになるからです。同じ広さのままではテーブルで扱いきれない数になるので、一辺を四分の一詰めています。

プレビューもヘクスの並びで描かれるので、生成前に実際の形を確かめられます。

## ダンジョン

### 雰囲気

石造迷宮 / 地下墓所 / 遺跡 / 洞窟 / 溶岩洞 / 氷窟 / 砂の墳墓 / 違法BAR / 廃ビル / コンテナ倉庫 / 下水道 / 魔術師の塔。

雰囲気は見た目だけでなく、間取りの作り方・暗闇の深さ・環境光・グリッド表示まで決めます。洞窟系は部屋と通路ではなくセルオートマトンで掘るため、要求した部屋数より少なくなることがあります。

### 家具のある場所

違法BAR・廃ビル・コンテナ倉庫・下水道・魔術師の塔の5つは、部屋に家具が入ります。扉の造り・照明・部屋の呼び名もその場所のものになります。

<Shot src="dungeon-bar" alt="暗い違法BARを斜め上から見たところ。真ん中の酒場に光の筋の入った長いバーカウンターがあり、壁にカクテルグラスのネオン看板が光っている。左の部屋に赤いボックス席、右下の部屋にアーケード筐体がある" caption="違法BARの酒場。ネオン看板と画面は暗い中でも光ります" />

- **違法BAR** — 階段を下りた先が「表の店」で、売り台・商品棚・自販機・木箱があります。表の店から奥へ抜ける扉は、壁と同じ見た目の**隠し扉**です。
  テーブルには「隠し扉」という名前で置かれ、GM用の概要には部屋ごとの隠し扉の数が出ます。奥の「酒場」には酒棚を背にしたバーカウンターとスツール、
  ネオン看板を掛けたボックス席、丸テーブル、ジュークボックスが入ります。「賭場」には真ん中のルーレット台と賭博台とスロット台、
  「密造酒の貯蔵庫」には樽と木箱の山と蒸留器があります。小部屋は「ラウンジ」（ボックス席とローテーブル）と「ゲーム部屋」（アーケード筐体）に順に分かれます。
  最奥は施錠された「元締めの部屋」で、大机・水槽・金庫があります。壁は暗いレンガ、床は黒いテラゾーです。
  扉は横に滑る鉄扉、照明は壁のネオン管で、赤く薄暗い光です。ルーレットの輪は回り、ネオン看板と画面は暗い中でも光ります
- **廃ビル** — 柱が格子に並ぶ「オフィスフロア」、向きのずれた事務机、天井が落ちた瓦礫。部屋は金庫室・役員室・物置・事務室と呼ばれます
- **コンテナ倉庫** — 「搬入口」から入ります。「中央倉庫」などの広い部屋には赤・青・緑のコンテナが通路をあけて列になり、
  一部は2段に積まれます。扉は巻き上げ式のシャッター、壁の照明は蛍光灯です
- **下水道** — 「点検口」から入ります。「ポンプ室」と「作業室」には、壁に沿って配管が1本につながって走り、ところどころにバルブが付きます。「密輸品の隠し場」の木箱とあちこちの樽は、部屋の隅に寄せて積まれます。
  扉は上へ開く鉄格子、壁の照明はランタンです。通路と部屋には水が流れます（→ [下水道の水](#下水道の水)）
- **魔術師の塔** — 円い塔の1階分です（→ [魔術師の塔](#魔術師の塔)）。入口の「螺旋階段の間」には燭台とガーゴイルが立ちます。
  「召喚の間」の床には光って回る魔法陣が描かれ、「秘宝庫」には浮いて回る水晶の台と宝箱が置かれます。最奥の「魔術師の書斎」には書き物机と本棚と書見台、
  行き止まりの「素材庫」には壺と薬棚があります。小部屋は「書庫」「錬金術の工房」「天文台」「寝室」に順に分かれ、本棚、大釜と錬金台、輪の回る天球儀と望遠鏡、
  天蓋の寝台と衣装棚が入ります。扉は木の扉で、壁の燭台が紫・水色・橙に灯ります

家具はまわりの床が空いている場所にだけ置きます。扉の前と出入り口には置かないので、床はどこからでも歩いて行き来できます。
棚や看板のように壁際に置く家具は、背を壁に付けて部屋の内側を向きます。
入口に集めるパーティを家具の上に立たせることも、家具のある場所に明かりを置くこともありません。ヘクスのテーブルでは家具を
1マスずつ組み、コンテナは積みません。寝台・ルーレット台・魔法陣のように数マスで1つの家具は、3Dモデルで置けばヘクスでも1つの地形になります。
家具も1つずつ地形として数えるので、[上限](#プレビューと上限)に近づきやすくなります。

### 下水道の水

<Shot src="sewer" alt="レンガの壁の下水道。通路の中央を暗い水が流れ、両脇が歩道になっている。奥の部屋は集水槽で、左右の壁の排水管から水が落ちている" caption="通路の中央が水路、部屋が集水槽になります。壁の排水管から水が落ちます" />

下水道では、通路の中央に水路が通り、両脇が歩道になります。水路は部屋の集水槽へ向かって流れます。

- **水路** — 3マス幅の通路の、中央の1マスです。歩道より低く掘ってあり、流れ出る手前の3マスはさらに深くなっていて、水が堰を越えて落ちます
- **集水槽** — 「集水槽」と「沈殿槽」の部屋は、壁沿いの1マスを縁に残して水が溜まります。その部屋がない小さな盤では、入口も出口もない部屋のうち最も広い1つが集水槽になります
- **排水管** — 集水槽の長い2辺の壁に1本ずつ立ち、口から集水槽へ水が落ちます。「家具・木箱・コンテナを3Dモデルで置く」を切ると、排水管は箱で置かれ、水は落ちません
- **汚水** — 水のマスは、入ると移動コストが1増えます。手番の始めに水の中にいるコマは、1d6のダメージと状態異常「毒」を受けます。「汚水」という名前の、全員に見える仕掛けとして置かれるので、量や状態異常はテーブルの上で変えられます

入口・出口とその周りは水になりません。水が床を切り離すところには渡れるマスが残るので、どの部屋にも水に入らずに歩いて行けます。

通路の幅を1〜2マスにすると、歩道を残せないので水路はできません。集水槽と排水管は置かれます。

地面の起伏を知らない古い版の画面では、床は平らなままで、水は床の上に乗って見えます。落ちる水は描かれません。

### 魔術師の塔

<Shot src="wizard-tower" alt="ヘクスのテーブルに作った魔術師の塔を斜め上から見たところ。石壁の部屋の板の床に、紫と水色に光る魔法陣が描かれている。隣の秘宝庫には宝箱と水晶の台がある" caption="召喚の間の魔法陣は光って回ります" />

魔術師の塔では、盤の真ん中に円い階を掘ります。円の外には何も置かれず、テーブルの地面がそのまま見えます。
円の縁に残った壁が塔の外壁になります。ヘクスのテーブルでも円になります。

盤は正方形です。円の外を使わないぶん、同じ部屋数のほかの雰囲気より盤が広くなります。

### 部屋数と壁の高さ

- **部屋数** — 3〜20。盤面の広さはここから決まります
- **壁の高さ** — 0.5〜6マス。雰囲気の既定に追随し、手で動かすとそこで固定されます

### 通路の幅

**最小**と**最大**を1〜4マスで決めます。既定は雰囲気に追随し、どちらも同じ値です（石造迷宮などの部屋と通路は1マス、洞窟系とコンテナ倉庫は2マス、下水道は3マス）。

1マスの通路は紙のダンジョンでよく見る幅ですが、[近接状態](/manual/move-range#engagement)を使う卓や、3マス幅のコマを歩かせるテーブルでは狭すぎます。広げると、迷路を刻む格子ごと大きくなります。

- 最小と最大を離すと、通路ごとに幅が変わります。1〜4なら狭い抜け道も広い大通りも出ます
- 壁の厚みは1マスのまま。広がるのは通路だけです
- 格子は**最大**の幅で刻みます。部屋の一辺もそれに合わせて丸められ、最大4なら4マスか9マスといった刻みです
- 盤面の上限は変わらないので、最大を広げるほど置ける部屋は減ります

洞窟系に格子はありません。こちらでは掘る筆の太さとして使われ、通路1本ごとに幅が決まります。

### 戦場の霧とパーティ

- **戦場の霧をかけた状態にする** — 生成したテーブルを最初から霧で覆います。誰も歩いていないダンジョンは、白紙の地図がいちばん似合う場所です
- **入口に集めるパーティ** — 選んだ[パーティ](/manual/party)のコマを、入口の近くのマスに1体ずつ並べます

パーティのコマは、どこに置かれていても、テーブルの床に出てきます。入口は、外壁を破った坑道口があればそこ、なければ階段の部屋です。扉のマスには立たせません。メンバーが乗っている乗り物や、メンバーが部位になっている本体は、乗り物や本体ごと入口に来ます。メンバーの部位、乗せているコマ、つかんでいるコマも一緒に来ます。パーティの外のコマにつかまれているメンバーは、放されて入口に来ます。そのほかのコマは動かしません。

### 入口

- **階段（地下へ降りる）** — 地下2階から先を想定
- **坑道口（外へ通じる）** — 外壁を1か所だけ破って通路網につなぐ。トンネルの入口や山肌の洞窟にあたる

雰囲気ごとに既定があります（石造迷宮・地下墓所・砂の墳墓・違法BAR・廃ビル・下水道・魔術師の塔は階段、遺跡と洞窟系とコンテナ倉庫は坑道口）。下水道の階段ははしごの絵で、魔術師の塔の階段は螺旋階段の絵で置かれます。

### 扉と鍵

扉は通路を塞ぐ薄い板として立ち、視線を遮ります。開き方は右クリックから選べます。

最奥の部屋は壁の開口をすべて閉じて施錠し、鍵は最奥を通らずに歩いて行ける部屋へ置かれます。1か所でも開いていれば回り込めてしまうため、扉の枚数ではなく壁の穴を数えて閉じています。洞窟系は扉を持たないので施錠もしません。

### 扉の幅と両開き

扉の幅は**最小**と**最大**を1〜4マスで決めます。既定はどちらも1マスで、紙のダンジョンに描かれる扉と同じ大きさです。

2マス以上にすると、扉が入るぶんだけ入口の壁を削ります。通路のほうが狭いときは扉の手前も1マス掘り、そこが敷居になります。通路が1マスでも、壁に余地があれば入口だけを4マスに広げられます。

**両開きの割合**は0〜100%です。両開きに当たった扉は幅を半分に割った2枚になります。幅4なら2マスの扉が2枚、幅2なら1マスの扉が2枚になります。1マスと3マスは半分に割れないので1枚のままです。両開きを引いた扉は偶数の幅から選ばれるため、割合を上げるほど2マスと4マスの扉が増えます。

- 入口のほうが扉より広いとき（部屋の壁沿いに通路が走っている場合など）は、扉を横に並べて塞ぎます
- 扉の両端は必ず壁の中に収まります。壁を端まで削り切ってしまう場所では、収まる幅までしか広げません
- 施錠された最奥の部屋でも入口は広がり、広がった分まで施錠されます。鍵を持たずに回り込める穴は開きません
- 扉1枚が地形1個です。両開きは2個になるので、広げるほど地形の個数は増えます

### 壁を登れなくする

生成パネルの**壁を登れなくする**を入れると、できあがる壁と扉が[登れない地形](/manual/terrain#登れない地形)になります。既定は切です。

高さを持つ壁の上へコマが乗らなくなり、[移動範囲](/manual/move-range)でも越えられません。石壁で仕切られた場所として遊ぶための設定です。

- 階段は対象外です。登るためのものなので、そのままです
- 扉は開けば通れます。閉じているあいだだけ壁と同じです

### 罠を仕掛ける

生成パネルの**罠**に数を入れると、その数だけ罠が部屋と通路に仕掛けられます。既定は0で、何も置かれません。

置かれるのは[イベント塗り](/manual/map-editor#イベント塗り)と同じ「踏むと起きる地面」で、GMの画面にだけ点線で出ます。部屋には落とし穴と爆発の紋章、通路には毒針・刃の罠・警報線が置かれます。数マス以内に2つは置きません。固まって並ぶと、通路が罠だらけの地雷原になってしまうからです。

パーティが入ってくる最初の部屋と、階段の足元には置きません。まだ動いていないコマの足元にある罠は、誰かが選んで踏んだものにならないためです。

仕掛けられた罠はGM用の概要の末尾に座標つきで並びます。中身を書き換えたいときは、マップエディターにこのテーブルを取り込んでください。**event**という名前のレイヤーとして戻ってくるので、ダメージも判定もそこで直せます。

### 溶岩だまり

溶岩洞の溶岩だまりは、これまで赤い床の絵でした。いまは渡るのに2マスぶん余計にかかり、その中で手番を迎えたコマの`HP`を2d6削ります。溶岩のゆらぎも上に乗ります。フィールドの毒の沼のほうは、足を取るだけで傷は付きません。

置かれるのは[危険地帯塗り](/manual/map-editor#危険地帯塗り)と同じ3つの部品なので、削る量も見た目もテーブルの上で直せます。

### 部屋の役割とGM用の概要

入口の間 / 大広間 / 宝物庫 / 最奥 / 行き止まり / 小部屋の役割が割り当てられます。違法BAR・廃ビル・コンテナ倉庫・下水道・魔術師の塔では、
同じ役割がその場所の呼び名で出ます（違法BARなら表の店 / 酒場 / 賭場 / 元締めの部屋 / 密造酒の貯蔵庫）。
違法BARと魔術師の塔の小部屋は、部屋ごとに順に呼び名が変わります（違法BARはラウンジ / ゲーム部屋、魔術師の塔は書庫 / 錬金術の工房 / 天文台 / 寝室）。

部屋番号・寸法・接続・施錠・鍵の在り処・松明の位置は、生成パネルの中に一覧で出ます。コピーしてメモ帳やチャットへ貼れます。盤の上には置きません。共有メモはテーブルに属さず、全部のテーブルに残ってしまうためです。

## フィールド

### 雰囲気

森林 / 草原 / 海岸 / 湿地 / 雪原 / 荒野 / ビル群 / ビル群(SF) / スラム街 / ゴミ処理場 / 農村 / 蛮族の砦 / 石造りの砦 / 城下町。地面の帯・生えるもの・天候・明るさが決まります（湿地は霧と薄暗がり、雪原は吹雪、荒野は砂塵）。

農村と2つの砦には家や畑や壁が、城下町には城壁と通りと店が並びます（→ [村と砦](#村と砦)、[城下町](#城下町)）。

ビル群からゴミ処理場までの4つは市街です。地形の起伏は使わず、道路で盤面を街区に切り、歩道で囲み、街区を区画に分けて、
空き地にしない区画に建物を建てます。

- **ビル群** — 1本の碁盤の目で切るので大通りがまっすぐ通ります。中央ほど高いビルが建ち、高層ビルの足元には基壇、
  屋上には給水塔、ところどころに植え込みの広場。夕暮れで、歩道に街灯がともります
- **ビル群(SF)** — 同じ街の100年後、雨の夜です。光の帯が走る黒ガラスと、継ぎ目の光る白パネルの塔。道路は金属舗装、
  広場は光り、歩道にはシアンとマゼンタのネオンの街灯が立ちます
- **スラム街** — レンガとブラウンストーンの長屋が街区の外周に通りを向いて並び、街区の中央は中庭になります。非常階段、
  屋上の木の給水タンク、街路樹、街灯、ときどき角でドラム缶の焚き火。奥行きの浅い街区は背中合わせの2列にして、
  どの家も表が通りに面します
- **ゴミ処理場** — 街区の列ごとに別々に切るので、路地が曲がりくねって妙な所で出会います。トタンの低いバラックが斜めに
  傾いて建ち、路地には水たまりと廃材の山、雨の中で人が集まるドラム缶の焚き火

### 広さと茂みの多さ

- **マップの広さ** — 20〜60マス（縦は横の3/4）
- **茂みの多さ** — 0〜100%。0なら地面だけの更地になります。市街では建物の建て込み具合です。50%で雰囲気の既定の
  割合の区画に建ち、0%ではその半分、100%ではほぼすべての区画に建ちます（市街は0%でも更地になりません）。
  村と砦と城下町では、家・畑・置かれる物の多さです

### 地面の起伏

**地面の起伏（マス）** は0〜6マスを0.5刻みで選びます。既定は2マスで、0にすると平らな地面になります。
いちばん低い所がテーブルの高さ、いちばん高い所が選んだ高さになるように、地面を盛ります。
市街では使わないので、市街の雰囲気を選んでいるあいだは欄が出ません。

農村と砦と城下町では、敷地を1つの高さにならしてから、まわりを盛ります（→ [村と砦の地面](#村と砦の地面)）。

### 村と砦

農村・蛮族の砦・石造りの砦・城下町の4つは、道と建物と壁を先に割り付けます。シードが同じなら、同じ形になります。

- **農村** — 少しずつ曲がる幅2マスの道に沿って、木の壁の家が並びます。家は扉を道に向け、前にランタンが置かれます。
  納屋と干し草を持つ家もあります。空いた所は畑になり、野菜・麦・とうもろこしの畑は柵で囲まれ、稲は水田になります。
  道ばたには井戸と荷車が置かれます。村を小川が横切り、岸に水車小屋が、空いた所に風車が立ちます
  （→ [小川・水車小屋・風車](#小川・水車小屋・風車)）
- **蛮族の砦** — 中央を丸太の柵が楕円に囲み、南に両開きの門が付きます。柵には見張り塔が立ちます。
  内側には族長の館、大きな焚き火を囲む天幕、トーテムがあり、門から盤面の端へ小道が通ります
- **石造りの砦** — 中央を四角い石垣が囲み、四隅と南の門の両脇に塔が立ちます。門は上へ開く鉄格子です。
  石畳の中庭の奥に天守、壁沿いに兵舎と厩舎があり、門から盤面の端へ道が通ります
- **城下町** — 盤の上の端を城壁が走り、真ん中の門から大通りが下へ通ります。通りの交わる所が噴水の広場で、まわりに店と家が建ちます
  （→ [城下町](#城下町)）

建物は中が部屋に仕切られ、部屋ごとに扉が付くので、コマを中に入れられます。
柵は視線を通し、登って越えられます。そのほかの壁は視線を遮り、登れません。
麦・とうもろこし・稲の畑は渡るのに1マスぶん余計にかかります。野菜の畑はふつうに歩けます。

### 小川・水車小屋・風車

<Shot src="village-mills" alt="農村を上から見たところ。家と畑のあいだを小川が流れ、道の所は橋になっている。小川の岸に水車小屋が、道ばたに風車が立っている" caption="農村には小川が流れ、水車小屋と風車が立ちます。羽根と輪は回ります" />

農村には、流れる小川が1本、盤面の上の端から下の端まで通ります。家・畑・庭を避けて曲がり、道とぶつかる所は橋になって、道のマスがそのまま残ります。

- **小川** — 幅1マスで、地面を半マス掘って流れます。入ると移動コストが1増えます。ダメージや状態異常はありません
- **水車小屋** — 小川がまっすぐ流れる所の岸に1棟立ちます。3×2マスで、輪は小川の中で、流れる向きに回ります。中には入れず、視線を遮ります
- **風車** — 空いた所に1基立ちます。3×3マスで、羽根は道のほうを向いて回ります。中には入れず、視線を遮ります

道・家・畑の並びは、小川や風車があってもなくても同じです。家や畑が詰まっていて小川の通り道がない村には、小川と水車小屋は置かれません。風車も、置ける空きがなければ立ちません。

羽根と輪が回るのは、「木・岩・サボテン・廃材を3Dモデルで置く」を入れているときです。切ると風車と水車小屋は箱で置かれ、回りません。演出を減らす設定にしている席では、羽根と輪は止まって見えます。

### 城下町

<Shot src="castle-town" alt="城下町の広場を斜め上から見たところ。石畳の広場の真ん中に噴水があり、縁に縞の屋根の露店と街灯とベンチが並ぶ。手前と奥に木組みの家が建っている" caption="城下町の広場。噴水を露店と街灯が囲みます" />

城下町は盤の外の北にある城の足元の町です。盤の上の端を城壁が走り、真ん中の門の両脇に塔が立ちます。城壁には旗が掛かります。

- **通り** — 門から大通りが盤の下の端まで通り、横の通りと交わります。広い盤では、大通りの両脇に小路も通ります。通りは石畳です
- **広場** — 大通りと横の通りの交わる所が、大きな敷石の広場になります。真ん中に噴水があり、縁には果物・布・壺の露店とベンチと花の箱と街灯が並びます
- **建物** — 衛兵の詰所・教会・宿屋・酒場・鍛冶屋・パン屋・雑貨屋が1つずつ建ち（狭い盤では入りきらない建物もあります）、残りの区画は民家と空き地です。教会と詰所は石の壁、ほかは木組みの壁です。
  門にいちばん近いのが詰所で、教会と宿屋と酒場は広場の近くに建ちます
- **部屋と家具** — どの建物も中が部屋に仕切られ、部屋ごとに扉が付きます。部屋には建物の種類に合った家具が入ります。
  宿屋の食堂と酒場にはカウンターと暖炉とテーブル、宿屋の客室には寝台、鍛冶屋には鍛冶炉と金床と武器掛け、パン屋にはパン窯と粉袋、雑貨屋には売り台と棚があります。
  教会には祭壇と、祭壇を向いた長椅子の列、詰所には机と二段寝台と武器掛け、民家には暖炉と食器棚と寝台があります
- **看板と灯り** — 宿屋・酒場・鍛冶屋・パン屋・雑貨屋は、扉の隣の壁に吊り看板を掛けます。通りに街灯が立ち、戸口のそばにランタンが灯ります。夕暮れの暗さです

通りの物と家具は、「木・岩・サボテン・廃材を3Dモデルで置く」を入れていると3Dモデルで置かれ、切ると箱で置かれます。吊り看板と旗は、3Dモデルで置くときだけ掛かります。

### 村と砦の地面

地面の起伏を0より大きくすると、農村と砦と城下町は台地の上に立ちます。
道・庭・畑・建物・壁のある敷地と、その外側の1マスが、同じ高さにならされます。
台地の高さは、敷地の中心にあたる場所の、ならす前の地面の高さと同じです。
台地の外は2マスの幅でなだらかに傾き、その先はまわりの地面の起伏につながります。

建物・壁・柵・作物はどれも同じ高さに立つので、家の床が傾いたり、壁が段差をまたいだりしません。
地面の起伏を0にすると、盤面はすべて平らになります。農村の小川だけは、起伏が0でも地面を掘って流れます。

### 置かれるもの

木・茂み・岩・岩場が置かれます。木と岩場は視線を遮ります。

上下左右のうち2つ以上が埋まっているマスには何も置きません。木立が壁になって歩けない盤面になるのを防ぐためです。水面にも何も置きません。

市街では、区画ごとに建物が1棟ずつ建ちます。建物は「建物」、屋上の給水塔や機械室は「屋上設備」という名前の地形です。
GM用の概要は建物を1棟ずつ数え、プレビューは屋上の素材で塗り分けるので、植え込みの広場を建物と見分けられます。
ヘクスのテーブルでは建物を1マスごとの柱で組み、基壇の縁は基壇の高さで止まります。

## 素材

壁と地面（フィールドでは障害物と地面）のピッカーで、同梱のテクスチャか画像保管庫の自前の画像を選べます。

フィールドの**障害物の素材**は選んだときだけ反映されます。選ばないあいだは、雰囲気が決めた素材のままです。市街の建物は
何種類かの外壁を混ぜて建ち、スラム街の街路樹の幹は木のままです。選ぶと、壁用のテクスチャで建つもの（建物・柱・幹など）が
すべてその素材になります。**地面素材**は雰囲気の既定の地面（ビル群ならアスファルト）の帯だけを置き換えます。

素材は形に影響しません。スウォッチを変えても盤面は振り直されないので、気に入った形のまま色味だけ試せます。

## 生成されたものの片づけ

生成した地形・扉・明かり・地面の絵は、すべてそのテーブルに属します。テーブルを削除すれば、一緒に消えます。地面の絵は画像保管庫からも取り除かれます。

## 未探索の場所を隠す

生成では未探索の覆いを置きません。盤面いっぱいのマスクを置くと、下にある地形をどれもクリックできなくなってしまうためです。

隠したいときは、テーブルの右クリックのメニューから、手で[マップマスク](/manual/map-mask)を置いてください。

## うまくいかないとき

| 見えるもの                                            | 原因と直しかた                                                                                                                   |
| ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 「地形が 400 個を超えます。部屋数を減らしてください」 | 置く地形が多すぎます。部屋数か広さを減らすか、雰囲気を変えます。ヘクスでは、四角より地形が増えます                               |
| 「置けた部屋は N 個です。…」                          | 洞窟系の雰囲気では、空洞どうしがつながるので、頼んだ部屋数より少なくなります。部屋をはっきり分けたいときは、ほかの雰囲気にします |
| 生成したのに、画面が変わらない                        | 生成しても、いまのテーブルは切り替わりません。**このテーブルへ移動**を押します                                                   |
| 前に作ったテーブルが消えた                            | 同じパネルからもう一度生成すると、前のテーブルを作り直します。残したいときは、先に名前を変えるか別のテーブルへ移ります           |
| 未探索の場所が見えてしまう                            | 生成では覆いを置きません。**戦場の霧をかけた状態にする**を入れて生成するか、[マップマスク](/manual/map-mask)を置きます           |
| 「このツールはゲームマスター専用です」                | GMではありません。接続パネルで役割を確かめます                                                                                   |

# テーブル設定

このページは、テーブル（マップ1枚）を作る・切り替える・消す手順と、テーブルごとの見た目（グリッド・大きさ・背景・暗闇・天候）の設定を説明します。
変えられるのはGMとPLです。見学は見るだけです。
移動範囲・ZOC・コマの向き・既定のダイスボットのような部屋全体の決めごとは、[部屋設定](/manual/room-settings)にあります。

## 開く

FABメニューの**テーブル関連**を押し、**テーブル設定**を押します。
左にテーブルの一覧、右に選んだテーブルの設定が並びます。

どの項目も、変えるとその場でテーブルに入り、同じテーブルを見ている全員に伝わります。
パネルの下の**保存**は、テーブルをファイル（`map_テーブル名`）に書き出すボタンで、設定を反映するためのものではありません。

## テーブルを作る・切り替える・消す {#tables}

| したいこと         | 操作                                                                                                                 |
| ------------------ | -------------------------------------------------------------------------------------------------------------------- |
| 新しく作る         | 一覧の上の**新しいテーブルを作る**を押します。「白紙のテーブル」という名前で、グリッドを常に表示した状態で作られます |
| 切り替える         | 一覧からテーブルを選びます。部屋の全員の表示が、そのテーブルに移ります                                               |
| 名前を変える       | **テーブル名**を書き換えます                                                                                         |
| 消す               | テーブルを選んで、パネルの下の**削除**を押します                                                                     |
| 消したのを戻す     | パネルを閉じる前に、**元に戻す**を押します                                                                           |
| ファイルに書き出す | **保存**を押します                                                                                                   |

テーブルを切り替えたときに流すものも、ここで決めます。

| 項目                   | 内容                                                                                                     | 既定値   |
| ---------------------- | -------------------------------------------------------------------------------------------------------- | -------- |
| 切り替え時のカットイン | 一覧からこのテーブルを選んだときに流す[カットイン](/manual/cut-in)。2つ以上選ぶと、そのつど1つを選びます | なし     |
| 切り替え時のBGM        | このテーブルに切り替えたときの音楽。「そのまま」「止める」か、曲を選びます                               | そのまま |

カットインの抽選は、切り替えた人の画面で1回だけ行い、結果を全員へ配るので、参加者はみな同じ演出を見ます。
部屋データの読み込み・リプレイの再生・消したテーブルの戻しでは流れません。

BGMは、一覧からこのテーブルを選んだときのほか、[スイッチ](/manual/switch)でこのテーブルへ切り替えたときや、落とし穴でこのテーブルへ運ばれたときにも流れます。
切り替えた人の画面から[ジュークボックス](/manual/jukebox)を動かすので、全員に同じ曲が流れます。
同じ曲がすでに流れていれば、頭から流し直さずにそのまま続けます。
スイッチ自身にBGMを流す・止める設定があれば、そちらが優先されます。
部屋データの読み込みやテーブルの作成では流れません。

## グリッド・スナップ {#grid}

| 項目               | 選択肢                                               | 既定値                               |
| ------------------ | ---------------------------------------------------- | ------------------------------------ |
| グリッド種類       | なし・スクエア・ヘクス（縦揃え）・ヘクス（横揃え）   | スクエア                             |
| グリッドを常に表示 | 入り・切り                                           | 切り（パネルで作ったテーブルは入り） |
| スナップ           | なし・セル・交差点・セル＋交差点・セル＋交差点＋辺   | セル                                 |
| グリッドカラー     | **グリッド**（線の色）と**座標**（壁の座標の字の色） | 黒（やや透ける）                     |
| 移動と射程の1マス  | 1×1マス〜4×4マス。スクエアのグリッドだけに出ます     | 1×1マス                              |

**グリッドを常に表示**を入れると、壁にもグリッドが出て、各マスに向き付きの座標（北壁＝`N`・東壁＝`E`・南壁＝`S`・西壁＝`W`、例`N-1-1`）が振られます。
切っているあいだは、コマを動かしているときだけグリッドが出ます。

スナップは、コマを置いたときに吸い付く場所です。
セルはマスの真ん中、交差点は線の交わるところ、辺は辺の真ん中です。

**移動と射程の1マス**を2×2以上にすると、移動・経路・射程・ZOCは、そのまとまりを1マスとして数えます。
まとめたマスの境目は、グリッドに太い線で引かれます。
コマを動かすと、まとめたマスの真ん中に止まります。
数えかたは[移動範囲](/manual/move-range#まとめたマスで数える)と[射程範囲](/manual/range#まとめたマスで数える)にあります。

## 見かた {#view}

| 項目                       | 内容                                                                                                                                                                                               | 既定値 |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| 推奨ビュー                 | このテーブルを3D（斜めから見る）と2D（真上から見る）のどちらで見るのがよいか。FABメニューの[表示](/manual/screen#表示)で視点が**自動**の人はこれに従い、3Dか2Dを自分で選んだ人はその選択のままです | 3D     |
| 磁場異常（方位磁石が狂う） | [方位磁石](/manual/screen#ウィジェット)の針が北を指さなくなり、振れ続けます。読みの代わりに「磁場異常」と出ます。別のテーブルへ移れば、針は北へ戻ります                                            | 切り   |

磁場異常は、磁鉄鉱の洞窟や異界の1室のように、そのテーブルにいるあいだだけ方位が狂う場所を作るのに使います。

FABメニューの**表示**にある視点のボタンは、**自動**→**3D**→**2D**の順に切り替わります。
自動のあいだは推奨ビューに従い、括弧の中に、いまどちらで見えているかが出ます。
画面を寝かせて四方から囲む使いかたは、[視点とテーブル操作](/manual/tabletop#tabletop-display)にあります。

コマの絵の向き（**キャラクターの向き**）、1マスの実寸、真上から見たときの見えかたは、[部屋設定](/manual/room-settings#共通)にあります。

## 大きさ・背景

| 項目                | 範囲・選択肢             | 既定値                                             |
| ------------------- | ------------------------ | -------------------------------------------------- |
| 幅・高さ            | 1〜100マス               | 20×20マス（新しい部屋の最初のテーブルは20×15マス） |
| 1マスの大きさ（px） | 16〜256                  | 50                                                 |
| 背景フィルタ        | なし・ホワイト・ブラック | なし                                               |
| 床・背景・壁の画像  | 画像の一覧から選ぶ       | なし                                               |
| 壁の高さ            | 1〜20マス                | 10                                                 |

1マスの大きさを変えると、テーブルに置いてある地形・マスク・光源などが、同じマスに残るように動きます。
いま見ているテーブルなら、キャラクターやカードのように、テーブルをまたいで出ているコマも動きます。
コマの大きさや射程の長さはマスの数で持っているので、変わりません。
スライダーは離したとき、数値は確定したときに入ります。

ズームで離れられる遠さと寄れる近さも、1マスの大きさに合わせて少しだけ変わります。
大きいマスのテーブルは遠くまで離れられ、小さいマスのテーブルは近くまで寄れます。

壁は、北壁・東壁・南壁・西壁のそれぞれに、**表示**の切り替えと画像があります。

## グリッドに合わせて設定

床の画像の横の**グリッドに合わせて設定**を押すと、マップ画像のグリッドの位置を、見ながら合わせる道具が開きます。

1. **画像を選択** — ファイル選択画面で合わせたい床画像を選ぶ
2. **固定のクリップ枠に画像を合わせる** — 切り出し範囲（クリップ枠）は中央に固定され、**画像のほうを動かして**合わせます。枠の外は暗く表示されます
   - **グリッドタイプ** — スクエア / ヘクス（縦） / ヘクス（横）を切り替えられます。初期値は現在のテーブルのグリッドタイプで、確定時にテーブルへも反映されます
   - **クリップ範囲（マス数）** — 枠の**右端・下端のハンドルをドラッグ**するとマス単位で枠が伸縮します。数値入力でも指定できます
   - **画像をドラッグ**して位置を移動、**四隅・辺のハンドル**でサイズを調整、**ホイール**でカーソル中心に拡大縮小（Shiftで微調整）
   - **縦横比をリンク** — ONでは四隅ハンドルが等倍で拡縮します。OFFにすると辺ハンドルが現れ、縦横を独立に伸縮できます（マスが正方形でないマップ画像を枠にぴったり合わせられます）
   - **枠に合わせる** — リンクONでは枠を覆うようにフィット、OFFでは枠にぴったり引き伸ばします
   - **Ctrl+ホイールで全体をズーム** — 作業領域ごと拡大縮小できます（切り出し内容は変わりません）。大きなマス数で枠が収まらないときは自動でズームアウトし、「表示 ○○%」を押すと全体が見える倍率に戻ります
   - 矢印キーで画像を1pxずつ移動（Shiftキーで10pxずつ）。「リセット」で初期表示に戻す
3. **設定**を押して確定します。枠の範囲を切り出した画像が画像の一覧に足され、テーブルの背景画像・幅・高さ・グリッドタイプが自動設定されます（画像が枠全体を覆っているときだけ確定できます）

::: tip マップエディターと組み合わせて使う
[マップエディター](/manual/map-editor)で書き出した画像を床画像に設定した場合も、このツールでグリッド位置を細かく調整できます。
:::

## レイヤー

テーブル画像の下、または上を流れる画像です。飛空艇の下で雲が流れ、その下をさらに地面が別の速さで流れる、といった重ね方ができます。テーブルの後ろに立てる「奥」のレイヤーも置けます（[奥のレイヤー](#奥のレイヤー)）。1枚のテーブルに、奥・背面・前面を合わせて6枚まで置けます。

**レイヤーを追加**で1枚増え、**画像を選ぶ**で絵を決めます。画像は上下左右に敷き詰められ、盤面からはみ出した分は切り取られます。継ぎ目が出ないよう、ちょうど1枚ぶん流れたところで元へ戻ります。

| 設定               | 内容                                                                               |
| ------------------ | ---------------------------------------------------------------------------------- |
| 重ね位置           | 奥（テーブルの後ろ）／背面（テーブル画像の下）／前面（テーブル画像の上・コマの下） |
| 横の速さ・縦の速さ | -2000〜2000 px/秒。負の値で逆向き、0で静止。奥のレイヤーは縦には流れません         |
| 不透明度           | 0〜100%                                                                            |
| 拡大率             | 0.1〜10倍。1枚がテーブルより大きくなる分は効きません                               |
| カメラへの反応     | 奥のレイヤーだけ。0〜100%                                                          |
| 高さ               | 奥のレイヤーだけ。0〜100%                                                          |

並びは奥から順です。上下の矢印で入れ替えられ、奥・背面・前面はそれぞれ別の並びとして数えます。左のチェックを外したレイヤーは描かれません。

::: warning 背面はテーブル画像の下です
テーブル画像が不透明なら、背面のレイヤーは隠れて見えません。透過した画像をテーブルに敷くか、レイヤーを前面へ置いてください。
:::

### 奥のレイヤー

重ね位置を「奥」にすると、レイヤーはテーブルの後ろの画面いっぱいに貼られます。山並みや街並みのような横長の絵を横につなげて並べ、縦は1枚だけ置きます。「高さ」は、画面の下端から絵の下端までの位置です。0%なら絵の足元が画面の下端にそろいます。絵の上下の端は少しずつ透けていくので、切れ目が線になって見えません。

奥のレイヤーは、カメラを回したり傾けたり動かしたりすると、少しだけついてきます。どれだけついてくるかは「カメラへの反応」で決めます。反応が小さいほど遠くに、大きいほど近くに見えます。遠い山を10%、手前の街並みを35%、流れる雲を70%のように何枚か重ねると、カメラを動かしたときに絵どうしがずれて奥行きが出ます。100%にすると、テーブルを1周回したときに絵がちょうど1枚分流れます。

奥のレイヤーは、遠景の画像より手前、テーブルより後ろに描かれます。

レイヤーはテーブルのものなので、部屋の全員に同じものが見えます。同期しないのは、いまどこまで流れたかだけです。数える人がいないので、それぞれのブラウザに任せてあります。FABメニューの**表示**にある[アニメーション](/manual/theme#animation)で演出を止めると、レイヤーも止まります。

## 暗闇（視界・照明）

| 項目                   | 内容                                                             | 既定値         |
| ---------------------- | ---------------------------------------------------------------- | -------------- |
| 暗闇を有効化           | テーブルを暗くして、視界や光源で照らされた範囲だけを見せます     | 切り           |
| 暗さ                   | 暗闇の濃さ                                                       | 92%            |
| 環境光                 | テーブル全体を照らす明るさ                                       | 0%             |
| 暗闇の色               | 暗いところの色                                                   | 黒に近い紺     |
| 照明をマス目に沿わせる | 照らされた範囲をマス単位に丸めます（暗闇が有効なときだけ出ます） | 切り           |
| 視点プレビュー         | 特定のPLや見学から、どう見えるかを確かめます（GMだけ）           | 自分（GM視点） |

## 戦場の霧（探索）

| 項目             | 内容                                                                               | 既定値   |
| ---------------- | ---------------------------------------------------------------------------------- | -------- |
| 戦場の霧を有効化 | 誰も踏み込んでいない場所を霧で覆います。暗闇とは別に使えます                       | 切り     |
| 霧の戻り方       | イージー（晴らした場所は明るいまま）・ノーマル（記憶を残す）・ハード（記憶を消す） | ノーマル |
| 霧の色           | 霧の色                                                                             | 灰色     |
| 霧をリセット     | 晴らした霧を、すべて元に戻します                                                   |          |

くわしい使いかたは、[暗闇・視界・光源](/manual/vision-lighting)にあります。

## 天候（マップ全体）

| 項目 | 内容                                                                                         | 既定値       |
| ---- | -------------------------------------------------------------------------------------------- | ------------ |
| 天候 | なし・濃霧・雨・雷雨・雪・降灰・火の粉・砂塵・瘴気・光の粒・水中。「なし」に戻せば止まります | なし         |
| 濃さ | 0〜100%。粒の数と空気の色の濃さが一緒に動きます                                              | 60%          |
| 色   | 粒と空気の色。**既定**を押すと、種類ごとの色に戻ります                                       | 種類ごとの色 |

選ぶと、そのテーブルを開いている全員の画面に降りはじめます。
水中にすると、テーブル全体が水の中になります（→ [水域と水中](/manual/water#天候「水中」)）。

濃霧と瘴気は、雲の塊で描きます。塊が重なったところが濃くなり、濃さを上げると数が増えます。塊は流れながらゆっくり回り、膨らんだり薄れたりします。

雷雨には、横殴りの雨と飛沫、それに稲光が付きます。光るタイミングは経過時間だけで決まるので、同じテーブルを見ている全員の画面で同時に光ります。

降るのはテーブルの上とその上空だけです。盤の外の余白には掛かりません。上空の高さは、壁の高さ（最低10マス）に合わせてあります。

天候はテーブルごとの設定です。屋外のマップだけ雨を降らせ、洞窟は無しにしておく、といった使い分けもできます。範囲を区切って毒沼や地面の噴出を置く方法は、[マップ演出（エフェクト）](/manual/map-effects)にあります。

## うまくいかないとき

| 見えるもの                     | 原因と直しかた                                                                                                    |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| 設定を変えられない             | 見学では変えられません。接続パネルで役割を確かめます                                                              |
| **移動と射程の1マス**が出ない  | グリッド種類がスクエアではありません。ヘクスとグリッドなしでは使えません                                          |
| グリッドが見えない             | **グリッドを常に表示**が切れています。切っているあいだは、コマを動かすときだけ出ます                              |
| コマがマスの真ん中に止まらない | **スナップ**が「なし」か「交差点」です。「セル」にします                                                          |
| 背景のレイヤーが見えない       | 重ね位置が「背面」で、床の画像が不透明です。前面へ移すか、透過した床画像を使います                                |
| 天候が降らない                 | **天候**が「なし」か、**濃さ**が0%です。FABメニューの**表示**で**アニメーション**を止めていると、動きも止まります |
| テーブルを消してしまった       | パネルを閉じる前なら、**元に戻す**で戻せます                                                                      |

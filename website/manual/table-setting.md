# テーブル設定

<Shot src="table-setting" alt="テーブル設定パネル。テーブル名・床画像・壁・サイズの設定項目が並んでいる" width="560" caption="床や壁の画像、グリッド、サイズをここで決めます" />

FAB メニューの「テーブル設定」から開きます。テーブルの作成と見た目をまとめて設定します。

卓の決めごと（移動範囲・ZOC・コマの向き・既定のダイスボット）はテーブルごとではなく部屋のものなので、[部屋設定](/manual/room-settings) へ移りました。パネル下の **部屋設定を開く** から行けます。

## テーブルの作成・切り替え

- **新しいテーブルを作る** — テーブルを追加
- 一覧から選んで使用テーブルを切り替え
- **テーブル名** の変更
- **切り替え時のカットイン** — 一覧からこのテーブルを選んだときに流す[カットイン](/manual/cut-in)を指定します。2 つ以上選ぶと、切り替えるたびにその中の 1 つが選ばれます

カットインの抽選は切り替えた人の画面で 1 回だけ行われ、結果が全員へ配信されます。参加者はみな同じ演出を見ることになります。部屋データの読み込み・リプレイ再生・削除したテーブルの復元では鳴りません。

## グリッド

- **グリッド種類** — 四角 / ヘクス など
- **グリッド常時表示** の切り替え。ON のときは **壁にもグリッドが表示** され、各マスに向き付きの座標ラベル（北壁＝`N`・東壁＝`E`・南壁＝`S`・西壁＝`W`、例 `N-1-1`）が振られます
- **スナップ設定** — セル中心 / 頂点 / セル＋頂点 / ALL（セル・頂点・辺の中点を統合）
- グリッドのフォントカラー

## コマの見せ方

- **コマ画像を常にカメラに向ける** — 視点を回してもコマの絵が正面を向いたままになります
- **2Dモード（俯瞰固定）** — 視点の傾きを固定し、真上から見下ろす盤面にします。このテーブルを見ている全員に効きます
- **地形の回転を許可（通常は2Dモードでは固定）** — ONにすると、2Dモードでも地形の回転ハンドルを操作できます。初期状態はOFFです

自分の画面だけを 2D にしたいときは、[FAB メニュー](/manual/#fab-メニュー)の、いま見えている方のアイコンを押してください。画面を寝かせて四方から囲む使い方には [卓上ディスプレイ設定](/manual/multi-angle) があります。

**キャラクターの向き** は [部屋設定](/manual/room-settings#コマの向きの示し方) へ移りました。俯瞰では絵が常にこちらを向くため、どちらを向いているかが分かりません。次の 3 つから選べます。

| 選択         | 見え方                                                                           |
| ------------ | -------------------------------------------------------------------------------- |
| 示さない     | これまでどおり。2Dモードではコマを回せません                                     |
| コマごと回す | 2Dモードでコマを回せるようになり、**絵ごと**その向きへ回ります                   |
| 矢尻で示す   | 絵はこちらを向いたまま、コマの外側の**矢尻**が向きを示します。3Dモードでも出ます |

矢尻はコマの足元と同じ平面に置くので、傾けたテーブルでは床に描いた印のように見えます。コマの縁をまたぐ
位置に、絵と名前より前へ描くので、俯瞰で名前の下に隠れることはありません。向きはコマの回転そのものなので、
部屋の全員に同じ向きが見えます。回すのはこれまでと同じで、コマの縁をつまんで回します。

コマを回しても、名前・HP バー・吹き出しはコマの上に出たままです（コマの向きは足元だけで表し、その上に
下がっているものは回しません）。

## 大きさ・背景

- **テーブル幅 / 高さ** のスライダー
- **背景フィルタ**（距離ビューの色味）
- 背景画像の設定

## グリッドに合わせて設定

床画像の横の **「グリッドに合わせて設定」** ボタンから、マップ画像のグリッド位置を視覚的に合わせる調整ツールを開けます。

1. **画像を選択** — ファイル選択画面で合わせたい床画像を選ぶ
2. **固定のクリップ枠に画像を合わせる** — 切り出し範囲（クリップ枠）は中央に固定され、**画像のほうを動かして**合わせます。枠の外は暗く表示されます
   - **グリッドタイプ** — スクエア / ヘクス（縦） / ヘクス（横）を切り替えられます。初期値は現在のテーブルのグリッドタイプで、確定時にテーブルへも反映されます
   - **クリップ範囲（マス数）** — 枠の**右端・下端のハンドルをドラッグ**するとマス単位で枠が伸縮します。数値入力でも指定できます
   - **画像をドラッグ**して位置を移動、**四隅・辺のハンドル**でサイズを調整、**ホイール**でカーソル中心に拡大縮小（Shift で微調整）
   - **縦横比をリンク** — ON では四隅ハンドルが等倍で拡縮します。OFF にすると辺ハンドルが現れ、縦横を独立に伸縮できます（マスが正方形でないマップ画像を枠にぴったり合わせられます）
   - **枠に合わせる** — リンク ON では枠を覆うようにフィット、OFF では枠にぴったり引き伸ばします
   - **Ctrl+ホイールで全体をズーム** — 作業領域ごと拡大縮小できます（切り出し内容は変わりません）。大きなマス数で枠が収まらないときは自動でズームアウトし、「表示 ○○%」を押すと全体が見える倍率に戻ります
   - 矢印キーで画像を 1px ずつ移動（Shift キーで 10px ずつ）。「リセット」で初期表示に戻す
3. **「設定」を押して確定** — 枠の範囲を切り出した画像がファイルストレージに追加され、テーブルの背景画像・幅・高さ・グリッドタイプが自動設定されます（画像が枠全体を覆っているときだけ確定できます）

::: tip マップエディターと組み合わせて使う
[マップエディター](/manual/map-editor)で書き出した画像を床画像に設定した場合も、このツールでグリッド位置を細かく調整できます。
:::

## 暗闇（視界・照明）・壁

- **暗闇（視界・照明）** — テーブルを暗くして、視界や光源で照らされた範囲だけを見せる
- **照明をマス目に沿わせる** — 照らされた範囲をマス単位に丸める（暗闇が有効なときだけ表示）
- **壁** — 四方（北壁 / 東壁 / 南壁 / 西壁）の表示と壁画像

**戦場の霧（探索）** も同じ場所にあります。誰も踏み込んでいない場所を霧で覆う仕組みで、暗闇とは独立して使えます。霧の戻り方を 3 段階から選べます。

詳しい使い方は [暗闇・視界・光源](/manual/vision-lighting) を参照してください。

## 天候（マップ全体）

濃霧・雨・雷雨・雪・降灰・火の粉・砂塵・瘴気・光の粒の 9 種類から選べます。選ぶと、そのテーブルを開いている全員の画面に降りはじめます。初期値は「なし」です。

- **天候** — 種類の選択。「なし」に戻せば止まります
- **濃さ** — 0〜100%。粒の数と空気の色の濃さが一緒に動きます
- **色** — 粒と空気の色。**既定**を押すと種類ごとの色に戻ります

濃霧と瘴気は**雲の塊**で描きます。塊が重なったところが濃くなり、濃さを上げると数が増えます。塊は流れながらゆっくり回り、膨らんだり薄れたりします。

雷雨には横殴りの雨と飛沫、それに**稲光**が付きます。光る拍は経過時間だけで決まります。だから同じテーブルを見ている全員の画面で、同時に光ります。

降るのはテーブルの上とその上空だけです。盤の外の余白には掛かりません。上空の高さは**壁の高さ**（最低 10 マス）に合わせてあります。

天候はテーブルごとの設定です。屋外のマップだけ雨を降らせ、洞窟は無しにしておく、といった使い分けもできます。範囲を区切って毒沼や地面の噴出を置く方法は [マップ演出（エフェクト）](/manual/map-effects) を参照してください。

設定したグリッド・スナップ・サイズはテーブルごとに参加者間で同期されます。最後に **保存** で反映してください。

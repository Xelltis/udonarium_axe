# 接続が切れたとき

このページは遊んでいる途中で接続が切れたり、ほかの人と画面の内容が食い違ったりしたときの、見分けかたと戻しかたを説明します。
Axeは、SkyWay版では参加者どうしを直接つなぎ、[部屋のサーバー（ベータ）](/guide/choose)では各自が部屋のサーバーにつながります。
回線が一瞬途切れたり、スリープから戻ったりすると、接続が落ちることがあります。
多くの場合は自動で戻るので、まずはそのまま待ってください。

## まず確かめること

| 見えるもの                                                                           | すること                                                                                                                                                                  |
| ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 「〇〇 さんとの接続が切れました。再接続しています…」                                 | 自動でつなぎ直しています。そのまま待ちます（→ [自動で復旧します](#自動での復旧)）                                                                                         |
| 「〇〇 さんとの再接続に失敗しました。…」                                             | 接続パネルの**部屋のデータを同期し直す**か、**再接続**を押します（→ [それでも直らないとき](#それでも直らないとき)）                                                       |
| 入ったのに卓が空のまま                                                               | 接続パネルで、相手とのつながり方と、部屋のデータの受け取りの進みを見ます（→ [相手ごとのつながり方を見る](#peer-links)）                                                   |
| 入った直後に、コマの絵が出ない・BGMが鳴らない                                        | SkyWay版では、画像と音楽はテーブルとチャットのあとに届きます。少し待ちます（→ [部屋に入った直後に届く順番](#first-sync)）                                                 |
| 相手のコマが動かない・チャットが届かない                                             | 通信品質のウィジェットで、その人の回線を見ます（→ [いまの通信品質を見る](#いまの通信品質を見る)）                                                                         |
| 自分とほかの人で、コマやチャットの内容が違う                                         | 接続パネルの**部屋のデータを同期し直す**を押します（→ [コマやチャットが食い違うとき](#コマやチャットが食い違うとき)）                                                     |
| 「部屋のサーバーにつながりません」                                                   | 部屋のサーバーで、5回つなぎ直しても戻りませんでした。ロビーか招待リンクから入り直します                                                                                   |
| 「新しい版のAxeが公開されています。ページを再読み込みしてください」                  | 設置する人がAxeを更新しました。ページを読み込み直します                                                                                                                   |
| 「ログインの期限が切れたか、別のアカウントでログインし直しました。…」                | 部屋のサーバーで、ログインが切れました。部屋に入り直します                                                                                                                |
| 「部屋のサーバーの運営者が、このアカウントか回線を止めているため、部屋に入れません」 | 部屋のサーバーを運営する人が、このアカウントか回線を止めました。Axeの側では直せないので、心当たりがなければ、知らせの下に出る問い合わせ先から運営する人に問い合わせます   |
| 「部屋のサーバーの運営者が、画像や音声を上げることを一時的に止めています。…」        | いま足した画像や音声は、自分の画面にだけ出ます。再開されると「画像や音声を上げられるようになりました。…」と出て、ほかの参加者にも届きます。届く前に部屋を出ると届きません |
| 「部屋の置き場所がいっぱいで、足した画像や音声は部屋に保存されません。…」            | 部屋に置ける量を超えました。いまいる人には届きますが、あとから入った人には届きません（→ [部屋に置ける量](/manual/rooms#部屋に置ける量)）                                  |
| 「部屋のサーバーの運営者が置けないようにしている画像か音声があります。…」            | その画像か音声は、ほかの参加者に届きません。別のものに替えます                                                                                                            |
| 誰ともつながらない                                                                   | 接続パネルで、**オフライン**になっていないか確かめます（→ [部屋とロビー](/manual/rooms#offline)）                                                                         |

## いまの通信品質を見る

FABメニューの[ウィジェット](/manual/screen#ウィジェット)にある**通信品質**（電波のアイコン）を押すと、通信品質のウィジェットが開きます。
ドラッグで好きな位置に置け、出しているかどうかはブラウザに残ります。
閉じるときは、右上の × か、もう一度同じボタンを押します。

<Shot src="connection-quality" alt="通信品質のウィジェット。見出しに「通信品質　良好」、その下に「部屋のサーバー」の1行があり、往復遅延は「--」と出ている" width="260" caption="部屋のサーバーにつないでいるときの通信品質。SkyWay版では、参加者ごとの行と往復遅延が並びます" />

ウィジェットの見出しには、自分と各参加者をつなぐ回線のうちいちばん悪いものが4段階で出ます。

| 表示 | 意味                                                        |
| ---- | ----------------------------------------------------------- |
| 緑   | 良好                                                        |
| 黄   | やや不安定（10秒ほど何も届いていない、または遅延200ms以上） |
| 橙   | 不安定（15秒以上無通信、または遅延500ms以上）               |
| 赤   | 切断                                                        |

見出しの下には参加者ごとの内訳が並び、名前と往復遅延（ms）を確認できます。灰色の「測定中」はつないだ直後でまだ計測できていない状態です。

往復遅延を測る通信は部屋のデータや画像よりも先に送ります。画像や音楽を送っている最中でも、数字は回線そのものの遅れを表します。回線が混んでいるかどうかは、接続パネルの受け取りの進みで確かめてください（→ [相手ごとのつながり方を見る](#peer-links)）。

**分かれ道アイコン**が付いている参加者は、直接つながれず**中継サーバー経由**になっています。遅延が大きくなりやすいので、その人だけ重いときの手がかりになります。

::: tip 見えるのは「自分から見た」品質です
P2Pなので、各自が測れるのは自分と相手を結ぶ回線だけです。参加者Aと参加者Bのあいだの状態は、あなたの画面には出ません。AとBだけで内容が食い違うときは、下の「同期し直す」を全員に試してもらってください。
:::

## 相手ごとのつながり方を見る {#peer-links}

SkyWay版では接続パネルの参加者の一覧に、その人と自分がどうつながっているかが出ます。
名前の左のアイコンと語で見分けられます。

| 表示                                               | 意味                                                                                                 |
| -------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| 鎖のアイコンだけ                                   | 直接つながっています                                                                                 |
| 分かれ道のアイコンと「中継サーバー経由」           | 直接つながっていますが、中継サーバーを通っています。遅延が大きくなりやすい回線です                   |
| 人のアイコンと「他の人経由のみ」                   | その人とは直接つながっていません。発言やコマの動きは、両方とつながっているほかの参加者が届けています |
| 回る矢印のアイコンと「再接続中」                   | つなぎ直しているところです。そのまま待ちます                                                         |
| 切れた鎖のアイコンと「接続できません（再試行中）」 | つなぎ直しを5回試してもつながりませんでした。30秒ごとの試行は続いていて、つながれば直接に戻ります    |

「他の人経由のみ」と「接続できません（再試行中）」の行には、下に「この人とは直接つながっていません。部屋のデータは他の人から受け取ります。」と出ます。
SkyWayが部屋にいると知らせている人は、まだ一度もつながっていなくても一覧に出ます。

**部屋のデータを同期し直す**のボタンの上には、自分の画面が部屋のデータをどこまで受け取ったかが出ます。

| 表示                                                                         | 意味                                                                                                |
| ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| 「部屋のデータを受け取っています（残り〇件）」とバー                         | 受け取っている途中です。残りの件数が減っていけば進んでいます。途中で件数が増えることもあります      |
| 「部屋のデータは最新です」                                                   | 受け取り終えました                                                                                  |
| 「受け取りが止まっています。回線が混んでいるか、相手とつながっていません。」 | 残りの件数が30秒減っていません。一覧で相手とのつながり方を確かめます                                |
| 「部屋のデータを受け取れる相手がいません」                                   | 直接つながっている人が1人もいません。卓が空のままなら、**再接続**を押すか、ページを読み込み直します |

部屋のサーバーでは、つながる相手が部屋のサーバーだけなので、この2つは出ません。

## 部屋に入った直後に届く順番 {#first-sync}

SkyWay版では、部屋に入るとまずテーブル・コマ・チャットが届き、画像・音楽・3Dモデルはそのあとに届きます。
入った直後は、コマや背景の絵が出ていなかったり、BGMが鳴り始めなかったりすることがあります。接続パネルに「部屋のデータは最新です」と出てから少し待つと、絵と音がそろいます。
テーブルやチャットの受け取りが長引いているときも、最初の相手とつながってから20秒たつと、画像と音楽を頼み始めます。

画像や音楽を送っているあいだも、コマの動きやチャットは先に届きます。
部屋のサーバーではこれまでどおり、入ってすぐに画像と音楽を取りに行きます。

## 自動での復旧

誰かとの接続が切れると、チャットにシステムメッセージが流れ、裏で自動的につなぎ直しを試みます。

1. **「〇〇 さんとの接続が切れました。再接続しています…」** — 復旧を開始した合図です
2. **「〇〇 さんとの接続を復旧しました。」** — つなぎ直せた合図です。そのまま続けられます
3. **「〇〇 さんとの再接続に失敗しました。」** — 5回試してもつなぎ直せなかった合図です（下記の手動操作へ）

つなぎ直しは1秒後・2秒後・4秒後…と間隔を空けながら5回試します。そのあとも、相手が部屋にいるあいだは30秒ごとに試し続け、つながると「〇〇 さんとの接続を復旧しました。」と出ます。相手が部屋から居なくなっていた場合は、待たずに打ち切ります。
いま誰とつなぎ直しているかは、接続パネルで確かめられます（→ [相手ごとのつながり方を見る](#peer-links)）。

::: tip 見た目が固まったように見えるとき
相手のコマが動かなくなっても、25秒ほど何も届かない状態が続けば自動で切断と判断し、つなぎ直しに入ります。無反応のまま繋がっているように見える状態が延々と続くことはありません。
:::

## 部屋のサーバーのとき {#room-server}

[部屋のサーバー（ベータ）](/guide/choose)では、各自がつながる相手は部屋のサーバーだけです。ここまでの説明とは、次の点が違います。

- 通信品質ウィジェットには「部屋のサーバー」の1行だけが出ます。緑はつながっている、赤は切れていることを表します。往復遅延は測らないので「--」のままです
- サーバーとの接続が切れると、自分の画面の下に「部屋のサーバーとの接続が切れました。再接続しています…」と出て（チャットには残りません）、1秒後・2秒後・4秒後…と最大5回つなぎ直します。つなぎ直せれば「部屋のサーバーとの接続を復旧しました。」と出て、そのまま続けられます
- 5回ともつながらないときは「部屋のサーバーにつながりません」と出て、部屋の外に戻ります。卓はサーバーに残っているので、ロビーか招待リンクから入り直してください
- 次のときに消した物は、削除がサーバーに届かず、あとで戻ることがあります。切断に気づくまでの数十秒、5回ともつながらなかったあいだ、接続が切れてから「再接続」を押すまでのあいだ、部屋のサーバーが落ちたり入れ替わったりする直前の1秒ほどです。少しずつ送っている大きな削除も、送り終わる前に「再接続」を押したり部屋を出たりすると、残りが届きません。つなぎ直したときや入り直したときに戻っていたら、消し直してください
- 同じときにタブの「元に戻す」や読み込みで戻した物は、反対に消えることがあります。そのときは、保存したzipから読み直してください
- 行の多いタブの削除や大きな部屋の読み込みは、サーバーの上限を超えないように少しずつ送ります。ほかの参加者に届くまで数十秒かかることがあり、そのあいだに送った発言・ダイス・コマの動きも、その後ろで届きます。送り終わる前に部屋を出ようとしたり再接続しようとしたりすると、確認が出ます。接続が切れているあいだに再接続しようとしたときも、切れる前に送り終わっていなかった削除や、切れてから消した物が戻ることを確かめます。動かした物や書いた発言は、入り直したときに届きます。サーバーで振るダイスも入り直したときに頼み直します。「不整合データを削除する」を有効にして再接続すると、キャラクターや共有メモなどは部屋のサーバーにある形に戻り、まだ届いていない変更は失われます
- 「部屋のデータを同期し直す」はほかの参加者ではなく部屋のサーバーから取り直します。部屋に自分ひとりのときも押せます
- 「再接続」も部屋に入っていれば人数にかかわらず出ます

## コマやチャットが食い違うとき

接続は繋がっているのに、自分の画面と他の人の画面で内容が違うことがあります。切断中に起きた変更を取りこぼした場合です。

SkyWay版では、参加者どうしが持っているデータを25秒ごとに照らし合わせ、食い違いが続くと自動で突き合わせ直します。1分ほど待つと、何もしなくても揃うことがあります。

待っても揃わないときは、接続パネルの**部屋のデータを同期し直す**を押してください。接続はつないだまま、参加者どうしでデータを突き合わせ直します。

- 押した人だけでなく、全員の画面が揃います
- コマや画像を消したり、部屋に入り直したりはしません
- 何人に要求したかがチャットに表示されます
- 頼めるのは、直接つながっている相手だけです。直接つながっていない人が部屋にいると、「〇人に部屋のデータの再同期を要求しました。部屋にいる〇人とは直接つながっていないため、頼めませんでした。」と出ます。その人とのつながり方は、接続パネルで確かめます（→ [相手ごとのつながり方を見る](#peer-links)）

これで直らないときだけ、次の再接続を試してください。

## それでも直らないとき

接続パネルの**再接続**から、部屋につなぎ直せます。こちらは一度接続を切ってから入り直す操作です。

- 実行前に[部屋データを保存](/manual/save-load)しておくと安全です
- 「不整合データを削除する」は**最終手段**です。同期がおかしくなった原因になりうるコマなどを消してから再接続します
- SkyWay版では、部屋のデータを持っている参加者が他に居ない状態で実行すると、データが失われます。部屋のサーバーでは、卓はサーバーに残ります

再接続でも復帰しないときは、ページを再読み込みしてください。前回の卓は自動保存されているので、[保存と読み込み](/manual/save-load#前回の卓を復元する)から復元できます。

## オンラインとオフライン

接続パネルの上の**オンライン**と**オフライン**の切り替えで、通信を切って、そのブラウザだけで動かせます。
切り替えかたと、切り替えたときに起きることは、[部屋とロビー](/manual/rooms#offline)にあります。

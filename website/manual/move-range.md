# 移動範囲

コマを持ち上げると、そのコマが動ける範囲が卓に浮かびます。距離はキャラクターシートから読み、壁や他のコマを避けた実際の道のりで数えます。

「あと何マス届くか」を目で数える手間がなくなります。効くのは、ダンジョンのように壁が入り組んだ卓です。

## まずシートに「移動」を書く

範囲はシートの項目から読みます。既定では **移動 / 移動力 / Speed / 速度** の順に探し、最初に見つかった項目の数値を使います。どれも無いコマには範囲を出しません。

新しく作ったキャラクターと、最初のルームに並ぶサンプルのコマには、はじめから「移動」が入っています。斥候は 8 マス。鎧を着た騎士は 4 マス、ゴーレムは 3 マスと、コマごとに違う値を入れてあります。

探す項目名は変えられます。使っているシステムが「機動力」と呼ぶなら、テーブル設定の **参照する項目** をそれに書き替えてください。カンマで区切って複数書けます。

::: warning 同じ名前の項目が 2 つあると読めません
シートの項目は名前で引くので、「移動」が 2 か所にあると、どちらを指すか決められず範囲が出ません。自分で項目を足すときは、既にある名前と重ならないようにしてください。
:::

## マスの単位が違えば換算する

シートが「30 フィート」で、卓が 1 マス 5 フィートなら 6 マス。この換算をテーブル設定で決めます。

- **マスの単位** — マス / メートル / フィートから選びます
- **1 マスの距離** — 1 マスが何メートル、何フィートにあたるか。単位がマスのときは意味がないので出ません

シート側の単位は、項目の単位欄に書いたものを読みます。フィートで書かれたシートをメートルの卓に持ち込めば、メートルに直してから数えます。逆も同じです。

シートが「マス」で書かれていれば、その数がそのままマス数です。卓が何で数えていようと換算しません。数えるものが最初からマスだからです。

## 斜めに動けるかは卓が決める

四角マスの [部屋設定](/manual/room-settings#移動範囲と-zoc-は、触るまでテーブルのまま) に **斜め移動を許可する** があります。許可すれば角を斜めに横切る一歩も 1 マスぶんとして数え、範囲は四角く広がります。許さなければ縦横だけを数えるので、範囲はひし形になります。

ヘクスのテーブルには出ません。六角形に角はなく、六方向のどれも等しく一歩だからです。

## 通れない場所

壁として立っている地形は通れません。閉じた扉も壁です。開いている扉は通れます。

**同じマスに複数のコマを置ける** を切ると、他のコマが立っているマスも通れなくなります。避けて回り込むぶん、届く範囲は狭くなります。大きいコマは占めるマスすべてがふさがります。3 マス幅のゴーレムの横はすり抜けられません。

### GM が塗る立入禁止

地形を置くほどでもない場所を通れなくしたいときは、[マップエディター](/manual/map-editor#機能塗り) の **機能ツール** で立入禁止を塗ります。塗ったマスは移動範囲の計算で壁と同じ扱いになります。

塗ったマスは卓に薄い赤で出ます。**参加者全員に見えます。** コマが思ったところへ行かない理由が、卓を見れば分かるようにするためです。

## ZOC — 敵が抑えている地面

敵に隣接したマスを通ろうとすると足が止まる、というルールを卓に入れられます。ウォーゲームのゾーン・オブ・コントロールや、ソード・ワールド 2.5 上級戦闘の移動妨害にあたるものです。

[部屋設定](/manual/room-settings#移動範囲と-zoc-は、触るまでテーブルのまま) の **ZOC** で効果を選びます。

| 選択肢       | 動き                                         |
| ------------ | -------------------------------------------- |
| なし         | 何も起きません（既定）                       |
| 足止め       | ZOC のマスに入ったら、そこで移動が終わります |
| 進入不可     | ZOC のマスには入れません                     |
| 移動コスト増 | ZOC のマスに入るのに、余分に移動力を使います |

**ZOC の範囲** で何マス先まで届くかを、**移動コストの増加** で余分にかかるマス数を決めます。リーチの長い武器や大型の敵を表したいなら範囲を 2 にしてください。

敵かどうかは NPC かどうかで分けます。プレイヤーのコマを動かすならモンスターが、モンスターを動かすならプレイヤーのコマが ZOC を張ります。パーティ設定は見ません。所属を持たないコマが多いからです。

見えていない敵は ZOC を張りません。暗闇の中の敵に範囲がへこめば、そこに何かいると分かってしまいます。

## 出したままにする

既定では、範囲は持ち上げている間だけ見えます。動かす前に見比べたいときは、テーブル設定で出したままにできます。

- **選んだコマの移動範囲を出したままにする**
- **ZOC の常時表示** — 選んだコマに対する ZOC を出したままにする

どちらも**選んでいるコマ**が基準です。コマを選ぶと出て、選択を外すと消えます。持ち上げている間は、手に持っているコマのほうが優先されます。

範囲は同期しません。出るのは自分の画面だけです。他の参加者の画面は静かなままですし、見えていない敵の情報も漏れません。

## 卓の見え方を変えるだけ

移動範囲は目安の表示です。コマがそこまでしか動けなくなるわけではなく、範囲の外へドラッグすることも、ZOC を無視して通り抜けることもできます。どう扱うかは卓の取り決めしだいです。

## 範囲の外へは置けなくする

[部屋設定](/manual/room-settings)の **移動** で **移動できるマスの中にしか置けないようにする** を入れると、移動範囲が出ているコマを範囲の外へ置こうとしたとき、持ち上げた場所へ戻ります。

移動範囲が出ないコマは対象外です。移動力の項目がないコマや、移動範囲そのものを切っているときは、これまでどおりどこへでも置けます。GM が敵をまとめて配置するようなときは、この設定を切るか、移動力のないコマを使ってください。

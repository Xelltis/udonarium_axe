# 移動範囲

コマを持ち上げると、そのコマが動ける範囲が卓に浮かびます。距離はキャラクターシートから読み、壁や他のコマを避けた実際の道のりで数えます。

「あと何マス届くか」を目で数える手間がなくなります。役に立つのは、ダンジョンのように壁が入り組んだ卓です。

## まずシートに「移動」を書く

範囲はシートの項目から読みます。既定では**移動 / 移動力 / Speed / 速度**の順に探し、最初に見つかった項目の数値を使います。どれも無いコマには範囲を出しません。

新しく作ったキャラクターと、最初のルームに並ぶサンプルのコマには、はじめから「移動」が入っています。斥候は8マス。鎧を着た騎士は4マス、ゴーレムは3マスと、コマごとに違う値を入れてあります。

探す項目名は変えられます。使っているシステムが「機動力」と呼ぶなら、テーブル設定の**参照する項目**をそれに書き替えてください。カンマで区切って複数書けます。

::: warning 同じ名前の項目が2つあると読めません
シートの項目は名前で引くので、「移動」が2か所にあると、どちらを指すか決められず範囲が出ません。自分で項目を足すときは、既にある名前と重ならないようにしてください。
:::

## マスの単位が違えば換算する

シートが「30フィート」で、卓が1マス5フィートなら6マス。この換算は[部屋設定](/manual/room-settings#移動範囲とzocは、触るまでテーブルのまま)の**移動**で決めます。

- **マスの単位** — マス / メートル / フィートから選びます
- **1マスの距離** — 卓の1マスが、シートの何メートル・何フィート・何マスにあたるか。0にすると割りません

シート側の単位は、項目の単位欄に書いたものを読みます。フィートで書かれたシートをメートルの卓に持ち込めば、メートルに直してから数えます。逆も同じです。

単位がマスの卓でも、シートの数を1マスの距離で割ります。シートの1マスと卓の1マスの大きさが違うシステムのためのもので、0.5にするとシートの3マスが卓の6マスになります。

メートルやフィートの卓に「マス」で書かれたシートを持ち込んだときだけは、その数をそのままマス数にします。マスを長さに直す手がかりがないからです。

## 斜めの一歩をいくつと数えるか

角を斜めに横切る一歩の値段は、システムによって違います。四角マスの[部屋設定](/manual/room-settings#移動範囲とzocは、触るまでテーブルのまま)の**斜め移動**で4つから選びます。

- **許可しない（縦横のみ）** — 角は横切れません。範囲はひし形に広がります
- **1マスとして数える** — 縦横の一歩と同じ値段。範囲は四角く広がります
- **1マス・2マスを交互に数える** — 1回目の斜めは1マス、2回目は2マス、3回目はまた1マス。D&D 3.5eやパスファインダー1eの数え方です
- **常に2マスとして数える** — 斜めは必ず2マスぶん

交互に数える卓では、同じマス目に届くかどうかが通り道によって変わります。移動範囲は一番安く着ける道で塗り、コマを運んだときの消費も同じ数え方で計算します。

この設定はヘクスのテーブルには出ません。六角形に角はなく、六方向のどれも等しく一歩だからです。

## 通れない場所

壁として立っている地形は通れません。閉じた扉も壁です。開いている扉は通れます。

他のコマが立っているマスをどう扱うかは、[他のコマの前を通る](#他のコマの前を通る)で決めます。

### GMが塗る立入禁止

地形を置くほどでもない場所を通れなくしたいときは、[マップエディター](/manual/map-editor#機能塗り)の**機能ツール**で**移動コスト**を選び、通りにくさを**通れない**にして塗ります。塗ったマスは移動範囲の計算で壁と同じ扱いになります。

塗ったマスは卓に薄い赤で出ます。**参加者全員に見えます。** コマが思ったところへ行かない理由が、卓を見れば分かるようにするためです。

## 渡るのに余分にかかる地面

通れなくするほどではないけれど歩きにくい、という地面も同じ筆で塗ります。茂み・瓦礫・浅瀬・氷のたぐいです。**通りにくさ**を **+1マス**〜**+9マス**から選んでください。

+1なら、そのマスに入るのに2マスぶん使います。D&Dの移動困難地形がこれです。深い沼を+2、流砂を+3と塗り分けられます。重なったところは**高いほうが効きます**。足し算にはなりません。塗り重ねるたびに値段が上がっていくと、卓の上で数えられなくなるからです。

斜めを2マスと数える卓では、追加コスト1のマスを斜めに横切ると4マスぶんになります。ZOCの余分なコストと重なれば、そちらも足されます。

塗ったマスには卓の上で色が乗り、値が高いほど濃く出ます。GMだけに見せる設定はありません。隠したところで、踏み込んだコマが半分しか進めないので、場所はどのみち知れます。

ヘクスの卓でも同じです。六角形に角はないので、追加コストがそのまま歩数に乗ります。

## 歩く以外で動く

コマを右クリックして**移動の仕方**を選ぶと、そのコマが歩いているのか、登っているのか、泳いでいるのか、這っているのか、飛んでいるのかを決められます。**移動**のすぐ下にあり、移動範囲の出ないコマには出ません。選んだものはコマが持ち続けます。空に上がった竜は、降ろすまで空にいます。

登る・泳ぐ・這うの3つは、**どのマスも1マスぶん余計にかかります**。移動力6のコマは3マスしか進みません。1フィート進むのに1フィート余計に要る、という数え方をそのまま入れたものです。

飛ぶを選ぶと、2つのことが変わります。**地面の追加コストを払いません。** 足が浸かっていないので、沼も浅瀬も普通の床と同じです。それと、**跳び越えと同じものを越えます。** 壁の上を通って向こう側へ降りられますが、[登れない地形](/manual/terrain#登れない地形)だけは越えられません。

## 大きいコマを狭い隙間に押し込む

3マス幅のコマは、3マスぶんの空きがないと立てません。幅2マスの通路はそのコマには閉じています。[部屋設定](/manual/room-settings)の**移動**で**大きなコマを、通れない隙間に押し込めるようにする**を入れると、ひと回り小さいコマとして入れるようになり、押し込んで入ったマスは**1マスぶん余計にかかります**。

既定では切ってあります。隙間が足りなければ通れない、というのがこれまでの動きだからです。

## 道は半分で進める

[マップエディター](/manual/map-editor#移動コスト塗り-—-通りにくさを1つの筆で塗る)の**移動コスト**で**道**を選んで塗ったマスは、1マスを0.5消費で渡れます。移動力3のコマは道沿いに6マス進みます。

道は下に塗ってあるものより優先されます。沼を貫く街道は街道です。

## 他のコマの前を通る

他のコマが立っているマスに入れるかどうかは、そのコマが自分と同じ[パーティ](/manual/party)かどうかで分けられます。[部屋設定](/manual/room-settings#移動範囲とzocは、触るまでテーブルのまま)の**移動**に、3つの相手それぞれの欄があります。

| 相手               | 何のことか                                                                                                |
| ------------------ | --------------------------------------------------------------------------------------------------------- |
| 同じパーティのコマ | 自分と同じパーティ、または[同盟](/manual/party#同盟-—-別のパーティを味方として扱う)を結んだパーティのコマ |
| 別のパーティのコマ | 同盟していない別のパーティのコマ                                                                          |
| 未所属のコマ       | どのパーティにも入っていないコマ                                                                          |

どれにも4つの扱いがあります。

| 選択肢                   | 動き                                                       |
| ------------------------ | ---------------------------------------------------------- |
| 通れない                 | そのマスには入れません                                     |
| 通れるが止まれない       | 通り抜けられますが、移動の終点にはできません               |
| 割高で通れて、止まれない | 上と同じで、通り抜けに**通り抜けの追加コスト**がかかります |
| 通れて止まれる           | 何も起きません                                             |

D&D 5eなら、同じパーティを**割高で通れて、止まれない**、別のパーティを**通れない**にします。味方の脇をすり抜けて奥まで届き、敵の前では足が止まる、という動きになります。

大きいコマは占めるマスすべてが対象です。3マス幅のゴーレムの横はすり抜けられません。

**触るまではこれまでどおりです。** 3つとも、同じ画面にある**同じマスに複数のコマを置ける**に従います。入っていれば「通れて止まれる」、切ってあれば「通れない」です。

見えていないコマは数えません。暗闇の中のコマのぶんだけ範囲がへこめば、そこに何かいると分かってしまいます。

## ZOC — 敵が抑えている地面

敵に隣接したマスを通ろうとすると足が止まる、というルールを卓に入れられます。ウォーゲームのゾーン・オブ・コントロールや、ソード・ワールド2.5上級戦闘の移動妨害にあたるものです。

[部屋設定](/manual/room-settings#移動範囲とzocは、触るまでテーブルのまま)の**ZOC**で効果を選びます。

| 選択肢       | 動き                                        |
| ------------ | ------------------------------------------- |
| なし         | 何も起きません（既定）                      |
| 足止め       | ZOCのマスに入ったら、そこで移動が終わります |
| 進入不可     | ZOCのマスには入れません                     |
| 移動コスト増 | ZOCのマスに入るのに、余分に移動力を使います |

**ZOCの範囲**で何マス先まで届くかを、**移動コストの増加**で余分にかかるマス数を決めます。リーチの長い武器や大型の敵を表したいなら範囲を2にしてください。

敵かどうかはNPCかどうかで分けます。プレイヤーのコマを動かすならモンスターが、モンスターを動かすならプレイヤーのコマがZOCを張ります。パーティ設定は見ません。所属を持たないコマが多いからです。通り抜けのほうはパーティで分けるので、両方を使う卓では決めごとが2通りあることになります。

見えていない敵はZOCを張りません。暗闇の中の敵に範囲がへこめば、そこに何かいると分かってしまいます。

### 近接状態 — 隣り合った全員をひとつと数える {#engagement}

敵と味方が隣り合ったところを、1対1の関係ではなく、ひとつの塊として扱うシステムがあります。**近接状態**を入れると、隣り合ったコマは敵味方の区別なくひとつにまとまります。すでに近接状態にあるコマの隣に立てば、そこへ加わります。離れた2つの近接状態の間に1体入れば、2つはつながってひとつになります。

まとまりが解けるのは、そこに敵がいなくなったときです。味方だけが集まっても近接状態にはなりません。

近接状態にいるコマは、**そこにいる全員から**地面を抑えられます。隣にいるのが味方でも同じです。抑えられた地面が何をするかは、上の表のとおりです。**足止め**や**進入不可**と組み合わせると、近接状態の中では一歩も動けないことがあります。抜けにくさを移動力で表したいなら**移動コスト増**を選んでください。

### 近接状態から出る一歩

出るときに何が起きるかは、**離脱**で選びます。

| 選択肢                 | 動き                                                         |
| ---------------------- | ------------------------------------------------------------ |
| 陣営の重さの差で決める | 相手陣営のほうが重ければ、その差ぶんだけ余分にかかる（既定） |
| 一定のコストがかかる   | 誰が出ても**離脱コスト**のぶんだけかかる                     |
| 離脱できない           | 近接状態から出られない。中を動くことはできる                 |
| 自由に離脱できる       | 何もかからない                                               |

**陣営の重さの差で決める**は、自分の側が相手より重ければ何もかからない、という数え方です。押し通って出られます。釣り合っていれば1マスぶん、相手のほうが2重ければ3マスぶんかかります。

重さは既定ではコマの大きさで数えます。3マス幅の敵は3として数えるので、それだけ抜けにくくなります。頭数だけで数えたい卓は**コマの大きさ**を切ってください。1体を1として数えます。

出たあとにまた敵と隣り合えば、そこでまた近接状態になります。1回の移動でひとつを抜けて別の近接状態へ入れば、そのたびに離脱のぶんがかかります。

## 出したままにする

既定では、範囲は持ち上げている間だけ見えます。動かす前に見比べたいときは、テーブル設定で出したままにできます。

- **選んだコマの移動範囲を出したままにする**
- **ZOCの常時表示** — 選んだコマに対するZOCを出したままにする

どちらも**選んでいるコマ**が基準です。コマを選ぶと出て、選択を外すと消えます。持ち上げている間は、手に持っているコマのほうが優先されます。

範囲は同期しません。出るのは自分の画面だけです。他の参加者の画面には何も出ませんし、見えていない敵の情報も漏れません。

## 動けない状態のコマ

[状態異常](/manual/buff#状態異常を登録して表から付ける)のうち、シートの「移動」を0にするものが付いていると、
移動範囲は出ません。最初から入っているものでは麻痺・睡眠・石化がこれにあたります。外せば元どおり出ます。

範囲が出ないコマは、これまでどおり掴んでどこへでも置けます。止めているのは範囲の表示であって、コマそのものではありません。

## 卓の見え方を変えるだけ

移動範囲は目安の表示です。コマがそこまでしか動けなくなるわけではなく、範囲の外へドラッグすることも、ZOCを無視して通り抜けることもできます。どう扱うかは卓の取り決めしだいです。

## 道すじを決めてから歩かせる

コマを右クリック（長押し）して**移動**を選ぶと、持ち上げる代わりに移動の計画が開きます。コマはその場に立ったまま、ポインタの位置までいちばん安い道すじが線で伸びていきます。**Shiftを押しながら掴む**のでも同じものが開きます。

| したいこと             | マウス                             | 指                 |
| ---------------------- | ---------------------------------- | ------------------ |
| そこまで歩かせる       | クリック                           | タップ             |
| 途中の曲がり角を決める | Shift + クリック、または右クリック | 長押し             |
| 決めた曲がり角を消す   | 同じ場所をもう一度                 | 同じ場所をもう一度 |
| やめる                 | Esc                                | コマ自身をタップ   |

曲がり角は、遠回りを自分で選ぶためのものです。いちばん安い道すじは壁の右を回るけれど左から行きたい、というときに、左側のマスでいったん決めてから続きを引きます。決めたぶんは濃い色に変わり、残りの移動力で行ける範囲が引き直されます。置いた場所をもう一度押せば、**いちばん最後に置いた曲がり角だけ**が取り消されます。

歩くのは1マスずつです。ZOCも立入禁止も移動範囲と同じ条件で数えるので、線が引けたなら必ずそこまで歩けます。移動力を使い切ると、それ以上は線が伸びません。

止まれないマスは曲がり角にもできません。味方の上では線を区切れないので、その向こうまで引いてから決めます。

計画のあいだ、卓上の右クリックは曲がり角を置く操作になります。コンテキストメニューは開きません。移動力の項目がないコマには、この計画そのものが出ません。組み立てている間は、画面の下に操作の説明が出ます。

### 高いところへ跳ぶ

壁や岩の上へは道すじが伸びません。歩いて登れる高さではないからです。線を引いているあいだに**スペース**を押すと跳び越えに変わり、**登れない地形**（[地形](/manual/terrain)の「登れない」）を除いて、高さに関わらず行き先に選べるようになります。範囲の色が紫に変わるのが目印で、もう一度押すと歩きに戻ります。

跳ぶと決めた道すじでは、コマが手前のマスから跳んで着地します。着地したコマは地形の上に立ちます。降りるほうは切り替えずに引けます。段差の下のマスは歩きのままでも行き先に選べて、コマはそこへ跳び降ります。

跳べる距離は、既定では移動力いっぱいです。移動力6のコマは6マスの谷を一息に跳び越えます。[部屋設定](/manual/room-settings)の**移動**にある**跳躍の距離**にマス数を入れると、一度の跳躍がそこまでに縮みます。0のままなら今までどおりです。

切り替えは、線を引いているあいだ画面の下に出る帯からも選べます。**歩く**と**跳ぶ**が並んでいて、いま効いているほうに色が付きます。指で操作するときはこちらを使ってください。

## 厳密な移動

[部屋設定](/manual/room-settings)の**移動**で**厳密な移動**を入れると、コマを掴んだだけで上の計画が開きます。掴んで運んで置く、という動かし方はなくなり、線を引いてから歩かせる1通りになります。

線はいつも最短経路なので、手が揺れても遠回りとは数えません。壁と立入禁止のマスは越えられず、移動力の届かない先へは線が伸びません。行き先はいつも線の終点です。

移動力の項目がないコマは対象外です。これまでどおり掴んでどこへでも置けます。GMが敵をまとめて配置するようなときは、この設定を切るか、移動力のないコマを使ってください。

### 組み立てている様子は部屋に見えます

厳密な移動のあいだ、誰がどのコマをどう動かそうとしているかは、部屋の全員の画面に出ます。卓が待っている操作だからです。他の人の移動範囲は**破線**、道すじは自分のものより細い線で描かれるので、自分の分と取り違えません。

送っているのはコマと道すじだけで、移動範囲そのものは送りません。移動範囲は見えている敵によって形が変わるので、そのまま配ると、範囲のへこみから見えていない敵の位置が伝わってしまいます。各画面が、自分に見えているものだけで引き直します。

移動を終えるかやめると、全員の画面から消えます。

# スイッチ

盤面の物をクリックすると、GMが決めておいたことが起きます。宝箱を開けると中身がチャットに出る、レバーを引くと隠し扉が現れる、壁を調べた人にだけ手がかりが届く、といった仕掛けを作れます。

作るのも中身を見るのもGMだけです。プレイヤーは押すだけで、何が起きるかは押すまで分かりません。

## スイッチを作る（GM）

1. 地形を置いて、右クリックの**固定する**で固定します
2. もう一度右クリックして**スイッチを設定…** を選びます
3. 開いたパネルで名前をつけ、押したときの動作を並べます

固定していない地形は押せません。GMが並べ替えている最中の地形を、うっかり押してしまわないためです。作りながら確かめるときは、右クリックの**スイッチを試しに押す**かパネルの**試しに押す**を使います。試し押しは回数に数えず、「押した物を消す」も実行しません。

マップエディターの塗りもスイッチにできます（→ [塗った範囲をスイッチにする](#塗った範囲をスイッチにする)）。

## 押す

固定された地形をクリックすると押せます。マウスを乗せると、ブロックの上にスイッチの名前が出ます。`?`キーを押すと、盤面のスイッチの名前もボタンの名前と一緒に出ます（→ [ボタンの名前をまとめて見る](/manual/#ボタンの名前をまとめて見る)）。

押せなかったときは、理由がブロックの上に少しのあいだ出ます。見学者は、**見学者も押せる**にしたスイッチだけ押せます。

## 押したときに起きること

動作は上から順に実行されます。2つ目からは、前の動作のあとの待ち時間（最大10秒）を入れられます。1つのスイッチに並べられる動作は20個までです。

| 動作                           | 中身                                                                                                            |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| 発言                           | チャットに文を送ります。発言者は下記                                                                            |
| 秘密の結果                     | 伏せた行を送ります。「押した人とGMだけが読める」か「GMだけが読める」を選びます                                  |
| 効果音・エフェクト・カットイン | 部屋にあるものから名前で選びます。エフェクトは押した人のキャラにかかります                                      |
| 伏せた物を見せる               | GMが伏せておいた物を、伏せたときの場所に戻します（→ [物を伏せて、スイッチで出す](#物を伏せて、スイッチで出す)） |
| 伏せる                         | 卓の上の物を、その場で伏せます                                                                                  |
| 押した物を消す                 | ほかの動作をすべて終えてから、スイッチの地形を卓から消します                                                    |
| コマを呼び出す                 | キャラクターの複製を、スイッチのそばか押した人のコマのそばに最大10体並べます                                    |
| テーブルを切り替える           | 全員の見ているテーブルを切り替えます。場面転換に使います                                                        |
| 押した人のコマを運ぶ           | 押した人のキャラを指定のマスへ運びます。別のテーブルを選ぶと、全員の視点も一緒に移ります                        |
| テーブル設定を変える           | 暗闇と戦場の霧のオン・オフ、テーブル画像、BGMを変えます                                                         |

コマを呼び出すときは、元にするキャラクターを墓場か伏せた場所に置いておくと扱いやすくなります。複製は空いているマスに近い順で置かれ、置く場所がなければその分は作られません。

## 誰として発言するか

**発言者**は次の3つから選びます。

- **押した人（選んでいるキャラ）** — チャット欄で選んでいるキャラとして発言します。ふだんの発言と同じなので、`1d100<={目星}`のようなダイスや`{HP}`の参照、`:HP-1`のリソース操作がそのまま使えます
- **この物の名前** — 地形の名前で発言します。「古い扉がきしむ」と扉自身に語らせる使い方です。ダイスは振られ、`{参照}`は押した人のキャラの値で埋まります。リソース操作は効きません
- **システム** — 「システム」の名前で出します。ダイスは振られません

送り先のタブは、指定しなければ押した人が開いているタブです。発言の動作があるスイッチは、そのタブで発言できない人には押せません。

## 押せる条件と回数

| 設定                     | 動き                                                                                                               |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| 押せる距離               | 押した人のキャラが、そのマス数以内にいるときだけ押せます。斜めも1マスで数え、壁越しでも数えます。0ならどこからでも |
| 見えているときだけ押せる | 押した人の視界に入っているときだけ押せます                                                                         |
| 回数                     | 何度でも／一度きり（全体で1回）／キャラごとに1回／1ラウンドに1回                                                   |

距離と回数でいう「押した人のキャラ」は、チャット欄で選んでいるキャラです。キャラを選ばずに押した場合、キャラごとの回数は人ごとに数えます。

GMは距離と視界を問われません。回数を使い切った地形のスイッチは、右クリックの**押された記録を消す**で元に戻せます。塗りのスイッチはテーブルを右クリックし、**押された記録を消す**に並ぶ一覧から選びます。

## 物を伏せて、スイッチで出す

GMが地形かキャラクターを右クリックして**伏せる（スイッチで見せる）** を選ぶと、その物は卓から見えなくなります。伏せた地形は、通り抜けられて見通せる状態です。伏せたキャラクターはインベントリの共有にも出ません。

伏せた物を戻す方法は2つあります。

- スイッチの動作**伏せた物を見せる**で、伏せたときの場所に戻す
- GMがテーブルを右クリックし、**伏せた物を見せる**から選ぶ

隠し扉が現れる、宝箱が開くと敵が出る、といった仕掛けはこの組み合わせで作ります。スイッチの動作**伏せる**では、共有メモ・ダイス・コイン・山札も伏せられます。

## 塗った範囲をスイッチにする

[マップエディター](/manual/map-editor#イベント塗り-—-コマが入ると起きること)のイベント塗りで、**発火**を**押したとき（スイッチ）** にします。設定欄がスイッチのものに切り替わり、地形のスイッチと同じことを決められます。

テーブルへ反映すると、塗ったマスをクリックして押せるようになります。上に固定した地形が置いてあっても、その下の塗りを押せます。卓には、スイッチの名前と「クリックで押す」が書かれます。

見せる相手の設定はそのまま効きます。GMにしか見えていない塗りは、プレイヤーには押せません。**押した物を消す**を入れた塗りは、押されると片付けられ、GMにだけ見える状態になります。押せなかった理由は、マウスポインタの横に出ます。

GMがテーブルの右クリックから**押された記録を消す**を選ぶと、押された塗りが一覧に出ます。選んだ塗りは描いたときの状態に戻ります。片付けた塗りはまた押せるようになり、押されて正体を現した塗りは、もとの**見せる相手**に戻ります。

## 中身の秘密について

スイッチの中身は、右クリックのメニューにもパネルにもGMにしか出ません。ただし、中身は部屋のデータに入っています。部屋の保存ファイルを受け取った人は中身を読めるので、プレイヤーに保存ファイルを渡すときは気をつけてください。

## 古い版との関係

スイッチに対応していない版で部屋を開くと、次のようになります。

- 地形のスイッチは、ただの地形として読まれます
- 押すタイプの塗りは、使用済みの罠として読まれ、発動しません
- 伏せた地形は見えません。伏せたキャラクターは、共有インベントリに出ます
- その版で保存し直すと、スイッチと伏せた地形は失われます

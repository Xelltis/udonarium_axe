# ロール（GM / PL / 見学）

参加者には**ゲームマスター（GM）／プレイヤー（PL）／見学**の3つのロール（役割）があります。ロールによって、できる操作や見える情報が変わります。ロールは参加者全員で同期され、[接続パネル](/manual/#画面の見かた)（接続情報）から設定します。

<Shot src="connection-panel" alt="接続パネル。ニックネーム・ID・役割の選択ボタンが並んでいる" width="430" caption="接続パネルの「役割」からGM / PL / 見学 を切り替えます" />

| ロール               | 主な権限                                                                             |
| -------------------- | ------------------------------------------------------------------------------------ |
| ゲームマスター（GM） | すべての操作が可能。隠し情報やシークレットも閲覧でき、公開範囲・オーナーを管理できる |
| プレイヤー（PL）     | 通常の操作（コマの移動・作成・編集・チャットなど）                                   |
| 見学                 | 読み取り専用。閲覧はできるが、卓上の操作や編集は一切できない                         |

## 自分のロールを設定する

FABメニューの**接続**から接続パネルを開くと、自分の名前の下に**役割**の選択ボタン`GM / PL / 見学`が並びます。**プレイヤーと見学はいつでも自由に切り替えられ**、その場で全員に反映されます。

- **GMは自分では選べません。** ほかにGMがいる間、GMボタンは押せません（横取り防止）。GMになるには、既存のGMに割り当ててもらうか、自分で**部屋を作成**します。
- 部屋を新しく作成した人は、自動的に**GM**になります。
- 設定は部屋に入る前からでき、見学やプレイヤーをあらかじめ選んでおけます。
- 部屋に入る前にGMを選んでいても、ほかの人が作った部屋には**プレイヤーとして入ります**。GMのまま入れるのは、その部屋でGMだった人が、再読み込みなどで抜けたあと同じタブから入り直すときだけです。

## 招待リンクで参加者を招く

接続パネルのルーム欄には**招待リンク**が表示されます。これを渡された人は、**リンクを開くだけでその部屋に入室**できます。
ロビーから部屋を探す必要も、部屋名や合言葉を口頭で伝える必要もありません。

- **プレイヤー用 / 見学用**をボタンで切り替えると、リンクにロールが埋め込まれます。開いた人はそのロールで入室します
- 合言葉つきの部屋では **「合言葉を含める」** を切り替えられます
  - **含める** — 開くだけで入室できます。リンクを知っている人は誰でも入れる状態になります
  - **含めない** — 部屋の場所だけを伝え、合言葉は入室時に入力してもらいます
- **コピー**でクリップボードに入ります。うまくコピーできない環境では、隣の入力欄から手で選択してください

リンクを開くと入室処理が自動で始まり、画面上部に進行状況が出ます。部屋が見つからないときや合言葉が合わないときは、
その旨が表示され、**ロビーを開く**ボタンが出ます。

### 配信用（透過画面）

同じ招待リンクの欄で**配信用（透過画面）** に切り替えると、OBSのブラウザソースに貼るためのURLになります。
開いた画面は盤面もパネルも出さず、**直近の発言と手番だけ**を透過の背景に映します。

- **見学のリンクを渡してください。** 配信用に開いた画面も通常の参加者として1枠を使います
- 部屋のサーバーでは、配信用の画面はログインしていても見学として入ります。同じブラウザで開いても、自分の席とは別の1枠になります
- 配信用の画面は卓の他の人には影響しません（ノベルモードと違い、めくった位置は同期しません）
- **密談・伏せたダイス・その役割に見えないタブは映りません。** 入室が終わるまでの一瞬も、狭いほうの役割で判断します

::: warning 合言葉入りのリンクの扱い
リンクに載る合言葉は**そのままの文字列では書き込まれません**（部屋ごとに異なる形に変換されます）。
URLを目で読んでも、チャットのプレビューやスクリーンショットからも、そのままでは読めません。

ただしこれは目隠しであって、暗号ではありません。変換に使う鍵は同じリンクの中に入っているため、
**リンクを持っている人は合言葉を取り出せます**。他の場所でも使っている合言葉を部屋に流用しないでください。
リンクが流れれば、その文字列も一緒に流れます。

リンクを持っている人はその部屋に入室できるので、SNSなど不特定多数の目に触れる場所には貼らないでください。
公開の場で募集するときは「合言葉を含めない」リンクを使い、合言葉は別の経路で渡してください。
:::

## GMが他の参加者のロールを変更する

GMのときは、接続パネルの**参加者一覧**で各参加者の右側にロールの選択メニューが表示され、他の参加者をGM / PL / 見学に変更できます。

参加者一覧やカーソルには、ロールが色付きのバッジ（GM / PL / 見学）で表示されるので、誰がどの役割かひと目で分かります。

## 各ロールでできること

### 見学（読み取り専用）

見学は卓の様子を見るための役割で、**操作するためのボタンやメニューが出ません**。

- コマ・カード・ダイスなどの**移動・回転・作成・削除・複製**ができません
- 右クリックのコンテキストメニュー、詳細・編集パネルの入力、ファイルの読み込みなどができません
- チャットの発言のメニューは開けます。出るのは本文のコピーや個人しおりなど、見学でもできる操作だけです
- 発言を[共有メモ](/manual/notes)にするボタンも出ません（メモは卓に置くものなので）
- チャットの[共有しおり](/manual/chat#しおり)はたどれますが、挟む・外す・題名を変えることはできません。自分にだけ見える個人しおりは使えます
- [ジュークボックス](/manual/jukebox#再生の操作)で、部屋の曲や環境音を流したり止めたりできません。試聴と自分の音量は変えられます
- [ノベルモード](/manual/visual-novel)の**SE再生**と、話すキャラクターの立ち位置・反転は出ません。チャットの色設定は、自分の発言の色を変えるものになります
- チャットの閲覧や、テーブルの閲覧は可能です
- **チャットログの保存（書き出し）は、ロールに関わらず誰でも行えます**
- 暗闇が有効な卓では、[全プレイヤーの視界を合成した範囲](/manual/vision-lighting)が見えます

::: warning 見学は自分で外せます
ロールは各自が自分の画面で選ぶものです。
見学とプレイヤーは接続パネルのボタンひとつで行き来でき、ほかにGMがいない部屋ならGMも名乗れます。

見学は「操作しない」という卓の約束であって、操作を封じる仕組みではありません。
見学のつもりで招待リンクを渡しても、受け取った人は自分の画面でプレイヤーに変えられます。配信用の画面も同じです。

隠しておきたいものがある卓では、ロールを仕切りに使わないでください。確実なのは部屋を分けることです。
合言葉は入室を絞りますが、入ったあとのロールは絞りません。
[公開範囲](/manual/disclosure)やシークレットも、[カード](/manual/cards)と同じく画面上の取り決めです。

ここまではSkyWay版の話です。部屋のサーバーでは、ロールはサーバーが決めて守ります（→ [部屋のサーバーでのロール](#room-server)）。公開範囲で絞った共有メモの中身やシークレットの中身も、見てよい人の環境にしか届きません。
:::

### ゲームマスター（GM）

GMは卓の進行役として、ほかの参加者には隠れている情報も確認できます。

- [インベントリ](/manual/inventory)で非表示にしたキャラクター
- シークレットダイスの出目、シークレットチャットの内容、隠した名前
- [公開範囲](/manual/disclosure)を「GMのみ」「特定プレイヤー」に設定した情報

さらにGM向けの管理機能として、[オブジェクト一覧（GM）](/manual/gm-object-list)で全オブジェクトを俯瞰・管理でき、[チャット](/manual/chat)はタブごとに閲覧・発言できるロールを設定できます。[ジュークボックス](/manual/jukebox#音量)の部屋の音量を動かしたり、[シャッフルとリピート](/manual/jukebox#再生の操作)を切り替えたりできるのもGMだけです。

#### GMツールバー

<Shot src="gm-toolbar" alt="GMツールバー。アイコンが横一列に並んでいる" width="620" caption="GMのときだけ出るツールバー。オブジェクト一覧・NPCバー・暗闇などへの入口" />

GMのときは画面上部に**GMツールバー**が表示され、よく使うGM機能にすぐアクセスできます（ドラッグで移動可能）。見出しの横の矢印で畳めるほか、FABメニューの[ウィジェット](/manual/#ウィジェット)で**GMツール**を消すこともできます。

- **オブジェクト一覧** — [全オブジェクトの俯瞰・管理](/manual/gm-object-list)
- **NPCバー** — NPCのアイコンを並べ、クリックでチャットパレットを素早く呼び出し／切り替え
- **同行** — キャラクターを[パーティに編成](/manual/party)し、視界を共有させる
- **インベントリ** — 卓の上のコマやオブジェクトを[一覧で管理](/manual/inventory)（FABメニューの**ゲームリソース**と同じパネル）
- **暗闇のON / OFF** — テーブルの[暗闇](/manual/vision-lighting)をワンクリックで切り替え
- **戦場の霧のON / OFF** — テーブルの[戦場の霧](/manual/vision-lighting#戦場の霧-探索)をワンクリックで切り替え
- **全員の視点を決める** — 部屋の全員を、同じコマの目線の[ダンジョンドリィマスターモード](/manual/dungeondry-master#全員の視点をそろえる-gm)に入れる
- **名前 / リソースバー / バフ / 吹き出しの表示** — コマの名前と頭上のリソースバー・バフ・吹き出しを、この画面だけでまとめて隠す・戻す（[PLツールバー](/manual/pl-tools#リソースバーとバフを隠す)と共通）
- **オフラインの所有を解放** — 接続していないオーナーの[所有をまとめて解除](/manual/disclosure#オーナー)（途中で抜けて入り直した人の手当てに）
- **行動順** — 戦闘中はラウンド数と現在の手番が並び、前後の送りボタンで[手番を回せます](/manual/turn-order)
- **ペルソナ** — 特定のプレイヤー・見学から卓がどう見えるかを[プレビュー](/manual/vision-lighting)

ツールバーの中身も、[メニューの編集](/manual/#メニューを自分で組む)で足したり外したりできます。GMツールのタブはGMのときだけ出ます。

GMが使う道具でも、ツールバーにないものはFABメニューから開きます。[マップエディター](/manual/map-editor)と[マップ生成](/manual/map-generator)は**テーブル関連**、[手札](/manual/cards#手札)と[バフマネージャー](/manual/buff#卓じゅうのバフを一覧する)は**ゲームリソース**、[エフェクト集](/manual/map-effects)は**メディア**にあります。

## 部屋のサーバーでのロール {#room-server}

[部屋のサーバー（ベータ）](/guide/backend#room-server)を使う配置先では、ロールは部屋のサーバーが決めて守ります。
接続パネルの「役割」は選択ボタンにならず、サーバーが決めたロールを表示するだけです。

部屋を作った人がGMになり、ほかの人はログインして入ればPL、ログインしないで入れば見学になります。
ログインの入り口は、ロビーの上にある「Discordでログイン」です。
ログインは小さな別の窓で開きます。ブラウザが窓を開かせないときはページごとログインへ移り、入っていた部屋からは一度出ます。ログインのあと、招待リンクを開き直すか、ロビーから部屋を選んでください。
一度入った人のロールはサーバーが覚えていて、抜けて入り直しても同じロールに戻ります。

GMは、参加者一覧のメニューでほかの参加者のロールを変えられます。
ログインしていない人を見学以外にする変更と、部屋からGMがいなくなる変更は、サーバーが断ります。
断った理由はシステムタブに出ます。

見学は卓の物を書き換えられません。キャラクターとして話しても、リソース操作（`:HP-3`など）・立ち絵の切り替え・`dice:`で卓のダイスに出目を出すことは反映されず、カットインも始まりません。スイッチも押せず、点呼・投票とアラームも始められません。

招待リンクには、サーバーが署名した招待が載ります。
GMはGM・PL・見学のどれで招くかを選べ、招待は作ってから30日使えます。
招待で決まるのは、ログインした人が初めてその部屋に入るときのロールです。
GM以外の人のリンクには招待が載らず、開いた人はログインしていればPL、していなければ見学として入ります。
途中でGMになった人のリンクには招待が載り、GMでなくなった人のリンクからは外れます。
GMでなくなった人が前に配ったGMの招待も効かなくなり、開いた人はPLとして入ります。
30日を過ぎた招待や、サーバーの鍵が替わる前の招待も、断られずにPLとして入り、そのロールが覚えられます。
あとから新しい招待を渡しても変わらないので、GMが参加者一覧のメニューからロールを変えてください。

部屋を削除できるのもGMだけです（→ [部屋のサーバーの部屋](/manual/rooms#room-server)）。

## GMがいなくなったとき

GMが退室・切断などでいなくなると、シークレットや隠し情報は誰にも見えない状態になり、卓はGMの復帰を待ちます。

- **ロールはタブを開いたままの再接続なら自動で復帰します。** ページを再読み込みした場合も、同じ部屋に入り直せば元のロールに戻ります。
- **GMが一人もいなくなると、GMボタンが押せるようになります。** 残った参加者の誰かが自分を**GM**に設定して進行を引き継げます（GMが戻れば、再び横取りはできなくなります）。
- 部屋のサーバーでは、ロールはサーバーに残るので、GMが入り直せばGMのままです。ほかの人が自分でGMになることはできません。
- 部屋のサーバーでアカウントを削除すると、ログインし直しても別のアカウントになります。元の席や手札には戻れません。GMだった部屋にGMとして戻るには、新しいアカウントでその部屋に初めて入るときに、削除する前に自分が出したGMの招待リンクから入ります。招待が効くのは初めて入るときだけです。ログインはタブのあいだで共有されるので、その部屋に入っている画面があれば、ほかのタブのものも含めて、ログインし直す前に部屋を出てください。ほかにGMがいれば、GMにしてもらうこともできます。GMに戻れば、その部屋を削除することもできます。GMの招待は作ってから30日のあいだ効き続け、ほかの人が開いてもGMとして入れます。サーバーは削除したアカウントもGMとして数えるので、ほかのGMが自分を降ろしても断られません。GMが自分ひとりの部屋があるなら、削除する前にほかの参加者をGMにしてください。

::: tip 表示されるIDについて
ユーザーIDは内部的には長い識別子ですが、画面では先頭6文字の短いIDで表示されます。完全なIDはマウスを乗せると確認できます。
:::

# ロール（GM / PL / 見学）

このページは、参加者の3つのロール（役割）と、ロールごとにできることを説明します。
ロールは、ゲームマスター（GM）・プレイヤー（PL）・見学の3つで、できる操作と見える情報が変わります。
自分のロールは接続パネルで選び、GMはほかの参加者のロールも変えられます。
ほかの人を部屋に呼ぶ招待リンクも、ここで説明します。

<Shot src="connection-panel" alt="接続パネル。ニックネーム・ID・役割の選択ボタンが並んでいる" width="430" caption="接続パネルの「役割」で、GM・PL・見学を切り替えます" />

| ----------------------------------------------------------------------------------------------------------------------- | :--: | :----------------------: | :----------------------------------------: |

| チャットで発言する                                                                                                      |  ○   |            ○             | タブで許されたときだけ（既定では読むだけ） |
| チャットログを保存する（書き出す）                                                                                      |  ○   |            ○             |                     ○                      |
| コマ・カード・ダイスなどを動かす・作る・消す・編集する                                                                  |  ○   |            ○             |                     ×                      |
| ジュークボックスで、部屋の曲と環境音を流す・止める                                                                      |  ○   |            ○             |                     ×                      |
| 物の[公開範囲](/manual/disclosure)とオーナーを変える                                                                    |  ○   |  自分がオーナーの物だけ  |                     ×                      |
| シークレットダイスの出目・隠した名前・「GMのみ」の情報を見る                                                            |  ○   |            ×             |                     ×                      |
| [インベントリ](/manual/inventory)で隠したキャラクターを見る                                                             |  ○   |            ×             |                     ×                      |
| ほかの参加者のロールを変える                                                                                            |  ○   |            ×             |                     ×                      |
| チャットのタブごとに、読める人と書ける人を決める                                                                        |  ○   |            ×             |                     ×                      |
| ジュークボックスの部屋の音量・シャッフル・リピートを変える                                                              |  ○   |            ×             |                     ×                      |
| [オブジェクト一覧](/manual/gm-object-list)・[マップエディター](/manual/map-editor)・[マップ生成](/manual/map-generator) |  ○   |            ×             |                     ×                      |
| [暗闇](/manual/vision-lighting)のテーブルで見える範囲                                                                   | 全部 | 自分のキャラクターの視界 |      全プレイヤーの視界を合わせた範囲      |

ロールは、部屋の全員に伝わります。
参加者一覧とカーソルには、ロールが色付きのバッジ（GM・PL・見学）で出るので、誰がどの役割か、ひと目で分かります。

## 自分のロールを決める

1. FABメニューの**接続**を押して、接続パネルを開きます。
2. 自分の名前の下の**役割**で、**PL**か**見学**を押します。

その場で、部屋の全員に伝わります。
PLと見学は、いつでも自由に行き来できます。
部屋に入る前から選んでおけます。

GMは、自分では選べません。
ほかにGMがいるあいだ、**GM**のボタンは押せません（横取りを防ぐためです）。
GMになるには、いまのGMに割り当ててもらうか、自分で部屋を作ります。
部屋を作った人は、自動でGMになります。

部屋に入る前にGMを選んでいても、ほかの人が作った部屋には、PLとして入ります。
GMのまま入れるのは、その部屋でGMだった人が、読み込み直しなどで抜けたあと、同じタブから入り直すときだけです。

## ほかの参加者のロールを変える（GM）

GMのときは、接続パネルの参加者一覧で、各参加者の右側にロールの選択が出ます。
選ぶと、その参加者のロールがGM・PL・見学に変わります。

## 招待リンクで参加者を招く

接続パネルには、部屋に入っているあいだ**招待リンク**が出ます。
受け取った人は、リンクを開くだけでその部屋に入れます。
ロビーから部屋を探す必要も、部屋の名前やパスワードを伝える必要もありません。

1. 接続パネルの**招待リンク**の欄で、招く人のロールのボタン（**PL**か**見学**）を押します。リンクにロールが入り、開いた人はそのロールで入ります。
2. パスワードのある部屋では、**合言葉を含める**を入れるか外すかを決めます（下の表）。
3. **コピー**を押して、リンクを渡します。コピーできない環境では、隣の入力欄から手で選んでコピーしてください。

| 合言葉を含める | 開いた人                                 | 向いている場面                           |
| -------------- | ---------------------------------------- | ---------------------------------------- |
| 入れる         | リンクを開くだけで入れます               | 身内に、チャットやメッセージで渡す       |
| 外す           | 部屋に入るときに、パスワードを聞かれます | 公開の場で募集する。パスワードは別に渡す |

リンクを開くと、入室が自動で始まり、画面の上に進み具合が出ます。
部屋が見つからないときや、パスワードが合わないときは、その旨と**ロビーを開く**のボタンが出ます。

::: warning リンクを持っている人は、パスワードを取り出せます
リンクに載るパスワードは、部屋ごとに異なる形に変えてあるので、URLを見てもそのままでは読めません。
ただし、これは目隠しで、暗号ではありません。
ほかのサービスで使っているパスワードを、部屋に使い回さないでください。
くわしくは[招待リンクのパスワード](/manual/rooms#招待リンクのパスワード)にあります。
:::

### 配信用（透過画面）

招待リンクの欄で**配信用（透過画面）** を入れると、配信ソフト（OBSなど）のブラウザソースに貼るためのURLになります。
開いた画面は、テーブルもパネルも出さず、直近の発言と手番だけを、透過の背景に映します。

- 見学のリンクを渡してください。配信用に開いた画面も、ふつうの参加者として1人分の枠を使います
- 部屋のサーバーでは、配信用の画面は、ログインしていても見学として入ります。同じブラウザで開いても、自分の席とは別の1人分になります
- 配信用の画面は、ほかの人には影響しません（ノベルモードと違い、めくった位置は同期しません）
- 秘話・伏せたダイス・その役割に見えないタブは映りません。入室が終わるまでの一瞬も、狭いほうの役割で決めます

## 各ロールのくわしい説明

### 見学（読み取り専用） {#見学-読み取り専用}

見学は、卓の様子を見るための役割で、操作するためのボタンやメニューが出ません。

- コマ・カード・ダイスなどを、動かす・回す・作る・消す・複製することができません
- 右クリックのメニュー、詳細や編集のパネルの入力、ファイルの読み込みができません
- チャットの発言のメニューは開けます。出るのは、本文のコピーや個人しおりなど、見学でもできる操作だけです
- 発言を[共有メモ](/manual/notes)にするボタンは出ません（メモはテーブルに置くものなので）
- チャットの[共有しおり](/manual/chat#しおり)はたどれますが、挟む・外す・題名を変えることはできません。自分にだけ見える個人しおりは使えます
- [ジュークボックス](/manual/jukebox#再生の操作)で、部屋の曲や環境音を流したり止めたりできません。試聴と、自分の音量は変えられます
- [ノベルモード](/manual/visual-novel)の**SE再生**と、話すキャラクターの立ち位置・反転は出ません。チャットの色設定は、自分の発言の色を変えるものになります
- 暗闇のテーブルでは、[全プレイヤーの視界を合わせた範囲](/manual/vision-lighting)が見えます

::: warning SkyWay版では、見学は自分で外せます
ロールは、各自が自分の画面で選ぶものです。
見学とPLは接続パネルのボタン1つで行き来でき、ほかにGMがいない部屋なら、GMも名乗れます。
見学は「操作しない」という卓の約束で、操作を封じる仕組みではありません。
見学のつもりで招待リンクを渡しても、受け取った人は自分の画面でPLに変えられます。
配信用の画面も同じです。

隠しておきたいものがある卓では、ロールを仕切りに使わないでください。
確実なのは、部屋を分けることです。
パスワードは入室を絞りますが、入ったあとのロールは絞りません。
[公開範囲](/manual/disclosure)やシークレットも、[カード](/manual/cards)と同じく、画面の上での取り決めです。

部屋のサーバーでは、ロールはサーバーが決めて守ります（→ [部屋のサーバーでのロール](#room-server)）。
公開範囲で絞った共有メモの中身や、シークレットの中身も、見てよい人の環境にしか届きません。
:::

### ゲームマスター（GM）

GMは卓の進行役として、ほかの参加者には隠れている情報も見られます。

- [インベントリ](/manual/inventory)で非表示にしたキャラクター
- シークレットダイスの出目、シークレットチャットの内容、隠した名前
- [公開範囲](/manual/disclosure)を「GMのみ」「特定PL」にした情報

GMの管理の道具として、[オブジェクト一覧（GM）](/manual/gm-object-list)でテーブルの上の物をまとめて見て直せます。
[チャット](/manual/chat)では、タブごとに読める人と書ける人を決められます。
[ジュークボックス](/manual/jukebox#音量)の部屋の音量を動かしたり、[シャッフルとリピート](/manual/jukebox#再生の操作)を切り替えたりできるのも、GMだけです。

#### GMツールバー

<Shot src="gm-toolbar" alt="GMツールバー。アイコンが横一列に並んでいる" width="620" caption="GMのときだけ出るツールバー。オブジェクト一覧・NPCバー・暗闇などへの入口" />

GMのときは、画面の上に**GMツールバー**が出ます。
ドラッグで動かせます。
見出しの横の矢印で畳めるほか、FABメニューの[ウィジェット](/manual/screen#ウィジェット)で**GMツール**を隠すこともできます。

| ボタン                             | すること                                                                                                                                                |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| オブジェクト一覧                   | [テーブルの上の物をまとめて見て直す](/manual/gm-object-list)                                                                                            |
| NPCバー                            | NPCのアイコンを並べ、押すとチャットパレットを呼び出す・切り替える                                                                                       |
| 同行                               | キャラクターを[パーティに編成](/manual/party)し、視界を分け合わせる                                                                                     |
| インベントリ                       | テーブルの上のコマを[一覧で管理する](/manual/inventory)（FABメニューの**ゲームリソース**と同じパネル）                                                  |
| 暗闇                               | テーブルの[暗闇](/manual/vision-lighting)のオンとオフを切り替える                                                                                       |
| 戦場の霧                           | テーブルの[戦場の霧](/manual/vision-lighting#戦場の霧-探索)のオンとオフを切り替える                                                                     |
| 全員の視点を決める                 | 部屋の全員を、同じコマの目線の[ダンジョンドリィマスターモード](/manual/dungeondry-master#全員の視点をそろえる-gm)に入れる                               |
| 名前・リソースバー・バフ・吹き出し | コマの名前と、頭上のリソースバー・バフ・吹き出しを、この画面だけでまとめて隠す・戻す（[PLツールバー](/manual/pl-tools#リソースバーとバフを隠す)と同じ） |
| オフラインの所有を解放             | 接続していないオーナーの[所有をまとめて外す](/manual/disclosure#オーナー)（途中で抜けて入り直した人のため）                                             |
| 行動順                             | 戦闘中はラウンド数といまの手番が並び、前後の送りボタンで[手番を回す](/manual/turn-order)                                                                |
| ペルソナ                           | 特定のPLや見学から、テーブルがどう見えるかを[確かめる](/manual/vision-lighting)                                                                         |

ツールバーの中身も、[メニューの編集](/manual/screen#メニューを自分で組む)で足したり外したりできます。
GMツールのタブは、GMのときだけ出ます。

GMが使う道具でも、ツールバーにないものはFABメニューから開きます。

- [マップエディター](/manual/map-editor)と[マップ生成](/manual/map-generator)は**テーブル関連**
- [手札](/manual/cards#手札)と[バフマネージャー](/manual/buff#卓全体のバフの一覧)は**ゲームリソース**
- [エフェクト](/manual/map-effects)は**メディア**

## 部屋のサーバーでのロール {#room-server}

[部屋のサーバー（ベータ）](/guide/choose)を使う配置先では、ロールは部屋のサーバーが決めて守ります。
接続パネルの**役割**は選ぶボタンにならず、サーバーが決めたロールを出すだけです。

| 入りかた               | ロール                                     |
| ---------------------- | ------------------------------------------ |
| 部屋を作った           | GM                                         |
| ログインして入った     | PL（GMの招待リンクなら、その招待のロール） |
| ログインしないで入った | 見学                                       |
| 一度入ったことがある   | 前と同じロール（サーバーが覚えています）   |

### ログインする

1. ロビーの上の**Discordでログイン**を押します。
2. 小さな別の窓で、Discordのログインの画面が開きます。Discordで許可すると、ログインが済みます。ロビーの上に「（名前） でログインしています」と出ます。
3. 招待リンクを開き直すか、ロビーから部屋を選んで入ります。

ブラウザが別の窓を開かせないときは、ページごとログインの画面へ移り、入っていた部屋からは一度出ます。

### ロールを変える

GMは、参加者一覧のメニューで、ほかの参加者のロールを変えられます。
次の変更は、サーバーが断ります。
断った理由は、チャットのシステムタブに出ます。

| 断られる変更                         | システムタブに出る文                                               |
| ------------------------------------ | ------------------------------------------------------------------ |
| ログインしていない人を見学以外にする | 「（名前）はログインしていないため、見学のままです」               |
| 部屋からGMがいなくなる               | 「部屋のGMがいなくなるため、（名前）の役割は変えられませんでした」 |
| GMでない人が変える                   | 「役割を変えられるのはGMだけです」                                 |

### 見学にできないこと

見学は、テーブルの物を書き換えられません。
キャラクターとして話しても、リソース操作（`:HP-3`など）・立ち絵の切り替え・`dice:`でテーブルのダイスに出目を出すことは反映されず、カットインも始まりません。
スイッチも押せず、点呼・投票とアラームも始められません。

### 招待リンクとロール

招待リンクには、サーバーが署名した招待が載ります。

- GMは、GM・PL・見学のどれで招くかを選べます。招待は、作ってから30日使えます
- 招待で決まるのは、ログインした人が初めてその部屋に入るときのロールです
- GM以外の人のリンクには、招待が載りません。開いた人は、ログインしていればPL、していなければ見学として入ります
- 途中でGMになった人のリンクには招待が載り、GMでなくなった人のリンクからは外れます
- GMでなくなった人が前に配ったGMの招待も効かなくなり、開いた人はPLとして入ります
- 30日を過ぎた招待や、サーバーの鍵が替わる前の招待で入った人も、断られずにPLとして入り、そのロールが覚えられます。あとから新しい招待を渡しても変わらないので、GMが参加者一覧のメニューからロールを変えてください

部屋を削除できるのも、GMだけです（→ [部屋のサーバーの部屋](/manual/rooms#room-server)）。

## GMがいなくなったとき

GMが部屋を出たり接続が切れたりしていなくなると、シークレットや隠した情報は誰にも見えない状態になり、卓はGMが戻るのを待ちます。

- タブを開いたままつなぎ直したときは、ロールは自動で戻ります。ページを読み込み直したときも、同じ部屋に入り直せば、元のロールに戻ります
- GMが一人もいなくなると、**GM**のボタンが押せるようになります。残った参加者の誰かが、自分をGMにして進行を引き継げます。GMが戻れば、また横取りはできなくなります
- 部屋のサーバーでは、ロールはサーバーに残るので、GMが入り直せばGMのままです。ほかの人が自分でGMになることはできません

### 部屋のサーバーでアカウントを削除したとき

アカウントを削除すると、ログインし直しても別のアカウントになり、元の席や手札には戻れません。
GMだった部屋にGMとして戻るには、新しいアカウントでその部屋に初めて入るときに、削除する前に自分が出したGMの招待リンクから入ります。

- 招待が効くのは、初めて入るときだけです
- ログインはタブのあいだで共有されます。その部屋に入っている画面があれば、ほかのタブのものも含めて、ログインし直す前に部屋を出てください
- ほかにGMがいれば、GMにしてもらうこともできます。GMに戻れば、その部屋を削除することもできます
- GMの招待は、作ってから30日のあいだ効き続け、ほかの人が開いてもGMとして入れます
- サーバーは、削除したアカウントもGMとして数えるので、ほかのGMが自分を降ろしても断られません。GMが自分ひとりの部屋があるなら、削除する前に、ほかの参加者をGMにしてください

::: tip 画面に出るID
ユーザーIDは長い識別子ですが、画面では先頭の6文字だけを出します。
マウスを乗せると、全体を確かめられます。
:::

## うまくいかないとき

| 見えるもの                                     | 原因と直しかた                                                                                                                                                   |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **GM**のボタンが押せない                       | ほかにGMがいます。いまのGMに、参加者一覧で割り当ててもらいます                                                                                                   |
| 自分で作った部屋なのに、PLになっている         | 読み込み直したときに、別のタブから入り直しています。ほかにGMがいなければ、**GM**を押して戻ります。部屋のサーバーでは、作ったときと同じアカウントでログインします |
| 見学なのに、操作のボタンが出ない               | 見学には出ません。操作するときは、**PL**に切り替えます（部屋のサーバーでは、ログインしてGMにPLにしてもらいます）                                                 |
| 招待リンクで入ったら、思ったロールにならない   | 部屋のサーバーでは、一度入った人のロールはサーバーが覚えています。GMが参加者一覧で変えます                                                                       |
| 「部屋のサーバーから招待をもらえませんでした」 | 部屋のサーバーとのやりとりが一時的に失敗しました。しばらくしてから、接続パネルを開き直します                                                                     |
| ログインの窓が開かない                         | ブラウザが別の窓を止めています。ページごとログインの画面へ移るので、そのままログインし、部屋に入り直します                                                       |

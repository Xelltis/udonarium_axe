# 射程範囲

攻撃や効果の届く範囲をテーブル上に表示するオブジェクトです。

<Shot src="range" alt="キャラクターを中心に広がる円形の射程範囲" caption="射程範囲は7種類の形状から選べます" />

## 射程範囲を置く

テーブルの何もない場所を右クリックし、**「射程範囲を作成」** にカーソルを合わせて形状を選びます。

## 形状を変える

射程範囲を**右クリック** → **「形状変更」** から、次の7種類に切り替えられます。

- 直線 / コーン / 三角形 / 四角形 / 五角形 / 六角形 / 円形

範囲は回転でき、グリッドに合わせて描画されます。

## 詳細を編集する

右クリック → **「射程範囲を編集」** で詳細パネルを開き、サイズや色などを調整できます。
セル単位で自由に塗る**カスタム範囲**（`CUSTOM`）も利用できます。

移動・コピー・削除など共通の操作は[オブジェクトの基本操作](/manual/objects)を参照してください。

# 射程範囲

このページは、攻撃や効果の届く範囲をテーブルに描く「射程範囲」を説明します。
円・扇（コーン）・直線など8種類の形と、マスを自由に塗る任意マスから選べ、範囲に入ったコマをまとめてターゲットにできます。
置いて直すのはGMとPLです。

<Shot src="range" alt="キャラクターを中心に広がる円形の射程範囲" caption="射程範囲は8種類の形と任意マスから選べます" />

## 射程範囲を置く

1. テーブルの何もない場所を右クリックします。
2. **射程範囲を作成**にカーソルを合わせます。
3. 形を選びます。直線・コーン・三角形・四角形・ダイヤ・五角形・六角形・円形と、マスを自由に塗る任意マスがあります。

右クリックした位置に、長さ3マス・幅3マス（直線は長さ4マス・幅1マス）の範囲が出ます。
キャラクターのそばに出したいときは、[PLツールバー](/manual/pl-tools#射程範囲を出す)から出すと、操作対象のコマにくっついた範囲になります。

四角形とダイヤは、メニューでは「四角形・ダイヤ」にまとめてあります。カーソルを合わせると「ダイヤとして出力」と「四角形として出力」が出るので、どちらかを選びます。

## 四角形とダイヤ

四角形は、中心から上下左右と斜めに「長さ」のマス数だけ広がる正方形です。ダイヤは、上下左右の角が中心から「長さ」のマス数だけ離れたひし形で、斜めには広がりません。四角のマスのテーブルでは、斜めを使わずに「長さ」の歩数で届くマスを塗ります。長さ2なら、四角形は25マス、ダイヤは13マスです。

ヘクスのテーブルでは、同じひし形の内側に中心が入るヘクスを塗ります。
グリッドなしのテーブルでは、四角のマスのテーブルと同じ形になります。

## まとめたマスで数える

[テーブル設定](/manual/table-setting#grid)の「移動と射程の1マス」を2×2以上にしたテーブルでは、射程の長さと幅を、まとめたマスで数えます。範囲の塗りもまとめたマスごとになり、置いた射程はまとめたマスの真ん中に寄ります。範囲の中のコマを対象にするときも、同じ数え方です。高さはこれまでどおり1マスずつ数えます。

## 形状を変える

射程範囲を右クリックし、**形状変更**から形を選び直せます。並びは作成のメニューと同じで、四角形とダイヤも同じく「四角形・ダイヤ」の下にあります。いまの形にはチェックの印が付きます。

[射程範囲を編集](#詳細を編集する)のパネルの形のボタンや、[PLツールバー](/manual/pl-tools#射程範囲を出す)、[ホットバー](/manual/hotbar)の枠では、ダイヤは四角形の隣に別の形として並びます。

## 範囲の中のコマを対象にする

円形・直線・四角形の射程範囲は、右クリックの**範囲内を対象にする**で、範囲に入っているコマをまとめてターゲットにできます。ほかのコマのターゲットは外れます。数えるのは自分から見えているコマだけで、[交戦エリア](/manual/engagement-zone#加わる・外れる)で場から外したコマは数えません。

コマが範囲に入っているかは、塗られたマスではなくコマの中心で決めます。[交戦エリア](/manual/engagement-zone)に加わっているコマは、エリアの中心で決めます。エリアの中心が入っていれば、加わっている全員が対象になります。

## 回す

範囲は、マウスを乗せると出る回転ハンドルで回せます。円形は回りません。任意マスは、右クリックの「回転可能」を入れたときだけ回ります。

`Alt`を押しながら回すと、四角のマスとグリッドなしのテーブルでは45°ずつ、ヘクスのテーブルでは30°ずつに角度がそろいます。
任意マスは90°ずつにしか置けないので、どのテーブルでも90°ずつそろいます。回しているあいだは画面の下に今の角度が出ます（[オブジェクトの基本操作](/manual/objects#move)）。

## 詳細を編集する

右クリックの**射程範囲を編集**で**射程範囲設定**のパネルを開き、次の項目を変えます。

| 項目               | 内容                                             | 既定値         |
| ------------------ | ------------------------------------------------ | -------------- |
| 名前               | 範囲の名前                                       | 射程範囲       |
| 形                 | 範囲の形                                         | 作ったときの形 |
| 長さ               | 中心から届くマス数                               | 3（直線は4）   |
| 幅                 | 直線とコーンの幅（マス）。ほかの形では使いません | 3（直線は1）   |
| 境界線・塗りつぶし | 縁の線と、中の塗りの色                           |                |
| 不透明度           | 範囲の濃さ                                       | 100            |
| キャラクターに追従 | くっつけたコマが動くと、範囲もついていきます     |                |

任意マスは、右クリックの「セルを編集」で専用のエディタを開き、塗るマスを1つずつ決めます。

移動・コピー・削除など共通の操作は、[オブジェクトの基本操作](/manual/objects)にあります。

## うまくいかないとき

| 見えるもの                                   | 原因と直しかた                                                                                                 |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 幅を変えても、形が変わらない                 | 幅を使うのは直線とコーンだけです                                                                               |
| 円形の範囲が回らない                         | 円形は回りません。任意マスは、右クリックの「回転可能」を入れたときだけ回ります                                 |
| **範囲内を対象にする**が出ない               | 円形・直線・四角形の範囲だけに出ます                                                                           |
| 範囲の中にいるのに、対象にならないコマがある | 自分から見えていないコマと、交戦エリアで場から外したコマは数えません。コマの中心が範囲に入っているかで決めます |
| コマを動かしても、範囲がついてこない         | 範囲がコマにくっついていません。**射程範囲設定**の**キャラクターに追従**を確かめます                           |

# 射程範囲

このページは攻撃や効果の届く範囲をテーブルに描く「射程範囲」を説明します。
円・扇（コーン）・直線など8種類の形と、マスを自由に塗る任意マスから選べ、範囲に入ったコマをまとめてターゲットにできます。柱・球・円錐・直線の立体としても置けます。
置いて直すのはGMとPLです。

<Shot src="range" alt="キャラクターを中心に広がる円形の射程範囲" caption="射程範囲は8種類の形と任意マスから選べます" />

## 射程範囲を置く

1. テーブルの何もない場所を右クリックします。
2. **射程範囲を作成**にカーソルを合わせます。
3. 形を選びます。直線・コーン・三角形・四角形・ダイヤ・五角形・六角形・円形と、マスを自由に塗る任意マスがあります。

右クリックした位置に、長さ3マス・幅3マス（直線は長さ4マス・幅1マス）の範囲が出ます。
キャラクターのそばに出したいときは、[PLツールバー](/manual/pl-tools#射程範囲を出す)から出すと、操作対象のコマにくっついた範囲になります。

四角形とダイヤは、メニューでは「四角形・ダイヤ」にまとめてあります。カーソルを合わせると「ダイヤとして出力」と「四角形として出力」が出るので、どちらかを選びます。

## 四角形とダイヤ

四角形は中心から上下左右と斜めに「長さ」のマス数だけ広がる正方形です。ダイヤは、上下左右の角が中心から「長さ」のマス数だけ離れたひし形で、斜めには広がりません。四角のマスのテーブルでは、ダイヤは斜めを使わずに「長さ」の歩数で届くマスを塗ります。長さ2なら、四角形は25マス、ダイヤは13マスです。

ヘクスのテーブルでは、同じひし形の内側に中心が入るヘクスを塗ります。
グリッドなしのテーブルでは、四角のマスのテーブルと同じ形になります。

## まとめたマスで数える

[テーブル設定](/manual/table-setting#grid)の「移動と射程の1マス」を2×2以上にしたテーブルでは、射程の長さと幅を、まとめたマスで数えます。範囲の塗りもまとめたマスごとになり、置いた射程はまとめたマスの真ん中に寄ります。範囲の中のコマを対象にするときも、同じ数え方です。高さはこれまでどおり1マスずつ数えます。

## 形状を変える

射程範囲を右クリックし、**形状変更**から形を選び直せます。並びは作成のメニューと同じで、四角形とダイヤも同じく「四角形・ダイヤ」の下にあります。いまの形にはチェックの印が付きます。

[射程範囲を編集](#詳細を編集する)のパネルの形のボタンや、[PLツールバー](/manual/pl-tools#射程範囲を出す)、[ホットバー](/manual/hotbar)の枠では、ダイヤは四角形の隣に別の形として並びます。

## 範囲の中のコマを対象にする

円形・直線・四角形の射程範囲は、右クリックの**範囲内を対象にする**で、範囲に入っているコマをまとめてターゲットにできます。ほかのコマのターゲットは外れます。数えるのは自分から見えているコマだけで、[交戦エリア](/manual/engagement-zone#加わる・外れる)で場から外したコマは数えません。

コマが範囲に入っているかは、塗られたマスではなくコマの中心で決めます。[交戦エリア](/manual/engagement-zone)に加わっているコマは、エリアの中心で決めます。エリアの中心が入っていれば、加わっている全員が対象になります。

## 立体射程

射程範囲は平面のほかに、立体としても置けます。立体にした射程はテーブルの上に半透明で描かれ、宙にいるコマも含めて、範囲に入るかを高さまで見て決めます。

| 立体 | 使える形   | 大きさ                                         |
| ---- | ---------- | ---------------------------------------------- |
| 柱   | すべての形 | 平面の形を「高さ」のマス数だけ立ち上げます     |
| 球   | 円形       | 半径が「長さ」です                             |
| 円錐 | コーン     | 頂点から底までが「長さ」、底の直径が「幅」です |
| 直線 | 直線       | 「長さ」×「幅」×「幅」の角柱です               |

テーブルの何もない場所を右クリックし、**立体射程を作成**から**球**・**円柱**・**円錐**・**直線**・**四角柱**のどれかを選ぶと置けます。置いてある射程は右クリックの**立体**から、立体にしたり平面に戻したりできます。[PLツールバー](/manual/pl-tools#射程範囲を出す)の射程の一覧にも同じ5つがあります。

### 発動者のまわりで動かす

立体射程をコマに追従させると、そのコマが発動者になります。平面では追従できない直線とコーンも、立体にすれば追従できます。

球と柱は発動者の足元を中心にした「届く距離」の半球の中を動かせます。ドラッグすると水平に動き、掴んだまま`Shift`を押してホイールを回すと高さが変わります。半球の外へ引くと、外周に沿って滑ります。動かしているあいだは、半球の形が線で出ます。発動者が動くと、置いた位置関係のまま付いてきます。右クリックの**立体**の**発動者の位置に戻す**で、発動者の足元に戻せます。

円錐と直線は、発動者の体の真ん中から伸びます。先端に出るハンドルをドラッグすると、その方へ向きます。ハンドルを持ったままホイールを回すと狙う点が1マスずつ上下し、上や下にも向けられます。`Alt`を押しているあいだは、向きが45°（ヘクスのテーブルでは30°）ずつ、仰角が15°ずつにそろいます。右クリックの**立体**の**水平に戻す**で、仰角を0°に戻せます。発動者のいない円錐と直線は、本体をドラッグすると場所が変わり、先端のハンドルで向きが変わります。

### 立体射程で対象にする

立体射程では、どの形でも右クリックの**範囲内を対象にする**が使えます。コマの足元から、コマの大きさのマス数だけ上までのどこかが立体に入っていれば、範囲内です。宙を飛ぶコマの下にある低い柱は、そのコマを数えません。

立体の中や奥にいるコマとダイスは、立体越しにそのまま押せます。

## 回す

範囲はマウスを乗せると出る回転ハンドルで回せます。円形は回りません。任意マスは右クリックの「回転可能」を入れたときだけ回ります。

`Alt`を押しながら回すと、四角のマスとグリッドなしのテーブルでは45°ずつ、ヘクスのテーブルでは30°ずつに角度がそろいます。
任意マスは90°ずつにしか置けないので、どのテーブルでも90°ずつそろいます。回しているあいだは画面の下に今の角度が出ます（[オブジェクトの基本操作](/manual/objects#move)）。

## 詳細を編集する

右クリックの**射程範囲を編集**で**射程範囲設定**のパネルを開き、次の項目を変えます。

| 項目               | 内容                                                                                               | 既定値         |
| ------------------ | -------------------------------------------------------------------------------------------------- | -------------- |
| 名前               | 範囲の名前                                                                                         | 射程範囲       |
| 形                 | 範囲の形                                                                                           | 作ったときの形 |
| 長さ               | 中心から届くマス数                                                                                 | 3（直線は4）   |
| 幅                 | 直線とコーンの幅（マス）。ほかの形では使いません                                                   | 3（直線は1）   |
| 境界線・塗りつぶし | 縁の線と、中の塗りの色                                                                             |                |
| 輪郭に沿って塗る   | 入れると、マスではなく範囲の形そのものを塗ります。外すと、中心が範囲に入ったマスを塗ります         | 外す           |
| 自由配置           | 入れると、テーブルのスナップの設定にかかわらず、離した所にそのまま置きます。任意マスにはありません | 外す           |
| 不透明度           | 範囲の濃さ                                                                                         | 100            |
| キャラクターに追従 | くっつけたコマが動くと、範囲もついていきます                                                       |                |
| 立体               | 平面・柱・球・円錐・直線から選びます。形によって選べるものが変わります                             | 平面           |
| 高さ               | 柱の高さ（マス）                                                                                   | 3              |
| 届く距離           | 球と柱を発動者のまわりで動かせる距離（マス）                                                       | 6              |
| 仰角               | 円錐と直線の上下の向き（°）。上が正です                                                            | 0              |

任意マスは右クリックの「セルを編集」で専用のエディタを開き、塗るマスを1つずつ決めます。

**自由配置**は右クリックのメニューからも入れたり外したりできます。入れた射程範囲をほかの物と一緒に選んでまとめてドラッグしたときは、一緒に動く物がマス目からずれないように、いつもどおりマス目に合わせます。

移動・コピー・削除など共通の操作は、[オブジェクトの基本操作](/manual/objects)にあります。

## うまくいかないとき

| 見えるもの                                       | 原因と直しかた                                                                                                 |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| 幅を変えても、形が変わらない                     | 幅を使うのは直線とコーンだけです                                                                               |
| 円形の範囲が回らない                             | 円形は回りません。任意マスは、右クリックの「回転可能」を入れたときだけ回ります                                 |
| **範囲内を対象にする**が出ない                   | 平面の射程では、円形・直線・四角形の範囲だけに出ます。立体射程ではすべての形に出ます                           |
| 範囲の中にいるのに、対象にならないコマがある     | 自分から見えていないコマと、交戦エリアで場から外したコマは数えません。コマの中心が範囲に入っているかで決めます |
| 立体射程の下にいるのに、対象にならないコマがある | 立体射程は高さも見ます。コマの足元から頭までのどこかが立体に入っていないと数えません                           |
| コマを動かしても、範囲がついてこない             | 範囲がコマにくっついていません。**射程範囲設定**の**キャラクターに追従**を確かめます                           |
| 直線がマスの途中から始まる                       | **輪郭に沿って塗る**を入れると、形はコマの中心から始まります。マスに合わせて塗るなら外します                   |

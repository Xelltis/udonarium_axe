# オブジェクトの基本操作

テーブル上のオブジェクト（コマ・カード・ダイス・メモなど）に共通する操作です。

## 移動・回転

- **移動** — オブジェクトをドラッグ
- **回転** — オブジェクトにマウスを乗せると現れる回転ハンドルをドラッグ。地形は 2D 表示中も回せます（コマ・カード・ダイスは俯瞰では回せません）
- **コンテキストメニュー** — 既定はどこでも通常のメニューです。真上から見ているあいだは、四方向のハンバーガーから開く棒メニューや回転メニューにも切り替えられます（[視点とテーブル操作](/manual/tabletop#tabletop-display)）

## 高度（高さ）

一部のオブジェクトは、右クリックメニューの **「高度設定」** で高さを変えて積み重ねられます。
「高度を 0 にする」で地面に戻せます。

ドラッグ中は、下にある地形の上に自然に乗ります。頭上に隙間のある地形の下はくぐれるので、橋やアーチの
下にも置けます。上に乗せたいときは、**掴んだままマウスホイールを回す**と、その場所にある足場を上下に
辿って乗り移ります（宙に浮いた岩の上などはこれで置きます）。

## 重なり順

同じ場所にオブジェクトが重なったとき、どれを手前に描くかを決められます。**掴んだものが手前に出る**のが
基本で、そのうえで右クリックメニューの「重なっているもの」一覧の下にある **「最前面へ」「最背面へ」**
から順序を指定できます。

コマ・カード・コイン・共有メモなど、重なり順を持つものすべてで使えます。地形とマップマスクは置いた形の
まま並ぶので、この 2 つには出ません。

## 複数選択・一括操作

- `Ctrl + クリック` で複数のオブジェクトを選択
- 選択した複数をまとめてドラッグ・複製・移動
- 何もない場所を長押し（ドラッグ）で矩形（マーキー）選択
- 指で操作する端末では、[スマートフォンで使う](/manual/mobile#操作のちがい)を参照してください

## コンテキストメニュー

各オブジェクトを**右クリック**すると、対象専用のメニュー（コピー・削除・詳細表示など）が開きます。
同じ位置にオブジェクトが重なっている場合は、メニューから対象を選び直せます。

テーブルの何もない場所を右クリックすると、コマ・カード・ダイス・コインなどの**作成メニュー**が開きます。

画面に入りきらない長いメニューは、中身がスクロールします。
右向きの矢印が付いた項目のサブメニューは、スクロールに関係なく画面内に収まる位置に出ます。

個別の操作は各ページを参照してください: [キャラクターコマ](/manual/character)・[カード](/manual/cards)・[ダイスとコイン](/manual/dice)・[共有メモ](/manual/notes)・[射程範囲](/manual/range)・[地形](/manual/terrain)・[マップマスク](/manual/map-mask)。

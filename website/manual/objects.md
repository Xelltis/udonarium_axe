# オブジェクトの基本操作

このページは、テーブルの上の物（コマ・カード・ダイス・メモ・地形など）に共通する、動かす・回す・高さを変える・重ねる・まとめて選ぶ操作を説明します。
物ごとの操作は、それぞれのページにあります（→ [個別のページ](#個別のページ)）。
GMとPLが使えます。見学は見るだけで、動かせません。

## 動かす・回す {#move}

| したいこと         | マウス                                                 | タッチ                               |
| ------------------ | ------------------------------------------------------ | ------------------------------------ |
| 動かす             | 物をドラッグします                                     | 物を指でドラッグします               |
| 回す               | 物にマウスを乗せると出る回転のハンドルをドラッグします | 常に出ているハンドルをドラッグします |
| 角度をそろえて回す | `Alt`を押しながら回します                              | なし                                 |
| メニューを開く     | 物を右クリックします                                   | 物を長押しします                     |

回転のハンドルをドラッグしているあいだは、画面の下にいまの角度が出ます。
`Alt`を押しながら回すと、四角のマスとグリッドなしのテーブルでは45°ずつ、ヘクスのテーブルでは30°ずつに角度がそろいます。
任意マスの[射程範囲](/manual/range#回す)だけは、どのテーブルでも90°ずつです。
ドラッグの途中で`Alt`を押したり離したりすると、その場で切り替わります。

地形は、2D表示のあいだも回せます。
コマ・カード・ダイスは、真上から見ているあいだは回せません。

右クリックのメニューの形は、既定ではどこでも通常のメニューです。
真上から見ているあいだは、四方向から開くメニューや回転メニューにも切り替えられます（→ [卓上ディスプレイ](/manual/tabletop#tabletop-display)）。

## 高さを変える {#height}

ドラッグ中の物は、下にある地形の上に自然に乗ります。
頭上に隙間のある地形の下はくぐれるので、橋やアーチの下にも置けます。
地面と上の足場のどちらに合わせるかは、いまの高さに近いほうです。
橋の下をくぐらせているコマは地面のまま、橋の高さまで持ち上げたコマは橋の上に乗ります。

| したいこと                   | 操作                                                                                 |
| ---------------------------- | ------------------------------------------------------------------------------------ |
| 上の足場に乗り移る           | 掴んだまま、マウスホイールを回します。その場所にある足場を、上下に辿って乗り移ります |
| 足場のないところへ持ち上げる | 掴んだまま、`Shift`を押しながらホイールを回します。1マスずつ、上下12マスまで動きます |
| 数で高さを決める             | 右クリックの**高度設定**で決めます。キャラクターでは**表示と扱い**の中にあります     |
| 地面に戻す                   | 右クリックの**高度を0にする**を選びます                                              |

掴んでいるあいだ、画面の下に、何ができるかが出ます。
操作を覚えていなくても、持ち上げれば書いてあります。
壁に掛けた物は高さを持たないので、ホイールでは動きません。

地面から浮いているコマには、足元までガイドが伸びます。
1マスごとの目盛りといまの高さ、真下の位置が出るので、浮いているのか、後ろの何かに乗っているのかを見分けられます。

## 重なり順

同じ場所に物が重なったとき、どれを手前に描くかを決められます。
掴んだ物が手前に出るのが基本です。
そのうえで、右クリックのメニューの「重なっているオブジェクト」の下にある**最前面へ**と**最背面へ**で、順を決めます。

コマ・カード・コイン・共有メモなど、重なり順を持つ物すべてで使えます。
地形とマップマスクは置いた形のまま並ぶので、この2つには出ません。

右クリックした場所に物が重なっているときは、「重なっているオブジェクト」から、操作する物を選び直せます。

## まとめて選ぶ {#select}

| したいこと                         | 操作                                                                           |
| ---------------------------------- | ------------------------------------------------------------------------------ |
| 1つずつ足す・外す                  | `Ctrl`を押しながらクリックします                                               |
| 範囲で選ぶ                         | 何もない場所を少し押したままにしてから、ドラッグして囲みます                   |
| 範囲で選んだ物を足す               | 範囲で選ぶときに、離すまで`Shift`を押しておきます                              |
| 選択を入れ替える                   | 範囲で選ぶときに、離すまで`Ctrl`を押しておきます                               |
| まとめて動かす                     | 選んだ物のどれかをドラッグします                                               |
| キャラクターだけをターゲットにする | `T`を押します。`Shift`＋`T`で全部外します                                      |
| 公開範囲をまとめて切り替える       | `G`を押します（→ [キー操作の一覧](/manual/shortcuts#gで公開範囲を切り替える)） |

選んだ物のどれかを右クリックすると、「N 件選択中」のメニューが開き、選んだ物をまとめて扱えます。

<Shot src="objects-select" alt="範囲で選んだキャラクター2体のうち1体を右クリックしたところ。「選択中のオブジェクト」のメニューに「2 件選択中」「選択をすべてコピー」「選択をすべて墓場へ」「選択をクリア」が並んでいる" caption="範囲で選んだ物を右クリックすると、まとめて扱うメニューが開きます" />

| 項目                    | すること                                               |
| ----------------------- | ------------------------------------------------------ |
| ダイスN個をまとめて振る | 選んだダイスを、まとめて振ります                       |
| ダイスN個をコマにしまう | 選んだダイスを、一覧から選んだキャラクターにしまいます |
| 選択をすべてコピー      | 選んだ物を、まとめて複製します                         |
| 選択をすべて墓場へ      | 選んだ物を、まとめて墓場へ移します                     |
| 選択をクリア            | 選択を外します                                         |

指で操作する端末での選びかたは、[スマートフォンで使う](/manual/mobile#操作のちがい)にあります。

## 物を置く

テーブルの何もない場所を右クリックすると、キャラクター・カード・ダイス・コインなどを作るメニューが開きます（→ [オブジェクトを置く](/manual/tabletop#オブジェクトを置く)）。

画面に入りきらない長いメニューは、中身がスクロールします。
右向きの矢印が付いた項目の小さなメニューは、スクロールにかかわらず、画面に収まる位置に出ます。

## うまくいかないとき

| 見えるもの                             | 原因と直しかた                                                                               |
| -------------------------------------- | -------------------------------------------------------------------------------------------- |
| 物を動かせない                         | 固定されているか、見学です。右クリックで固定を外すか、接続パネルで役割を確かめます           |
| ドラッグすると、範囲選択の枠が出る     | 物ではなく、何もない場所を押しています。物の絵の上を押します                                 |
| 回転のハンドルが出ない                 | 真上から見ているあいだは、コマ・カード・ダイスは回せません。3Dに切り替えます                 |
| 下の物を押したいのに、上の物が選ばれる | 右クリックの「重なっているオブジェクト」から選び直すか、**最背面へ**で上の物を後ろへ回します |
| 持ち上げた物が、橋の上に乗ってしまう   | いまの高さに近い足場に合わせます。掴んだままホイールを回して、地面まで辿ります               |

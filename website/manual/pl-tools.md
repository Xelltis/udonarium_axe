# PLツールバー

このページは、ロールがPLのときに画面の上に出るPLツールバーの、ボタンごとの働きを説明します。
自分のキャラクター・インベントリ・射程範囲・行動順に、手早く触れるための道具が並びます。
見学のときは出ません。
GMのときは、代わりに[GMツールバー](/manual/roles#gmツールバー)が出ます。

<Shot src="pl-toolbar" alt="PLツールバー。アイコンが横一列に並んでいる" width="620" caption="自分の受け持ちに手早く触れるための道具が並びます" />

ツールバーは、ドラッグで好きな位置へ動かせます。
並んでいる道具は、[メニューの編集](/manual/screen#メニューを自分で組む)で足したり外したりできます。
アイコンの名前は、`?`キーを押すとまとめて出ます。

## ボタンの一覧

初期配置では、左から次の順に並びます。

| ボタン（アイコン）                   | すること                                                                                                        |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| 所有キャラクター一覧（人の形）       | 自分がオーナーのキャラクターを並べたパネルを開く（→ [所有キャラクター一覧](#所有キャラクター一覧)）             |
| インベントリ（フォルダ）             | [インベントリ](/manual/inventory)を開く。FABメニューの**ゲームリソース**にあるものと同じパネルです              |
| 射程範囲（レーダー）                 | 操作対象のコマを基点に、[射程範囲](/manual/range)を出す（→ [射程範囲を出す](#射程範囲を出す)）                  |
| ダンジョンドリィマスターモード（目） | 自分のコマの目線で歩くモードに入る（→ [ダンジョンドリィマスターモード](#ダンジョンドリィマスターモードに入る)） |
| 名前（ラベル）                       | コマの名前を隠す・戻す                                                                                          |
| リソースバー（横棒）                 | コマの頭上のリソースバーを隠す・戻す                                                                            |
| バフ（杖と星）                       | コマの頭上のバフのバッジを隠す・戻す                                                                            |
| 吹き出し                             | コマの頭上に出る発言の吹き出しを隠す・戻す                                                                      |
| バフ表示（全体）                     | すべてのコマのバフの見せかたを、アイコン・詳細・個数の順に切り替える                                            |
| 行動順                               | 戦闘中だけ、ラウンド数といまの手番が出る                                                                        |
| 操作対象キャラクター                 | 操作対象にしたキャラクターのサムネイルが出る（→ [操作対象キャラクター](#操作対象キャラクター)）                 |

名前・リソースバー・バフ・吹き出し・バフ表示（全体）は、この画面だけの設定です（→ [頭上の表示を隠す](#リソースバーとバフを隠す)）。

## 所有キャラクター一覧

**所有キャラクター一覧**を押すと、自分がオーナーのキャラクターだけを並べたパネルが開きます。
ほかの参加者のコマは混ざりません。
墓場に送ったコマも出ません。
上の欄に名前を入れると、絞り込めます。

各行のボタンでできることは、次のとおりです。

| ボタン                     | すること                                                                                           |
| -------------------------- | -------------------------------------------------------------------------------------------------- |
| 操作対象にする（◎）        | そのキャラクターを「いま動かしている1体」にする（→ [操作対象キャラクター](#操作対象キャラクター)） |
| チャットパレットを開く     | そのキャラクターの[チャットパレット](/manual/chat-palette)を開く                                   |
| キャラクターシートを開く   | [シート](/manual/character)を開く                                                                  |
| リモートコントローラを開く | 複数のキャラクターをまとめて操作するパネルを開く                                                   |
| コマの位置へ視点を移す     | テーブルの上のそのコマへ視点を寄せる。テーブルにいないときは押せません                             |

行の下には、HPやMPなどのリソースが並び、数値の入力とスライダーで、その場で増減できます。
ダメージのたびにシートを開き直す必要はありません。

自分のキャラクターがまだないときは、「オーナーのいないキャラクター」の見出しの下に、テーブルの上のキャラクターが並びます。
**自分のものにする**を押すと、そのキャラクターを受け取れます。
オーナーの決めかたは[情報の公開範囲](/manual/disclosure#オーナー)にあります。

[同行（パーティ）](/manual/party)に入っているキャラクターは、名前の右に、パーティの色と名前が付きます。
マウスを乗せると、同行しているほかのキャラクターの名前が出ます。
どこにも入っていないキャラクターには、何も付きません。

::: tip 仲間のコマが暗闇で見えないとき
同行しているキャラクターどうしは視界を分け合い、暗闇の中でもおたがいのコマが見えます。
編成はGMが行います。
:::

## 操作対象キャラクター

所有キャラクター一覧で **◎** を押すと、そのキャラクターがツールバーの右端に、サムネイル付きで出たままになります。
複数のキャラクターを受け持っているときに、いまどれを動かしているかを見失わないための目印です。

- サムネイルを押すと、そのキャラクターのチャットパレットが開きます
- 選んだときにチャットパレットがもう開いていれば、その中身が選んだキャラクターに切り替わります
- もう一度 **◎** を押すと、外れます
- オーナーでなくなったときや、コマが消されたときは、自動で外れます

## 射程範囲を出す

1. ツールバーの**射程範囲**（レーダーのアイコン）を押します。
2. 出したい形を選びます。

操作対象のコマを基点に、[射程範囲](/manual/range)が出ます。
範囲はコマにくっついた状態で作られるので、あとからコマを動かすと、範囲もついてきます。

操作対象をまだ決めていないときにボタンを押すと、所有キャラクター一覧が開きます。
先に、基点にするキャラクターの **◎** を押してください。

## ダンジョンドリィマスターモードに入る

ツールバーの目のアイコンを押すと、自分のコマの目線でダンジョンを歩く[ダンジョンドリィマスターモード](/manual/dungeondry-master)に入ります。

- 見られるコマが2体以上いるときは、ボタンの下に名前が並ぶので、見るコマを選びます
- 入っているあいだは、同じボタンでテーブルに戻れます
- GMが全員の視点をそろえているあいだは、押せません

## 頭上の表示を隠す {#リソースバーとバフを隠す}

テーブルが混み合って見づらいときは、テーブルにいる全員のコマから、頭上の表示をまとめて隠せます。
もう一度押すと戻ります。

| ボタン               | 隠すもの                     | 注意                                                                                                       |
| -------------------- | ---------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 名前（ラベル）       | コマの名前                   | 表示に戻しても、キャラクターの設定で名前を隠してあるコマは、GM以外には名前が出ません                       |
| リソースバー（横棒） | 頭上のリソースバー           |                                                                                                            |
| バフ（杖と星）       | バフのバッジ                 |                                                                                                            |
| 吹き出し             | キャラクターの発言の吹き出し | GMが[部屋設定](/manual/room-settings#吹き出し)で部屋全体の吹き出しを止めているときは、表示にしても出ません |

**バフ表示（全体）** は、隠す代わりに、すべてのコマのバフの見せかたを、押すたびに**アイコン**・**詳細**・**個数**の順に切り替えます。
コマ1体ごとの見せかたは、コマの右クリックの**バフの表示**で変えられます（→ [バフ／デバフ](/manual/buff)）。

どれも、変わるのはこの画面だけで、ほかの参加者の画面は変わりません。
選んだ状態はこのブラウザに残り、次に開いたときも同じです。

## 行動順の表示

戦闘中は、ツールバーにラウンド数といまの手番が出ます。
[行動順](/manual/turn-order)のウィジェットを開かなくても、いま誰の番かを確かめられます。

戦闘が始まっていないあいだは、出ません。
手番を進めるのは、GMの操作です。

## 畳む・隠す

見出しの横の矢印を押すと、ツールバーが見出しだけに畳まれます。
もう一度押すと、元に戻ります。
畳んだかどうかは、このブラウザに残ります。

ツールバーそのものが要らない場面では、FABメニューの[ウィジェット](/manual/screen#ウィジェット)で**PLツール**を消せます。
出し直すと、ドラッグで置いた位置に戻ります。

[手札](/manual/cards#手札)と[バフマネージャー](/manual/buff#卓全体のバフの一覧)はFABメニューの**ゲームリソース**から、[エフェクト](/manual/map-effects)は**メディア**から開きます。

## うまくいかないとき

| 見えるもの                                                     | 原因と直しかた                                                                                                        |
| -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| PLツールバーが出ない                                           | ロールがPLでないか、**ウィジェット**で隠しています。接続パネルの**役割**と、FABメニューの**ウィジェット**を確かめます |
| 所有キャラクター一覧が「所有しているキャラクターがありません」 | 自分がオーナーのキャラクターがいません。**自分のものにする**で受け取るか、GMにオーナーにしてもらいます                |
| 射程範囲のボタンで、一覧が開くだけ                             | 操作対象をまだ決めていません。一覧で、基点にするキャラクターの **◎** を押します                                       |
| **コマの位置へ視点を移す**が押せない                           | そのコマは、いま見ているテーブルにいません                                                                            |
| ダンジョンドリィマスターモードのボタンが押せない               | GMが全員の視点をそろえています。GMが戻すまで待ちます                                                                  |
| 名前を表示にしても、名前が出ないコマがある                     | そのキャラクターは、設定で名前を隠してあります。GMにだけ見えます                                                      |

# はじめに

Udonarium Axe（以下Axe）は、ブラウザで遊べるTRPGのセッションツールです。
テーブルにコマ・カード・ダイスを置き、チャットで話しながらセッションを進めます。
インストールもアカウントの登録も要りません。

このページは、はじめてAxeを使う人が、どのページから読めばよいかを案内します。

## 1人で試す {#try-alone}

1人で確かめるだけなら、部屋を作る必要はありません。

1. [デモサイト](https://axe.xelltis.com)を開きます。サンプルのコマが並んだテーブルが出ます。
2. コマをドラッグして動かします。
3. 左下のチャットの入力欄に`2d6`と打って、`Enter`を押します。ダイスが振られ、結果がチャットに出ます。

通信を切りたいときは、接続パネル（FABメニューの**接続**）で**オフライン**を選びます。
押すとページが読み込み直され、いまの部屋からは抜けるので、卓の最中には使わないでください。
保存と読み込みはオフラインのままできるので、次の卓の下ごしらえに使えます（→ [部屋とロビー](/manual/rooms#offline)）。

## デモサイトで遊ぶときの注意

短いセッションなら、デモサイトのまま遊んでもかまいません。
ただし、卓を続けて預ける場所には向きません。理由は次の3つです。

- ロビーは、ほかの人と共用です。一覧には、ほかの人が作った部屋も並びます。人に見られたくない卓には、パスワードを付けてください
- 卓は、自動では残りません。参加者が0人になると、部屋は消えます（→ [部屋とロビー](/manual/rooms#gone)）
- 予告なく止めたり、初期化したりします。動作確認と開発のための場所なので、予定した卓の当日に止まっていることもありえます

毎週のように続けて遊ぶなら、自分の環境に設置するのが確実です（→ [設置ガイド](/guide/)）。

## 動作確認しているブラウザ

もっとも多く動作確認しているのは、デスクトップ版のChromeです。
スマートフォンやタブレットでも遊べます（→ [スマートフォンで使う](/manual/mobile)）。

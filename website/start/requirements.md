# 推奨環境

Axeをブラウザで遊ぶときの、パソコンとブラウザの目安です。
テーブルを3Dで描くので、パソコンの性能と、ブラウザのグラフィックの設定で動きの軽さが変わります。

## おすすめの環境

| 項目         | おすすめ                                                 | 下回るとき                                                                                                                                |
| ------------ | -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| ブラウザ     | デスクトップ版Chromeの最新版。Edgeでも同じように描けます | Chrome 111・Safari 16.4・Firefox 128より古い版では、画面の表示が崩れます。Firefoxでは、描画の設定が「自動」のとき、いつも表示を軽くします |
| グラフィック | ブラウザの「グラフィックアクセラレーション」を有効にする | 無効のままだと、テーブルを動かしているあいだの描画が大きく遅くなります。起動のたびに、有効にするよう案内が出ます                          |
| CPU          | 4コア以上                                                | 2コア以下のパソコンでは、描画の設定が「自動」のとき、表示を軽くします                                                                     |
| メモリ       | 8GB以上                                                  | 2GB以下のパソコンでは、描画の設定が「自動」のとき、表示を軽くします                                                                       |
| 画面         | 1920×1080                                                | 幅が768px未満の画面では、[スマートフォン版の画面](/manual/mobile)になります                                                               |
| 操作         | ホイールつきのマウスとキーボード                         | タッチでも遊べます。マップエディターのように線を引く機能は、マウスのほうが精密に扱えます                                                  |

描画の設定は、[画面の見かた](/manual/screen#表示)にある「表示」の小窓で変えられます。

## 測った目安

GPUのあるWindowsのパソコン（16スレッド・メモリ32GB）のChromeで最初の部屋を開くと、テーブルを回しているあいだも毎秒60コマで描けました。
同じパソコンでグラフィックアクセラレーションを切ると、毎秒12コマほどになりました。
このときのChromeのメモリは、Axeのタブ1つで1.4〜2.2GBほどでした。

初めて開くときは、最初の部屋の3Dモデルなどを合わせて、24MBほどを読み込みます。

## グラフィックアクセラレーションを有効にする

ブラウザの設定で、次の項目をオンにしてから、ブラウザを開き直します。

| ブラウザ | 設定の場所                                                                                                                                            |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| Chrome   | 設定の「システム」にある「グラフィック アクセラレーションが使用可能な場合は使用する」                                                                 |
| Edge     | 設定の「システムとパフォーマンス」にある「使用可能な場合はグラフィックス アクセラレータを使用する」                                                   |
| Firefox  | 設定の「一般」の「パフォーマンス」で「推奨のパフォーマンス設定を使用する」を外し、「ハードウェアアクセラレーション機能を使用する (可能な場合)」をオン |

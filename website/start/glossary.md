# 用語集

このページは、このサイトで断りなく使う言葉の意味をまとめたものです。
遊ぶときの用語と、設置するときの用語に分けています。

## 遊ぶときの用語

| 言葉                     | 指すもの                                                                                                              |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| 卓                       | セッションそのもの。「卓を回す」「卓を立てる」                                                                        |
| テーブル                 | いま映っているマップ1枚。1つの部屋に何枚でも作れて、場面ごとに切り替えます                                            |
| 部屋（ルーム）           | 参加者どうしをつなぐ入れ物。作った人がGMになります                                                                    |
| パスワード               | 部屋に鍵をかける文字列。招待リンクの画面では「合言葉」と呼ばれています                                                |
| FABメニュー              | 画面の左上の丸いハンバーガーボタン。パネルはここから開きます。メニューの編集では「Fav メニュー」                      |
| 接続パネル（接続情報）   | 名前・役割・ルーム名・招待リンクが並ぶパネル。FABメニューの**接続**から                                               |
| GM / PL / 見学           | 役割。GMは全部見えて全部触れ、見学は読むだけです（→ [ロール](/manual/roles)）                                         |
| コマ                     | テーブルに置く物。キャラクター・カード・ダイス・メモなど                                                              |
| オーナー                 | コマの持ち主。自分がオーナーのコマは、自分で公開範囲を変えられます（→ [情報の公開範囲](/manual/disclosure#オーナー)） |
| 公開範囲                 | コマの中身を誰に見せるか。全員・特定PL・GMのみ（→ [情報の公開範囲](/manual/disclosure)）                              |
| 秘話                     | 特定の人にだけ送る発言（→ [チャットの基本](/manual/chat)）                                                            |
| ダイスボット             | チャットに打ったコマンドでダイスを振る仕組み（→ [ダイスボット](/manual/dicebot)）                                     |
| SkyWay版・部屋のサーバー | 参加者のつなぎかたの2つの方式。どちらで動いているかは、設置した人が決めます（→ [方式を選ぶ](/guide/choose)）          |

## 設置するときの用語

| 言葉                 | 意味                                                                                                                     |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 静的ホスティング     | ファイルを置くだけで、そのままWebページとして配ってくれるサービス。Cloudflare Pages、GitHub Pages、レンタルサーバーなど  |
| Origin               | URLのうち、`https://`からドメイン（とポート）までの部分。`https://axe.example.com/room?x=1`なら`https://axe.example.com` |
| トークン発行サーバー | SkyWay版で置くサーバー。SkyWayを使うための許可証（トークン）をAxeに渡す。卓の中身は通らない                              |
| 部屋のサーバー       | サーバー版で置くサーバー。部屋ごとに参加者のやりとりを中継し、卓と画像と音声を預かる                                     |
| `config.json`        | Axe本体の`assets/config.json`。どの方式で、どのサーバーにつなぐかを書く（→ [config.jsonを書く](/guide/configuration)）   |
| SkyWay               | NTTドコモビジネスが提供する、ブラウザ同士をつなぐサービス。SkyWay版で使う。アカウントとアプリの作成が要る                |

サーバーの側の用語は、バックエンドの文書の[用語](https://xelltis.github.io/udonarium_axe_backend/guide/#用語)にあります。

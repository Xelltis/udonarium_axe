# はじめてのセッション（GM）

このページは、自分でGMとして卓を回す人が、部屋を作ってから、終わって保存するまでの一晩の流れを説明します。
用意するものは、部屋の名前ひとつです。
GMが部屋を作り、出てきた招待リンクを配れば、あとは全員がリンクを開くだけで卓が始まります。

手順1から6を順に読むと、一晩の流れになります。
個々の機能の操作は、[操作マニュアル](/manual/)にあります。

## 部屋を作る前にできること

Axeは、開いた時点でもうテーブルが動いています。
サンプルのコマが並び、ダイスも振れる状態なので、地形を描いたりマップを組んだりする下ごしらえは、部屋を作る前にひとりで進められます。
部屋は「ほかの人とつなぐ」ためのもので、テーブルを持つためのものではありません。

## 1. 部屋を作る

画面左のFABメニュー（丸いハンバーガーボタン）から**接続**を開き、下の**ロビー（ルーム一覧）を表示**を押します。
ロビーの**新しいルームを作成する**で、ルーム名とパスワードを決めれば部屋ができます。
決められる項目と上限は[部屋とロビー](/manual/rooms#部屋を作る)にまとめました。

作成した人はそのまま**GM**になります。
GMは他の人からは選べないので、卓を回す人が部屋を作ってください。

## 2. 招待リンクを配る

部屋ができると、接続パネルのルーム欄に**招待リンク**が出ます。
その**コピー**を押して、Discordなりチャットなりに貼るだけです。
リンクを開いた人は、ロビーを探すこともパスワードを打つこともなく、その部屋に入ります。

配る前に、2つ選べます。
ひとつは、**PL**と**見学**の切り替えで、開いた人の役割がリンクに入ります。
部屋のサーバーでは、プレイヤー用のリンクでも、ログインしていない人は見学として入ります（→ [招待リンクで参加する](/start/join)）。
もうひとつは**合言葉を含める**（パスワードのことです）かどうか。
含めれば開くだけで入室できます。そのぶん、リンクを知っている人は誰でも入れます。
公開の場で募集するなら含めないリンクを配り、パスワードは別の経路で渡してください。

配信のためにOBSへ映したいときは、同じ欄の**配信用（透過画面）** を使います（→ [ロール](/manual/roles#招待リンクで参加者を招く)）。

## 3. テーブルを用意する

初回は既定のテーブルのままで足ります。床も壁も画像を用意しなくてかまいません。

地図が欲しくなったら、FABメニューの**テーブル関連**にある**マップ生成**がいちばん早いです。
ダンジョンかフィールドかと雰囲気を選んで押せば、壁も木立も地形として置かれたテーブルが1枚できます。
生成してもテーブルは勝手に切り替わらないので、セッション中に次の場面を仕込んでも、プレイヤーの画面はいまの場面のままです。

<Shot src="map-generator" alt="マップ生成のパネル。部屋と通路のプレビューと、生成するのボタンがある" width="360" caption="マップ生成。プレビューを見て「生成する」を押すだけです" />

凝るなら[マップエディター](/manual/map-editor)でセルを塗り、手描きで済ませたいなら[ホワイトボード](/manual/white-board)に描いてください。
床や壁の画像を差し替えるのは[テーブル設定](/manual/table-setting)からです。

## 4. キャラクターを置く

初回は、画像を投げ込むのがいちばん早いです。
テーブルへ画像ファイルをドロップすると、そのままキャラクターのコマになります。
ファイル名が名前になります。

シートごと持ち込むなら、FABメニューの**セーブ&ロード**の**キャラ取り込み**に、キャラクター保管所・キャラクターシート倉庫・ゆとシート・CharaXivのURLかJSONを貼ってください。
能力値もリソースもチャットパレットも付いてきます（→ [キャラクターの取り込み](/manual/character-import)）。

ココフォリアで作った卓ごと持ってきたいなら、書き出したzipをテーブルにドロップする道もあります。
ただしBGMはココフォリアのzipに含まれず、カードとカットインも未対応です（[実験的機能](/manual/room-import)）。

## 5. ゲームシステムを決める

遊ぶシステムは、**部屋設定**の**一般**のタブの、既定のダイスボットで決めます。ここで選んでおくと、参加者は入った時点でそのシステムの判定を打てます。
決め忘れても各自がチャット欄から選び直せますが、卓の頭で全員に選ばせるより手数が少なくて済みます。
システムごとの書き方は[ダイスボット](/manual/dicebot)にあります。

## 6. 終わったら保存する

::: warning 部屋は、参加者が0人になった時点で消えます
最後の1人がタブを閉じた瞬間に、その部屋はもうありません。
:::
[部屋のサーバー（ベータ）](/guide/choose)の部屋はしばらく（既定では24時間）残りますが、そのあとは消えます。

続きを遊ぶつもりなら、解散する前に、FABメニューの**セーブ&ロード**の**保存**を押して、zipを書き出してください。
テーブルもコマもカードもチャットも、まとめて1つのファイルになります。

押し忘れたときの保険として[自動保存](/manual/save-load#自動保存)がありますが、効かない条件が3つあります。
プライベートウィンドウ、自動保存を切っている場合、そして別の端末から開こうとした場合です（→ [部屋とロビー](/manual/rooms#gone)）。
本番の卓を預けるなら、やはりzipのほうが確かです。

## 次の回を始める

保存したzipは、ブラウザの画面へドロップすれば読み込まれます。
読み込んでから部屋を作っても、部屋を作ってから読み込んでもかまいません。

同じ面子で続けるなら、GMが卓を戻してから、招待リンクを配り直す流れになります。

## うまくいかないとき

| 見えるもの                             | 原因と直しかた                                                                                                       |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 部屋を作れない                         | ほかの部屋に入っているか、部屋のサーバーでログインしていません（→ [部屋とロビー](/manual/rooms#うまくいかないとき)） |
| 招待リンクで、参加者が入れない         | → [リンクを開いても入れないとき](/start/join#stuck)                                                                  |
| 参加者の画面で、ダイスのシステムが違う | 既定のダイスボットを決めていません。部屋設定の**一般**で選びます                                                     |
| 次の日に部屋がない                     | 部屋は0人になると消えます。保存したzipを読み込んでから、部屋を作り直します                                           |

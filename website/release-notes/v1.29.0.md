# v1.29.0

2026-08-11リリース

**セッションログ（リプレイ）** が入りました。卓で起きたことをそのまま記録し、あとから読み返し、盤面ごと再生し、
編集して**MP4の動画に書き出す**ところまでできます。あわせて**マップ演出**に20種の演出が加わりました。

## ✨ 新機能・改善

### セッションログ（リプレイ）

卓の進行を、このブラウザの中に記録します。**記録は他の参加者には共有されません**（自分の端末の中だけに残ります）。

#### 記録する

時計の脇に**録画ピル**が出ます。押すと開き、**記録の細かさ**を決めてから「記録を始める」で始まります。

| 細かさ       | 残るもの                                                   |
| ------------ | ---------------------------------------------------------- |
| チャットのみ | 発言とダイスだけ                                           |
| 標準（既定） | 発言・ダイスに加えて、コマの移動やリソース増減など主な操作 |
| すべて       | 上記に加えて細かい編集まで                                 |

記録中のピルには**経過時間と件数**が出ます。「目印」に見出しを書いて押すと、**章の区切り**が入ります（例: 第二幕）。
あとで読むときも、動画にするときも、この目印が章立てになります。

- **部屋が無くても記録できます** — ひとりで開いた卓もそのまま記録できます（一覧では「ひとりの卓」と表示されます）
- **記録は始めた卓に紐づきます** — 部屋を移ると、そこでいったん締めます
- **秘匿はそのまま** — 内緒話・GM限定・非公開のコマは、当時の見え方のまま記録され、読むときも権限で絞られます
- **端末に残ります** — 直近5本 / 合計512MBまでを保持し、古いものから消えます（記録中のものは消えません）

#### 読む

**リプレイパネル**に、記録されたできごとが読み物として並びます。話者や「秘匿を隠す」「チャット / 盤面」で絞り込めます。
「◯◯ が △△ を(3, 4)から(5, 4)へ動かした」のように、盤面の操作も文章になります。

#### 再生する

記録を選んで**読み進めるだけなら、卓はそのまま**です。
「盤面も再生する」を選ぶと、**今の卓をいったん預かって**記録当時の盤面を映します。

- この間の操作は**同卓者には届きません**（他の人の卓を巻き込みません）
- 「卓に戻す」で**元の状態に戻ります**
- タイムラインは**できごとの多さを山**で描き、章の目印が並びます。掴んで動かせば、その時点へ飛べます

#### 直す・書き足す

記録は**元を変えずに**編集できます。編集した結果は「別の記録として保存」され、元の記録はそのまま残ります。

- **並べ替え** — つまんで移動、または矢印で1つずつ
- **削除**・**台詞の書き直し**
- **差し込み** — 発言・ダイス・目印を、任意の位置に手で書き足す
- **収録** — 手で書く代わりに、**実際に盤面を操作して**その結果を差し込む。動かした・振った・演出した内容がそのまま記録されます（同卓者には届きません）
- **Ctrl+Z**で1手ずつ取り消せます

#### 持ち出す・読み込む

`.axe-replay.zip`で書き出し / 読み込みができます。「画像も含める」を付ければ、別の環境でも絵付きで開けます。

#### 動画（MP4）にする

記録を**絵コンテ**に起こしてMP4に書き出します（1発言 = 1カット、目印は章の扉）。

| 選べるもの | 内容                                                      |
| ---------- | --------------------------------------------------------- |
| 大きさ     | 720p / 1080p                                              |
| 間の取り方 | 読める速さ / 当日と同じ間                                 |
| 入れるもの | 台詞と章だけ / 盤面の動きも入れる（既定）                 |
| 音         | 効果音を入れる・BGMを入れる（**それぞれ個別に**選べます） |

- **盤面が主役の構図** — 画面のほぼ全面が盤面で、台詞窓はその上に重なります。コマのある範囲へ寄せて映すので、広い卓でも小さくなりません
- **コマが実際に動きます** — 記録した移動の道筋に沿って滑り、**移動の軌跡と行き先の矢印**、**マス目の線**が描かれます
- **立ち絵**は、話し手のコマがある側（左右）へ寄ります
- 書き出し中は進捗が出て、途中で「やめる」を押せば止まります

::: warning 書き出しの制限
1時間で打ち切ります。盤面は**真上からの2D**で、暗闇・視界・光源・3Dの見え方は再現しません。
カットインの動画とYouTubeの音声は入りません。WebCodecsに対応していないブラウザでは書き出せません
（ボタンが押せない状態になります）。
:::

### マップ演出（エフェクト）に20種

射撃と大剣まわりが厚くなりました。いずれも**撃つコマを選択**してから対象を指定すると、その向きに飛びます。

| 追加された演出                           | どう見えるか                                                                             |
| ---------------------------------------- | ---------------------------------------------------------------------------------------- |
| **飛ぶ斬撃** / **飛ぶ連斬**              | 三日月の刃がまっすぐ飛んでいって斬る。連斬は続けざまに                                   |
| **光線銃**（単発 / 連射）・**狙撃**      | 白い芯を色の鞘でくるんだ光条。狙撃は細い曳光が最速で一直線に走る                         |
| **レーザー照射**                         | 細い光を当て続け、焼け跡の輪と立ち上る光で押す                                           |
| **矢の連射** / **アローレイン**          | 1本ずつ間を置いて射る／射手が空へ36本を撃ち上げ、落ちる位置を示してから降らせる          |
| **マイクロミサイル** / **誘導弾**        | 12発が別々に膨らんでから食い付く／水平に巡航し、的の直前で一気に突っ込む                 |
| **弾道ミサイル**                         | 真上へ撃ち上げて画面外へ消え、的の真上から落ちてきてきのこ雲                             |
| **光の大剣**（炎 / 氷 / 雷 / 大地 / 闇） | 足元から光が立ち上って巨大な刃になり、根元を支点に振り下ろされる。属性ごとに締めが変わる |

演出の効果音には[効果音ラボ](https://soundeffect-lab.info/)と[On-Jin～音人～](https://on-jin.com/)の素材を使っています。

## 🐛 不具合修正・変更

- **ノベル表示の背景ぼかしが既定でオフになりました** … 台詞は元から専用の暗い帯の上に乗っているため、既定のぼかしは選んだ背景を損なうだけでした。読みづらい背景のための3段階の設定は残っています（すでに設定してある場合はその設定が優先されます）

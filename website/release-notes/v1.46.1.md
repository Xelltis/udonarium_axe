# v1.46.1

2026-08-31リリース

不具合修正のみのリリースです。v1.46.0で入ったホットバーの「場に置く」で、置いたエフェクトを
片付けられるようになりました。

## 🐛 置いたエフェクトを片付けられます

ホットバーの枠に**エフェクト**を入れ、モードを**場に置く**にすると、押すたびにコマの足元へ
エフェクトが置かれます。これが押すたびに増えていくうえ、**バーから消す手段がありませんでした。**
置いたものに触れるのはエフェクト集のパネルだけなので、パネルを開かずに済ませるためのバーから、
わざわざパネルを開くことになっていました。

**範囲を置く枠と同じトグルになりました。** 一度押すと置き、もう一度押すと片付きます。

片付くのは、**押した枠がそのコマのために置いた分だけ**です。同じエフェクトを別の枠から置いていても、
同じ枠でも別のコマとして置いていても、そちらは残ります。手で置いたものやエフェクト集から置いたものも
巻き込みません。

編集画面の**試す**で置いたものも、画面を閉じたときに一緒に片付きます。これまでは範囲だけが
片付いていました。

::: tip スペシャルサンクス
ホットバーは、[ユドナリウムリコリス](https://github.com/oron1208/udonarium-lycoris)（oron1208氏）の
同名の機能に着想を得ています。コードは受け継いでおらず、Axe独自の実装です。
:::

## 開発者向け

置いたエフェクト（`EffectField`）に`laidByHotbarSlot`が付きました。射程範囲と同じ、
「どの枠がどのコマのために置いたか」を表す印です。片付けはこの印の一致で選ぶので、
同じプリセットを複数の枠から置いても取り違えません。

# v1.79.0

2026-11-15リリース

SkyWay版で、切れた相手とつなぎ直せないまま終わることがあったのを直しました。相手が部屋にいるあいだはつなぎ直しを続け、食い違ったデータは自動で突き合わせ直します。接続パネルには、相手ごとのつながり方と、部屋のデータをどこまで受け取ったかが出ます。

エフェクトをすべて描き直し、聖の系統をはじめ、新しいエフェクトが増えました。大剣は、撃ち手が刃を掲げて振り下ろし、奔流を放つ技になりました。エフェクト集の行を押してもすぐには撃たず、構えてから対象を選んで発動します。コマのバフを外し、シートの値を戦闘の前へ戻すリセットも入りました。

部屋設定に「項目の別名」が入り、シートによって名前の違う項目を1つの名前で扱えます。バフは減るたびに動かす量が動く時期を`発生:`で決められます。マップ生成の農村と砦は、起伏のある地面でも平らな台地の上に立ちます。チャットのお知らせは読む人それぞれの画面の言語で出ます。行動順は、チャットのコマンドでも動かせます。

## 🔌 SkyWay版の接続と同期

相手との接続が切れたあと、5回つなぎ直しても戻らないと、そこで止まっていました。今は、相手が部屋にいるあいだ30秒ごとに試し続け、つながると「〇〇 さんとの接続を復旧しました。」と出ます。接続が切れたことにも、これまでより早く気づきます。開きも閉じもしないまま30秒たった接続は、閉じてつなぎ直します。

参加者どうしは持っているデータを25秒ごとに照らし合わせます。食い違いが続くと、足りない分を自動で頼み直します。同時に入った2人が、あとから増えたコマや画像を互いに知らないままになることがなくなります。

部屋に入るとまずテーブル・コマ・チャットが届き、画像・音楽・3Dモデルはそのあとに届きます。画像や音楽を送っている最中も、コマの動きとチャットは先に届きます。遅い回線では、画像や音楽の受け取りが途中で最初からやり直しになりにくくなりました。

接続パネルの参加者の一覧には、その人とどうつながっているかが、アイコンと語で出ます。「中継サーバー経由」「他の人経由のみ」「再接続中」「接続できません（再試行中）」の4つで、直接つながっているときは鎖のアイコンだけです。**部屋のデータを同期し直す**の上には、「部屋のデータを受け取っています（残り〇件）」のように受け取りの進みが出ます。入ったのに卓が空のままのときは、ここで原因を見分けられます。

**部屋のデータを同期し直す**を押したとき、直接つながっていない人が部屋にいると、頼めなかった人数もチャットに出ます。

くわしくは[接続が切れたとき](/manual/connection#peer-links)を参照してください。部屋のサーバーの動きは変わっていません。

## ✨ エフェクトの描き直し

すべての系統のエフェクトを描き直しました。炎は層を重ねた1つの火として燃え、斬撃は大きな三日月を描き、落雷は空から先導が降りてきてから落ちます。

いくつかの種類は、等級で描き方そのものが変わります。打撃では、殴打がまっすぐの突き、強打が頭上からの振り下ろし、崩拳が力を溜めて背中まで撃ち抜く一撃になります。落雷・氷結・回復・障壁・転移・重力なども、等級ごとに別の見た目です。系統と「道中の粒」でも見た目が変わり、竜巻は氷の系統で吹雪に、斬撃は風の系統で風の刃になります。

当たったコマの動きも、見た目に合わせました。地面から突き上がるエフェクトはコマを浮かせ、光の柱は上から押さえ、竜巻は持ち上げて引き寄せ、生命吸収は撃ち手のほうへ引き寄せます。

新しく入ったエフェクトは次のとおりです。

| 系統             | エフェクト                                         |
| ---------------- | -------------------------------------------------- |
| 聖（新しい系統） | 聖印・裁きの光・光輪・聖域・天罰                   |
| 闇               | 影の棘・暗黒球・奈落・蝕                           |
| 風               | 鎌鼬・真空波・大嵐・風の大剣                       |
| 土               | 地割れ・大地震・砂塵のブレス                       |
| 氷               | 吹雪・氷棺                                         |
| 射撃             | 雷弾                                               |
| 状態異常         | 毒・出血・燃焼・混乱・魅了・恐怖・暗闇・沈黙・鈍足 |

光の大剣・聖なる吐息・聖光弾は、聖の系統に移りました。状態異常のエフェクトは、その状態の姿をコマの上に描きます。睡眠なら頭から「Z」が昇り、拘束なら足元から蔓が巻き付きます。

前の版で作った部屋には、増えたエフェクトは自動では入りません。エフェクト集の**メニュー**の**足りない既定を追加**で、部屋にないものだけを足せます。部屋にある既定のエフェクトは前の版の設定のまま残るので、流星・極彩ビーム・光の大剣・睡眠などを新しい見た目にするには**既定を反映**を使います。手を加えた既定のエフェクトも上書きされます。

くわしくは[既定のエフェクト](/manual/map-effects#既定のエフェクト)を参照してください。

## ⚔️ 大剣

光・炎・氷・雷・大地・闇・風の大剣は、撃ち手が剣を頭上に掲げる技になりました。まわりから光を集めて何マスもの高さの刃を立て、対象へ振り下ろします。刃が水平になった瞬間、撃ち手から対象を抜けてその先まで属性の奔流が床を走り、通り道のコマを飲み込みます。撃ち手は振る前に身を引いて踏ん張り、当たったコマは奔流の向きへ押し流されます。

くわしくは[大剣](/manual/map-effects#大剣)を参照してください。

## 🧪 状態異常を付けたときのエフェクト

状態異常のパネルで「付けたとき、同じ名前のエフェクトを再生する」にチェックを入れると、コマに状態異常を付けた瞬間、同じ名前のエフェクトがそのコマに流れます。新しい部屋に最初から登録してある12個の状態異常には、どれも同じ名前のエフェクトがあります。インベントリのチェック欄・チャットの`&毒`・機能塗りのどれで付けても流れ、演出は全員の画面に出ます。部屋ごとの設定で、既定は切です。

くわしくは[状態異常を付けたときに出す](/manual/map-effects#状態異常を付けたときに出す)を参照してください。

## 🎯 エフェクト集と構え

エフェクト集の行を押しても、すぐには発動しなくなりました。選んだエフェクトは構えの欄に入り、盤面のコマを押して対象を選んでから、**対象に発動する**かEnterで発動します。撃ち手は構えたあとでも変えられ、盤面では撃ち手の足元に白いひし形が出ます。範囲攻撃は、構えているあいだにコマへマウスを載せると、巻き込む範囲と相手が先に見えます。構えているあいだは画面の下の帯にも「発動」と「中止」が出るので、パネルが盤面に重なっていても発動できます。

エフェクト集は、左に系統の索引を並べた形に変わりました。索引を押すと、その系統まで一覧が送られます。検索はひらがなでも探せ、等級と対象（単体・複数・範囲）で絞り込めます。行にマウスを載せると、一覧の上の枠でそのエフェクトが再生され、行は矢印キーでも移れます。エフェクトの編集画面にも、編集中のエフェクトを繰り返し再生するプレビューが付きました。

くわしくは[エフェクトを構えて発動する](/manual/map-effects#エフェクトを構えて発動する)と[エフェクト集を探す](/manual/map-effects#エフェクト集を探す)を参照してください。

## 🏷️ 項目の別名

シートの出どころが違うと、同じ値でも「行動値」と「イニシアティブ」のように項目の名前が違うことがあります。部屋設定の**一般**のタブの**項目の別名**で、こうした項目に部屋で1つの名前を付けられます。別名ごとに候補の項目を順番に並べると、コマごとに最初に見つかった項目が使われます。

別名はインベントリの表示項目と並び順、チャットの`{行動値}`、`:行動値+3`のようなリソース操作、バフの対象、移動範囲や交戦エリアのルールで使えます。別名で値を書き換えると、そのコマで見つかった候補すべてが同じ値になります。変えられるのはGMだけです。

くわしくは[項目の別名](/manual/room-settings#項目の別名)を参照してください。

## ⏳ バフの効果が動く時期

`0~+3`や`++`のように、減るたびに動かす量を持つバフは、動く時期を`発生:`で決められます。`発生:ラウンド終了`・`発生:手番開始`・`発生:手番終了`の3つが書けます。手番はそのバフを持っているコマ自身の手番です。

```
&!再生/:HP/+/0~+3/none/発生:手番開始
```

この行で付けたバフは、自分の手番が始まるたびにHPを3回復します。バフ編集とバフマネージャーには**効果の発生タイミング**の欄が入りました。

くわしくは[効果が動くタイミング](/manual/buff#効果が動くタイミング)を参照してください。

## 🔄 バフと値のリセット

戦闘のあとに、コマに付いたバフをまとめて外し、シートの値を戦闘の前へ戻せるようになりました。

シートの項目には、リセットで戻る先の既定値を持たせられます。キャラクターシートの上部の**いまの値を既定値にする**を押すと、そのコマのいまの値をまとめて既定値にできます。バフには「バフ」か「デバフ」かの区分が付き、状態異常として付けたものはデバフになります。デバフのバッジには小さな`▼`が出ます。

| すること                           | チャット                  | コマの右クリック     |
| ---------------------------------- | ------------------------- | -------------------- |
| バフをすべて外す                   | `&*-`                     | **バフをすべて外す** |
| 区分がバフのものを外す             | `&*バフ-`                 | **バフだけ外す**     |
| 区分がデバフのものを外す           | `&*デバフ-`               | **デバフだけ外す**   |
| 値を既定値に戻す                   | `:*=既定`                 | **値を既定値に戻す** |
| バフをすべて外し、値を既定値に戻す | `&リセット-`（`&reset-`） | **すべてリセット**   |

`t&リセット-`のように先頭に`t`を付けるとターゲットにしたコマに、`&&リセット-`のように`&&`で始めると卓の上の全コマに効きます。全コマに効く形を使えるのはGMだけです。リセットを報告した行には、リセットした本人の画面にだけ**元に戻す**のボタンが出ます。バフマネージャーの**バフの一括解除（GM）** にも、バフだけ・デバフだけを外す条件と、**値も既定値に戻す**が入りました。

くわしくは[バフと値のリセット](/manual/buff#reset)と[既定値](/manual/data-element#既定値)を参照してください。

## ⌨️ チャットからの行動順の操作

発言の先頭にコマンドを書くと、[行動順](/manual/turn-order)をチャットから動かせます。行動順ウィジェットを開いていなくても使え、チャットパレットやホットバーにも登録できます。英字のコマンドと日本語のコマンドは同じ働きです。

| コマンド                   | すること                               |
| -------------------------- | -------------------------------------- |
| `&T`・`&手番`              | 発言者のコマの手番を始めます           |
| `&TE`・`&手番終了`         | 手番を終えて、次へ渡します             |
| `&TW`・`&待機`             | 手番のコマを待機させます               |
| `&TI`・`&割り込み`         | 待機している発言者のコマが割り込みます |
| `&TB`・`&前へ`             | 1つ前の状態へ戻します                  |
| `&RS`・`&ラウンド開始`     | ラウンドを始めます                     |
| `&RN`・`&次のラウンド`     | いまのラウンドを閉じて、次を開きます   |
| `&RB`・`&ラウンドを戻す`   | 前のラウンドが終わった時点まで戻します |
| `&RR`・`&ラウンドリセット` | 手番とラウンドを最初の状態へ戻します   |

`&T`を使えるのは、[陣営ごと](/manual/turn-order#陣営ごとに動かす)でフェイズ内が「自由」の進め方のときです。発言者に選んだコマの手番が始まります。コマンドのうしろに続けて書いた部分は、行動順を動かしたあとに、ふつうの発言として別の行で送ります。`&T 2d6+5 命中判定`と1行で書くと、手番を始めてから振ります。

```
&T 2d6+5 命中判定       手番を始めてから 2d6+5 を振る
&RN 次のラウンドです    次のラウンドを開いてから発言する
```

コマンドを使えるのは、行動順ウィジェットのボタンを押せるGMとPLです。誰のコマの手番でも使えます。見学の人は使えません。バフの残ラウンド、手番の知らせ、効果音、画面の移動は、ボタンで操作したときと同じです。コマンドで進めた分も**前へ**で戻せます。効かない場面で打ったときは行動順は動かず、打った本人にだけ理由が出ます。

入力欄では、発言の先頭に`&`を打つとコマンドが候補に並びます。書いたコマンドにポインタを乗せると説明が出て、効かない場面では波線と理由が出ます。

くわしくは[行動順の操作](/manual/chat-syntax#行動順の操作)を参照してください。

## 🧩 部位の行の詳細とバフ

[複数の部位を持つコマ](/manual/ride#複数の部位を持つコマ)では、本体の名前の下に部位の行が並びます。部位の行にマウスを乗せると、その部位だけの詳細の小窓が出ます。タッチの端末では、行を押すと小窓が出ます。内容が公開されていない部位の行では、小窓は出ません。

部位の行のバフは、これまでいつもアイコンで出ていました。今は本体と同じ「バフの表示」（アイコン・詳細・個数）で描かれます。本体のコマを右クリックして「バフの表示」を切り替えると、本体の行と部位の行が一緒に変わります。乗り物に乗っているコマの行も同じです。

くわしくは[複数の部位を持つコマ](/manual/ride#複数の部位を持つコマ)を参照してください。

## 🏘️ マップ生成の村と砦

マップ生成の**地面の起伏（マス）** が、農村・蛮族の砦・石造りの砦にも効きます。道・畑・建物・壁のある敷地と外側の1マスを同じ高さにならし、その外を2マスの幅でまわりの地面につなぎます。建物も壁も柵も作物も平らな台地の上に立ちます。地面の起伏を0にすると、これまでと同じ平らな盤面になります。

くわしくは[マップ生成](/manual/map-generator#村と砦の地面)を参照してください。

## 🌐 お知らせの言語

手番・交戦エリア・乗り降り・ダイス・カード・コイン・点呼と投票・アラーム・トリガー・ゲーム内時間・バフの一括操作のお知らせは、これまで送った人の画面の言語で全員に届いていました。今は読む人それぞれの画面の言語で出ます。

エフェクトと効果音の一覧も、表示している言語の順に並びます。項目の種類の名前やアイコンの分類は、言語を切り替えるとその場で変わります。自動計算バフの記法を作る画面の最初の名前も、表示している言語のものになります。

## 🖱️ テーブルの上のクリック

- コマの端を右クリックすると、隣のコマのメニューが開くことがあったのを直しました。乗り手を右クリックしたのに、乗り物のメニューが開くことがありました。押したコマのメニューが開きます
- コマの端をクリックやダブルクリックすると、隣の物が反応することがあったのを直しました。並んだ扉の隣の扉が開くことがありました
- カードをすばやく2回右クリックすると裏返り、山札では1枚引いていたのを直しました。ダブルクリックに数えるのは、同じボタンの2回だけです。コインとダイスも同じです
- 投げた人の画面で、ダイスが途中から別の転がり方でやり直していたのを直しました
- 一人称視点で、盛り上げた地面に立つコマの目が地面の下にあったのを直しました

## 🧱 テーブルの見た目

- 幅・奥行き・高さのどれかが0の地形が、ちらついていたのを直しました
- ホワイトボードを裏から見ると、描いたものが左右逆に透けていたのを直しました。裏には板の色だけが見えます
- 直立させた共有メモが裏から見ると消えていたのを直しました。裏には紙の色だけが見えます
- 大きさが0のコマが、1マスぶんの影を落としていたのを直しました
- 縦長の盤面で、射程範囲の起点の印がずれていたのを直しました

- Axeが更新されたあと、マウスを乗せたときの詳細が出なくなることがあったのを直しました。読み込めないときは、ページの再読み込みを案内します
- ジュークボックスで**全て**のタブを選んでいるとき、言語を切り替えると選択が外れていたのを直しました

## ⚠️ 動きが変わるところ

**消えない**バフに`~`や`++`・`--`の量を書くと、以前の版では一度も動きませんでした。この版からは、ラウンドが終わるたびに動きます。すでにコマに付いているバフも動き始めます。動かしたくないバフは`~`のない量で付け直してください。`&R-`やリモコンで手で減らしたときも、消えないバフは残ラウンドをそのままに1回動きます。

発言の先頭に`&T`や`&RS`のようなコマンドの語だけを書くと、行動順のコマンドとして読みます。これまでは「T」や「RS」という名前のバフを付けていました。この名前のバフを付けるときは、`&T/効果`のように`/`で欄を続けて書きます。`&T-`で外す書き方と、文の途中に書いた`&T`は、これまでどおりバフの操作として読みます。`&手番`や`&待機`のような日本語のコマンドも同じです。

`&*-`・`&*バフ-`・`&*デバフ-`・`&リセット-`・`&reset-`は、名前にかかわらずバフを外す操作とリセットとして読みます。これまでは`*`や`リセット`という名前のバフを外していました。`*`のうしろにほかの語を書いたときは、これまでどおり、その名前のバフを外します。

エフェクト集でエフェクトを押しても、その場では発動しません。これまでは、上限まで対象を選ぶとそのまま発動し、対象が「自分」のエフェクトは押した時点で発動していました。今は構えてから、**対象に発動する**かEnterで発動します。キャラクターシートの演出欄・コマの右クリック・ホットバーの**発動**の枠は、ほかのコマをターゲット指定していないとき、これまでは押したコマ自身にかかっていました。今は相手が要るエフェクトなら、そのコマを撃ち手にして構えます。対象が「自分」のエフェクトは、これまでどおりそのコマにかかります。

SkyWay版では、あとから入った人の画面に、画像・BGM・3Dモデルが届くのが少し遅くなります。テーブルとチャットを先に受け取るためです。接続パネルに「部屋のデータは最新です」と出てから少し待つと、絵と音がそろいます。テーブルとチャットの受け取りが長引いても、最初の相手とつながってから20秒たつと頼み始めます。

通信品質のウィジェットの往復遅延は、回線が混んでいるとき、これまでより小さい数字になります。測るための通信を、部屋のデータや画像より先に送るようにしたためです。回線が混んでいるかどうかは、接続パネルの受け取りの進みで確かめてください。

マップエディターでテクスチャに取り込んだ画像は、すでに別のタグが付いていても、タグが「テクスチャ」に変わります。これまでは元のタグのまま残り、テクスチャの一覧に出ませんでした。元のタグの一覧からは外れます。[自分専用にしたタグ](/manual/images#private-tag)に入れてある画像だけは、タグを変えません。ほかの人に見えてしまうためです。取り込んだ画像はそのまま塗りに使え、テクスチャの一覧に並ぶのは、自分専用を解いてから取り込み直したときです。タグを変えなかったことは、画面の下の知らせで分かります。スタンプに取り込んだ画像も同じ扱いです。ココフォリアの部屋の取り込み・マップ生成・`map.zip`のロードが自動で付けるタグは、これまでと同じく、タグのない画像にだけ付きます。

## ⚠️ 以前の版との互換

部屋のデータと通信の版は変わっていません。v1.78.1以前の版の人とも、同じ部屋で遊べます。違いが出るのは次のところです。

お知らせを読む人の言語で出すために、送り方を変えました。v1.78.1以前の版の参加者の画面では、この版の人が始めた点呼・投票・アラームの行が、`@i18n:`で始まる文字のまま出ます。ほかのお知らせにも、正しく出ないものがあります。全員が同じ版になれば起きません。

項目の別名はv1.78.1以前の版では使われません。その版の人の画面では別名のない部屋として動きます。

`発生:`を書いたバフは、v1.78.1以前の版の人が行動順を進めた回には、残ラウンドが減るときに動きます。消えないバフはその回には動きません。

行動順のコマンドは、打った人のブラウザで行動順を動かします。v1.78.1以前の版の人が`&T`や`&RS`を打つと、行動順は動かず、その名前のバフが付きます。

SkyWay版のデータの照らし合わせは、この版の人どうしで行います。v1.78.1以前の版の人が頼んだ画像と音楽は、これまでどおりすぐに送ります。

この版で増えた種類のエフェクト（聖印・光輪・聖域・影の棘・暗黒球・地割れなど）は、v1.78.1以前の版の画面では爆発として描かれます。状態異常の姿（毒・睡眠など）はその版では呪いの姿で、極彩ビームは極太ビームの姿で描かれます。描き直したほかのエフェクトは、その版の画面では以前の見た目のままです。

状態異常を付けたときのエフェクトは、状態異常を付けた人のブラウザから撃ちます。v1.78.1以前の版の人が状態異常を付けたときは流れません。

バフの区分と項目の既定値は、v1.78.1以前の版の人の画面でも消えずに残り、部屋の保存にも書き出されます。その版ではリセットの操作は使えません。その版の人が`&*-`や`&リセット-`を打つと、その名前のバフを外す操作になり、`&毒霧/命中-2/3/デバフ`と打つと、アイコンが「デバフ」の文字になります。

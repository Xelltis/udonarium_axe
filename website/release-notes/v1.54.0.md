# v1.54.0

2026-09-13リリース

ダイスをまとめて置き、使い終えたものに印を付けられる版です。個数と持ち主を決めて一度に並べ、使ったダイスは暗くしておけます。

GMは右クリックひとつでパーティを一か所に集められるようになりました。掴んだコマは**Shift＋ホイール**で宙に持ち上げられます。

不具合では、見学の画面から部屋全体に効く操作ができていた箇所と、ほかの人の操作がドラッグするまで画面に出なかったものをまとめて直しました。

## 🎲 ダイスをまとめて置く

テーブルの何もない場所を右クリックし、**ダイスを作成**の一覧の最後にある**個数を指定して作成…** を選びます。種類と個数を決めると、押した場所から5個ごとに折り返して並びます。重なったダイスを手でほどく手間はもうかかりません。

同じダイアログで**所有者**と**自分だけ見る（伏せて置く）** も決められます。所有者にしたコマでは、`dice:コマ名`の連動や「コマにしまう」がすぐに使えます。既定は「なし」と「全員に見える」で、メニューから1個置いたときと同じです。詳しくは[ダイス](/manual/dice#ダイスシンボルを置く)にあります。

## 🔅 使い終えたダイスを暗くする

ダイスの右クリックメニューに**使用済み**が増えました。入れると、ダイスが枠ごと暗く表示されます。1回に1個、1シーンに1個と使い切るダイスをテーブルに並べておく遊び方で、どれがまだ残っているかを覚えておかずに済みます。

変わるのは見た目だけで、振ったり動かしたり出目を読んだりは、これまでどおりできます。伏せたダイスにも付けられます。

## 🧭 パーティを一か所に集める

テーブルの何もない場所を右クリックし、**この地点を中心にパーティを配置**からパーティを選ぶと、そのパーティのコマが押した地点の周りに集まります。散らばった一行を次の場面へ連れていくとき、1体ずつ動かさずに済みます。GMにだけ出る項目です。

コマは押した升目から近い順に、空いている升目へ並びます。ほかのコマが立っている升目は避け、大きなコマは必要な広さが空いた場所に入ります。ヘクスのテーブルでも同じように並びます。

卓に出ていないメンバーがいるパーティは、「卓上の3体」「卓外の2体も出す」のように2つの項目に分かれて出ます。何体動くかを押す前に確かめられます。卓外のメンバーは、置ける場所が見つかったものだけが卓に出ます。詳しくは[同行（パーティ）](/manual/party#この地点に集める)にあります。

## 🎈 コマを宙に持ち上げる

コマを掴んだまま**Shiftを押しながらホイール**を回すと、高度が1マスずつ上下します。上下とも12マスまでです。これまでは右クリックメニューの**高度設定**で数値を入れるしかありませんでした。Shiftなしのホイールは、これまでどおり足場を上下に辿ります。壁に掛けたコマは高度を持たないので、この操作は効きません。

掴んでいるあいだ、地面から浮いたコマには足元までガイドが伸びます。1マスごとの目盛りと今の高さ、真下の位置が出るので、浮いているのか、後ろの何かに乗っているのかを見分けられます。画面の下にも「ホイールで足場を上下に辿る」「Shift＋ホイールで高さを1マスずつ」と操作の案内が出ます。

詳しくは[オブジェクトの基本操作](/manual/objects#height)にあります。手を離したコマが足場まで落ちる理由は[よくある質問](/help/#falls)にまとめました。

## 📋 卓のコマから決まる表示項目

表示項目は卓のコマから決まるようになりました。新しい部屋では、インベントリの表示項目と並び順が空の状態で始まるようになりました。表示項目は、インベントリの列と、リモコンのキャラクター一覧に並ぶ値を決める設定です。これまでは見本のシートに合わせたHP・MPと6能力値、敏捷度の降順が最初から入っていたため、取り込んだシートばかりの部屋では中身の出ない列や値が並んでいました。

表示項目が空のあいだは、卓に出ているコマが実際に持っているリソースから項目を組み立てます。コマにバーを出す設定の項目が先に、多くのコマが共有している項目がそのあとに来て、8列までです。簡略表示では、さらにうしろへ状態異常のチェック欄が付きます。リソースの名前を変えれば、列もついてきます。手番の表示は、並び順を決めるまで一覧に並んだ順です。

表示項目に名前を書けばそちらが優先されるのは、これまでと同じです。すでに項目が入っている部屋は変わりません。サンプルのコマ6体つきで作った部屋も、これまでと同じ項目と並び順で始まります。

表示項目では、引用符で囲んだ名前を1項目として読むようになりました。`"所持金 合計"`のように空白を含む名前も、`"リソース/正気度"`のようにシートの階層をたどる書き方も使えます。同じ名前の項目がシートに2つあるとき、どちらを出すかを場所で指定できます。引用符の外の`/`は、これまでどおり改行です。詳しくは[インベントリ](/manual/inventory#検索と表示設定)にあります。

## 📏 単位がマスのときの1マスの距離

部屋設定の**移動**で、単位が「マス」のときも**1マスの距離**を設定できるようになりました。シートの1マスとテーブルの1マスの大きさが違うシステム向けです。0.5にすると、シートの3マスがテーブルの6マスになります。

メートルやフィートからマスへ切り替えると、1マスの距離は1に戻ります。ただし、この版より前にマスへ切り替えた卓には、画面に出ないまま前の値が残っていることがあります。マスの卓で移動範囲の広さが変わったら、1マスの距離を確かめてください。詳しくは[移動範囲](/manual/move-range#単位の換算)にあります。

## 🎮 リモコンのリソース操作

リモコンでシートのどの項目も動かせるようになりました。リモコンのリソース操作のボタンを、操作する相手のコマが持っている項目から作るようになりました。相手は選んだコマで、何も選んでいなければタブ内の全コマです。これまでは、リモコンの持ち主のシートにあって、しかも部屋の表示項目に入っている項目しか押せませんでした。相手のコマにしか無い項目も、セッションの途中でシートに足した項目も、そのまま操作できます。部屋の表示項目に入っている項目は先頭に並びます。

リソース項目を選ぶと、動かす場所を**現在値・最大値・最大値ベース・最大値補正・最小値ベース・最小値補正**から選べます。項目やコマを切り替えても選んだ場所はそのままなので、何体かのコマの同じ箇所を続けて動かせます。同じ名前がシートに2つある項目は、どちらを動かすか決められないためボタンに出ません。

バフのコマンドでも、`HP_MAX`（最大値のベース）・`HP_MAX_BUFF`（その補正値）・`HP_MIN`・`HP_MIN_BUFF`を書けるようになりました（→ [バフ／デバフ](/manual/buff)）。

## 🐛 直った不具合

**見学の画面から、部屋全体に効く操作ができていました**。できていたのは、チャットタブの削除とログの消去、手番の受け渡しやラウンドの進行、カットインの作成と削除、ダイス表の作成・編集・削除です。見学の画面ではこれらのボタンが出ないか、押せない表示になりました。なお見学は、各自が接続パネルで外せる役割です。隠し事を守る仕組みではないことを[ロール](/manual/roles#見学-読み取り専用)に書き足しました。

**シークレットダイスを、振った本人以外も公開できていました**。チャットの簡易表示で、どの行にも公開ボタンが出ていたためです。いまは振った本人とGMだけが公開できます。

**GMを選んだまま他人の部屋に入ると、GMとして入っていました**。ロビーや招待リンクから入るときは、プレイヤーになってから入ります。自分の部屋を再読み込みしてロビーから戻るときは、同じタブならGMのままです。

**同じキャラクターのダイスを2回目に「コマにしまう」と、ダイスが消えていました**。ほかの参加者がいる部屋で起き、シートからもテーブルからも消えて、コマから出し直すこともできませんでした。しまえなかったダイスは、消さずにテーブルへ残すようにもしています。

**壁画像を貼ったテーブルを保存すると、読み込んだときに壁が白紙へ戻っていました**。画像のない壁は描かれないので、壁に掛けたコマまで見えなくなっていました。壁画像も保存データに入るようになりました。載っている壁が描かれなくなったときも、コマは床に表示します。壁を戻せば、コマも壁に戻ります。

**ほかの人の操作が、そのオブジェクトを動かすまで画面に出ないことがありました**。次のものは、操作したその場で全員の画面に反映されます。

- ダイスを伏せる、カードを自分のものにする
- 山札のロック、山札を見ている人の名前
- スクラッチマスクの大きさ・色・ロック
- 参加者の名前の変更（カーソルに出る名前）
- カードやホワイトボードに設定した画像
- マウスを載せたときに出る詳細（ダイスを伏せても出目が見えたままでした）

そのほか、次のものを直しました。

- 壁から床に下ろしたコマが、保存して読み込むとテーブルに沈み、寝た向きで表示されていた
- ノベルモードの吹き出しとバックログで、ルビの記法`|テキスト《ルビ》`がそのまま表示されていた。ルビを付けて表示し、ふりがなは本文の大きさに合わせて小さくしています
- バフ編集で、チャットから付けたバフのタイミングが「ラウンド終了時」、トリガーが未設定と表示されていた（バフ自体は正しく動いていました）
- 別ウィンドウに出したパネルから開いたパネル（チャットの設定やダイス表など）が、元の画面に出ていた。セレクトボックスの一覧も同じでした

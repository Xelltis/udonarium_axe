# v1.12.1

2026-06-07リリース

## 🐛 不具合修正

- **行動順** … 行動順ウィジェット（最小化したインベントリ）に、インベントリ「テーブル」タブで**非表示**にしているキャラクターまで表示され、手番送りの対象にもなっていた問題を修正しました。通常のインベントリ表示と同じく、非表示のキャラクターは行動順から除外されます。
- **行動順** … 手番の通知（ラウンドの開始・終了、現在の手番のキャラクター、リセット）が、システムメッセージの送信先タブの設定によってはメイン以外のタブに流れてしまうことがありました。行動順の通知は常に**メインタブ**に表示されるようにしました。

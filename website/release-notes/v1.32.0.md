# v1.32.0

2026-08-11リリース

**入退室の知らせで会話が流れなくなった**回です。システムメッセージ専用のタブができました。

## ✨ 新機能・改善

### システムメッセージが「システム」タブに出るようになりました

これまで、**入退室・再接続・無応答**などの知らせは会話をしているタブ（既定ではメインタブ）に出ていました。
誰かがふつうに退室しただけで知らせが続けて流れ、読んでいたやり取りが画面の外へ押し出されてしまっていました。

v1.32.0からは、これらの知らせは**専用の「システム」タブ**にまとまります。会話のタブは会話だけになります。

| 出る場所           | 内容                                                         |
| ------------------ | ------------------------------------------------------------ |
| **システムタブ**   | 入室・退室・再接続・無応答・接続エラー・ルーム取り込みの結果 |
| **これまでどおり** | ラウンド開始 / 手番 / バフの失効（卓の進行の告知）           |

ラウンドや手番の告知は**卓の進行の一部**で、あとから読み返すものなので、会話のタブに残しています。

#### システムタブの決まり

- **消せません。** 消してしまうと知らせの行き先が無くなり、会話のタブへ戻ってきてしまうためです
- **「全タブ」のログ書き出しには入りません。** 読み返したいやり取りが入退室の知らせに沈まないようにするためです。
  知らせも残したいときは、システムタブを選んで「**このタブ**」で書き出してください
- **名前は変えられます。**「お知らせ」などに変えても、システムタブとしての扱いは変わりません
- **前からある部屋でも使えます。** 保存しておいた部屋データを読み込むと、システムタブが自動で足されます

チャットのタブ設定にあった「システム表示先を設定」は、行き先が固定になったため無くなりました。

# v1.16.0

2026-06-13リリース

前バージョンで追加した**マップエディター**の使い勝手を大きく高めるアップデートです。描いたあとの編集（フリーハンド・曲線・スタンプ・レイヤー）を中心に、キャンバス上での文字入力やPhotoshopのような消しゴムにも対応しました。

## ✨ 新機能・改善

### マップエディターの編集機能を強化

- **キャンバス上で直接文字入力** … テキストツールでクリックした位置にそのまま入力でき、フォント・サイズ・色・ズームを反映したまま編集できます。改行はEnter、確定はCtrl+Enterかキャンバスの別の場所をクリック、取り消しはEsc。置いた文字はダブルクリックで再編集できます。
- **任意の画像をスタンプに** … 「スタンプ」ツールに**画像**カテゴリを追加し、手持ちの画像をアップロードしてスタンプとして配置できます。アップロードした画像はメディアに登録され、「**マップスタンプ**」タグが自動で付きます。メディア側で同じタグを付けた画像も、候補として自動で並びます。画像は**1マスに収まるよう**リサイズされて配置されます。
- **フリーハンドの編集** … 描いた線を選択して、**色と線幅**を後から変更できるようになりました。
- **曲線の編集** … 確定後の曲線・閉じ曲線を選択すると**制御点（アンカー）** がハンドルとして表示され、ドラッグして形を再調整できます。
- **消しゴムの刷新** … 消しゴムが**フォーカス中のレイヤーに合わせて**動作します。セルレイヤーではマスを、スタンプ・画像・文字レイヤーではその要素を消し、**フリーハンドはPhotoshopの消しゴムのように線を部分的に消去**します（線は消した箇所で分割されます）。消しゴムのサイズはスライダーで調整でき、カーソルには消しゴムの円が表示されます。
- **スタンプは1つ＝1レイヤー** … スタンプを置くたびに専用レイヤーが作られ、画像と同じように個別の表示 / ロック / 並び替え / 不透明度を管理できます。
- **レイヤーのドラッグ＆ドロップ並び替え＋ミニプレビュー** … レイヤー一覧を**ドラッグで並び替え**できるようになり、各レイヤーに内容の**サムネイル**が表示されるようになりました。

詳しくは[マップエディターのマニュアル](/manual/map-editor)を参照してください。

## 🐛 不具合修正

- **描画の既定色** … 既定の線・文字・スタンプ色がほぼ白で、明るい / 透明な背景に描くと見えなかった問題を修正し、視認しやすい濃色を既定にしました。
- **ウィンドウモードの操作** … マップエディターのキャンバスをドラッグするとウィンドウ自体が動いてしまい操作しづらい問題を修正しました。
- **セルレイヤーの追加** … レイヤー追加メニューから、セルレイヤーなど同じ種類のレイヤーを2枚目以降作れなかった問題を修正しました。

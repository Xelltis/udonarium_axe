# v1.67.0

2026-10-14リリース

卓に**水域**を置けるようになりました。池や川、浜から深みへ続く海辺を描けて、濁り・汚れ・浮き葉・流れも付けられます。水の中にいる駒は、水面から下が水ごしに見えます。卓全体を水の中にする天候「水中」も加えました。

ミニプレイヤーに**DJデッキ**を付けました。曲ごとの音量をそろえ、効果音が鳴るあいだは音楽を下げ、曲と曲を重ねてつなぎます。曲のテンポも読み取るので、拍に合わせた曲の切り替えやキューへの移動、エフェクトやパッドで場を盛り上げられます。

乗り物の乗る高さを、乗り物の高さに対する割合や、好きな数値で決められるようにしました。

## 🌊 水域と水中

盤面の何もないところを右クリックし、「環境エフェクトを置く」から「水」を選ぶと、水域が置かれます。並べた水域は、つなぎ目のない1つの水として描かれます。四角の卓でもヘクスの卓でも使えます。

右クリックの「環境エフェクトの設定」で、水面の高さ・濁り・汚れ・浮き葉・流れの速さと向きを決めます。澄んだ水・濁った水・泥水・藻の浮いた水・よどんだ水・白く濁った水・蓮池の見た目から選ぶこともできます。

水の底は、水域の床とその下の地形のうち高いほうです。傾いた地形の上に水域を置くと、浅瀬から深みへ水の色が濃くなり、水面まで届いた地形の縁には波が打ち寄せます。足元が水面より低い駒は、水面から下が水ごしに見え、深いほど、濁っているほど薄れていきます。

テーブル設定の天候で「水中」を選ぶと、卓全体が水の中になります。ダンジョンドリィマスターモードでは、水の中に入ると濁りに応じて見通しが縮み、流れのある水では漂う粒が目の前を流れていきます。マップエディターの機能塗りでも、危険地帯の「水」で水を塗れます。

くわしくは[水域と水中](/manual/water)にあります。

## 🎧 DJデッキ

ミニプレイヤーのDJボタンでデッキが開きます。部屋に追加した音源は裏で1曲ずつ読み取られ、曲全体の大きさ、前後の無音、テンポと小節の頭がわかります。読み取った結果は部屋の全員に共有されます。ジュークボックスや再生リストの曲名の横にも、BPMが出ます。

デッキでは、曲の拍に合わせて光る点を見ながら、テンポを直したり、曲の中の位置を4つまでキューとして覚えたりできます。フィルター・エコー・残響のつまみと、レコードを止めたように曲を減速させるブレーキもあります。パッドには効果音を8つまで割り当てて、押すだけで鳴らせます。

GMはミックスのタブで、部屋の鳴らし方を決めます。

- 自動音量：曲ごとの大きさの差をそろえます
- ダッキング：効果音やカットインが鳴るあいだ、音楽を下げます
- クロスフェード：曲の終わり近くで、次の曲と重ねてつなぎます
- 一時停止のフェード：止めるときと再開するときに、音を小さくしてから止め、小さい音から戻します
- クオンタイズ：曲の切り替えを次の小節の頭まで、キューへの移動を次の拍の頭まで待ちます
- ビートライト：曲の拍に合わせて、全員の画面の縁が光ります

くわしくは[DJデッキ](/manual/dj-deck)にあります。

## 🐎 乗る高さ

「コマ高さを指定」をした乗り物では、乗っている駒が画像の上端に立つようにしました。指定していない乗り物は、これまでどおり大きさの半分の高さです。

乗り物のメニューの「乗る高さ」では、乗り物の高さの1/4・半分・3/4・高さいっぱいも選べます。いちばん下の「数値で指定…」を選ぶと、駒の詳細の設定タブが開き、px・マス・%で好きな高さを入れられます。

くわしくは[乗り物に乗る](/manual/ride#乗り物にする)にあります。

## ⚠️ 以前の版との互換

v1.66.0以前の画面では、水域は毒沼として描かれ、天候「水中」は何も描かれません。DJデッキの自動音量・ダッキング・クロスフェード・エフェクトは効かず、ブレーキはふつうの一時停止に、キューへの移動はふつうのシークになります。

乗る高さは、部屋にいる人それぞれの画面が決めて書き込みます。v1.66.0以前の人が部屋にいると、「コマ高さを指定」をした乗り物の乗り手や、割合・数値で高さを決めた乗り物の乗り手が、その人の画面の既定の高さに戻されることがあります。部屋の全員がページを再読み込みして、この版にそろえてください。

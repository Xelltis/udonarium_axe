# v1.65.1

2026-10-11リリース

ダンジョンドリィマスターモードの見え方を直したリリースです。巨大なコマが小さく描かれていたのを、卓と同じ大きさで描くようにしました。景色をドラッグして見回せるようにもなり、巨大なコマの真横に立って見上げられます。

## 🐉 巨大なコマを卓と同じ大きさで描く

このモードでは、コマの画像を決まった比率の枠に収めていました。そのため、縦長の画像ほど小さくなり、大きなコマが卓で見るより小さく見えていました。今は卓と同じく、幅はコマのサイズのマス数、高さは画像の縦横比で決まります。コマ画像の高さを指定したコマは、その高さで立ちます。

大きなコマは、真ん中のマスが柱の陰に隠れていても、足元のどこかが見えていれば描かれます。名前とリソースバーは、普通の大きさのコマと同じ幅で出るので、画面の端から端まで伸びることはありません。

壁に囲まれた部屋では、壁より背の高いコマが立っていると、その部屋の天井をコマの頭の上まで上げます。天井で頭が切れなくなりました。

くわしくは[ほかのコマと卓の上の物](/manual/dungeondry-master#ほかのコマと卓の上の物)にあります。

## 👀 ドラッグで見回す

景色をマウスでドラッグすると、その方へ見回せます。タッチ操作では指1本でなぞります。左右はぐるりと後ろまで、上下はほぼ真上・真下まで向けます。離すと、コマの正面・水平へ戻ります。

見回しはこの画面の中だけのもので、卓の上のコマの向きは変わりません。見回しながらキーで歩くこともできます。

くわしくは[見回す](/manual/dungeondry-master#見回す)にあります。

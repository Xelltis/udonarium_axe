# v1.47.0

2026-09-02リリース

**戦場の霧**が入りました。誰も足を踏み入れていない場所を霧で覆い、パーティが進んだぶんだけ盤面が
開いていきます。テーブル設定のスイッチ1つで、ダンジョンを少しずつ明かしていく進め方を始められます。

あわせて、**ノベルモード**の画面を窓に分けました。**一覧**には1コマ1行の表が加わり、
部屋は状態異常のカタログを持つようになります。

## 🌫️ 戦場の霧

テーブル設定の **「戦場の霧（探索）」** から入れます。既定はオフなので、既存の部屋がひとりでに
霧に沈むことはありません。

暗闇とは別の仕組みです。暗闇が「今どこが照らされているか」を描くのに対し、霧は
**「パーティがどこまで踏み込んだか」** を描きます。明るい屋外マップで霧だけ使う、という組み合わせも
できます。

### 霧の戻り方を3段階から選べます

| モード   | 一度晴らした場所                 | 見つけた敵                       |
| -------- | -------------------------------- | -------------------------------- |
| イージー | 明るいまま固定される             | どこへ動いても位置がわかる       |
| ノーマル | 霧は戻らないが、離れると暗くなる | 踏破済みの場所にいる間だけ見える |
| ハード   | 視界から外れると霧に戻る         | 見失う                           |

既定は**ノーマル**です。イージーでは探索の記録がそのまま地図になり、ハードでは曲がり角の先を
覚えていられません。探索の厳しさを、卓に合わせて選べます。

### 霧はコマにも地形にもかかります

未踏破の場所に立つコマは表示されません。地形は**マス単位**で隠れるので、長い壁のうち、踏破した
マスにかかる部分だけが現れます。手前の面は霧の向こうでも描かれるので、「そこに何かある」ことは
わかります。

::: warning 霧を晴らせるのはプレイヤーのコマだけです
霧を晴らせるのは、プレイヤーが所有するコマの視界です。GMが持つNPCやモンスターの視界では晴れません。
[同行（パーティ）](/manual/party)を組んでいれば、仲間の誰かが通った場所は全員の地図に記録されます。

所有者を設定していないコマは、例外的にパーティの目として扱われます。GMが動かすコマにはNPC印を
付けておいてください。
:::

::: warning 視界範囲0のコマは、霧をほとんど残しません
視界範囲0は「制限なし」を意味します。暗闇を使わず霧だけ使う卓では、壁に遮られない限りどこまでも
見通してしまうため、盤面が開いたままになります。**コマの視界範囲を設定してから霧を入れてください。**

暗闇と併用する場合は、照らされている場所しか見えないので、この心配はありません。
:::

### 視界の形を選べるようになりました

コマの視界設定に**視界の形**が加わりました。ドーム・コーン・複数コーン・背面付きコーン・周辺視・
カスタムの6種類です。ドーム以外はコマの向きを基準にするので、回すと一緒に回ります。
**視界範囲を表示**を入れると、その形が盤上に線で描かれます。

### GMは視界をまとめて配れます

[オブジェクト一覧（GM）](/manual/gm-object-list)でキャラクターの行にチェックを入れると、選んだ全員の
視界を1回で設定できます。モンスターを20体置いてから暗視を配る、といった場面のためのものです。

触った項目だけが書き換わります。視界の形だけを揃えて距離は各自のままにする、といった配り方も
できます。

詳しくは[暗闇・視界・光源](/manual/vision-lighting)を参照してください。

## 🎭 ノベルモードが窓に分かれました

1枚のパネルに全部が入っていた画面を、**読む・演じる・演出する**の3つに分けました。バックログ、
表情の選択、表示設定、演出パネルは、それぞれ動かせてサイズも変えられる窓になります。

- **卓の雑談は台本から外れます。** ノベルモードが読んでいるタブに流れる「ちょっと待って」のような
  発言は、進行に出しません。GMが地の文として書いたものは残ります
- **GMの地の文に専用の置き場**ができました
- **キャラクターを退場させられます。** 切り替えではなく、見送る演出になります
- **タブを別窓で眺められます**
- **立ち絵の演出には、発言したあとから名前を付けられます。** ログの行から指定でき、名前は部屋の
  言語で表示されます

::: warning 表情と表示設定の場所が変わりました
これまでパネルの中にあった**表情の選択**と**表示設定**は、それぞれ独立した窓になりました。
ノベルモードのバーにあるボタンから開きます。
:::

::: warning 発言の記録に「話し手の役割」が加わりました
ノベルモードは、発言時点の役割を見て地の文と雑談を分けます。これまでは**現在の**役割で判定して
いたため、GMが席を譲ると過去の地の文が台本から消え、再接続すると雑談が混ざる問題がありました。

このバージョン以降に書かれた発言には役割が記録されます。**それ以前の発言は記録を持たない**ため、
従来どおり「誰のものか分からない発言」として扱われ、台本に残ります。
:::

## 📋 一覧を表として読めるようになりました

インベントリの読み方が3通りになりました。従来の**フル表示**、**ラウンド表示**に加えて、
**1コマ1行の表**です。バーのボタンを押すたびに切り替わります。

表には、能力値6種と部屋が持つ状態異常が列として並びます。マップの上に浮かせられ、中身に合わせて
広げられるので、戦闘中の一覧として使えます。行の左端には番号が付きます。

**検索と表示設定は別窓に移りました。** 一覧のバーにある調整アイコンから開きます。窓は1つだけ開き、
どの一覧のものかを覚えています。この窓にはGMが隠したコマをあえて表示する設定が入っているため、
テーブルを編集できる役割でのみ開きます。

## 🩸 部屋が状態異常を最初から持つようになりました

新しい部屋には、毒・出血・燃焼・麻痺・睡眠・石化・混乱・魅了・恐怖・暗闇など12種類が入っています。
名前・色・アイコン・継続ラウンド・効果の適用タイミングを、部屋ごとに書き換えられます。既存の部屋は
空のままなので、必要なものを自分で足してください。

カタログからコマへ付けられ、一覧の表には列として並びます。**継続ラウンドを0にすると、取り除くまで
消えません**。麻痺や石化のように「解除されるまで続く」ものを表現できます。

バフのアイコンには、絵文字だけでなく**部屋にある画像**を使えるようになりました。

## 🪟 そのほかの変更

**リソースの増減音に機械系が加わりました。** HPやMPが動いたときの音を、生身と機械から選べます。
ゴーレムやロボットのコマに機械音を割り当てられます。増減演出は項目ごとのオプトインなので、以前から
使っているキャラクターに自動で音が付くことはありません。

**窓の中身から、タイトルバーにボタンを置けるようになりました。** ノベルモードや一覧のバーは、この
仕組みで並んでいます。あわせて**ゴースト表示**（半透明にして盤面を透かす）と、**中身に合わせて畳む**
動きが入りました。ログ窓は最新の行を追いかけるようになり、こちらもゴーストにできます。

**サンプルの部屋が変わりました。** 新しく作った部屋のキャラクター3体は、視界2マスを持ち、
パーティ1に所属した状態で置かれます。霧や暗闇をすぐ試せるようにするためです。モンスター3体には
NPC印が付き、パーティには入りません。既存の部屋には影響しません。

## 開発者向け

### 戦場の霧の記録

踏破したマスは、テーブルの子として同期されるオブジェクトに記録されます。書き込むのは部屋で1人です。
GMがいればGM、いなければユーザーID順で最初のプレイヤーが担当し、他のクライアントが持つ記録は
上書きではなくマージされます。記録の識別子はテーブルの識別子から導かれるため、書き手が一時的に
二重になっても記録は1つに収束します。

イージーモードで追跡する「発見済みのコマ」も、同じ記録に併記されます。霧のリセットで一緒に消えます。

### 役割を読む処理の共通化

`PeerCursor.myCursor`は静的フィールドで、部屋に参加するまで存在しません。これを条件付きで参照して
いた48か所は、参加前に評価されるとシグナルの依存を1つも登録せず、既定の役割を返したまま固定されて
いました。`ObjectChangeService.trackMyCursor()`に集約し、カーソルの集合そのものも追うようにして
います。

### パネルの開閉状態

`PanelService.hasSingle()`がリアクティブになりました。名前が押さえられた・解放されたときにバージョンが
進むので、ボタン側は自前のフラグを持たずに`computed`で問い合わせられます。

### 同梱素材

機械音6本が加わりました。ダメージ側の3本は`src/assets/sounds/otologic/`（OtoLogic・CC BY 4.0）、
回復側の3本は`src/assets/sounds/soundeffect-lab/`（効果音ラボ）です。帰属は
[copyright.txt](https://github.com/Xelltis/udonarium_axe/blob/main/src/assets/copyright.txt)に
まとめています。

# v1.62.0

2026-10-08リリース

スマートフォンでキャラクターシートを読みやすく、直しやすくしました。狭い画面に合わせた並びになり、数値は「−」「＋」で増減でき、項目の組み替えも指でできます。消した行やセクションは、パソコンでもスマートフォンでも元に戻せます。

音まわりでは、雨音や焚き火のように流し続ける**環境音**をジュークボックスに加えました。ループ位置を書き込んだ曲は、1曲リピートでその区間をくり返します。新しい**音の設定**パネルでは、カットインや通知音、ダイスの音などの大きさを種類ごとに決められます。部屋の音量も、GMが種類ごとに決められるようになりました。

ほかに、背景の絵をテーブルの奥に重ねて奥行きを出す**奥のレイヤー**と、チャットを`Ctrl + F`で探す検索欄が入りました。

## 📱 スマートフォンでキャラクターシートを読む

スマートフォンで開いたキャラクターシートは、狭い画面に合わせた並びになりました。横向きに持っても同じです。パソコンでも、シートのパネルを細くするとこの並びに切り替わります。

- 一番上に、コマの立ち絵を小さくした画像と名前が出ます。画像を押すと、立ち絵の一覧が下から開きます。右上の「⋮」には、コピーを作る・保存・すべて畳む・すべて開くが入っています
- その下にセクションの名前が横に並び、押すとそのセクションへ移ります。この並びは読み進めても上端に残り、いま読んでいるセクションの名前に色が付きます
- 数値とリソースの横に「−」と「＋」が付き、1ずつ増減できます。リソースは「− 180 / 180 ＋」の形です。続けて押した分は押し終えてから1回の変更として送るので、コマの上の演出も1回で済みます
- 表になったセクションは指で横に送れます。行の見出しは左に残ります
- 長い文章の欄は、中身に合わせて縦に伸びます

セクションは見出しを押すと畳めます。これはパソコンでも同じです。畳んだ状態はこの端末に残るので、シートを開き直しても、別のキャラクターの同じ名前のセクションも、畳まれたままです。

くわしくは[スマートフォンで使う](/manual/mobile#キャラクターシート)にあります。

## ✏️ スマートフォンでシートの項目を組み替える

セクションの鉛筆を押して編集に入ると、各行には取っ手と名前、値、「⋯」だけが並びます。名前か「⋯」を押すと、その行の設定が下から開きます。名前と種別、詳細設定をまとめて変えられ、並べ替えや別のグループへの移動、複製、削除もここで行います。種別はアイコンの一覧から選びます。

- グループとセクションの見出しにも「⋯」があります。名前とアイコン、通常表示とテーブル表示の切り替え、項目やグループの追加、テンプレートの保存と呼び出しはここで行います
- 項目は、各グループの末尾にある**項目を追加**から足します。種別を選ぶとその場で項目ができ、名前を打ち直せる状態で設定が開きます
- 行の左端の取っ手を指で押さえたまま上下に動かすと、並び順を変えられます。置かれる場所に線が出て、指を画面の上端や下端に寄せるとシートが送られます

タブレットのように画面が広くても、指で操作する端末では、この「⋯」から開く設定で編集します。マウスで操作するパソコンでは、これまでどおり行の横のボタンで編集します。

くわしくは[項目を組み替える](/manual/mobile#項目を組み替える)にあります。

## ↩️ 消した行やセクションを元に戻す

シートの行やグループ、セクションを消すと、画面の下に通知が数秒出るようになりました。通知の**元に戻す**を押すと、消したものが名前と値ごと元の場所に戻ります。パソコンでもスマートフォンでも同じです。

## 🧑 オーナーのいないキャラクターを自分のものにする

[所有キャラクター一覧](/manual/pl-tools#所有キャラクター一覧)が空のときは、何をする一覧なのかの説明と、卓の上にいるオーナーのいないキャラクターが並ぶようになりました。**自分のものにする**を押すと、そのキャラクターが自分のものになり、一覧に入ります。コマを渡される前に部屋に入った人も、ここから自分のキャラクターを選べます。

スマートフォンでは、メニューの**キャラクター**から開く一覧です。

## 🌧️ 環境音を流す

雨音や焚き火、酒場のざわめきのように、BGMの下で流し続ける**環境音**を流せるようになりました。ジュークボックスで音源のタグを「環境音」にすると、ライブラリの行の ▶ で部屋の全員に流れ始めます。

- 環境音はくり返し再生され、止めるまで鳴り続けます。BGMを替えたり止めたりしても止まりません
- いくつでも重ねて流せます。流れている環境音は「NOW PLAYING」の下に一覧で出ます
- 一覧のスライダーは、その環境音の音量で、部屋の全員で共有します。止めても残り、次に流したときも同じ大きさで鳴ります
- 鳴り始めと止めるときは、1.5秒かけて大きさが変わります
- 途中から部屋に入った人にも聞こえます

どの環境音を流しているかとその音量は、部屋の保存データに入りません。

[リプレイ](/manual/replay)の記録にも環境音が入り、盤面の再生では記録したとおりに鳴ります。動画にすると、鳴り始めから止まるまでを1本ずつBGMに重ねて収録します。

くわしくは[環境音](/manual/jukebox#環境音)にあります。

## 🔁 ループ位置を指定した曲を、その区間でくり返す

ゲーム用のBGMには、イントロを一度だけ流し、そのあとの部分をくり返すように作られた曲があります。音源ファイルにくり返す区間が書き込まれていれば、ジュークボックスの**1曲リピート**でその区間をつなぎ目なしにくり返すようになりました。ほかのリピートでは、これまでどおり曲の最後まで流します。

- 読み取るのは、OGG（VorbisとOpus）・FLAC・M4Aの`LOOPSTART`・`LOOPLENGTH`タグ（RPGツクールと同じ書き方）と、WAVの`smpl`チャンクのループです
- 区間をくり返すために曲を丸ごとメモリに読み込むので、最初に流すときは鳴り始めるまで少し待つことがあります。8分ほどを超える長い曲は、曲全体をくり返します
- 環境音も、ループ位置があればその区間をくり返します

くわしくは[ループ位置を指定した曲](/manual/jukebox#ループ位置を指定した曲)にあります。

## 🔊 自分の音の大きさを種類ごとに決める

新しい**音の設定**パネルで、自分の端末で鳴る音の大きさを種類ごとに決められるようになりました。FABメニューの**表示**の小窓にある**音の設定**から開きます。ジュークボックスの「自分の音量」の横のボタンや、チャット設定の発言の効果音の欄からも開けます。スマートフォンでは、メニューの**音の設定**から開きます。

種類は、試聴・BGM・環境音・カットイン・通知音・操作音・演出の効果音・その他の効果音の8つです。これまで効果音としてまとめていた音を、次のように分けました。

- カットイン … カットインの音楽、場面に合わせて鳴る音、YouTube動画の音
- 通知音 … チャットの発言の効果音、アラーム
- 操作音 … ダイスやコインを振る音、カードを引く・混ぜる音、コマを持ち上げる・置く音など
- 演出の効果音 … マップ演出の音、HPなどが増えたり減ったりしたときの音

各行の左のボタンを押すと、その種類の音を消せます。もう一度押すと、消す前の大きさに戻ります。チャットの発言の効果音の設定も、このパネルから変えられます。

ここで決めた値は自分にだけ効き、このブラウザに保存されます。ジュークボックスの試聴・BGM・SE・環境音のスライダーも同じ値を動かします。これまでは開き直すたびに半分に戻っていましたが、今は次に開いたときも、別の部屋に入っても同じ大きさで聞こえます。

ジュークボックスの音量の欄は、「自分の音量」と「部屋の音量」の2つに分けて見出しを付けました。

くわしくは[音の設定](/manual/sound-settings)にあります。

## 🎚️ 部屋の音量を種類ごとに決める

部屋の全員に効く音量を、GMが種類ごとに決められるようになりました。音の設定パネルの**部屋の音量**では、すべての音に掛かる「全体」の下に、BGM・環境音・カットイン・通知音・操作音・演出の効果音・その他の効果音が並びます。たとえば、BGMを聞かせたい場面で、操作音だけを部屋の全員分まとめて下げられます。

- どのスライダーも、最初はつまみが真ん中にあり、元の大きさのままです。右へ動かすと、最大で2倍まで大きくなります
- 実際に聞こえる大きさは、自分の音量に、部屋の全体の値と同じ種類の値を掛けたものです
- ジュークボックスの「部屋の音量」でも、全体・BGM・SE・環境音を動かせます。どちらで変えても、同じ値が動きます
- ほかの参加者には、値だけが見えます

部屋の音量を動かせるのは、GMだけになりました。これまでは、横の「GM」にチェックを入れれば誰でも動かせました。

くわしくは[部屋の音量](/manual/sound-settings#部屋の音量)にあります。

## 🏞️ 背景をテーブルの奥に重ねる

背景のレイヤーを、テーブルの後ろの画面いっぱいに置けるようになりました。テーブル設定のレイヤーで、重ね位置を「奥」にします。山並みや街並みのような横長の絵を横につなげて並べ、縦は1枚だけ置きます。

奥のレイヤーは、カメラを回したり傾けたり動かしたりすると、少しだけついてきます。どれだけついてくるかは、レイヤーごとの「カメラへの反応」で決めます。反応が小さいほど遠くに、大きいほど近くに見えます。遠い山を10%、手前の街並みを35%、流れる雲を70%のように何枚か重ねると、カメラを動かしたときに絵どうしがずれて奥行きが出ます。

- 「高さ」は、画面の下端から絵の下端までの位置です
- 絵の上下の端は少しずつ透けていくので、切れ目が線になって見えません
- 横に自動で流す動きと透明度、拡大率も、ほかのレイヤーと同じように使えます
- 奥のレイヤーは、遠景の画像より手前、テーブルより後ろに描かれます

くわしくは[奥のレイヤー](/manual/table-setting#奥のレイヤー)にあります。

## 🔍 チャットを検索する

チャットウィンドウで`Ctrl + F`（Macでは`Command + F`）を押すと、右上に検索欄が開くようになりました。この検索欄が開くのは、入力欄を使っているときと、チャットウィンドウの上にマウスがあるときです。それ以外の場所で押すと、ブラウザの検索が開きます。タブの並びの右にある**検索**ボタンからも開けます。

長いチャットは、いま見ているあたりの発言だけを画面に出しているので、ブラウザの検索では古い発言が見つかりませんでした。この検索欄は今のタブの発言すべてから探し、見つかった発言まで画面を送ります。

- 発言の本文と発言者の名前から探します。全角と半角、大文字と小文字は区別しません
- 最初はいちばん新しい発言に移り、「2 / 5」のように何件目かが出ます。`Enter`で一つ前の発言へ、`Shift + Enter`で一つ後の発言へ移ります
- 見つかった文字には黄色の印が付き、いま見ている発言の文字だけはオレンジになります
- 自分に見えない発言は見つかりません。シークレットダイスの結果が見つかるのは、振った人とGMだけです

くわしくは[発言を探す](/manual/chat#発言を探す)にあります。

## 🐛 直った不具合

- チャットで文字を入れた直後に`Enter`を押すと、発言は送られたのに入力欄に文字が残ることがありました。画面の処理が重いときに起きていました
- スマートフォンとタブレットで、パネルを別のウィンドウに出すボタンが出ていました。別のウィンドウはタブが1つ増えるだけで、テーブルと並べて使えないため、今は出しません
- ジュークボックスのパネルで、何も再生していないときに、シークバーの横に「—」だけが出ていました
- 10MBを超える音源や2MBを超える画像を取り込もうとすると、何も知らせずに捨てていました。今は画面の下に、取り込めなかったファイルの名前と上限を出します
- zipファイルに入れたOpus（.opus・.oga）やFLAC、AACの音源が、読み込まれていませんでした

## ⚠️ 以前の版との互換

v1.61.1以前の版を使っている人がいると、次のようになります。

- その人には環境音が聞こえません。その人のジュークボックスでは環境音のタグが「BGS」と出て、▶ を押すとBGMとして流れます
- その人の画面では、部屋の音量のうち全体だけが効き、種類ごとの値は効きません。その人は、これまでどおり「GM」にチェックを入れれば、全体の音量を動かせます
- 奥のレイヤーは、その人の画面ではテーブルの下のレイヤーとして、テーブルの面に描かれます
- ループ位置を指定した曲も、その人の画面では曲全体をくり返します

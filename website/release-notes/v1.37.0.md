# v1.37.0

2026-08-15リリース

**卓上のダイス**を大きく広げた回です。振った結果がチャットに残り、ダイスをコマの持ち物にでき、
使わないあいだはキャラクターシートに預けておけます。振ると卓の上を転がって、出た目が浮かび上がります。

コインの結果が見ていないタブに出ていた問題も直りました。

## ✨ 新しくできること

### 振った結果が、いま読んでいるタブに残る

盤上のダイスは振ると面が変わるだけで、記録がどこにも残っていませんでした。そのため、チャットが
先へ進むと、何が出たのかを後から確かめられませんでした。

これからは、振った結果が**そのとき開いているタブ**に流れます。コインと同じ扱いです。

```
わたし が ダイスA を振りました → 5
```

### 複数のダイスをまとめて振れる

ダイスを複数選んで右クリックすると**ダイス（個数）個をまとめて振る**が出ます。選んだぶんが
同時に回り、ログは1行にまとまります。面がすべて数字なら合計も添えます。

```
わたし が ダイス3個を振りました → 3, 5, 18（合計 26）
```

伏せられているダイス（他の人が「自分だけ見る」にしたもの）は、まとめて振っても回りません。

### ダイスをコマの持ち物にして、チャットのロールと連動させる

ダイスを右クリックして**コマに持たせる**から選ぶと、そのダイスは選んだコマのものになります。
「自分だけ見る」の所有者とは別なので、公開したまま誰かのダイスにできます。

持たせたあと、チャットのコマンドに`dice:コマ名`を書き添えてください。

```
2d6 dice:ゴブリンA
```

ダイスボットが`2d6`を振り、出た3と5が、そのままゴブリンAのダイス2個の面になります。
**卓の上のダイスとチャットのログが一致する**ので、盤にダイスを並べておく意味が出ます。

出目は面の数が合うダイスから順に入り、その目を出せないダイス（10の位しか持たないD10に3が
来た場合など）は動きません。コマが喋っている行なら`dice:`だけでも構いません。

### キャラクターがダイスを持てる

ダイスを**キャラクターシートに預けられる**ようになりました。預けたダイスは個数と面の絵柄がシートに
残り、部屋の保存にもキャラクターの持ち出し（zip）にも一緒に付いていきます。

- **預ける** — 盤上のダイスを右クリックして**コマにしまう**。複数選んだときは、選択メニューから
  預け先のコマを選んでまとめて預けられます
- **出す** — キャラクターを右クリックして**ダイスを展開する（3個）**。預けたぶんがコマの隣に並びます
- **出目も残る** — しまったときに出ていた面を1個ずつ覚えています。場を片付けて次の日に開いても、
  置いていったとおりの目で並びます

1個のダイスは、盤の上かシートの中のどちらかにしかありません。展開したぶんはシートから減るので、
続けて押してもダイスが増えることはありません。

詳細画面の「所持ダイス」には、ダイス1種類が1行の表として出ます。個数・出目・面ごとの絵柄が
並んでいて、その場で書き換えられます。

### 転がる演出

ダイスを振ると、**卓の上を転がって**元の位置に落ち着き、出た面が大きく浮かび上がって消えます。

転がり方は3通りを順に使うので、まとめて振っても同じ動きになりません。出目が浮かぶのは
転がり終わってからです。伏せられているダイスは出目を出しません。

## 🐛 修正

### コインの結果が、見ていないタブに出ていた問題

コインを投げた結果はシステムタブに流れていました。投げた本人はたいてい会話のタブを見ているので、
結果が目に入りません。表か裏かはダイスと同じものなので、**投げた人が読んでいるタブ**に出します。

チャット窓をまだ開いていない部屋では、これまでどおりの行き先です。

### 振った本人の画面だけ、ダイスが回っていなかった問題

ダイスを振ったときのアニメーションは、**振った本人以外の画面でだけ**再生されていました。
自分で振ると、面が音もなく切り替わるだけです。今回の転がる演出を入れるにあたって直しました。

### シート窓が、コマの中心からずれて開いていた問題

コインや地形などのシート窓が、**開く位置だけ古い大きさに合わせたまま**になっていました。窓の大きさを
変えたときに、位置の計算が付いてきていなかったためです。窓の大きさから位置を出すようにしたので、
これからはずれません。

意図してポインタの横に開く窓は、そのままです。

- テストの後片付け漏れで、実行順によって別のテストが落ちることがあった箇所を2つ直しました

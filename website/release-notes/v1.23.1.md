# v1.23.1

2026-08-02リリース

保存データを読み込んだとき、**チャットの立ち絵が表示されない**問題を修正するリリースです。

## 🐛 不具合修正

- **読み込んだルームでチャットの立ち絵が出ない問題を修正** … ルームのzipはチャットのログを先に、画像をあとに収めています。そのため発言だけが先に並び、あとから届いた立ち絵が発言に反映されないことがありました。同じzipをもう一度読み込むと表示されたのは、2回目には画像がすでにブラウザ内にあったためです。画像が届いた時点で発言のサムネイルに反映されるようになりました。

## 🔧 開発者向け

自分でビルドして使っている方向けの変更です。

- **ダイスの回転ハンドルで重複していた枠線の指定を整理** … 同じ枠線の太さが2つ指定され、片方が効かない状態でした。見た目は変わりません。

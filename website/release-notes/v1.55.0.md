# v1.55.0

2026-09-15 リリース

**「重い」「固まる」をまとめて手当てした**版です。ページを開いた直後にダイスボットを丸ごと読み込むのをやめ、
部屋に入る途中で画面が止まったまま戻らなくなる不具合を直しました。Firefox と性能の低い端末では、描画を
自動で軽くします。

スマートフォンでは、マウスを載せないと出なかった操作を**長押しのメニュー**から使えるようになりました。
iPhone で BGM もダイスの音も鳴らなかった不具合も直しています。

機能では、**チャットパレットの検索**と、**マップマスクの設定パネル**が加わりました。

## ⚡ 開いてから遊べるまでが軽くなった

これまでは、ページを開いて数秒たつと、まだ部屋に入っていないうちから、ダイスボットの全 336 システム
（約 11MB）を読み込んで実行していました。回線が遅いと、初回の読み込み時間の大半がこれでした。速い端末
でも、実行のあいだ約 0.5 秒は画面の処理が止まります。

いまは、**部屋でダイスを振るときに、そのシステムの分だけ**を読み込みます。先に読んでおくのは共通部分の
約 600KB で、システムの大きさは半分が 21KB 以下です。そのかわり、あるシステムで最初に振るときだけ、
読み込みの分わずかに待つことがあります。待っているあいだも、挨拶のようにダイスになりえない発言はすぐに
送られます。

最初の画面で使わないものも、あとに回しました。

- 見本の卓の背景とコマ、チャットに出るシステムのアイコンを、軽い画像形式（WebP）に替えました。見た目は
  同じで、読み込む量は卓の画像が約 740KB から 260KB に、アイコンが約 790KB から 120KB になります。
  前に保存した部屋も、同じ画像をそのまま見つけます
- アイコンのフォントを 2 回読み込んでいたのを、1 回にしました
- チャットウィンドウ、スマートフォン用の画面、コマにマウスを載せたときの詳細は、初めて使うときに
  読み込みます

## 🧊 部屋に入る途中で固まらなくなった

**部屋に入った直後、まだ受け取っていないものを持っている人が抜けると、そのタブが止まったまま
戻りませんでした**。それを持っていたのが抜けた人ひとりだけのときに起きていました。いまは、ほかに
つながっている人が持っていればその人に頼み直し、誰も持っていなければ待つのをやめて先へ進みます。

後から入った人の部屋が揃うまでのやりとりも減らしました。

- 誰かがつながるたびに、全員が全員へ画像の一覧を配り直していました。いまは入ってきた人にだけ送ります。
  画像を 1 枚送り終えるたびの配り直しも、1 秒後にまとめて 1 回にしました
- 音声の多い部屋では、流れている BGM が最後に届くことがありました。いまは再生中の曲を先に受け取ります
- 画像と音声は、これまでの倍の大きさに区切って送ります。受け取りを確かめる往復が半分になります
- 届いたメッセージを 1 件ずつ別々に処理していたのを、まとめて処理するようにしました

やりとりの形式は変えていないので、前の版を使っている人とも同じ部屋で遊べます。

同期まわりでは、次の不具合も直しました。

- ドラッグの最後の位置が、自分の画面にだけ残ることがあった
- 足場に載せたコマが、ほかの人の画面では元の場所に残っていた。壁から降ろして足場に載せたコマも、壁に
  掛かったままとして送られていた
- 読めないメッセージが 1 件届くと、それ以降に届いたものがセッションの終わりまで全部捨てられていた

## 🪶 描画を軽くする設定

メニューの **エフェクト** ボタンの隣に、描画の設定が加わりました。押すたびに **描画: 自動** →
**描画: 軽くする** → **描画: 通常** と切り替わります。スマートフォン用の画面では、メニューの一番下に
並んでいます。

設定を **軽くする** にすると、次のように変わります。

- パネルの背景のすりガラス（うしろが透けてぼける表現）が無くなり、不透明になります
- 天候と地面の演出が、2 フレームに 1 回の動きになります
- 暗闇（視界）を低い解像度で描きます。大きな卓では、見えている範囲の縁、特にヘクスの縁が少し
  やわらかくなります
- 天候のかかる範囲は、カメラを動かしたあと最大 0.4 秒遅れてついてきます

設定が **自動** なら、Firefox と、CPU が 2 コア以下かメモリが 2GB 以下と報告する端末で **軽くする** になり、
それ以外は **通常** です。iPhone と iPad は機種を問わず 2 コアと報告するので、この判定には使わず、自動
では **通常** のままにしています。

選んだ設定はこのブラウザが覚えておきます。部屋のデータには関係せず、ほかの人の画面も変わりません。
自動で軽くなった見た目を戻したいときは、**通常** を選んでください。

## 🖥️ 通常の描画も、見た目はそのままで軽くした

設定が **通常** のままでも、次の場面で余計な描き直しと計算を減らしました。見た目は変わりません。

- **暗闇と光源**: コマの名前やメモを変えただけでは、視界を作り直しません。作り直すときも、計算し直すのは
  動いたコマの目の分だけです。揺らぐ光源は、光の届く周りだけを描き直します。これまでは、部屋の両端に
  松明が 2 本あるだけで、盤面全体を 1 秒に 20 回描き直していました
- **コマのバー**: コマをドラッグしているあいだや、別のコマのデータを変えたときに、全部のコマのバーと
  バフのアイコンを計算し直すのをやめました
- **効果音**: 鳴らすたびに音声を展開し直していたのを、一度で済ませます
- **チャット**: 新しい発言が来るたびに、画面にあるダイスの行がそれぞれログ全体を読み直していました。
  長いセッションほど重くなっていたものです。iPhone と iPad では、一番下で読んでいるあいだ、ずっと上の
  行を画面から外します
- **演出**: 何も再生していないあいだは、演出の重ね絵に手を付けません。画面の縁を流れるティッカーの
  文字は、行ごとに一度だけ測ります

## 📱 スマートフォンで、長押しから操作する

タッチの画面には「マウスを載せる」も「ダブルクリック」もないので、スマートフォンからはできない操作が
ありました。次の操作を、右クリックか長押しで開くメニューやボタンからも使えるようにしています。
パソコンでのこれまでの操作は、そのまま使えます。

| 場所                         | できるようになったこと                                                                                                                                                               |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| チャットの発言               | メニューが開き、返信・引用・別のタブにコピー・共有メモにする・編集・ティッカーを選べます。**元のメッセージへ移動** と **本文をコピー** も加わりました                                |
| ノベルモードのログ           | 自分が直せる行から、編集を始められます                                                                                                                                               |
| インベントリ                 | 行のメニューに **卓で表示** が加わりました。卓の上にあるコマへ視点を移します                                                                                                         |
| マップエディター             | 選んでいるレイヤーの名前の横に鉛筆が出ます。押すと名前を変えられます                                                                                                                 |
| カットインの編集             | キーや SE を押して離すと、再生ヘッドがそこへ移ります。ツールバーの **再生ヘッドの位置のキーを外す** と **再生ヘッドの位置の SE を外す** で外せます。ロックしたレイヤーでは押せません |
| 並べ替えがドラッグだけの一覧 | ジュークボックスの再生リスト、カットインのレイヤー、キャラクターシートのカード、データ要素で、**いちばん上へ**・**ひとつ上へ**・**ひとつ下へ**・**いちばん下へ** を選べます          |

スマートフォンでは、チャットの発言の文字を長押しで選べなくなったかわりに、メニューの **文字を選ぶ** で
選べます。一部だけをコピーしたり、スマートフォンの調べる・翻訳・共有を使ったりするときはこちらから
どうぞ。パソコンで発言の一部を選んで右クリックしたときと、添付画像を右クリックしたときは、これまで
どおりブラウザのメニューが出ます。

そのほか、タッチの画面で次のところを直しました。

- マウスを載せたときにだけ出ていたボタンが、タッチの画面では見えませんでした。リプレイの行のあいだに
  ある書き込み・記録のボタンと、カードとメモの回転ハンドルのアイコンです
- ホットバーのページ・保存・ロック、チャットのタブを送る矢印、チャット入力欄の横の 2 つのボタンは、
  見た目より広い範囲で押せるようにしました。隣のボタンを押してしまわない幅にしています
- コマやノベルモードの話者の画像を長押しすると、iPhone の画像を保存するメニューが出ていました。いまは出ず、
  iPad で画像をつまみ出してしまうこともありません
- iPhone で **パソコン版の画面を使う** にしていると、文字の入力欄を触るたびに画面が拡大されていました。
  指で広げて拡大するのは、これまでどおりできます

## 🔎 チャットパレットを検索する

チャットパレットの下に検索欄が付きました。言葉を入れると、その言葉を全部含む行が、欄のすぐ上に並び
ます。全角と半角、大文字と小文字は区別しません。スペースで区切れば、複数の言葉で絞り込めます。

並ぶ順は、言葉で始まる行、言葉が前のほうにある行、パレットに書いた順です。行には、その行が入っている
見出しが添えられ、一致した言葉に印が付きます。

結果を押すと、その行が入力欄に入り、パレットの中の同じ行も選ばれます。2 回押すと送信するのは、パレット
の行と同じです。キーボードでは、上下の矢印キーで結果を選び、Enter で送らずに入力欄へ入れ、Esc で検索を
消します。

見出しと設定の行、空行は検索しません。パレットを編集しているあいだと、キャラ情報を表示しているあいだは、
検索欄が出ません。

## 🗺️ マップマスクの設定パネル

マスクを右クリックして **マスクを編集** を選ぶと、専用の設定パネルが開くようになりました。これまでは、
データ項目がそのまま並ぶ汎用のシートでした。

パネルでは、名前・幅・高さ・不透明度と、マスクの画像と色を決められます。ここには **コピーを作る** と
**保存** もあります。ほかの人が同じマスクを変えれば、開いているパネルにもすぐ出ます。これまでのシートで
細かい項目を触りたいときは、パネルの **詳細データ** から開けます。

## ✂️ 削ったマスに画像や色を出す

設定パネルの **削ったあと** で画像か色を決めると、削って開けたマスに、盤面の代わりにそれが出ます。削って
いる途中の見え方にも出ます。正方形の卓でもヘクスの卓でも同じです。

設定した画像は部屋の保存に入ります。何も決めていないマスクは、これまでどおり削ると盤面が見えます。

古い部屋のデータに残っていた **スクラッチマスク** は、もう作ることも削ることもできず、色の設定も効いて
いませんでした。この版からは、部屋を読み込んだときや、前の版の人が持ち込んだときに、普通のマップマスクへ
置き換えます。置き換えは、卓を変更できる参加者の画面で行います。

名前・大きさ・位置・高さ・ロック・所有者はそのまま引き継ぎます。色は「更新部カラー」を使い、無ければ
「カラー」を使って、前と同じ 60% の不透明度で描きます。古いマスクで開いていたマスは、削ったマスとして
残ります。

## 🔄 前の版のタブを開いたままだったとき

新しい版が出たあとも前の版のタブを開いたままにしていると、チャットウィンドウなど、初めて開く画面を読み
込めないことがあります。そのときは **Udonarium Axe が更新されました** と出て、ページの再読み込みを
勧めます。その場で読み込み直さないときは **あとで** を選んでください。案内はページごとに 1 回です。

ダイスボットのシステムを読み込めなかったときは、発言は送られますが、ダイスは振られません。送った本人
にだけ、そのタブに「この発言のダイスは振られていません」と出ます。回線が悪く、10 秒たっても読み込め
ないときも同じです。もう一度送っても振れなければ、ページを再読み込みしてください。

部屋で決めたのと違うルールで振ってしまわないように、ほかのダイスボットで代わりに振ることはしません。
`:HP-5` のようなリソースの増減とバフは、読み込めなくても反映されます。`S` で始まるシークレットダイスの
発言も、伏せたままです。

## 🐛 直った不具合

**iPhone で、BGM もダイスの音もカットインの音も鳴りませんでした**。画面に指が触れた瞬間には音を出せない
iPhone の仕組みに合っていなかったためです。電話がかかってきたり、ページを隠したりして止まった音も、
戻りませんでした。いまは指を離したときに音を出せるようにし、止まった音も次の操作で戻ります。部屋の BGM
を鳴らせなかったときは、次にタップしたときに鳴り始めます。

**iPhone と iPad の Safari で、保存したファイルが届かないことがありました**。部屋の保存、チャットログ、
リプレイ、スキン、マップ、ホワイトボードの画像です。

**カットインを「自分だけ再生」したあと、BGM の停止と、音だけのカットインがほかの人に届いていません
でした**。誰かが全員向けのカットインを始めるか止めるまで、この状態が続いていました。

**チャットログを書き出すと、複数行の発言が 1 行につながっていました**。「標準」と「CoCログ形式」で
起きていました。

そのほか、次のものを直しました。

- プレイヤーがインベントリの行をフォルダへドラッグすると、パネルごと動いていた
- 壁に掛けたコマや足場に載せたコマを、インベントリやホットバー、パーティの一覧などから表示すると、
  コマの見えない場所へ視点が移っていた

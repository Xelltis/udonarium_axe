# v1.65.0

2026-10-11リリース

卓に組んだダンジョンを、コマの目線で1マスずつ歩ける**ダンジョンドリィマスターモード**を足しました。地形の壁と扉がそのまま通路になり、歩いた分は卓の上のコマも動きます。GMは部屋の全員を同じコマの目線にそろえられます。

画像は、取り込む前に切り抜き・背景の透過・回転・縮小ができるようになりました。2MBを超える画像も、編集画面で小さくして取り込めます。取り込み済みの画像を編集して、使っている場所ごと差し替えることもできます。

射程範囲にはダイヤの形が戻り、Altキーを押しながら回すと角度が45°ずつそろうようになりました。

## 🧭 コマの目線でダンジョンを歩く

<Shot src="dungeondry-master" width="520" alt="石の通路の先にゴブリンが立っている一人称の画面" caption="生成したダンジョンを、コマの目線で歩きます" />

FABメニューの「テーブル関連」にある「ダンジョンドリィマスターモード」で、コマの目線の画面に切り替わります。PLツールバーの目のアイコン、コマの右クリックの「このコマの視点で見る」、ホットバーの枠からも入れます。

WASDか↑↓キーで歩き、QとEか←→キーで向きを変えます。Spaceキーで扉を開け閉めし、Fキーでコマの明かりを点けます。使えるキーは、画面の下に並んで出ます。四角のマスでもヘクスでも、グリッドなしの卓でも歩けます。歩いた分は卓の上のコマも動き、スイッチの仕掛けもそのまま起きます。

描くのは目の前12マスまでで、遠くはぼかして暗くします。暗闇と戦場の霧は卓と同じように効き、ほかのコマは見えているものだけが立ち絵のように立ちます。右下には方位磁針とミニマップが出ます。景色の中のコマはクリックやTキーで狙え、エフェクトもこの画面から撃てます。

GMはGMツールバーの**全員の視点を決める**で、部屋の全員を同じコマの目線にそろえられます。

くわしくは[ダンジョンドリィマスターモード](/manual/dungeondry-master)にあります。

## ✂️ 画像を取り込む前に編集する

「画像の編集」のパネルで、切り抜き、背景の透過、回転と反転、書き出す大きさの変更ができるようになりました。切り抜きは、自由な形のほかに1:1や16:9などの比率でも囲めます。

2MBを超える画像は、断らずにこのパネルで開きます。小さくすれば、そのまま取り込めます。画像パネルとファイル一覧の「編集してから追加」を入れておくと、選んだ画像を1枚ずつこのパネルで開いてから取り込みます。貼り付けた画像も、このパネルで開きます。

くわしくは[画像を編集する](/manual/images#画像を編集する)にあります。

## 🔁 取り込み済みの画像を差し替える

画像パネルで画像を1枚チェックして「編集」を押すと、取り込み済みの画像を編集できます。「置き換える」を押すと、その画像を使っているコマ・シート・背景がすべて新しい画像になり、タグと秘匿も引き継ぎます。元の画像を残したいときは「コピーとして追加」を押します。

くわしくは[取り込み済みの画像を編集する](/manual/images#取り込み済みの画像を編集する)にあります。

## 💠 射程範囲のダイヤ

射程範囲にダイヤの形が戻りました。中心から上下左右に「長さ」のマス数だけ届き、斜めには広がりません。右クリックの「射程範囲を作成」と「形状変更」では、四角形と一緒に「四角形・ダイヤ」にまとめてあり、「ダイヤとして出力」と「四角形として出力」から選びます。

くわしくは[四角形とダイヤ](/manual/range#四角形とダイヤ)にあります。

## 🔄 Altキーを押しながら回すと角度がそろう

回転ハンドルを回すとき、Altキーを押しているあいだは角度が45°ずつそろうようになりました。ヘクスの卓では30°ずつです。コマ・地形・カード・射程範囲など、回せる物すべてに効きます。90°ずつにしか置けない任意マスの射程範囲は、90°ずつそろいます。回しているあいだは、画面の下に今の角度が出ます。

くわしくは[オブジェクトの基本操作](/manual/objects#move)にあります。

## 🛡️ 見学のロールではファイルを読み込まない

見学のロールでページにファイルを落とすと、画像や部屋のデータを読み込めていました。見学は卓を見るためのロールなので、落としても何も読み込まないようにしました。画像パネルでも、見学のときは取り込みとタグの変更の操作を出さないようにしました。

くわしくは[見学（読み取り専用）](/manual/roles#見学-読み取り専用)にあります。

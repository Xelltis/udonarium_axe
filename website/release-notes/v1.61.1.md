# v1.61.1

2026-10-06リリース

不具合修正のみのリリースです。v1.60.0で入ったリソースのスライダーが、スマートフォンで出すコマの詳細では動かせませんでした。

## 🐛 スマートフォンでもコマの詳細からスライダーを動かせます

スマートフォンでは、コマをタップすると詳細が出ます。リソースに**スライダー表示**を入れていれば、この詳細にもスライダーが並びます。ところが指で触れても動かず、下のテーブルを押したことになって、詳細ごと閉じていました。

タップで出す詳細は、テーブルの操作を邪魔しないよう、どこに触れても操作が下のテーブルに届く作りです。スライダーだけをこの例外にして、指で動かせるようにしました。動かして離したところが現在値になるのは、パソコンでマウスを乗せて出す詳細と同じです。

詳細のほかの欄はこれまでどおりで、触れても操作できません。数値を打ち込みたいときは、キャラクターシートを開いてください。

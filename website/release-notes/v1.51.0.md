# v1.51.0

2026-09-09リリース

画面を自分の好きな色にする版です。ライトとダークの切り替えしかなかったところに、**スキン**という配色の選択が入りました。40種類から選べて、つまみを動かせば自分の色も作れます。パネルの背景に絵を敷くこともできます。

もうひとつ、パネルを別のウィンドウに出せるようになりました。チャットやチャットパレットをサブモニタへ移して、元の画面にはテーブルだけを映しておく、という置き方ができます。

## 🎨 配色を40種類から選ぶ

FABメニューの**スキン**（パレットのアイコン）から専用パネルが開きます。

<Shot src="skin" alt="スキンパネル。上に見本、下にライトテーマとダークテーマの選択と、系統ごとに並んだ色の候補" width="620" caption="上の見本がその場で塗り替わります" />

ライトテーマとダークテーマで別々に選びます。明るいときは羊皮紙、暗いときは深海、と決めておけば、テーマを**自動**のままOSに従わせても、切り替わった先の色はそれぞれ自分の選んだものになります。

いまの配色（**標準**）を入れて、どちらにも20種ずつあります。標準以外は4つの系統に分かれています。

| 系統         | ライトテーマ                                 | ダークテーマ                                       |
| ------------ | -------------------------------------------- | -------------------------------------------------- |
| 色みで選ぶ   | 羊皮紙・桜色・琥珀・若竹・水浅葱・藤色・銀鼠 | 墨・夜の羊皮紙・焦土・葡萄・深紫・紺青・深海・常盤 |
| 見やすさ重視 | くっきり・モノクローム・外光                 | くっきり・モノクローム                             |
| 卓の雰囲気   | 雪原・森林・草原・海岸・荒野                 | 地下墓所・溶岩洞・氷窟・砂の墳墓・洞窟             |
| 懐かしい配色 | 元祖・学園×青春・我らの青春・生まれたばかり  | 四階調の緑・よん？・八ビットの黒・迷宮の琥珀       |

**元祖**は本家Udonariumの配色から起こしたものです。灰色のタイトルバーとクリームのパネルに見覚えのある方もいると思います。

一覧の上に見本があり、候補にカーソルを乗せると見本がその場で塗り替わります。20種類を試すのに20回選び直す必要はありません。気に入らなければ**開いたときに戻す**で元通りです。

選んだ色が使われるのはこの画面だけです。同じ部屋の他の人には伝わりませんし、保存データにも入りません。卓を囲む面々が別々の場所・別々の明るさの中にいる以上、誰かが他人の画面を塗り替えられるべきではないためです。

## 🖌️ 自分の配色を作る

同じパネルの下にあるつまみで、面の色相・濃さ・明るさ、アクセントの色を決められます。

つまみの可動域は、文字が読める範囲に収めてあります。どこへ動かしても、本文・リンク・警告の文字はコントラスト比4.5:1（WCAG AA）を下回りません。組み込みの40種類も同じ基準です。「色を変えたら文字が見えなくなった」ということは起きません。

### パネルに絵を敷く

背景画像を6枚まで重ねられます。1枚ごとに透け具合・敷き方（覆う／収める／並べる／原寸）・寄せる位置を決められて、重ね順も入れ替えられます。羊皮紙のテクスチャを敷いて、その上に薄く紋章を置く、といった作り方ができます。

推奨サイズはパネルに書いてあります。大きすぎる画像は自動で縮めるので、そのまま放り込んで構いません。

### 配色を配る

作った配色はzipで書き出せます。つまみの値も、敷いた絵も、まとめて1つのファイルになります。読み込めば同じ配色が再現されるので、卓のメンバーに配ったり、別のブラウザへ持っていったりできます。

## 🪟 パネルを別のウィンドウに出す

パネルのタイトルバーに **↗ のボタン**が増えました。押すと、そのパネルがブラウザの別ウィンドウに移ります。

<Shot src="chat-palette" alt="チャットパレット。タイトルバーの右端に別ウィンドウへ出すボタンが並んでいる" width="560" caption="タイトルバーの ↗ で外に出ます" />

出せるのは部屋のパネル（チャット・インベントリ・ジュークボックスなど）と、コマのパネル（キャラクターシート・チャットパレット・リモコン）です。ウィンドウを閉じれば、パネルは元の画面に戻ります。別ウィンドウ側に閉じるボタンはありません。ウィンドウの枠にある閉じるボタンを使うからです。

外に出したパネルの中で右クリックしても、メニューはそのウィンドウの中に出ます。元の画面に出てしまって「押したのに何も起きない」ということはありません。

チャットパレットの**見出し**だけは、別ウィンドウのときにドロップダウンに変わります。見出しの一覧はポインタの位置に開くメニューだったので、そのままでは外のウィンドウで見えないところに開いていました。

::: tip
ブラウザのポップアップブロックに止められると、別ウィンドウは開きません。その場合は許可してからもう一度押してください。
:::

## 🐛 直したもの

**ホットバーのダイスが、コマに近いほうのダイスボットで振られるようになりました。** [枠そのもの → そのコマのチャットパレット → 部屋の既定 → チャットウィンドウ](/manual/hotbar)の順です。

これまではパレットだけを見ていて、しかもパレットは作られた時点で`DiceBot`を持っているため、部屋やチャットで選び直しても反映されませんでした。`DiceBot`は「選んでいない」として扱うことにしたので、クトゥルフ神話TRPGのパレットを持つコマはその系統で振り、パレットが既定のままのコマは部屋やチャットの選択に従います。

**2Dで見ているだけの画面に、卓上モード用のメニューが出なくなりました**。真上から見ているというだけで、右クリックが四方向メニューに変わっていました。2D表示と卓上モードは別のもので、四方の席に向けたメニューは後者のためのものです。

**卓上モードのチェックも、2Dで見ているだけでは入らなくなりました**。視点ではなく、四方の席へ向ける設定が実際に入っているかで判断します。まとめて入れたあとに一部を切ると、チェックは外れます。

[部屋設定](/manual/room-settings#ui)の**UI**も、この違いに沿って**共通 / スキン / 卓上**の3つに分け直しました。これまでは一続きの長い一覧に、部屋の設定と画面の配色と四方の席へ向けた設定が混ざっていました。

**卓上モードは「卓上ディスプレイ用の推奨設定をオン」になりました**。入れると視点が2Dになり、四方の席へ向ける設定がまとめて入ります。切ると項目は既定に戻ります。部屋設定の卓上タブからも同じように入れられます。

**「コマ画像をマス内に収める」は、部屋の設定になりました**。画面ごとに違っていたものを部屋で揃えます。真上から見ているあいだだけ働きます。

**部屋全体に効く設定はGMだけが変えられるようになりました**。既定のダイスボット、コマの向き、コマ画像の扱いです。これまでPLの画面からも変えられていました。GM以外の画面では操作できない見た目になります。

あわせて、コンテキストメニューの設定が**通常 / 四方向 / 回転**の三択になりました（[視点とテーブル操作](/manual/tabletop#tabletop-display)）。既定は**通常**です。卓上モードを入れると**回転**になります。以前に回転メニューを入れていた部屋はそのまま**回転**として読み込まれます。

## ⚙️ 中で何が変わったか

スキンの実体は**レシピ**です。色相・彩度・アクセントなど数個の値から、42個のCSS変数をCIELCh色空間で組み立てます。画面に出せない色になったときは、彩度を二分探索で落として収めます。40種類はどれもレシピしか持っていないので、明度の階段の作り方を直せば全部が同時に直ります。

コントラストはテストで固定しています。40種類 × 7通りの前景背景の組を毎回測り、4.5:1を割ったらビルドが落ちます。自作スキンのつまみの可動域も、格子状に総当たりして同じ基準を満たすことを確かめてあります。

背景画像はCSSの`background-image`ではなくDOMの層です。重ねた画像に1枚ずつ違う透過率を与える書き方がCSSにないためです。画像そのものはIndexedDBに置き、先頭バイトを見て本当に画像か確かめ、縮めてから保存します。どのスキンからも参照されなくなった画像は次回起動時に掃除します。

別ウィンドウのパネルは、元の画面で閉じて別ウィンドウの層に開き直しています。ノードは動かしません。書きかけの一行やスクロール位置は失われますが、パネルは同じコンポーネントのまま、同じ部屋の情報を受け取り続けます。ノードを移す方式では、この点が成り立ちません。

テーマとスキンの塗りは、開いている全ウィンドウに対して行います。メニュー・ダイアログ・ツールチップは、フォーカスのあるウィンドウの層に描きます。別ウィンドウに出したパネルが1つもないあいだはレジストリが空なので、これまでと同じ経路を通ります。

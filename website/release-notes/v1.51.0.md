# v1.51.0

2026-09-09 リリース

**画面を自分の好きな色にする** 版です。ライトとダークの切り替えしかなかったところに、**スキン**
という配色の選択が入りました。40 種類から選べて、つまみを動かせば自分の色も作れます。パネルの
背景に絵を敷くこともできます。

もうひとつ、**パネルを別のウィンドウに出せる**ようになりました。チャットやチャットパレットを
サブモニタへ追い出して、卓は卓だけを映しておく、という置き方ができます。

## 🎨 配色を 40 種類から選ぶ

FAB メニューの **スキン**（パレットのアイコン）から専用パネルが開きます。

<Shot src="skin" alt="スキンパネル。上に見本、下にライトテーマとダークテーマの選択と、系統ごとに並んだ色の候補" width="620" caption="上の見本がその場で塗り替わります" />

ライトテーマとダークテーマで **別々に** 選びます。明るいときは羊皮紙、暗いときは深海、と決めて
おけば、テーマを **自動** のまま OS に従わせても、行き先の色はそれぞれ自分の選んだものになります。

いまの配色（**標準**）を入れて、どちらにも 20 種ずつあります。標準以外は 4 つの系統に分かれています。

| 系統         | ライトテーマ                                 | ダークテーマ                                       |
| ------------ | -------------------------------------------- | -------------------------------------------------- |
| 色みで選ぶ   | 羊皮紙・桜色・琥珀・若竹・水浅葱・藤色・銀鼠 | 墨・夜の羊皮紙・焦土・葡萄・深紫・紺青・深海・常盤 |
| 見やすさ重視 | くっきり・モノクローム・外光                 | くっきり・モノクローム                             |
| 卓の雰囲気   | 雪原・森林・草原・海岸・荒野                 | 地下墓所・溶岩洞・氷窟・砂の墳墓・洞窟             |
| 懐かしい配色 | 元祖・学園×青春・我らの青春・生まれたばかり  | 四階調の緑・よん？・八ビットの黒・迷宮の琥珀       |

**元祖** は本家 Udonarium の配色から起こしたものです。灰色のタイトルバーとクリームのパネルに
見覚えのある方もいると思います。

一覧の上に見本があり、**候補にカーソルを乗せるとその場で塗り替わります。** 20 種類を試すのに
20 回選び直す必要はありません。気に入らなければ **開いたときに戻す** で元通りです。

選んだ色が効くのは **この画面だけ** です。同じ部屋の他の人には伝わりませんし、保存データにも
入りません。卓を囲む面々が別々の部屋・別々の明るさの中にいる以上、誰かが他人の画面を塗り替え
られるべきではないためです。

## 🖌️ 自分の配色を作る

同じパネルの下にあるつまみで、面の色相・濃さ・明るさ、アクセントの色を決められます。

つまみの可動域は、**文字が読める範囲に収めてあります。** どこへ動かしても、本文・リンク・警告の
文字はコントラスト比 4.5:1（WCAG AA）を下回りません。組み込みの 40 種類も同じ基準です。
「色を変えたら文字が見えなくなった」は起きません。

### パネルに絵を敷く

背景画像を **6 枚まで** 重ねられます。1 枚ごとに透け具合・敷き方（覆う／収める／並べる／原寸）・
寄せる位置を決められて、重ね順も入れ替えられます。羊皮紙のテクスチャを敷いて、その上に薄く紋章を
置く、といった作り方ができます。

推奨サイズはパネルに書いてあります。大きすぎる画像は自動で縮めるので、そのまま放り込んで構いません。

### 配色を配る

作った配色は **zip で書き出せます**。つまみの値も、敷いた絵も、まとめて 1 つのファイルになります。
読み込めば同じ配色が再現されるので、卓のメンバーに配ったり、別のブラウザへ持っていったりできます。

## 🪟 パネルを別のウィンドウに出す

パネルのタイトルバーに **↗ のボタン**が増えました。押すと、そのパネルがブラウザの別ウィンドウに
移ります。

<Shot src="chat-palette" alt="チャットパレット。タイトルバーの右端に別ウィンドウへ出すボタンが並んでいる" width="560" caption="タイトルバーの ↗ で外に出ます" />

出せるのは部屋のパネル（チャット・インベントリ・ジュークボックスなど）と、コマのパネル
（キャラクターシート・チャットパレット・リモコン）です。**ウィンドウを閉じれば元の画面に戻ります。**
別ウィンドウ側に閉じるボタンはありません。ウィンドウの枠が閉じるボタンだからです。

外に出したパネルの中で右クリックしても、**メニューはそのウィンドウの中に出ます。** 元の画面に
出てしまって「押したのに何も起きない」ということはありません。

チャットパレットの **見出し** だけは、別ウィンドウのときにドロップダウンに変わります。見出しの
一覧はポインタの位置に開くメニューだったので、そのままでは外のウィンドウで見えないところに
開いていました。

::: tip
ブラウザのポップアップブロックに引っかかると開きません。その場合は許可してからもう一度押して
ください。
:::

## 🐛 直したもの

**ホットバーのダイスが、チャットウィンドウで選んだシステムで振られるようになりました。** これまでは
コマのチャットパレットに設定されたダイスボットが優先されていて、パレットは作られた時点で `DiceBot`
を持っているため、チャット側で選び直しても反映されませんでした。枠自身がシステムを持っている場合は
そちらが優先されます。

**2D で見ているだけの画面に、卓上モード用のメニューが出なくなりました。** 真上から見ているというだけで、
右クリックが四方向メニューに変わっていました。2D 表示と卓上モードは別のもので、四方の席に向けた
メニューは後者のためのものです。

**卓上モードのチェックも、2D で見ているだけでは入らなくなりました。** 視点ではなく、四方の席へ向ける設定が実際に入っているかで判断します。まとめて入れたあとに一部を切ると、チェックは外れます。

あわせて、コンテキストメニューの設定が **通常 / 四方向 / 回転** の三択になりました（[視点とテーブル操作](/manual/tabletop#tabletop-display)）。
既定は **通常** です。卓上モードを入れると **回転** になります。以前に回転メニューを入れていた部屋は
そのまま **回転** として読み込まれます。

## ⚙️ 中で何が変わったか

スキンの実体は **レシピ** です。色相・彩度・アクセントなど数個の値から、42 個の CSS 変数を
CIELCh 色空間で組み立てます。画面に出せない色になったときは、彩度を二分探索で落として収めます。
40 種類はどれもレシピしか持っていないので、明度の階段の作り方を直せば全部が同時に直ります。

コントラストはテストで固定しています。40 種類 × 7 通りの前景背景の組を毎回測り、4.5:1 を割ったら
ビルドが落ちます。自作スキンのつまみの可動域も、格子状に総当たりして同じ基準を満たすことを
確かめてあります。

**背景画像は CSS の `background-image` ではなく DOM の層です。** 重ねた画像に 1 枚ずつ違う透過率を
与える書き方が CSS にないためです。画像そのものは IndexedDB に置き、先頭バイトを見て本当に画像か
確かめ、縮めてから保存します。どのスキンからも参照されなくなった画像は次回起動時に掃除します。

別ウィンドウのパネルは、こちらで閉じて向こうの層に **開き直して** います。ノードは動かしません。
書きかけの一行やスクロール位置は失われますが、パネルは同じコンポーネントのまま、同じ部屋の情報を
受け取り続けます。ノードを引っ越す方式では、ここが成り立ちません。

テーマとスキンの塗りは、開いている全ウィンドウに対して行います。メニュー・ダイアログ・ツール
チップは、フォーカスのあるウィンドウの層に描きます。切り出しが 1 つもない間はレジストリが空なので、
これまでと同じ経路を通ります。

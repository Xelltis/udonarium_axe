# v1.46.0

2026-08-31リリース

**ホットバー**が入りました。攻撃のマクロ、開幕の効果音、射程の設置のように、卓の最中に何度も繰り返す操作を
枠に入れておき、数字キーひとつで撃てます。

あわせて、チャットまわりの3つの機能（発言の効果音・別タブへのコピー・表示設定の全体／タブ毎）、
コマの向き表示、ホワイトボードで動く画像も入りました。ノベルモードの立ち絵切り替えの不具合も直っています。

## 🎛️ ホットバー

PLツールバー（GMのときはGMツールバー）の**格子のアイコン**で出します。**10枠 × 5ページ**あり、
10枠は数字キーの`1`〜`0`とそのまま対応します。ページは`Shift`＋数字か`[` `]`で変えられます。
見学のロールでは出ません。

空き枠を押すと登録画面が開きます。枠に入れられるのは次のものです。

| 種別                     | 例                                         |
| ------------------------ | ------------------------------------------ |
| チャット／ダイス         | `2d6+3 攻撃`、`:HP-5`、`&!毒/継続/3`       |
| エフェクト               | 卓のエフェクトを発動・設置・プレビュー     |
| 範囲を置く／消す         | 名前・大きさ・色まで枠が覚えます           |
| 所持ダイスを出す／しまう | キャラクターのダイス                       |
| パネルを開く             | チャットパレット／シート／リモコン         |
| コマへ視点を移す         | 迷子になったコマへ一発で                   |
| 効果音・カットイン       | 卓の音と演出                               |
| チャット欄に下書き       | 送信せず入力欄へ入れます                   |
| 行動順                   | 進める／戻す／リセット                     |
| マルチアクション         | 上記の枠をいくつか、順番と間隔を決めて連続 |

**枠は「誰として」撃つかを覚えます。** モンスターの攻撃マクロを入れた枠は、操作対象を切り替えても
そのモンスターとして飛びます。別の部屋へ持っていったときは、同じ名前のコマが1体だけいれば
そちらを見つけて撃ちます。

**マルチアクション**は、効果音 → エフェクト → 攻撃ロールのような開幕を1押しにまとめる枠です。
選んだ枠は一覧に並び、**↑ ↓ で順番**、**msで1つ前からの間隔**をそれぞれ決められます。

**バーはzipファイルで持ち歩けます。** システムやキャラクターが変われば中身も変わるので、
卓ごとに書き出しておいて、その日使うものを読み込む使い方ができます。読み込みを間違えても
「元に戻す」で戻せます。

エフェクト集の右クリックや、チャットパレットの行の右クリックからも枠に登録できます。

::: tip スペシャルサンクス
ホットバーは、[ユドナリウムリコリス](https://github.com/oron1208/udonarium-lycoris)（oron1208氏）の
同名の機能に着想を得ています。コードは受け継いでおらず、Axe独自の実装です。
素晴らしい機能を先に形にしてくださったことに感謝します。
:::

## 💬 チャット

### 発言があったら音で知らせます

チャット設定の**発言の効果音**で、誰かが発言したときに音を鳴らせます。卓を眺めていて発言を
取りこぼすことが減ります。

音は5種類（ページめくり・バブル・サイバー・通知1・通知2）から選び、**音量**と**試聴**が付いています。
**全体で1つ決めるか、タブごとに決めるか**を選べるので、雑談タブは静かに、メインタブだけ鳴らす、
といった分け方もできます。

::: warning
**既定はオフ**です。鳴らしたい人が自分で入れてください。鳴るのは自分以外の発言だけで、
ダイスの結果や入退室のお知らせでは鳴りません。この設定は自分の端末だけのもので、
同じ卓の中で鳴らす人と鳴らさない人が同席できます。
:::

音は[OtoLogic](https://otologic.jp)（CC BY 4.0）の素材です。

### 発言を別のタブにコピーできます

発言のボタンから**別のタブにコピー**を選ぶとタブの一覧が出て、選んだタブに同じ発言が作られます。
名前・立ち絵・色・添付画像がそのまま引き継がれるので、**そのタブで発言したのと同じ見た目**になります。
タブを間違えて発言したときや、雑談タブのやりとりを本編に残したいときに使えます。

一覧に出るのは自分が発言できるタブだけです。秘話とシークレットの発言にはボタンが出ません。

### 立ち絵・簡易表示の設定が選べるようになりました

「（このタブ）」と書かれたチェックボックスが2つ並んでいたところを、**適用範囲（全体／タブ毎）** を
選ぶ形に変えました。全体を選べば1つのチェックで全タブに効き、タブ毎を選べばタブの一覧が出ます。
設定はタブの名前で覚えるので、部屋をファイルから読み直しても前と同じ状態で開きます。

### そのほか

- 縦長の立ち絵を使っていると、**書き出したログで頭が切れていた**のを直しました
- **見学ロールでは、発言から共有メモを作れなくなりました**。メモは卓に置くものなので、見学の権限では
  ボタン自体が出ません

## 🎭 ノベルモード

**立ち絵の切り替え矢印が効かなくなっていた不具合を直しました。** 押しても表示が変わらず、
変えたつもりの絵で発言が飛ぶ状態でした。**立ち絵に名前を付けている場合は、番号の代わりに名前が出ます。**

操作バーも整理しました。上から「誰が話すか」「進行と再生」「入力」の3段に分かれ、終了ボタンは
右上に固定です。以前は1段目に詰め込みすぎて、終了ボタンだけが折り返して見えていました。

ログを消したときなどのシステムメッセージが、ノベルモードでは翻訳されず`@i18n:...`のまま
出ていたのも直しています。

## 🧭 コマの向きが分かるようになりました

2Dモード（俯瞰固定）では絵が常にこちらを向くため、どちらを向いているのか分かりませんでした。
テーブル設定の**キャラクターの向き**で、示し方を選べます。

| 選択         | 見え方                                                     |
| ------------ | ---------------------------------------------------------- |
| 示さない     | これまでどおり。2Dモードではコマを回せません               |
| コマごと回す | 2Dでコマを回せるようになり、絵ごとその向きへ回ります       |
| 矢尻で示す   | 絵はこちらを向いたまま、矢尻が向きを示します。3Dでも出ます |

向きはコマの回転そのものなので、部屋の全員に同じ向きが見えます。

## 🖼️ ホワイトボードで画像が動きます

**APNG・GIF・アニメーションWebPを貼ると、卓に立てたボードの上でも動きます。** これまでは
1コマで止まっていました。

::: warning
その画像より上のレイヤーに何か描かれているときは、書き込みを覆わないよう静止画として焼き込みます。
動かしたい画像は、いちばん上のレイヤーに置いてください。
:::

**何か描いた後にCtrl+Zを押すとキャンバスが4×3マスに縮んでいた不具合**も直しました。

## ❤️ リソースの増減演出を項目ごとに選べます

HPを減らしたときのエフェクトと効果音を、**リソース項目ごとに**オン・オフできるようになりました。
シートの詳細設定に**増減でエフェクト**と**増減で効果音**が増えています。

::: warning
**どちらも既定はオフです。** これまで使っている部屋のキャラクターや、取り込んだキャラクターは
両方オフから始まるので、鳴らしたい項目にチェックを入れてください。新しく作るキャラクターの
HPとMPは、最初から両方オンです。
:::

弾数や所持金まで光って鳴ると肝心の一撃が埋もれる、という声を受けての変更です。

## 開発者向け

### パネルの重なり順に「レイヤー」が入りました

`PanelOption.layer`を渡して開いたパネルは、そのz-indexに固定されます。ホットバーをピン留めした
ときの登録画面のように、通常のパネルの積み重ねとは別の高さに置きたいものが対象です。

このレイヤー指定パネルは、`DraggableDirective`の重なり順の付け替え（つかんだものを最前面へ出す
処理）から**除外**されます。これまでは除外していなかったので、レイヤー指定パネルが通常の積み重ねに
巻き込まれて沈み、逆に通常のパネルがモーダルより手前へ昇格していました。除外の目印は`data-z-layer`属性です。

画面全体の重なり順は`src/app/ui/z-layers.ts`に一覧化しました。新しく「モーダルより手前」を
足したくなったときは、まずこのファイルを見てください。

### DraggableDirectiveが入力を実際に発火するようになりました

これまで宣言だけされていて発火していなかったものが動きます。**既存の利用側の挙動が変わる**ので、
自前のディレクティブやコンポーネントで使っている場合は確認してください。

- `draggable.disable`が実際に効きます（これまでは固定してもドラッグできました）
- `draggable.start` / `draggable.move` / `draggable.end`が発火します
- `draggable.settled`を追加しました。ウィンドウのリサイズで位置が押し出され、落ち着いた
  400ms後に1回だけ飛びます。位置の記録用です

### チャット送信とパネル呼び出しの共通化

キャラクターのマクロ送信が`CharacterMacroService`に、チャットパレットの行解釈が
`domain/chat/palette-rows.ts`に集約されました。チャットパレット・リモートコントローラ・
ホットバーの3か所に散っていた同じ処理が1か所になっています。

キャラクター系パネル（チャットパレット／シート／リモコン）は`RoomPanelService`から**名前で**
開く形になりました。`DEFAULT_CHARACTER_PANEL`などの名前は`domain/ui/room-panel.ts`にあります。

### 動く画像の判定

APNG・GIF・アニメーションWebPの判定は`core/storage/animated-image.ts`の
`isAnimatedImageBytes()`です。ファイル先頭の64KBだけを読み、pngはacTLチャンク、
webpはANIMチャンクを探します。判定結果は`AnimatedImageService`が画像1枚につき1回だけ
記憶します。**バイト列を実際に読めたときだけ**記憶するので、P2Pで転送中の画像を「静止画」と
覚え込むことはありません。

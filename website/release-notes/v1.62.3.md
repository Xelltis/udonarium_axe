# v1.62.3

2026-10-08リリース

不具合修正のリリースです。v1.62.0から、PCでもパネルの「別のウィンドウで開く」ボタンが出ないことがありました。あわせて、このブラウザに残っているデータをすべて消す機能を部屋設定に入れました。

## 🐛 「別のウィンドウで開く」ボタンがPCでまた出ます

v1.62.0で、スマートフォンではパネルの「別のウィンドウで開く」ボタンを出さないようにしました。スマートフォンでは別のウィンドウが新しいタブになるだけで、卓と並べて使えないためです。ところが、この判定がPCにも当たっていました。

- ブラウザのウィンドウが狭いとき。画面の拡大率が125%や150%のノートPCでは、ブラウザを画面の半分の幅にするだけで当たります
- タッチパネルの付いたPCで、ブラウザが指を主な入力とみなしているとき

狭いときに開いたパネルは、あとでウィンドウを広げてもボタンが出ないままでした。

今は、マウスやタッチパッドがあれば、ウィンドウの幅に関係なくボタンが出ます。指だけで操作するスマートフォンとタブレットでは、これまでどおり出ません。

## 🧹 このブラウザのデータをすべて消せます

部屋設定の**ユーティリティ**タブのいちばん下に、**危険な操作**の欄を足しました。「このブラウザのデータをすべて消す」を押すと、このブラウザに残っているデータをまとめて消して、ページを読み込み直します。表示や動きがおかしいままで、読み込み直しても直らないときに試してください。

消えるのは、自分の設定（表示・音量・スキン・ウィジェットの配置など）、部屋の自動保存とリプレイの記録、マイダイスとスキンの画像です。元には戻せません。押すと確かめるダイアログが出るので、消えるものを見てから決められます。

読み込み直すと、いまの部屋からはいったん抜けます。ひとりで遊んでいるときは保存していない部屋の内容も消えるので、残したい部屋は先に保存してください。詳しくは[部屋設定](/manual/room-settings#このブラウザのデータをすべて消す)を参照してください。

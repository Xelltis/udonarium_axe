## ✨ 新機能

### キャラクターやダイスの名前・バフを隠せるように

テーブル上のオブジェクトごとに、**名前ラベル**や**バフラベル**の表示・非表示を切り替えられるようになりました。NPCやマップ装飾、伏せておきたいダイスなど、名前を出したくないオブジェクトをすっきり見せられます。

切り替えられる項目は次のとおりです。

- **キャラクター** … 名前を隠す / バフを隠す
- **ダイスシンボル** … 名前を隠す

操作方法は2通りあります。

- **右クリックメニューから**
  - キャラクター … **「表示」** サブメニューの **「名前を隠す」** / **「バフを隠す」**
  - ダイスシンボル … **「名前を隠す」**
- **詳細設定から**
  - キャラクター … 設定パネルの **「名前を隠す」** / **「バフを隠す」** チェックボックス
  - ダイスシンボル … ダイス目シートの **「名前を隠す」** チェックボックス

この設定はオブジェクトごとに保持され、同じルームの参加者全員に同期されます。隠した名前やバフは、もう一度同じ項目を切り替えればいつでも再表示できます。

# v1.71.0

2026-10-26リリース

コマを、GMと持ち主・同じパーティの人にだけ見える「ステルス」にできるようになりました。

インベントリでは、行をドラッグしてフォルダやほかのタブへ移せます。並び順は第3以降もいくつでも足せます。表示設定には、検索欄を一覧の上に出す、ラウンド操作を戦闘中だけ出す、リッチ表示を詰める、の3つを加えました。

手番では、まだ動いていないコマを待機させて、あとから割り込ませられます。ほかに、数値リソースのスライダーを部屋全体で出す設定、コマ画像の幅と高さを別々に決める設定、このブラウザで最初に開く部屋を決める機能を加えました。

## 🫥 ステルス

コマの右クリックの「コマの状態」に **ステルス（GMと持ち主・仲間にだけ見える）** を加えました。テーブルにいるコマなら、インベントリの行の右クリックからも切り替えられます。切り替えられるのは、GMとそのコマの持ち主だけです。見学の人には、自分が持ち主のコマでも出ません。

ステルス中のコマは、明るさに関係なく、GM・持ち主・同じパーティの人にだけ見えます。ほかの人の画面ではテーブルに描かれず、インベントリ、行動順、チャットの発言者、射程や移動範囲、射線、スイッチからも外れます。暗がりにいて見えないコマと同じ扱いです。パーティが見つけていたコマも、ステルスにすると見えなくなります。GMがPLの視点で見ているときは、そのPLと同じように見えます。手番の知らせにコマの名前が出るのは、PLが持ち主のコマと、PLのコマと同じパーティにいるコマだけです。

見えている人の画面では、ステルス中のコマは画像が薄くなり、足もとに破線の輪と、斜線の入った目の印が付きます。インベントリの名前の横にも同じ印が出ます。

交戦エリアの設定に「ステルス中のコマを『姿が見えない』として扱う」を加えました。既定はオフです。オンにすると、ステルス中のコマは、手で「姿が見えない」を付けたコマと同じく移動を止められず、止めたときはその場で交戦エリアを作ります。

ステルスは、コマを画面に出さないための機能です。部屋のデータは、暗がりのコマと同じく全員に届いています。コマが出す光と、GMがそのコマとして話した発言は隠れません。

## 🎒 インベントリ

表示設定に、次の3つを加えました。どれも既定はオフで、選んだ内容はこのブラウザに残ります。

- **一覧の上に検索欄を出す**: 一覧のすぐ上で絞り込めます。表示設定の検索欄と同じ文字が入ります
- **ラウンド操作は戦闘中だけ出す**: ラウンドが始まるまではラウンド操作の帯を隠します。タブの右の▶を押すと、1ラウンド目が始まります
- **リッチ表示を詰める**: 選んでいない行は、画像・名前・バフの印と、表示項目に入れた数値リソースの細いバー（値と最大値つき）だけになります。選んだ行は今までどおり開きます

表示設定を使わなくても変わるところがあります。

- リッチ表示で、リソースの値の横に最大値が出ます。欄が狭いときは出しません
- 並び順の欄に、表示項目の名前と「名前」が候補として出ます
- 表示項目の欄の横に**候補**ボタンを加えました。卓にいるキャラクターが持つ項目の名前を、持っているキャラクターが多い順に並べます。押すと欄の最後に足し、もう一度押すと外します。手で書いた内容はそのまま残ります
- まだ選んでいない行のゲージを押すと、行が選ばれるだけで、値は変わりません。キーボードではこれまでどおりゲージを動かせます

### 並び順を足す

並び順は、第1と第2のほかに、いくつでも足せます。**並び順を足す**を押すと行が増え、行ごとに昇順と降順を選べます。行の右の✕で外せます。

後の並び順は、それより前の並び順で同じ値になったコマどうしを並べるときに使います。前の並び順の項目をどちらのコマも持っていないときも、後の並び順で並べます。行動順はテーブルタブの並び順に従うので、行動順にも効きます。

### ドラッグで移す

開いているフォルダの上なら、見出しでなくても、どこに落としてもそのフォルダに入ります。コマをほかのタブの上に落とすと、そのタブの場所（テーブル・共有・個人・墓場）へ移ります。タブへ移せるのは卓を編集できる人だけで、一括移動でチェックしたコマも一緒に移ります。簡略表示の行もドラッグできます。

行は、項目の欄の上からもつかめます。文字や数値の欄の中で押したときは、ポインターが欄から出るまで文字の選択として扱います。ゲージ・選択肢・ボタンは、それぞれの操作だけをします。タッチでは、欄の上で指を動かすと一覧がスクロールします。

ドラッグできる行では、つかむ形のカーソルが出ます。ドラッグ中は、ポインターの横にコマの名前が付いてきて、複数を移すときはその数も出ます。PLがテーブルタブの行を押してドラッグすると、インベントリのパネルではなくコマが動くようになりました。パネルはタイトルバーで動かします。別のウィンドウに出したインベントリでは、そのウィンドウの中だけでドラッグします。

## ⏸️ 待機と割り込み

ラウンドの途中で、まだ手番を終えていないコマを待機にできます。手番のコマは、インベントリのラウンド操作の⏸ボタンで待機にします。ほかのコマは、インベントリの行の右クリックの**待機させる**で待機にします。

待機中のコマは「次へ」で飛ばされ、行に⏸の印が出ます。ほかに手番を待つコマがいなくなると、待機中のコマに手番が回ります。

待機中のコマは、行の手番ボタン（▶）か、行の右クリックの**割り込む**で、その場で手番になります。割り込まれたコマは、手番を終えていない扱いのまま残ります。割り込んだコマの手番が済んで「次へ」を押すと、割り込まれたコマの手番に戻ります。待機する前に手番が始まっていたコマは、手番が戻ってきても、手番の始まりの処理（バフの残りを減らすなど）をもう一度はしません。

陣営ごとに手番を回すときは、待機中のコマは自分の陣営のフェイズで飛ばされます。割り込むと、いま開いているフェイズの中で手番になります。すべての陣営のフェイズが終わってから、待機中のコマに手番が回ります。

「ラウンドを進める」を押したときに待機中のコマが残っていると、まだ動いていないコマとして名前が出ます。「前へ」で、待機させる前に戻せます。

## 🎚️ リソースのスライダー

部屋設定の「UI」の「共通」に**数値リソースにスライダーを既定で出す**を加えました。既定はオフです。項目ごとに出す・出さないを選んでいない数値リソースは、この設定に従います。コマのデータは書き換えないので、卓にいるコマにも、新しく作るコマにも、読み込んだコマにも効きます。項目ごとに出す・出さないを選んだリソースは、その選択に従います。

項目の設定でスライダーのチェックを外すと、「出さない」と記録するようにしました。部屋の既定がオンでも、そのリソースだけスライダーを外せます。

コマの右クリックの「表示と扱い」に**リソースのスライダー**を加えました。「すべて出す」と「すべて隠す」で、そのコマの数値リソースのスライダーをまとめて切り替えます。インベントリの一括移動の帯にも、同じボタンを加えました。どちらも、卓を編集できる人だけが使えます。

## 🖼️ コマ画像の幅と高さ

コマの設定の「コマ高さを指定」を**コマ画像の大きさを指定**に変え、高さに加えて幅も決められるようにしました。コマのサイズのマス数は変えずに、立ち絵の大きさをほかのコマとそろえられます。

幅と高さの右にあるチェーンのボタンで、縦横比を保つかどうかを切り替えます。つながっているときは画像の縦横比を保ち、幅を変えると高さが、高さを変えると幅が合わせて変わります。押して切ると幅と高さを別々に決められ、画像はその大きさに引き伸ばされます。もう一度押すと、いまの高さのまま画像の縦横比に戻ります。

## 🏠 開始時の部屋

セーブ&ロードに**この部屋を開始時の部屋にする**と**開始時の部屋を元に戻す**を加えました。

「この部屋を開始時の部屋にする」を押すと、いまの部屋をこのブラウザに残します。コマやテーブルに使っていない画像パネルの画像と、ジュークボックスの音声も一緒に残ります。次にAxeを開いたとき、サンプルの卓とコマの代わりに、その部屋で始まります。すでに残してあるときは、置き換えてよいか確かめます。「開始時の部屋を元に戻す」を押すと、残した部屋を消し、次からはサンプルの部屋で始まります。

残した部屋を読み込めなかったときは、サンプルの部屋で始め、そのことを知らせます。残した部屋は、このブラウザだけのものです。ロビーからほかの人の部屋に入るときは、入る前に開始時の部屋を片付けてサンプルの状態に戻すので、卓やコマ、チャット、画像や音声が相手の部屋へ持ち込まれることはありません。部屋に入れなかったときは、開始時の部屋を読み込み直します。このとき、開始時の部屋にしてから変えたところは戻りません。自分で作った部屋には、開始時の部屋のまま入ります。招待リンクから開いたときは使いません。部屋のサーバーで伏せた形のまま受け取った物がある卓は、開始時の部屋にできません。部屋設定の「このブラウザのデータをすべて消す」を使うと、一緒に消えます。

あわせて、部屋とコマの保存データに、Axeに入っている画像（サンプルのコマの画像など）の場所を書くようにしました。サンプルを置いていないブラウザで読み込んでも、その画像が出ます。

## 🛠️ 直したこと

- リソース操作で、割り算の端数の処理（`/2C`は切り上げ、`/2R`は四捨五入、`/2F`は切り捨て）が使えませんでした。`:HP+[{器用度}/2C]+1`のように書くと、ダイスロールと同じく端数を処理して計算します
- リソース操作で、出目修正などを付けたダイスの後ろに足し算や引き算を続けると、計算できませんでした。`t:HP-([k3@{C値1}]+{追加D1}+{追加D修正}{出目修正}-t{防護})Z`のような書き方も計算します
- タッチパネル付きのノートPCで、パネルの「別のウィンドウで開く」ボタンが出ないことがありました。マウスを動かすと出ます
- 接続し直したときに、インベントリの個人タブが共有タブとして表示され、共有タブが2つ並ぶことがありました。個人タブの行に、表示項目が出ないこともありました
- オフラインのとき、裏向きに置いたカードの表が見え、ダイスの出目を自分だけのものにできませんでした。手札に取ったカードがテーブルから消え、手札にも入らないこともありました。オフラインのときと接続が開く前は、マスクを削れませんでした
- カットインとダイス表を、確かめずに消していました。今は、危ない操作として確かめてから消します。確かめたあとに消したカットインが一覧に残ることもありました
- 狭いウィンドウでは、インベントリのタブがボタンの下にもぐっていました。今はタブが横にスクロールします。行にマウスを乗せたり行を選んだりすると、手番とメニューのボタンが出て、項目の位置がずれていました。今は名前の行の端に重ねて出します。タッチ画面では、これまでどおりの位置に出ます
- パネルの一覧で途中で切れた名前は、マウスを乗せるかタップすると全部出ます
- テーブル設定と部屋設定で、ラベルが入力欄に重なっていました。暗闇・霧・天候の欄の並びもそろえました。パネルは、上のツールバーの下に開きます
- 明るいテーマで、役割のバッジが読みにくくなっていました。標準のスキンの薄い文字とパネルのタイトルは、濃くしました。暗いテーマで、アクセント色のボタンの白い文字が読みにくくなっていました
- アイコンだけのボタンに名前を付けました。メニューの引き出しの項目にキーボードで移れ、確認のダイアログにキーボードで答えられます。枠線を消しているボタンでも、キーボードでいまどこにいるかがわかります

## ⚠️ 以前の版との互換

v1.70.1以前の人の画面では、ステルス中のコマも見えます。

v1.70.1以前の版では、第3以降の並び順は使わず、第1と第2だけで並べます。

v1.70.1以前の版は待機を知りません。その版の人が「次へ」を押すと、待機中のコマにも順番どおり手番を回し、割り込みのボタンも出ません。その版の人がラウンドを動かすと、待機の記録は消えます。

「数値リソースにスライダーを既定で出す」は、v1.70.1以前の人の画面では効きません。項目ごとにスライダーを出すと選んだリソースにだけ、スライダーが出ます。

v1.70.1以前の版では、幅を別に決めたコマの画像も、指定した高さで縦横比を保って出ます。

この版で保存した部屋をv1.70.1以前の版で読み込むと、Axeに入っている画像の場所は読み飛ばします。サンプルを置いたブラウザでは、今までどおり画像が出ます。

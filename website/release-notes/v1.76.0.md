# v1.76.0

2026-11-03リリース

毒やリジェネのように、切れても戻さないステータスの変化をバフで書けるようになりました。チャットには、自分に向けて振られた結果を目標値にする`{目標値}`が入り、抵抗判定を数を打たずに振れます。発言の流れの窓は、チャットウィンドウから開けるようになり、窓の中から発言もできます。

ホットバーの枠で、発言者の名前がラベルに重なっていたのも直しました。

## 🧪 毒やリジェネを書けるバフ

`&!`のステータス名の前に`:`を付けると、バフが切れても、そのステータスは動いたままになります。`&!毒/:HP/+/0~-3/3`なら、残ラウンドが減るたびにHPが3減り、切れても戻りません。切れる回にも減るので、3ラウンドの毒ならHPは3回減ります。

これまでの`~`は、切れたときに、減るたびに動かした分もまとめて戻していました。そのため、毒のダメージやリジェネの回復は書けませんでした。

1つのバフの中で、戻すステータスと戻さないステータスを混ぜられます（`&!毒/回避-2,:HP+0~-3/3`）。状態異常の「動かす項目」にも`:HP`と書けます。バフマネージャーの記法を作る欄には、**戻さない**のチェックが入りました。詳しくは[切れても戻さない](/manual/buff#切れても戻さない)を参照してください。

## 🎯 振られた結果を目標値にする

`{目標値}`と書くと、送るときに、このタブで振られたダイスの結果に置き換わります。`2d+{生命抵抗}+{生命抵抗修正}>={目標値}`をパレットに置けば、敵が振った達成値を打たずに抵抗判定を振れます。

置き換わるのは、発言者のコマに向けて振られた、いちばん新しい結果です。それが無ければ、ほかの発言者がターゲットなしで振った、いちばん新しい結果を使います。シークレットダイスの結果は使いません。

敵の判定をPCごとに向けて振るには、行のどこかに`t:`だけを書きます。`2d+8 魔法行使 t:`は、ターゲットに選んだコマごとに振られ、結果にそのコマの名前が付きます。複数のPCへ別々に振っても、それぞれのPCの`{目標値}`には、そのPCに向けた結果が入ります。詳しくは[振られた結果を目標値にする](/manual/chat-syntax#振られた結果を目標値にする)を参照してください。

## 💬 発言の流れの窓から発言する

チャットウィンドウの上に**別窓**ボタンが入りました。押すと、そのタブの発言だけが並ぶ窓が開きます。これまでは、タブの右クリックか、ノベルモードの下段バーからしか開けませんでした。

窓のタイトルバーの**発言欄**を押すと、タブの切り替えと入力欄が出ます。窓の中でタブを選び直して、そのまま発言できます。発言欄を出したままにすると、次に開く窓にも付きます。詳しくは[発言の流れを別窓で見る](/manual/chat#発言の流れを別窓で見る)を参照してください。

## 🛠️ 直したこと

- 発言者を決めたホットバーの枠で、発言者の名前がラベルに重なって読みにくくなっていました。名前は枠の左上に出るようになりました。枠にポインタを重ねると、発言者の名前を最後まで出します

## ⚠️ 以前の版との互換

`:`を付けたバフは、v1.75.3以前の版の人が外しても、動いた分を戻しません。ただし、その人が残ラウンドを減らしたときは、減るたびの分が動きません。v1.75.3以前の版からこの書き方で付けることはできません。

`{目標値}`と単独の`t:`は、送る人の版で読みます。v1.75.3以前の版から送ると、`{目標値}`は置き換わらず、`t:`は書いたまま1回だけ振られます。

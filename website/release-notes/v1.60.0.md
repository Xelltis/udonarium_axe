# v1.60.0

2026-10-02リリース

チャットで振ったダイスを**3Dで転がして**見せられるようになりました。ダイスは画面の左から飛び込んで跳ね回り、ダイスボットが出した目のとおりの面で止まります。転がす場所はセリフの枠か卓の上、またはその両方で、GMが部屋設定で選びます。

ジュークボックスの**再生リストはいくつでも**作れるようになりました。「街」「戦闘」と場面ごとに分けておけば、場面が変わったところで切り替えて流せます。キャラクターのリソースは、スライダーでも動かせるようになりました。

## 🎲 チャットのダイスを3Dで転がす

GMが**部屋設定**の**一般**にある**ダイスの演出**で選びます。部屋の全員に同じ設定が適用されます。

- **出さない** — 既定です。前からある部屋も、選び直すまではこのままです
- **セリフの枠** — ダイスボットの答えの吹き出しの下に細長いトレイが開き、その中で転がります。ノベルモードのダイス結果の枠にも出ます
- **卓の上** — 振ったコマの手前に転がります。止まったダイスはしばらく残ってから消えます
- **両方** — 枠と卓の両方で転がります。転がり方は別々ですが、止まる目は同じです

<Shot src="dice-3d-frame" alt="ダイスボットの答えの吹き出しの下にトレイが開き、赤いD6 2個とD20が出目を上にして止まっている" caption="セリフの枠では、答えの吹き出しの下でダイスが転がります" />

止まったダイスは、上を向いた面の数字が読む人に向けて立ちます。卓を回していても同じです。

- シークレットのロールは、振った本人の画面でだけ転がります。GMの画面にも出ません
- ダイスボットがクリティカルと判定したロールでは金の輪が、ファンブルでは赤の輪が、止まった瞬間にダイスの足元で光ります
- 転がるのはD4・D6・D8・D10・D12・D20です。D100は十の位と一の位に分けたD10 2個で、D3は1〜3を2回ずつ書いたD6で振ります
- 一度に転がるのは50個までです。それより多いロールは、残りを「+5」のように数だけ添えます
- アニメーションを止めている画面では、枠の中に目を上にしたダイスが並ぶだけで、卓の上には何も出ません

転がるのは、その場で振ったロールだけです。部屋を読み込み直したときや、リプレイを再生したときには転がりません。卓の上のダイスはコマや壁より手前に描くので、コマの陰には隠れません。

くわしくは[チャットのロールを3Dのダイスで転がす](/manual/dice#roll-in-3d)にあります。

## 🎵 ジュークボックスの再生リストを場面ごとに分ける

**再生リスト**タブの上に、部屋の再生リストが並ぶようになりました。**＋新規**で作って名前を付けておき、名前の欄の横の ▶ を押すと、その再生リストを最初の曲から流します。最初からある**メイン**は消せませんが、名前は変えられます。

- 再生リストの曲を右クリック（スマートフォンでは長押し）すると、**別の再生リストへ移す**と**別の再生リストにコピー**が出ます
- ライブラリのBGMを右クリックすると再生リストの一覧が出て、選ぶたびにその再生リストへ入れたり外したりできます
- ミニプレイヤーでは、曲の一覧の上にある **‹ ›** で前後の再生リストへ移れます

パネルにも、ミニプレイヤーと同じ再生の操作が付きました。ミニプレイヤーを隠したままでも曲を回せます。操作は参加者全員に同期します。

- **一時停止**した曲は、もう一度押すとその位置から続きます
- **前の曲**は、曲が始まって3秒を過ぎていれば、いまの曲を頭から流し直します
- **シャッフル**は、全曲を一度ずつ流し終えるまで同じ曲を回しません。ミニプレイヤーにも同じボタンがあります
- **シークバー**で再生位置を動かせます。左の鍵を掛けると動かせなくなり、鍵の状態も全員で共有します

くわしくは[ジュークボックス](/manual/jukebox#再生リストを使い分ける)にあります。

## 🎚️ リソースをスライダーで動かす

リソースの詳細設定に**スライダー表示**が増えました。入れると、キャラクターシートと、コマにマウスを乗せると出る詳細の両方で、現在値の下にスライダーが出ます。範囲は下限（置いていなければ0）から最大値までで、動かして離したところが現在値になります。最大値は変わりません。

ドラッグしている間は数字が動くだけで、書き込むのは離したときの1回です。増減でエフェクトや効果音が出る項目でも、出るのは1回だけです。

くわしくは[リソースは現在値と最大値を別々に持つ](/manual/data-element#リソースは現在値と最大値を別々に持つ)にあります。

## 🐛 直った不具合

- スマートフォンで、キャラクターコマを縦に傾けるハンドルが画像の上端に重なり、顔が隠れていました。今は画像の左右に出ます
- テクスチャのない地形（透明な壁）は、GMが足元の点線の枠を狙わないと掴めませんでした。今は枠で囲まれたところならどこを掴んでも動かせます。マウスを乗せると、地形全体がうっすら色づきます

## ⚠️ 以前の版との互換

ダイスの演出は、GMが選ぶまで**出さない**のままです。前からある部屋を開いても、ダイスは転がりません。

v1.59.0以前の版を使っている人がいると、次のようになります。

- その人が振ったロールは、誰の画面でも転がりません
- その人の画面では、ほかの人が振ったロールも転がりません
- ダイスの演出とスライダー表示の設定は、その版で開いても消えずに残ります
- 再生リストは最初の**メイン**しか見えません。その人の画面で曲が終わると、メインの次の曲へ進みます

再生リストは部屋の保存データに入りません。接続している参加者のあいだで共有され、全員が部屋を出ると消えます。

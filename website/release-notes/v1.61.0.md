# v1.61.0

2026-10-04リリース

3Dのダイスが**1回のロールで200個まで**転がるようになりました。51個以上のロールは枠を分けて転がし、同時に転がるロールも増えました。チャットの前の行にも、止まった姿のダイスが並びます。

自分が振るダイスの見た目を**マイダイス**で選べるようになりました。材質と色のほか、手元の画像をダイスに貼ることもできます。スキンでは、ダイスが転がる枠に好きな色や画像のマットを敷けます。

## 🎲 1回のロールで200個まで転がす

これまでは、1回のロールで転がるのは50個まででした。今は51個以上のロールを、50個以下の枠に均等に分けて転がします。120個なら40個ずつ3枠です。枠は4つ、ダイスは200個までで、残りは最後の枠の隅に「+5」のように数だけ添えます。

- **チャット欄**では、枠が縦に並びます
- **ノベルモード**では、2枠ずつ横に並べて画面に収め、吹き出しもその幅まで広がります
- **卓の上**では、振ったコマの手前に枠を横に並べます。最後の枠のダイスが止まってから、全部の枠がそろって消えます

同時に転がるロールは3件から6件に増えました。動いているダイスは合わせて400個まで（描画を軽くしている画面では200個まで）で、それを超えたロールは転がさずに目を上にして並べます。ほかに何も転がっていなければ、200個のロールでも転がります。

ダイスを**セリフの枠**に出す設定では、その場で振ったロールより前の行にも、目を上にしたダイスが並ぶようになりました。部屋を読み込み直したときや途中から入ったとき、ダイスの演出を「出さない」にしていたころに振った行も同じです。チャット欄を遡って、行が見えたところで並べます。

くわしくは[51個以上は枠を分けて転がす](/manual/dice#_51個以上は枠を分けて転がす)にあります。

## 🧊 自分のダイスの見た目を選ぶ

部屋がダイスを出す設定になっていると、チャット入力の**色設定**の隣にサイコロのボタンが出ます。押すと**マイダイス**のパネルが開きます。

- **材質** — 樹脂・マーブル・金属・半透明の4つです。マーブルは1個ずつ渦の入り方が違い、半透明は向こう側の面や下に敷いたマットが透けて見えます
- **ダイスの色** — 既定ではロールを書き込んだ発言と同じ色です。チェックを外すと好きな色を選べます
- **数字の色** — 既定ではダイスの色から読みやすい色を自動で選びます。こちらもチェックを外すと選べます

パネルを開いたときと何かを変えるたびに、D4からD20まで1個ずつ、その見た目で振って見せます。

**画像**の**画像を選ぶ**からは、手元の画像をダイスに貼れます。石や木目の写真、自分で描いた模様、ロゴなどが使えます。

- **巻き付ける** — 模様が面の境目をまたいでつながり、ダイスごとに画像の違う部分が出ます。石・木目・星空のような模様に向いています
- **各面に貼る** — どの面にも画像が丸ごと入り、その上に数字が載ります。ロゴや紋章に向いています

画像を貼っているあいだ、材質は樹脂になります。外すと、貼る前に選んでいた材質に戻ります。透過PNGの透けた部分にはダイスの色が出ます。8MBを超えるファイルは受け付けません。

選んだ見た目は、部屋の全員の画面で同じように見えます。見た目は発言に記録されるので、部屋を読み込み直しても、セーブデータを開いても、そのロールは同じ見た目で出ます。設定はこのブラウザに保存され、キャラクターを替えても変わりません。

貼った画像は部屋の全員に送られ、部屋を保存すればセーブデータにも入ります。届くまでのあいだ、ほかの人の画面では画像のないダイスが転がり、届いたところで画像付きに描き直されます。

- 見学の人にはボタンが出ません。見学では部屋に画像を足せないためです
- 描画を軽くしている画面では、半透明のダイスを樹脂として描きます。ほかの人の画面では半透明で見えます

くわしくは[自分のダイスの見た目を選ぶ](/manual/dice#my-dice)と[ダイスに画像を貼る](/manual/dice#my-dice-picture)にあります。

## 🟩 ダイスの枠にマットを敷く

スキンパネルの**ダイスのマット**で、ダイスがチャットの枠で転がる面を変えられます。フェルトの色を選ぶだけでも、布目と照明の当たり具合が付きます。**画像を追加**でプレイマットの画像を敷くと、ダイスの影はその上に落ちます。

マットもライトテーマ用とダークテーマ用を別々に持てます。変わるのは自分の画面だけです。スキンをzipで書き出すと、マットとその画像も入ります。

くわしくは[ダイスのマットを敷く](/manual/theme#dice-mat)にあります。

## 🐛 直った不具合

- FABメニューの**表示**と**ウィジェット**の小窓が、項目を押すたびに閉じていました。今は開いたまま続けて切り替えられます
- アニメーションを**停止**にしても動く演出が残っていました。新しいコマが弾んで現れる動き、ダメージを受けたコマの揺れや光、回復と撃破の演出、コインとダイスシンボルの回転、ジュークボックスの円盤、チャットの行が流れ込む動きなどです。今は停止にすると一瞬で終わります。読み込み中の回転、録画中の点滅、誰かが入力中の点は、状態を知らせる表示なのでそのまま動きます
- 性能の低い端末で、ある材質のダイスを初めて描いたときに、ダイスが途中まで飛んでいたり、卓の上のダイスがすぐ消えたりしていました。今は描き始めた所から続きます
- Safariのプライベートウィンドウで、スキンの画像と部屋の自動保存（スナップショット）が保存されていませんでした。今は保存できます。マイダイスの画像も同じように保存できます
- スキンパネルで、重ねた画像の**合わせ方**と**位置**の欄が、実際の設定に関係なく先頭の選択肢を表示していました

## ⚠️ 以前の版との互換

v1.60.0以前の版を使っている人がいると、次のようになります。

- その人の画面では、マイダイスの見た目や画像は出ず、いつもの樹脂のダイスに見えます
- その人が振ったロールは、誰の画面でもいつもの見た目で転がります
- その人の画面では、51個以上のロールは50個まで転がり、残りは数だけ添えます。前の行のダイスも出ません
- マイダイスの見た目と画像は、その版で開いても発言から消えません。その版で部屋を保存しても、画像はセーブデータに入ります

マットの入ったスキンのzipをv1.60.0以前で読み込むと、配色と重ねた画像だけが反映されます。反対に、マットのない古いスキンを読み込むと、マットはいつものグレーのフェルトになります。

この版からは、スキンの画像と自動保存のスナップショットを、ブラウザに新しい形で保存します。この版より前に保存したものは、そのまま読み込めます。一方、この版で保存したものは、v1.60.0以前に戻すと読み込めません。

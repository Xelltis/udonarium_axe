# v1.20.0

2026-07-30リリース

プレイヤーの手元まわりを大きく作り足した回です。GMツールバーの対になる**PLツールバー**、実際のトランプのように扱える**手札**、そして暗闇の中で仲間と視界を分け合う**同行（パーティ）** が加わりました。

## ✨ 新機能・改善

### PLツールバー

プレイヤーのとき、画面上部に[PLツールバー](/manual/pl-tools)が出るようになりました。GMツールバーと同じくドラッグで移動できます（見学のときは出ません）。

- **所有キャラクター一覧** … 自分がオーナーのキャラクターだけを並べ、チャットパレット・[シート](/manual/character)・リモートコントローラ・コマへの視点移動を1か所から開けます。**HP / MPなどのリソースはその場で増減**でき、ダメージのたびにシートを開き直す必要がありません
- **操作対象キャラクター** … 「いま動かしている1体」をツールバーに常駐表示します。複数のキャラクターを受け持っていても見失いません
- **射程範囲のショートカット** … 操作対象のコマを基点に[射程範囲](/manual/range)を出し、コマにドッキングした状態で作ります
- **行動順の表示** … 戦闘中はラウンド数と現在の手番が並びます（[行動順](/manual/turn-order)ウィジェットを開かなくても確認できます）

### 手札

カードの置き場としての[手札](/manual/cards#手札)が加わりました。手札に入れたカードは**テーブルから消え**、自分だけが中身を見られます。

- 画面下部の帯（レール）に、実際の手札のように**扇状**に並びます。ポインタを乗せた1枚が起き上がり、枚数が増えても帯の大きさは変わりません
- **ドラッグで出し入れ**できます。テーブルから帯へ入れ、帯からテーブルへ出す。帯の中でドラッグすれば並び替えで、差し込まれる位置に隙間が開きます
- **重なったカードを手札に加える**で、重なっている分をまとめて回収できます
- 帯そのものもドラッグで好きな位置へ動かせます
- 手札は**userId基準**なので、再接続しても失われません

従来の「[場に伏せて自分だけ見る](/manual/cards#場に伏せて自分だけ見る)」は別の機能として残ります。場に置いたまま自分だけ内容を知る手と、手元に引き取る手を使い分けてください。

::: warning 秘匿の程度について
サーバを持たないP2P構成のため、手札の中身も参加者全員の環境へ同期されています。「見えない」のは画面上の取り決めであって、技術的な秘匿ではありません（[詳しく](/manual/cards#手札)）。
:::

### 同行（パーティ）

同じパーティに入れたキャラクターどうしが、**視界を共有**するようになりました。[暗闇](/manual/vision-lighting)のダンジョンで「隣を歩いているはずの仲間のコマが見えない」という状態を解消します。同行者の視界に照らされた範囲が自分の視界に合わさり、暗闇の中でも同行者のコマは見えたままになります。

- 編成はGMツールバーの**同行**パネルから。パーティの作成・改名・色分け・解散と、メンバーの割り当てができます
- 所属するのは**プレイヤーではなくキャラクター**です。1人のプレイヤーが2体受け持っているとき片方だけ斥候に出す、GMのNPCを案内役として同行させる、といった使い分けができます
- プレイヤー側は所有キャラクター一覧で所属と同行者を確認できます（編成できるのはGMだけです）
- 編成はルーム全体に対する設定で、テーブルを切り替えても維持され、[保存データ](/manual/save-load)にも含まれます

詳しくは[同行（パーティ）](/manual/party)を参照してください。

### 照明をマス目に沿わせる

テーブル設定の暗闇に **「照明をマス目に沿わせる」** が加わりました。照らされた範囲がマス単位に丸められ、四角マスなら正方形、ヘクスなら六角形の縁になります。「このマスは明るいのか」を目で数えられるので、移動や射程の判定に使えます。

丸めるのは遮蔽を計算した後なので、**壁を越えて光が漏れることはありません**（[暗闇・視界・光源](/manual/vision-lighting)）。

### 時計とミニプレイヤー

卓上に浮かぶ小物を、GM / PLどちらのツールバーからも表示切り替えできるようになりました。表示状態はブラウザに保存され、次回も引き継がれます。

- **時計** … 枠のないデザインで卓の上に時刻を出します。ドラッグで移動でき、ポインタを乗せたときだけ背景と × が出ます
- **ミニプレイヤー** … [ジュークボックス](/manual/jukebox)の再生操作。**隠してもBGMは流れ続けます**

### GMツールバーの拡充

[GMツールバー](/manual/roles#gmツールバー)にも、行動順（ラウンド数・現在の手番と前後の送りボタン）、手札の開閉、同行パネル、時計 / ミニプレイヤーの切り替えが並びました。

## 🐛 不具合修正

- **コマに近づくと画像が粗くなる問題を修正** … カメラを寄せたときにキャラクター・ダイス・カード・カードスタックの画像がぼやける問題を修正しました。近距離でも輪郭が保たれます
- **ヘクスマップの端で暗闇が外形からずれる問題を修正** … ヘクスマップに暗闇をかけたとき、外周のギザギザの部分が覆われずに残り、下端では逆にマップの外まで暗闇が伸びていました。マップの外形ちょうどで止まるようにしました

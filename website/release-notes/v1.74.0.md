# v1.74.0

2026-10-29リリース

チャットの入力欄で、記法が種類ごとに色分けされ、このまま送ると効かない書き方に波線が付くようになりました。太字や色の装飾とルビは、送ったあとと同じ見た目で描かれます。入力欄の上の**記法**ボタンから、記法を選んで入れることもできます。

シークレットの`s&`が効いていなかった不具合なども直しました。

## ✍️ 入力欄での色分けと指摘

ダイスのコマンド・リソース操作・バフ・参照・立ち絵・演出などが、種類ごとの色で出ます。`{HP}`のような参照の横には、いまの値が出ます。太字・色・書体の装飾とルビは、カーソルが外にあるあいだ送ったあとの見た目で描かれ、カーソルを入れると記号が出て書き直せます。

このまま送ると効かない書き方には波線が付き、ポインタを乗せると理由が出ます。ダイスボットが振れないコマンド、発言者のコマにない項目、見つからない立ち絵、ターゲットのいない`t:`、閉じていない装飾などが対象です。ダイスのコマンドは、選んでいるダイスボットで実際に振れるかを確かめます。入力欄の横のボタンに指摘の数が出て、押すと一覧が開きます。指摘があっても、送ることはできます。

`{`・`:`・`&`・`@`・`《`のあとには、ステータスや立ち絵、演出の名前の候補が出ます。行の最初の語には、ダイスボットのコマンドの例が出ます。候補は`Tab`で入れます。`Enter`はこれまでどおり送信です。

チャットパレットの編集欄でも、行ごとに色分けと指摘が出ます。

色分けを使わず、もとの入力欄に戻すときは、チャットの設定の「入力欄で記法を色分けする」を外します。この画面だけの設定です。詳しくは[入力欄での色分けと指摘](/manual/chat-syntax#入力欄での色分けと指摘)を参照してください。

## 🧰 記法ボタン

入力欄の上の「装飾」ボタンが**記法**ボタンになりました。装飾・ルビ・ダイス・参照・リソース操作・バフ・立ち絵・演出とカットイン・引用に分かれていて、項目の名前に書き方が並んでいます。選んだ記法は、読まれる場所に入ります。装飾は選んだ文字を囲み、立ち絵とカットインは行末に、シークレットは行頭に入ります。ダイスには、選んでいるダイスボットのコマンドの例も並びます。

## 🛠️ 直したこと

- シークレットでバフを付ける`s&`が効いていませんでした。マニュアルのとおり、伏せたまま付くようになりました
- 1行に`s:`を2つ以上書くと、2つ目からが効いていませんでした
- `s&`の行が、シークレットの行として扱われていませんでした。ほかの人にそのまま見え、行末のカットインも起きていました
- ターゲットを2人以上選んで送ると、発言者自身への`s:`・`s&`の操作が、人数分かかっていました

## ⚠️ 以前の版との互換

送る文字列も、チャットのログの形も変わりません。v1.73.0以前の版でも、同じ記法の文字列として読めます。

`s&`を書いた行は、この版からシークレットの行として送られます。v1.73.0以前の版でも、届いた行は伏せて表示されます。

`s&`と`s:`について直したことは、この版で送った行に効きます。v1.73.0以前の版で送った行は、これまでどおりです。

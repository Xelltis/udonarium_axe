# v1.41.3

2026-08-22リリース

デモサイトのアドレスが変わりました。アプリ側の修正は、日本語の扱いに関わる1件です。

## 🏠 デモサイトがaxe.xelltis.comに移りました

[デモサイト](https://axe.xelltis.com)のアドレスが`demo.savage-tribe.com`から
**`axe.xelltis.com`** になりました。Axeの開発と運営をXelltisに移したためです。

旧アドレスを開くと、しばらくは新アドレスへ転送されます。ブックマークも、配ってある
[招待リンク](/manual/roles#招待リンクで参加者を招く)も当面そのまま届きますが、転送はいずれ止めます。折を見て
新しいアドレスに入れ替えてください。

このドキュメントサイトと、配布物を置いているGitHubのリポジトリも同時に引っ越しました。
`axe_x.y.z.zip`の取得先も不具合の報告先も変わっていますが、サイト内のリンクはすべて新しい先に
張り替えてあります。

自分でホストしている方は、この移動の影響を受けません。

## 🔤 画面が何語なのかブラウザに伝わるようになりました

これまでAxeは、表示している言語をブラウザに伝えていませんでした。人の目には日本語に見えても、
ブラウザから見れば言語の指定がない画面でした。

その結果、読み上げソフトは日本語を英語の発音で読み上げ、行の折り返しやフォントの選ばれ方も
日本語向けの規則になりませんでした。表示を英語に切り替えても、事情は同じでした。

これからは、いま選んでいる言語がそのままブラウザに渡ります。言語を切り替えれば、その指定も
一緒に切り替わります。

## 🔧 開発者向け

自分でビルドして使っている方向けの変更です。

- **リポジトリが`Xelltis/udonarium_axe`に移動** … 旧アドレスからはGitHubが自動転送するので、
  `git clone`や`git push`はそのまま通ります。リモートのURLは書き換えておくと安心です
- **公開先をproductionとpublicの2つに整理** … 検証用のstagingと、役目が重複していたdemoを
  畳みました。リリース後は本番、続いて公開インスタンスの順にデプロイされます。アプリの動作は
  変わりません

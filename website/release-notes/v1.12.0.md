# v1.12.0

2026-06-05リリース

## ✨ 新機能

### 行動順トラッカーを追加

戦闘などで「今は誰の手番か」を管理する**行動順**機能を追加しました。テーブル上のキャラクターを並び順どおりに表示し、手番が変わるたびにチャットへ通知して、対象のコマを光らせます。手番の状態は参加者全員で同期されます。

- **行動順ウィジェットを開く** … [インベントリ](/manual/inventory)を開き、パネルの**最小化（−）** ボタンを押すと、インベントリが行動順ウィジェットに切り替わります。キャラクターのアイコンが行動順に積み重なり、現在の手番のキャラクターがリングと淡い光で強調されます。
- **手番を進める** … ウィジェット上部の**次へ** / **前へ** / **リセット**ボタン、またはアイコンの**クリック**で手番を操作できます。「次へ」を押していくと、ラウンドの開始・終了を含むシステムメッセージがチャットに流れます。
- **インベントリ画面からも操作可能** … 最小化していない通常のインベントリ「テーブル」タブからも、ラウンド表示・前へ・次へ・リセット、各キャラクターの「手番にする」を操作できます。
- **表示順** … インベントリ「テーブル」タブの**並び順**（例: 敏捷度の降順）がそのまま使われます。

詳しい使い方は[行動順マニュアル](/manual/turn-order)を参照してください。

## 🐛 不具合修正

- **ミニジュークボックス** … 最小化したミニジュークボックスを元に戻したときの位置が、画面外にはみ出さず表示領域内に収まるようにしました。
- **ミニジュークボックス** … タッチ操作で最小化・復元のボタンが押しづらかった問題を修正しました。

## ♻️ 改善

- **テーブル設定** … 設定パネルの項目を種類ごとのグループに分け、入力欄の左端と幅をそろえて見やすくしました。

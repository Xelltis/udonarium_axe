# v1.44.1

2026-08-28リリース

不具合修正が中心のリリースです。v1.44.0のマップ生成を実際に使って見つかった3件と、チャットの
リソース操作が何も表示せずに止まる2件を直しました。あわせて、リソース操作の計算式に、ソードワールドの
威力表のようなシステム固有のダイスコマンドを混ぜられるようになっています。

## 🎲 威力表や`2dx`を、リソース操作の式に混ぜられます

`:HP-2d6`のような一般的なダイス式は前から書けました。一方でソードワールドの`k10`やダブルクロスの
`2dx`は、ダイスボットが単独のコマンドとして答えるため、足し算の項には置けません。

角括弧で囲むと、そこだけを先に振り、出た数字を式に戻してから残りを計算します。

```
t:HP-([k10]+5-t{防護})
```

対象のHPから「威力表10の出目 + 5 − 対象の防護点」を引きます。振った内訳は、操作結果の下に並びます。

```
[キャラクターB] HP:200-(5+5-3)＞193
  └ [k10] KeyNo.10c[10] ＞ 2D:[5,4]=9 ＞ 5
```

書式は[チャットの特殊記法](/manual/chat-syntax#特殊なダイスコマンドを式に混ぜる)に書きました。

## 🐛 不具合修正

- **計算できないリソース操作が何も表示されずに捨てられる問題を修正** … 部屋のダイスボットが解釈できないコマンドや、参照先の見つからない`{...}`が1つ混ざると、同じ行に書いた他の操作までまとめて捨てられ、チャットには何も出ませんでした。送信が届かなかったのか書き方が悪いのかも分かりませんでした。今はどのコマンドが駄目だったかを「〜を計算できません」と名指しし、残りの操作はそのまま通ります
- **キャラクター以外の発言で`t{...}`が展開されない問題を修正** … `t{防護}`が読むのは対象のシートで、発言者が誰かは関係ありません。それでも自分名義の発言では展開が飛ばされ、`t:HP-t{防護}`が波括弧のままダイスボットへ渡り、何も起きずに終わっていました
- **地形が自分の高度のぶん持ち上がる問題を修正** … 高度を指定して置いた地形は、卓のコマが1つ動くと、その高度をもう一度足した位置へ跳ね上がっていました。生成したフィールドで目立ち、幹の上に載っていた葉が倍の高さまで浮いて、木がばらばらに分解して見えました
- **フィールド生成でサボテンが石壁になる問題を修正** … 雰囲気ごとの素材は、側面に壁テクスチャを持つ地形すべてに着せていました。サボテンもその一つだったため、荒野では岩と同じ砂岩をまとい、上だけ緑で側面が石積みという姿になっていました
- **ヘクスのマップ生成で、奥がテーブルからはみ出す問題を修正** … ヘクスのマスは四角より横幅が狭いのに、必要なテーブルの広さを四角のマス数で数えていました。25 × 19のダンジョンが22 × 20のテーブルに置かれ、奥の3列がテーブルの外に出て見えなくなり、手前には空のヘクスが1列余っていました

## ⚡ 軽くなったところ

地形が数百個ある卓では、コマを1マス動かすたびに、壁の形と光の通り道を全部計算し直していました。生成した
ダンジョンやフィールドがちょうどこの規模になります。壁はコマが歩いても動かないので、動かない間は前の
結果を使い回すようにしました。

暗闇を使っていない卓では、明るさの計算そのものをやめています。暗闇が切ってあれば地形はすべて最大の
明るさになり、計算しても答えは変わらないからです。

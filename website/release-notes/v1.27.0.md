# v1.27.0

2026-08-06リリース

**倒したときの演出**を足した回です。周りで何かが光るのではなく、**コマそのものが砕けて散ったり、斬られてずれ落ちたり**します。あわせて、保存したルームを読み込むと回復音が鳴り続ける問題を直しました。

## ✨ 新機能・改善

### 倒れたときの演出

エフェクト集に**撃破**の系統が増えました。ほかの演出と違い、**コマ自身**が壊れます。

|              | 何が起きるか                                                                                    |
| ------------ | ----------------------------------------------------------------------------------------------- |
| **崩壊**     | 轟音とともにコマが格子状に砕け、**下の段から順に**落ちて散り、光になって立ち上ります            |
| **両断**     | 一閃が走り、コマが**斬り口で2つにずれて滑り**、開いた隙間から血が噴き出します                   |
| **血しぶき** | 傷口から**脈打って3度**噴き上がり、飛んだ滴が落ちて地面に跡が残ります。コマはのけぞって戻ります |

使い方はほかの演出と同じです。✨ から**エフェクト集**を開き、**撃破**の系統から選んで、倒したコマをクリックしてください。

崩壊は4秒半かけてゆっくり崩れます。とどめの一撃に合わせて出すと間が持ちます。

**演出が終わるとコマは元に戻ります。** 倒れたコマを片づけるか、その場に残して「戦闘不能」として扱うかは、今までどおり自由に決められます。

コマに**画像を設定していない場合**は、崩壊と両断は光の欠片が砕ける形になります。

詳しくは[マップ演出](/manual/map-effects#倒したとき)を参照してください。

## 🐛 不具合修正

- **保存したルームを読み込むと回復音が鳴り続ける問題を修正** … 読み込みでHPなどの値が入れ替わるのを、全員が「回復した」と受け取っていました。数字も一斉に飛び出していました。**自動保存の復元**でも、**参加者が合流したとき**でも起きていた問題です。人が値を変えたときだけ演出が出るようになりました
- **v1.26.0より前に保存したルームを読み込むとエフェクト集が空になる問題を修正** … 演出がまだ無かった頃のルームを読み込むと、既定のエフェクトごと消えていました。読み込んだルームに演出が入っていなければ、既定のものが戻ります

# v1.52.0

2026-09-11リリース

地形の高さが遊びの中で意味を持つ版です。コマは箱の上に登り、隙間があれば橋の下をくぐります。崖のように「登れない」と決めた地形は、乗り越えられない壁になります。

もうひとつ、パネルをタブでまとめられるようになりました。チャットとキャラクターシートを1枚の枠に畳んで、名前をクリックして切り替えます。

## 📑 パネルをタブでまとめる

パネルのタイトルバーを、別のパネルのバーへドラッグして落とすとまとまります。上に名前が並び、クリックで切り替わります。

名前を枠の外へ引っぱると、そのパネルだけが出ていきます。中身はそのままです。チャットの読みかけの位置も、打ちかけの一行も、移した先へついていきます。

まとめた枠には、いま見せているタブのものが使われます。名前もボタンも、透明度の設定も、そのタブの種類のものです。チャットを見ているときはチャットの透明度、シートを見ているときはシートの透明度になります。

枠ごと別ウィンドウへ出すこともできます。出したときの大きさと位置のまま開き、ウィンドウを閉じると元の場所へ戻ります。

## ⛰️ 地形の下をくぐる

これまで、コマをドラッグすると目の前の地形にすぐ登ってしまい、下へ回り込めませんでした。

頭上に隙間のある地形なら、その下を通れるようになりました。橋やアーチの下に立たせられます。地面に置かれた箱には、これまでどおり登ります。

掴んだままマウスホイールを回すと、その場所にある足場を上下に辿って乗り移ります。ホイールを1ノッチ回すと足場を1つ移るので、宙に浮いた岩の上にもこれで置けます。

視界と光もこれに対応しました。浮いた地形の下に立つと、足元の霧が晴れ、そばのランプの光が届きます。

## 🦘 高いところへ跳ぶ

[厳密な移動](/manual/move-range#厳密な移動)で線を引いているあいだに**スペース**を押すと、跳び越えに切り替わります。登れない地形を除いて、高さに関わらず行き先に選べるようになります。

範囲の色が紫に変わるのが目印です。もう一度押すと歩きに戻ります。

跳ぶと決めた道すじでは、コマが手前のマスから跳んで着地します。着地したコマは地形の上に立ちます。降りるほうは切り替え不要で、段の下は歩きのままでも行き先に選べます。

画面の下に出る帯からも選べます。**歩く**と**跳ぶ**が並んでいて、いま選ばれているほうに色が付きます。指で操作するときはこちらを使ってください。帯の説明文も、タッチのときはタップと長押しの言い方に変わります。

## 🧗 登れない地形

地形の右クリックメニューに **「登れない」** が増えました。崖、ガラス、堀のように「向こう側へ行けない」ものを表すための設定です。既定は切です。

入れると、その地形はこう変わります。

- コマは天面に乗りません。脇の地面に留まります
- ドラッグすると、コマは手前の面で引っかかって止まります
- [移動範囲](/manual/move-range)では、越えられないマスとして数えます
- 扉は開いていれば通れます。閉じているあいだだけ壁と同じです

1マスの隙間は、1マスのコマがそのまま通れます。壁の間を抜ける道はふさぎません。

GMだけは例外で、そのまま越えて動かせます。地形そのものを組んでいるときも引っかかりません。

同じ設定は[マップエディター](/manual/map-editor)の機能塗りからも、ダンジョン生成の**壁を登れなくする**からも入れられます。生成したダンジョンの壁と扉をまとめて登れなくできるので、石壁で仕切られた場所として遊べます。階段は登るためのものなので、そのままです。

## 🚪 ダンジョンの扉を広くする

生成する扉の幅を、**最小**と**最大**で1〜4マスから決められます。既定はどちらも1マスで、これまでと同じ見た目です。

2マス以上にすると、扉が入るぶんだけ入口の壁を削ります。**両開きの割合**を上げると、幅を半分に割った2枚の扉になります。幅4なら2マスの扉が2枚です。

## ☑️ 表の列をまとめてチェック

技能表のように、列いっぱいにチェックボックスが並ぶ表で、見出しから列全体をチェックできるようになりました。一部だけ入っているときは見出しのボックスが半分塗りになるので、下の状態がひと目で分かります。

## 📦️ 地形の床

地形に床が表現できるようになりました。今まで地形オブジェクトは、軽量化のために5面しか描いていませんでした。今回のリファクタリングで地形全体を描いても問題がなくなったため、地形は完全に覆われるようになりました。

## 🐛 直った不具合

**ライトモードで文字が読めない箇所**をまとめて直しました。直したのは、移動中に出る操作説明、キャラクターシートの編集ボタン、設定の注意書き、カードやマップマスクの名前です。どれも暗い画面向けの色のままで、明るい配色では背景に溶け込んでいました。警告表示のための色をスキンに足し、明るくても暗くても読めるようにしています。

**コピーした光源が、部屋のすべてのテーブルに出ていました**。コピーは元の情報だけから作られるので、どのテーブルの子でもない状態になり、テーブルを持たない光源は「いま見ているテーブルに出す」扱いになるためです。コピー元と同じテーブルに置かれるようになりました。まとめてコピーしたときも同じです。

**何かに載せた地形が、床にあるものとして視界を遮っていました**。台の上に置いた木箱や、重力で壁の上に落ち着いた地形で、載った高さのぶんが無視されていました。リプレイでも同じでした。

そのほか、次のものを直しました。

- マップエディターの機能塗りで置いた地形が、高さを失って床に落ちることがあった
- 1マスが50ピクセルでないテーブルで、地形の高さや厚みが違う縮尺で読まれ、めり込んだり浮いたりしていた
- 台座に載せた壁が、地上の視線を素通しさせていた
- ダンジョンの概要で、幅を広げた扉1枚が「扉4」と数えられていた

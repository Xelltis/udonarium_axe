# v1.71.1

2026-10-26リリース

Axeを組み立てる道具を新しい版にしたリリースです。画面や操作の変更はありません。

## 🔧 Angularの更新

YouTubeのプレイヤーと、Axeを組み立てるビルドの道具を、Angular 22.2.4にしました。ビルドの道具の修正には、3Dダイスやリプレイ動画の書き出しで裏で動く処理（Web Worker）のファイルに、区別できる名前を付ける修正が含まれます。

## ⚠️ 以前の版との互換

部屋のデータは変わりません。v1.71.0の人とも、今までどおり同じ部屋で遊べます。

# v1.28.0

2026-08-06リリース

**ターゲット表示**を作り直した回です。小さな黄色い矢印だったものが、コマの足元で明滅する**赤いリング**と、頭上に浮かぶ**TARGET**バッジの2段構えになりました。

## ✨ 新機能・改善

### ターゲット表示の刷新

コマを**Alt + クリック**すると、そのコマが「ターゲット中」になります。もう一度Alt + クリックで解除、**Shift + Alt + クリック**で全員ぶん解除、という操作はこれまでどおりです。変わったのは**目印の見た目**です。

|                  | 何が出るか                                                                                 |
| ---------------- | ------------------------------------------------------------------------------------------ |
| **台座のリング** | コマの足元が赤く縁取られ、ゆっくり明滅します。四角グリッドでもヘクスでも台座の形に沿います |
| **TARGETバッジ** | 頭上（バフ表示より上）に赤いバッジが浮かび、上下にゆっくり揺れます                         |

これまでの黄色い矢印は20×32ピクセルの小さな画像で、卓を引くと何が起きているのか判別できませんでした。今回から、**どのコマが狙われているか**は足元のリングで、**それが何の状態なのか**は頭上のバッジで分かります。

バッジは**カメラを傾けても回してもコマの中心線から外れません**。テーブルを回すと頭上の表示が左右にずれて見える問題を、バッジについては解消しています。

リングは立ち絵に一切かぶらないので、狙われているコマが増えても卓が見づらくなりません。

## 🐛 不具合修正

- **バフを隠しているキャラクターにターゲット表示が出ない問題を修正** … バフを持っていて「バフを隠す」を設定したコマは、Alt + クリックしても目印がまったく出ていませんでした。目印はバフの表示設定と関係なく出るようになりました

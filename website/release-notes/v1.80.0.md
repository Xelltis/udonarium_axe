# v1.80.0

2026-11-17リリース

射程範囲を立体にできるようになりました。形は柱・球・円錐・直線の4つで、宙を飛ぶコマも含めて、範囲に入るかを高さまで見て決めます。コマに追従させた球と柱はそのコマのまわりの半球の中を動かせ、円錐と直線は上下にも向けられます。

卓の上の2点のあいだを測る物差しも入りました。高さの違う点のあいだも直線・水平・高さの差とマス数で測れます。引いている物差しは同じテーブルを見ているほかの人にも見え、卓に置いて残すこともできます。

## 🧊 立体射程

射程範囲は平面のほかに、柱・球・円錐・直線の立体にできます。柱はどの形からでも作れます。球は円形から、円錐はコーンから、直線は直線から作れます。立体は卓の上に半透明で描かれ、ダンジョンドリィマスターモードの目線からも見えます。

卓の右クリックの**立体射程を作成**から置けます。置いてある射程は右クリックの**立体**で、立体にしたり平面に戻したりできます。射程範囲設定のパネルには、立体の種類と高さ・届く距離・仰角の欄が増えました。PLツールバーの射程の一覧とホットバーの範囲の枠からも、立体射程を出せます。

立体射程をコマに追従させると、そのコマが発動者になります。球と柱は発動者の足元を中心にした半球の中を動かせ、外へ引くと外周に沿って滑ります。円錐と直線は発動者の体の真ん中から伸び、先端のハンドルで上下左右に向けられます。

立体射程の**範囲内を対象にする**は、すべての形で使えます。コマの足元から頭までのどこかが立体に入っていれば範囲内なので、低い柱の上を飛ぶコマは数えません。平面の射程の判定はこれまでと変わりません。

くわしくは[射程範囲](/manual/range#立体射程)にあります。

## 📏 物差し

ツールバーの**物差し**か`M`キーで物差しを持ち、卓をドラッグすると2点のあいだを測れます。コマの右クリックの**ここから測る**を選ぶと、そのコマから測り始めます。線の上と画面の下の帯に、直線・水平・高さの差と、部屋設定の**斜め移動**の数え方で数えたマス数が出ます。部屋設定の**マスの単位**がメートルかフィートなら、直線・水平・高さはその単位の長さで出ます。

コマの上から引いた端はコマにつながり、コマの高度も測る高さに入ります。ホイールで先の端を上下すれば、宙の点までの距離も測れます。引いている物差しは同じテーブルを見ているほかの人にも名前つきで見えます。端が見えないコマにつながっていたり霧で隠れた場所にあったりする物差しは、その端が見えない人には見えません。

帯の**置く**を押すと、物差しを卓に置いて、全員に見えるように残せます。置いた物差しは部屋の保存に入り、端を置き直したり、右クリックで消したりできます。

くわしくは[物差し](/manual/ruler)にあります。

## ⚠️ 以前の版との互換

v1.79.0以前の人とも同じ部屋で遊べます。ただし、その人の画面では立体射程が同じ形の平面の射程に見え、置いた物差しと引いている物差しは出ません。v1.79.0以前の版は置いた物差しを読み飛ばすので、その版で部屋を保存し直すと、置いた物差しは消えます。

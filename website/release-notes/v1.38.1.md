# v1.38.1

2026-08-16リリース

前の版（v1.38.0）で入り込んだ、**エフェクトが卓から消えることがある問題**の修正だけの版です。
新しい機能はありません。

エフェクトの受け渡しを使った方、エフェクトを含む部屋データを読み込む方は、**v1.38.0のまま
使わないでください**。

## 🐛 修正

### 読み込んだエフェクトが、卓から消えることがあった問題

v1.38.0から、エフェクトのファイルにはエフェクトごとの識別子が入るようになりました。同じものが
戻ってきたときに元のエフェクトへ重ねるための仕組みですが、**一度卓から削除したエフェクトが同じ
識別子で戻ってくる**場合に問題がありました。

他の参加者の手元には「そのエフェクトは削除済み」という記録が残っています。そこへ同じ識別子の
エフェクトが現れると、他の参加者の側では削除の取りこぼしと見なし、削除を送り返します。結果として、**読み込んだ本人の
手元からもエフェクトが消えます**。

エフェクトを含む部屋データの読み込みも同じ処理を通っていました。部屋の読み込みは先に手元の
エフェクトを片付けてからファイルの中身を読むので、**読み込んだエフェクトがまとめて消える**
可能性がありました。

これからは、卓で削除した識別子だけは引き継がず、**新しいエフェクトとして入ります**。同じ名前の
エフェクトがあれば中身が入れ替わるので、増えることもありません。

1人で開いているとき（他の参加者がいないとき）には起きない問題でした。

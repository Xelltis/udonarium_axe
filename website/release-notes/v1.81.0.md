# v1.81.0

2026-11-19リリース

マップ生成のダンジョンに、雰囲気「下水道」が入りました。通路の中央を汚水の水路が流れ、部屋は集水槽になり、壁の排水管から水が落ちます。

水が流れ落ちる表現も入りました。流れのある水は流れの先にある低い水へ滝になって落ちます。下水道だけでなく、どのテーブルの水域でも同じです。

マップ生成の農村には、小川と水車小屋と風車が加わりました。水車の輪と風車の羽根は回ります。

## 🚰 下水道

<Shot src="sewer" alt="レンガの壁の下水道。通路の中央を暗い水が流れ、両脇が歩道になっている。奥の部屋は集水槽で、左右の壁の排水管から水が落ちている" caption="通路の中央が水路、部屋が集水槽になります" />

[マップ生成](/manual/map-generator#下水道の水)のダンジョンの雰囲気で**下水道**を選ぶと、レンガの壁の下水道が1枚できます。通路は3マス幅で、中央の1マスが水路、両脇が歩道です。水路は歩道より低く掘ってあり、集水槽へ向かって流れ、流れ出る手前で堰を越えて落ちます。

「集水槽」と「沈殿槽」の部屋には、壁沿いの縁を残して水が溜まります。集水槽の壁には排水管が立ち、口から水が落ちます。「ポンプ室」と「作業室」には、壁に沿って配管が1本につながって走り、ところどころにバルブが付きます。「密輸品の隠し場」の木箱と、あちこちの樽は、部屋の隅に寄せて積まれます。扉は上へ開く鉄格子、明かりは壁のランタン、入口ははしごです。

水のマスは、入ると移動コストが1増えます。手番の始めに水の中にいるコマは、1d6のダメージと状態異常「毒」を受けます。「汚水」という名前の、全員に見える仕掛けとして置かれるので、量や状態異常はテーブルの上で変えられます。どの部屋にも水に入らずに歩いて行けます。

## 💧 落ちる水

<Shot src="waterfall" alt="高い池の水が、手前の低い池へ白い帯になって流れ落ちている。落ち口と着水のところに白い泡が立ち、低い池に波紋が広がっている" caption="流れのある水は、流れの先にある低い水へ落ちます" />

水面の高さが違う水域を隣り合わせに置き、高いほうに流れの速さと、低いほうへ向かう流れの向きを付けると、境目で水が流れ落ちます。落ち口と着水のところに泡が立ち、下の水面に波紋が広がります。水面の差が0.25マス以上あることと、流れが境目を越える向きであることが条件です。

流れのない水は落ちません。水面の高さだけが違う池を並べた地図は、今までどおりに見えます。

同梱の3Dモデルに**排水管**が増えました。排水管で描いた地形は口から水を落とします。口の先に水があれば水面まで、なければ床まで落ちます。口の先に水から出たブロックがあれば、その上に落ちます。マップエディターの[3Dオブジェクト塗り](/manual/map-editor#_3dオブジェクト塗り)で、好きな壁に置けます。

くわしくは[水域と水中](/manual/water#落ちる水)にあります。

## 🌾 村の小川と水車と風車

<Shot src="village-mills" alt="農村を上から見たところ。家と畑のあいだを小川が流れ、道の所は橋になっている。小川の岸に水車小屋が、道ばたに風車が立っている" caption="農村には小川が流れ、水車小屋と風車が立ちます" />

[マップ生成](/manual/map-generator#小川・水車小屋・風車)のフィールドの雰囲気**農村**に、流れる小川が1本通るようになりました。小川は家と畑を避けて曲がり、道とぶつかる所は橋になります。岸には水車小屋が、空いた所には風車が立ち、輪と羽根が回ります。

道・家・畑の並びは、同じシードなら今までと同じです。小川が通るぶん、木と茂みの位置は変わります。家や畑が詰まっていて通り道がない村には、小川と水車小屋は置かれません。

風車と水車小屋は、同梱の3Dモデルにも加わりました。マップエディターの[3Dオブジェクト塗り](/manual/map-editor#_3dオブジェクト塗り)で置いても、羽根と輪は回ります。演出を減らす設定にしている席では止まって見えます。

## 🤖 AIのアプリでAI GM

[AI連携（MCP）](/manual/ai-link)でつないだClaude CodeなどのAIのアプリに、[AI GM](/manual/ai-gm)としてGMをさせられるようになりました。AI GMのパネルはAI連携のパネルにまとまり、**GMを任せる**のタブになりました。Claude APIのキーは要らず、AIを動かす料金はAIのアプリの契約にかかります。

- メニューの**AI連携**を開き、**GMを任せる**のタブで**始める**を押し、AIのアプリで`/mcp__axe__run_ai_gm`を実行します。AIは自分の番が来るまで待ち、番が来ると起きたことと指示とメモを受け取って動きます
- 出番・聞くタブ・呼び名・進めてもらう・止めるは、APIキーで動かすときと同じに効きます
- モデル・考える深さ・使用額の上限はAIのアプリの側で決めます。AIが番を待っていないときは、パネルにそう出ます
- メニューの「AI GM」は「AI連携」にまとまりました。つながっているかと、AIに許すこと（読むだけ・書くことも許す）は、パネルの上にいつも出ます。メニューを自分で並べ替えていて「AI GM」を置いている場合は、そのまま**GMを任せる**のタブを開く項目として使えます

くわしくは[AIのアプリにAI GMをさせる](/manual/ai-gm#aiのアプリにai-gmをさせる)にあります。ブリッジ（`axe-mcp.mjs`）はこの版のものに替えてください。前の版のブリッジにはつながりません。

## 📝 そのほか

- AI GMがAPIキーを断られて止まったとき、パネルに止まった理由ではなくキーの作り方の説明が出ていたのを直しました
- チャットのログを、途中から前だけ消せるようになりました。発言を右クリックして「この発言より前のログを消去」を選ぶか、タブ設定の「ログ消去」で日時を入れます。前回のログを残したまま卓を始めてしまったときに使えます（[ログを消去する](/manual/chat#ログを消去する)）
- ログの消去は、自分に見えている発言だけを消すようになりました。タブ全体を消すときも同じです。GMが消しても、ほかの人どうしの秘話は残り、確認に出る件数にも数えません
- [AI GM](/manual/ai-gm)が、聞くタブに選んでいないタブの発言に応えることがあったのを直しました。呼び名（初めは「GM」）を含む発言なら、どのタブでも呼ばれたものとして動いていました。聞くタブを選ぶと、ほかのタブの発言と、そこで振ったダイスの結果はAIに届かなくなります。AIの席への秘話と「システム」タブの知らせは、どのタブを選んでも届きます
- 同梱の3Dモデルに、樽・鉄のはしごと、つなげて敷ける配管の部品（直管・バルブ付き・曲がり・端）が増えました。壁のテクスチャには「下水道のレンガ壁」が増えました
- 地面の起伏がある農村で、水田に水が張られていなかったのを直しました
- 斜面や迷路の壁、水際のふちに、細い線が出ることがあったのを直しました
- 動作の重い端末で、戦闘カットインのダメージの数字が出ないまま終わることがあったのを直しました
- GPUを使えないブラウザで、エフェクト一覧からエフェクトを選ぶと画面が数秒固まることがあったのを軽くしました。プレビューは、初めて描く種類のエフェクトを先に組み立て、組み立て終わってから始めから再生します
- コマの詳細を横に出したまま、そのコマを動かすと、詳細が元の場所に残り、落とした先のコマに重なってコマをつかめなくなることがあったのを直しました。コマを動かすと詳細は閉じます
- メニューエディターでアイコンを選ぶとき、高さの低い画面で初めて開くと、一覧が自分のボタンに重なっていたのを直しました。一覧はボタンのすぐ下に出ます

## ⚠️ 以前の版との互換

v1.80.0以前の人とも同じ部屋で遊べます。ただし、その人の画面では水は落ちず、高いほうの水の横が動かない壁として見えます。排水管は置いたとおりに見えますが、水は落ちません。

v1.80.0以前の人の画面では、風車の羽根と水車の輪は回らず、作ったときの姿勢のままです。風車と水車小屋は、羽根や輪まで含めた大きさで枠に収められるので、ひとまわり小さく見えます。

下水道のテーブルはv1.77.0以降の版なら同じ形に見えます。地面の起伏を知らないそれより前の版では、床は平らなままで、水は床の上に乗って見えます。

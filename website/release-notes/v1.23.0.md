# v1.23.0

2026-08-02リリース

**ビジュアルノベルモード**を作り直した回です。GMが背景を差し替え、全員の画面を揃えて場面を見せられるようになりました。あわせて**重いルームでの自動保存と読み込み**に手を入れ、画像が数百枚あるルームでも操作が止まりにくくなっています。**ココフォリアのルーム取り込み**と**バフの残ラウンド自動減少**も入っています。

## ✨ 新機能・改善

### ココフォリアのルーム取り込み（実験的機能）

ココフォリアで書き出した**ルームデータzipをテーブルにドラッグ&ドロップ**すると、盤面ごと取り込めるようになりました。コマを1体ずつ移す[キャラクターの取り込み](/manual/character-import)に対して、こちらは卓そのものを持ち込みます。

取り込んだ結果はチャットにシステムメッセージとして流れ、何が入って何が入らなかったかを確認できます。ココフォリア側の仕様は公開されていないため**実験的機能**です。詳しくは[ココフォリアのルーム取り込み](/manual/room-import)を参照してください。

### バフの残ラウンドが自動で減ります

[行動順](/manual/turn-order#バフの残ラウンドを自動で減らす)でラウンドを進めると、コマに付いた[バフ](/manual/buff)の残ラウンドが1減り、0になったバフは自動で消えてチャットに通知されます。砂時計のアイコンで自動減少を切り替えられます。

### ノベルモードの演出

GMが[ノベルモード](/manual/visual-novel)専用の**背景画像**を指定できるようになりました。指定した背景は参加者全員に同期され、場面転換に合わせてフェードやワイプで切り替わります。解除すればテーブルの背景に戻ります。

- **表示レイアウト**を3種類から選べます … 立ち絵の上に出る**吹き出し**、画面下に固定する**ADV**ウィンドウ、長い文章を読ませる**全画面**
- **文字の読みやすさ**（なし / 弱 / 中 / 強）で、背景を暗くしてぼかす度合いを調整できます。参加者ごとの設定です
- 演出に**退場**が加わりました。指定した発言を最後にその立ち絵がステージから消え、再び発言すれば戻ります
- **BGM**をSEパネルから直接切り替えられます。ジュークボックス経由なので参加者全員に反映されます

### 上映モード

GMが**上映モード**を入れると、**GMがめくった位置に参加者全員の画面が追従**します。リプレイの読み合わせや、場面をそろえて見せたいときに使います。参加者は「自分で読む」でいつでも追従を外れ、「追従に戻る」で戻れます。

### ノベルモードの進行

- **オートプレイが現在地から始まります**。これまでは必ず最古の発言まで巻き戻っていました。巻き戻して再生したいときは隣の**最初から再生**を使います
- **対象のチャットタブを選べる**ようになりました。メインタブ固定ではなくなり、選択は次回も引き継がれます
- **キーボードで進行できます** … `Ctrl`を押している間はスキップ、`Home` / `End`で最古 / 最新へ、`A`でオートプレイ、`L`でログ、`S`で立ち位置ガイド。`?`で一覧を開けます
- **バックログを絞り込めます** … 自分の発言のみ / 演出付きのみ、そして「現在地へ」で表示中の行まで戻れます。発言が多いルームでは直近200件だけを描画し、残りは「さらに読み込む」で伸ばします

### 見やすさ・読み上げ

- **演出の強さ**に「控えめ」を追加しました。揺れや跳ねなど繰り返すアニメーションが止まります。OSの「視差効果を減らす」設定にも従います
- 表示中の台詞を**スクリーンリーダーが読み上げられる**ようになり、アイコンだけのボタンにも名前が付きました

### 重いルームでの保存と読み込み

画像が数百枚ある数十MBのルームで、[自動保存](/manual/save-load#自動保存)が操作を止めてしまう問題に対処しました。

- **コマをドラッグしている間は保存しません**。手を離したあと、ブラウザの処理に余裕ができるタイミングまで待ちます
- 保存に時間がかかるルームでは**保存の間隔を自動で広げます**
- 保存データの**圧縮と展開をバックグラウンドで処理**するようになりました。すでに圧縮済みの画像を圧縮し直すのもやめています
- 読み込み時に、保存データの画像を**変換し直さなくなりました**。取り込んだときに変換済みのものを、開くたびにやり直していました

## 🐛 不具合修正

- **文字送りで絵文字が壊れるのを修正** … ノベルモードの本文が1文字ずつ表示される途中で、絵文字が半分に割れて「�」になることがありました
- **場面転換の演出が正しく発火するように修正** … 背景の切り替え演出が、場面転換の発言ではなく「添付したSEを外したとき」に走っていました
- **スマートフォンで立ち絵と吹き出しが画面からはみ出すのを修正**
- **ホーム画面に追加したアプリのアイコン・名前が欠ける問題を修正** … 認証のあるサイトで`manifest.webmanifest`の取得が失敗していました

## 🔧 開発者向け

自分でビルドして使っている方向けの変更です。

- **ノベルモードのオーバーレイを分割** … 1000行を超えていたコンポーネントから、立ち絵の配置ロジック・再生制御・バックログをそれぞれ独立した単位に切り出しました
- **zipの生成と展開をWeb Workerへ移動** … メインスレッドでのCRC計算とアーカイブ組み立てが無くなります。ワーカーが使えない環境では従来どおりメインスレッドで処理します
- **サムネイル生成を`createImageBitmap` + `OffscreenCanvas`に変更** … 非対応環境はcanvas経由にフォールバックします
- **`xml-formatter`への依存を削除** … 保存するXMLの整形を自前の実装に置き換えました

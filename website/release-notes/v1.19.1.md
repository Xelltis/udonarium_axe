# v1.19.1

2026-07-18リリース

本家ユドナリウムのバックエンド（udonarium-backend）に**接続できないことがある問題**を修正するリリースです。

## 🐛 不具合修正

- **本家バックエンド（Cloudflare Workers版など）に接続できない問題を修正** … トークン取得のリクエストがブラウザのCORS事前確認（プリフライト）を伴う形式になっており、プリフライトに応答しないバックエンドでは接続がエラーになっていました。
  - まず従来どおりの形式で送り、失敗した場合は**プリフライトが不要な形式へ自動で切り替えて**再送します。
  - バックエンド側の変更や再設置は不要です。本家[udonarium-backend](https://github.com/TK11235/udonarium-backend)をそのまま設置している場合も、この修正だけで接続できるようになります（導入手順は[クイックスタート](/guide/quickstart)を参照）。

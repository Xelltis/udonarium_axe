# v1.18.0

2026-06-17リリース

他のツールで作ったキャラクターを**そのまま取り込んでキャラコマにできる**ようになった大型アップデートです。ココフォリアのコマや、キャラクター保管所・キャラクターシート倉庫・CharaXivのデータから、能力値やチャットパレットごとAxeに持ち込めます。

## ✨ 新機能・改善

### 他ツールのキャラクターを取り込めるように

- **取り込みパネル** … 画面左のFABメニュー（丸いハンバーガーボタン）に **「キャラ取り込み」** を追加しました。データを貼り付けて **「取り込む」** を押すと、テーブルにキャラコマが追加されます。
- **対応している取り込み元**
  - **ココフォリアのコマJSON** … 「ココフォリア用コピー」で出力したJSONを貼り付け。いあきゃら・Charaeno・ゆとシート・CharaXivなど、多くの作成サービスがこの形式の出力に対応しています。
  - **キャラクター保管所**（charasheet.vampire-blood.net）… JSON、またはキャラクターページの**URLを貼り付けると自動で取得**します。
  - **キャラクターシート倉庫**（character-sheets.appspot.com）… 同じくJSON / URLに対応します。
  - **CharaXiv** … 「ココフォリア用コピー」で出力したJSONを貼り付けます。
- **取り込まれる内容** … 名前・アイコン画像・HP / MPなどのリソース・能力値・メモ・[チャットパレット](/manual/chat-palette)。
- **ゲームシステム固有のデータも保持** … 技能・コンボ・武器などを、キャラクターシートのセクションとして展開します。クトゥルフ（CoC）では能力値（STR・CON…）や正気度（SAN）を読みやすいラベルで取り込みます。

::: tip 取り込み後の仕上げ
取り込み元の仕様によっては、アイコン画像が取得できなかったり、項目の見出しがサービス内部の名称のまま入ったりすることがあります。コマは作成されるので、[キャラクターシート](/manual/character)や[画像](/manual/images)パネルで整えてください。
:::

詳しい使い方と注意点は[キャラクターの取り込み](/manual/character-import)を参照してください。

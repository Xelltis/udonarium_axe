# v1.64.1

2026-10-10リリース

不具合修正のリリースです。v1.64.0では、ほかの人が作った部屋に入っても、その部屋にいる人とつながりませんでした。チャットの発言もコマの移動も相手に届かず、おたがいに自分の発言しか見えない状態になっていました。

## 🔌 部屋に入ると、先にいる人とつながります

v1.64.0では、ロビーのルーム一覧や招待リンクから部屋に入ると、部屋の名前は出るのに、先にいる人との接続が始まりませんでした。部屋に入れたように見えても、チャットの発言や卓の操作はどちらの側にも届きませんでした。

原因は、v1.64.0で再読み込みのあとに入り直せるようにしたときの誤りです。部屋の準備ができたという知らせを、自分の接続のものではないと判定していました。そのため、先にいる人へ接続する手順が飛ばされていました。今は知らせを正しく受け取り、部屋に入るとすぐに先にいる人とつながります。

## ⚠️ 以前の版との互換

直ったのは部屋に入る側の処理です。部屋に先にいる人がv1.64.0のままでも、あとから入る人がこの版を読み込んでいればつながります。反対に、v1.64.0のまま入ってくる人は、この版の人がいる部屋でもつながりません。

v1.64.0のまま部屋にいて、ほかの人とつながっていない人は、ページを再読み込みしてから、ロビーか招待リンクで入り直してください。入り方は[部屋とロビー](/manual/rooms#部屋に入る)を参照してください。

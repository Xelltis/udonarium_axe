# v1.66.0

2026-10-13リリース

敵と入り乱れて戦っている場所を、円の**交戦エリア**として卓に描けるようになりました。加わっているコマの数で大きさが変わり、近づいたエリアは1つにまとまり、片方の陣営がいなくなれば消えます。経路を決めて動かすときは、届く敵やエリアの側が移動に割り込んで止められます。射線を遮るものの確認、戦闘の始まりの並べ方、距離による修正の表示もそろえました。点と円で位置を管理して戦うルールを、部屋の設定と組み合わせて再現できます。

グリッドのない卓では、移動の経路を折れ線で引いて、メートルで数えられるようになりました。部屋で決めた移動の種類から、倍率や上限のついた移動も選べます。

コマをほかのコマに乗せて、**乗り物**として一緒に動かせるようになりました。乗り物と乗り手は同じ手番に動き、転んだり倒れたりすると乗り手が落ちて、落下距離がチャットに出ます。

ルビを親文字1文字ずつにも振れるようにし、ルビの見え方を読み手ごとに選べるようにもしました。

コマの絵の透明なところを押すと、後ろにあるコマを掴めます。

コマの右クリックメニューは、よく使う項目だけを残し、ほかを名前の付いたグループにまとめました。

## ⚔️ 交戦エリア

[部屋設定](/manual/room-settings)の**移動**タブで「交戦エリアを使う」に印を付けると使えます。同じ点にいる敵どうしで、コマのメニューの「交戦エリア」から「〇〇と交戦する」を選ぶと、その点を中心にエリアができます。コマを敵と同じ点に置いたときは、画面の下に出る**交戦する**からも始められます。

エリアの大きさは、加わっているコマの数で決まります。人数ごとの半径は部屋設定の表で変えられ、1つのコマを何人分と数えるかもシートの欄で決められます。エリアの中心がほかのエリアに入ると、2つは中心の真ん中で1つにまとまります。狭い場所では、GMがエリアを正方形にしたり、入れる人数に上限を付けたりできます。

エリアに加わっているコマは、離れると予告した次のラウンドまで動けません。ほかのコマがエリアに入ると、そこで止まって加わります。どちらも、自分の陣営が人数で十分に上回っていれば止められません。コマには「姿が見えない」「倒れている」「その場から動けない」の状態も付けられ、それぞれ止められ方や加わり方が変わります。同じ点にいる敵をつかんで、逃がさないようにもできます。

最初のルームのサンプルのコマで、そのまま交戦エリアを試せます。

くわしくは[交戦エリア](/manual/engagement-zone)にあります。

## 📏 移動の種類と折れ線の経路

部屋設定の「移動の種類」に「名前:倍率:上限(m)」を並べると、移動の計画を開いたときに種類を選べます。移動力にその倍率を掛け、上限があればそこで止めた長さだけ動けます。

部屋設定で「グリッドなしの卓では、経路を折れ線で引く」に印を付けると、グリッドのない卓では計画がマスではなく折れ線になり、長さをメートルで数えます。右クリックで曲がり角を決め、残りの距離で届く範囲が円で出ます。

くわしくは[移動の種類を選ぶ](/manual/move-range#移動の種類を選ぶ)と[グリッドのない卓で折れ線を引く](/manual/move-range#グリッドのないテーブルで折れ線を引く)にあります。

## ✋ 移動の割り込み

部屋設定で「移動の割り込みを使う」に印を付けると、経路を決めて歩かせる前に、その経路に届く敵の側へ割り込むかどうかを尋ねます。尋ねられるのはコマの持ち主で、持ち主のいないコマはGMが答えます。割り込むと、その地点で移動が止まり、割り込んだコマと一緒に新しい交戦エリアができます。

交戦エリアに入る移動や、エリアの中に立っているだけのコマが動く移動も、止めるかどうかをエリアの側が選びます。止めると、動いたコマはエリアの中心に移って加わります。2つのエリアのコマで一緒に止めたときは、どちらのエリアに引き込むかを選べます。計画の帯の**止められない移動**を押した移動は、誰にも止められません。

くわしくは[移動の割り込み](/manual/engagement-zone#移動の割り込み)にあります。

## 🎯 射線チェックと範囲の中のコマ

ターゲットにしているコマがあるとき、コマのメニューの「射線チェック」で、ターゲットまでの距離と、射線を遮る交戦エリアや敵のコマが一覧で出ます。エリアの外からエリアに加わっているコマを撃つときは、当たりうる相手が並び、**無作為に選ぶ**でダイスボットに1人選ばせられます。

円形・直線・四角形の射程範囲は、右クリックの「範囲内を対象にする」で、範囲に入っているコマをまとめてターゲットにできます。

くわしくは[射線チェック](/manual/engagement-zone#射線チェック)と[範囲の中のコマを対象にする](/manual/range#範囲の中のコマを対象にする)にあります。

## 🗺️ 戦闘の始まりの並べ方

GMはコマのメニューの「初期配置」で、相手の陣営の先頭と、距離と向きを決めて、両方の陣営を一度に並べられます。部屋設定の「距離による修正表」を書いておくと、先頭どうしの距離にあたる行が出ます。表には、距離のかわりに状況の名前を書いた行も入れられ、当てはまるものに印を付けてチャットで知らせられます。

くわしくは[初期配置](/manual/engagement-zone#初期配置)にあります。

## 🐎 乗り物に乗る

コマのメニューの**乗り物**で「乗り物にする」に印を付けると、そのコマに乗れるようになります。コマを掴んで乗り物の上に置くと、画面の下に**乗る**が出て、押すと乗り手になります。乗り物の設定によっては、後ろに同乗したり荷物として積まれたりもできます。降りるときは、乗っているコマを乗り物から離れたところに置きます。乗っているコマは乗り物の上に重ねて描かれ、3Dの卓では乗り物の上に立ちます。乗り物と乗っているコマの名前・ゲージ・バフは、どちらの絵にも重ならない1枚の札にまとめて出ます。

乗り手が移動の計画を開くと乗り物の計画になり、乗り物の移動力で数えます。歩き終えると、乗っているコマはみな同じ点へ運ばれます。部屋設定に乗り物を操る技能の欄を書くと、技能のないコマは前に乗れる乗り物が限られます。

行動順を回しているあいだ、乗られている乗り物と同乗しているコマは、乗り手の手番に一緒に動きます。乗り降りは1つの手番に1回まで、乗り物が動けるのは1つのラウンドに1つの手番だけです。交戦エリアでは、乗り物と乗り手を合わせて1つと数えます。

コマには「転んでいる」の状態も付けられます。乗り物や乗り手が転ぶか倒れると、乗っているコマが自動で落ち、乗り物が動いていた長さから落下距離を出します。部屋設定に式を書けば、落ちたコマの名前でダメージを振れます。ふたり乗りのあいだだけ付けるバフも、部屋設定に書けます。

くわしくは[乗り物に乗る](/manual/ride)にあります。

## 🔤 ルビの振り方と見え方

ルビの記法で、親文字1文字ずつにルビを振れるようになりました（モノルビ）。`|漢字《かん|じ》`のように、ルビを`|`で区切ります。区切らなければ、これまでどおり親文字のまとまりに振ります（グループルビ）。

親文字とルビの長さが違うときは、短い方の文字の間を1：2：1で空けて割り付けるようにしました。この見え方は、チャット設定の**ルビ**で読み手ごとに変えられます。中付きか肩付きか、詰めて中央に寄せるか、ルビの大きさ、括弧で添えるか振らないかを選べます。チャットのほか、ノベルモード・共有メモ・書き出すログでも同じ見え方になります。

くわしくは[ルビ（ふりがな）](/manual/chat-syntax#ルビ-ふりがな)にあります。

## 📋 右クリックメニューの整理

コマの右クリックメニューには、移動・詳細を表示・チャットパレット・リモコン・固定・コピー・ターゲットだけをそのまま並べました。乗り物の上にいるコマや乗っているコマには、乗り降りの項目も移動の下に並びます。ほかは「バフ・演出」「視界と視点」「交戦エリア」「表示と扱い」「駒の状態」「乗り物」「公開とオーナー」「しまう」のグループにまとめてあり、ポインタを重ねると開きます。GMのメニューの最後には、初期配置やエリアの形・定員を変える「交戦エリアの管理」を置きました。

画面の右端で開いたメニューのグループは、右に入りきらないときは左に開くようにしました。これまでは親のメニューに重なって開き、ポインタの通り道の項目まで開いてしまうことがありました。

くわしくは[コンテキストメニュー](/manual/character#コンテキストメニュー)にあります。

## 🖼️ コマの絵の透明なところ

コマの画像の透明なところは、押しても素通りするようになりました。大きなコマの絵のすき間から後ろのコマが見えていれば、そこを押すと後ろのコマを掴めます。そのコマ自身を掴むときは、絵の描かれているところか、台座や名前を押します。

くわしくは[作成と配置](/manual/character#作成と配置)にあります。

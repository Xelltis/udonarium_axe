# v1.62.1

2026-10-08リリース

不具合修正のみのリリースです。YouTubeの動画を使ったカットインが、v1.49.0から再生されなくなっていました。

## 🐛 YouTubeのカットインがまた再生されます

YouTubeの動画を設定したカットインを流すと、ウィンドウには動画のサムネイルと再生ボタンが出るだけで、動画が始まりませんでした。v1.49.0で、カットインを卓の各席へ同時に出すときに、ウィンドウがそろってから再生を始めるようにしました。そのときの変更が原因です。

今は、カットインを流すと動画もそのまま始まります。一覧からの再生、チャットからの起動、テーブルを切り替えたときの再生のどれでも同じです。

動画の音量には、v1.62.0で入った[音の設定](/manual/sound-settings)の「カットイン」と、部屋の音量も掛かります。

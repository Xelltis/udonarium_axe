# v1.62.1

2026-10-08リリース

不具合修正のリリースです。YouTubeの動画を使ったカットインが、v1.49.0から再生されなくなっていました。
あわせて、ジュークボックスのシャッフルとリピートはGMだけが切り替えられるようにし、切り替えた人の名前をシステムタブに出すようにしました。

## 🐛 YouTubeのカットインがまた再生されます

YouTubeの動画を設定したカットインを流すと、ウィンドウには動画のサムネイルと再生ボタンが出るだけで、動画が始まりませんでした。v1.49.0で、カットインを卓の各席へ同時に出すときに、ウィンドウがそろってから再生を始めるようにしました。そのときの変更が原因です。

今は、カットインを流すと動画もそのまま始まります。一覧からの再生、チャットからの起動、テーブルを切り替えたときの再生のどれでも同じです。

動画の音量には、v1.62.0で入った[音の設定](/manual/sound-settings)の「カットイン」と、部屋の音量も掛かります。

## 🔁 シャッフルとリピートはGMだけが切り替えます

BGMの1曲リピートが、流している途中でいつのまにか解除されているという報告がありました。ジュークボックスには、リピートをひとりでに解除する処理はありません。切り替わるのは、だれかがリピートのボタンを押したときだけです。ミニプレイヤーでは、このボタンが音量のスライダーのすぐ左にあります。

シャッフルとリピートは部屋の全員にかかる設定なので、部屋の音量と同じく、GMだけが切り替えられるようにしました。プレイヤーの画面では、ボタンが薄く表示されて押せません。再生・一時停止・曲送りは、これまでどおりプレイヤーも使えます。

GMが切り替えると、チャットの[システムタブ](/manual/chat#システムタブ)に「〇〇 さんがジュークボックスのリピートを解除しました。」のように、名前と新しい設定が出ます。

[見学](/manual/roles)のときは、部屋の曲や環境音を流したり止めたりすることも、再生リストを編集することもできなくなりました。試聴と自分の音量は、これまでどおり変えられます。

古い版のままの参加者の画面では、これまでどおりだれでも切り替えられ、システムタブにも出ません。全員が新しい版を読み込めば、どの画面でも同じ制限になります。

# v1.63.0

2026-10-09リリース

チャットの発言に**しおり**を挟めるようになりました。聞き込みで出た証言のように、あとで読み返したい発言へ、一覧からすぐ戻れます。しおりには、部屋の全員に見える共有しおりと、自分にだけ見える個人しおりがあります。

全員に向けて送った自分の発言は、あとから特定の相手への秘話に変えたり、チャットから削除したりできるようになりました。削除した発言はチャットからは消えますが、ログには残ります。ログを書き出すときに、削除した発言を外すこともできます。書き直した発言は、前の文面を編集履歴として残すようになりました。

発言の操作のボタンは、吹き出しの右上に浮かぶツールバーにまとめました。ボタンが行の場所を取らなくなったので、狭いウィンドウでも発言の並びがずれません。

## 🔖 発言にしおりを挟む

発言にマウスを置き、ツールバーのしおりのボタンを押すと、共有しおりか個人しおりを挟めます。発言のメニューにも「共有しおりを挟む」「個人しおりを挟む」があります。挟んだ発言には、名前の横に印が付きます。

- 共有しおりは部屋の全員に見え、部屋データにも保存されます
- 個人しおりは自分にだけ見えます。このブラウザに保存され、ほかの人には送られません。同じブラウザで部屋データを読み込み直すと、また出てきます

タブの並びの右にある**しおり**ボタンを押すと、全タブのしおりが発言の順に並んだ一覧が開きます。ボタンの横の数字は、自分に見えているしおりの数です。項目を押すと、その発言のタブに切り替わり、発言が窓の中央に来て一瞬光ります。長いログの、画面に出ていない古い発言にも戻れます。

- しおりの題名は、最初は発言の書き出しです。鉛筆のボタンで「事件の証言A」のように付け直せます
- 一覧の上の切り替えで、共有と個人のどちらかだけに絞れます
- 発言が消えると、しおりも消えます。ログの消去やタブの削除で消えたときも同じです
- 自分に見えない発言のしおりは、一覧に出ません
- [見学](/manual/roles)は共有しおりをたどれますが、挟む・外す・題名を変えることはできません。個人しおりは見学でも使えます

くわしくは[しおり](/manual/chat#しおり)にあります。

## 🤫 送った発言を、あとから秘話にする

全員に向けて送った自分の発言を、あとから秘話に変えられるようになりました。発言のメニューの「あとから秘話にする」から、相手を部屋の参加者から1人選びます。

あとから秘話にした発言は、ふつうの秘話と同じになります。名前は「アリア > ノア」のように相手付きになり、自分と相手のチャット画面にだけ出ます。ほかの人のチャット画面やログからは消えます。

- 選べる相手は、その発言のタブを読める人だけです
- 同じメニューから別の相手に選び直したり、「あとから秘話をやめて全員に戻す」で元に戻したりできます
- 初めから秘話として送った発言、ダイスの結果、システムメッセージは対象外です
- 秘話の相手でない人には、この発言への返信や引用にも中身が出ません

くわしくは[あとから秘話](/manual/chat#あとから秘話)にあります。

## 🗑️ 発言を削除する

自分の発言を、チャットから削除できるようになりました。ツールバーのごみ箱のボタンを押すか、メニューの最後の「削除」を選び、確認で「削除」を押します。

削除した発言は、自分を含む全員のチャット画面から消えます。元に戻す手段はありません。ただし部屋のデータには残るので、保存した部屋データにも、書き出したログにも入ります。ログでは「(削除済)」の印が付きます。

- ティッカー、ノベルモード、配信用の透過画面、発言の検索にも出ません。未読の数や、タイトルの発言数にも数えません
- この発言への返信や引用にも、中身が出なくなります
- ダイスの結果とシステムメッセージは削除できません

ログを書き出すときに、タブ設定かプレビューで**削除した発言をログに出力しない**にチェックを入れると、削除した発言と、その発言に添付した画像を外せます。既定はオフで、この設定はこのブラウザに保存されます。

くわしくは[発言を削除する](/manual/chat#発言を削除する)と[ログの書き出し](/manual/chat#ログの書き出し)にあります。

## 📝 発言の編集履歴を見る

自分の発言を書き直すと、書き直す前の文面が時刻と一緒に発言に残るようになりました。「(編集済)」を押すか、メニューの「編集履歴を見る」を選ぶと、発言の下に最初の発言から今の文面までが順に並びます。

- 編集履歴は、その発言が見える全員が見られます。部屋データにも保存されます
- ノベルモードのログから書き直した場合も残ります
- 残すのは書き直し50回分までです。超えると、最初の発言は残したまま、古い書き直しから消えていきます
- この版より前に書き直した発言には、履歴が残っていません。もう一度書き直すと、その前の文面は「履歴を残す前に編集された文面」として時刻なしで残ります

くわしくは[編集と編集履歴](/manual/chat#編集と編集履歴)にあります。

## 🧰 発言の操作をツールバーにまとめる

発言の操作のボタンは、これまで発言の見出しに最大9個並んでいました。隠れているときも場所を取っていたため、狭いウィンドウでは見出しが行ごとに違う位置で折り返し、発言の並びがずれていました。

今は、発言にマウスを置くと、吹き出しの右上にツールバーが浮かんで出ます。行の高さや並びは変わりません。

- ツールバーには、返信・引用・しおりと、自分の発言なら編集・削除が並びます。削除のボタンは、マウスを重ねると赤くなります
- いちばん右の「…」で、すべての操作が入ったメニューが開きます。発言を右クリックしても同じメニューが開きます
- メニューは、返信・引用、文字のコピー、しおりやメモなど残す操作、前後を読む操作、自分の発言への操作、削除の順に並べ、区切り線で分けました。削除は押し間違えないよう、最後に離して置いています
- スマートフォンやタブレットでは、発言を長押しするとメニューが開きます
- 見出しは1行に収まります。狭いときは時刻などから縮み、発言者の名前は最後まで残ります
- [見学](/manual/roles)でも、発言のメニューを開けるようになりました。出るのは、本文のコピーや個人しおりなど、見学でもできる操作だけです

くわしくは[発言の操作](/manual/chat#発言の操作)にあります。

## 🐛 直った不具合

- メニューの中で選べない項目が、ほかの項目と同じ見た目で出ていて、押すとメニューが閉じていました。公開範囲の「他の参加者がいません」や、「この地点を中心にパーティを配置」に出るメンバーのいないパーティがこれに当たります。今は薄く表示し、押しても何も起きません

## ⚠️ 以前の版との互換

v1.62.3以前の版を使っている人がいると、次のようになります。

- あとから秘話にした発言は、その人にもふつうの秘話として届きます
- 削除した発言は、その人の画面には残ります
- その人には、共有しおりと編集履歴が見えません。その人が発言を書き直した分は、編集履歴に残りません

# v1.17.0

2026-06-14リリース

テーブルの**壁と地形の立体表現**を強化したアップデートです。壁にグリッドと座標を表示できるようになり、壁から突き出した地形を「梁」にしてキャラクターを乗せられるようになりました。地形は面ごとに別画像を設定でき、梁の天面・外側面にもグリッド座標を貫通表示します。

## ✨ 新機能・改善

### 壁にグリッドと座標を表示

- **壁にもグリッドが出る** … テーブル四方の壁に、床と同じグリッドが表示されるようになりました（スクエア／ヘクスの全グリッドタイプに対応）。テーブル設定の**グリッド常時表示**に連動します。
- **壁の座標ラベル** … 各マスに**壁の向き＋座標**（北壁＝`N`・東壁＝`E`・南壁＝`S`・西壁＝`W`、例: `N-1-1`）が振られ、壁面上の位置を共有しやすくなりました。

### 壁から伸ばした地形を「梁」にしてキャラを乗せられる

- 壁に貼り付けた地形が壁から室内へ突き出し、**「梁」** として使えます。
- **床のキャラクターを梁の上に乗せられます** … 床のコマを梁へドラッグ＆ドロップすると、梁の天面に乗ります。ドラッグ中も天面に追従し、離すとそのまま固定されます（重力で保持）。北・東・南・西すべての壁の梁に対応します。

### 地形を面ごとに違う画像で表示（6面個別画像）

- 地形の各面（**上面・北・南・東・西**）に、それぞれ別の画像を設定できるようになりました。地形シートの**面ごとの画像**から選べます。
- 画像を設定していない面は、従来どおり**床画像（上面）／壁画像（側面）** が使われます。**既存の地形の見た目は変わりません。**

### 梁にグリッドを貫通表示（床座標・壁座標）

- 地形の**グリッド貫通表示**をONにすると、梁にワールド座標のグリッドが出ます。
  - **歩ける天面** … 真下にあたる**床の座標**を表示。梁の上でもグリッドに合わせてコマを置けます。
  - **室内側の外側面** … 接している**壁の座標**（`N-…`など）を表示し、背後の壁グリッドと連続します。

詳しくは[地形](/manual/terrain)と[テーブル設定](/manual/table-setting)を参照してください。

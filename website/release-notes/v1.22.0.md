# v1.22.0

2026-08-01リリース

まるごと**スマートフォン対応**の回です。狭い画面には**専用のレイアウト**が用意され、コマのメニューは**長押し**で開き、**ホーム画面に追加**すればアプリのように起動します。サイトとチュートリアルに置いていた「スマートフォンは非推奨」の注意書きも外しました。

## ✨ 新機能・改善

### スマートフォン専用のレイアウト

幅768px未満の端末では、デスクトップの浮遊メニューやツールバーに代えて、**卓とチャットの上下分割**になります。指で操作する端末なら、横向きにして画面が低くなったときも切り替わったままです。

- 上が**テーブル**、下が**チャット**。境目のつまみをドラッグすると配分を変えられ、比率は次回も引き継がれます
- 下部のバーから**キャラクター**（[所有キャラクター一覧](/manual/pl-tools#所有キャラクター一覧)）と**メニュー**を開きます
- **メニュー**は画面の下から出るシートで、浮遊メニューとツールバーが持っていた機能がすべて入っています。接続・テーブル設定・画像・ジュークボックス・カットイン・インベントリ・コマを作る・キャラ取り込み・自動保存 / 復元・ノベルモード・操作中パレット・手札を開閉・保存・読込。ゲームマスター専用のもの（オブジェクト・同行・暗闇の切り替え・手番・マップエディター）は **「ゲームマスター」** の見出しの下にまとまります
- シートの一番下には**パソコン版の画面を使う**・テーマ・言語の切り替えが並びます。デスクトップ表示にしたあとは、浮遊メニューのスマートフォンのアイコンで戻せます
- パネルは**全画面**で開きます。指では掴めないドラッグやリサイズの取っ手は出ません

詳しくは[スマートフォンで使う](/manual/mobile)を参照してください。

### 指で操作する

- **コマのメニューは長押し** … 指を止めたまま0.4秒ほど押すと、右クリックと同じメニューが開きます。タッチ端末には右クリックがなく、iOSはブラウザ側のイベントも起こさないため、これまでコマのメニューを開く手段がありませんでした
- **卓の何もない所を長押ししてから指を滑らせる**と、範囲選択の枠を描けます。指を止めたままならテーブルのメニューが開きます
- すでに選んでいるコマがあるときの範囲選択は**追加と解除の切り替え**になります。選んでいる数はチャットの上に **「N個選択中 ✕」** として出て、押せば解除できます
- **コマの詳細はタップ**で開きます。ホバーでしか出なかった操作（インベントリの行メニュー、立ち絵の切り替え、コマの取っ手）は、タッチ端末では常に表示されます
- 行数の多いコンテキストメニューは画面に収まるよう詰まり、はみ出す場合はメニュー自体がスクロールします。サブメニューも画面の端で切れません
- 文字を入力している間は、画面が**キーボードの上に収まるように縮み**ます。ノッチやホームインジケータも避け、入力欄は16pxあるのでiOSで勝手に拡大されることもありません

### ホーム画面に追加する

ブラウザの共有メニューから **「ホーム画面に追加」** を選ぶと、アプリのように単独のウィンドウで起動するようになりました。アドレスバーが消えるぶん卓を広く使えます。

- 名前とアイコンが正しく付きます（これまでは名前なし・アイコン欠けのショートカットになっていました）
- ステータスバーの色はライト / ダークのテーマに追従します

### コマを作るパネル

名前・大きさ・画像を決めて[キャラクターコマ](/manual/character)を置く **「コマを作る」** パネルが、開けるようになりました。フォーク以来どこからも参照されていない状態だったものを、アプリの見た目に作り直して繋いでいます。

- **デスクトップ** … テーブルを右クリックして **「コマを作る…」**
- **スマートフォン** … メニューシートの **「コマを作る」**

あわせて、浮遊メニューはアイコンを少し小さくして、高さの低いウィンドウでも項目が収まるようにしました。

### 画面ごとの作り直し

390px幅で全パネル・全ダイアログを見直し、崩れていたものを直しました。

- **チャット** … ダイスボットやパレットの行を折りたたみ、ログの見える高さを確保しました
- **ノベルモード** … 上下分割を解除して画面全体を使います。操作パネルはメッセージ欄だけを出し、残りは左のつまみから開きます
- **手札** … チャットの上に出るようになりました（従来はチャットの裏に隠れて、開いても何も起きないように見えていました）。扇は画面幅に合わせて縮み、「表向きで出す」などのボタンはカードの**下**に出ます
- **リモコン** … 「発言元」「対象 / バフ / リソース」「次の操作が効く相手」の3段構成になり、誰に何をするパネルなのかが読み取れます
- **マップエディター** … キャンバスをツール列の隣に置き、設定とレイヤーは引き出しで開きます。削除とテキストの確定 / 取り消しはボタンから行えるので、キーボードが要りません
- **テーブル設定・キャラクターシート・デッキ・インベントリ・切り抜き・判定候補** … 横並びだった列を縦に積み、はみ出していた入力欄とボタンを画面内に収めました

## 🐛 不具合修正

- **zipを落とすと中の画像までコマになる問題を修正** … v1.21.0で入った「画像をテーブルに落とすとコマになる」処理が、zipを展開したあとの画像にも適用されていました。保存したルームを読み込むと、中に入っている画像の数だけコマが並んでしまいます。コマになるのは**直接落とした画像だけ**になり、zipの中の画像は今までどおり[画像パネル](/manual/images)に入ります。

## 🔧 開発者向け

自分でビルドして使っている方向けの変更です。

- **E2Eにスマートフォンのプロジェクトを追加** … Pixel 7相当（CIではiPhoneも）でシェル・メニュー・全画面パネルを通すsmokeテストが走ります。あわせて全プロジェクトのブラウザ言語を`ja-JP`に固定し、日本語ラベルを読むテストが実行環境の言語に左右されないようにしました。
- **Tailwindの走査範囲を`src`配下に限定** … 設計メモの中にしか存在しないクラスの定義が、製品版のスタイルシートに残っていました。

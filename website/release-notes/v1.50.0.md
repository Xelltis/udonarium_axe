# v1.50.0

2026-09-08 リリース

**卓のルールに合わせる** 版です。斜め移動の数え方が 4 つから選べるようになり、敵味方が隣り合った
ところを「近接状態」というひとつの塊として扱えるようになりました。どちらもシステムによって作法が
違うところで、これまではひとつのやり方しか選べませんでした。

盤面では、**マスにコマが入ると何かが起きる**塗りが増えました。落とし穴や毒沼や回復の泉を、GM が
手で処理せずに置けます。ランダムダンジョンは通路の幅を選べるようになり、生成と同時に戦場の霧を
かけたり、パーティを入口に並べたりできます。

卓上ディスプレイの設定は、3 か所に散っていたものを **1 つのパネル**にまとめました。**卓上モード**
のスイッチひとつで、視点も細かい設定もまとめて入ります。

## 🎲 斜めの一歩をいくつと数えるか

角を斜めに横切る一歩の値段は、システムによって違います。[部屋設定](/manual/room-settings) の
**移動** に **斜め移動** が増え、4 つから選べるようになりました。

| 選択肢                       | 数え方                                                      |
| ---------------------------- | ----------------------------------------------------------- |
| 許可しない（縦横のみ）       | 角は横切れません。範囲はひし形に広がります                  |
| 1 マスとして数える           | 縦横の一歩と同じ値段。範囲は四角く広がります                |
| 1 マス・2 マスを交互に数える | 1 回目の斜めは 1 マス、2 回目は 2 マス、3 回目はまた 1 マス |
| 常に 2 マスとして数える      | 斜めは必ず 2 マスぶん                                       |

交互に数えるのは D&D 3.5e やパスファインダー 1e の数え方です。この方式では、同じマス目に届くか
どうかが通り道によって変わります。移動範囲は一番安く着ける道で塗り、コマを運んだときの消費も同じ
数え方で計算します。**厳密な移動**で角を置いて道を折っても、斜めの数え直しは起きません。1 回の移動
のあいだ通しで数えます。

これまでの卓は何も変わりません。テーブルの **斜め移動を許可する** が入っていれば「1 マスとして
数える」、切ってあれば「許可しない」として読みます。ヘクスのテーブルには出ません。

## ⚔️ 近接状態 — 隣り合った全員をひとつと数える

隣り合った敵と味方をまとめて、ひとつの塊として扱うシステムがあります。
[部屋設定](/manual/room-settings) の **ZOC** に **近接状態** が増えました。

入れると、隣り合ったコマは敵味方の区別なくひとつにまとまります。すでに近接状態にあるコマの隣に
立てば、そこへ加わります。離れた 2 つの近接状態の間に 1 体入れば、2 つはつながってひとつになります。
まとまりが解けるのは、そこに敵がいなくなったときです。味方だけが集まっても近接状態にはなりません。

近接状態にいるコマは、**そこにいる全員から**地面を抑えられます。隣にいるのが味方でも同じです。

### 抜けるときに何が起きるか

これは **離脱** で選びます。

| 選択肢                 | 動き                                                         |
| ---------------------- | ------------------------------------------------------------ |
| 陣営の重さの差で決める | 相手陣営のほうが重ければ、その差ぶんだけ余分にかかる（既定） |
| 一定のコストがかかる   | 誰が出ても **離脱コスト** のぶんだけかかる                   |
| 離脱できない           | 近接状態から出られない。中を動くことはできる                 |
| 自由に離脱できる       | 何もかからない                                               |

**陣営の重さの差で決める** は、自分の側が相手より重ければ何もかからない、という数え方です。押し
通って出られます。釣り合っていれば 1 マスぶん、相手のほうが 2 重ければ 3 マスぶんかかります。重さは
既定ではコマの大きさで数えるので、3 マス幅の敵は 3 として数えます。頭数だけで数えたい卓は
**コマの大きさ** を切ってください。

抜けたあとにまた敵と隣り合えば、そこでまた近接状態になります。1 回の移動でひとつを抜けて別の近接
状態へ入れば、そのたびに離脱のぶんがかかります。

## 💥 マスにコマが入ると何かが起きる

[マップエディター](/manual/map-editor#機能塗り) の機能塗りに、4 つ目の対象 **イベント** が増えました。
塗ったマスにコマが入ると、そのコマに何かが起きます。この版でできるのは**リソースの増減**です。
落とし穴、毒沼、休むと回復する泉、といったものを卓に置けます。

塗りごとに決められるのは次のものです。

| 設定             | 中身                                                                      |
| ---------------- | ------------------------------------------------------------------------- |
| 名前             | チャットに出る仕掛けの名前                                                |
| 削るリソース     | コマのリソース名。卓にあるものが候補に出ます                              |
| 量               | `5` のような数か、`2d6`・`1d6+2` のようなダイス。マイナスを書けば回復です |
| 発火             | **止まったとき**（移動の終点）か、**通ったとき**（踏んだ時点）            |
| 対象             | 全部のコマ / PC のコマ / NPC のコマ                                       |
| 一度きり         | 1 回発火して消費されます                                                  |
| 全員に見せる     | 切ると GM の画面にだけ点線で出ます（既定）                                |
| 発動したら見せる | 踏まれた時点で全員に見えるようになります                                  |
| エフェクト       | 踏んだコマに出す[マップ演出](/manual/map-effects)                         |

**通ったとき** は踏んだマスの数だけ起きます。毒沼を 4 マス渡れば 4 回です。厳密な移動で 1 マスずつ
歩くあいだ、**踏んだその場で発火します。** 渡り終えてから 4 回まとめて、にはなりません。

発火するとチャットに 1 行出ます。`【落とし穴】斥候 は HP を 6 受けた` のような行です。隠してある
仕掛けでも行は出ますが、マスの場所は出しません。リソースが減れば、コマの[増減演出](/manual/character)
もそのまま出ます。

::: warning 削るリソースは空欄のままにしないでください
空欄でも発火はしますが、減るものがないので何も起きません。名前が合っているかは、発火したときに
チャットへ出る行で分かります。見つからなければ `【落とし穴】斥候 が踏んだ` とだけ出ます。
:::

塗ったものを直すときは、テーブルを取り込み直して、レイヤー一覧で **event** という名前のレイヤーを
選んでください。選ぶと機能ペンが手に入り、プロパティにその塗りの設定が出ます。

## 🖥️ 卓上ディスプレイの設定がひとつのパネルに

真上から見て遊ぶための設定は、**テーブル設定の 2D/3D**・**部屋設定の 2D 表示**・**FAB の視点** の
3 か所に分かれていました。どれを触ればいいのか分からない、という声をいただいたので、FAB メニューの
**卓上ディスプレイ**（ノベルモードの下）にまとめました。

::: tip まとめ方はフォークの形に倣いました
卓上ディスプレイの設定を FAB のパネルへ集める形は、[okamichi](https://github.com/okamichi) 氏が
フォークで先に作られていたものです。本家では元の置き場所を残したまま、同じ形のパネルを足しました。
:::

いちばん上の **卓上モード** を入れれば、あとは触らなくて構いません。視点が 2D になり、四方の席へ
向ける設定がまとめて入ります。切ると視点だけ 3D に戻り、入れた設定はそのまま残ります。3D では何も
しない設定なので、消す必要がないからです。

| 大項目         | 中身                                                       | 誰に効くか                |
| -------------- | ---------------------------------------------------------- | ------------------------- |
| 視点           | 自分の視点、テーブルの推奨、遠近をなくす                   | 自分の画面 / テーブル・GM |
| コマの見せ方   | コマ画像をマス内に収める、向きの示し方、カメラに向ける     | 自分の画面 / 部屋・GM     |
| 多方向表示     | コマ名の周回、外周ティッカー、カットインの向き、文字サイズ | 自分の画面だけ            |
| メニューと操作 | 回転メニュー、コマの詳細表示、ウィンドウの 90° 回転        | 自分の画面だけ            |
| 実寸表示       | 1 マスの実寸、実寸で表示、ビュー固定、画面の実測           | 自分の画面だけ            |

項目ごとに **誰に効くか** の札が付きます。**2D のとき** の札が付いた段は真上から見ているあいだしか
効かず、3D では薄く表示されます。

元の置き場所からは何も消していません。テーブル設定と部屋設定に慣れている人はこれまでどおり使えます。

### コマ画像をマス内に収める

新しい設定です。コマの絵はマスの下端から上へ伸びるので、縦長の絵はマスからはみ出して後ろのコマを
隠します。真上から見ているとそれが特に響くので、**卓上モード**にも入れてあります。手で高さを決めた
コマも、収めるあいだはマスに合わせます。

## 🗺️ ランダムダンジョンで決められること

[マップ生成](/manual/map-generator) に 3 つ増えました。

**通路の幅** は最小・最大を 1〜4 マスで決めます。1 マスの通路は紙のダンジョンの標準ですが、近接状態
を使う卓や 3 マス幅のコマを歩かせる卓では狭すぎます。最小と最大を離すと、通路ごとに幅が変わります。
壁の厚みは 1 マスのままで、広がるのは通路だけです。ただし格子は最大の幅で刻むので、**最大を広げる
ほど置ける部屋は減ります。** 洞窟系では掘る筆の太さとして効き、トンネル 1 本ごとに決まります。

**戦場の霧をかけた状態にする** を入れると、生成したテーブルが最初から霧で覆われます。誰も歩いて
いないダンジョンは、白紙の地図がいちばん似合う場所です。

**入口に集めるパーティ** を選ぶと、そのパーティのコマを入口の近くへ 1 体 1 マスで並べます。入口は、
外壁を破った坑道口があればそこ、なければ階段の部屋です。近いマスから順に取るので、通路に一列に
伸びず固まって出てきます。扉のマスには立たせません。選ばなかったコマは動かしません。

## ⚙️ 中で何が変わったか

読まなくても困りませんが、動きが気になる方へ。

### 斜めの数え方と探索

「交互に数える」では、同じマスへの一番安い着き方が通り道によって変わります。安く着いた道が先へ続く
とは限らないので、移動範囲と経路の探索は「マス＋斜めを切った回数」を単位にして、
同じマスを回数ごとに確定します。厳密な移動で角を置いて脚が切れても、回数は持ち越します。

### 近接状態はマスごとに引き直す

どの近接状態にいるかは立っている場所で決まるので、盤面の全マスについて「そこに立ったらどの塊に
入るか」「抜けるのに何マスかかるか」を先に出しておき、一歩ごとに参照します。突破して出たあと別の
敵に隣接すれば、そこでまた近接状態になります。大きいコマは占有マス全部で接触を判定します。

### 広い通路の掘り方

迷路は「2 マス進んで 1 マスを壁に残す」前提で書かれていました。これを「通路の幅ぶん進んで 1 マスを
壁に残す」に一般化し、どの通路も格子マスの同じ角に寄せて掘ります。こうすると幅 1 の通路と幅 4 の
通路が交差しても必ず角を共有するので、つながりが切れません。行き止まりの刈り取りと崩落も格子単位
にしました。崩落は両側に通路が開いている幅ぶんだけ壁を落とします。

### イベントの発火

発火するのはコマを動かした人の画面です。部屋の全員が判定すると人数ぶん重複するためです。厳密な
移動では 1 マス進むごとに、掴んで運ぶ移動では出発点と置いた先だけを見ます。手はどこを通ったか言わ
ないので、掴んで運ぶ移動では「通ったとき」も「止まったとき」と同じ扱いです。

「発動したら見せる」で開いた状態は、塗りそのものとは別に持っています。同じ塗りをもう一度反映しても、
発動済みの罠が新品に戻ることはありません。

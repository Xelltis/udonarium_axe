# v1.19.0

2026-06-28リリース

[v1.18.0](/release-notes/v1.18.0)で追加した**キャラクターの取り込み**が、対応するTRPGシステムを大幅に増やして帰ってきました。クトゥルフやソード・ワールド、ダブルクロス、シノビガミ、ネクロニカ、迷宮キングダムなど、多くのシステムのキャラクターを**キャラクター保管所・キャラクターシート倉庫・ゆとシートから直接キャラコマ**にできます。

## ✨ 新機能・改善

### 取り込みに対応するシステムを大幅拡充

[キャラクターの取り込み](/manual/character-import)が対応するゲームシステムを一気に増やしました。

- **キャラクター保管所**（charasheet.vampire-blood.net）… クトゥルフ神話TRPG第6版 / 新クトゥルフ神話TRPG（第7版）、ソード・ワールド（旧 / 2.0）、ダブルクロスThe 3rd Edition、アリアンロッド2E、グランクレスト、ネクロニカ、迷宮キングダム、ナイトウィザードThe 3rd Edition、ガーデンオーダー、りゅうたま、ウタカゼ、パラサイトブラッド、千幻抄、エリュシオンなどに対応しました。
- **キャラクターシート倉庫**（character-sheets.appspot.com）… シノビガミ、ダブルクロス3rd、インセイン、艦これRPG、ステラナイツ、ビーストバインド・トリニティ、キルデスビジネス、モノビースト、スターリードールズほか、サイコフィクション系を中心に多数追加しました。
- **ゆとシート**（yutorize）… ソード・ワールド2.5は**URLを貼り付けると自動取得**。そのほかのゆとシート系シートも汎用的に取り込めるようになりました。

### 取り込んだ項目が読みやすく

- **元シートのページ見出しから項目名を取得** … 技能や能力値などのラベルを、保管所・倉庫の実際のページ見出しから読み取るようにしました。サービス内部の英語キーではなく、シートで見たままの名前で並びます。
- **シノビガミの特技表** … 取り込み時に特技表を一覧（ギャップ表）として展開します。

### 対応システムが一覧で確認できるように

取り込みパネルに**対応システムの一覧と、データ種別ごとの対応状況の表**を表示するようにしました。自分の使うシステムが対応しているか、能力値やチャットパレットまで入るかを、取り込む前に確認できます。

## 🐛 不具合修正

- **チャットのルビ（ふりがな）が文字色に追従するように** … ルビが常に既定の色・太字で表示され、発言の[文字色](/manual/chat)に追従しない問題を修正しました。親文字もふりがなも、まわりの本文と同じ色・太さで表示されます（[チャットの特殊記法](/manual/chat-syntax#ルビ-ふりがな)）。
- **ゆとシートの判別を安定化** … シート名に依存していた判別をシート固有の目印で行うようにし、一部のゆとシート系シートが取り込めないことがある問題を修正しました。

::: tip 対応システムはこれからも増えます
最新の対応状況は取り込みパネル内の一覧が確実です。うまく取り込めないシートがあれば、[キャラクターの取り込み](/manual/character-import)の注意点もあわせて参照してください。
:::

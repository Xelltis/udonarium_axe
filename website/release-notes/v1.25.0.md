# v1.25.0

2026-08-04リリース

**コマの頭上**を作り込んだ回です。HPやMPがバーとして並び、バフが丸いバッジとして付き、値が動けば数字が飛び出して音が鳴るようになりました。シートを開かなくても、卓を見ただけで誰が瀕死で誰に毒が入っているかが分かります。

## ✨ 新機能・改善

### コマの頭上にHPバーが出ます

**HPとMPは最初からバーで出ます**。上から**バフ → リソースバー → キャラクター名**の順に積まれ、カメラを回しても常に正面を向きます。

- HPでもMPでもSANでも弾数でも、**リソース項目なら何でも**バーにできます。シートを**編集**にして、その行の**詳細設定**（つまみのアイコン）から**コマにバーを表示**を入れてください
- バーの色は残量で変わります（緑 → 黄 → 赤）。項目名の頭文字と`現在値/最大値`が横に付き、幅はキャラクター名と同じくらいに取ってあります
- 値を変えると全員の画面のバーが同時に動きます

### マイナスリソース

狂気度・汚染度・ストレスのように、**増えると悪くなる**項目のための設定です。同じ詳細設定の**マイナスリソース**を入れると、バーの色と下記の演出がまとめて裏返ります（満タンが赤、増加がダメージ扱い）。数字そのものは実際の増減のままなので、`+30`は`+30`と出ます。

### ダメージと回復が飛び出します

リソースの**現在値や最大値が変わると**、その差分がコマの上に飛び出します。シートからでも[リモコン](/manual/pl-tools)からでも、値を変えた経路は問いません。

- **減ったとき** — 赤い数字（`-30`）と赤い閃光、そして**コマが小刻みに震えます**
- **増えたとき** — 緑の数字（`+60`）と、**足元から立ち上る緑の光の輪**
- **効果音は最大値に対する割合で3段階**に鳴り分けます（15%未満は軽く、40%以上は重く）。かすり傷と致命傷が同じ音で鳴ることはありません

詳しくは[キャラクター](/manual/character#ダメージと回復が飛び出します)を参照してください。

### バフが丸いバッジになりました

コマの頭上に並ぶ[バフ](/manual/buff)が、**色付きの丸に絵文字を乗せたバッジ**になりました。**左上に効果量・右下に残ラウンド**が角へ重なるので、アイコンを隠さずに読めます。効果量は効果欄の数値（`防+1`なら`+1`）を自動で拾います。

- **色を選べます** … 赤・橙・黄・緑・青・紫・桃・灰と既定の黒。強化は青、状態異常は赤、と塗り分けておくと卓の状況が一目で分かります
- **バフ編集から** … 名前の左の丸ボタンを押すと、絵文字と色を選べます。ボタン自体がバッジのプレビューになっています
- **リモコンから** … バフ欄は`バフ名 効果 ラウンド数 色 アイコン`の空白区切り。入力欄の上の**色の丸**を押しておけば、色を打たずに済みます
- **チャットから** … `&毒/継続2/3/red/☠️`のように4つ目以降で指定できます。色は`red` `青` `#c62828`のいずれでも通り、色と絵文字の順番は問いません

見せ方は3つから選べます。コマを**右クリック** → **バフの表示**で、**アイコン**（既定）・**詳細**（名前と効果を全文）・**個数**（`バフ3個`）を切り替えられます。頭上には操作するものを置いていないので、表示に触ってコマが動いてしまうことはありません。

## 🐛 不具合修正

- **リモコンのリソース操作で、操作する項目が1つも選べない問題を修正** … シートの階層が深いキャラクターで、セクションとグループの下にあるリソースが候補に出ていませんでした
- **リソース行の操作ボタンが2段に折り返し、最大値に重なる問題を修正** … 行のボタン帯を1段に収まる幅へ戻しました

## 🔧 開発者向け

自分でビルドして使っている方向けの変更です。

- **頭上表示の解像度** … バーや名前は3倍の大きさで描いてから縮小しているため、テーブルを拡大しても輪郭が粗くなりません
- **頭上表示の寸法をテストで固定** … 積み順・間隔・重なり・折り返し・省略の有無を、実際のブラウザで測って検証するE2Eを追加しました
- **効果音は鳴った場所だけで再生** … リソースの増減音は他の参加者へ配信せず、変化が起きた画面でのみ鳴ります

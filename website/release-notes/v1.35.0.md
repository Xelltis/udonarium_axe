# v1.35.0

2026-08-12リリース

**点呼・投票**の回です。これまでは投票の窓を閉じるとその場で棄権あつかいになり、開き直す手段がありませんでした。
窓をやめて**ウィジェット**にしたので、**閉じても（折りたたんでも）参加はそのまま**続きます。

## ✨ 新機能・改善

### 点呼・投票がウィジェットになりました

点呼や投票が始まると、パネルではなく小さなウィジェットが出ます。ドラッグで好きな位置に置けて、位置は次回も覚えています。

| 操作                    | これまで                     | これから                                     |
| ----------------------- | ---------------------------- | -------------------------------------------- |
| **閉じる / 折りたたむ** | その場で棄権・欠席が確定した | 見出しだけの帯になる。**参加はそのまま続く** |
| **棄権する / 欠席する** | 窓を閉じるしかなかった       | **専用のボタン**を押したときだけ確定する     |
| **開き直す**            | できなかった                 | 折りたたんだ帯を押せば戻る                   |

帯になっている間も **「確認2/5」** のように進み具合が見えるので、締め切りが近いかどうかは畳んだままでも分かります。

### 途中で再読み込みしても戻ってきます

ウィジェットは部屋の状態そのものから出ています。**同じタブで再読み込みして部屋に戻れば、終わっていない点呼のウィジェットは出てきます**。
これまでは開始の合図を受け取り損ねると、その回には二度と参加できませんでした。

### 始めた人が「締め切る」を押せます

誰かが答えないまま放置しても卓が止まらないよう、**始めた人（議長）** のウィジェットに **「締め切る」** が付きました。
未回答の人を残したまま集計を確定します。集計には **`未回答:2`** のように、答えなかった人数が出ます。

自分を対象に含めずに点呼を取った場合も、**始めた人には集計だけが見えます**。

### 点呼・投票のログが「始めたタブ」に出ます

これまでシステムタブにまとめて出ていた点呼・投票の発言が、**それを始めたチャットタブ**に出るようになりました。

- 「点呼開始！」
- 各自の回答（`点呼：準備完了(3/5)`）と棄権
- 集計（`点呼終了(3/5) 棄権:1 未回答:2`）

雑談タブで取った点呼が戦闘タブに混ざる、といったことが無くなります。
なお**閲覧できる人が限られたタブから始めると、そのタブを見られない参加者にはログが見えません**。
全員に見せたいときは、共通のタブから始めてください。

### 集計の文が言語設定に沿うようになりました

「点呼終了(3/5)」などの集計文が日本語で固定されていたのを、表示言語に合わせて出すようにしました。
ただし、この文は**発言としてそのまま全員に配られる**ため、**始めた人の言語**で全員に届きます。

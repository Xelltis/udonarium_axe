# v1.75.1

2026-11-02リリース

不具合修正のリリースです。発言者の項目の値に`t{名前}`があるとき、その項目を呼んだ行がターゲットに届かず、`t{名前}`が値に置き換わっていなかったのを直しました。バフのタイミングに`none`と書いても消えないバフにならず、3ラウンドで切れていたのも直しました。

## 🎯 項目の値の中のターゲット参照

キャラクターAのシートに「項目A」と、値が`{項目A}+t{項目B}`の「項目C」を作り、キャラクターBのシートに「項目B」を作ります。Bをターゲットにして、Aのチャットパレットやチャットの入力欄から`{項目C}`を送ると、項目Bのところが空になるか、`t{項目B}`のまま送られていました。入力欄では値が入って見えていたので、送った行だけが食い違っていました。

ターゲットに送る行かどうかを、打った文字に`t{`があるかだけで決めていたためです。今は、発言者の項目や変数を置き換えたあとの行でも確かめます。置き換えた行に`t{名前}`や`t:`・`t&`の操作があれば、打った行と同じく、ターゲットごとに`[B]`のような名前を付けて送ります。ターゲットが何体いても、どの行も、発言者の値を置き換えたあとの同じ行から作ります。誰もターゲットにしていなければ、`t{`を打った行と同じく、対象がいないと出ます。入力欄の指摘も同じ読み方にしたので、送る前から`{項目C}`に「ターゲットにしているコマがありません」と出ます。

ターゲットが2体以上いるとき、自分のリソースやバフを動かす操作（`:MP-2`など）は、これまでどおり1体目の行にだけ残します。ただし、項目や変数の値の中に書いた操作は取り除けず、`{消費} t:HP-5`のような行ではターゲットの数だけ効いていました。今は、値の中の操作も1体目の行にだけ残ります。

くわしくは[項目と変数の参照](/manual/chat-syntax#項目と変数の参照)にあります。

## 🛡️ 消えないバフの`none`

`&毒/継続2/3/none`のように、バフの4つ目以降の欄に`none`や`なし`と書くと、消えないバフになるはずでした。ところが`none`と`なし`はバッジの色を既定に戻す語としても読んでいて、色のほうを先に読んでいました。そのためタイミングはラウンド終了時のままで、3ラウンドで切れていました。バフマネージャーの**自動計算バフの記法を作る**で消失タイミングを「消えない」にしたときも、記法に`none`を書き出すので、同じように切れていました。

今は、`none`と`なし`はタイミングとしてだけ読みます。色を既定の黒に戻すときは、マニュアルにあるとおり`既定`と書きます。ラウンド数の欄にタイミングを書いた`&毒/継続2/none`も、ラウンド数を省いたものとして読み、消えないバフになります。リモコンからバフを付けるときも同じです。消えないバフを付けたときのチャットの行には、ラウンド数を出しません。

くわしくは[いつ切れるかを決める](/manual/buff#いつ切れるかを決める)にあります。

## ⚠️ 以前の版との互換

部屋のデータは変わりません。v1.75.0の人とも、今までどおり同じ部屋で遊べます。

次の2つの書き方は、この版から動きが変わります。

- バフの見た目の欄に`none`や`なし`と書いて色を既定に戻していた行は、消えないバフを付けます。色だけを戻すときは`既定`に書き換えます
- 変数や項目の値に`t{名前}`を入れて、ターゲットがいなければ空になる項として使っていた行は、ターゲットがいないと送られなくなります。`t{名前}`を直接打った行と同じ扱いです

チャットの行とバフの操作は、送った人の画面で処理します。v1.75.0のままの人が送ると、以前と同じように動きます。公開されているAxeは、ページを再読み込みすればこの版になります。

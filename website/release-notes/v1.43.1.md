# v1.43.1

2026-08-25リリース

不具合修正のみのリリースです。v1.43.0で入った「切り替え時のカットイン」まわりの2件を直しました。

## 🐛 不具合修正

- **テーブル設定を開くと動作が重くなる問題を修正** … テーブル設定を開いている間、画面全体が重くなっていました。「切り替え時のカットイン」の欄が、指定は変わっていないのに変わったと判定し続け、画面の描き直しが止まらなくなっていたためです。卓に置いたコマや画像が多いほど症状が出やすく、テーブル設定を閉じるまで収まりませんでした
- **選んだカットインの名前が読めない問題を修正** … 「切り替え時のカットイン」で選んだものは、名前を囲んだ小さな枠になって欄に並びます。この枠は文字と背景がほぼ同じ明るさで、名前がまったく読めませんでした。候補一覧で選択済みの項目と同じ配色に揃えています。枠が増えたときは折り返すようにもしたので、3つ4つと選んでも欄からはみ出しません

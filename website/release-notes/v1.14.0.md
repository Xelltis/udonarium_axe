# v1.14.0

2026-06-11リリース

チャットのやり取りを、立ち絵とメッセージウィンドウで再生・進行できる**ビジュアルノベルモード**を中心としたアップデートです。あわせて、ロールまわりの細かな挙動を改善しました。

## ✨ 新機能

### ビジュアルノベルモード

チャットのやり取りを、立ち絵とメッセージウィンドウで構成された**ノベル風の画面**で再生・進行できるモードを追加しました。FABメニューの**ノベルモード**（本のアイコン）から開きます。オーバーレイ表示なので、テーブルや他のパネルはそのまま操作できます。

- **立ち絵ステージ** … 発言したキャラクターの立ち絵が最大6人まで並び、発言中のキャラクターが前面で明るく表示されます。本文は1文字ずつ送られます。
- **進行とオートプレイ** … クリック・キー・マウスホイールで前後に進められます。**オートプレイ**で最古から最新まで自動再生でき、速度も調整できます。
- **演出（エモート）** … 発言タイプ（セリフ / 地の文 / ロケーション / 場面転換）や、吹き出し・立ち絵のアニメーション、漫符を付けられます。演出は通常のチャットログにも`〔…〕`の形で記録され、参加者全員のノベルモードで同じ演出が再生されます。
- **SE（効果音）** … [ジュークボックス](/manual/jukebox)に**SEタグ**で登録した音声を、単体で、または次の発言と同時に再生できます。再生はジュークボックスと同期し、**▶ 再生 ↔ ■ 停止**で止められます。
- **バックログ** … これまでの発言を検索・ジャンプでき、自分の発言は本文だけでなく演出・立ち位置も後から編集できます。
- **発言まわり** … 発言キャラクターや立ち絵パターン・立ち位置・反転を選べ、ダイスボットやチャットパレットもそのまま使えます。

詳しくは[ノベルモードのマニュアル](/manual/visual-novel)を参照してください。

## 🐛 不具合修正

- **GMツールバー** … ロールをGM→プレイヤー→GMと切り替えると、移動したGMツールバーが画面の左上に戻ってしまう問題を修正しました。
- **チャットのタブ権限** … 読み取り専用の**見学**が、[タブの閲覧・発言権限](/manual/chat)を変更できてしまう問題を修正しました。権限を変更できるのはGM・プレイヤーだけです。

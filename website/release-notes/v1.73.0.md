# v1.73.0

2026-10-28リリース

[部屋のサーバー（ベータ）](/guide/choose)で、ログインしている人が、自分を見学に切り替えられるようになりました。

バフは、1つでいくつものステータスを動かせ、残ラウンドが減るたびにステータスをさらに動かせます。手番のうちに待機すると、手番開始で減ったバフが元に戻ります。チャットパレットのタブ、コマのメモ、戦闘カットインの窓、バフアイコンの大きさも加え、いくつかの不具合を直しました。

## 👀 見学への切り替え

接続パネルの「役割」で「見学」を押すと、自分を見学に切り替えられます。隣の「PL」（GMなら「GM」）を押すと、元の役割に戻ります。

部屋のサーバーが覚えている役割は変わりません。見学していることも部屋のサーバーが覚えるので、読み込み直したり、接続が切れたりして入り直しても見学のまま入り、いつでも元の役割に戻れます。同じアカウントでほかのタブや端末から入っている席も、一緒に切り替わります。見学に切り替えているあいだは、GMもGMの操作ができません。GMがその人の役割を変えると、見学への切り替えは終わります。

この切り替えのために、部屋のサーバーとのやりとりの形が変わりました。部屋のサーバーもv1.4.0以降が必要です。

詳しくは[見学に切り替える](/manual/roles#watch)を参照してください。

## 🧮 いくつものステータスを動かすバフ

`&!全力攻撃/追D+4,回避-2/1/手番開始`のように、2つ目の欄にステータス・操作・量を`,`で並べると、1つのバフでいくつものステータスを動かします。コマの頭上には1つのバッジとして出て、`&全力攻撃-`で外せば、動かした分をすべて戻します。

バフマネージャーの「自動計算バフの記法を作る」でも、「ステータスを足す」で行を増やして組み立てられます。詳しくは[いくつものステータスを動かす](/manual/buff#いくつものステータスを動かす)を参照してください。

## 📈 数えるたびに動かすバフ

量のうしろに`~`と数を付けると、残ラウンドが減るたびに、ステータスをその分だけさらに動かします。`&!変身/器用度/+/5~-1/5`は、器用度を5上げ、減るたびに1ずつ戻します。

操作を`++`と2つ重ねると、減るたびに同じ量を足し続けます。`&!猛攻撃/命中/++/1/3`なら、命中が1上がり、減るたびにさらに1ずつ上がります。詳しくは[数えるたびに動かす](/manual/buff#数えるたびに動かす)を参照してください。

## ⏸️ 待機したときのバフ

手番が始まって減ったバフは、そのコマを手番のうちに待機させると元に戻り、手番が戻ってきたときにもう一度減ります。切れて消えたバフも、動かしたステータスと一緒に戻ります。

部屋のGMとPLに、この版より前のAxeを使っている人がいるときは、これまでどおり戻しません。詳しくは[行動順](/manual/turn-order#バフの残ラウンドを自動で減らす)を参照してください。

## 🗂️ チャットパレットのタブ

`◆◆戦闘`のように、`◆`を2つ並べて名前を書いた行で、パレットをタブに分けられます。選んだタブの行だけが出て、検索はすべてのタブから探します。

ユドナイトで保存した部屋を読み込むと、ユドナイトのタブも、それぞれタブとして入ります。詳しくは[タブで分ける](/manual/chat-palette#tabs)を参照してください。

## 📝 コマのメモ

コマの右クリックの「メモ」で、持ち物やイベントのフラグなどを書いておけます。メモのあるコマは、ポインタを乗せたときのカードで、ステータスとメモを切り替えて読めます。

ユドナイトで保存した部屋を読み込むと、コマのメモもそのまま入ります。詳しくは[コマのメモ](/manual/character#memo)を参照してください。

## 🪟 戦闘カットインを窓で見る

戦闘カットインのパネルの「表示の大きさ」か、カットインの右上のボタンで、全画面のほかに大・中・小の窓を選べます。窓のときは、再生中も窓の外の卓を操作でき、窓は上の縁をつかんで動かせます。

この画面だけの設定です。詳しくは[窓で見る](/manual/battle-cut-in#window)を参照してください。

## 🔍 バフアイコンの大きさ

PLツールバーの「バフアイコンの大きさ」で、コマの頭上のバフのアイコンを、75%から200%まで5段階で大きくできます。この画面だけの設定です。

## 🎲 チャット欄の式に付けたバフ

チャット欄に`2d+10{加護}`のように、ダイスの式の数字のすぐ後ろへバフの参照を付けて送ったとき、コマにそのバフが無ければ、参照を空にして`2d+10`で振ります。これまでは`{加護}`が残り、式として振れませんでした。チャットパレットから送ったときは、これまでどおり空になります。

## 🛠️ 直したこと

- 画像を選んだバフのアイコンが、バフの表示を「詳細」にしたコマと、マルチアングルでコマの周りに並ぶバッジで、画像ではなく長い英数字で出ていました
- 手番開始時に減るバフをバフ編集で開くと、消失タイミングが「ラウンド終了時」と出ていました。表示だけの誤りで、減るのは手番開始時でした。シートの表とポインタを乗せたときのカードの選択欄、ホワイトボードのレイヤーのグループも、開いたときに先頭の選択肢が出ていました
- 見学者が、ポインタを乗せたときのカードとインベントリの表で、項目の値や状態異常を書き換えられました。今は読むだけです

## ⚠️ 以前の版との互換

SkyWay版の部屋では、v1.72.0以前の人とも、今までどおり同じ部屋で遊べます。ただし、この版で加えたものは、v1.72.0以前の版では次のように見えます。

- いくつものステータスを動かすバフは、ステータスごとの別々のバフに見えます。外すと、それぞれが動かした分を戻します
- 数えるたびに動かすバフは、v1.72.0以前の版が残ラウンドを減らしたときには、ステータスを動かしません
- `◆◆`のタブは、見出しとして出ます
- コマのメモは出ませんが、保存し直しても消えません

`◆◆`で始まる行を見出しの飾りに使っていたパレットは、この版でタブに分かれます。行は消えません。

部屋のサーバーには、この版より前のAxeでは入れません。開いたままの古いタブは、再読み込みを促されます。
反対に、この版のAxeは、v1.3.1以前の部屋のサーバーには入れません。部屋のサーバーを置いている人は、Axeと一緒に更新してください。

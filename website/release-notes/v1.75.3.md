# v1.75.3

2026-11-02リリース

不具合修正のリリースです。コマの頭上のバフを詳細で見せているとき、バフに付けた色が出ず、消えないバフにも残りラウンドが出ていたのを直しました。

## 🛡️ 詳細で見せるバフ

コマを右クリックして**バフ・演出** → **バフの表示**を**詳細**にすると、頭上にバフの名前・効果・残りラウンドが1行ずつ並びます。この行の頭には絵文字だけが出ていて、バフに付けた色は出ていませんでした。チャットから`&!石化/HP/=/0/1/green`のように色を付けても、バフ編集では緑の丸なのに、頭上の行には色が付きませんでした。

消えないバフも、残りラウンドを`3R`や`1R`と出していました。`&毒/継続2/none`で付けた毒は減らないのに、頭上では`毒 / 継続2 / 3R`と見えていました。

今は、詳細の行の頭に、**アイコン**で見せるときと同じバッジを出します。バフの色の丸に絵文字を乗せ、左上に強度、右下に残りラウンドを重ねたものです。消えないバフは、行の残りラウンドを`∞R`と出します。

くわしくは[追加・編集・削除](/manual/buff#追加・編集・削除)にあります。

## ⚠️ 以前の版との互換

部屋のデータは変わりません。v1.75.2の人とも、今までどおり同じ部屋で遊べます。頭上の見せ方は、見ている人の画面で決まります。

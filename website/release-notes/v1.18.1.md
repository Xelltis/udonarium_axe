# v1.18.1

2026-06-17リリース

トークン発行サーバーの**コールドスタート（起動直後の一時的な失敗）への耐性**を高める修正リリースです。

## 🐛 不具合修正

- **トークン発行サーバーのコールドスタートで接続が止まる問題を修正** … サーバーを用意した直後やデプロイ直後など、トークン発行サーバーが起動しきっていないタイミングでは、最初のリクエストが一時的に失敗し、接続がそのまま止まってしまうことがありました。
  - トークンの取得を**タイムアウト付きで数回リトライ**するようにしました。サーバーが起動しきるまでの一時的な失敗は、このリトライでやり過ごします。
  - それでも失敗が続く場合は、**少し待ってから自動で再接続**を試みます。再接続の回数には上限があり、サーバー自体に到達できない場合は、上限に達した時点でエラーを通知します。

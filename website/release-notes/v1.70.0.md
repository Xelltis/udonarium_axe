# v1.70.0

2026-10-24リリース

まとめたマスのテーブルで、1つのまとめたマスにコマを並べて置けるスナップ「グリッド」を加えました。

PLも、自分が足した画像と音声を部屋から削除できるようになりました。画像のタグを自分専用にして、そのタグの画像を自分とGMにだけ見せることもできます。

ホットバーには、テーブルに出している所持ダイスをまとめて振り直す枠を加えました。

## 🔲 スナップ「グリッド」

テーブル設定の「移動と射程の1マス」で2×2マス以上にまとめると、これまではスナップを入れたとき、コマはまとめたマスの真ん中にしか止まりませんでした。同じまとめたマスに2つ目のコマを置くと、1つ目に重なっていました。

スナップに**グリッド**を加えました。コマは真ん中に寄らず、まとめたマスの中の、置いたマスに止まります。パーティのコマを、1つのまとめたマスに並べて置けます。移動範囲・射程・ZOCは、今までどおりまとめたマスで数えます。

[厳密な移動](/manual/move-range#厳密な移動)でも、行き先のまとめたマスの中のマスを選べます。行き先のマスは白い枠で出ます。登れない高さのマスや、ほかのコマがいて止まれないマスを指したときは、そのまとめたマスの中で止まれるいちばん近いマスに止まります。同じまとめたマスの中で置き直しても、移動は減りません。

まとめたマスを使っていないテーブルでは、グリッドはセルと同じに働きます。

くわしくは[テーブル設定](/manual/table-setting#grid)と[移動範囲](/manual/move-range#まとめたマスで数える)にあります。

## 🎲 所持ダイスを振り直す

ホットバーの枠の種別に**所持ダイスを振り直す**を加えました。キャラクターがテーブルに出している所持ダイスを、まとめて1回で振り直します。鳴る音とチャットの行も1回分です。

持ち主を決めたダイスの出目は、持ち主にだけ見えます。シートにしまってあるダイスは振りません。テーブルに1つも出ていないときは、そのことが出ます。

くわしくは[ホットバー](/manual/hotbar#kinds)にあります。

## 🗑️ 自分が足した画像と音声の削除

v1.69.0では、画像と音声を削除できるのはGMだけでした。この版から、PLも自分が足した画像と音声を削除できます。GMは今までどおり、どの画像と音声も削除できます。削除したものを戻せるのは、GMだけです。

画像パネルでは、自分が足した画像が一覧にあるとき、PLにも**削除**のボタンが出ます。チェックした中にほかの人の画像があると、確認にその数が出て、その画像は残ります。ジュークボックスでは、自分が足した音源の行に、ごみ箱のボタンが出ます。

足した人は、部屋のサーバーではログインしたアカウントで、SkyWay版ではブラウザで見分けます。SkyWay版で別のブラウザや別の端末から入ると、別の人として扱われます。この版より前に足した画像と音声は、足した人が記録されていないので、GMだけが削除できます。

くわしくは[画像](/manual/images#remove)と[ジュークボックス](/manual/jukebox#remove)にあります。

## 🔒 タグを自分専用にする

画像パネルでタグを選んで**自分専用にする**を押すと、そのタグに鍵がかかります。鍵をかけたタグの画像は、鍵をかけた人とGMの画面にだけ出ます。誰が足した画像かは問いません。GMが次の場面で出す画像をまとめておくときや、PLが自分だけで使う画像を分けておくときに使います。

隠れるのは、画像パネルと、画像を選ぶすべての画面です。ほかの人の画面では、タグの一覧にもそのタグが出ません。すでにコマや背景に設定した画像は、全員に見えたままです。鍵を外せるのは、鍵をかけた人とGMだけです。

SkyWay版では、画像そのものは参加者全員に届いています。不正をしない相手への目隠しと考えてください。

くわしくは[画像](/manual/images#private-tag)にあります。

## 🛠️ 直したこと

- インベントリの詳細設定で「開いたときフォルダを畳んでおく」を入れても、共有のフォルダが畳まれていませんでした。今は、どのタブのフォルダも、そのタブを最初に開いたときに畳まれます
- テーブルの幅や奥行きがまとめたマスで割り切れないとき、端に残ったマスはどのまとめたマスにも入らず、そこにいるコマの移動範囲が出ませんでした。端に残ったマスも、1つのまとめたマスとして数えます。20×15マスのテーブルを4×4でまとめると、下の3行は4×3のまとめたマスになります

## ⚠️ 以前の版との互換

v1.69.0以前の人の画面では、スナップのグリッドはセルとして働きます。ホットバーの「所持ダイスを振り直す」の枠は、v1.69.0以前の版では何もしない枠になります。

v1.69.0以前の人の画面では、鍵をかけたタグの画像も見えます。v1.69.0以前の版のPLは、画像と音声を削除できません。

部屋のサーバーでPLが画像と音声を削除するには、部屋のサーバーがv1.3.0以降である必要があります。それより前の部屋のサーバーでは、PLの削除は取り消され、画像と音声は残ります。

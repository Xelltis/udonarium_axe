# v1.41.1

2026-08-20 リリース

**アプリの動きは変わりません。** v1.41.0 で入ったバフまわりの説明が追いついていなかったので、
リリースノートと操作マニュアルを揃えた版です。あわせて、開発時のテストにあった不具合を 1 つ直しました。

## 📖 v1.41.0 の説明が揃いました

v1.41.0 はバフが大きく変わった版でしたが、[操作マニュアル](/manual/)には何も書かれていませんでした。
次のページに書き足しています。

- [バフ／デバフ](/manual/buff) — 消失タイミングとトリガー、ステータスを実際に動かす `&!` 記法、
  バフマネージャーの 3 節
- [チャットの特殊記法](/manual/chat-syntax#バフ-デバフ操作) — `&!` の書式と、色やアイコンの隣に置ける
  タイミング・トリガー
- [オブジェクトの基本操作](/manual/objects#重なり順) — コマの前後の入れ替え
- [チャットの基本](/manual/chat#chat-settings) — 端末に残る設定と、新しく加わった文字サイズ
- [行動順](/manual/turn-order#バフの残ラウンドを自動で減らす) — 手番で切れるバフはラウンド終了の
  一斉減少に含まれないこと

[v1.41.0 のリリースノート](/release-notes/v1.41.0)も同時に公開しました。

## 🔧 開発者向け

自分でビルドして使っている方向けの変更です。

- **テストが時々落ちる問題を修正** … テスト用のオブジェクト置き場（`ObjectStore`）が、テストファイル
  をまたいで共有されていました。前のファイルが残したオブジェクトを次のファイルが自分のものとして
  数えてしまい、`ng test` が実行のたび別の場所で落ちます。共通のセットアップで、テストごとに置き場を
  空にしてから始めるようにしました。長らく「マシンが混んでいるせい」と扱っていた失敗の正体で、
  アプリの動作には関係ありません

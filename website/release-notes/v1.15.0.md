# v1.15.0

2026-06-13リリース

GM向けの新ツール**マップエディター**を中心に、マップの作成と調整まわりを大きく強化したアップデートです。あわせてグリッド調整ツールを一新し、いくつかの不具合を修正しました。

## ✨ 新機能

### マップエディター

セル・図形・スタンプ・画像などを組み合わせてマップ画像を描き起こせる**GM専用ツール**を追加しました。GMツールバーの**マップエディター**ボタンから開きます。

- **12種類の描画ツール** … 設定・選択・ペン・消しゴム・塗りつぶし・自由線・線・図形・多角形・文字・スタンプ・画像。ツールはショートカットキーでも切り替えられ、アンドゥ/リドゥにも対応します。
- **塗り（テクスチャ）** … 単色のほか、草原・海・岩・砂漠・レンガ・溶岩など**16種のテクスチャ**（継ぎ目なくループ）を使えます。「テクスチャ」タグの付いた画像もパレットに並び、**「＋」タイル**から画像をアップロードして正方形に切り抜けば、自動でタグが付いて保存されます。
- **線** … 直線・折れ線・**曲線**・**閉じ曲線**を切り替えられます。曲線は頂点を結ぶ滑らかなカーブで描かれ、閉じ曲線は塗りにも対応します。線は色だけでなく**テクスチャ**でも描け、**線種**（実線 / 破線 / 点線 / 一点鎖 / 長破線）と**影**も設定できます。
- **図形** … 矩形・楕円・三角形・五角形・六角形・五芒星・六芒星を描けます。
- **グリッドとレイヤー** … グリッドはスクエア・ヘクス（縦）・ヘクス（横）に対応。レイヤーごとに表示/ロック/不透明度/並び替え/名前変更/削除を管理できます。
- **スタンプ・画像** … 扉・階段・家具・自然・ダンジョン・マーカーの6カテゴリ49種のスタンプを配置でき、画像はマス目（ヘクスではヘクス形）に沿って切り抜けます。ドラッグ中はマス単位の長さ・サイズを示す**計測表示**が出ます。
- **透明背景** … 背景を透明にでき、書き出した画像も透過PNGになります。
- **セーブ / ロード** … マップを画像テクスチャ・配置画像ごと`map.zip`にまとめて保存・復元できます。完成したマップは**画像として保存**できるほか、**テーブル背景に設定**して、マス数・マスサイズ・グリッドタイプをそのままテーブルへ反映できます。

詳しくは[マップエディターのマニュアル](/manual/map-editor)を参照してください。

### グリッド調整の刷新

床画像のグリッド位置を視覚的に合わせる「**グリッドに合わせて設定**」ツールを一新しました。テーブル設定の床画像欄から開けます。

- **固定したクリップ枠**の下で画像をドラッグして移動、四隅・辺のハンドルでサイズ調整、ホイールでカーソル中心に拡大縮小できます。
- **スクエア / ヘクス（縦）/ ヘクス（横）** に対応し、確定時にグリッドタイプもテーブルへ反映されます。
- 作業領域のズームや、マス数が多いときの自動フィットで、画面内で完結して調整できます。

詳しくは[テーブル設定のマニュアル](/manual/table-setting)を参照してください。

## 🐛 不具合修正

- **パネルの重なり順** … 最大化したパネルがフローティングメニューの背面に隠れてしまう問題を修正しました。
- **投票** … 特定の状況で投票の集計に失敗することがある問題を修正しました。
- **チャット** … 特定の状況でチャットタブの表示が一時的にエラーになる問題を修正しました。

# v1.58.0

2026-09-29リリース

地面に効果を持たせられるようになりました。渡るのに余分にかかる沼、半分で進める道、踏むと毒を受ける地帯、落ちると
別のテーブルへ飛ぶ落とし穴。どれもマップエディターの筆で塗って置きます。マップ生成も、組み上げた部屋に
罠と危険地帯を一緒に仕掛けるようになりました。

コマの動き方も増えました。登る・泳ぐ・這う・飛ぶをコマごとに選べ、跳躍で壁を越え、大きなコマは身を縮めて
狭い隙間を通ります。他のコマの前を通れるかどうかは、陣営ごとに決められます。

同じ名前のバフは、これまで後から付けた数値で上書きされていました。`&+`を付ければ足し算になり、`&++`なら
ラウンド数も足されます。FavメニューとGM／PLツールバーは、中身を自分で組み替えられるようになりました。

## 🧪 地面が何かをする

マップエディターの**機能塗り**に2つ増えました。

沼・瓦礫・深い雪のように、渡るのに余分にかかる地面は**移動コスト塗り**で置きます。数値を決めて塗ると、
移動範囲の計算にその数値が入り、テーブルにも数字が出ます。逆に**道**を塗れば半分で進めます。

踏んだコマに何かをする地面が**危険地帯塗り**です。1つの筆で次のどれでも作れます。

- HPを減らす、あるいは回復する（`2d6`のようにダイスでも）
- 卓に判定を振らせて、成功したら軽く済ませる、あるいは何も起きない
- 状態異常を付ける（持続ラウンドつき）
- 別の場所へ運ぶ。同じテーブルの中でも、**別のテーブルへでも**
- 音を鳴らす、カットインを出す、チャットに文章を流す

いつ起きるかは止まったとき・通ったとき・手番の開始時・手番の終了時から、何回起きるかは毎回・1コマ1回・
1ラウンド1回から選びます。毒沼の中で手番を迎えれば毒を受け、走り抜けるだけなら
何も起きない、という書き分けができます。

見せる相手も選べます。GMだけに見せておくと、塗った場所はテーブルでは普通の床に見え、踏んで初めて姿を
現します。罠はこれで作ります。

くわしくは[マップエディター](/manual/map-editor#危険地帯塗り-—-毒沼を一筆で置く)にあります。

## 🚶 歩く以外の動き方

コマを右クリックして**移動の仕方**を選びます。歩く・登る・泳ぐ・這う・飛ぶの5つです。

- 登る・泳ぐ・這うは、どのマスも1マスぶん余計にかかります。移動力6のコマは3マス進みます
- 飛ぶは地面の追加コストを払いません。沼も浅瀬も普通の床と同じです。壁も越えられます

部屋設定の**移動**にも項目が増えました。

| 項目                                             | 何を決めるか                                                                   |
| ------------------------------------------------ | ------------------------------------------------------------------------------ |
| 跳躍の距離                                       | 1回の跳躍が何マス届くか。0なら移動力いっぱい                                   |
| 大きなコマを、通れない隙間に押し込めるようにする | サイズ3のコマが2マスの隙間を通れるか。通るマスは1マスぶん余計に消費します      |
| 同じ／別の／未所属のパーティのコマ               | 通れない／通れるが止まれない／割高で通れて止まれない／通れて止まれる、から選ぶ |
| 通り抜けの追加コスト                             | 「割高で通れて」のときの上乗せ                                                 |
| サイズが2マス以上違う相手のマスは通り抜けられる  | 小さいコマの脇をすり抜ける                                                     |
| 敵味方の分け方                                   | NPCかどうかで分けるか、パーティで分けるか                                      |
| 掴んで運んだときも、通り道の仕掛けを発動させる   | ドラッグで運んだとき、途中のマスの仕掛けを鳴らすか                             |

大きなコマの扱いも直しました。これまでは体が入りきらない場所にも立てましたし、自分では立てない幅の隙間を
通り抜けられました。どちらもできなくなっています。

## 🌫️ 霧で視線を切る、区画ごとに明るさを変える

通り抜けられるのに向こうが見えない区画が**霧**です。煙幕や濃霧をテーブルに置けます。

その範囲だけ明るさを変えるのが**明るさの区画**です。明かりを消す区画も置けるので、照らされた部屋の中に
闇だまりを1つ作れます。

## 🤝 別のパーティを味方として扱う

同行パネルで2つのパーティを**同盟**にできます。移動範囲の上で同じパーティとして扱われ、他のコマの前を
通る判定とZOCの敵味方がそれに従います。味方NPCの一団を敵とは別扱いにしたり、3すくみの戦闘で
「AとBは手を組んだ、Cは敵」と書いたりできます。

視界の共有は別の話で、同盟を結んでも共有されません。共有したいなら同じパーティに入れてください。

## ✨ 同じバフを重ねる

`&攻撃力+2/3R`をもう一度打つと、これまでは後の値で上書きされていました。

- `&+攻撃力+2/3R` — 今ある数値に**足します**。+2を2回で+4。ラウンドは長いほうが残ります
- `&++攻撃力+2/3R` — 数値もラウンドも足します。3Rのあとにもう一度打てば6R

マイナスも同じです。`&+攻撃力-1`を重ねれば下がっていきます。チャット・リモートコントローラのバフ欄・
記法ビルダーのどれからでも使えます。くわしくは[バフ／デバフ](/manual/buff)にあります。

## 🧰 メニューを自分で組む

Favメニューと自分のツールバーの中身を組み替えられるようになりました。**表示**の中の**メニューの編集**で開きます。

- **足す・外す** — 「項目を足す」で一覧が開きます。名前で絞り込めて、選ぶと末尾に付きます。外すのは行のゴミ箱
- **並べ替える・小窓に出し入れする** — 左端の取っ手をつかんで運びます。小窓の見出しのすぐ下に落とすとその中へ入ります
- **名前とアイコンを変える** — アイコンも一覧から選べます
- **初期配置に戻す** — そのメニューだけ元に戻ります

並びは**この端末だけのもの**です。部屋の保存ファイルには入らず、同じ部屋のほかの人にも影響しません。
別の端末で同じ並びを使いたいときは、「書き出す」でファイルに保存して向こうで「読み込む」を押します。

並びを書き換えても、使える機能は増えません。GMツールのタブはGMのときだけ出ますし、一覧に出る項目も
そのロールが使えるものだけです。

## 🐛 直った不具合

- Firefoxで、別ウィンドウに出したパネルのプルダウンが開きませんでした
- チャット窓を2つ開いていると、「返信」を押したときにもう一方の窓へカーソルが移っていました
- 誰にも見えないコマが移動範囲の敵味方の計算に入っていて、居場所が範囲の欠けから読めていました
- インベントリのリソースの数値が固定の濃い灰色で書かれ、ダークテーマでは灰色に灰色で読みにくくなっていました。
  色が付くのは正気度が8割以下に落ちたときだけになり、ほかはテーマの色で出ます
- テーブルの光源が二重に保存されていました
- 塗りのレイヤーを消しても、テーブルの上の塗りが残っていました
- マップエディターで、ほかの人がテーブルに付けた見た目を上書きすることがありました
- カットインの「自分だけで再生」ボタンに、アイコンではなく文字が出ていました

## ⚠️ 以前の版との互換

部屋設定に増えた項目は、**パネルで触れるまで未設定のまま**です。触っていない部屋は今までどおりに動きます。

メニューの並びはブラウザに保存されます。部屋の保存ファイルの形は変わりません。

# v1.53.0

2026-09-11リリース

チャットログを、卓の雰囲気に合わせた装飾つきで書き出せる版です。羊皮紙、ノワール、ターミナルなど14の形式があり、保存する前にプレビューで仕上がりを見比べられます。

キャラクターシートでは、グループやセクションを丸ごと複製したり、テンプレートとして取っておいたりできるようになりました。似た行が並ぶ表を、1行ずつ作り直さずに済みます。

## 📜 ログを卓の雰囲気で書き出す

チャットのメニューから**タブ設定**を開くと、「ログ保存」に**形式**が増えています。これまでの「標準」「CoCログ形式」に、装飾つきの14形式が加わりました。

| 形式       | 向いている卓           |
| ---------- | ---------------------- |
| 羊皮紙     | 剣と魔法の冒険譚       |
| 和紙       | 和風・時代物           |
| ゴシック   | 吸血鬼・耽美な物語     |
| 怪奇       | 恐怖と狂気の記録       |
| ノワール   | 探偵・ハードボイルド   |
| 電脳       | 近未来・サイバー       |
| ターミナル | ハッカー・レトロSF     |
| 星海       | 宇宙冒険・幻想譚       |
| 作戦       | ミリタリー・メカ       |
| 蒸気       | スチームパンク         |
| 大海原     | 海洋冒険・航海         |
| トーク     | 現代もの・日常もの     |
| ノート     | 学園もの・青春もの     |
| ポップ     | コメディ・にぎやかな卓 |

装飾つきの形式では、ログの冒頭に部屋とタブの名前、ログの日時の範囲、発言の数、参加者の一覧が並びます。日付が変わるところには区切りが入り、同じ人が続けて話した発言はひとかたまりに見えます。

ダイスの結果はカードになり、最後の値が大きく出ます。クリティカル・ファンブル・成功・失敗には印が付くので、読み返したときに山場がすぐ見つかります。シークレットダイスは伏せたままです。

「全タブ」で書き出したログは、開いたあとでタブごとに絞り込めます。ファイル1つで完結していて、ネットにつながっていなくても同じ見た目で開けます。スマートフォンの幅でも崩れず、印刷すると白い紙に濃い文字で出ます。

既定は「標準」のままで、「標準」と「CoCログ形式」が書き出す中身も変わりません。これまでの「CoCログ形式で出力」のチェックは、形式の選択肢に移りました。選んだ形式はそのブラウザに残ります。詳しくは[チャットの基本](/manual/chat#ログの書き出し)にあります。

## 👀 保存する前に見比べる

形式の隣の**プレビュー**を押すと、専用のパネルが開きます。左に形式が並び、選ぶと、保存されるファイルそのままの姿で右側に映ります。

プレビューに使うのは直近の60件の発言です。まだ誰も話していないタブでは、見本の会話で見せます。「このタブ」と「全タブ」を切り替えられ、気に入った形式が見つかれば**この形式で保存**でそのまま書き出せます。保存されるのは、プレビューに映った分ではなくタブ全体です。

## 🧬 グループやセクションを複製する

シートのグループやセクションの見出しに、**複製**のボタンが付きました。中の項目ごとコピーされ、すぐ下に入ります。名前が重なるときは「義眼2」のように番号が付きます。

## 🔖 テンプレートとして取っておく

見出しの**テンプレートとして保存**を押すと、その部分の写しがコマに残ります。元の部分を消しても、テンプレートは消えません。

保存したテンプレートは、キャラクターシートの**設定**タブの**テンプレート**欄に並びます。シートと同じ画面で編集できるので、中の値を空にする、名前を使い回しやすいものに変える、選択肢を足す、といった下ごしらえをしておけます。テンプレートの複製や削除、シートの末尾へ新しいセクションとして足す操作も、この欄から行います。

シートのどの見出しからも、**テンプレートから追加**で呼び出せます。見出しの中に収まるならその中へ、収まらなければ一段外の直後へ、どこにも収まらなければ新しいセクションとして入ります。同じ部分をもう一度保存すると、前のテンプレートは上書きされず、別のテンプレートが増えます。

テンプレートはコマと一緒に保存され、部屋データにもそのまま入ります。テンプレートの中にある効果や範囲は、シートに戻すまでコマの右クリックメニューには出ません。詳しくは[シートの項目](/manual/data-element#テンプレート)にあります。

## 🦾 見本キャラクターのパーツ表

新しい部屋に最初から置かれている見本のキャラクターのシートに、**パーツ**のセクションが加わりました。頭・腕・胴・脚がそれぞれ1つの表で、1行が1つのパーツです。

各パーツには、タイミング・コスト・射程・効果と、**損傷**と**使用**のチェックがあります。修理しても使った事実は消えないので、2つは別々のチェックにしています。**使用**の列見出しのボックスを押せば、手番の終わりに列ごとまとめて外せます。複製やテンプレートを試す題材にもどうぞ。

## 🐛 直った不具合

**行を持つグループで、アイコン選択が下の行に隠れていました**。一覧のほとんどが見えず、押すこともできませんでした。いまは選択を開いているあいだ、見出しが下の行より手前に出ます。

## 🧩 そのほか

- アイコン選択の「キャラクター」に、手と体と足のアイコンが加わりました。同梱のアイコンには胴や靴がないため、体は腕を広げた人の姿、足はローラースケートで表しています
- 書き出すログの立ち絵を、これまでの倍の解像度で埋め込むようにしました。高精細な画面でもぼやけません

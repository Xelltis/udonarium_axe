# v1.69.0

2026-10-21リリース

GMが、部屋に足された画像と音声を、部屋全体から削除できるようになりました。

部屋設定に「通知」タブを加え、ラウンドの進行などのシステム通知を、種類ごとに好きなタブへ送れるようにしました。リソースの詳細設定には、現在値が最大値を超えられる「オーバーリソース」を加えました。

部屋のサーバーでは、運営する人の措置（BAN、緊急停止、置けないようにした画像と音声、部屋に置ける量の上限）を、画面ではっきり知らせるようにしました。運営する人が問い合わせ先を出していれば、その知らせの下に出ます。部屋の中の画像・音声・部屋そのものを、運営する人に通報することもできます。

## 🗑️ 画像と音声の削除（GM）

画像パネルで画像にチェックを入れて**削除**を押すか、ジュークボックスの各行のごみ箱のボタンを押すと、部屋から削除できます。削除できるのはGMだけです。

確認には、その画像や音声を使っているコマや背景などの数が出ます。削除すると、全員の画面から消え、あとから入った人にも届きません。部屋のサーバーでは、サーバーの置き場所からも消えます。流れていたBGMや環境音は止まります。

削除は取り消せません。GMが同じファイルをもう一度足すと、使っていたところにそのまま戻ります。GM以外の人が足しても取り込まれず、GMだけが足し直せると出ます。

くわしくは[画像](/manual/images#remove)と[ジュークボックス](/manual/jukebox#remove)にあります。

## 📢 システム通知の送り先

部屋設定に「通知」タブを加えました。システムがチャットに書く知らせを7つの種類に分け、種類ごとに、送るタブを選べます。

| 種類                   | 既定の送り先 |
| ---------------------- | ------------ |
| ラウンド・手番の進行   | 一番左のタブ |
| 盤上のダイスの公開     | 一番左のタブ |
| トリガー               | 一番左のタブ |
| 移動・交戦エリア・騎乗 | システムタブ |
| カード                 | システムタブ |
| BGMの再生設定          | システムタブ |
| 接続・部屋の管理       | システムタブ |

会話用と戦闘用でタブを分けている卓なら、タブの並びを変えずに、ラウンドの進行だけを戦闘用のタブへまとめられます。**送らない**も選べます。何も選ばなければ、今までどおりの場所に出ます。選べるのはGMだけです。戦闘タブの「ラウンド」の欄からも、通知タブへ移れます。

くわしくは[部屋設定](/manual/room-settings#システム通知の送り先)にあります。

## ➕ オーバーリソース

リソースの詳細設定に、「マイナスリソース」と並べて「オーバーリソース」を加えました。入れた項目は、現在値が最大値を超えられます。

命中の補正を`命中V 1/1`のように持ち、戦闘中に`:命中V+2`で`3/1`へ上げ、戦闘が終わったら`:命中V={命中V^}`で`1/1`へ戻す、という使いかたができます。チャットの`L`やリモコンの「最大値制限」を付けた増減は、入れていても最大値で止まります。HPやMPのように入れていない項目は、今までどおり最大値で止まります。

くわしくは[データ項目](/manual/data-element#リソースの現在値と最大値)にあります。

## 🚩 運営する人への通報

部屋のサーバーで遊んでいるときは、部屋の中の画像・音声・部屋そのものを、部屋のサーバーを運営する人に通報できます。GM・PL・見学の誰でも通報できます。

画像パネルの各画像とジュークボックスの各行には旗のボタンを置き、接続パネルには**この部屋を運営者に通報**を加えました。理由を500字まで書いて送ると、受付番号が出ます。通報には、送った人の回線とアカウントの情報も一緒に送られます。

くわしくは[部屋とロビー](/manual/rooms#report)にあります。

## 🛡️ 部屋のサーバーの運営者の措置

部屋のサーバーを運営する人が措置を取ったとき、何が起きたかを画面で知らせるようにしました。

- BAN：止められたアカウントや回線は、つなぎ直そうとせずに止まり、チャットに「このアカウントか回線を止めているため、部屋に入れません」と出ます。招待リンクやロビーの一覧でも、止められていることを出します
- アップロードの緊急停止：止まっているあいだに足した画像や音声は自分の画面にだけ出て、再開されてから部屋に届きます。止まったときと再開したときに、知らせが出ます
- 置けないようにした画像と音声：その画像や音声は、ほかの参加者に届きません。知らせが出ます
- 部屋に置ける量の上限：上限を超えると「部屋の置き場所がいっぱいで、足した画像や音声は部屋に保存されません」と出ます。いまいる人には届きますが、あとから入った人には届きません
- 部屋の削除：運営する人が部屋を削除したときも、GMが削除したときと同じように知らせます

運営する人が問い合わせ先を出していれば、BANや緊急停止の知らせの下に、その問い合わせ先がリンクで出ます。

くわしくは[接続が切れたとき](/manual/connection#まず確かめること)にあります。

## 🖱️ 作った直後のコマをつかめないことがあった

コマを作った直後に名札などでつかんで動かすと、少しして元の場所へ戻ってしまうことがありました。「動きを減らす」を入れていると起きやすい不具合でした。今はつかんだまま動かせます。

## ⚠️ 以前の版との互換

削除した画像と音声は、v1.68.0以前の人の画面には残ります。その人から、この版の人の画面へ戻ることはありません。

v1.68.0以前の人がラウンドを進めると、通知タブの設定にかかわらず、ラウンドの知らせは一番左のタブに出ます。v1.68.0以前のGMが部屋設定を変えると、通知タブの設定は既定に戻ります。

オーバーリソースを入れた項目も、v1.68.0以前の人が値を変えると、最大値で止まります。

通報、問い合わせ先、部屋に置ける量の上限は、部屋のサーバーが対応しているときだけ働きます。対応していない部屋のサーバーでは、通報を送ると「この部屋のサーバーは通報を受け付けていません」と出ます。

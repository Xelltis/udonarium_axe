# v1.18.2

2026-06-17リリース

ブラウザを開き直すとユーザーIDが`???`のまま接続できないことがある問題を修正しました。

## 🐛 不具合修正

- ブラウザを閉じて開き直すとIDが`???`のままになる問題を修正しました。タブを閉じて開き直したり、PCを再起動したあとの初回アクセスなどで、ユーザーIDが`???`のままルーム一覧を開けないことがありました。ページを再読み込み（F5）すると直り、別タブでは再発する、という症状です。
  - 原因は、起動時の設定読み込み完了の通知が、それを待ち受ける接続開始処理よりも先に発生してしまうことがある点でした。そうなると、接続の開始が一度も呼ばれませんでした。特に、設定ファイルがブラウザにキャッシュされていて読み込みが速いときに起きていました。
  - 設定読み込み完了の通知を後から受け取っても取りこぼさないようにし、タイミングやキャッシュの状態に関わらず確実に接続を開始するよう修正しました。F5による回避は不要になります。

::: tip 接続まわりの安定化（v1.18.1と合わせて）
`???`のままになる原因は二系統ありました。[v1.18.1](/release-notes/v1.18.1)ではトークン発行サーバーのコールドスタートを、本リリースではブラウザ起動時のタイミング問題を、それぞれ修正しています。
:::

# v1.72.0

2026-10-27リリース

交戦のようすを全員の画面に大きく見せる「戦闘カットイン」を加えました。攻撃する側と受ける側のコマを左右に並べ、エフェクト・ダメージの数字・リソースのバーの減り・撃破までを見せます。

チャットでは、発言の一部を太字にしたり、書体・大きさ・色を変えたりできるようになりました。ほかに、グラフィックアクセラレーションが無効なブラウザへの案内と、ホットバーで選んだエフェクトのプレビューを加え、いくつかの不具合を直しました。

## ⚔️ 戦闘カットイン

画面いっぱいに帯が開き、攻撃する側が踏み込んでエフェクトを放ちます。当たった瞬間に受けた側が揺れ、ダメージや回復の数字が飛び出して、コマの頭上と同じリソースのバーが減ります。受ける側は4体まで並びます。画面のどこかを押すか、Escキーを押すと閉じます。続けて出したカットインは、順番に再生します。

出し方は次の5つです。

- **チャット**: `t:HP-10 《vs》`のように、リソース操作の発言に`《vs》`を付けると、発言したキャラクターが`t:`の対象を攻撃します。同じ行に`《ファイア》`のようにエフェクトの名前を書くと、それを攻撃の演出にします。リソースが変わる行は、数値が変わるのを待ってから再生します
- **リモコン**: 「戦闘カットイン」ボタンで、リモコンのキャラクターがチェックしたターゲットを攻撃します。「戦闘カットインでも見せる」にチェックを入れると、リモコンでリソースを変えるたびにカットインも出します
- **コマの右クリック**: 「戦闘カットイン」の「このコマで攻撃」
- **スイッチ**: スイッチの動作に「戦闘カットイン」を加えました
- **パネル**: 左のメニューの「メディア」にある「戦闘カットイン」パネルの「全員に再生」。「自分だけで見る」は、自分の画面にだけ再生します

ターゲットがいないときは、GMが決めた左右の組で戦います。GMは、パネルかコマの右クリックで、コマを左右の組に入れます。組で再生すると、手番のコマ、押した人のコマ、左の組の先頭の順に、組にいるコマが攻撃します。攻撃を受けるのは、反対側の組のコマ（4体まで）です。

コマごとに、攻撃に使うエフェクトを決めておけます（コマの右クリックの「攻撃演出を選ぶ…」）。決めていないコマは、ダメージや回復の量に合った演出になります。

撃破の演出は、指定したリソース（既定はHP）が0以下になったコマに出ます。撃破の演出を出すかどうか、判定に使うリソース、撃破の演出の種類は、パネルの部屋の設定でGMが変えられます。

### 舞台

背景には、ファンタジー・現代・ホラー・サイバーパンク・ロボットSFの5つの舞台を、夜と昼の2通りずつ用意しました。既定はファンタジーの昼です。ホラーの昼は、曇った午後の廃村です。

GMは、部屋の画像を「画像を登録」で24枚まで登録して、舞台の代わりに使えます。登録した画像は、部屋のセーブに入ります。

### 出さない設定と見学者

パネル上部の「この画面で戦闘カットインを出す」を外すと、自分の画面にだけ出なくなります。その画面では、攻撃のエフェクトと撃破の演出を、テーブルの上のコマに出します。

スイッチは、GM・PL・見学者のだれでも押して出せます。リモコン、コマの右クリック、パネルの「全員に再生」で全員に出せるのは、GMとPLです。見学者は「自分だけで見る」で、自分の画面にだけ再生できます。

詳しくは[戦闘カットイン](/manual/battle-cut-in)を参照してください。

## ✍️ 文字の装飾

発言の一部を`**`で囲むと、太字になります。ほかの装飾は、`[名前]`で始めて`[/名前]`か`[/]`で閉じます。

```
今日は**晴れ**です
[明朝]古の契約に従い、[/明朝]扉は開かれた。
[赤][大]危ない！[/大][/赤]
```

- 斜体・取り消し線、3段階の大きさ（小・大・特大）、6種類の書体（明朝・丸ゴシック・手書き・ポップ・ドット・ゴシック）、11色の文字色と色コード（`[#f80]`など）を使えます。名前は英語と韓国語でも書けます
- 入力欄の色設定の横にある「装飾」ボタンからも選べます。先に文字を選んでおくと、選んだ部分を囲みます。複数の行を選んで太字にすると、1行ずつ囲みます
- 白と黒の文字は、明るいチャットでも暗いチャットでも読めるよう、反対の色で細く縁取ります
- 装飾は、チャット・共有メモ・カードの文面・ノベルモード・配信用画面・HTML形式で保存したログに付きます。テキスト形式のログ・ティッカー・頭上の吹き出し・チャット検索・発言のコピーでは、記法を外した文字になります
- 書体は、発言で使われたときに初めて読み込みます
- 閉じていない`[赤]`や、知らない名前の`[注意]`は、書いたとおりに表示します。これまでの発言の見た目は変わりません。装飾になる記号をそのまま書きたいときは、`\**`や`\[赤]`のように前に`\`を付けます

配信用画面では、ルビも読みがなとして表示するようにしました。

詳しくは[チャットの記法](/manual/chat-syntax#文字の装飾)を参照してください。

## 🖥️ グラフィックアクセラレーションの案内

ブラウザのグラフィックアクセラレーションが無効になっていると、3DのテーブルをGPUを使わずに描くため、とても重くなります。手元で測ったときは、1秒に1コマほどしか描けませんでした。

そのようなブラウザでAxeを開くと、そのたびに、グラフィックアクセラレーションを有効にするよう勧める案内を出します。Chrome・Edge・Firefoxそれぞれの設定の場所も載せています。テーブルの見た目は変えません。

## 🎯 ホットバーのエフェクトのプレビュー

ホットバーの枠の設定でエフェクトを選ぶと、一覧の下でそのエフェクトを繰り返し再生して見せます。音は鳴らさず、ほかの人の画面にも出ません。

## 🛠️ 直したこと

- サイズを0にしたコマは点として描かれますが、視界・持っている明かり・見えるかどうかの判定・一人称視点・ダイスの受け皿では1マスの大きさとして扱っていたため、半マスずれていました。今は描かれた点の位置で扱います
- サイトのデータを保存しない設定のブラウザで、テーマ・ウィジェットの配置・スマホの画面の配置・リプレイの設定・最初の言語・エフェクトの自動再生が動かないことがありました
- 一人称視点で、画像を並べて敷く設定のブロックの画像が、面いっぱいに引き伸ばされていました。今はテーブルと同じく1マスずつ並べます。ブロックの上の面と下の面の画像が、視界の端で縮んだりずれたりすることもなくなりました
- 一人称視点で、画像を設定していないテーブルの壁が、灰色の面として出ていました。今はテーブルと同じく出しません
- リモコンの報告に「feature.controller.remote…」のような文字が出ていました。英語の表示では、投票とロビーの人数にも同じような文字が出ていました
- チャットや共有メモなどで、`example.com?x=1`や`example.com#a`のように`https://`を付けずに書いたアドレスは、ドメインまでしかリンクになりませんでした。今は`?`や`#`の後ろまでリンクにします

## 🧱 内部の整理

Axeの内部の作りを大きく整理しました。画面や操作は変わりません。

## ⚠️ 以前の版との互換

v1.71.1以前の版の人の画面には、戦闘カットインも、その代わりのテーブル上の演出も出ません。スイッチの「戦闘カットイン」の動作は、v1.71.1以前の版では何もしません。

v1.71.1以前の版で部屋を保存し直しても、コマの左右の組と攻撃演出の設定は消えません。

文字の装飾は、v1.71.1以前の版やほかのツールでは、記法がそのまま表示されます。

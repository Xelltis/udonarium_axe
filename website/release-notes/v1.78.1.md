# v1.78.1

2026-11-13リリース

不具合修正のリリースです。戦場の霧や暗闇でターゲットにしたコマが見えなくなったあとも、ターゲットが付いたままで外す手段がなく、`t:`のダメージが見えない相手に届いていたのを直しました。見えなくなったコマのターゲットは自動で外れます。合わせて、ターゲットがあるあいだは画面の下に一括で外す帯を出し、手番が次のキャラクターに移ったときはターゲットを全部外すようにしました。

## 🎯 見えなくなったコマのターゲット

戦場の霧を使っているセッションで、プレイヤーが敵のコマをターゲットにしたあと、その敵がパーティの視界の外へ移動すると、プレイヤーの画面からそのコマは消えます。ところがターゲットは付いたままでした。見えないコマは押せないので外す手段がなく、そのまま`t:HP-10`のような行を送ると、見えない相手にダメージが届いていました。

今は、ターゲットにしたコマが自分から見えなくなった時点で、そのコマのターゲットが外れます。戦場の霧の向こうへ行ったとき、暗闇に入ったとき、ステルスになったとき、自分のコマが離れて視界から外れたときのどれも同じです。ターゲットにできるのは見えているコマだけなので、外れる条件もそれと同じにしました。GMはテーブルの全部が見えているので、GMのターゲットは外れません。GMが「プレイヤー視点でレビュー」で見ているあいだも外れません。

くわしくは[暗闇・視界・光源](/manual/vision-lighting#キャラクターの視界)にあります。

## 🎯 ターゲットを一括で外す帯

ターゲットにしたコマが1体でもあるあいだ、画面の下に「ターゲット N体」の帯が出ます。帯の**すべて外す**を押すと、ターゲットが全部外れます。これまでも`Shift + T`やコマの右クリックメニューから全部外せましたが、ターゲットがいま何体いるかを、見える場所で確かめられるようにしました。ターゲットがないあいだは帯は出ません。

くわしくは[キャラクター（コマ）](/manual/character#コンテキストメニュー)にあります。

## 🎯 手番が移ったときのターゲット

行動順で手番が次のキャラクターに移ると、部屋にいる全員の画面でターゲットが全部外れます。ラウンドを閉じたときも同じです。前の手番で狙っていた相手が、次の手番の`t:`に残らないようにするためです。設定はなく、常に外れます。ターゲットは各自のブラウザだけで持っているので、ほかの人の画面に影響する変更ではありません。

くわしくは[行動順](/manual/turn-order#手番を進める)にあります。

## ⚠️ 以前の版との互換

部屋のデータは変わりません。v1.78.0の人とも、今までどおり同じ部屋で遊べます。ターゲットは自分のブラウザだけの指定なので、この版の人の画面だけで外れます。v1.78.0の人の画面では、これまでどおり自分で外します。

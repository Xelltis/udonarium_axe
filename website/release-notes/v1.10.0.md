# v1.10.0

2026-06-02リリース

## ✨ 改善

### チャットの自動追従が「最下段にいるときだけ」に

チャット設定の **「スクロール位置を最新に追従」** をオンにしていても、ログを少しでも上に遡って読んでいる間は、最下段に引き戻されなくなりました。

- **最下段を表示しているとき** … 新着発言で自動的に追従します
- **1行でも遡って読んでいるとき** … 自動追従を一時停止します（他者の入力中表示や新着発言でも動きません）
- **最下段に戻ると** … 追従を自動で再開します

ログをほんの少しだけ遡って確認したいときに、そのつど追従のチェックを外す必要がなくなりました。

## 🐛 不具合修正

### 固定した共有メモがドラッグできてしまう問題を修正

**固定（ロック）した共有メモ**が、鍵アイコンが付いているにもかかわらずドラッグで動かせてしまう不具合を修正しました。固定中はドラッグで移動できなくなり、表示と挙動が一致します。

# v1.33.0

2026-08-12リリース

**記録が読み物になった**回です。あわせて、v1.32.0で入れたシステムタブの作りが根本から間違っていたので直しました。

## ✨ 新機能・改善

### リプレイを読み物として書き出せるようになりました

セッションの記録から、**そのまま読める文章**を作って保存できます。動画（MP4）と違って軽く、そのまま公開できます。

リプレイのワークスペースにある **「読み物にする」** から、組み方を選んで書き出してください。Markdownファイルになります。

| 組み方   | 出てくるもの                         |
| -------- | ------------------------------------ |
| **小説** | 話者とセリフを地の文としてつないだ形 |
| **台本** | 「名前: セリフ」と話者を頭に置いた形 |

- **章の見出し**は、記録に付けた目印がそのまま`##`の見出しになります
- **盤面の動きも入れる**を選ぶと、コマの移動やダメージも文章に混ざります。既定では**入りません**（入れると読み物ではなく操作ログになるためです）
- **章に経過時間を添える**を選ぶと、各章の見出しに卓の開始からの時間が入ります
- 書き出す前に**何行になるか**が出ます

見える範囲は**書き出す人のロールに従います**。GMだけに見えていた発言や密談は、PLが書き出した文章には入りません。動画の書き出しとまったく同じ絵コンテを使っているので、章の切れ目も地の文の扱いも動画と揃います。

### ダイスの出目そのものが記録に残るようになりました

これまでは「2D6 → 5 + 3 → 8」のような**文章だけ**が残っていて、あとから「今日1D100で何が出たか」を数え直せませんでした。

v1.33.0からは、振ったダイスの**一つひとつの目**と**成功・失敗・クリティカル・ファンブル**が、発言といっしょに記録されます。画面の見た目は変わりません。これは「今日のダイス運」のような集計をこれから載せるための準備です。

- **これから振る分**が対象です。すでに残っているログからは復元できません
- 盤面のダイスコマは、録画中であれば目の変化が記録に残ります

### メニューの並びを意味ごとに整えました

左上のメニューは、機能が増えるたびに末尾へ足されていて、インベントリがカットインの後ろにあるような並びになっていました。**3つのまとまり**で並べ直しました。

1. 卓で開いておくもの — 接続 / チャット / テーブル設定 / インベントリ
2. 卓の見せ方 — ノベルモード / 画像 / ジュークボックス / カットイン
3. 出し入れ — キャラ取り込み / ZIP読込 / 自動保存・復元 / リプレイ

項目そのものは増減していません。

## 🐛 修正

### 部屋データを読み込むとシステムタブが壊れていた問題

**v1.32.0でシステムタブを使っている場合は、この修正が入るまで部屋データの読み込みに注意が必要でした。**

保存しておいた部屋データを読み込むと、システムタブが**見た目だけ残って中身が繋がっていない**状態になっていました。その結果、次のことが起きていました。

- システムタブを開いても**何も表示されない**
- 入退室などの知らせが**どこにも出ない**
- 続けてもう一度読み込むと、**「システム」タブが2つ**に増える
- 読み込んだ直後、選んでいたタブが行方不明になり、**発言できなくなる**ことがある

原因は、システムタブを部屋データの一部として扱っていたことでした。v1.33.0では、システムタブは**卓（ブラウザ）側の備品**という扱いになります。

- 部屋データには**保存されません**（読み込みで作り直されることも無くなりました）
- 部屋データを読み込んでも**消えません**。それまでの知らせも残ります
- v1.32.0で保存した部屋データにシステムタブが入っていた場合、読み込むと**中身が1枚にまとめ直され**ます

古い（v1.32.0より前の）部屋データを読み込んだときも、システムタブは1枚だけ、正しく繋がった状態で用意されます。

### システムタブに、意味のない設定が並んでいた問題

チャットのタブ設定で、システムタブが**ふつうのタブと同じ**に扱われていました。名前を変えられ、並び替えられ、発言を許可でき、部屋データとして書き出すことまでできてしまう状態でした。

システムタブは**知らせの貼り紙**なので、次のようになりました。

- **誰も書き込めません。** PLもゲストもGMも同じです。システムタブを開いても発言欄は出ません
- **全員に見えます。** 見せる相手を選ぶ設定は無くなりました
- **名前と並びは固定**です。名前は「システム」、位置は末尾です
- **消せません**（v1.32.0から変わりません）
- **部屋データとしては書き出せません**
- **CoC形式のログ書き出しはできません。** 会話ログの体裁なので、入退室の記録には使いません
- **「全タブのログを保存」はシステムタブを選んでいるときは出しません。** もともとこのタブを含まない書き出しなので、隣に並んでいると紛らわしいためです

残っているのは「このタブのログを保存」と、ログの削除だけです。

::: warning v1.32.0のお知らせの訂正
v1.32.0のリリースノートで「システムタブの**名前は変えられます**」とお伝えしましたが、この扱いは取り消しました。名前は固定になります。
:::

# 遊ぶときの困りごと

卓の最中や直前につまずきやすいところを、症状のほうから引けるように並べています。
設置と運用の質問は [自分で設置するときの質問](/guide/faq) にあります。

## 音は鳴るのに、演出が画面に出ません {#motion}

OS 側の「動きを減らす」設定です。
Axe は既定でこれに従い、演出の絵だけを止めて効果音は残します。

確認したのは Windows 11 の場合で、**設定 → アクセシビリティ → 視覚効果 → アニメーション効果** です。
動作を軽くする目的でオンにされることも多い項目なので、意図せず有効になっている場合があります。
macOS・iOS・Android にも、アクセシビリティの中に同じ趣旨の項目（動きを減らす／視差効果を減らす）があります。

OS の設定なので、Chrome も Firefox も Edge も同じ値を読みます。ブラウザを変えても直りません。

雨が降らずに画面が少し暗くなるだけ、霧が白くなるだけ、というのも同じ症状です。
空気の色は止めても残り、降る粒だけが消えるためこう見えます。

OS の設定はそのままにして卓の演出だけ出したいときは、FAB メニューの
[エフェクトボタン](/manual/theme#エフェクトの表示)を **常に再生** にしてください。

## 部屋が消えました — 0 人になった時点で解散します {#room-gone}

最後の 1 人がタブを閉じれば、その部屋はもうありません。

戻せる可能性はあります。部屋につながずにアプリを開くと、そのブラウザに[自動保存](/manual/save-load#自動保存)のひかえがある場合に画面の上へ案内が出ます。
効く条件と効かない条件は [部屋とロビー](/manual/rooms#gone) にまとめました。

## GM になれません — 部屋を作った人が GM です {#gm}

ほかに GM がいる間、GM ボタンは押せない作りです（横取り防止）。

自分が回すなら、自分で部屋を作ってください。作成した人がそのまま GM になります。
すでに誰かの部屋にいるなら、その GM に割り当ててもらうことになります（→ [ロール](/manual/roles)）。

## 他のツールで作ったキャラクターを持ち込めますか {#import}

はい。次のどれかを貼り付ければコマになります。

- ココフォリアのコマ JSON
- キャラクター保管所・キャラクターシート倉庫の JSON か URL
- ゆとシートの JSON か URL
- CharaXiv の「ココフォリア用コピー」出力

貼り付け先は、FAB メニュー（画面左端の丸いハンバーガーボタン）の **部屋設定 → ユーティリティ → キャラ取り込み** です。
いあきゃら・Charaeno・TRPG スタジオなど多くの作成サービスは「ココフォリア用コピー」を備えているので、その出力を貼るのがいちばん確実です。
対応の細かいところは [キャラクターの取り込み](/manual/character-import) にあります。

## ココフォリアの卓をそのまま持ってこられますか {#ccfolia}

実験的機能として対応しています。
書き出したルームデータ zip をテーブルにドロップすると、盤面画像・マス数・画像パネル・コマを再現します。
ココフォリアのシーン 1 つが、AXE のテーブル 1 枚になります。テーブルを切り替えれば、そのままシーンの切り替えです。

BGM はココフォリアの仕様上 zip に含まれないため持ってこられません。カード・カットインも未対応です。
→ [ココフォリアのルーム取り込み](/manual/room-import)

## スマートフォンで遊べますか {#mobile}

遊べます。幅の狭い画面では[専用のレイアウト](/manual/mobile)に切り替わり、卓とチャットの上下分割・下部のメニュー・長押しのコンテキストメニューで操作します。
横向きでも、ホーム画面に追加してアプリのように起動しても使えます。

動作確認がもっとも厚いのは **デスクトップ版 Chrome** です。
マップエディターのように線を引く機能は、指よりマウスのほうが精密に扱えます。

## 誰かのコマだけ動かなくなりました {#stuck}

その人との接続が落ちかけています。多くは自動でつなぎ直すので、まず待ってください。
25 秒ほど何も届かなければ、Axe のほうから切断と判断して再接続に入ります。

自分の画面と他の人の画面で中身が食い違っているときは、接続パネルの **部屋のデータを同期し直す** を押してください。
接続はつないだまま、参加者どうしでデータを突き合わせ直します。
手順の続きは [接続が切れたとき](/manual/connection) にあります。

## ゲームの中身はサーバーに残りますか {#privacy}

残りません。テーブル上のものは WebRTC の P2P 通信でブラウザ間を直接行き来します。
サーバーがするのは接続の仲介と入室トークンの発行だけです。

裏を返すと、卓のデータはどこにも預けられていません。
だからこそ、残したい卓は自分で保存する必要があります。

## ここに無いことは {#ask}

[操作マニュアル](/manual/) を検索するか、[GitHub の Issue](https://github.com/Xelltis/udonarium_axe/issues) で聞いてください。

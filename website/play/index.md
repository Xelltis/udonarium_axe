# 遊びかたの案内

このページは、Axeで遊ぶ人が、最初にどのページを読めばよいかを案内します。
招待リンクで参加する人と、GMとして部屋を作る人とで、読むページが違います。

| いまの状況             | 読むページ                                                                                        |
| ---------------------- | ------------------------------------------------------------------------------------------------- |
| 招待リンクをもらった   | [招待リンクをもらったら](/play/join)。リンクを開けば、そのまま部屋に入れます                      |
| GMとして卓を回す       | [はじめてのセッション](/play/first-session)。部屋を作るところから、終わって保存するまでの流れです |
| まず1人で試したい      | 下の[1人で試す](#try-alone)                                                                       |
| 操作のしかたを調べたい | [操作マニュアル](/manual/)。機能ごとにページが分かれています                                      |
| うまく動かない         | [遊ぶときの困りごと](/play/faq)                                                                   |

もっとも多く動作確認しているのは、デスクトップ版のChromeです。
スマートフォンでも遊べます。

## 1人で試す {#try-alone}

1人で確かめるだけなら、部屋を作る必要はありません。
[デモサイト](https://axe.xelltis.com)を開いたまま、コマを動かし、地形を置き、ダイスを振ってみてください。

通信を切りたいときは、接続パネル（FABメニューの**接続**）で**オフライン**を選びます。
押すとページが読み込み直され、いまの部屋からは抜けるので、卓の最中には使わないでください。
保存と読み込みはオフラインのままできるので、次の卓の下ごしらえに使えます（→ [部屋とロビー](/manual/rooms#offline)）。

## デモサイトで遊ぶときの注意

短いセッションなら、デモサイトのまま遊んでもかまいません。
ただし、卓を続けて預ける場所には向きません。理由は次の3つです。

- ロビーは、ほかの人と共用です。一覧には、ほかの人が作った部屋も並びます。人に見られたくない卓には、パスワードを付けてください
- 卓は、自動では残りません。参加者が0人になると、部屋は消えます（→ [部屋とロビー](/manual/rooms#gone)）
- 予告なく止めたり、初期化したりします。動作確認と開発のための場所なので、予定した卓の当日に止まっていることもありえます

毎週のように続けて遊ぶなら、自分の環境に設置するのが確実です（→ [設置ガイド](/guide/)）。

## よくある困りごと

| こうなった                   | 見るところ                                 |
| ---------------------------- | ------------------------------------------ |
| 招待リンクを開いても入れない | [招待リンクをもらったら](/play/join#stuck) |
| 音は鳴るのに演出が出ない     | [遊ぶときの困りごと](/play/faq#motion)     |
| 相手のコマが動かなくなった   | [接続が切れたとき](/manual/connection)     |

## 用語

ここから先で断りなく使う言葉です。

| 言葉                     | 指すもの                                                                                                              |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| 卓                       | セッションそのもの。「卓を回す」「卓を立てる」                                                                        |
| テーブル                 | いま映っているマップ1枚。1つの部屋に何枚でも作れて、場面ごとに切り替えます                                            |
| 部屋（ルーム）           | 参加者どうしをつなぐ入れ物。作った人がGMになります                                                                    |
| パスワード               | 部屋に鍵をかける文字列。招待リンクの画面では「合言葉」と呼ばれています                                                |
| FABメニュー              | 画面の左上の丸いハンバーガーボタン。パネルはここから開きます。メニューの編集では「Fav メニュー」                      |
| 接続パネル（接続情報）   | 名前・役割・ルーム名・招待リンクが並ぶパネル。FABメニューの**接続**から                                               |
| GM / PL / 見学           | 役割。GMは全部見えて全部触れ、見学は読むだけです（→ [ロール](/manual/roles)）                                         |
| コマ                     | テーブルに置く物。キャラクター・カード・ダイス・メモなど                                                              |
| オーナー                 | コマの持ち主。自分がオーナーのコマは、自分で公開範囲を変えられます（→ [情報の公開範囲](/manual/disclosure#オーナー)） |
| 公開範囲                 | コマの中身を誰に見せるか。全員・特定PL・GMのみ（→ [情報の公開範囲](/manual/disclosure)）                              |
| 秘話                     | 特定の人にだけ送る発言（→ [チャットの基本](/manual/chat)）                                                            |
| ダイスボット             | チャットに打ったコマンドでダイスを振る仕組み（→ [ダイスボット](/manual/dicebot)）                                     |
| SkyWay版・部屋のサーバー | 参加者のつなぎかたの2つの方式。どちらで動いているかは、設置した人が決めます（→ [方式を選ぶ](/guide/choose)）          |

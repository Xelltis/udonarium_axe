# 遊びはじめる

いま自分がどこに立っているかで、読むページが変わります。
招待リンクを渡された人と、これから卓を回す人とでは、必要なものがまるで違うからです。

このページは振り分けです。入口は 3 つあり、当てはまるものを 1 つ読めば足ります。
[操作マニュアル](/manual/) と [遊ぶときの困りごと](/play/faq) は通読するものではなく、詰まったときに引くものです。

<div class="choice">

**招待リンクをもらった** <span class="choice__tag">準備ゼロ</span>

リンクを開けばそのまま入室します。決めるのは自分の名前だけです。
→ [招待リンクをもらったら](/play/join)

</div>

<div class="choice">

**自分が卓を回す** <span class="choice__tag">5 分</span>

部屋を作り、出てきた招待リンクを配れば始まります。終わったら保存する、までが一晩の流れです。
→ [はじめてのセッション](/play/first-session)

</div>

三つ目は、まだ誰も呼ばないときです。一人で確かめるだけなら、上の 2 つはどちらも要りません。
[デモサイト](https://axe.xelltis.com)を開いたまま、コマを動かし、地形を置き、ダイスを振ってみてください。
接続パネル（FAB メニューの **接続**）で **オフライン** を選べば通信そのものを切れます。
押すとページが再読み込みされ、いまの部屋からは抜けるので、卓の最中には使わないでください。
書き出しと読み込みはオフラインのままできるので、次の卓の下ごしらえに向きます（→ [部屋とロビー](/manual/rooms#offline)）。

動作確認がもっとも厚いのは **デスクトップ版 Chrome** です。スマートフォンでも遊べます。

## 短い卓ならデモのまま。続く卓は預けられない

デモサイトで一晩遊ぶぶんには、そのまま使ってかまいません。
預ける先として当てにならない、というだけです。理由は 3 つあります。

- **ロビーは共用です。** 一覧には他の人が立てた部屋も並びます。人目に触れたくない卓にはパスワードを付けてください
- **卓は自動では残りません。** 参加者が 0 人になると部屋は消えます（→ [部屋とロビー](/manual/rooms#gone)）
- **予告なく停止・初期化します。** 動作確認と開発のための場所なので、日程が決まっている卓の当日に落ちていることがありえます

毎週の卓を回すつもりになったら、自分の場所を持つのが確実です。
SkyWay の無料枠と静的ホスティングだけで一式そろいます → [クイックスタート](/guide/quickstart)

## 言葉の対応

ここから先で断りなく使う言葉です。

| 言葉                   | 指すもの                                                                       |
| ---------------------- | ------------------------------------------------------------------------------ |
| 卓                     | セッションそのもの。「卓を回す」「卓を立てる」                                 |
| テーブル               | いま映っているマップ 1 枚。1 つの部屋に何枚でも作れて、場面ごとに切り替えます  |
| 部屋（ルーム）         | 参加者どうしをつなぐ入れ物。作った人が GM になります                           |
| パスワード             | 部屋に鍵をかける文字列。招待リンクの画面では「合言葉」と呼ばれています         |
| FAB メニュー           | 画面左端の丸いハンバーガーボタン。パネルはここから開きます                     |
| 接続パネル（接続情報） | 名前・役割・ルーム名・招待リンクが並ぶパネル。FAB の **接続** から             |
| GM / PL / 見学         | 役割。GM は全部見えて全部触れ、見学は読むだけです（→ [ロール](/manual/roles)） |

# はじめてのセッション

用意するものは部屋の名前ひとつです。
GM が部屋を作り、出てきた招待リンクを配れば、あとは全員がリンクを開くだけで卓が始まります。

この順で読めば一晩ぶんの流れになります。
個別の機能を引きたいときは [操作マニュアル](/manual/) へどうぞ。

## 部屋を作るのは、人を呼ぶ直前でいい

Axe は開いた時点でもう卓が動いています。
サンプルのコマが並び、ダイスも振れる状態なので、地形を描いたりマップを組んだりする下ごしらえは、部屋を作る前にひとりで進められます。
部屋は「他の人とつなぐ」ためのもので、卓を持つためのものではありません。

## 1. 部屋を作った人が GM になる

画面左の FAB メニュー（丸いハンバーガーボタン）から **接続** を開き、下の **ロビー（ルーム一覧）を表示** を押します。
ロビーの **新しいルームを作成する** で、ルーム名とパスワードを決めれば部屋ができます。
決められる項目と上限は [部屋とロビー](/manual/rooms#部屋を作る) にまとめました。

作成した人はそのまま **GM** になります。
GM は他の人からは選べないので、卓を回す人が部屋を作ってください。

## 2. 招待リンクを配る

部屋ができると、接続パネルのルーム欄に **招待リンク** が出ます。
その **コピー** を押して、Discord なりチャットなりに貼るだけです。
リンクを開いた人は、ロビーを探すこともパスワードを打つこともなく、その部屋に入ります。

配る前に 2 つ選べます。ひとつは **プレイヤー用 / 見学用** の切り替えで、開いた人の役割がリンクに埋まります。
もうひとつは **合言葉を含める**（パスワードのことです）かどうか。
含めれば開くだけで入室できます。そのぶん、リンクを知っている人は誰でも入れます。
公開の場で募集するなら含めないリンクを配り、パスワードは別の経路で渡してください。

配信のために OBS へ映したいときは、同じ欄の **配信用（透過画面）** を使います（→ [ロール](/manual/roles#招待リンクで参加者を招く)）。

## 3. 卓を用意する

初回は既定のテーブルのままで足ります。床も壁も画像を用意しなくてかまいません。

地図が欲しくなったら、GM ツールバーの **マップ生成** がいちばん早いです。
ダンジョンかフィールドかと雰囲気を選んで押せば、壁も木立も地形として置かれた卓が 1 枚できます。
生成しても卓は勝手に切り替わらないので、セッション中に次の場面を仕込んでも、プレイヤーの画面は今の場面のままです。

凝るなら [マップエディター](/manual/map-editor) でセルを塗り、手描きで済ませたいなら [ホワイトボード](/manual/white-board) に描いてください。
床や壁の画像を差し替えるのは [テーブル設定](/manual/table-setting) からです。

## 4. キャラクターを置く

初回は画像を投げ込むのがいちばん早いです。テーブルへ画像ファイルを **ドロップすると、そのままキャラクターコマになります**。ファイル名が名前になります。

シートごと持ち込むなら、**部屋設定 → ユーティリティ → キャラ取り込み** に、キャラクター保管所・キャラクターシート倉庫・ゆとシート・CharaXiv の URL か JSON を貼ってください。
能力値もリソースもチャットパレットも付いてきます（→ [キャラクターの取り込み](/manual/character-import)）。

ココフォリアで作った卓ごと持ってきたいなら、書き出した zip をテーブルにドロップする道もあります。
ただし BGM はココフォリアの zip に含まれず、カードとカットインも未対応です（[実験的機能](/manual/room-import)）。

## 5. ダイスの種類を決めておく

遊ぶシステムは **部屋設定 → 一般 → 既定のダイスボット** で決めます。ここで選んでおくと、参加者は入った時点でそのシステムの判定を打てます。
決め忘れても各自がチャット欄から選び直せますが、卓の頭で全員に選ばせるより手数が少なくて済みます。
システムごとの書き方は [ダイスボット](/manual/dicebot) にあります。

## 6. 終わったら保存する

**部屋は参加者が 0 人になった時点で消えます。**
最後の 1 人がタブを閉じた瞬間に、その部屋はもうありません。

続きをやるつもりなら、解散する前に FAB メニューの **保存** を押して zip を書き出してください。
テーブルもコマもカードもチャットも、まとめて 1 つのファイルになります。

押し忘れたときの保険として[自動保存](/manual/save-load#自動保存)がありますが、効かない条件が 3 つあります。
プライベートウィンドウ、自動保存を切っている場合、そして別の端末から開こうとした場合です（→ [部屋とロビー](/manual/rooms#gone)）。
本番の卓を預けるなら、やはり zip のほうが確かです。

## 次の卓は、読み込みから始まる

保存した zip は、ブラウザの画面へドロップすれば読み込まれます。
読み込んでから部屋を作っても、部屋を作ってから読み込んでもかまいません。

同じ面子で続けるなら、GM が卓を戻してから招待リンクを配り直す流れになります。

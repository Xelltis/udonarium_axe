# GMの道具

## シーン

- **シーン** — 卓の見た目と部屋の音をまとめて持ち、GMが1回押すだけで切り替える物（`BoardScene`、`@SyncObject('board-scene')`、`domain/scene/board-scene`）。たとえば同じ地図の昼の村・夜の村・燃える村を1件ずつ持つ。変えられる部分は、見せるテーブル・床・背景・空・壁・前景・天候・暗闇・戦場の霧・BGM・環境音・カットイン・ゲーム内時間の時間帯・切り替えのテキスト・暗転の15種で、並びは`BOARD_SCENE_PARTS`（`domain/scene/board-scene-parts`）。パネルは「シーン」（`features/scene/scene-panel`）。シーンは部屋のデータとして保存し、読み込むと置き換わる（`domain/peer/room`）
- **空文字は「変えない」** — 各部分の欄は空文字を「変えない」と読み、シーンは変える部分だけを持つ。画像の欄に`none`（`SCENE_NO_PICTURE`）を書くと、その画像を外す。暗闇と戦場の霧は`on` / `off`、BGMは`stop` / `track` / `playlist`、環境音は`replace` / `stop`、空は`clock` / `none`（`none`は背景画像のまま）で、ほかの値も「変えない」と読む。欄を知らない版のピアが送らなかった欄も空と読むので、その部分は変わらない
- **編集画面** — 部分ごとのチェックで、反映したときに変える部分を選ぶ（`features/scene/scene-editor`）。チェックを入れると、いまの盤面と流れている音から値を埋め、音が流れていなければBGMと環境音は`stop`から始まる。チェックを外すと、その部分の欄（`BOARD_SCENE_PART_FIELDS`）を全部空文字に戻す。音楽つきのカットインは流れるとBGMを止めるので、BGMの部分と一緒に選ぶと注意を出す。ゲーム内時間を24時間で表している部屋では、時間帯の部分は時刻を変えない
- **画像と識別子の保存** — 画像を指す欄はどれも名前が`ImageIdentifier`で終わるので、部屋の保存zipがシーンの画像も拾う。切り替えのテキストに入れたスタンプは`stamps`に識別子を並べ、保存がその絵を拾う。ホットバーの枠とスイッチはシーンを識別子で指すので、シーンは識別子ごと保存し、読み込んでも同じ識別子に戻す（`toAttributesKeepingIdentifier`、`core/sync/persisted-identifier`）。テーブルは保存で識別子が変わるので、保存には見せるテーブルのいまの名前を`tableName`に書く。反映ではテーブルを識別子で探し、見つからなければ、その名前のテーブルが1つだけあるときに名前で探す。名前で見つけたときは、GMの画面がシーンの`tableIdentifier`と`tableName`をいまのテーブルに書き直す
- **反映の順番** — `BoardSceneService.apply`（`application/tabletop/board-scene.service`）は、途中で何も待たずに1回の`GameObject.batch`で反映する。中の順番は、テーブルに見た目を書く → そのテーブルを見せる → 環境音 → BGM → カットイン → ゲーム内時間の時間帯で、最後に`Config.boardScene`へシーンの識別子を書く（パネルの「いまのシーン」の印）。1回のバッチで送るので、部屋の誰の画面にも、古いテーブルが新しい見た目で映ることはない。切り替えのテキストは、新しい見た目を書いたバッチのあとに、システムとして`textTab`のタブ（消えていれば最初のタブ）へ出す
- **書き込む先のテーブル** — 見せるテーブルを指定したシーンはそのテーブルに、指定していないシーンはいま見ているテーブルに見た目を書く。指定したテーブルが消えていれば、見ているテーブルを上書きせず、見た目はどこにも書かない。書くのは、シーンが変える部分のうちテーブルの値と違う欄だけで（`sceneTableWrites`）、すでに同じ見た目のテーブルには何も書かない
- **音とカットイン** — BGMは「止める」「曲を流す」「再生リストを最初から流す」から選ぶ。流れている曲と同じ曲は頭から流し直さず、止まっていれば再開する。同じ再生リストを再生中で、いまの曲がその並びにあれば、そのまま続ける。効果音と環境音のタグを付けた音は、BGMとしては流さない。環境音は、シーンが挙げた音だけを残してほかを止め、まだ鳴っていない音を始める。1つも挙げなければ全部止める。カットインは複数挙げると1つを選んで流し、消えたカットインは選ばない
- **反映を省く** — シーンの右クリックメニューの「BGMを変えずに反映」と「テキストを送らずに反映」は、BGMか切り替えのテキストを持つシーンにだけ出る。ホットバーの「シーン」の枠とスイッチの「シーンを反映」も、BGMを変えずに反映する指定（`keepBgm`）を持つ
- **暗転** — 「暗転」を入れたシーンは、`callSceneFade()`で、自分を含めて部屋にいる全員の画面を暗くし、300ms後（`SCENE_FADE.inMs`）に反映する。画面は300msで暗くなり、250ms（`holdMs`）暗いまま保ってから450ms（`outMs`）で戻る。暗いまま保つ間に、変化が全員の画面に届く。演出をオフにしている画面（`MotionService`）は暗くせず、そのまま切り替える（`features/tabletop/scene-fade-overlay`）
- **今の盤面から作る・上書き** — 「今の盤面から作る」は見せているテーブルの見た目の全部分と、流れているBGM・環境音をシーンにする（`BoardSceneService.capture`）。テーブルにない画像は`none`として書くので（`captureTableLook`）、別のシーンで変えたテーブルもこのシーンでそのとおりに戻る。既定でない再生リストの曲が流れていれば、曲ではなく再生リストとして取る。「今の盤面で上書き」はシーンが変える部分だけを書き直し、名前・テキスト・カットインなどは残す。いま流れていないBGMと環境音は、シーンの値を残す。複製は全欄（`BOARD_SCENE_FIELDS`）を写す
- **前景** — シーンは前景の絵・不透明度・合わせ方も変えられる。前景の`none`は前景を外し、不透明度と合わせ方は絵を置くときにだけ書く。前景そのものは[卓とテーブル](tabletop.md#テーブル表示2d--3d)にある
- **使える人と配り方** — シーンを作る・直す・反映するのはGMだけ（`BoardSceneService.canUse`）。スイッチの動作「シーンを反映」だけは`trusted`で反映し、PLが押してもその人の画面で反映する（[スイッチ](map-editor.md#スイッチ)）。部屋のサーバーは見学者の書き込みを戻すので、見学者が押したときは反映しない（`PeerCursor.isMyselfKeptOffTable`）。ホットバーの「シーン」の枠はGMだけが使える（[ホットバー](pl-tools.md#ホットバー)）。ホットバーとスイッチは、反映のコードを初めて要るときに読み込む（`BoardSceneLoader`）。スイッチが押した人の画面でシーンを反映するので、部屋のサーバーはシーンをPLと見学者にも配る（`core/network/server/contract/visibility.json`）
- **フォルダ** — シーンは`folderName`（`第1話/村`のようなパス）でフォルダに分け、フォルダは4段まで（`MAX_FOLDER_DEPTH`、`domain/folder/folder-path`）。中が空のフォルダも`Config._boardSceneFolders`に残す

## シナリオテキスト

- **シナリオテキスト** — GMが前もって書いておき、場面が来たらチャットに出す文（`ScenarioText`、`@SyncObject('scenario-text')`、`domain/scenario-text/scenario-text`）。たとえば描写・ハンドアウト・NPCの台詞を書く。欄は`title`・`text`・`folderName`・`order`・`sendAs`・`tab`・`color`・`stamps`。本文はチャットの装飾の記法で書き、書いた装飾のまま出る。パネルは「シナリオテキスト」（`features/scenario-text`）で、書くのも送るのもGMだけ（`ScenarioTextService`、`application/chat/scenario-text.service`）。シーンと同じく識別子ごと保存し、部屋のデータとして保存して、読み込むと置き換わる。フォルダの決まりもシーンと同じで、中が空のフォルダは`Config._scenarioTextFolders`に残す
- **書いたとおりに出す** — 送るときは`ChatMessageService.sendVerbatim`を通し、本文のダイスもコマンドも読まない。`1d100`で始まる本文もそのまま出て、コマのリソースも立ち絵も変わらない
- **送り方** — `sendAs`は`title`（タイトルを発言者の名前にする）・`character`（話しているキャラクターとして）・`system`（システムとして）の3つで、空と知らない値は`title`と読む（`scenarioTextSpeakerOf`）。`character`で話しているキャラクターがいなければ、タイトルの名前で送る。`tab`が空なら開いているタブに送る。システムタブには`system`のときだけ送り、ほかの送り方ではシステムタブでない最初のタブに回す。`color`が空なら話し手の色で出る。行の右クリックの「送り方を変えて送る」はその1回だけ別の送り方で送り、「秘話で送る」は選んだプレイヤーにだけ送る
- **送った印** — プレイヤーがもう聞いた文をGMが見分けられるように、送った時刻を部屋ごとにlocalStorage（`axe.scenario-text.sent.<部屋のID>`）へ書き、パネルの行に出す。ほかの人には届かないので、別のブラウザから見ると印はない
- **入力欄の候補** — GMがチャットの入力欄に2文字以上打つと、タイトルにその文字を含むテキストと、本文のどれかの行がその文字で始まるテキストを、最大8件（`SCENARIO_TEXT_SUGGESTIONS`）候補に出す（`scenarioTextsMatching`）。大文字と小文字、装飾は区別しない。ふつうの発言を打ち始めた数文字で、それを含むテキストが全部出てこないように、行の途中にあるだけでは出さない。選ぶと本文が入力欄に入り、いまの発言者として送れる（`features/chat/chat-window`）
- **まとめて取り込む** — 貼り付けた文章を、`#`（1〜6個）か`■`で始まる見出しの行ごとに1件のテキストに分ける（`splitScenarioTexts`、`domain/scenario-text/scenario-text-import`）。見出しがタイトルに、次の見出しまでの行が本文になり、本文の前後にある空行は落とす。最初の見出しより前に文があれば、それもタイトルのない1件になり、パネルが既定の名前（「テキスト」と番号）を付ける。取り込んだテキストは、選んでいるテキストと同じフォルダに入る
- **配り方** — 部屋のサーバーはシナリオテキストをGMにだけ配る（`core/network/server/contract/visibility.json`の`gmPreparations`）。SkyWayの部屋では全員に届き、GM以外の画面はパネルも候補も出さないだけ

## ゲーム内時間と時間帯の空

- **ゲーム内時間** — 部屋が持つ物語の中の日と時刻で、全員が同じ時刻を見る。`Config._gameClock`にJSONで持ち（`readGameClock` / `writeGameClock`、`domain/game-clock/game-clock`）、空文字と読めない値は既定と読み、範囲の外の値は範囲の中に戻す。既定は1日目・時間帯で表す（`mode`が`'periods'`）・8:00（`minutes`が480）・1回で60分・進めたらチャットに出す。時刻の表し方は「時間帯」と「24時間」で、24時間のときに1回で進める幅は10・30・60・180分（`GAME_CLOCK_STEPS`）。日は1〜99999、時間帯は12個まで（`MAX_GAME_CLOCK_PERIODS`）で、名前は1つ20字まで。時間帯の名前はカンマか読点で区切って書き、空にすると表示中の言語の「朝,昼,夕,夜」を使う。日の書き方は`{n}`を日の数に置き換え、`{n}`を含まない書き方（空を含む）は「{n}日目」になる
- **進める・戻す** — 進めるのも設定するのもGMだけ（`GameClockService`、`application/game-clock/game-clock.service`）。時間帯で表すときは1回で次の時間帯に進み、最後の時間帯の次は翌日の最初になる。1日目の始めより前と、99999日目の終わりより後には動かない。「進めたり戻したりしたときにチャットに出す」がオンなら、`sendSystemNotice('clock')`で「時間を進めました」「時間を戻しました」の行を出す。送り先は[チャット](chat.md#チャット)のシステム通知の送り先で選ぶ。日や時刻を手で合わせたときと、端にいて動かなかったときは出さない
- **時間帯の名前を変える** — 名前を書き換えても、いまの時間帯の位置は保つ。数が減ってその位置がなくなれば、最後の時間帯にする。時間帯ごとに選んだ空の時刻は、同じ名前の時間帯に引き継ぎ、数が変わらなければ同じ位置で名前だけ変えた時間帯にも引き継ぐ（`carryPeriodSkies`）
- **時間帯の空** — 時間帯で表すとき、時間帯ごとに何時の空を出すかを、6・9・12・15・18・21・0・3時から選べる（`GAME_CLOCK_SKY_HOURS`）。選ばない時間帯は、1日を時間帯の数で等分して6時から順に当てた時刻になる（`evenDayFractionOf`。既定の4つなら朝6時・昼12時・夕18時・夜0時）。選んだ時刻は時計とは別の`Config._gameClockSkies`に、時間帯の順のJSON配列で持つ。別にしてあるので、`_gameClockSkies`を知らない版のGMが時計を進めて`_gameClock`を書き直しても、空の設定は消えない。24時間で表すときは、その時刻の空になる（`dayFractionOf`）
- **卓の空** — テーブル設定の「空」（`GameTable.skyKind`、既定`''`）を「ゲーム内時間で移る空」（`'clock'`）にした卓は、3Dの卓で盤の向こうに、その時刻の空を描く（`skyDomeAt`、`domain/tabletop/world/sky-dome`）。太陽は6時に東から昇って正午に南に立ち、18時に西へ沈み、月は夜のあいだ空を渡る。朝焼けは夕焼けより淡い金色で、星は地平線より上にだけ出す。盤の外に地面は描かない。卓を見下ろすカメラでは、空をカメラの横の軸で回し、地平線を見たときの空として盤の奥に描く（`skyLevelTurn`、`infrastructure/table-3d/sky-level`）。俯角が24°までは回す量を少しずつ増やし、それより下を向くと、地平線が画面の中央より少し下に来る角度に固定する。水平に近いカメラ（一人称など）では回さないので、空は本物の地平線の上に立つ。もやは盤をほとんど霞ませない濃さにしてある。知らない値は「背景画像のまま」（`''`）と読む（`tableSkyKindOf`、`domain/tabletop/table-sky`）。奥のレイヤーとの重なりは[卓とテーブル](tabletop.md#テーブル表示2d--3d)の「空のある卓の奥」にある
- **時刻の光** — 卓を照らす光の向きと色は、`skyKind`に関係なく、どの卓でもゲーム内時間に従う（`domain/tabletop/world/sky-light`の`skyLightAt`を`Table3dService.skyLight`が読む）。昼は太陽、夜は月のある方から照らす。平らな面が受ける明るさはどの時刻でも同じで、時刻で変わるのは立体のどの面が照らされるかと光の色。卓の暗さは暗闇の設定が決める（[暗闇・視界・光源](vision-lighting.md#暗闇視界光源)）。空を描かない卓は前からの色で照らす。空を描く卓では光にも時間帯の色を付ける（`skyLightAt`の`underSky`）。昼は暖かい日差しと少し青い空の光、昇る日は金色、沈む日は橙と紫で、日が沈みきるまでは日の光で照らし、そのあとの薄明のあいだに月明かりへ移る。夜の空の光は暗い青で、`SkyLight.moonlit`の分だけ月明かりとして描く。月明かりは`SceneVeil`が照らした色に掛け、暗い色ほど彩度を落として青みの灰色へ寄せ、灯りが明るく照らす色は残す
- **ウィジェット** — ゲーム内時間のウィジェット（`features/widgets/game-clock`）は、その時刻の空の絵の上に日と時刻を書き、太陽か月を空に渡らせる。GMにはその下に、進める・戻すボタンと設定を出す。空の絵は前へだけ進み、太陽と月はいつも東から西へ渡る。演出をオフにしている画面では、新しい時刻の空にすぐ移る。表示の有無は席ごとにlocalStorage（`ui-widgets`）に残る。卓の空がゲーム内時間に従うので、既定で表示する。保存に書いた`review`（既定を見直した回の番号）が1未満の席も、一度だけ表示に戻す（隠し直せる）
- **シーンからの時間帯** — シーンの「ゲーム内時間の時間帯」は、時間帯の位置を数字の文字列で`clockPeriod`に持ち、反映すると`GameClockService.setPeriod`で合わせる。手で合わせたときと同じく、チャットには出さない

## オブジェクト一覧とNPCバー

- **オブジェクト一覧（GM）** — 部屋にある物を種類と場所をまたいで1つの一覧に並べるパネル（`GameObjectListPanelComponent`、`features/gm-object-list`）。種類はキャラクター・カード・山札・ダイス・コイン・共有メモ・地形・射程範囲・光源・環境エフェクトの10種（`OBJECT_LIST_TYPES`）で、種類のボタンで絞り込み、名前とオーナーで検索する。場所は卓上・共通・墓場・個人（そのプレイヤーの名前）・その他に分けて行に書く。GM以外には「このツールはゲームマスター専用です」だけを出す
- **行の作り方** — 行は純関数`buildObjectRow`（`features/gm-object-list/game-object-list-row`）で作る。行の絵には実際の見た目を使い、キャラクター・ダイス・コインは画像、カードは表の面、地形は壁があれば壁の絵、なければ床の絵を出す。任意マスの射程はマスの形の縮図を描き、ほかの種類は種類のアイコンを出す。オーナー・公開範囲・固定・インベントリ非表示は、その種類が欄を持つときだけ読む
- **行の操作** — 卓上の行を押すと、その物へ視点を移す。行のメニューは、フォーカス（卓上の物だけ）・詳細を表示・移動（卓上へ・共通へ・墓場へ）・別の面へ移動・固定する／固定解除・コピーを作る・公開範囲・削除する。「サーフェス・座標を編集」は面（床と、いまのテーブルで立てている壁）とX・Yを数値で書き換える
- **視界の一括設定** — キャラクターの行にチェックを付けて複数のコマを選び、「視界を一括設定」で開く1枚の視界設定パネルから、まとめて設定する（`bulkVisionTarget`、`domain/tabletop/vision-bulk`）。パネルは最初のコマの値を読み、触った欄だけを全部のコマに書く。触らない欄はコマごとの値のまま残る。値が揃っていなければ「設定が揃っていません」を出す（`disagreeingVisionFields`）。「表示中をすべて選択」は絞り込みで見えているキャラクターだけにチェックを付ける。絞り込みを変えても、付けたチェックは残る
- **NPCバー** — GMツールの下に開く、NPCを並べた帯（`NpcBarComponent`、`features/gm-tools/npc-bar`）。GMツールの「NPCバー」で開閉する。開いているかどうかは`NpcBarService.isOpen`（`application/ui/npc-bar.service`）がその画面のメモリにだけ持ち、部屋にも保存にも残らない。並べるのは`GameCharacter.isNpc`が立っていて墓場にいないキャラクターで、名前で絞り込める。押すと、開いているチャットパレットのうち最後に開いたものの発言者をそのNPCに替え、開いているパレットがなければそのNPCのチャットパレットを開く。右クリックか×で登録を外す
- **NPCの登録** — NPCの印は`GameCharacter.isNpc`（SyncVar、既定`false`）で、部屋の全員に同期する。インベントリかオブジェクト一覧からキャラクターをドラッグし、GMツールかNPCバーの上で離すと登録する（`NpcDragService`、`application/tabletop/npc-drag.service`）。インベントリから運べるのはGMだけ。ほかに、オブジェクト一覧の行の星のボタンと、コマの右クリックの「☐ NPC にする」「☑ NPC にする」（GMだけ）でも切り替える。同じ欄を、ZOCの敵味方（既定はNPCかどうかで分ける、[移動範囲](movement.md#移動範囲)）、手番の効果音（[行動順](turn-order.md#行動順)）、トリガーの対象、視界も読む。視界では、オーナーのいないコマをプレイヤー全員の目として扱うが、NPCは外す

## 投票と点呼

- **ウィジェットで答える** — Lily由来の投票と点呼は、対象の人と主催者の画面に出るウィジェットで答える（`VoteWidgetComponent`、`features/vote/vote-widget`）。ウィジェットは同期する`Vote`（`@SyncObject('Vote')`、`domain/vote/vote`）と、各席の`PeerCursor.voteAnswer` / `voteId`から組み立てるので、投票中にページを読み込み直してもウィジェットが戻る。折りたたんでも参加は続き、答えないことは「棄権する」（点呼では「欠席する」）のボタンで示す。`Vote.voteAnswerByPeerId`は席の答えを選択肢の番号で返し、未回答は`-1`、棄権・切断・退室は`-2`で返す。投票と点呼はGMでなくても始められる
- **始めたタブに出す** — `Vote.chatTabIdentifier`に投票を始めたタブを持つ。開始・回答・棄権・集計の行は、どれもそのタブに出す
- **主催者が締め切る** — 主催者は「締め切る」で、未回答を残したまま締め切れる（`Vote.finishByChair`）。対象の全員が答えると、主催者の画面が自動で締め切る。domainは集計の文を組まず、`FinishVoteEvent`に数だけを載せる。文にするのは`VoteEventHandlerService`（`features/vote/vote-event-handler.service`）で、選択肢ごとの票数に棄権と未回答の数を添える
- **締め切るまで伏せる** — 「締め切るまで中身を伏せる」（`Vote.isSecret`）を選んだ投票は、締め切るまで、誰が何に入れたかと選択肢ごとの票数を誰にも見せず、何人が回答したかだけを出す。回答したときにチャットに出る行も、選んだ選択肢を書かず「回答しました」と回答数だけになる。自分の回答は自分の画面にだけ見える。点呼では選べない（`makeVote`が`isRollCall`のとき`false`にする）
- **見学者** — 見学者はどちらのモードでも、投票と点呼を始めず、答えず、聞かれもしない。アラームとリアクションも同じで、チャットウィンドウのボタンも出ない（`VoteService`・`AlarmService`・`ChatReactionService.mayReact`）。部屋のサーバーで主催者が見学者になった投票は、締め切りをサーバーが戻して集計が何度もチャットに出るのを避けるため、締め切らずに開いたままにする

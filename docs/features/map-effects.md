# マップ演出

## マップ演出（エフェクト）

盤面のコマにエフェクトを再生する。見た目の種類（`EffectKind`、`domain/effect/effect-kind`）は37種で、既定のプリセット121個（`domain/effect/builtin-effect-presets`の`DEFAULT_EFFECT_PRESET_SEEDS`）を17系統（物理・打撃・射撃・炎・雷・氷・土・風・闇・聖・時空・回復・状態異常・防御・強化・撃破・組み立て）× 初級〜上級で揃える。ブレス・電流・生命吸収・極太ビーム・大剣のように、発射元との位置関係を使う演出も持つ。`grade`は規模と粒の量を段階付け、種類によっては描き方そのものを選ぶ（[見た目の選び分け](#見た目の選び分け)）。`scale` / `durationMs`は大きさと長さを決める。

### 段で組み立てる（バレットエディット式）

1プリセットが**段の列**を持てる（`domain/effect/effect-stage`）。役割は**運び / 着弾 / 残留 / 派生**の4つで、運び・着弾・派生は数珠つなぎ、残留だけは後段を待たせず並走する。段が指すのは**37種類の見た目**であってプリセットではないので、循環が原理的に起きず深さも描画前に確定する（派生の中で再度の派生は禁止、段は最大6・分裂は2〜8）。

- **合成** — 段ごとの時間窓は`domain/effect/effect-stage`の`stageLayoutOf`が、段の発射元と着弾点は`domain/effect/effect-stage-timeline`の`placesFor`が出す。卓の場面では`domain/effect/scene/effect-frame`が、段ごとに既存の見た目を描く。運びの段の飛翔体・弾道ミサイル・光の剣は着弾を自分では描かない（`TRAVELLING`。次の段が着弾なので二重になる）。コマの絵を切る見た目（崩壊・両断）の段は`stagedCutPictures`が絵を切る。切り方は`CutPicturePainter`として引数で受け取る（`effect-timeline`との相互importを避けるため）
- **段ごとの見え方** — 色・等級・大きさ・尺は段で上書きできる。`@SyncVar`はプロトタイプのアクセサなので、**代入すると卓の全員のプリセットが書き換わる**。`Object.create`＋自前プロパティで読み取りだけ差し替える
- **場面と音** — 段は自分の時間窓と、見た目ごとに決めた消えきるまでの時間（`SCENE_LINGER_S`）の間だけ場面に描く。派生した枝は、段が着いた点から広がりの角度（`spreadDeg`）に振り分け、1マスに`scale`を掛けた長さの1.6倍（`BRANCH_REACH`）離れた点で描く。発射音は運びの段の開始ごと、着弾音は着弾と派生の段の開始ごとに鳴らす（`domain/effect/effect-sound-times`の`stageSoundTimes`。近いものは間引く。派生の枝は同時に始まるので1回に畳む）
- **保存と互換** — 段リストはプリセットの1フィールド（`stages`、JSON文字列）。見本の3つを除く既定のプリセットは空で、1種類の見た目を描く。旧版のクライアントはこのフィールドを無視し、`kind`の1種類を描く
- **編集** — エフェクト編集画面の「演出の組み立て」で追加・並べ替え・削除・パラメータ編集。役割に合わない見た目は自動で既定へ戻す。書き込みは**リスト全体を1回で**（1段ずつ書くと編集途中が同卓者へ流れる）
- **見本** — 「散弾の魔弾」「氷結の追撃」「着弾の絨毯」を既定プリセットに同梱（系統「組み立て」）

### 発動の入口

入口は次のとおり。

- エフェクト集パネル（`features/effect/effect-library-panel`）。タイルを選ぶと構えに入り、確定の操作で発動する（[構えと対象の選び方](#構えと対象の選び方)）
- チャット記法`《…》`（`domain/effect/effect-chat-token`で解析し、`features/effect/effect-chat-event-handler`が`resourceEditMessage$`で受けて発火。送信者だけが撃つのは、全員が撃つと人数ぶん重なるため。対象は`t:`と同じ、撃ち手はその行の発言者）
- キャラクターシートの`DataElementFieldType.EFFECT`欄（値は演出名。コマ右クリックの「演出を発動」にも並ぶ）。シートの行（`features/data-element/game-data-element`）もコマのメニュー（`features/character/game-character/game-character-menu.service`）も、名前でプリセットを引いて`EffectTargetingService.castFrom`を呼ぶ
- ホットバーのエフェクト枠（`features/hotbar/hotbar-runner.service`。[ホットバー](pl-tools.md#ホットバー)）。動作が「発動」の枠は`castFrom`を呼ぶ。「ターゲットを無視して自分に」を入れた枠は`EffectCastService.fire`で押したコマ自身に撃ち、「設置」と「自分だけ」の枠は`castFrom`を通らない
- スイッチの動作「エフェクト」と、踏んだら起きることの`TableTrigger.effect`（[スイッチ](map-editor.md#スイッチ)、[機能塗り](map-editor.md#機能塗りマップエディター)）。どちらもエフェクトを名前で引き（`application/media/named-cue.service`）、スイッチは押した人の発言者のコマに、罠は踏んだコマに撃つ
- リソースの増減（`EffectAutoPlayService`）。オプトインで、2つの設定がどちらも入のときだけ出る。1つはエフェクト集のメニューの「HPの増減に演出を出す（自分の画面だけ）」で、`localStorage`（`axe.effect.autoPlay`）に持つ個人設定。既定は切。もう1つはリソース欄ごとの「増減でエフェクト」（`cs-change-effect`属性、`domain/character/resource-feedback`の`playsEffectOnChange`）で、属性の無い欄では出ない。見本のキャラクターのHPとMPにだけ、`CharacterTemplateFactory`が`'true'`を書く。属性を持たない欄を入に移す処理はない。出すのは同梱の打撃（殴打・強打・崩拳）か回復（治癒・回復光・大治癒）で、最大値に対して動いた割合が15%未満なら1つ目、40%未満なら2つ目、それ以上なら3つ目を使う（`resourceChangeSeverity`、`domain/effect/resource-effect-map`）。増減は同期済みなので、`EFFECT_CAST`を送らず各画面が自分で再生する
- 状態異常を付けたとき（`features/status-ailment/status-ailment-effect-event-handler.service`）。部屋の状態異常の一覧（`StatusAilmentCatalog`）の属性`plantEffect`が`'true'`のときだけ出る（`playsEffectOnPlant`）。属性の無い部屋と`'true'`以外の値は切と読むので、既定は切。チェックは状態異常のパネル（`features/status-ailment/status-ailment-panel`）にあり、卓を編集できる席だけが変えられる。`plantStatusAilment`（`domain/character/status-ailment-plant`）が、付けた端末の中だけに`statusAilmentPlanted$`で知らせ、ハンドラが状態異常の名前でプリセットを引いて`EffectCastService.fire`で撃つ。全員の画面に出て、人数ぶん重ならない。同じマイクロタスクのうちに付いたものは名前ごとにまとめ、プリセットの上限（`targetLimit`）ずつ撃つ。卓に出ていないコマ、同じ名前のプリセットが無い状態異常、外したときは撃たない。インベントリのチェック欄、チャットの`&名前`、踏んだら起きることの状態異常は、どれも`plantStatusAilment`を通る

発動すると`EFFECT_CAST`イベントで全員の画面が同時に再生しSEも鳴る（リソースの増減と試し撃ちは送らない）。演出の状態は同期せず、各クライアントが受信時刻を起点に純関数でフレームを算出する。

シートの行・コマのメニュー・ホットバーの枠が通る`castFrom(preset, piece)`は、押した時点のターゲット指定で動きを分ける。

| 条件                                                                 | 動き                                                                       |
| -------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 卓を編集できない席（見学）                                           | 何もせず`null`を返す。ほかの条件より先に見る                               |
| そのコマ以外に`targeted`のコマがある                                 | `EffectCastService.fireFromCharacter`でその場で発動する                    |
| 対象規則が`self`のプリセット                                         | 同じく、その場で発動する                                                   |
| 卓に出ていないコマ                                                   | `fireFromCharacter`でその場で発動する                                      |
| 上のどれでもない（相手が要るプリセットで、ほかのコマを狙っていない） | `begin`のあと`setCaster`でそのコマを撃ち手にして構えに入り、`'held'`を返す |

チャット記法・スイッチ・罠・リソースの増減・状態異常は構えを通らず、その場で再生する。チャット記法を撃つのは発言した席だけで（`features/effect/effect-chat-event-handler.service`）、卓を編集できない席（見学）の発言は撃たない。発言そのものは通常どおり流れる。

### 構えと対象の選び方

エフェクト集のタイルを選んでも発動しない。選んだプリセットは発動を待つ状態（構え）になり、確定の操作があるまでそのまま残る。構えは`application/effect/effect-targeting.service`の`EffectTargetingService`が持つ。中身は、構えたプリセット（`preset`）、選んだ順の対象（`picks`）、撃ち手（`casterIdentifier`）の3つ。

| 操作           | メソッド                         | すること                                                                                                                                                           |
| -------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 構える         | `begin(preset)`                  | `targeted`のコマのうち自分から見えるものを上限まで対象に引き継ぎ、開始前の`targeted`を覚える。対象規則が`self`で引き継ぐコマが無ければ、選択コマを対象に入れておく |
| 対象を選ぶ     | `pick(identifier)`               | 選んでいないコマを足し、選んであるコマを外す。上限に届いても発動しない                                                                                             |
| 撃ち手を変える | `changeCaster()` / `setCaster()` | `changeCaster()`のあと最初に押されたコマを、対象に足さず`setCaster`に渡す。`setCaster`はそのコマを対象から外す。空文字を渡すと撃ち手なしになる                     |
| 確定する       | `confirm()`                      | `picks`のうち卓にいるコマへ`EffectCastService.fire`で撃ち、構えを解く。対象が0体なら何もせず、構えも残す                                                           |
| 中止する       | `cancel()`                       | `targeted`を開始前の状態に戻して構えを解く                                                                                                                         |

発動するのは`confirm()`だけで、呼ぶのはエフェクト集の「対象に発動する」、ターゲット帯の「発動」、一人称のビューのボタン、Enterキー（`game-table`の`onEnterKey`。入力欄にフォーカスがある間は取らない）の4か所。`cancel()`は、それぞれの「中止」、Escキー（`onEscapeKey`）、構えたプリセットのタイルの再選択が呼ぶ。`PieceTargetService.clear()`（ターゲット帯の「すべて外す」とShift+T）は先に`cancel()`を呼んでから`targeted`を全部外す。卓を編集できない席に変わったときも中止する。

対象は選択コマ（`SelectionSignalService.selectedObject`）の変化で拾う。構えた時点で選択されていたコマは、押し直されていないので対象にしない。順番の扱いは`domain/effect/effect-target-picks`の`toggleEffectPick`が決め、上限に達した状態で別のコマを選ぶと最古の対象と入れ替える。

`areaRadius`を持つプリセットは、1回の`pick`で中心からの半径内を近い順に上限までまとめて選び直す（`domain/effect/effect-area`の`effectAreaTargets`）。交戦ゾーンにいるコマはゾーンの中心にいるものとして測り、戦線を離れたコマ（`offField`）は入れない。半径は`areaRadiusCells × gridSize`で、ヘクスの卓でも円で測る。

選んだ順の配列が元データで、コマの`targeted`はその写し（`mirror()`）。発動後も`targeted`を残すので、チャットの`t:`がそのまま同じ対象へ効く。対象規則が`self`のプリセットだけは、発動後に`targeted`を開始前の状態へ戻す。自分から見えないコマは、撃つが`targeted`にはせず、番号も付けない（`pickOrder`は見えるコマだけで数える）。

撃ち手は`begin`の時点の選択コマを固定して持つ（選び進めると選択が対象側へ移るため）。`EffectCastService.fire`は、撃ち手が対象の中にいるときは撃ち手なしで撃つ。そうならないよう、対象規則が`self`でないプリセットでは撃ち手を対象に入れない。撃ち手のコマを押しても`pick`は何もせず、範囲も撃ち手を巻き込まず、押す前の範囲の表示にも出さない。`begin`の時点で選択コマが引き継ぐ対象の中にいたときは、そのコマを対象に残して撃ち手なしで始める。確定した発動は`lastConfirmed`に置くので、Enterやターゲット帯で確定したときも、エフェクト集は知らせの行に相手の名前を出せる。

### 構えている間の卓の表示

`features/effect/effect-target-overlay`が、次の印を、卓のcanvasがその場所を描く画面上の位置に重ねる。床に寝かせるのは番号以外の全部で、番号だけは画面へ向けて立てる（盤を傾けると寝かせた数字は読めない）。

| 印             | 元にする値                  | 見た目                                                               |
| -------------- | --------------------------- | -------------------------------------------------------------------- |
| 対象           | `marks`                     | プリセットの主色の円と、選んだ順の番号                               |
| 撃ち手からの線 | `links`                     | 撃ち手から各対象への帯                                               |
| 撃ち手         | `casterMark`                | 白い二重線のひし形。対象が0体でも出す                                |
| 範囲           | `areaCenter` / `areaRadius` | 中心を押したあとの破線の円                                           |
| 押す前の範囲   | `areaProspect`              | ポインタの下のコマを中心にした点線の円と、巻き込むコマごとの破線の輪 |

対象は円、撃ち手はひし形にして、色だけでなく形でも見分けられるようにしている。押す前の範囲は線だけで描き、卓の上に面を敷かない。

`areaProspect`は`pick`と同じ`areaPicks`で求めるので、見せた相手と、押して選ばれる相手が一致する。ポインタがコマに入ったことと出たことは、コマ（`features/character/game-character`）が`hoverPiece`で知らせる。ホバーできない端末（`ViewportService.canHover`が偽）、撃ち手の変更を待っている間、すでに中心として押したコマの上では出さない。

本体と一緒に選ばれた部位は印を持たない（本体の印に重なるため）。一人称のビューは、番号と撃ち手の印を出さない（`badges`と`casterRing`を偽にする。番号は卓のカメラへ向けて立てるもので、撃ち手はそのビューが覗いているコマだから）。

ターゲット帯（`features/tabletop/target-band`）は、構えた瞬間から構えが解けるまで、対象が0体でも出し続ける。選んだ数と上限を幅の決まった箱に入れ、「発動」「中止」「すべて外す」のボタンを持つので、対象の数が変わっても帯の大きさは変わらず、エフェクト集のパネルに手が届かなくても確定と中止ができる。ボタンの高さは44px。構えていない間は、`targeted`のコマが1体以上ある間だけ出る。

### エフェクト集パネルの配置

`features/effect/effect-library-panel`は、上から4つの領域を決まった高さで並べる。状態が変わっても領域の中身を差し替えるだけで、行を足さない。構えても、対象が増えても、発動しても、一覧の位置は動かない。

| 領域           | `data-testid`            | 中身                                                                                                       |
| -------------- | ------------------------ | ---------------------------------------------------------------------------------------------------------- |
| 検索と絞り込み | `effect-library-filters` | 検索欄、「追加」と「メニュー」のボタン、等級と対象の切り替え                                               |
| 構えの領域     | `effect-library-stance`  | プレビューの枠、プリセット名と「選んだ数/上限」、撃ち手の行、対象の行、発動と中止のボタン                  |
| 一覧           | `effect-library-list`    | 左に系統の索引、右に最近使ったもの・系統ごとの行・置いてある演出。索引と行の欄がそれぞれ縦にスクロールする |
| 知らせの行     | `effect-library-notice`  | 1行。知らせ（`notice`）があればそれを、無ければ直前の発動の相手（`lastFired`）を出す                       |

初めて開くときの大きさは540×720で、枠を引いても340×420より小さくはできない（`application/effect/effect-library-size`の`EFFECT_LIBRARY_SIZE`と`EFFECT_LIBRARY_MIN_SIZE`）。540pxは索引の横に行を2列に並べられる幅にしてある。ウィンドウのほうが小さいときはウィンドウに収まる大きさで開き、縮むのは一覧の領域だけになる。

利用者が枠を引いて変えた大きさは`localStorage`（`axe.effect.librarySize`）に覚え、次に開くときはその大きさで開く。`ui-panel`は枠を引き終えたとき（`onPanelResizeEnd`）に、前面のパネルの`PanelService.resized$`へ新しい大きさを流し、パネルがそれを`writeEffectLibrarySize`で書く。`RoomPanelService`は開くたびに`readEffectLibrarySize`で読み、読めない値と最小より小さい値は初めての大きさに戻す。全画面のようにコードが与えた大きさは流さない。部屋には保存せず、同期もしない。`resized$`を聞くのはエフェクト集だけなので、ほかのパネルの大きさの扱いは変わらない。

卓を編集できない席（見学）は、部屋のエフェクトと置いてある演出を変えられない。「追加」のボタンとメニューの「既定を反映」「足りない既定を追加」は`disabled`にし、行の編集ボタンと置いてある演出の片づけのボタンは出さない。右クリックのメニュー（`effect-library-context-menu`の`buildEffectLibraryContextMenu`）からは、編集・複製・削除・設置を外す。メニューを開いたまま見学になった席も通さないよう、パネルの各ハンドラも`canEditTabletop()`を確かめる。検索・索引・等級と対象の切り替え・系統の畳みと展開・試し撃ち・チャット記法・ホットバーへの登録・書き出し・増減の演出の切り替えは、部屋を変えないので見学でも使える。

構えの領域の各行は、構えの前後で次のように変わる。

| 行     | 構える前                                                       | 構えている間                                                     |
| ------ | -------------------------------------------------------------- | ---------------------------------------------------------------- |
| 名前   | 「エフェクトを選んでください」                                 | プリセット名と、`pickOrder`の数/`limit`                          |
| 撃ち手 | 「撃ち手（予定）」として`upcomingCasterIdentifier`（選択コマ） | `casterIdentifier`のコマ。変えるボタンと、なしにするボタンが付く |
| 対象   | `targeted`で自分から見えるコマ                                 | `pickOrder`のコマ                                                |

撃ち手の名前を選択コマから出さないのは、対象を押すたびに選択が対象へ移るため。撃ち手の2つのボタンは、パネルの幅が420px以上なら「変える」「なしにする」の文字を添え、それより狭いとアイコンだけにして`aria-label`で名前を持たせる。対象の行は名前のチップを1行に並べ、収まらないぶんは横スクロールで読ませる。折り返すと行の高さが変わる。発動と中止のボタンは常に置き、使えない間は`disabled`にする。タッチの端末（`pointer-coarse`）では高さを44pxにする。

行の選択（`choose`）は`begin`を呼ぶだけで、対象規則が`self`のプリセットも発動しない。構えたプリセットの行をもう一度選ぶと`cancel`を呼ぶ。

行はキーボードで移れる。Tabキーが止まる行は1つだけにし（`tabStopKey`。最後にフォーカスした行、無ければ先頭）、矢印・Home・Endでどの行へ移るかは`effect-tile-keys`の`tileAfterKey`が、行の画面上の位置から決める。行は2列に並び、左右は読む順（左の列、右の列、次の段）の前後へ移る。上下はいちばん近い段の、横の位置がいちばん近い行へ移り、1つしかない段ではその行へ移る。SpaceとEnterは行を選ぶ。行の上のEnterは`enterOnTile`が受けて卓へ渡さない（卓の`onEnterKey`が同じ押下で発動しないように）。構えたプリセットの行の上のEnterだけは卓へ通し、発動になる。

### 系統の索引と行

一覧の左には系統の索引（`effect-library-index`）を常に出す。1行が1系統で、系統の色・名前・いま一覧に出ている件数を並べる。並びと件数は`effect-library-list`の`familyIndex`が出し、順番は`domain/effect/effect-families`の`EFFECT_FAMILY_ORDER`に従う。同梱のプリセットの17系統をこの順に並べ、ほかの系統はその後ろ、系統の無いものは最後に置く。系統の色も同じファイルの`effectFamilyColor`がダーク用とライト用の2色で持ち、利用者が足した系統は中間色になる。見出しにも同じ色の印と件数を出す。

索引を押すと、その系統の見出しが一覧の上端に来るまで送る（`jumpToFamily`）。一覧は絞り込まず、畳んであった系統は開く。一覧の残りが短くて見出しを上端まで送れないときは、足りない高さの空白を一覧の下に足し（`tailSpaceFor`）、一覧の中身が変わったら外す。一覧をスクロールすると、上端に来た見出しの系統へ索引の印が移る（`familyAtScroll`）。検索・等級・対象で絞り込むと件数が変わり、0件になった系統は薄くして残す。索引の行の数と高さは変わらない。

索引でTabキーが止まる行は1つで（`indexStop`。一覧がいま立っている系統）、上下の矢印・Home・Endで系統を移り（`rowAfterKey`）、EnterかSpaceで送る。タッチの端末では索引の行の高さを44pxにする。

行には種類の印（28px）・名前・等級の★・届く範囲・種類の名前を出す。届く範囲は`reachOf`が決め、対象規則が`self`なら「自分」、`areaRadius`があれば「範囲Nマス」、上限が2以上なら「N体まで」、それ以外は「単体」と出す。範囲は色を変えて太字にする。名前は2行まで折り返し、切らない。タッチの端末では行の編集ボタンを出さず、行の右端の「⋮」（`data-effect-more`）で右クリックと同じメニューを開く。

印は`domain/effect/effect-shapes`の`presetGlyphSvg`が描き、37種類すべてに専用の印がある。飛翔体は飛ぶ物の見た目（`projectileLook`）ごとに描き分け、魔法弾は着弾の見た目（`impactKind`）で頭の形を変える。2発以上撃つものは後ろにもう1発を重ねる（`glyphLookOf`）。エフェクトの編集画面とホットバーの枠の編集も同じ印を使う。

### 検索と絞り込み

検索は名前・系統・種類の名前・等級・届く範囲の文字に当てる（`effect-search`の`searchTextOf`）。全角と半角、大文字と小文字、ひらがなとカタカナの違いは見ない（`foldForSearch`）。空白で区切って語を2つ以上入れると、全部の語を含むものだけを残す。同梱のエフェクトに使う漢字の語は`effect-readings`が読みを持つので、漢字の名前もひらがなで探せる。読みを持たない語は書いたとおりの字でだけ当たる。一致した文字は名前と種類の名前の中で強調し（`highlightParts`）、読みで当たったときは強調しない。絞り込んでいる間は検索欄に件数を出し、0件のときは探し方と「絞り込みを解除」を出す。

等級と対象は、見出しの付いた切り替え（すべて／初級／中級／上級、すべて／単体／複数／範囲）で選ぶ。「単体」は対象規則が`self`のものも含み、「複数」と「範囲」は`reachOf`の値で分ける。狭い画面（`ViewportService.isCompact`）では、2つの切り替えを選択欄2つにして1行に並べる。

上段のボタンは「追加」と「メニュー」の2つで、どちらも文字を出す。パネルの幅が420px未満のときは「メニュー」をアイコンだけにし、`aria-label`で名前を持たせる。メニューの項目は既定を反映・足りない既定を追加・エフェクト集を書き出す・HPの増減に演出を出す（チェック）・系統をすべて畳む・系統をすべて開くの6つ。上下の矢印・Home・Endで項目を移り、Escで閉じてボタンへフォーカスを戻す。このEscは卓へ渡さない（構えの中止と重なるため）。パネルのほかの場所を押しても閉じる。

### プレビュー

`features/effect/effect-preview`は、10×7マスの盤に代役のコマを2体置いた小さな舞台（`infrastructure/table-3d/effect-stage`の`createEffectStage`）で、プリセットを繰り返し再生する。描くのは卓と同じ`EffectLayer`。周と周の間は600ms（`EFFECT_PREVIEW_REST_MS`）あけ、プリセットの大きさに合わせてカメラを引く。音は鳴らさない。演出を止めている間は、尺の半分の時点の1枚を出す。

入力は3つ。`preset`が替わると頭から再生し直す。`version`は同じプリセットの値が変わった回数で、増えるたびに描き直して頭から再生する（編集中のプリセットは同じインスタンスのままなので、`preset`だけでは変化が伝わらない）。`fill`を付けると、置かれた箱の高さいっぱいに広がる。

置いてあるのは次の4か所。

| 場所                   | 映すもの                                                                                                                      |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| エフェクト集           | 構えているプリセット。構えが無ければ、ポインタかフォーカスが200ms（`EFFECT_TILE_PREVIEW_DELAY_MS`）留まったタイルのプリセット |
| エフェクトの編集画面   | 編集中のプリセット。上部に固定し、項目の欄だけをその下でスクロールさせる                                                      |
| ホットバーの枠の編集   | 枠に選んだプリセット（`chosenEffect`）                                                                                        |
| 戦闘カットインのパネル | 一覧で選んでいるプリセット（`focusedPreset`。[戦闘カットイン](battle-cut-in.md#戦闘カットイン)）                              |

エフェクト集のプレビューは1つだけで、`preset`を差し替えて使う。プレビューは1つにつきcanvasとレンダラーを1つずつ持つので、タイルごとには置けない。作るのは最初に映すものができたとき（`previewMade`）で、パネルと一緒に破棄する。タイルのプレビューはホバーできる端末でだけ出し、ホバーできない端末では構えたプリセットだけを映す。

### 見た目の選び分け

1つの種類（`EffectKind`）の描き方は、`domain/effect/`の`*-looks.ts`（`fire-looks`・`thunder-looks`・`ice-looks`・`earth-looks`・`wind-looks`・`dark-looks`・`holy-looks`・`space-looks`・`strike-looks`・`blade-looks`・`great-sword-looks`・`beam-looks`・`blessing-looks`・`ailment-looks`・`magic-looks`）と、`scene/shot/shot-looks`・`scene/breath/breath-looks`が、プリセットの値から選ぶ。手がかりは次の4つで、新しい`kind`を足さずに見た目を増やせる。

| 手がかり                | 種類と選ぶ見た目                                                                                                                                                                                                                                                                                                                    |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 等級（`gradeLevel`）    | 打撃（`strikeLookOf`。`jab`・`swing`・`crush`）、落雷（`boltLookOf`。`snap`・`strike`・`storm`）、裁きの光（`smiteLookOf`。`seal`・`judgement`・`heaven`）、回復（`healLookOf`）、障壁（`isMirror`）、影（`shadowLookOf`）、黒い太陽（`orbLookOf`）、転移（`warpLookOf`）、重力（`gravityLookOf`）、上級の闘気（`breaksOutAsAura`） |
| 等級と範囲              | 氷結（`frostLookOf`。`hail`・`freeze`・`zero`・`coffin`）、竜巻（`windLookOf`。`gust`・`tornado`）、地割れ（`quakeLookOf`。`rift`・`quake`）                                                                                                                                                                                        |
| 道中の粒（`moteStyle`） | 呪印（`curseLookOf`）、極太ビーム（`beamLookOf`）、回復の浄化（`cleanse`）、竜巻の吹雪（`isBlizzard`）と大嵐（`isStormWind`）、斬撃の風の刃（`cutsAsWind`）、ブレスの属性（`breathElementOf`）                                                                                                                                      |
| 系統（`tagName`）       | 粒を選んでいないときの粒（`effectMoteOf`）、魔法弾の属性（`magicShotOf`・`isFireShot`・`isIceShot`など）、光の息と砂のブレス                                                                                                                                                                                                        |

斬撃の太刀筋は`slashStyle`が、電流の描き方は対象の数が決める。

粒の名前で選ぶ見た目（状態異常の姿・極彩・浄化）は、新しい`kind`にしない。この名前を知らない版は、粒の選択が無いものとして系統の粒に戻るので、知らない`kind`のように爆発（`effectKind`の既定）へ落ちず、元の呪印・極太ビーム・回復として描く。

各`*-looks.ts`は見た目の拍（当たる・閉じる・砕ける時刻）も持つ（`frostStrikesOf`・`boltStrokesOf`・`darkStrikesAt`・`holyStrikesAt`・`spaceBeatAt`・`greatSwordTimingOf`・`beamTimingOf`など）。拍は秒で持ち、短い再生では再生の割合で押さえる（`[秒, 割合]`の組の早いほう）。場面の絵（`domain/effect/scene/`）、当たり（`effect-blows`）、着弾音の時刻（`EffectPreset.impactSoundAt`）、コマの動き（`effect-reaction`）が同じ関数を読むので、絵と音と揺れの拍がずれない。`domain/effect/`直下の`*-looks.ts`は見た目の本体（`scene/effect-frame`）を読み込まないので、音を鳴らす側は本体を読み込まずに済む。

### 飛翔体（射撃系）

撃ち手が卓にいれば、いま描かれている位置の0.6マス上（`AIMED_FROM_CELLS`）から、いなければ撃った時点の位置（`EffectCast.origin`）から対象へ飛ばす。どちらも無いときは対象の斜め上から飛ぶ。着弾後は`impactKind`が指す種類の見た目を、着弾の瞬間からの自分の時計で描く（空、または飛翔体・光の剣・弾道ミサイルを指していれば爆発。`strikesInSceneWith`）。連射（`shots` / `shotInterval`）に対応し、弾ごとに撃つ・飛ぶ・当たるが独立する。連射の弾は互いに少し離れた所に当たり、1発ぶんの着弾は小さめに、粒の量を弾数の平方根で割って描く（`volleyLandingPreset`）。

着弾の見た目は、単独で撃つときと変えるものがある（`scene/effect-frame`の`LANDINGS`と`SHOT_LANDINGS`）。飛翔体・弾道ミサイル・大剣が衝撃波・岩石破砕・地割れ・影・黒い太陽で着弾するときは、小さく短い見た目（`struckImpact`・`struckRubble`・`struckQuake`・`struckShadow`・`struckOrb`）を描く。飛翔体が裁きの光と落雷で着弾するときは、弾の等級によらず最も小さい見た目（`shotSmite`・`shotBolt`）を描き、大剣は自分の等級の光と落雷で着弾する。

飛ぶ物は`scene/shot/shots`の`drawProjectile`が次の順に選ぶ。

1. 弾の見た目が`meteor`なら隕石（[隕石](#隕石)）
2. 魔法弾（`bolt`）が属性の見た目に着弾し、系統と粒がほかの属性でなければ、その属性の弾。風（`isWindShot`。回る空気の塊で、着弾は竜巻を立てずに風の輪で弾ける）、岩（`isRockShot`。低い弧で転がりながら飛ぶ岩で、着弾は岩が砕ける）、炎（`isFireShot`）、雷（`isThunderShot`）、氷（`isIceShot`。つららで、着弾の氷結の上で砕ける`landsAsIcicle`）。各`*-looks.ts`がほかの属性を持つ系統と粒の一覧（`OTHER_ELEMENTS`・`OTHER_MOTES`）を持つ
3. 飛ぶ斬撃（`crescent`）は`scene/blade/flying-slash`。着弾が竜巻なら真空波（`fliesAsVacuum`）
4. 光線（`blaster`）は`scene/shot/blaster-shot`
5. ほかは`shotLookOf`（`scene/shot/shot-looks`）が、撃つ瞬間から当たった所に残る物までを1つの見た目（`ShotLook`）で描く。矢・銃弾・曳光・ミサイル・誘導弾と、属性の無い魔法弾（`magicShotOf`。気・呪い・聖・無属性の4つ）。矢・銃弾・曳光が衝撃波か岩石破砕で着弾するときは、自分で当たり方を描き、着弾の見た目は描かない（`strikesByItself`）

| 見た目             | 飛び方と当たり方                                                                                                                                                                                                                                      |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bolt`魔法弾       | 上の属性の弾か、`magicShotOf`の4つ。気（`spirit`）は手元で溜めてから投げ、破裂音とともに弾ける。呪い（`curse`）は髑髏の顔の黒い塊がうねって飛び、当たると巻き付く。聖（`holy`）は光の輪を付けた槍で羽根を落とす。無属性（`arcane`）は菱形の芯に炎の尾 |
| `arrow`矢          | 低い弧で飛び、刺さった所に立って震える。連射の矢は当たった所に並んで立つ。上級は引き絞ってから光に包まれて飛び、対象を貫いて先の地面に刺さる                                                                                                          |
| `bullet`銃弾       | 銃口炎・煙・薬莢と、目で追えない筋。当たると火花と破片が散り、後ろの地面がえぐれる。着弾が岩石破砕なら重い弾として貫く。連射は弾ごとに銃口からずれ、重い弾の長い連射は着弾が地面を這って対象へ寄る                                                    |
| `crescent`飛ぶ斬撃 | 刃から放つ大きな三日月。床に光る線を刻み、着弾が斬撃なら交差した斬り跡を残す。連射の三日月はそれぞれ傾きを変え、最後のものを最も大きくする                                                                                                            |
| `blaster`光線      | 銃口の光の輪と、白い芯を色で包んだ長い光弾。通り道が一瞬残り、当たると光が飛び散って床が焦げる                                                                                                                                                        |
| `tracer`曳光       | 狙撃。赤い照準の線と点で狙ってから撃ち、通り道全体が一度に白く光って対象を貫く。そのあと航跡が漂う                                                                                                                                                    |
| `missile`ミサイル  | 翼と推進炎を持つ胴が、太い煙の筋を引く。群れはそれぞれうねり、筋が編み込まれる                                                                                                                                                                        |
| `cruise`誘導弾     | 大きな1発。揺れながら寄り、床の赤い輪で狙いを絞ってから突っ込む                                                                                                                                                                                       |
| `meteor`隕石       | 撃ち手から撃たず、空から落とす                                                                                                                                                                                                                        |

速さは`PROJECTILE_TRAVEL_MS`（`domain/effect/timeline/flight-timing`）に見た目ごとの実時間で持ち、再生の5〜60%に収める（再生の割合で持つと、尺の長い連射ほど弾が遅く飛ぶ）。隕石だけは87.5%まで遅らせられる（落ちる前の予兆も飛ぶ時間に含むため）。岩の弾は`ROCK_TRAVEL_MS`で遅く飛ぶ。狙撃と気弾は、撃つ前の狙いと溜めのぶん遅れて放つ（`aimedTiming`）。

ミサイルは撃ち手の横へ蹴り出されてから的へ曲がり込み、誘導弾はより高く上がって大きく振れ、迫りながら揺れる（道は`scene/shot/shots`の`courseOf`）。連射の弾は`SWERVE_SIDE`の順に左右へ振り分けるので、束に見えない。群れのミサイルはさらにそれぞれの道のまわりをうねる（`scene/shot/missile-shot`）。本体は`scene/shot/bodies`の`missileBody`が描く。

**SEは発射音と着弾音の2段階**で鳴らす（`impactSoundIdentifier`を着弾時刻に予約）。発射音は弾ごとに鳴らす（`launchSoundTimes`。連射で1回しか鳴らないと弾数が耳に伝わらない）。飛翔体でない見た目の着弾音は`EffectPreset.impactSoundAt`の時刻に鳴らし、光・闇・時空・地割れ・大嵐・落雷・電流はそれぞれの`*-looks.ts`の当たる時刻に、極太ビームは放つ時刻に寄せる（溜めの間が無音にならないように）。

射撃で揺らすのは、強く撃ち込む見た目だけにする（`effect-shake`の`hitsHardAsShot`ほか）。銃弾・曳光・ミサイル・誘導弾、隕石、岩の弾は等級どおりに揺らし、上級の矢、中級以上の気弾と飛ぶ斬撃は軽く揺らす。ほかの魔法弾と光線は、着弾の見た目が揺れる種類でも揺らさない。

### アローレイン（`arrowrain`）

**撃ち上げ → 落下 → 突き刺さり**の三段（`scene/shot/arrow-rain`）。撃ち手の位置から`ARROW_RAIN_COUNT`本が順に空へ上がって消え、対象とその周り（`areaRadius`の範囲。無ければ的のまわり）へ、撃ち手の側から斜めに、手前から奥へ波のように落ちる。落ちる間は落ちる範囲の地面を暗くし、矢ごとの影を刺さる点へ縮める。刺さった所で光と土埃を上げ、2本に1本は撃ち手の側へ傾いたまま立って震える。対象の足元そのものには落とさず、コマが矢の間に立って見えるようにする。見た目が消えるときは、矢を一度にではなく1本ずつ消す。撃ち上げを省くと矢がどこから湧いたのか分からない。落ちる位置はキャストの種から1回だけ決めて覚えるので、毎フレーム同じ場所へ落ちる。矢1本ごとの撃つ・落ちる・刺さるは`arrowRainShots()`が返す1枚の表で、絵と音の両方がこれを見る。**発射音も着弾音も矢ごとに鳴らす**（110ms未満は間引く。1発ずつ鳴らすと連続音になって本数が聞き分けられなくなる）。

### 弾道ミサイル（`ballistic`）

**打ち上げ → 予告 → 落下 → 爆発**の四段（`scene/shot/missile-ballistic`）。撃ち手の足元を発射台にして、閃光と地を這う煙を出し、太い煙の柱を残して真上の見えない高さへ抜ける。落ちる位置の地面に赤い輪（`TARGETED`）が絞り込み、的の上空に光の点が光ってから、機首を下にして落ちる。落ちる道には蒸気の輪が開き、煙の尾が残る。最後に`impactKind`の見た目を描く（同梱の「弾道ミサイル」はきのこ雲）。撃った先が見えないぶん、落ちてくる位置の輪を地面へ描いておかないと、画面外から爆発だけが現れる。画面の揺れは落ちてきた瞬間に来る（[光・揺れ・音の経路](#光揺れ音の経路)）。

### 隕石

弾の見た目が`meteor`の飛翔体は、撃ち手から撃たずに空から落とす（`scene/meteor/`）。落ちる前に対象の床が赤く光り、空高くに光の点が見える（`meteor-fall`）。岩は斜めの一直線を少しずつ速く落ち、近づくほど大きく描く。白熱した面から炎が流れ、炎の塊を落としては煙に変え、通った所に炎の帯を残す（`meteor-rock`・`meteor-shed`）。当たると白い拍を当たりの止めの間保ち、縁から煤へ冷える溶けた穴、沈んだ岩、飛んできた向きへ投げる岩と砂利、左右へ低く走る砂煙を残す（`meteor-wreck`）。爆発で着弾するときは、拍・炎・焦げ跡を隕石に任せ、爆発は周りに投げる物だけを描く。

落ちる線は卓のマスで、岩の大きさはエフェクトの大きさで測る。大きな隕石ほど遠くから落ちることはない。岩とその炎は自分の深さに留める（`exactDepth`）ので、手前のコマに隠れ、床に沈み、目の近くでは薄くなる。連射の隕石はそれぞれの線で落ち、それぞれの穴を残す。隕石は等級どおりに画面を揺らす（`fallsAsMeteor`）。

### 大剣（`skyblade`）

撃ち手が剣を掲げ、光を集めて刃を立て、振り下ろして奔流を放つ。拍は`domain/effect/great-sword-looks`の`greatSwordTimingOf`が出す（集め終わる`gatheredAt`、振り始める`swingsAt`、水平になって放つ`releasesAt`、奔流が撃ち手の側から細る`thinsAt`、抜けきる`spentAt`）。場面は`scene/blade/skyblade`が組む。

- 集める間は撃ち手のまわりを暗くし、床を光らせ、属性の粒をまわりと床から刃へ吸い込む（`sword-gather`）
- 剣は帯を長さ方向に並べた色の物体で、平らな面を目へ向ける（`great-blade`）。その上に光の刃が立つ（`light-blade`）
- 振り下ろしは握りを支点に回し、後ろに大きな扇を残す。水平になった瞬間に画面を白くし、撃ち手のすぐ前から対象を抜けてその先まで、床に沿って1本の奔流を放つ（`sword-torrent`）。奔流は通り道に立つコマに当たって割れる（`BREAKS_ON_BYSTANDERS`）
- 対象の所では`impactKind`の見た目を奔流の中に描き、通ったあとには属性ごとの残り物を道全体に置く（`sword-wake`）

属性（光・炎・氷・雷・土・闇・風）は`impactKind`から決まる（`sword-paint`。炎の見た目は炎、`frost`は氷、`bolt`と`arc`は雷、地面の見た目は土、`miasma`・`curse`・`gravity`・`drain`は闇、`vortex`は風、それ以外は光）。どの属性も芯・内・本体・鞘・縁の順に塗るので、7つが同じ技に見える。芯は闇だけが黒で、ほかは白熱させる。属性で変えるのは、刃と奔流が運ぶ物（`light-blade`・`torrent-element`）と残す物（`sword-wake`）だけである。風の大剣だけは刃を風の柱に、奔流を横倒しの竜巻にする（`scene/wind/wind-sword`）。

1回のキャストで振る剣は1本で、最初に描く対象への線に沿って振り、ほかの対象は順に着弾だけを受ける。撃ち手がいないときは対象の横に立てる（`UNWIELDED_WAY`）。コマの動きは`addGreatSwordJolts`が決める。撃ち手は振る前に引き、振り下ろしで前へ運ばれ、奔流の間は震えながら踏ん張る。当たったコマは奔流の向きへ投げられ、流れている間そこで押さえられて震え、抜けたあと戻る。画面は奔流を放つ瞬間に等級どおり揺らす（`loosesAsGreatSword`）。段の運びに置いた光の剣は、着弾を次の段に任せる（`TRAVELLING`）。

### 極太ビーム・レーザー照射

極太ビーム（`beam`）とレーザー照射（`raybeam`）は別の見た目で、`domain/effect/beam-looks`がそれぞれの拍を出す（`beamTimingOf`・`laserTimingOf`）。場面は`scene/shot/beam`から`scene/beam/`の見た目へ渡す。

極太ビームは`scene/beam/colossal`が共通の流れを描く。撃ち手の前に溜め、放つ直前に細い槍で通り道を示し、白い閃光で放つ（当たりの止めがここに掛かる）。放った瞬間に、銃口から対象を抜けてその先まで全体が現れ、通り道に立つコマを飲み込み（`BREAKS_ON_BYSTANDERS`）、床に焼け溝を刻んで両側の床を照らす。最後は銃口の側から細くなって光の粒になり、溝は光ったまま冷えて煙を上げる。本体は`beamLookOf`で選ぶ。既定は1本の巨大な本体（`great-beam`）で、`moteStyle`が`prism`なら、白い芯のまわりに色相環から取った束を編む極彩（`prism-beam`）になる。束は帯を半分ずつ描いて（`half`）芯の前後を通す。本体の帯は目に近づくと細くして消す（`thins`）ので、撃ち手の目から覗いても画面が光で埋まらない。撃ち手は溜めで身を引き、放つ瞬間に押し戻され、照射の間踏ん張る。浴びたコマは押し戻されて震える（`beam-reaction`）。

レーザー照射（`scene/beam/laser`）は、細い照準線を対象の手前の床に当ててから光り、床を焼き切りながら対象まで進む。対象を捉えると照らし続け、切れたあとも焼け跡が光って煙を上げる。捉えている間、対象は震える。

### ブレス（`breath`）

撃ち手が息を吸い、口元で白く弾け、先端が円錐を最も遠い対象まで走ってから、吹き続ける（`scene/breath/breath`）。円錐はキャストの全対象に1つで、最初に描く対象と一緒に描く（`breath-cone`。対象が離れすぎて1つの円錐に収まらないときは首を振る）。流れは口から途切れない噴流（`breath-jet`）と、その上を流れる塊（`breath-stream`）で描き、どちらも最も暗い層から芯へ順に重ねて1つの体にする。円錐の中に立つコマには、対象でもそうでなくても当たって割れ、回り込んで跳ね返る（`Stage.bystanders`）。息が切れると口元から細り、残りが円錐を流れ、各コマと床に残す物（`breath-leftovers`）が燃え・張り付き・光り続ける。流れの速さは秒で持つ（再生の割合で回すと、尺の長いものほど中身が遅くなって勢いが無くなる）。流れは自分の深さに留める（`exactDepth`）ので、後ろを通るコマに隠れ、内側から覗く目の近くでは薄くなる。口元だけは撃ち手の前へ寄せる。

属性は`scene/breath/breath-looks`の`breathElementOf`が決める（炎・氷・毒・雷・風・闇・光・砂の8つ）。回復と聖の系統は光の息（`isGentleBreath`）、土の系統で粒を選んでいないものは砂、ほかは`effectMoteOf`の粒で決まる。火の粉は炎、氷晶は氷、放電は雷、木の葉は風、黒い靄は状態異常の系統なら毒でほかは闇、「出さない」は副色が炎の色なら炎でほかは氷になる。属性ごとの`BreathLook`が勢い・浮き沈み・層ごとの塊の種類と量・照らす光の強さを持つ。コマの動きは`addBreathJolts`が決める。撃ち手は吸い込みで身を引いて吐き出しで前へ出され、吹かれた対象は等級に応じて風下へ押されて震える。

### 斬撃・打撃

斬撃（`slash`）は、撃ち手の立つ側から対象を横切る弧を刃が掃き、その跡に三日月を描く（`scene/blade/slash`・`crescent`）。三日月は暗い縁・刃の色の本体・淡い帯・振る側の白熱した内縁で塗り、残像と速度線と切っ先から裂ける空気を付け、刃が過ぎると尾から崩れる。横切る瞬間を1フレームの当たりにして、対象を貫く光の線・火花と破片・十字の光を出し、そのあと斬り口を開いて光を噴かせ、床の斬り跡を冷まし、粒を昇らせる（`cut-impact`）。太刀筋は等級と無関係で、`slashStyle`が決める。一太刀と連撃は`slash`、居合は`slash-iai`、薙ぎ払いは`slash-sweep`、唐竹割りは`slash-cleave`が描く。刃の線は`domain/effect/timeline/blade`の`slashHits`が持ち、場面・当たり・コマの動きがこれを読む。系統が風か粒が木の葉の斬撃は、風の刃（`scene/wind/sickle`、`cutsAsWind`）で描く。斬られたコマは各太刀の刃の向きへ流し（`cutCarriesOf`）、唐竹割りでは上から押し込む（`strikesFromOverhead`）。

飛ぶ斬撃は`scene/blade/flying-slash`が、刃から放つ大きな三日月として描く。床に光る線を刻んで対象を抜け、着弾が斬撃なら斬り跡を交差させる。

打撃（`bash`）は`domain/effect/strike-looks`の`strikeLookOf`が等級で3つに分ける（`scene/strike/`）。

- 初級の`jab`は拳の形の力をまっすぐ打ち込み、当たった点から棘の星と圧力の輪を弾かせ、背中側へ力の円錐を抜く
- 中級の`swing`は頭上から重く振り下ろし、輪を鳴り続けさせ、当たったコマを床に跡を引かせて滑らせる
- 上級の`crush`は拳に力を溜めてから打ち込み、力を背中から抜き、床を網の目に割って岩を浮かせてから落とす（`crush-ground`）

当たるまでの溜めは`strikeLandsAt`が決め、重い見た目ほど長い。撃ち手は引いてから運ばれ、当たったコマは見た目ごとに跳ね返る・滑る・足をすくわれる（`strike-reaction`。横へ流すのは`knockTurnOf`で`swing`だけ）。

### 炎

炎の見た目はどれも`scene/fire/fire-body`の塗り方で描く。炎を層に分け、最も広く暗い赤から最も熱い層へ、全部の炎の縁を先に、本体をあとに重ねる。多くの炎が1つの火にまとまり、縁が赤く芯が淡くなる。炎は先が裂ける`lick`か、縁が転がる`blaze`で、冷えると芯の層から失い、残りは煙（`billow`）になる。

- 爆発（`burst`）は、熱が一点に集まって白い拍で弾け、火球が膨らんで転がりながら、縁から赤へ、煙へ冷える（`scene/fire/burst`。弾ける見た目はみな`blast`を使う）。等級は大きさと、することの量で、中級は床に衝撃の輪と砂埃、上級は2つ目の輪と岩と燃えさしを足す
- 炎上（`flame`）はコマを炎で包む（`scene/fire/flame`・`flame-fire`）。炎の舌はコマの四方に立てるので、奥の舌はコマに隠れ、コマは火の中に見える。手前に描くのは、コマを隠さない小さな火だけ。等級は火の大きさで、初級は撃ち手から飛んだ火の粉がついて消えかかり、中級は頭まで包み、上級は背丈を超えて燃え上がる
- 大爆発（`nova`）は範囲を持つ。低く広い炎のドームと、範囲の端まで走る衝撃の輪と炎の前線（`fire-ground`）を描き、巻き込んだコマは衝撃が届いた順に自分の爆発を受ける
- 業火（`mushroom`）は地面を割って炎を漏らし、地を這う炎の上に炎の柱を立て、柱の上で笠を巻かせて煙に変える（`mushroom-cloud`）。衝撃の輪と炎の前線で地面を広く燃やす

炎の弾は`domain/effect/fire-looks`の`isFireShot`が決める（魔法弾で、炎の見た目に着弾し、副色が炎の色で、ほかの属性の系統や粒を持たないもの）。初級は細い炎の矢、それより上は尾の長い炎の球で、煙の糸を残す（`scene/shot/fire-shot`）。

### 雷

稲妻は`scene/storm/lightning`が、2点の間の帯として描く。淡い光・白熱した幹・細い枝の3つで、床より下には描かない。落雷（`bolt`）は`domain/effect/thunder-looks`の`boltLookOf`が等級で3つに分ける（`scene/storm/`）。

- 初級の`snap`は撃ち手の手元に火花を集め、細い稲妻を対象へ道を変えて3度走らせる。撃ち手がいなければ、対象の頭の少し上から落とす
- 中級の`strike`は床を暗くして光の輪を絞り、空から先導を枝分かれさせながら降ろす。コマから昇る光と出会うと、同じ道を太い幹が戻り、さらに道を変えて2度落ちる
- 上級の`storm`は頭上に雲の輪を渦巻かせ、対象に雷の柱を立てる。柱はキャストのほかの対象にも枝を伸ばし、最後にひときわ太い一撃で終わる。当たりは柱が立つときと最後の一撃の2つ（`boltStrokesOf`）

電流（`arc`）は対象の数で描き方を変える（`scene/shot/arc`）。1体なら撃ち手と対象の間に電流を保ち（`current`）、2体以上なら選んだ順にコマからコマへ跳ばし、全部つながった瞬間に太く光らせてから、撃ち手の側から順に切る（`chain`）。届く時刻と離す時刻は`CURRENT_REACHES_AT` / `CURRENT_BREAKS_AT`。

雷の弾（`isThunderShot`）は紫の球に細い稲妻を巻き、通った床へ時々稲妻を落とす。着弾は`shotBolt`で、最も小さい`snap`を撃ち手なしで当たった所へ落とす。落雷も対象の大きさの平方根でしか大きくしない（嵐が卓全体を暗くしないように）。雷に打たれたコマは離されるまで等級に応じて震え（`addConvulsions`）、空から落ちる`strike`と`storm`では押し戻されずに跳ね上がる（`strikesFromSky`）。

### 氷

氷結（`frost`）は`domain/effect/ice-looks`の`frostLookOf`が4つに分ける（`scene/ice/`）。

- 初級で範囲の無いものは雹（`hail`）。撃ち手の肩越しに大きな塊を続けて叩きつけ、折れた根元を立たせる
- 上級で範囲のあるものは凍結（`zero`）。範囲の空気を青くし、中心から冷気の前線を広げて各対象に尖塔を立て、全体を止めてから一度に砕く。範囲全体は最初の対象と一緒に1回描き、ほかの対象にはそのまわりだけを描く
- 上級で範囲の無いものは氷柱（`coffin`）。板で囲んでから1つの結晶で閉じ、ひびを順に走らせて砕く
- ほかは結晶の冠（`freeze`）。ほかの見た目の着弾として描く氷結も冠になる。飛翔体の着弾では弾の大きさの冠、大剣の着弾では大剣の等級のまま描く

拍は`hailStrikesOf`・`freezeTimingOf`・`zeroTimingOf`・`coffinTimingOf`が出す。凍結と氷柱は、閉じるときと砕けるときの2回当たる。結晶は粒の`crystal`、霜は床の印の`rime`で描く。氷結も対象の大きさの平方根でしか大きくしない。

竜巻のうち、粒が氷晶か、粒を選ばず系統が氷のものは吹雪（`isBlizzard`、`scene/ice/blizzard`）になる。白い風の帯をコマに何重にも巻き、帯の奥の半分をコマの後ろ、手前の半分をコマの前に描く（帯の`half`）。吹かれたコマは押されて震える（`ice-reaction`）。氷の弾（`isIceShot`）はつららで、着弾の氷結の上で砕ける（`scene/ice/ice-shot`）。

### 土

`domain/effect/earth-looks`が拍を出す（`rubbleHeavesOf`・`upheavalTimingOf`・`quakeStrikesOf`）。見た目は`scene/earth/`にある。

- 衝撃波（`impact`）は地面を一点で踏む。床に平たい閃光、打った向きに大きく後ろに小さい三日月の衝撃、めくれて傾いて落ちる敷石、扇形の岩と砂利、土の柱、縁の盛り上がったへこみを描く
- 岩石破砕（`rubble`）は対象の下を3度隆起させる。そのたびに対象と両脇に口を開け、敷石をめくってコマほどの岩と土砂を噴き上げ、口の間の亀裂を赤く光らせる。岩は落ちて跳ね、転がって止まる。当たりは隆起ごとに3つで、2つ目からは止めを短くする
- 地隆（`upheaval`）は撃ち手の足元から対象へ岩の牙を順に突き出し、対象の下から大きな柱、範囲の端まで牙の輪、巻き込んだ対象の下にも柱を立て、ひびを光らせてから上から崩す（`upheaval`・`fangs`・`fang-layout`）
- 地割れ（`quake`）は`quakeLookOf`で2つに分ける。上級で範囲のあるものは大地震（`earthquake`）で、範囲を震わせてから3度大きく揺らし、そのたびに砂煙の波紋と光る大亀裂を走らせ、巻き込んだコマの下にも亀裂を開く。ほかは裂け目（`rift`）で、撃ち手の前から対象まで地面を裂き、対象の足元で弾けさせ、少し先まで走らせて冷ます

岩は粒の`crag`、亀裂は床の印の`fissure`と`cracks`で描く。土の見た目は対象の大きさの平方根でしか大きくしない（竜ほどの大きさの岩は卓を塞ぐ）。岩石破砕・地隆・地割れが当たったコマは押し戻さず、上へ突き上げる（`heavesGround`）。岩の弾（`isRockShot`、`rock-shot`）は転がりながら低い弧で飛ぶ岩で、着弾では岩が砕ける。土の系統のブレスは砂で、床に砂の帯と吹きだまりを残す（`scene/breath/breath-sand`）。

### 風

竜巻（`vortex`）は`domain/effect/wind-looks`で3つに分かれる（`scene/wind/`）。

- 初級で範囲の無いものは突風（`gust`）。撃ち手の足元に砂を寄せてから、白い三日月を先頭にした風の壁を対象まで走らせ、対象に当たって左右に割る。当たりは壁が当たる瞬間の1つで、押し戻しは最も大きい
- 粒が放電のものは大嵐（`storm`、`isStormWind`）。大きな竜巻に範囲を覆う雷雲を載せ、巻き込んだコマを持ち上げて回し、雲から3度、各コマへ順に雷を落とす。当たりは雷ごとに来る
- ほかは竜巻（`tornado`）。地面の渦から空へ伸びる漏斗で、暗い鞘の柱に風の帯を巻き、巻き上げた物を上から放り出す。真下のコマを持ち上げ、まわりのコマを引き寄せる

粒が氷晶の竜巻は吹雪（[氷](#氷)）になる。風の帯は帯の追加の欄で描く（[卓の場面での描画](#卓の場面での描画)）。物に巻き付く帯は奥の半分と手前の半分を別々に描いて、物の後ろと前に分ける。

ほかの見た目にかかる風は次のとおり。

- 系統が風か粒が木の葉の斬撃は風の刃（`sickle`）。誰も持たない白い三日月が斬り、斬り跡を白線で残し、最後の一太刀のあとに突風で吹き散らす
- 着弾が竜巻の飛ぶ斬撃は真空波（`fliesAsVacuum`）。圧縮した空気の三日月が床に溝を刻んで飛び（`vacuum-wave`）、対象で風の輪になって弾けたあと、しばらく風の刃が対象のまわりを回って斬り続ける（`vacuum-gale`）
- 着弾が竜巻の魔法弾は風の弾（`isWindShot`、`wind-shot`）
- 風の大剣は刃を風の柱に、奔流を横倒しの竜巻にする（`wind-sword`）

### 闇

`domain/effect/dark-looks`が等級で選び、拍を出す（`darkStrikesAt`）。影（`shadow`）は上級で奈落（`abyss`）、ほかは棘（`spike`）。黒い太陽（`darkorb`）は上級で蝕（`eclipse`）、ほかは球（`orb`）。見た目は`scene/dark/`にある。

- 棘は対象の影を広げて縁を紫に燃やし、黒い棘を突き上げてから折って沈める。突き上げたコマを浮かせる（`stabsFromBelow`）
- 奈落は床に穴を開け、巨大な影の手（`shadow-hand`）を立てて巻き込んだコマをつかませ、引くたびに腕を縮めてコマを沈め、最後に穴を閉じて黒い炎を噴く（`abyss`・`abyss-pit`）。範囲があれば最初の対象のまわりに範囲の広さで1回開き、範囲が無ければ対象ごとに開く。当たりはつかむときと閉じるときの2つ
- 球は闇を流し込んで対象を飲み、光を吸ってから一点へ縮めて弾けさせる
- 蝕は卓の上空で白い太陽を黒い円盤で隠して卓全体を暗くし、縁から光の針をキャストの全対象へ降らせ、コロナが広がる瞬間に全員を黒い炎で包む。キャストに1回、最初の対象の上に描く。コマを上から押さえる（`fallsAsEclipse`）

吸収（`drain`）は撃ち手から3本の帯を対象に打ち込み、脈ごとに対象の光を紅い帯に沿って撃ち手へ運び、最後に切って撃ち手を光らせる（`drain`・`drain-drinker`）。当たりは打ち込むときと切れるときの2つで、1つ目はコマを撃ち手へ引き寄せ、2つ目で戻す（押し返しの量が負）。毒霧（`miasma`）は対象のまわりに低く毒の雲を転がし、泡を浮かべて弾けさせる。飛翔体や大剣が影・黒い太陽で着弾するときは、等級によらず棘か球で描く。

### 聖

系統「聖」は聖印・裁きの光・天罰（`smite`）、光輪（`halo`）、聖域（`sanctuary`）と、光の大剣・聖なる吐息・聖光弾を持つ。`domain/effect/holy-looks`の`smiteLookOf`が等級で`smite`を3つに分け、`holyStrikesAt`が見た目ごとの「見えてから当たるまで」を出す。見た目は`scene/holy/`にある。

- 印（`seal`、初級）は、対象の頭上に紋章を灯し、細い光の柱を落とす
- 裁き（`judgement`、中級）は、床に輪を絞り、太い柱を白い拍で落として立たせ、羽根を降らせる
- 天の光（`heaven`、上級）は、雲を集めて割り、床に大きな紋章を広げてから巨大な柱を落とす（`heaven`）。範囲があれば最初の対象に範囲の広さで1回落とし、ほかの対象には同じ瞬間に小さな柱を落とす
- 光輪（`halo`）は対象の胴の高さに輪を出して締め、白く弾けさせる
- 聖域（`sanctuary`）は床に紋章を開いて回し、縁から金色の光の壁を立て、各対象の足元から光を噴かせる。範囲があれば最初の対象のまわりに1回開く

紋章は床の印の`crest`、羽根は粒の`feather`で描く。どれも当たりは1つで、印・裁き・天の光はコマを上から押さえ（`fallsFromAbove`）、聖域はコマを持ち上げる（`burstsFromBelow`）。光で打った所には光の染みを残す。系統が聖の魔法弾、または光や回復の見た目に着弾する魔法弾は光の槍（`magicShotOf`の`holy`、`scene/shot/holy-shot`）になる。

### 時空

`domain/effect/space-looks`が等級で選び、拍を出す（`spaceBeatAt`）。転移（`warp`）は上級で召喚（`summon`）、ほかは瞬き（`blink`）。重力（`gravity`）は上級で特異点（`singularity`）、ほかは押し潰し（`crush`）。見た目は`scene/space/`にある。

- 瞬きはコマを縦に貫く光の裂け目を開き、コマから光の糸を吸い込んでから閉じ、十字の光と残像を残す（`blink`・`blink-after`）。閉じるときにコマを持ち上げる
- 召喚は金色の筆で床に文字の帯と五芒星を書き、陣を回して光の柱を立て、呼ばれたコマを持ち上げる（`summon`・`summon-circle`・`summon-pillar`）。陣は床の印の`seal`で描き、`sealSeedOf`が帯か星かと、書き終えた割合を種に詰める。色は深い色を黒に近い地に置き、金を通す、召喚だけの配色である
- 押し潰しは対象の頭上に黒いレンズを開き、床を井戸のように曲げ、圧力の円錐を叩きつけてコマを押さえ続け、離してから跳ね戻す（`crush`・`crush-well`・`crush-parts`）。対象が多いほど1体ぶんの描く量を減らし、1フレームの予算に収める
- 特異点は範囲の中心で空中に黒い穴を開き、光の円盤と焼け焦げた渦で土砂と巻き込んだコマを引き寄せ、一点に縮んだあと白い拍で全部を外へ吹き飛ばす（`singularity`・`singularity-body`・`singularity-parts`）。キャストに1回、最初の対象の上に開く

時空の見た目は太い色の体で描く（`space-bold`）。どの体も1つの色相をその最も暗い色の縁で少し太く囲み、芯を淡い色へ寄せ、光を下に敷くのは燃える所だけにする。明るい卓でも遠くから読めるようにするためである。色相はプリセットの色から取るので、色を変えたプリセットはその色で描かれる。当たりは押し潰しと特異点に1つずつで、転移は当たらない。コマの動きは`space-reaction`が決める。

### 回復・防御・強化

`domain/effect/blessing-looks`が選び、見た目は`scene/holy/`にある。

- 回復（`heal`）は`healLookOf`で5つに分ける。粒が`cleanse`なら浄化で、初級は泡で追い出す`purge`、それより上は波で押し流す`wash`（`cleanse`）。ほかは等級で、初級は芽吹き（`mend`）、中級は光の雨（`rain`）、上級は恩寵（`grace`）。恩寵は紋章とドームを全対象の中心に1回描き、各対象には光の柱を立てて持ち上げる（`liftsAsGrace`）。`cleanse`は編集画面の粒の選択肢に出さず、同梱の状態治療と状態回復が持つ
- 障壁（`barrier`）は、上級なら鏡（`mirror`、`isMirror`）、ほかはハニカムのドーム（`barrier`）。ドームは板の縁をドームの曲面に沿わせるので、どこから見てもドームに見え、奥の面はコマの後ろに、手前の面はコマが透ける薄さで描く。鏡は面を飛んでこさせて組み、空中から来る物を3度弾き返す
- 闘気（`aura`）は気の炎でコマを囲む（`aura`）。上級は溜めてから弾ける（`aura-breakout`、`breaksOutAsAura`）。弾ける瞬間に当たりを1つ持ち、画面を軽く揺らし、コマを持ち上げるが、押し戻さない

回復・障壁と上級でない闘気は、画面を揺らさない。

### 状態異常

呪印（`curse`）は`domain/effect/ailment-looks`の`curseLookOf`で描き方を選ぶ。粒が`AILMENT_LOOKS`の12の名前ならその状態、粒が放電（選んだものか、系統の既定）なら麻痺（`shock`）、ほかは呪いそのものを描く。見た目は`scene/ailment/`で、体に効くもの（毒・出血、`ailment-body`）、心に効くもの（睡眠・混乱・魅了、`ailment-mind`）、感覚や力を奪うもの（暗闇・沈黙・鈍足、`ailment-senses`）、石化（`ailment-stone`）、拘束（`ailment-bind`）、燃焼（`ailment-burn`）、恐怖（`ailment-fear`）、麻痺（`shock`）に分ける。

状態を表す印は粒の記号の形（`heart`・`zed`・`skull`など）で描き、`aside`で画面上の右と上へずらす。どの向きから見ても頭の横に出る。

当たりは掛かる瞬間の1つ（`takesHoldAt`）で、止めは短く、画面を揺らさず、コマを押し戻さない。かわりに`ailment-reaction`が再生の間コマにその状態の動きをさせる（恐怖は震えて縮こまり、睡眠は息に合わせてうなずき、混乱はよろめき、拘束は締め付けの合間にもがく）。

同梱の状態異常のプリセット（`builtin-effect-presets`の`ailmentSeed`）は、新しい部屋の状態異常の一覧と同じ名前で持つ。状態異常を付けたときに名前で引けるようにするためである（[発動の入口](#発動の入口)）。

### 撃破の演出

**撃破の演出はコマ自身に効く**（`dissolve`崩壊 / `gore`血しぶき / `bisect`両断）。崩壊はコマの絵を、ぎざぎざの線で区切った破片に`clip-path`で切り、風上の端から1枚ずつはがして、回しながら画面の右上へ飛ばす（`domain/effect/timeline/body`）。両断は斬り口で2枚に切って互いへ滑らせる（`domain/effect/timeline/blade`）。この絵の破片だけはoverlayが卓の上に重ね、絵のまわりの光・血・粒は場面で描く。

- 崩壊（`scene/body/dissolve`）は、足元から頭へ駆け上がる光の帯とひび、破片の縁の光と破片が崩れた粒、淡い残像、最後に昇る粒と縮む光の輪を描く。破片は絵と同じ種から作る（`dissolveShards`）ので、場面の光は絵の破片に重なって動く
- 両断（`scene/body/bisect`）は、斬る前に斬る角度へ刃の光を走らせ、当たりの1フレームで黒い縁・紅の本体・白い縁の太い線をコマの向こうまで引き、斬り口から血を噴かせて血だまりを広げる
- 血しぶき（`scene/body/body`）は、傷から飛ぶ血・脈打つ噴出・床の血だまりをすべて場面で描く

血はプリセットの色にかかわらず血の赤に留め、滴と跡に様式化する（`scene/body/blood`）。対象の絵は`EffectSpriteOptions.resolveImage`でoverlayから渡し、部位を狙ったときは本体の絵を切る。絵の無いコマは絵を切らず、場面で描く分だけが出る。コマ本体は`defeatReactionOf()`が返す合図（`dissolve` / `bisect` / `flinch`）で、`game-character`が卓のcanvasのコマに倒れる動き（`domain/tabletop/world/piece-motions`の`defeat-dissolve` / `defeat-bisect` / `defeat-flinch`）を再生する。

### 置きっぱなしの場

毒沼・炎の壁のような**置きっぱなしの場**は`EffectField`（`TabletopObject`）として盤面に置き、`EffectFieldService`が同じプリセットを尺で折り返して繰り返す（identifier由来の位相ずらしで並べても同じ動きにならない）。場面では`EffectFrameService`が尺の3/4（`NEXT_ROUND_AT`）ごとに次の周を始める。前の周の煙などが消えきる前に次が始まるので、継ぎ目が見えない。発動中の演出と場は`EffectFrameService`が1つのフレームにまとめ、コマの絵を切る見た目の破片はoverlayがまとめる。

### 環境エフェクト（天候・地表）

戦闘プリセットの繰り返しとは別に、**場の状態そのもの**を描く経路を持つ。種類は`domain/effect/ambience/ambience-kind`の16種で、マップ全体向けの`SKY_AMBIENCE_KINDS`（濃霧・雨・雷雨・雪・降灰・火の粉・砂塵・瘴気・光の粒・水中）と、範囲向けの`GROUND_AMBIENCE_KINDS`（毒沼・地面の炎上・地面の噴出・濃霧・瘴気・溶岩・氷結・光の粒・水）の2つの一覧に振り分ける。水と水中は[水域](water-ground.md#水域)と[水中の天候](water-ground.md#水中の天候)にある。ページのcanvasに描く粒は、経過時間から毎回まるごと計算し直す純関数で、位置を端で折り返して繰り返す。

- **霧と瘴気の濃さは塗りではなく雲の重なりで作る** — 塗りを濃くすると雲が沈んで団子になる。塊は流れながら回り、大きさ・伸び・濃さが別々の周期で揺れる（`haze()`）。平行移動だけだと板が流れて見える
- **稲光は経過時間だけの純関数**（`skyAmbienceFlash`） — 5.2秒（`STRIKE_CYCLE_MS`）ごとに1回、種から決めた時刻に光る。1回で消さず二度光らせないと、雷ではなく写真のフラッシュに見える。雷雨の卓では、`Table3dEngine`が場面を描くたびにこの値で場面の明かりを上げる

**マップ全体（天候）** は`GameTable`の`weatherKind` / `weatherColor` / `weatherDensity`。雨・雷雨・雪（`domain/tabletop/world/weather-fall`の`WEATHER_FALL_KINDS`）は卓の場面が降らせる（`infrastructure/table-3d/weather-layer`）。雨粒と雪片は、カメラの見ている所を中心にした四角の中で、それぞれ決まった出発点から経過時間ぶん進めた所に折り返して描き、四角の端・盤の外・空から出てくる所で薄れる。一度に描くのは最大6000粒（`MAX_WEATHER_FALL`）。ほかの天候の粒と、すべての天候の空気の色（`skyAmbienceWash`）は、`features/tabletop/table-weather-overlay`が画面大の1枚として卓のcanvasの上に重ねる。大きさはhostの`ResizeObserver`で測る（`observeSize`）。盤から天井（壁の高さ、最低10マス）までの箱の8つの角を`pageOfTablePoint`で画面へ投影し、それを覆う楕円の`mask-image`で盤の外へ向けて薄れさせる（`weatherMaskImage`。盤の端まで濃さを保ち、その1.55倍の所で消える）。多角形で切ると、空中にガラスケースのような直線の縁が出る。**床の四角形だけで覆ってはいけない**。盤の上空に降っているぶんが消えて、粒が地面に貼り付いて見える。投影は100msごと（描画を軽くしている間は400ms）に、カメラが動いていればやり直し、動かなくても1秒ごとにやり直す（バーが開くなど、カメラが動かずにページが動くことがある）。空気の色は盤の奥から手前へ薄くなる向きに塗る（`weatherDepthDirection`）。一人称のビューでは、マスクを掛けず画面全体に描く（`fromInside`）。

**範囲**は`TableAmbience`（`TabletopObject`）。マップマスクと同じくテーブルの子なので、マップを切り替えると一緒に切り替わる。`ambience-ground`が面（`groundSurfaceLayer`）と立ち上り（`groundVaporSheets`）を別々の層で返す。`features/tabletop/table-ambience`は、面の塗りと粒を、卓のcanvasがその範囲の地面の四隅を描く画面上の位置へ`matrix3d`で貼り（`quadMatrix`）、立ち上りの板は、板が立つ地面の点が描かれる画面上の位置に、カメラへ向けて立てる。水は自分の粒を持たず、水面は卓の場面が描く（`groundAmbienceHasParticles`）。粒の大きさは`unit`（1マス）を基準に決めるので、範囲を広げても粒が巨大化しない。

- **立ち上りは奥行き方向へ複数枚の板に分ける**（`vaporSliceCount`。奥行き2.5マスごとに1枚、最大5枚） — 板を1枚だけ立てると、奥のものも手前のものも同じ深さに並ぶので、16×16では盤面に帯を貼っただけに見える。粒はそれぞれ範囲の中に自分の点を持ち、カメラから見てその点のすぐ手前に立つ板に、点が板より奥にあるぶんだけ上へずらして描く（下へずらすと板の立つ床より下に沈む）。板は卓の向き（`tableViewRotation`）に合わせて並べ直す。粒の総数は板の枚数で変えず、上限だけを1枚あたり150（`MAX_VAPOR_PER_SLICE`）で数える。範囲全体で上限を数えると、広い範囲ほど粒が薄まり、炎がまばらに浮く
- **大きさは1粒ずつ大きく散らす**（`scaleMin` / `scaleMax` / `scaleBias`） — 揃った大きさで並べると、大炎上ではなく焚き火にしかならない。biasを上げて「小さいものが多く、大きいものが稀」にする
- **炎の先端を暗い色まで落とさない** — 加算合成では暗い色はほとんど何も足さないので、色ランプを最後まで通すと粒の過半が見えなくなって炎が痩せる。白熱させるのは根元だけにして、あとは濃さで消す

- **粒の数はマスで数える** — 面積(px²)を基準にすると、既定の4×4マス（0.04メガピクセル）では数個しか出ず、置いても何も無いように見える
- **オブジェクトを返すcomputedに版を吸わせない** — `versionOf()`を読んでから同じオブジェクトを返すcomputedを挟むと、参照が変わらないのでsignalsが下流へ変化を伝えない。版そのもの（数値）を配って各値がそれを読む。これを間違えるとロックも大きさの変更も画面に出ない
- **canvas 1枚の画素数に上限を置く**（`features/effect/effect-canvas`の`pixelRatioFor`、`MAX_CANVAS_PIXELS`＝400万） — マップ全体を覆う範囲は一辺数千pxになり、高精細画面では数億画素を確保しようとする。画素比は2までで、上限を超える層は粗く描く
- **canvasは範囲より一回り大きく取る**（面は0.9マス＝`SURFACE_PAD_UNITS`、立ち上りは最大の粒の半径＋0.2マス＝`VAPOR_PAD_MARGIN_UNITS`） — 粒はcanvasの形に切り取られるので、粒の直径が範囲と同じくらい大きいと、中心が真ん中にあっても裾が枠で切られて灰色の四角が浮く。中心からの距離で透明度を落としても防げない
- **塗りのグラデーションは`closest-side`** — 既定のfarthest-cornerだと、中心を寄せた塊が箱からはみ出し、はみ出した側が不透明なまま直線で切られる
- **演出を止めていても面の塗り（`groundSurfaceWash` / `skyAmbienceWash`）は残す** — 発動する演出と違い、消すと「そこが毒沼である」という盤面の情報ごと消える
- **OSの設定は既定値であって最終決定ではない**（`application/ui/motion.service`、`auto` / `on` / `off`） — Windowsは描画を軽くする目的で「アニメーション効果」を切る。`prefers-reduced-motion`にそのまま従うと、音だけ鳴って画面には何も出ない卓ができあがる
- **描画ループの持ち主は複数いる** — `EffectPlaybackService.setPersistent(source, boolean)`はソース名で持ち主を数える。真偽値ひとつだと、場と環境演出のうち後から来たほうが前の要求を消してしまう

### 卓の場面での描画

演出は卓のthree.jsの場面の中に、コマや壁と一緒に描く。見た目ごとの振り付け（`Choreography`）は`domain/effect/scene/`配下の純関数で、1つの対象について、その瞬間に描く物（`EffectFrame`。粒`motes`・帯`ribbons`・床の印`floor`・光`lights`）を卓の座標（卓のpx。xは東、yは南、zは上）で返す。受け取る`Stage`は、対象の足元と床の高さ・1マスの大きさ・対象の背丈（`tall`。絵やモデルの描かれた高さ）・経過秒と尺・当たりの時刻（`blowsAt`）・範囲の広さ・発射元・口元（`mouth`）・種のほか、キャストの全対象（`targets`）と、見た目が求めたときだけ通り道のほかのコマ（`bystanders`）を持つ。`application/effect/effect-frame.service`が再生中の演出と置きっぱなしの場を毎フレーム1つの`EffectFrame`にまとめ、`application/tabletop/table-3d.service`が`infrastructure/table-3d/effect-layer`の`EffectLayer`へ渡す。描く物が何もなければ、同じ空のフレームを返して時計を読まない。見た目の本体（`domain/effect/scene/effect-frame`）は大きいので別に読み込み（`EffectSceneLooksService`）、卓を最初に描くときに読み始める。読み込みに失敗したら5秒あけて読み直す（`EFFECT_LOOKS_RETRY_MS`）。

overlay（`features/effect/table-effect-overlay`）に残るのは、崩壊と両断が切ったコマの絵の破片だけで、卓のcanvasがそのコマを描く画面上の位置に重ねる（1フレーム400枚まで、`MAX_SPRITES`）。環境エフェクトのうち、雨・雷雨・雪の粒と水面は場面で描き、ほかはページに重ねる（[環境エフェクト](#環境エフェクト天候地表)）。[プレビュー](#プレビュー)（`features/effect/effect-preview`）は、盤と代役のコマを置いた小さな舞台（`infrastructure/table-3d/effect-stage`の`createEffectStage`）に、戦闘カットインは舞台の上の透明なcanvasに、同じ`EffectLayer`で描く（[戦闘カットイン](battle-cut-in.md#戦闘カットイン)）。視界外の対象には描かない。演出を止めているとき（`MotionService.enabled`が偽）は何も描かずSEだけ鳴らす。

- **対象ごとと、キャストに1つ** — `stageEffect`は対象ごとに振り付けを呼ぶ。ブレスの円錐、大剣、蝕、特異点、恩寵、範囲のある凍結・奈落・天の光・聖域のように、キャスト全体で1つの物は、最初に描く対象の呼び出しで`targets`を見て描き、ほかの対象の呼び出しではそのまわりの物だけを描く
- **大きさ** — 対象のまわりで起きる見た目は対象の大きさで大きくするが、狙って撃つ見た目と、土・氷結・斬撃・落雷は、対象の大きさの平方根でしか大きくしない（`GROWS_BY_ROOT`。竜ほどの大きさで岩や結晶や三日月を描くと卓を塞ぐ）
- **光と色の2つの層** — 粒・帯・床の印は、どれも光（足し算で重ね、まわりにあふれる）か色（上に塗る）のどちらか（`EffectBlend`）。熱い物は光、煙・砂埃・破片・炎の体は色で描き、白は最も熱い芯と縁にだけ使う。`EffectLayer`は粒・床の印・帯を、光と色の2つずつのバッチで描く
- **粒の形** — 粒の形（`EffectMoteShape`、`domain/effect/scene/effect-scene`）は、丸い光・火花・煙・破片・星などのほかに、流れる形・記号・岩と氷を持つ。流れる形（`lick`・`wisp`・`jet`・`gust`・`blaze`・`billow`）は、根元から先へ模様が流れて縁を削り、芯を`core`の色へ2段で寄せる。`spin`は回転ではなく模様の流れた量になる。岩（`crag`）と氷の結晶（`crystal`）は、`spin`の整数部に先の折れた量、小数部に筋やひびの届いた高さを詰める。記号（`heart`・`zed`・`skull`・`feather`など）は暗い輪郭の付いた平たい形で、`aside`で画面上の右と上へずらすので、頭の横に掛けた印はどの向きから見ても頭の横に出る。形はシェーダーへ一覧の位置の番号で渡し（`effect-layer`の`MOTE_SHAPE`）、流れる形と記号はそれぞれ一覧の中でまとめて並べる
- **帯の描き方** — 帯（`EffectRibbon`）は刃の弧・稲妻・ビーム・弾の軌跡に使う。風や炎の帯は、縁を流れる模様で削り（`torn`）、縁へ薄め（`soft`）、模様を流し（`flowed`）、芯を片側へ寄せる（`leans`）。物に巻き付く帯は、各点の巻き付く先（`about`）を持たせ、目に近い側の半分と遠い側の半分を別々に描く（`half`）。巻き付く先の前と後ろに分けて重ねるためである。`thins`の帯は、目に近づいて視界を埋めるほどになると細くして消す
- **床の印の形** — 床の印（`EffectFloorShape`）は、輪・円盤・紋・ひび・焦げ・亀裂（`fissure`）と、光の紋章（`crest`）・霜（`rime`。`width`が厚さ）・召喚の陣（`seal`。帯か星かと書き終えた割合を種に詰める、`sealSeedOf`）を持つ
- **バッチは最初から場面に置く** — 6つのバッチは演出が無くても場面にあり、何も描かずに待つ。グラフィックスカードの準備を卓と一緒に済ませるので、最初の演出で卓が止まらない。1フレームに描く量の上限は`EFFECT_FRAME_BUDGET`（光と色それぞれ、粒4096・床の印256・帯の点4096）。対象の多いキャストでは、1体ぶんの描く量を減らす見た目がある（押し潰しなど）
- **深度を書かない** — 演出はコマや壁に隠されるが、自分は何も隠さない。粒と帯は目の側へ寄せて描く（粒は`forward`、帯は12px＝`RIBBON_NEARER_PX`）。寄せないと、真ん中に立つコマの絵で切られる。大きな粒は大きさの割合ぶんさらに寄せるが、`exactDepth`の粒は`forward`だけ寄せ、手前に立つコマに隠れるようにし、目に近づいて視界を埋めるほどになると薄くして消す。ブレスの流れや隕石の岩のように、コマの間を通る物と内側から覗かれる物に使う
- **床の印は地面の起伏に沿わせる** — 地面の高さ（`domain/effect/scene/effect-ground`の`effectGroundOf`）に沿わせ、印1枚を縦横16に割って起伏に合わせる（`MARK_SEGMENTS`）。高さは盤全体を読むので、演出を描いている間だけ読み、描き始めに渡す。毎フレームは渡さない
- **乱数は種から** — 散らす粒は、キャストの種（`EffectCast.seed`）から作る乱数で1回だけ作って覚え（`domain/effect/scene/parts`の`throwerFor` / `keptFor`）、毎フレーム作り直さない。どの画面でも同じ絵になる
- **品質の固定** — `domain/effect/effect-quality.spec`が、全種類を上級・4体・横からで撃った重いキャストが1フレームの上限に収まること、種の無い乱数を使わないこと、対象と撃ち手から10マスより遠くに描かず床へ深く潜らないこと、同じ時刻は前に描いた物にかかわらず同じ絵になることを確かめる
- **対象側は届いてから描く** — 飛翔体・弾道ミサイル・大剣は、着弾の見た目を着弾の時刻からの自分の時計で描く。ブレスは流れが対象に届くまで、ビームは放つまで、対象側を描かない。届く前から出すと、当たる前に燃えていることになる
- **overlayのスプライトに`will-change`は付けない** — 崩壊は1体につき数十枚の破片を出す。全部を合成レイヤーへ昇格させると、その場でレイヤーを確保することになり、確保が終わるまで画面が暗く落ちる。毎フレーム位置も透明度も変わるので、昇格させても得が無い

### 光・揺れ・音の経路

- **当たり** — `domain/effect/effect-blows`の`effectBlowsOf`が、打つ見た目（`STRIKING_KINDS`。斬撃・飛翔体・爆発・打撃・落雷・氷結・ビーム・裁きの光・影・地割れなど）について、最初の対象に当たる時刻・止める長さ・揺れ・押し返しを`EffectBlow`として出す。時刻は各`*-looks.ts`の拍から取る。止める長さは等級1〜3で60・90・140ms、押し返しは0.06・0.10・0.16マス。前に止めた当たりから180ms未満の当たりは止めず、止める長さの合計は300msまで。回復・障壁と、上級でない闘気は当たりを持たない。段で組んだ演出は、打つ見た目の着弾の段ごとに1つ持つ
- **当たりの例外** — 岩石破砕と大地震は隆起ごとに当たり、2つ目からは止めを短くする。呪印とその状態は、掛かる瞬間に短く止めるだけで、揺らさず押し戻さない。上級の闘気は弾ける瞬間に短く止めて軽く揺らし、押し戻さない。吸収は打ち込むときにコマを撃ち手へ引き（押し返しが負）、切れるときに戻す。竜巻は当たりを持たないが、突風は壁が当たる瞬間に、最も大きく押し戻す。大嵐は雷ごとに当たる
- **当たりの止め** — 再生の時計は当たりごとに止まる（`heldEffectClock`）。止めたぶん、音と揺れの予約も後ろへずらす（`wallClockOf`）。演出を止めている画面では止めない
- **揺れ** — 揺れる見た目（`domain/effect/effect-shake`の`SHAKING_KINDS`。爆発・閃光・きのこ雲・衝撃波・岩石破砕・地隆・地割れ・打撃・斬撃・両断・氷結・落雷・極太ビーム・レーザー照射・重力・吸収・裁きの光・光輪・聖域・影・黒い太陽・弾道ミサイル）は、等級2で`soft`、3で`hard`に揺れ、1は揺れない。初級でも衝撃波と影の棘だけは`soft`に揺れる。飛翔体は着弾の見た目では揺らさず、弾の見た目で決める（[飛翔体](#飛翔体射撃系)）。大剣・大嵐は等級どおり、上級の闘気は`soft`だけ揺れる。`EffectPlaybackService`は止めのある当たりの瞬間に`shake`を立て、340ms（`SHAKE_MS`）で戻す。続けて来たら強いほうを取り、時間だけ延ばす。撃った瞬間に揺らすと撃った側が殴られたように見えるので、当たりの瞬間まで待つ。揺れは卓のcanvasを包む視界大の要素（`game-table`の`#root`。`overflow-hidden`でクリップされる）に`animate-effect-shake-soft` / `animate-effect-shake-hard`のクラスで掛け、一人称のビューも同じクラスを使う。振れ幅はCSS変数にせず、強さごとのキーフレーム（`src/styles/map-effects.css`の`effectShakeSoft` / `effectShakeHard`）で持つ。継承するCSS変数を書き換えると、その下のすべての要素のスタイルが無効になる
- **押し返しと踏み込み** — `domain/effect/effect-reaction`の`effectJoltsOf`が、各席でコマを描く位置のずれを出す。ブレス・吹雪・竜巻・大嵐・呪印・大剣・打撃・時空は、それぞれの動かし方へ渡す（`addBreathJolts`・`ice-reaction`・`addTornadoJolts`・`wind-reaction`・`ailment-reaction`・`addGreatSwordJolts`・`strike-reaction`・`space-reaction`）。ほかは当たったコマを止めの間そのままにし、撃ち手から離れる向きへ押し返して420msで戻す。押し返しは重なっても0.25マスまで。斬撃は太刀の刃の向きへ流し、裁きの光・蝕・唐竹割りは上から押さえ、岩石破砕・地隆・地割れ・聖域・影の棘は上へ突き上げ、空から落ちる雷は跳ね上げる。そのうえで、ビームの踏ん張り（`beam-reaction`）、闇の拘束（`dark-reaction`）、恩寵と上級の闘気による持ち上げ（`blessing-reaction`）、雷の震え（`addConvulsions`）を足す。撃ち手は打ち出す見た目（`LEANING_KINDS`）と突風のとき、最初の対象へ0.12マス踏み込んで戻る。`application/effect/effect-reaction.service`が各席で計算し、`TablePiecesService`がコマを描く位置だけをずらす。部位は本体として動かす。コマ自体は動かさず、何も送らない
- **光** — 各見た目は、まわりを照らす光（`EffectLight`。位置・色・強さ・届く距離）を`EffectFrame.lights`に入れる。爆発は一瞬、炎は燃えている間、まわりの床とコマを照らす。`application/effect/effect-light.service`が強い順に2つ（`MAX_EFFECT_LIGHTS`）を選び、卓の場面に最初から置いた2つの`PointLight`へ渡す。光の無い間は強さ0で待たせる。灯りの数が変わると場面を組み直すことになるため。演出の光は影を落とさない
- **音** — 音の時刻は、描画と別に`domain/effect/effect-sound-times`がプリセットだけから出す（音を鳴らす側が描画のコードを読み込まずに済む）。`EffectPlaybackService`が止めのぶんずらして予約する。発射音は55ms、着弾音は70ms（アローレインは110ms）より近いものを間引く。演出を止めている画面でも音は鳴らす

### 音

SEは効果音ラボ・On-Jinの素材を取り込み、`PresetSound`経由で割り当てる。音のidentifierはファイルのパスなので、編集画面では`domain/media/preset-sound-labels`がファイル名からi18nの表示名（`feature.effect.sounds.*`）へ引き直す（持ち込んだ音はファイル名だけを見せる）。**演出の尺は音の実尺から導出**する（`soundMs`をseedに持たせ400〜6000msに収める）ので、絵だけ先に終わって音が残ることがない。

### プリセットの編集と持ち出し

プリセットは**編集できる**。`features/effect/effect-preset-editor`が種類・系統・道中の粒・等級・色・大きさ・尺・ずらし・対象規則・範囲・SE・種類ごとの項目（弾の見た目 / 弾数 / 間隔 / 着弾演出 / 太刀筋）を直接モデルへ書き込み、範囲は`EffectPreset`のgetterが丸める。どの項目を出すかは`domain/effect/effect-preset-form`の純関数が種類から決める。**試し撃ちはローカル再生**（`EffectCastService.preview()`が`EffectPlaybackService`を直接叩き、`EFFECT_CAST`を送らない）。卓の上のコマに音つきで再生するので、対象になるコマが要る。編集画面の上部には[プレビュー](#プレビュー)を置き、`ObjectChangeService.versionOf`の値を`version`に渡して、値を変えるたびにその内容で再生し直す。

一覧は検索・等級と対象での絞り込み・系統の索引と折りたたみ・最近使った履歴を持ち、印には演出の形から起こしたSVGグリフを当てる。一覧からは追加・複製（`duplicatedEffectName`で連番）・削除（右クリックメニュー、`effect-library-context-menu`）ができ、`gmOnly`のプリセットはPLの一覧に名前ごと出さない。置いてある演出（`EffectField`）は一覧の最後に見出しつきで並べ、ここから片づける。領域の並びとキーボードの操作は[エフェクト集パネルの配置](#エフェクト集パネルの配置)にある。

エフェクト集の持ち出しは`EffectPresetSet`（`InnerXml`の入れ物。`ObjectStore`には残さない）。`EffectPresetSet.of([preset])`で**1つだけ**書き出せ（タイル右クリックと編集パネルの「書き出す」）、形式は集合と同じなのでドロップの読み込み経路も共通。`EffectPreset`は`toAttributes` / `parseAttributes`でidentifierをXMLに残す（`ChatMessage`と同じ手。既定では`ObjectSerializer.parseXml`が読むたびに新しいidentifierを振る）ので、**併合の第一の鍵はidentifier**（`domain/effect/effect-preset-merge`の`takeIntoLibrary`）。同じidentifierがあればそこへ、無ければ同名へ`toContext()` / `apply()`で中身を丸ごと移す（フィールドを列挙しないので段リストのような後付けも自動で乗る）。どちらも無ければ追加。identifierで重ねた結果その名前が別のエフェクトと衝突するときは、戻ってきた側を`duplicatedEffectName`で連番にする（名前はチャット記法やシートの演出欄から呼ばれるため、先にその名前を使っていた方を動かさない）。プリセットは部屋データとしても保存され、読み込んだ部屋に既定のプリセットを足すことはしない。メニューの「既定を反映」（`EffectLibraryService.restoreDefaults`）は既定プリセットを最新のseedへ再適用し、欠けたものを再作成する。「足りない既定を追加」（`addMissingDefaults`）は、部屋に無い既定プリセットだけを作り、ある物には触れない。あとの版で増えた既定を、卓が手を加えたプリセットを上書きせずに入れるためである。どちらも自作プリセットには触れず、消された既定は`announceComingBack`で戻ることを先に知らせてから同じidentifierで作る（作れないときは新しいidentifierで作る）。

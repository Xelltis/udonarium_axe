# ビジュアルノベルモード

## 開き方と画面

- **開閉はその画面だけ** — FABの「テーブル関連」の「ノベルモード」（メニューの命令`visualNovel`）で開く。`VisualNovelModeService`は開閉を`VN_MODE_EVENT`として自分の端末の中にだけ流し（`localDispatch`）、部屋には送らないので、ほかの参加者の画面は変わらない。画面（`features/visual-novel/visual-novel-overlay`）は`app.component`の`@defer`で、初めて開いたときに読み込む。狭い画面での並びは[モバイル（狭い画面）](ui.md#モバイル狭い画面)
- **別パネル** — ログ・演出・表示設定・進行はノベルモードの画面より上の層（`Z_VISUAL_NOVEL_PANEL`）に開くパネルで、ノベルモードを閉じると全部閉じる（`visual-novel-panels`の`closeVisualNovelPanels`）。操作列からは[ストリームチャットウィジェット](chat.md#チャット)も開ける

## 台本

- **1つのタブを台本として読む** — 「対象チャットタブ」で選んだタブの行を1行ずつ読む（`features/visual-novel/visual-novel-playback.service`）。選んだタブは表示設定と一緒に覚え、読めないタブになったら読める最初のタブに移る。削除した発言と物語外の知らせ（`isOutOfStory`）は台本にもログにも入れない。シークレットダイスは、ノベルモードが行を画面の中央に出し、配信用の画面もあって人に見せる画面になるので、振った本人の画面にも出さない
- **プレイヤーの雑談を飛ばす** — 既定では、プレイヤーが本人の名前で言った行を台本から外し、ログにだけ残す（`visual-novel-script`の`isPlayerAside`）。GM本人の発言・ダイス・ロールを頼んだ行・システムの知らせは残し、話し手の分からない行（話し手を記録していない古い部屋や取り込んだログの行）も残す。話し手はキャラクターから送った行ならキャラクター、そうでなければ行に記録した`ChatMessage.senderRole`、それも無ければ送った人の今の役割で決める。役割は後から変わり、カーソルも接続のたびに作り直されるので、行に記録した役割を先に見る。表示設定の「プレイヤーの雑談」を「そのまま読む」にすると全部読む
- **文字送り** — 行を1字ずつ打ち出す。`visual-novel-text`の`typedLineOf`が装飾とルビの単位に切り、見える字だけを数える（文中のスタンプは1字）。ロケーション・場面転換の行と、ロールを頼んだ行（次の行がダイスボットの結果で、`timestamp`が1後・`originFrom`が同じ行）は全文を一度に出す。戻る・行へ飛ぶ・スキップでも一度に出す。進むと、打ち途中の行は全文を出し、最後の行では最新の行に追従する
- **オートプレイとスキップ** — オートプレイは1行ごとに`min(4000, 1200 + 35×文字数)`ミリ秒を再生速度で割った分だけ待って進み、最新の行に着くと止まる。最新の行では始まらない。「最初から再生」は先頭の行からオートプレイする。Ctrlを押している間は120ミリ秒ごとに進む
- **システムの知らせは読む人の言語で** — 知らせはi18nのキーで持つので、ノベルモードでも読む人の言語に直して出す（`visual-novel-message`）

## 舞台の立ち絵

- **誰が立つか** — 今の行から最大60行（`VN_STAGE_LOOKBACK`）さかのぼり、キャラクターとして話した行の立ち絵を最大6人（`VN_STAGE_MAX`）まで、コマ1つにつき1人立てる（`domain/visual-novel/vn-stage-cast`の`buildVnStage`）。名前ではなくコマで見分けるのは、行に書く名前が改名や秘話（`話者 > 相手`）で変わるため。システム・ダイス・ロールを頼んだ行は飛ばし、場面転換の行でさかのぼるのをやめる。退場の印のある行の話し手は、その行より前の舞台からも外し、その退場の行を読んでいる間だけ立ってフェードする。ロケーションと場面転換の行では舞台を空にする。ふつうのセリフの行では話し手の立ち絵を強調する
- **立ち位置** — 舞台は12スロット（画面幅の8%〜92%）。位置は、行の`ChatMessage.vnPortraitPos`、キャラクターの`GameCharacter.vnPortraitPos`、チャットの立ち位置（シートの`POS`）、行の`imagePos`の順に見る。2つの`vnPortraitPos`は既定が-1で、未設定を表す。全員がスロット0なら、立ち位置を触っていない部屋として舞台に均等に並べる。ほかはスロットどおりに置き、近すぎる2人は押し広げる（`spreadStagePositions`）。立ち位置ガイド（`S`）で選ぶとキャラクターの`vnPortraitPos`に書き、部屋で共有する。「通常の位置に合わせる」で-1に戻す。旧版の保存では位置が文字列で、無い欄は空文字に読めるので、`toPortraitSlot`は空文字を未設定として読む（`domain/visual-novel/vn-portrait-position`）
- **立ち絵のリセット** — GMが進行パネルの「立ち絵をリセット」を押すと、読んでいるタブに物語外のシステムの知らせ（「{{user}}さんが立ち絵をリセットしました。」）を書き、その`placedAt`を`ChatTab.vnPortraitResetAt`に書く（`VisualNovelSceneService.resetStage`）。ログは書き換えない。それより後の行を読んでいる間は、それより前の行の話し手を立てず、さかのぼればその時の舞台が出る（`stageCutFor`）。境を時計ではなく知らせの`placedAt`にするのは、タブの`timestamp`が参加者の時計と関係なく前へ進むよう作られていて、ほかの所を境にすると直前の発言が境の反対側に残りうるため。タブに持つのは、ファイルから読んだ部屋はタブを作り直し、タブのidentifierで別の所に持つ値は行き場を失うため

## 発言と演出

- **発言者** — 発言欄から読んでいるタブへ送る。選べる発言者はこの席が話せるキャラクターだけで、GMだけは自分の名前も選べる。ノベルモードは場面を演じる画面で本人の名前の発言は場面に入らないが、GMは卓を進めるために本人として話す。キャラクターの発言はチャットパレットの`evaluate`を通してからダイスボットに渡す。送ると最新の行に追従する。立ち絵パターンはキャラクターの画像の何枚目かを前後に送り、このブラウザだけに持つ（`GameCharacter.selectedPortraitIndex`）
- **演出の種類** — 発言タイプ（セリフ / 地の文 / ロケーション / 場面転換）・吹き出しの形（ふつう / もやもや / 叫び / ささやき）・吹き出し演出（なし / ゆれ / ぽよん / ドキドキ / ふわふわ）・立ち絵演出（なし / ジャンプ / ぶるぶる / ズーム / うなずき / ゆらゆら / しょんぼり）・漫符（！ ？ 💢 💧 ♥ ♪ …）・「この発言で退場する」を演出パネルで選び、次の1行に付ける（`domain/visual-novel/vn-emote`、`VisualNovelEmoteSelectionService`）。場面転換は全員の舞台を空にするのでGMだけが選べ、送ると背景の切り替えを全員の画面で流す。選んだ演出は、送ったときとノベルモードを閉じたときに既定へ戻る
- **立ち絵の反転** — 「立ち絵を反転」はキャラクターシートの`FLIP`欄を0 / 1で切り替え（無ければ`POS`の隣に作る）、送るときに行の演出へ`flip`として書く。立ち位置と反転を変えられるのは卓を編集できる人（`canEditTabletop`）だけ
- **演出の保存形式** — 本文とは別のSyncVar`ChatMessage.vnEmote`に、既定と違う値だけを空白区切りのコード（`kind:scene`・`shape:shout`・`bubble:shake`・`portrait:jump`・`mark:heart`・`flip`・`exit`）で書く（`encodeVnEmote`）。初期値を付けないので、演出の無い行には属性が付かない。読むときは知らないコードを1つずつ飛ばして残りを効かせる（`decodeVnEmote`）ので、古いビルドの参加者は名前の分からない演出1つだけを失う。演出の名前は行に書かず、読む人の言語でi18nのキーから引く（`vn-emote-label`）
- **旧形式の演出** — `vnEmote`が空の行は、本文の末尾の`〔叫び・ゆれ〕`のような括弧を演出として読み、表示する本文からは外す（`parseLegacyVnEmoteSuffix`、`vnBodyOf`）。括弧の中の語がすべて演出の語で、どの種類も1回までのときだけ演出と読み、それ以外は書いた文字として残す。この形で新しく書くことはない
- **チャットでの印** — チャット設定の「ノベルモードの演出を表示」（`ChatPreferencesService.showVnEmoteBadge`、既定オフ、このブラウザだけ）で、チャットの行の隣に演出の名前を出す。書き出すログには本文だけを入れる（`ChatLogExporter`が`vnBodyOf`を通す）
- **SE再生** — 操作列の「SE再生」で、部屋のSE（`AudioTag`が`SE`の音）・同梱のプリセット・カットイン・BGMを検索して流す（`features/visual-novel/visual-novel-sound-board`）。カットインは「全員に流す」。SEは「次の発言と同時に再生」で次の行に付けられ、送ったときに鳴らす。卓を編集できる人だけが使える

## ログ

- **バックログ** — `L`かログのボタンで開くパネル（`features/visual-novel/visual-novel-backlog`）。台本で飛ばしたプレイヤーの雑談も含め、台本の元になる行をすべて並べる。検索・「自分のみ」・「演出付き」で絞り、「現在地へ」で読んでいる行へ移る。200件ずつ出し、「さらに {{count}} 件を読み込む」で増やす。行を選ぶとその行を読み、台本に無い行ならその前で台本にある行から読む
- **ログから編集** — 自分の行はログで本文・演出・その行だけの立ち位置（`ChatMessage.vnPortraitPos`）を直せる。本文か演出が変わったときは`ChatMessageService.editMessage`から`ChatMessage.edit`を通るので、チャットでの編集と同じく[編集履歴](chat.md#チャット)に残る。タッチ画面では行の右クリックメニュー（長押し）の「編集」から開く（`buildBacklogEntryContextMenu`）

## 背景と上映

- **舞台の状態** — 部屋に1つの`VnStage`（`@SyncObject('vn-stage')`、identifierも`VnStage`。`domain/visual-novel/vn-stage`）。起動時に作って全員に同期するが、部屋のデータ（`Room.innerXml`）には入れないので、保存した部屋には残らない。欄は`backgroundImageIdentifier`（既定`''`）・`transition`（`none` / `fade` / `wipe`、既定`fade`）・`transitionTrigger`（既定0）・`isDirected`（既定false）・`directorPeerId`・`playheadTabIdentifier`・`playheadIdentifier`（3つとも既定`''`）
- **背景と切り替え** — 進行パネルで、GMが背景の画像を選ぶ・外す、切り替え（切替なし / フェード / ワイプ）を選ぶ、切り替えだけを流す（`VisualNovelSceneService`）。背景を変えるときと切り替えを流すときは`transitionTrigger`を1増やすので、同じ切り替えを何度でも全員の画面で流せる
- **上映モード** — GMが「上映モード（全員の画面を同期）」を入れると、その席が進行役になり（`VisualNovelDirectorService.toggleDirecting`。ほかのGMの上映は引き継ぐ）、読んでいるタブと行を`setPlayhead`で書く。ほかの画面はその行へ飛んで追従する。追従する人が読めないタブには移らない。追従中に自分で進む・戻る・行へ飛ぶ・ログを開くと追従をやめ、「追従に戻る」で戻る。進行役がGMでなくなった上映は終わったものとして扱い、進行役がまたGMになってもひとりでに再開しないよう、それを見たGMか進行役本人（部屋のサーバーで見学になった場合を除く）が`stopDirecting`する（`VisualNovelEventHandlerService`）

## 表示設定とキー操作

- **表示設定** — 読む人ごとの設定で、localStorageの`vn-settings`に持ち、部屋には送らない（`features/visual-novel/visual-novel-settings.service`）。文字送り（なし / ゆっくり / ふつう / はやい。1字ごとに60 / 30 / 12ミリ秒、既定ふつう）・立ち絵の登場演出（なし / フェード / スライド / バウンド、既定スライド）・文字サイズ（小 / 中 / 大、既定中）・演出の強さ（ふつう / 控えめ、既定ふつう）・文字の読みやすさ（なし / 弱 / 中 / 強。画面全体を暗くしてぼかす強さ、既定なし）・表示レイアウト（吹き出し / ADV / 全画面、既定吹き出し）・プレイヤーの雑談（ノベルに出さない / そのまま読む、既定ノベルに出さない）。ほかに再生速度（0.5〜2、既定1）と読むタブも覚える。吹き出しのレイアウトでは話し手の立ち絵が舞台に無い行をADVの形で出す
- **キー操作** — Enter・Space・→・↓で進む（打ち途中なら全文を出す）、←・↑で戻る、Home・Endで最初と最新の行、Ctrlを押している間スキップ、`?`でキー操作の一覧、`L`でログ、`A`でオートプレイ、`S`で立ち位置ガイド、Escで開いている物を閉じ、何も開いていなければノベルモードを終える（`visual-novel-shortcut`の`visualNovelKeyDown`）。入力欄で打っている間・変換中・修飾キーとの組み合わせでは何もしない。メッセージの上でホイールを回すと、上で戻り下で進む（160ミリ秒に1回まで）

# 卓とテーブル

## テーブル表示（2D / 3D）

- **卓の描画** — 卓はthree.js（WebGPU、使えない端末ではWebGL2）で1枚のcanvasに描く。どちらも作れないブラウザでは、卓の場所に描けない理由と設定の場所を出す。名札やゲージのように文字や押し所の要る物は、canvasの上のDOMに置く（[設計](../architecture.md)の「卓の描き方」）
- **2Dトップダウンモード** — 真上視点表示。カメラ向きに応じたピースラベル（orbit-aware）と、2D時のピース回転ジェスチャ無効化
- **2D多方向閲覧** — 卓を四方から囲んで読めるよう、キャラクター名とバフ名を一文字ずつ円周に沿わせて時計回りに表示。短いラベルは4個、長さに応じて3～1個へ減らし、`◆`と余白で区切る。任意設定で最大4件のリソースを台座外周の円弧ゲージにし、バフアイコンも名前より少し遅い独立した外周へ配置できる。コマ画像と台座は別の速度で平面回転し、連続回転と90°ごとの間欠回転、各一周時間と静止時間を部屋設定のUIタブ（個人設定）で変更できる（[利用方法](multi-angle.md)）
- **方向別のコマ詳細** — 2D多方向閲覧中は、コマへマウスを乗せた位置を90°ごとの領域に分け、その側から読める向きで詳細を表示
- **卓上ディスプレイの設えは画面のもの** — 遠近の有無・1マスの実寸・メニューの出し方・多方向表示・コマ詳細・外周ティッカー・多方向カットイン・ウィンドウの回転ボタンは、その画面のlocalStorageが答える。**部屋へは配らない**（画面を囲むのはオフラインの卓であり、同じセッションに遠隔から入っている人の見え方を変えてはいけない）。まだ触っていない項目はいま出ているテーブルが答えるので、フォーク版で作った部屋の見え方は変わらない。GM権限は要らない（`domain/tabletop/tabletop-display`、`application/tabletop/tabletop-display.service`、`application/ui/tabletop-display-preference.service`）
- **実寸表示とビュー固定は保存しない** — 実寸表示とビュー固定の入り切りと、カードで測った画面の寸法はメモリにだけ持ち、ページを読み込み直すと消える。寸法を残さないのは、次に開いた画面が測った画面と同じかを見分けられないため。実寸表示とビュー固定はいまの画面の使い方を表す状態で、次のセッションの部屋に持ち越すと意味が通らない（`application/ui/display-calibration.service`、`application/ui/view-lock.service`）
- **推奨ビュー** — テーブルは3D / 2Dのどちらで読むのが良いかを示すだけで、強制しない。席の視点は自動・3D・2Dの三択で、自動のときだけ推奨ビューに従う（`domain/ui/view-mode`）
- **壁面サーフェス** — テーブルに北 / 東 / 南 / 西の壁を追加。各壁面にオブジェクトを配置でき、ドラッグまたはコンテキストメニューでサーフェス間を移動
- **重力** — 支えとなるオブジェクトが動くと、上に載ったオブジェクトが落下。混雑したテーブルでも重くならないよう購読をインデックス化
- **登れない地形（`blocksClimb`）** — 崖やガラスのように「向こう側へ行けない」地形。コマは天面に乗らず、ドラッグでは手前の面で止まる（止める領域は地形の箱そのもの。コマが自分のマスからはみ出す分だけ広げるので、1マスの隙間は1マスのコマが通れる）。移動範囲でも越えられないマスとして数える。開いた扉は通す。GMと、地形そのものを組んでいるときは対象外。右クリックメニュー・機能塗り・ダンジョン生成の「壁を登れなくする」から入れられる（`domain/tabletop/move/blocked-path`、`domain/tabletop/move/blocked-cells`）
- **ドラッグ中の高さ** — 掴んだコマは足場の高さに合わせて上下し、頭上に隙間のある地形の下はくぐれる。掴んだままホイールを回すと、その場所にある足場を上下に辿って乗り移る（1ノッチで1足場）。手を離したときのグリッドスナップも同じ判定を通す（`ui/directives/movable-helpers`）
- **ビルボード** — キャラクター / ダイスの画像をカメラ方向へ向ける（テーブル単位で切り替え可）。名前・所有者・バフラベルもカメラ追従
- **範囲（マーキー）選択** — 空のテーブル長押しで矩形選択
- **テーブル領域の拡大とズーム範囲の拡張**
- **重なったオブジェクトのコンテキストメニュー表示** — 同じ位置に重なった対象を選べる
- **奥のレイヤー（疑似3D）** — `TableBackgroundLayer`の「重ね位置」に、「背面」「前面」と並んで「奥（卓の後ろ・カメラに少しついてくる）」がある。奥のレイヤーは盤面ではなく卓の後ろの画面いっぱいに、横長の絵を横方向にだけ敷き詰める（縦にも並べると山並みが逆さに立つため、縦の速さは効かない）。絵の上下端15%はマスクで消す。カメラの回転・傾き・移動には「カメラへの反応」（`cameraFollow`、0〜1、既定0.3）の割合だけついてきて、反応が小さいほど遠く見える。何枚か重ねると奥行きが出る
- **奥のずらし量と描画** — 純関数`backdropOffset`（`domain/tabletop/backdrop-offset`）がずらし量を出す。横は卓1回転で絵1枚分回り、パンの1/4だけ引きずられる。縦は傾き50°を基準に上下し、400px×反応で頭打ちになる。横のずれは絵1枚の幅に畳むので継ぎ目が見えない。`BackdropFrameService`は、卓のカメラを書き出すのと同じフレーム（`GameTableGestureService`）で、登録された要素の`transform`だけを書く。値が同じなら書かず、変更検知も起こさない（`ui/directives/backdrop.directive`）
- **空のある卓の奥** — テーブル設定の「空」が「ゲーム内時間で移る空」の卓では、canvasの空がページ側の奥のレイヤーより手前に描かれる。そこで`BackdropRing`（`infrastructure/table-3d/backdrop-ring`）が、同じ絵を盤の中心を軸にした円筒に貼って立てる。円筒の半径は、「カメラへの反応」が1の絵で盤の対角の1.6倍、0の絵で8倍になり、反応の小さい絵ほど遠くに立つ。「高さ」は地平線から上の角度に置き換え、横の速さで輪に沿って流し、上下端15%を薄めて消す。空を描かない卓では輪を立てない
- **奥の保存互換** — `placement`は文字列で、未知の値は「背面」として読む。新規の`cameraFollow`と`backdropHeight`（「高さ」、画面下端からの割合、既定0）は、欄の無いデータでも空値を0ではなく既定値として読む（0は「動かない」「下端」という意味を持つため）。レイヤーの上限6枚には奥も含まれる。テーブル設定では奥を先頭に並べ、並べ替えは奥どうしの間だけで行う
- **前景** — テーブル設定の「前景」は、盤面とコマの上、画面の手前に重ねる1枚の絵。`GameTable`の`foregroundImageIdentifier`・`foregroundOpacity`（既定1）・`foregroundFit`（既定`''`）に持ち、`tableForegroundOf`（`domain/tabletop/table-foreground`）を通して読む。欄を知らない古いピアは不透明度を送らないので、空の不透明度は0ではなく1として読む。合わせ方は`cover`・`contain`・`fill`で、それ以外の値は`cover`として読む。`TableForegroundOverlayComponent`（`features/tabletop/table-foreground-overlay`）が画面全体に`pointer-events: none`で重ねるので、クリックは下のコマや盤面に届く。重ね順を持たないので、パネルより手前には出ない。GMは「自分の画面では薄く見る（GMだけ）」で、自分の画面だけ不透明度を0.25倍にできる。この選択はlocalStorage（`axe.foreground.seeThrough`）に残り、PLの画面は変わらない（`application/ui/foreground-see-through.service`）。欄名が`ImageIdentifier`で終わるので、部屋の保存zipに画像も入る
- **方位磁石** — FABの「ウィジェット」から出すウィジェット（`features/widgets/compass`）。文字盤を卓の水平回転（`UiSignalService.tableViewRotationZ`）に合わせて回し、画面の上が向く方位を度数と8方位で出す。描く角度は`nearestTurnTo`（`domain/ui/compass`）で前回の角度に最も近い値へ書き直す（0〜360°に収めると、北を跨ぐたびに針が逆回りに一周するため）。表示の有無はlocalStorage（`ui-widgets`）に残り、位置はドラッグで動かせる。文字盤の絵柄は右クリック / 長押しで「現代風」「ファンタジー風」「SF 風」から選び、好みの問題なので部屋へは配らず、localStorage（`axe.compass.face`）に置く（`application/ui/compass-face.service`）
- **磁場異常** — テーブル設定の「磁場異常（方位磁石が狂う）」（`GameTable.magneticAnomaly`、SyncVar、既定`false`）。部屋の決めごとではなくテーブル単位にしたのは、磁鉄鉱の洞窟のような1室だけに掛け、そこを出れば方位が戻るようにするため。有効な卓では`swingNeedle`が向きではなく回転速度を揺らすので、針は行き過ぎては戻る。度数表示は「磁場異常」に替わる。ウィジェットを隠しているときと、演出をオフにしているとき（`MotionService`）は揺らさない
- **GPUを使わないブラウザへの案内** — ブラウザがGPUを使わずに描いているとき（WebGLは作れるが`failIfMajorPerformanceCaveat`付きでは作れない、または描画装置の名前がソフトウェアのラスタライザ）は、起動のたびにグラフィックアクセラレーションを有効にするよう強く勧める小窓を出す（`features/gpu-notice`、判定は`core/util/graphics-acceleration`）。案内に出す設定の場所は Chrome・Edge・Firefoxを見分けて変える。見た目は何も変えない。GPUなしのChromeでは、暗闇の卓の松明の揺らぎだけで止まっていても1fps前後になる（GPUありは60fps）。自動操作のブラウザ（`navigator.webdriver`）には出さない（E2Eのブラウザはソフトウェアで描くため）

## ヘクスグリッド対応

- ヘクスサーフェス、ヘクス形状の台座（pedestal）と範囲セル
- ヘクスマップ外周境界、マップマスクのヘクスグリッド削り出し、暗闇オーバーレイのヘクス外形追従
- 地形（terrain）のヘクスマップ対応とヘクス角柱の壁レンダリング

## スナップ / グリッド

- **スナップの種類** — テーブル設定の「スナップ」は「なし」「セル」「交差点」「セル＋交差点」「セル＋交差点＋辺」「グリッド」から選ぶ。「なし」は`gridSnap`を切り、ほかは`gridSnapStyle`（`GridSnapStyle`の`CENTER`・`VERTEX`・`BOTH`・`ALL`・`GRID`）に書く。「セル＋交差点＋辺」は四角の卓で辺の中点にも吸い付く。「グリッド」は「セル」と同じく1マスずつに吸い付き、「移動と射程の1マス」を2×2以上にした卓でも、コマをまとめたマスの真ん中へ寄せず、置いたマスに止める（`keepsPiecesOnCells`、`domain/tabletop/grid-snap-style`）。スナップUIを集約
- グリッド表示・スナップをテーブル単位のSyncVar化（P2P同期）
- グリッドのフォントカラー設定

## 複数選択・一括操作

- `Ctrl + クリック`での選択トグルと一括操作（バッチ）メニュー
- 選択した複数オブジェクトのグループドラッグ
- 一括移動・複製など
- **選んだコマへのキー** — `T`で選んだキャラクターだけをターゲットにし（`PieceTargetService.setOnly`）、`Shift+T`で全部外す。`G`は選んだキャラクター・カード・ダイス・共有メモのうち`DisclosureService.canEdit`が通るものの公開範囲を切り替える。1つでも全員以外があれば全員に、全部が全員ならGMのみに戻し、特定PLには行かない（`switchedDisclosureMode`）。判定は純関数`tabletopKeyDown`、受けは`features/keyboard/tabletop-shortcut-event-handler.service`。入力中・IME変換中・修飾キー併用・フォーカスがbody以外のとき、ノベルモード・モバイル・配信オーバーレイ・ダンジョンドリィマスターモード・リプレイの盤面再生のあいだは受けない。ターゲットそのものの持ち方と外れ方は[行動順・ターゲット・バフ](turn-order.md#ターゲットと目標値)にある

## 回転の枠

- **回転の枠** — ダイス・共有メモ・地形・ホワイトボードは、足元の18px外側に、床と平行な角丸の枠を出す（`TurnFrameComponent`、`ui/tabletop/turn-frame`。形は`domain/tabletop/turn-frame`の`turnFrame`）。四隅に28pxのつまみがあり、前の辺の中央の印が物の向きを示す。枠の線とつまみはどれも`appRotable`の`.rotate-grab`なので、どこを押しても回せる。物の手前に来る部分は描かず、枠は物の後ろを回る。ホワイトボードだけは、傾けた板が足元の奥を隠しても四隅のつまみを描く。固定した物には枠を出さず、ダイスには2D表示のときも出さない
- **枠の出る時** — ホバーできる端末では、ポインタが物に乗っている間と、離れてから600ms（`HOVER_GRACE_MS`）出す。600msは、物の天面から側面を越えて足元の枠までポインタを運ぶ間の猶予。ホバーできない端末では、最後に単独で押した物に出す。回している間はどちらでも出し、押して持っている間は枠を残したまま描かない
- **コマの輪と傾けるつまみ** — キャラクターは、台座を囲む輪（`turn-ring`）と向いている側のつまみで向きを変え、立ち絵の右のつまみで前後に傾ける。傾けるつまみはダブルクリックで`roll`を0に戻す。出方は回転の枠と同じで、タッチでは最後に押したコマに出す。輪は2D表示では出さないが、部屋設定の「キャラクターの向き」が「示さない」以外なら出す。傾けるつまみは2D表示では出さない。固定したコマと、卓を編集できない席には、どちらも出さない（`features/character/game-character`）
- **Altで刻む** — Altを押しながら回すと、四角とグリッドなしの卓では45°、ヘクスの卓では30°ずつ回る（`rotationSnapStep`、`domain/tabletop/rotation-snap`）。任意マスの射程は、どの卓でも90°ずつ回る

## 最初の卓

- **チュートリアルボード** — 新しい部屋の最初のテーブル（`gameTable`、32×20マス）の北端の外に、32×15マスのホワイトボード「はじめに」を立てる（`application/tabletop/tutorial-board`）。卓を真上から見る席では、立てずに北側へ寝かせる。ボードは固定してあり、卓を動かすつもりのドラッグでは動かない。書く内容は、上段の「Udonarium Axeへようこそ」と、その下に並ぶ「① コマ」「② チャットとダイス」「③ 戦闘」「④ 暗闇と地形（GM向け）」の欄で、表示中の言語で書く。ボードの絵はマップエディターのシーンと描画で作るので、書く部分（`tutorial-board-faces`）は遅延で読み込む。ボードの手前には、書き換えを試す共有メモ、D4・D6・D8・D20のダイス、コイン、木箱の地形、明かりを並べる
- **サンプルのコマ** — 新しい部屋はサンプルのコマを並べて始まる（`makeDefaultTabletopObjects`、`application/tabletop/tabletop-default-setup`）。同梱の3Dモデルを持つ9体を各列の西に、絵で描くコマを東に並べ、モンスターの列は地面を盛った段に立てる。PCはパーティ`testParty_1`に入れて視界を共有し、モンスターは別のパーティ`testParty_2`に入れる。2マス以上のモンスターは、交戦エリアで数える「人数」の欄を持つ。サンプルのコマ・パーティ・チュートリアルの物はどの席でも同じ識別子で作るので、最初の卓を持った2人が出会っても卓に出るのは1組だけ
- **最初の視点** — 最初のテーブルの視点は、盤の四隅とチュートリアルボードの四隅が画面に収まるまで、ズームの限界まで引く（`firstViewPoints`・`firstTableView`、`features/tabletop/game-table/first-table-view`）。元の視点より寄ることはない。パネルを卓の横に開く画面で、接続パネルの右に画面幅の半分以上が空くときは、その空きに収める
- **片付け** — チュートリアルボードと共有メモの右クリックメニューに、「チュートリアルだけを片付ける」と「片付けて白紙のテーブルにする」を出す（`features/tabletop/tutorial/put-away-tutorial`）。前者はボード・メモ・ダイス・コイン・木箱・明かりを消し、サンプルのコマは残す。ボードに載せた物は、見た目の位置のまま卓へ戻す。後者はさらにサンプルのコマと2つのパーティを消し、地面の起伏と塗りを平らに戻し、テーブルの画像を外してグリッドを表示する。あとから置いたコマは残る
- **開始時の部屋** — 「セーブ&ロード」の「この部屋を開始時の部屋にする」は、いまの部屋全体を、このブラウザにある画像と音ごと保存データにまとめ、IndexedDB（`axe-start-room`）に残す。次からこのブラウザは、サンプルの代わりにその部屋で始まる。「開始時の部屋を元に戻す」で消すと、サンプルの部屋に戻る（`application/file/start-room.service`）。開始時の部屋を出すのは、ほかに誰もいない間だけ。ほかの人の部屋に入る前に、開始時の部屋と、サンプルのコマ・パーティ・チュートリアル・最初の2つのチャットタブをこの画面から外す。外さずに入ると、それらを削除した記録のない部屋に紛れ込むためである。外すときに削除の記録は残さないので、それらを持つ部屋からは戻ってくる。席に付く物（`SEAT_OWN`の`PeerCursor`・`hotbar`・`hotbar-slot`）は外さない。部屋に入れなかったときは、開始時の部屋を読み込み直す。入室の最中と、部屋のサーバーで伏せた形のまま受け取った物がある卓は、開始時の部屋にできない

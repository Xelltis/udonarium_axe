# 一人称と三人称

## 一人称（ダンジョンドリィマスターモード）

- **卓の代わりに出す景色** — キャラクターコマ1体の目から見た景色を、卓の代わりに画面いっぱいに出す（`features/first-person/first-person-view`）。出しているあいだは卓の層（`#app-table-layer`）を隠し、卓のcanvasを`Table3dService.lend()`で借りて、`TableEyeService`に渡した目のカメラから同じ場面を描く。見ているコマ自身は描かない。ほかのコマの名前・リソースバー・バフは、DOMで絵の上に重ねる。ビューは`@defer`で遅延して読み込む
- **見るコマの決め方** — 純関数`firstPersonTarget`（`domain/tabletop/first-person/first-person-target`）が、GMの共有視点が効いていればそのコマを、なければこの画面で選んだコマを返す。選んだコマはlocalStorageの`ui-first-person-piece`に置く（`application/ui/first-person-preference.service`）ので、ページを読み込み直してもモードが続く。見られるのは卓の床に立つキャラクターコマで、グリッドのある卓ではマスの上にいることも要る（`FirstPersonService`の`pieceOn`）。コマが卓を離れると卓の表示に戻る。選んだコマは覚えたままなので、コマが卓に戻れば視点も戻る
- **入り方** — FABの「テーブル関連」（メニューコマンド`firstPersonView`）、PLツールバー（`firstPerson`）、コマの右クリックの「このコマの視点で見る」、ホットバーの枠（[ホットバー](pl-tools.md#ホットバー)）から入る。FABとPLツールバーの候補は`firstPersonSeats`（`domain/tabletop/first-person/first-person-seats`）が絞る。候補になるのは、自分で動かせるコマ（自分のコマと持ち主のいないコマ）と、`Party.players`に自分の名前があるパーティのコマ（[パーティのプレイヤー](movement.md#同行パーティ)）。右クリックの項目は、見られる状態のコマなら持ち主に関係なく出る
- **向きの刻み** — `latticeOf`（`domain/tabletop/first-person/first-person-lattice`）が、卓のマスの形から向きの数を決める。四角は4方向（90°）、ヘクスは6方向（60°。頂点が上のヘクスは30°から数える）、グリッドなしは8方向（45°）。コマの`rotate`をこの刻みに丸めて読み、向きを変えると刻み1つ分を`rotate`に書く
- **キー** — W/S・↑↓で前後に歩き、Q/E・←→で向きを変える。四角とグリッドなしの卓ではA/Dで横へ歩き、ヘクスの卓ではA/Dで斜め前、Z/Cで斜め後ろへ歩く。Spaceで扉、Fで明かり、Tでターゲット、Shift+Tで全部外す（純関数`firstPersonKeyDown`、`features/first-person/first-person-keys`）。入力中・IME変換中・修飾キーの併用中と、モーダル・ノベルモード・移動の計画のあいだは受けない
- **1歩** — グリッドのある卓では、`MoveRangeService.canStepTo`が通した隣のマスへ`PieceStepService.step`で動かすので、卓でコマを動かすときと同じ判定を通る（[移動範囲](movement.md#移動範囲)）。グリッドのない卓では、向いた方へ1マスの長さだけ先の点へ動かす。純関数`freeStepClear`（`domain/tabletop/first-person/free-step`）は、卓の外へ出る歩き、移動を遮る地形の辺をまたぐ歩きと地形の中へ入る歩き、地面の起伏を1マスより大きく上り下りする歩き、見えているコマに半マスより近づく歩きを止める。部屋設定でコマが同じマスに入れるときは、コマでは止めない。暗闇や霧で見えないコマで止めないのは、止まったことで見えないコマの居場所が分かってしまうため。歩けたら`piecePut`、止まったら`blockPut`の効果音を鳴らす
- **一緒に動く物と続けて押したキー** — 歩いたあとは`PieceLinksService.carryBound`で、部位・乗り手・つかんでいるコマを同じ所へ運ぶ。1歩を動かしている途中に押した操作は、最後の1つだけを次に回す
- **歩かせられる人** — `FirstPersonService.mayWalk`が決める。見学の席は歩かせられない。固定したコマと、移動の計画中、リプレイを開いているあいだ（`ReplayPlaybackService.isOpen`）も歩かせない。部位のコマは本体と一緒に動くので、部位からは歩かせない。GMはどのコマも歩かせられ、ほかの席は`isControllableByUser`が通るコマ（自分のコマと持ち主のいないコマ）を歩かせる。扉と明かりも、歩かせられる席だけが操作できる
- **目と見える範囲** — 目は立つ点（グリッドのある卓ではマスの中心、ない卓ではコマの中心）から向きの逆へ0.3マス下がった所、コマの立つ高さから0.8マス上に置く（`FIRST_PERSON_EYE_BACK`・`FIRST_PERSON_EYE_HEIGHT_CELLS`）。横の視野は90°（`FIRST_PERSON_FOV_DEG`）。描くのは12マス先まで（`FIRST_PERSON_DEPTH_CELLS`）で、6マス（`FIRST_PERSON_CLEAR_CELLS`）より先は遠いほどぼかす。視線の通るマスは`computeVisibleCellsFor`で目の高さから求め、視野に40°の余りを足して数える。マスの中心が壁の角に隠れていても、四隅から中心へ1割入った点のどれかが見えればそのマスを描く（`cornerInset`）。中心が見えないだけで、壁の角が半分隠したマスを黒く残さないため
- **暗闇と霧** — GMには明かりに関係なく、壁で遮られない範囲を見せる。PLの席は、目から視線の通るマスのうち、卓がその席に見せているマス（`VisionService.overlayVision`の`visible`）だけを描く。通った所を霧が覚える卓では、覚えているだけのマスも、目の届く所なら描く範囲（`seen`）に入れる。コマの視界の距離は、暗闇のある卓でだけ効く
- **天井** — `firstPersonRoofOf`（`domain/tabletop/first-person/first-person-roof`）が、床の壁と扉の地形に囲まれ、卓の端から壁を越えずにはたどり着けないマスに天井を張る。扉は開いていても壁に数える。高さは卓でいちばん高い地形の壁に合わせる。天井は目に見えるものではなく卓の形から求めるので、野外で塔の方を向いても野原に天井は掛からず、向きを変えても天井は上下しない。壁より背の高いコマがいる部屋は、その部屋の天井だけをコマの頭より0.5マス上まで上げる（`roofRaisedFor`）。上げるのはその席に見えているコマのためだけで、見えないコマで上げると居場所が分かってしまう
- **ミニマップ** — 目の周り5マス（`MINIMAP_RADIUS_CELLS`、`domain/tabletop/first-person/minimap-view`）を、床・壁・立入禁止・閉じた扉・開いた扉に塗り分けて描く（`infrastructure/first-person/minimap-painter`）。PLには、見えているマスと霧が覚えているマスだけを出す。壁・立入禁止・扉の形は、地形か卓が変わったときだけ求め直し、歩くたびには求めない
- **扉・明かり・ターゲット** — Spaceは目の前のマス（グリッドなしの卓では0.5マス先と1マス先）の扉を開け閉めし、そこに扉がなければ足元の扉を開け閉めする。Fはコマの`lightEnabled`を切り替え、明るさの半径を持たないコマに点けるときは光源のプリセット「たいまつ」を入れる（`toggleTorch`）。Tは、正面から20°以内で目から視線の通るコマのうち、最も正面に近いコマのターゲットを切り替える。ターゲットは卓と同じ`PieceTargetService`が持つ

## 共有視点（全員の視点）

- **全員を1体の視点に入れる** — GMは、テーブルの`GameTable.sharedViewPiece`（SyncVar、既定`''`）にコマの識別子を書き、GM以外の全員（見学を含む）をそのコマの視点に入れる。書くのは`FirstPersonService.share`で、GMの席でなければ何もしない。GMツールバーの「全員の視点を決める」（メニューコマンド`firstPersonShare`）か、コマの右クリックの「全員をこのコマの視点にする」で共有を始める。共有中のコマが卓にいないあいだ、GMツールバーのボタンは「共有中のコマが卓にいません（押すと解除）」になり、押すと解除する
- **共有中の画面** — 共有中のPLは、Escでも抜けられない（`firstPersonKeyDown`の`forced`）。卓に戻るボタンの代わりに「GM の共有視点」の札を出す。描くのは、席の視界と重ねずに、そのコマから見える範囲そのまま（`litCells`）。そのコマに自分の目を持たない席は、重ねると暗闇に閉じ込められるため
- **共有中に歩かせられる人** — GMと、コマの持ち主と、`Party.players`でそのコマのパーティに名前がある人。持ち主のいないコマは、パーティにプレイヤーの名前がなければGMだけが歩かせる。GMが全員の前に出したコマとして扱うため
- **効くのはGMが部屋にいるあいだだけ** — `firstPersonTarget`は、部屋のカーソルのどれかがGMのとき（`gmPresent`）だけ共有視点を選ぶ。共有中のPLは自分では抜けられないので、GMのいない部屋に閉じ込めないため。GM自身は共有視点に入らず、自分で選んだコマか卓を見る。共有するコマが卓を離れると、PLは自分で選んでいたコマか卓に戻り、コマが卓に戻れば共有視点に戻る
- **保存には残さない** — `GameTable.toAttributes()`が`sharedViewPiece`を外して書き、`parseAttributes()`は保存に何が書いてあっても`''`に戻す。共有はGMがその場にいるあいだの操作なので、ファイルから開いた部屋が、全員をコマの視点に閉じ込めた状態で始まらないようにするため

## 見回す

- **画面だけの向き** — 景色をドラッグすると、ドラッグした方へカメラを回して傾ける（`FirstPersonLookService`、`features/first-person/first-person-look.service`）。コマの`rotate`は変えず、部屋にも配らず、どこにも残さない。8px（`LOOK_DRAG_THRESHOLD_PX`）より短い押下はクリックとして扱うので、コマを押してターゲットにする操作はそのまま使える。ボタンや入力欄の上の押下は見回しにしない
- **向ける範囲と戻り方** — 左右は制限なく回し、上下は±85°まで（`LOOK_PITCH_LIMIT_DEG`、`domain/tabletop/first-person/first-person-look`）。手を離しても向いた方に留まるので、何かを見たまま手をチャットへ移せる。コマが歩くか向きを変えると、ドラッグ中でなければ240ms（`LOOK_RETURN_MS`）かけて正面・水平へ戻り、Escでも戻る。演出を止めているとき（`MotionService`）はすぐ戻す。別のコマから見始めると正面・水平から始める
- **見回し中の視線** — 見回しているあいだは、目からの視線を360°で求める（`FirstPersonService.lookAround`）。どちらを向いても描く範囲が欠けないようにするため。求めるのは見回しを始めたときと終えたときの1回ずつで、見回しの動きごとには求めない

## 三人称（後ろから追う）

- **卓のカメラで追う** — コマの右クリックの「このコマを後ろから追う」で、卓のカメラをコマの肩越しに置き、コマが歩いても向きを変えても後ろから追わせる（`ThirdPersonService`、`application/tabletop/third-person.service`）。一人称と違って卓の画面のまま描くので、コマも頭上の表示も押した所の判定も、卓のものがそのまま使える。カメラの値は`thirdPersonCameraView`（`domain/tabletop/camera/third-person-camera`）が卓のカメラの形で出し、`GameTableGestureService`は追っているあいだ卓自身の視点の代わりにそれを使う。卓自身の視点は別に持っているので、「後ろから追うのをやめる」で元の視点に戻る
- **カメラの位置** — 既定はコマの真後ろから25°見下ろし、4マス離れた所（`DEFAULT_THIRD_PERSON_ORBIT`）。ドラッグでコマの周りを回り込み、見下ろす角度を-10°〜80°のあいだで変える。ホイールで1.5〜12マスのあいだを寄ったり離れたりする。縦の視野は60°（`THIRD_PERSON_FOV_DEG`）。カメラが向く点はコマの中心で、足元から0.8マス上。足元の高さは`StandingGroundService`の面（氷の上を含む）から読む
- **カメラを物に埋めない** — コマからカメラへの線に地形や物が当たれば、当たった所の0.25マス手前まで寄せる（`TablePickService`の当たり判定）。地面の起伏は0.5マスおきに調べ、地面から0.25マス上より下へは潜らせない。一人称の天井の下に立つコマでは、カメラを天井の0.25マス下に収め、天井をカメラの上に描く。どの場合も0.5マスより近くには寄せない。カメラが1.5マスより近づいたら、コマを透かして描く
- **動きと操作** — コマが3マス以内で動いたときは160msかけてカメラを滑らせ、それより遠い移動と、演出を止めているときは一度に移す。歩く・向きを変えるキーは一人称と同じで、`FirstPersonService.walkPiece`・`turnPiece`を通るので、歩かせられる人の決まりも一人称と同じ（`features/first-person/third-person-hud`）。Escで追うのをやめる。追っているあいだは、キーボードでの卓の操作と範囲選択を受けない
- **追うコマの持ち方** — 追うコマはlocalStorageの`axe.table.follow`に置き、部屋には配らない。追えるのは一人称で見られるコマと同じ条件（`canLookOutOf`）を満たすコマで、一人称で見ているあいだは追わない

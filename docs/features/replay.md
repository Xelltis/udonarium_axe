# セッションログと配信

## セッションログ（リプレイ基盤）

- **記録の始め方** — 画面右上のピルを開いて「記録を始める」を押すと始まる。見学の席は始められず、記録の盤面を出している間も始められない。記録の細かさ（チャットのみ / 標準 / すべて）と残す本数はこのブラウザに覚えさせ、次の卓へ持ち越す（`application/replay/replay-preference.service`、`features/replay/replay-indicator`）
- **部屋は要らない** — 同期メッセージは接続の有無に関わらず自分へも返るため、ひとりで開いた卓もそのまま記録できる。録画は始めた部屋に紐づき、部屋を出入りして部屋名が変わったところで止める（`features/replay/replay-event-handler.service`。一覧では部屋名なしの記録を「ひとりの卓」として示す）
- **記録の作り方** — `networkMessage$`を購読し、自分と他人の操作を同じ経路で拾う。`UPDATE_GAME_OBJECT`はオブジェクト全体が飛ぶため、シャドウコピーとの差分から「移動」「リソース増減」等の意味を起こす（`domain/replay/replay-diff`、`domain/replay/replay-interpreter`）
- **記録される3層** — 読むための意味づけ済みイベント、巻き戻しと再生のための前後差分パッチ、復元の起点となるキーフレーム（画像・音声を含まないmsgpackのオブジェクト一覧。識別子を保つのでpatchが当たる）
- **初期同期の除外** — 開始時に現在の盤面をシャドウとして取り込み、同期由来の同値更新を差分ゼロで落とす。加えて開始直後5秒は未知オブジェクトを到着した状態として扱う
- **畳み込み** — ドラッグ中の毎フレーム更新を、同一の人・同一のコマ・1.5秒以内で1件にまとめ、始点と終点を残す（`domain/replay/replay-coalescer`）
- **秘匿の保存** — 内緒話・GM限定・非公開コマを当時の可視性ごと記録し、閲覧者のロールで絞り込む
- **保存** — イベントはmsgpackでチャンク化してIndexedDBへ。**既定では古い録画を消さない**（`DEFAULT_REPLAY_RETENTION`は本数・容量とも上限なし）。残す本数は録画ピルで選べ、選ばなければ消えない。開始時に`navigator.storage.persist()`で保持を頼み、空きが減ったときに録画ごと消される既定の扱いから外す（`core/storage/replay-log-store`、`core/storage/persistent-storage`）
- **録画インジケータ** — 画面右上のピル。記録中は経過時間を出し、開くと件数と、章の見出し（目印）の入力と、停止のボタンが出る。待機中は「記録なし」と出し、開くと開始のボタンが出る。細かさと残す本数はどちらのときも選べる（`features/replay/replay-indicator`）
- **卓を邪魔しない工夫** — シャドウ複写は素の再帰コピー（`structuredClone`の約4倍速）、表示用シグナルはドラッグ中250msに間引き、10分ごとのキーフレームはidleかつ非ドラッグまで待つ
- **持ち出し** — `.axe-replay.zip`（目録JSON + イベントmsgpack + キーフレーム + 任意で画像）で書き出し / 読み込み（`domain/replay/replay-archive`、`application/replay/replay-library.service`）
- **再生** — 読み物として送るだけなら卓に触れない。盤面再生は直近キーフレームを復元してpatchを前向きに積む（巻き戻しも作り直し）。再生中は`setNetworkIsolated()`で送信を止めて同卓者に漏らさず、抜けるときに元の卓へ戻して再同期を求める（`core/network/network-isolation`、`application/replay/replay-playback.service`）
- **ワークスペース** — 記録一覧・舞台・項目一覧を1枚のパネルに収め、選ぶところから編集して保存するまでを行き来なしで済ませる（`features/replay/replay-workspace`）
- **タイムライン** — 目盛りは経過時間。各時点のできごとの多さを山として描き、通り過ぎた分を色で示す。目印は章のしおりとして並び、押せばその1件へ飛ぶ（`features/replay/replay-timeline`）
- **非破壊編集** — 削除・並べ替え（つまんで移動、または矢印で1つずつ）・台詞の直し・任意のイベントの差し込みを行い、別の記録として保存する。移した項目は移した先の時刻を引き継ぐ。Ctrl+Zで1手ずつ戻せる。派生先には編集後の並びで計算し直したキーフレームを書く（`domain/replay/replay-edit`、`features/replay/replay-editor.service`）
- **捏造の収録** — 手で打つ代わりに、盤面を預かった状態で実際に操作し、その結果をイベントとして任意の位置へ差し込む（`application/replay/replay-staging.service`、`features/replay/replay-staging-banner`）
- **MP4書き出し** — 記録を動画の時間割に組み、1コマずつcanvasに描いてWebCodecsで符号化する。時間割は発言・ダイス・章・告知・カットインの場面を順に並べ、発言の合間に盤面で起きたことを1つの場面にまとめて挟む。編集中なら編集後の並びから組む。**長さで打ち切らない**。記録した分は最後まで書き出す。書き出す前に、場面の数と長さとファイルの大きさの見込みをパネルに出す（`domain/replay/video/replay-video-timeline`、`application/replay/replay-video-production`、`features/replay/replay-video-panel`）
- **選べる項目** — 見せ方（ノベル / 卓）、見せる相手、言語、大きさ（720p / 1080p / 1440p / 2160p）、なめらかさ（30 / 60fps）、間の取り方（読める速さ / 当日と同じ間）、字幕の速さ（4段階）、冒頭に部屋の名前と日付を出すか、効果音、BGMと環境音を選べる。既定はノベル・公開用・画面の言語・1080p・60fps・読める速さで、字幕の速さは「ふつう」、冒頭と音はすべて入れる。プレビューと書き出しは同じ選択を使い、同じ描画処理（`infrastructure/replay/video/replay-video-renderer`）で描くので、プレビューで見た動画がそのまま書き出される（`features/replay/replay-video-settings.service`、`features/replay/replay-video-preview`）
- **見せ方** — 「ノベル」は画面の下に幅の広い枠を置いて1ページ3行で字幕を組み、話し手の名札を枠の上の縁に載せ、立ち絵を枠の後ろに立てる。立ち絵の並びはVNモードと同じ`buildVnStage`で決める。発言の場面では盤面を暗くし、VNの場面転換で背景の絵が決まっていれば盤面の代わりにその絵を敷く。「卓」は盤面を覆わないように、映画の字幕のような1ページ2行の字幕を画面の下寄りに組み、話し手の顔を横に添える。どちらも1920×1080を基準に組んで大きさに合わせて拡大する（`domain/replay/video/replay-video-layout`）
- **字幕** — 枠の幅で折り返してページに分け、収まらない分は打ち切らずに次のページへ送る。日本語は禁則を守ってどの字の間でも折り、英字とハングルは単語を割らない。1ページを出す長さは、0.8秒に言語ごとの読む速さ（1秒に日本語7字・韓国語9字・英語15字）で読み切る時間を足したもので、1.8秒から9秒の間に収める。字幕の速さはこの読む速さに掛ける（`domain/replay/video/replay-text-layout`）
- **見せる相手** — 「公開用」は見学者のロールで、「自分」は自分のユーザーIDとPLのロールで、「GM」はGMのロールで、出来事と盤面と暗闇を絞る（`replayVideoViewer`、`application/replay/replay-video-studio.service`）。「公開用」以外を選ぶと、公開していない情報が映る旨をパネルに出す
- **場面** — 発言（台詞・地の文・場所）、ダイス、章、告知、カットイン、盤面の動きの6種類（`ReplayVideoSegment`）。目印は章の扉になり、冒頭の部屋名と日付も同じ扉で出す。ラウンドと手番の移り変わり、テーブルの切り替えは告知の帯で出す。効果音、部屋の運営に当たる出来事、盤面を組み直すためだけの出来事（コマと一緒に届く部位など）は場面にしないが、盤面の状態には入る
- **ダイスの場面** — 結果の行の直前に、同じ人が同じタブで5秒以内に打ったコマンドの行があれば、2つを1つの場面にし、コマンドのあとに書いた文を振りの説明として添える。途中の式と結果を並べ、結果はクリティカル・成功・失敗・ファンブルで色を変える
- **盤面の動き** — 発言の合間に盤面で起きたことは、1つの場面の中で1件ずつ少し（最大180ms）ずらして動かす。1つの場面にまとめるのは16件までで、当日20秒を超えて何も起きなかった所でも分ける。場面の長さは0.9秒から4.5秒。置く・しまう・取り除くはフェードで出入りさせ、ダイスの振りと山札のシャッフルは揺らし、裏返すときは幅を細めて途中で面を替え、回転は回して見せる。値の変化は増減を大きく、変わったあとの値を小さく、そのコマの上に浮かべる。エフェクトは使ったコマから対象のコマへ光の線を伸ばす（`domain/replay/video/replay-board-motion`）
- **コマの滑走** — 移動では記録したfrom / to（畳んだ移動は途中の道のりも）を経路として、道のりに応じた0.5秒から1.3秒でeaseで滑らせる。滑り終わりは記録された置き場所にぴったり重なる（`domain/replay/replay-route`を再生と共有）
- **カメラ** — 場面ごとに映す範囲をコマの位置から決める（`domain/replay/video/replay-video-camera`）。盤面の動きの場面は、動いたコマ・値が変わったコマ・エフェクトの両端のコマと、移動の始点を余白3マスで寄せて映す（`action`）。発言・ダイス・手番の告知のように映すコマが決まった場面は、そのコマを余白4マスで映す（`speaker`）。それ以外は卓のコマ全部を余白2マスで映す（`wide`）。映す幅は`action`で12マス、ほかは16マスより狭めない。映すコマが卓に無ければコマ全部を、コマが1つも無ければ卓全体を映す。範囲は画面の縦横比に合わせて広げ、卓が範囲より広ければ卓の外を映さない。場面が変わると1.1秒かけて次の範囲へ動く。中心は等速で、大きさは比で変えるので、寄るときも引くときも同じ速さに見える。話しているコマの足元には話し手の色の輪を出す
- **動画に映る盤面** — 記録で最初の出来事より前にあるキーフレームを起点に出来事を積んで、場面ごとにその時点の卓を組み直す（`domain/replay/replay-board-view`）。組み直した盤面は400件ごとの区切りと直近の数枚だけを持ち、近い区切りから積み直すので、長い記録でも手元に持つ盤面は少ない。卓は真上から描き、卓の絵・マス目・コマの絵と名前・大きさ（マス数）・重なり順を持つ。卓に出ていないコマと、見せる相手に見えないコマは描かない。ほかの人が隠して振ったダイスは目を伏せる。地形のブロックだけは、卓を傾けて見たときのように高さに応じて天面を上へずらし、手前の側面を描く（`infrastructure/replay/video/replay-board-painter`）
- **当日と同じ間** — 各場面を、読める速さで決まる長さを下限に、次の出来事までの当日の間だけ出す。ただし何も起きなかった間は8秒（`REPLAY_QUIET_CAP_MS`）で切る
- **付随する音** — 効果音は移動や判定に付いて鳴るだけで、それ自体は出来事ではない。だから音としては残すが、記録一覧には既定では出さず（一覧の「付随する音も出す」で編集用に出せる）、動画でも場面にせず、読み物にも書かない（`isIncidentalReplayEvent`）
- **動画に入る音** — 効果音は鳴った出来事の時刻に置く。ダイスを振ってから3秒以内に鳴った音は、その振りの場面の頭に置く。盤面の動きの場面の中で鳴った音は、その直前に動き始めた変化の時刻に置く。BGMは鳴り始めから止まる（または曲が変わる）までを区間として置き、区間ぶんループしてフェードで出入りする。環境音は鳴り始めから止まるまでを、鳴らしたときの音量で重ねる。これらを`OfflineAudioContext`で数秒ずつ混ぜてリミッターに通すので、長い動画でも混ぜた音を一度に全部は持たない。混ぜられなかったときは、無音の動画にせず書き出しを止める（`domain/replay/replay-soundtrack`、`application/replay/replay-sound-mixer`）
- **読み物書き出し** — 記録をMarkdown（小説 / 台本）で書き出す（`domain/replay/replay-script`、`features/replay/replay-script-panel`）。絵コンテ（`buildReplayStoryboard`、`domain/replay/replay-storyboard`）で目印を章に、発言を1カットずつに起こしてから書く。長い発言は絵コンテが90字ずつのカットに割るので、同じ`seq`を持つカットだけ1つの発言へ戻す（話者で繋ぐと、続けて喋った別の発言まで繋がる）。見えるものは書き出す人のロールで決まる（`canViewReplayEvent`）。盤面の動きは既定で入れない。入れると読み物が操作ログになる
- **書体** — 動画の文字は同梱のNoto Sans JPとNoto Sans KR（`Axe Replay JP` / `Axe Replay KR`の名で登録）で組むので、端末の書体で字幅が変わらない。初めてプレビューか書き出しをするときに読み込み、読めなければ端末の書体で組む（`infrastructure/replay/video/replay-fonts`）
- **描く場所** — ページの処理を止めず、裏に回したタブでも遅くならないように、WebCodecsが使えるブラウザでは描画と符号化をWorkerで行う（`application/replay/replay-video.worker`、`application/replay/replay-video-worker-client`）。Workerはページが組んだ時間割を受け取り（`ReplayVideoProduction.share()`）、画像と音は要るたびにページへ尋ねる。ページが同梱の書体で字幕を組んだのにWorkerがその書体を読めなければ、最初のコマを描く前に失敗し、ページで書き出し直す。Workerを起動できないときもページで書き出す。省エネのためにブラウザがタブを止めたことは`freeze`イベントで知り、パネルに出す
- **符号化** — 映像はH.264のHighプロファイルで、大きさとなめらかさに足りる最も低いレベルを選ぶ。キーフレームは2秒ごと（`VIDEO_KEYFRAME_SECONDS`）。音はAAC → Opusの順に`AudioEncoder.isConfigSupported()`で試すので、AACが無い環境でも無音にならない（`core/media/video-encoder`）
- **書き出し先** — `showSaveFilePicker`があれば「書き出す」を押したときに保存先を尋ね、`FileSystemWritableFileStreamTarget`でディスクへ直接流す。長さを決めるのは空き容量だけになる。無い環境でも、見込みが512MB（`VIDEO_INLINE_INDEX_BUDGET_BYTES`）を超えれば`StreamTarget`で分割してBlobに積む（索引を先頭に置く`fastStart: 'in-memory'`は全体をメモリに載せるので、長い動画では使わず`'fragmented'`に切り替える）。保存先を選べないブラウザで見込みが1GBを超えると、途中で失敗しうる旨をパネルに出す（`core/media/video-file-sink`）
- **符号化できない環境** — WebCodecsが無ければ`MediaRecorder`へ落とし、ページで描く（`core/media/media-recorder-encoder`）。canvasの絵と混ぜた音をそのまま流し込むので**尺と同じだけ実時間がかかる**（その旨をパネルに出す）。入れ物はMP4 → WebMの順に、そのブラウザが受け取れるものを選ぶ
- **動画の暗闇・視界・光源** — キーフレームから`VisionScene`を組み直し、判定は生きている卓と同じ`domain/tabletop/vision-scene`に任せる（`domain/replay/replay-vision-scene`）。見せる相手のロールで見え方が変わるのも同じで、GMは全部、PLは自分の持ちコマと同行者、見学者は卓に居るPLの視界を借りる。暗闇で見えない位置に立つコマは描かない。描くのはcanvasに切り抜きが無いので、暗幕を別の面へ描いてから灯りの形で削り、削り終えた面を盤面へ重ねる（`infrastructure/replay/replay-darkness-painter`）。面は長辺2048px（`DARKNESS_LAYER_MAX`）で頭打ちにして引き伸ばす。暗闇の縁はぼかしてあるので、粗さは目立たない。地形・マスク・メモ・カードは暗闇の下に、コマ・ダイス・コイン・光源は暗闇の上に描く
- **カットイン** — 画像のカットインと、レイヤーで組んだカットインを、カットインの場面として画面に重ねる。長さはレイヤーの演出の長さか、カットインの`outTime`（秒）で決め、どちらも無ければ3.5秒にし、1.5秒から8秒に収める。動画のカットイン（`isVideoCutIn`）と音だけのカットインは画に入れない
- **まとめ** — 記録を1枚に数え上げる（`domain/replay/replay-digest`、`features/replay/replay-digest-panel`）。数・今日の称号・ダイスの出方・受けた増減を出し、Markdownでも書き出せる。数えるのは記録に残っているものだけで、足りない欄は「出せません」と表示する。**与えた側は出さない**。記録に残るのは値を変えた人であって攻撃した人ではない（GMが敵のHPを減らせばGMの名前になる）。出目はv1.33.0以降の記録にしかない。見える範囲は読む人のロールに従う
- **記念写真** — 卓に出ていたコマの立ち絵を1枚に並べ、部屋名と日付を焼き込んだPNGを保存する（`features/replay/replay-digest-panel/replay-photo.service`、`domain/replay/replay-cast`）。盤に出ているコマだけを並べ、入りきらなかった人数は、知らせないまま切り捨てずに画面へ出す。絵が手元に無いコマも枠と名前は残す

## 配信オーバーレイ

- **透過画面** — 招待リンクの「配信用（透過画面）」で開くと、盤面もパネルも出さず直近の発言と手番だけを透過の背景に出す（`features/streaming-overlay`、`application/ui/overlay-mode.service`）。OBSのブラウザソースに貼る用途
- **見せる範囲は狭いほうを優先する** — 密談・伏せたダイス・その役割で見えないタブは出さない。入室が終わるまで自分のロールは既定（PL）のままなので、リンクで頼んだロールとの狭いほうを採る（広いほうを採ると入室の途中だけ見えてはいけないタブが映る）
- **古い行は落とす** — 直近の数件だけを組み、10秒ごとの拍で古い行を落とす（`streaming-overlay-feed`）。卓が静かな間も貼り付いたままにしない

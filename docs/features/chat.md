# チャット

## チャット

- **インライン編集 / 返信 / 引用 / 元発言へジャンプ / メモとして共有**
- **外周ティッカー** — 発言を2Dモードの画面四辺へ時計回りに流す。専用タブは無く、入力欄の色設定の横にある「ティッカー」ボタン（この画面でティッカーを有効にしているときだけ出る）を入れて投稿すると、その発言が`ChatTickerSelectionService`の部屋イベントで全参加者へ届く。投稿済みの公開メッセージも発言のメニューかチャットツールの「ティッカー」から流せる。ON/OFFと速度は「卓上ディスプレイ」の「多方向表示」か、部屋設定の「UI」タブの「卓上」で決める。投稿待ちでは最後の内容を繰り返す。短文は`◆`区切りで最大8個まで複製して外周へ等間隔に置き、長文では重ならない個数まで自動的に減らす（[利用方法](multi-angle.md#外周ティッカー)）
- **オートフォロースクロール**トグル、新着インジケータ、最新へジャンプ、タブあふれ用スクロール矢印
- **画像フィールドの添付**
- **入力中インジケータ** — 対向ペア表示のstickyバー、chat-inputと一体化した角丸カード
- **可読性** — 発言の色は変えず、吹き出しの背景の明るさを、その色がWCAG-AAの4.5:1で読めるところまで動かす（`ui/pipes/chat-color-style.pipe`の`autoChatBubble`）。ダーク / ライト両対応のユーザカラー
- **システムメッセージ** — 匿名システム通知（`sendSystemMessage()`）、システムアイコン、BCDice既定アバター。行き先は**専用のシステムタブ**（identifier `SystemTab`）で、無い部屋には読み込み時に足す。**消せず、全タブの書き出しにも入れない**（入退室や無応答の知らせで会話が流れるため。1タブだけの書き出しでは選べる）。見分けは名前ではなくidentifierで付ける（改名しても別物にならない）。卓の進行の告知（ラウンド・手番・バフ失効）は会話の一部なので、既定では一番左のタブへ送る（送り先は次の「システム通知の送り先」で変えられる）
- **システム通知の送り先** — システムがチャットに書く知らせのうち8種類は、部屋ごとに送り先のタブを選べる（`domain/chat/system-notices`）。種類と既定の送り先は`round`（ラウンド・手番の進行）・`clock`（ゲーム内時間）・`diceReveal`（盤上のダイスの公開）・`trigger`（トリガー）が一番左のタブ、`movement`（移動・交戦エリア・騎乗）・`card`（カード）・`bgm`（BGMの再生設定）・`room`（接続・部屋の管理）がシステムタブ。選べるのは既定・部屋のタブ・「送らない」（`'off'`）で、部屋設定の「通知」タブ（「戦闘」タブの「ラウンド」にある「通知の送り先を選ぶ」からも開く）でGMだけが変えられる。`Config._systemNotices`には選んだ種類だけを種類→タブidentifierのJSONで書き、何も選んでいない部屋は空文字になる。空文字と読めない値はすべて既定の送り先と読むので、送り先を選べない版で保存した部屋も既定の送り先へ送る。この版の知らない種類は消さずに残す。書くときは`ChatMessageService.sendSystemNotice`が`noticeTabOf`で送り先を引き、選んだタブが消えていれば既定の送り先へ書く
- **チャットパレット** — 読み取り専用キャラデータビュー、ロールコマンドのチャット入力中継、オートコンプリートの候補はcomputed signal（`autoCompleteListSignal`）
- **入力欄** — 縦リサイズと高さの永続化
- **文字の装飾** — `**太字**`と`[名前]…[/名前]`（`[/]`でも閉じる）で、発言の一部を太字・斜体・取り消し線・大きさ3段・書体6種・文字色11色か`#rgb`に変える（`domain/chat/chat-decoration`）。名前は日英韓のどれでも読み、入力欄のツールバーは表示言語の名前で書く。対にならない`**`、閉じていないタグ、知らない名前は文字のまま残すので、記法の無かった頃の発言は変わらない。`\`が記号を書くのは、その記号が装飾として効くとき（`\**`や`\[赤]`）だけで、ほかの`\`は残す。複数行を選んだ太字ボタンは1行ずつ`**`で囲む。斜体は`skewX`で傾けるので箱になり、そのままでは行をまたげない。そこで`leaningPiecesOf`で折り返せる単位（英単語はまとめ、ほかは1字ずつ、開き記号は後ろへ・閉じ記号は前へ付ける）に切り、1つずつ箱にする。白や黒に近い色（名前でも色コードでも）は`chatColorHalo`で反対の色の細い縁を付ける。記法は本文の文字列のまま保存するので、旧版には記法が文字のまま見える。描画は`decorateChatStyleText`と`splitRubyNotation`（ルビ部品）で、チャット・共有メモ・カード・ノベルモード・配信用画面・HTMLログに付き、テキストログ・ティッカー・吹き出し・検索・発言のコピーでは外す。書体はOFLの`@fontsource`5種（明朝・丸ゴシック・手書き・ポップ・ドット、計約17MB）をビルド時に`assets/fonts/chat/`へ写し、発言が初めてその書体を使ったときに`chatFontWanted$`経由で`ChatFontService`が`<link>`を足す（文字の範囲ごとに分かれているので、使った字の分だけ届く）
- **ルビの記法とモノルビ** — `|漢字《かんじ》`（`|`は全角の`｜`でもよい）で親文字に読みを振る（`domain/chat/chat-ruby-notation`の`RUBY_NOTATION`）。読みを`|`で親文字の字数と同じ数に区切った`|漢字《かん|じ》`は、1字ずつに振るモノルビになり、空にした部分の字には振らない。区切りの数が字数と合わなければ、区切りを落として語全体に振るグループルビになる（`rubyRunsOf`）。描くときは`<ruby class="chat-ruby">`にし、テキストログ・発言のコピーでは区切りを落とした`語（よみ）`の括弧書きにする（`readingOf`）
- **ルビの表示設定** — 読む人ごとに「チャット設定」の「ルビ」で振り方（上に振る / 括弧で添える / 振らない）・位置（中付き / 肩付き）・長さが違うとき（短い方を1:2:1で割り付ける / 詰めて中央に寄せる）・大きさ（親文字の半分0.5em / 標準0.65em / 大きめ0.8em）を選ぶ。既定は上に振る・中付き・1:2:1・標準で、位置・割り付け・大きさは「上に振る」のときだけ選べる（`domain/chat/ruby-display`）。選んだ値は`ChatPreferencesService.rubyDisplay`としてlocalStorageの`chat-preferences`に持ち、部屋には送らない。`ChatPreferencesService`が値を`<html>`の`data-ruby-*`属性に書き（別ウィンドウに出したパネルの文書にも書く。`AttachedDocuments`）、`styles/components.css`の規則が`ruby.chat-ruby`の描き方を切り替える。チャット・共有メモ・カード・ノベルモードの`<ruby class="chat-ruby">`に効き、保存するHTMLログには保存した人の設定を`rubyDisplayCss`で`<style>`として埋め込む
- **HTMLログエクスポート** — 送信者ポートレートをbase64埋め込み、重複画像のdedupとダウンスケール、WebP化、引用 / 返信関係の可視化
- **書式つきの入力欄と記法の指摘** — チャットの入力欄とパレットの編集欄は、Tiptap 3（ProseMirror）のエディター（`features/chat/chat-editor/`）。太字・斜体・取り消し線・大きさ・書体・色はmark、参照・ルビ・演出・立ち絵・文末のカットインはinlineのatom（部品）で持ち、記号は見せない。送る文字列とは`domain/chat/chat-rich-text`の`parseChatRichText` / `serializeChatRichText`で行き来し、ライブラリには何も保存させない。手を入れていない行は元の文字を段落の`source`に持ち、1字も変えずに書き戻す（履歴やパレットのいじっていない行が変わらない）。手を入れた行は決まった形で書く（太字は`**`、ほかはタグを積んで名前で閉じ、タグ名は読む人の言語、書式は行末で閉じる）。文字としての`**`やタグは、読み直して意図と食い違うときだけ`\`で守る。表示と読み直しが変わらないことは、例文と種を決めた乱数のspecで固定している。入力欄の上のツールバー（`features/chat/chat-toolbar/`、`@defer`で別チャンク）が書式の付け外しと、記法の種類ごとのボタンからの挿入（`chat-syntax-items`）を受け持ち、カーソル位置の書式でボタンを光らせる（`ChatTextField.activeMarks`）。選択の上には`@tiptap/extension-bubble-menu`の小バー、`{` `《` `@`と語の頭の`:` `&`のあとには`@tiptap/suggestion`の名前の候補を出す（引き金は純関数の`findChatTrigger`）。候補はEnterかTabで入れ、候補が出ていないEnterは送信。小窓・候補・小バーは上に開く（`AnchoredPopover`の`prefer: 'up'`、floating-uiの`top`）。`**x**`などは打ち終えた時点でmarkや部品に変え、直後のBackspaceで戻す。貼り付けは記法として読み（Ctrl+Shift+Vは文字のまま）、コピーは記法の文字列にする。入力欄の上の行（`chat-input-selects`）は発言者・送信先・ダイスボットと「?」で、各セレクトは名前が読める幅を下限に持ち、発言者と送信先が残りの幅を分け合う。足りなければダイスボットが次の行へ回る。書式と記法の種類ごとのボタン・スタンプ・発言の色・マイダイス・ティッカーは、入力欄の枠（`chat-input-frame`）の上端の帯（`chat-input-edits`）に並べ、組の間に細い線を引く（420px以下の幅では引かない）。立ち絵が2枚以上なら帯の左端にスライダーを置き、幅が足りるうちはボタンと同じ行に縮めて収める。発言の色のボタンは、その色の下線を吹き出しの色で縁取った「A」。入力欄の文字と背景は`ChatColorStylePipe`で発言の色と吹き出しにし、案内の文字はその色を65%の濃さで描く。指摘の数は入力欄の右下に出し、一覧は上に開く小窓にする。記法の読み取りは`domain/chat-syntax/chat-syntax`の`scanChatSyntax`で、送るときの解釈を範囲つきの関数に分けたもの（`resourceCommandSites`・`portraitCommandSite`・`readCutInChatTail`・`effectTokenSites`・`chatDecorationLayout`など）をそのまま使うので、送ったときの動きと食い違わない。部品にならない記法には、その範囲に種類ごとの薄い帯を付け、文字は発言の色のままにする。部品は吹き出しに関係なく読めるよう、パネルの地の上に描き、種類は縁とアイコンの色で示す。帯は`uiRovingToolbar`で、Tabは1回、矢印キーでボタン間を移る。指摘は`chat-lint`の`lintChatSyntax`が`ChatLintContext`（発言者・ターゲット・立ち絵・カットイン・演出・ダイスボット）に照らして出し、`application/chat/chat-lint.service`がsignalで組み直す。文末にない立ち絵とカットインの部品は薄くして理由を出す。BCDiceは`checkRollLine`が送るときと同じ順（半角化→繰り返し→パターン→`eval`）で確かめる。ダイスボットの待ち行列とログには乗せず、振る数が1万を超える式は`eval`しない。BCDice 4.10は数字で始まる行（`1日目`）にもパターンが合うので、`looksLikeRollWord`で式の形をした語だけを調べる。エディターは`chat-editor-loader`で遅延読み込みし（約400KB、初期バンドルには入らない）、届くまでと届かないときは`<textarea>`で書く。`<textarea>`でもツールバーは使え、選択範囲を記法で囲む。送った発言の書き直し（`features/chat/chat-line-editor/`）も同じエディターで書き、`ChatEditorHost`の`marker`で目印を`data-chat-line-edit`に替え、`cancel`でEscを取り消しに当てる。下のツールバーは`syntax`をfalseにして書式・ルビ・スタンプだけを出し、名前の候補は出さない。書き直してもコマンドは動かないので、指摘は装飾・ルビ・スタンプ・引用の範囲だけを`lintChatSyntax`にかける。ボタンと案内の色は、ツールバーが読むCSS変数（`--chat-toolbar-ink`など）で吹き出しの文字色に合わせる。入力欄は`ChatTextField`越しに扱い、目印は`data-chat-input`。キーはEnterで送信・Shift+Enterで改行・Ctrl+↑↓で履歴・Ctrl+←→はウィンドウのタブ切り替えへ渡し、変換中と`compositionend`から50msのEnterは送らない。チャットの設定「書式つきの入力欄を使う」（`ChatPreferencesService.richInput`、localStorage、既定オン）で`<textarea>`に戻せる
- **タブ内検索（Ctrl+F）** — チャットログは仮想化してスクロール位置付近の行しか描かないので、ブラウザの検索では長いタブの残りを拾えない。ウィンドウ内（ポインタが乗っているだけでも可）のCtrl+F（MacはCommand+F）か、タブ列横の「検索」で専用の検索欄を開き、表示名と本文を全角半角・大文字小文字を区別せずタブ全体から探す（`features/chat/chat-search/`）。最新のヒットから始め、Enterで前、Shift+Enterで次へ循環する。`ChatTabComponent.reveal`がヒット行の周りを描いて中央へ寄せる。語の印はDOMを書き換えないCSS Custom Highlight API（`::highlight(chat-search)`。非対応ブラウザでは現在行の強調だけ）で付ける。他人宛ての秘話・削除した発言・見せてもらえないシークレットダイスの中身は見つからない
- **しおり（共有 / 個人）** — 発言のしおりボタンか右クリックメニューで「共有しおり」「個人しおり」を挟む。タブ列横の「しおり」で全タブ横断・発言順の一覧を開き（種類で絞り込める）、選ぶとそのタブへ切り替えて`reveal`で描き寄せ、行を光らせる。共有しおりは発言自身のSyncVar（`bookmarkedAt` / `bookmarkTitle`）なので部屋と一緒に同期・保存され、ログ消去やタブ削除で発言が消えれば一緒に消える。個人しおりは発言のidentifierをキーにlocalStorageの`chat-personal-bookmarks`（新しい方から1000件）へ置くだけで、部屋には何も流れない。同じブラウザで部屋を読み直せば戻る（`application/chat/chat-personal-bookmark.store`）。題名は空なら発言の書き出しを使う。見学は共有しおりを辿れるが変えられず、個人しおりは持てる。見えない行（他人の秘話・削除した発言・閲覧できないタブ）のしおりは一覧に出ない（`domain/chat/chat-bookmark`、`features/chat/chat-bookmark.service`）
- **あとから秘話** — 全員に言った自分の発言を、メニューの「あとから秘話にする」で部屋のほかの参加者から1人選んで秘話に変える（`ChatMessage.makeAfterWhisper`、`ChatLineEditService.makeAfterWhisper`）。`to`と`name`（`話者 > 相手`）を普通の秘話と同じ形に書き換えるだけで専用の印は付けないので、古い版のクライアントでもそのまま秘話として出る。元の宛先と名前は`afterWhisperTo` / `afterWhisperName`（時刻は`afterWhisperAt`）に残すので、別の相手へ移すことも「あとから秘話をやめて全員に戻す」で戻すこともできる。ダイス結果とシステム通知は対象外（ロールは卓が見た場所に残す）。秘話に加わっていない人には、返信・引用の参照からも中身が消える（チャットと書き出しログの両方。`ChatLogExporter.referencedLine`）。各端末の表示を変えるだけで、行そのものはほかの参加者にも届いている
- **発言の削除（疑似削除）** — 自分の発言（ダイス結果とシステム通知は除く）を、チャットツールかメニューの「削除」から確認つきで消す（`ChatLineEditService.pseudoDelete`）。`pseudoDeletedAt`を立てるだけで、本人を含む全員のチャットから最初から無かったように消え、元に戻せない。ティッカー・ノベルモード・配信用画面・チャット検索・頭上の吹き出し・ウィンドウタイトルの件数・返信 / 引用の参照からも外れる（判定は`ChatMessage.isShownInChat`）。部屋データには残るので、保存した部屋にも書き出したログにも「削除済」の印つきで入る。ログから外したいときは、「チャットタブ設定」と「ログのプレビュー」のチェック「削除した発言をログに出力しない」で添付画像ごと除く（既定オフ。localStorageの`chat-log-omit-deleted`に記憶。`ChatLogExporter.withoutDeleted`）
- **編集履歴** — `ChatMessage.edit()`が、置き換えた文面と時刻を`editHistory`（SyncVar、JSON文字列。`domain/chat/chat-message-history`）に積む。履歴は発言と一緒に同期・保存される。「編集済」の印かメニューの「編集履歴を見る」で、最初の発言から現在までの全版を開始時刻つきで開け、発言が見える人なら誰でも読める。ノベルモードのバックログからの編集も同じ経路で残る。保持は過去50版までで、超えたら最初の版を残して古い編集から落とす。編集済みの印（`fixd`）があって`editHistory`が空の発言（履歴を残さない版で編集した行）は、次の編集から開始時刻・回数不明の版として履歴が始まる（`appendChatMessageEdit`）
- **チャットツール** — 発言の操作のボタン。ヘッダーに並べると狭い窓で行ごとに折り返し位置がずれ、コンパクト表示では本文の後ろに続いて行が揃わないため、吹き出しの右上に浮かぶツールバーに並べ、行の高さを取らない。ツールバーはポインタが乗っているか、キーボードフォーカスが中にある間だけ出る。並びはメニューの編集の面`chatTools`（「メニューの編集」の「チャットツール」。「チャット設定」の「チャットツールを並べ替える」からも開く）で端末ごとに組み替えられ、足す・外す・並べ替えのほか、名前とアイコンも替えられる。`MenuLayoutService`がlocalStorageの`axe.menu.chatTools`に持ち、部屋にも保存ファイルにも入れない。置けるのは`CHAT_TOOLS`の12種（`domain/ui/menu-command`。キーは`chat:reply`のように`chat:`で始まる）で、返信・引用・リアクション・しおり・本文をコピー・共有メモにする・ティッカー・目標値・編集履歴・元のメッセージへ移動・編集・削除。この12種はチャットツールの面にしか置けず、ほかの面にもホットバーにも置けない。既定の並びは返信・引用・リアクション・しおり・編集・削除（`domain/ui/builtin-menu-layouts`の`CHAT_TOOLS_ROW`）。各ボタンはその行で使えるときだけ出る（編集と削除は自分の行だけ）。削除はホバーで赤くなる。並びの後ろには並べ替えの対象にならない「その他の操作」があり、右クリックと同じメニューを開く。メニュー（`buildChatMessageContextMenu`）は、応答 / 本文 / しおり・メモ・転記・ティッカー / 元発言・編集履歴 / 本人の変更の用途別に区切り線で分け、削除は最後に離して置く。タッチ画面ではツールバーを出さず（`pointer-coarse:hidden`）、長押しで同じメニューを開く。ヘッダーは1行に保ち、狭い窓では送信元IDと時刻から縮めて名前を最後まで残す
- **ストリームチャットウィジェット** — 1つのタブの発言を流す小窓（`features/chat/chat-stream/`）。チャットウィンドウのタイトルバーのボタン（「別のウィンドウで開く」の後ろ）、タブ名の右クリックメニュー、[ノベルモード](visual-novel.md)の操作列から開き、同じ所でもう一度押すと閉じる（`ChatStreamPanelService.toggle`）。中身はタブ列・発言の一覧・入力欄だけで、入力欄と行の操作はチャットウィンドウと同じ部品を使うので、送る・返信・引用・編集はチャットウィンドウと同じに動く。パネル名は`chat-stream:<タブidentifier>`で、タブごとに1つ開ける。タブ列で別のタブに替えると、小窓のパネル名もそのタブのものに替わる（そのタブを映していたほかの小窓からは、その名前が外れる）。Ctrl+←→でもタブを替える（行を編集中の欄では替えない）。発言者は開いたときのチャットウィンドウの発言者から始まり、小窓で替えてもチャットウィンドウには移らない。ダイスボットはチャットウィンドウと共有する。タイトルバーには「最新に追従」と「透明モード」の切り替えがあり、透明にすると、タブ列と入力欄にだけ半透明の地（`--ui-ghost-bg`）を敷き、発言の行の区切り線を消す。ノベルモードの横で読めるよう、ノベルモードの画面より上の層（`Z_VISUAL_NOVEL_PANEL`）に開く。コードは初めて開いたときに読み込む
- **テキスト形式のログ保存** — ログの形式の1つが「テキスト」で、「ログのプレビュー」と「チャットタブ設定」のどちらからも選べ、`.txt`で保存する（`domain/chat/chat-log-plain`の`renderPlainChatLog`、判定は`isPlainChatLogStyle`）。HTML形式と同じく、読者に見える行だけを配置順に並べる。各行の頭に時刻と名前（複数タブをまとめて書き出すときはタブ名も）を置き、日付の変わり目に区切り行を入れる。引用・返信は字下げして下に置き、シークレット・編集済・削除済の印も残す。ルビは`語（よみ）`の括弧書き、添付画像は名前だけなので、画像の縮小・埋め込みの準備は飛ばす（`SaveDataService.saveChatLog`）
- **スタンプ** — 描き文字（`sfx`）・判子（`seal`）と、システムちゃんの絵スタンプ5系統（`roll`/`battle`/`explore`/`feel`/`talk`。絵は`assets/images/stamps/<系統>/<キー>.webp`）を、入力欄のスタンプボタンから2段のタブで選ぶ（一覧は`domain/chat/stamp-catalog`、選ぶ部品は`ui/components/stamp-picker`、描く部品は`ui/components/stamp`）。4文字の判子は2×2に組み、右の列から読む。スタンプだけの行は識別子を`ChatMessage.stamp`に持ち、本文には代わりの文字を書く。知らない版や書き出したログでも文字として読めるようにするためで、知らない識別子の行は代わりの文字のまま出す。入力中の文と一緒に送ると、同じ1行の最終行に代わりの文字が入る（`domain/chat/stamp-line`）。ダイスボットは1行目しか読まないので、文に書いたロールはそのまま振れる。文の中のスタンプは本文に`［名前:ID］`と書く（`domain/chat/inline-stamp`）。名前は送った人の言語のもので、知らない版・書き出したログ・検索・ティッカー・吹き出しでは`［名前］`として読める（`withoutChatDecoration`がそう書き換える）。読むのは今ある系統のIDと`image:`だけで、たまたま書いた括弧は拾わない。参照の置き換え・空白の詰め・行末の立ち絵を通っても崩れないよう、波括弧・`@`・空白を含まない。名前の空白は`_`に置き換えるので、名前のどこも語の頭にならず、`&`や`:`の命令としては読まれない。装飾とルビの記号（`*` `[` `]` `|` `《》` `\`）も名前から除く。チャットのログは`decorateChatStyleText`に渡す`stampMarkup`で文字の高さに描き（スタンプだけの行は大きく並べる）、ノベルモードと配信用画面は`RubyPart.stamp`を`ui-stamp`で描いて文字送りでは1字に数える。描き方は`ui/components/stamp/stamp-view`の`stampViewOf`を`ui-stamp`と文字列の両方で使う。入力欄ではスタンプのボタンで選ぶとカーソルの位置に入り（書式つきの入力欄では部品の`chatStamp`）、スタンプ1つだけで返信・引用のない行はスタンプだけの行として`ChatMessage.stamp`の形で送る。`ChatMessageService`は送る直前に、部屋が止めているスタンプと知らないIDを`［名前］`に書き換え、部屋の絵は添付に足す（添付の一覧には出さない）
- **部屋のスタンプ集** — 部屋の画像からスタンプの組を作れる（`StampPack`、`features/chat/stamp-pack-panel`）。スタンプは組の中の位置ではなく画像で見分ける（`image:<画像ID>`）。組を変えても消しても、送り済みの行や付いたリアクションはそのまま見える。画像は組の要素として持つので、部屋の保存に乗る
- **リアクション** — 発言にスタンプを付ける。1人が1行に付けたスタンプは、その人の`ChatReaction`（行の識別子・利用者ID・名前・スタンプの並び）にまとめ、ほかの人の記録には書かない。同じ行へ同時に付けても上書きが起きない。記録は行の子ではなく部屋に置く。行の下に何かあると、読み込んだ行の本文が出なくなるため。保存したログには、付いたスタンプも並ぶ
- **スタンプの使い道を部屋で決める** — 部屋設定の「スタンプ」タブで、行として送る使い方とリアクションの使い方を、それぞれまとめて止めたり、スタンプごとに禁じたりできる（`Config._stampRules`、読み書きは`domain/chat/stamp-rules`、変えられるのはGMだけ）。決まりが効くのはこれからの使い方だけで、送り済みのスタンプはそのまま見せる。空の値と読めない値は「すべて使える」と読み、この版の知らない禁止スタンプも次の版のために残す
- **頭上の吹き出し** — 卓上のキャラとして話した公開の行を、そのコマの上に数秒出す（`domain/chat/speech-bubble`、`application/chat/speech-bubble.service`）。「」があればその中だけを、なければ全文を出す。ルビは親文字にし、80字か4行を超えた分は切る。スタンプの行はスタンプを出す。秘話（あとからの秘話を含む）・シークレット・通知・削除した行・物語外の行・見られないタブの行には出さない。ダイスとリソース変更の行も出さない。道具は答えを同じタブへ、元の行の`timestamp`の1（ダイス）か2（リソース変更）後に、`originFrom`を付けて書くので、出すまで400ミリ秒待ってその答えを探し、遅れて答えが来たら消す。参加した直後に届く過去ログは、残りの表示時間の分だけ出す（ふつうは出ない）。コマごとに1つで、同時に出すのは8つまで。行を編集すると新しい文に変わる。部屋設定「一般」の「キャラクターの発言を頭上の吹き出しに出す」（`Config._speechBubbles`。`'off'`だけが止める）と、各自のツールバーの切り替え（端末に保存）で消せる。ゲージとバフの上に積み、平面表示とポスターでも同じように出す。その画面がノベルモードの間は出さない（ノベルモードの窓が台詞を1字ずつ出すので、吹き出しが全文を先に見せてしまうため。閉じれば残りの表示時間の分だけ出る）。読み上げからは外し、動きを減らす設定では動かさず、軽量表示では影を付けない
- **リセットの記法と実行の順番** — 値を既定値へ戻す`:*=既定`・`:名前=既定`・`:名前^=既定`は`readDefaultResetCommand`（`domain/data/resource-command-words`）が読み、ダイスボットには渡さない。語は`既定`・`既定値`・`規定`・`規定値`・`default`で、NFKCで正規化して小文字で比べる。`&リセット-`（`&reset-`）は`isPieceResetCommand`が読み、`&*-`と`:*=既定`の2つに直して実行する。`&&リセット-`は`isTableResetCommand`が読む。1行の実行の順は`ResourceEditProcessor.applyResourceBuffEdits`が決める。`:`の操作、`&`の操作、`&&`の操作（卓全体のリセットを含む）の順に行い、既定値へ戻す操作は、行のどこに書いてあっても最後に行う。ステータスを動かすバフは外れるときに動かした分を戻すので、値を先に戻すと、その分が既定値からもう一度動くため。報告はほかの`:`・`&`と同じ1行に日本語で書く。中身を見せないコマの値は、全員の行には項目の数だけを書き、全文を`tellThoseWhoMaySee`で見える席に送る。卓全体のリセットの報告は件数だけ。処理の中身は[キャラクター](character.md)の「リセット」にある
- **リセットの色分け・指摘・候補** — 入力欄は、名前にかかわらず外す記法、既定値へ戻す記法、その両方を、構文の種類`reset`として読む（`domain/chat-syntax/chat-syntax`。届く範囲の`reach`は`piece`か`table`、することの`takes`は`buffs`・`values`・`both`）。指摘は3つある（`domain/chat-syntax/chat-lint`）。`reset.gmOnly`はGM以外が書いた卓全体のリセット、`reset.noDefaults`は既定値が1つもない相手へ値を戻す記法、`reset.shadowsBuff`は記法と同じ名前（`*`・`リセット`・`reset`など）のバフが付いているときに出る。ターゲットがないとき、発言者がコマでないとき、見学のときの指摘は、ほかの操作と同じものを使う。候補（`features/chat/chat-input/chat-syntax-items`）は表示している言語の語で書き、卓全体の形はGMにだけ出す
- **リセットを元に戻すボタン** — リセットを報告した行は、`ResetUndoService.isOffered`が真の席でだけ「元に戻す」を出す（`features/chat/chat-message`）。真になるのは、その行の識別子で記録を持つ端末の、卓を変えられる席だけ。記録は同期しないので、ほかの席の同じ行にボタンは出ない。押すと`PieceResetService.takeBack`が戻し、行には戻した体数と、変わっていて戻さなかった体数を出す。記録は結果にかかわらず使い切るので、2回は押せない

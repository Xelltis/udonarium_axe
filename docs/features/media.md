# メディアと音楽

## メディア / 音楽

- **ジュークボックス** — 複数の再生リスト（流す先は`Jukebox.playlistIdentifier`で同期、曲の移動・コピー）、シャッフル（シードと曲の識別子だけで順が決まるので、曲が終わったとき全ピアが同じ次の曲を選ぶ）、位置を残す一時停止、シークバー、リピートモード、アートワーク表示
- **オーディオのタグ付け** — BGM / SE / 環境音のプリセットのタグ（`JukeboxComponent.PRESET_TAGS`）、SE専用の音量コントロール
- **取り込める音声の大きさ** — 1ファイル10MBまで（`MAX_LOADED_AUDIO_BYTES`、`core/storage/file-archiver`）。ドロップ・ファイルの選択・保存zipの中身のどれでも、超えたファイルは取り込まず、ファイル名を画面に知らせる（`features/file/files-too-large`）
- **ミニジュークボックス** — フローティング・ミニプレイヤー（最小化モード、シークバーロック）
- **BGM同期** — ほかのピアのシークに合わせるときは0.6秒のクロスフェードでつなぐ（遅延ペア向け。ずれが250ms未満なら動かさない）。シークバーロックの状態は`Jukebox.isSeekLocked`でピア間に共有する
- **カットイン** — 「チャット末尾発動」（`CutIn.chatActivate`）のカットインは、チャットの行の最後の語がその名前なら起動する。名前の前に`@`を付けると音声だけを鳴らす（`domain/media/cut-in-chat-tail`、`CutInService.activateFromChatText`）。カットインの音源を選ぶ画面（`features/media/cut-in-bgm`）は、部屋の音源を「全て」「BGM」「SE」で絞り込む。カットインの大きさの決め方は`CutInSizingService`（`application/media`）の1か所にあり、編集画面とAI連携の道具がどちらもこれを呼ぶ。幅か高さを変える、縦横比を保つ、動画にする・絵に戻す、原寸にする、絵を差し替える、の5つで、縦横比を保つときに保つ比率は、動画なら既定の大きさ、絵なら絵そのものの大きさになる。今の大きさは使わない（`CutIn.ownShape`）。絵の大きさは`PictureSizeService`が絵ごとに1回だけ測る。まだ測れていない絵は、測れたときに、カットインがまだ同じ絵でそれを求めていれば合わせる。数でない幅か高さを頼まれたら、大きさは変えない（`CutIn.resizeSide`）。YouTubeの動画を流すカットインは[YouTubeのカットイン](#youtubeのカットイン)を参照
- **環境音（BGS）** — 雨や焚き火のような音を、BGMの下で部屋全員に複数同時にループさせる。曲を替えても止まらない。タグには「環境音」がある（保存値は`BGS`＝`AUDIO_TAG_BGS`で、`audiotag.xml`に入る）。このタグの音源は`Jukebox.play()`が`BackgroundSound.start()`へ回し、再生リストが空のときの曲順（`Jukebox.queue`）からも外す。実体は音源ごとに1つの`BackgroundSound`（`domain/media/background-sound`、identifier `bgs_<音源ID>`、SyncVarは`audioIdentifier` / `volume`（音源ごとの部屋音量0〜1）/ `isPlaying` / `startedAt`）。**止めても破棄せず`isPlaying`を落とすだけ**にしている。破棄したidentifierは再利用できず、音量も次回へ残したいため。同時に2人が同じ音を始めても1つにまとまる。`volume`が空や数値でなければ全開として読む（`background-sound-level`。旧版のピアや空の属性で、気づかないうちに無音にならないように）
- **環境音の操作と鳴らし方** — ジュークボックスの一覧で環境音の行を押すと開始・停止する。鳴っている間は音源ごとに「全員共通の音量」スライダーと停止ボタン、「すべて止める」が並び、ミニジュークボックスは名前を1行で出す。操作できるのはゲスト以外（`BackgroundSoundPlaybackService`、`canEditTabletop`）。途中参加者にも鳴り、`AudioSharingSystem.preferredIdentifiers`が再生中の環境音のファイルを優先して配る。ピア間でループ位置は揃えない。音は背景チャンネル（`VolumeType.BACKGROUND`）の`LoopPlayer`（`core/storage/loop-player`）で鳴らす。2MB以下のファイルはデコードしてメモリから回し（`<audio>`がループの継ぎ目に空ける隙間を避けるため）、それより大きいものとデコード後48MBを超えるものはストリーミングする。フェード（1.5秒）はオーディオクロックで刻むので、裏に回ったタブでも最後まで進む
- **ループポイント** — `core/storage/audio-loop-points`がファイルのバイト列から読む。対象はOgg（Vorbis / Opus）、FLAC（Vorbis comment。先頭のID3タグは飛ばす）、MP4 / M4Aのfreeformタグの`LOOPSTART`と`LOOPLENGTH`（または`LOOPEND`）で、RPGツクールと同じくサンプル数として解釈する。WAVは`smpl`チャンクの最初のループを使う。ジュークボックスの曲（SEタグ以外、`AudioPlayer.followsLoopPoints`）は`LoopPointTrack`でメモリから鳴らす。**1曲リピート中だけ**区間を隙間なく回し、ほかのモードでは最後まで流す。再生位置はループ区間に折り返して数えるので、シークバーとピア間のシーク同期がずれない。ループ指定が無い曲、デコード後の見積もりが192MBを超える曲（長さ不明ならファイル8MB超）、まだ端末に届いていない曲はストリーミングで鳴らす。デコード済みは直近2曲だけ保持し、同じ曲へのクロスフェードで再デコードしない。環境音はループポイントがあれば、サイズによらずデコードしてその区間を回す
- **環境音のリプレイ** — 開始と停止を専用のイベント`media.bgs`（`ReplayEventKind.MediaBackgroundSound`）で記録し、ログに音源名つきで出す。音量だけの変更はパッチに任せる。このイベントはストーリーと盤面の両方のカテゴリに入るので、動画のタイムラインで尺を取る。動画の音声（`domain/replay/replay-soundtrack`）では、開始から停止までをBGMに重ねて敷く。音量は開始時の部屋音量×`REPLAY_BGS_GAIN`で、BGMを入れる選択（`withMusic`）に従う。盤面での再生も録画どおりに鳴らし、抜けると部屋の環境音に戻す
- **種類ごとの音のチャンネル** — 単発の音も`VolumeType`の別チャンネルで鳴らす。カットイン（`CUT_IN`。音楽・場面の音・動画）、通知音（`NOTIFICATION`。チャット通知とアラーム）、操作音（`HANDLING`。ダイス・カード・コマなど）、演出の効果音（`EFFECT`。マップ演出と増減）、その他の効果音（`SE`）。部屋へ送るのは音源IDだけで、**種類は受け手が判定する**。`SoundEffect.kindOf`が組み込み音（`PresetSound`）の名前から`domain/media/preset-sound-kinds`で引き、部屋に追加された音は`SE`とする。このため旧版のピアにも同じ音が届く。カットイン動画は音声チャンネルの届かない別フレームで鳴るので、`cut-in-window`で個人音量（既定0.5を等倍とする）×部屋音量を動画音量に換算する
- **音の設定パネル** — 「音の設定」（`features/sound-settings/sound-settings-panel`）の「自分の音量」に、試聴・BGM・環境音・カットイン・通知音・操作音・演出の効果音・その他の効果音を並べる。それぞれ音量を保ったまま消せる。続けて「チャットの通知音」と「部屋の音量」を出す。開く場所は「表示」メニュー、モバイルのメニュー、ジュークボックスの「自分の音量」の横、チャットの通知音の設定欄（「自分の音の設定をすべて開く」）。値は`PersonalVolumeService`がlocalStorage（キー`audio-personal-volumes`、各音量と`muted`配列のJSON）に書き、起動時と部屋の音量が変わるたびに`applyToChannels()`が、部屋の音量を掛けて各チャンネルへ渡す。部屋へは送らない。欠けた値や範囲外の値は既定の0.5、知らない種類名のミュートは捨てるので、種類の少なかった旧版の保存値も読める
- **部屋の種類別音量** — 全体の`Config._roomVolume`に加え、`Config._roomKindVolumes`（既定`''`）でBGM・環境音・カットイン・通知音・操作音・演出の効果音・その他の効果音ごとの部屋音量（0〜2）を持つ。両者の積が各チャンネルに掛かる（`Config.roomScaleFor`。試聴は全体だけ）。値は**1から外れた種類だけ**を書いたJSON文字列（`domain/media/room-volumes`）で、空・読めない・範囲外は1と読む。この欄の無い旧データと旧版のピアのConfigは、全種類を1として鳴らす。変更できるのは全体音量も含めてGMだけ（`RoomVolumeService`）。音の設定パネルは全種類を、ジュークボックスの「部屋の音量」はBGM・SE・環境音を出し、GM以外は見るだけ。個人の音量は`PersonalVolumeService`が持ち、部屋音量との積をチャンネルに掛け直すので、部屋音量が変わっても消した種類は無音のまま
- **テキスト層の書体** — 書体の名前を手で打つ欄の下に、「既定」「ゴシック」「明朝」「丸ゴシック」「等幅」を並べる（`domain/media/cut-in-font-presets`）。それぞれ主なOSにある書体を並べ、最後に総称の系統を置くので、どの画面でも似た字形になる。選ぶと手で打つのと同じ欄に書くだけで、新しく保存・同期するものはない
- **文字を1字ずつ出す** — テキスト層の「文字の動き」（`letterMotion`。`type`/`fade`/`pop`/`slide`/`wave`/`shake`。空と知らない値は動きなし）と、字の間隔（`letterStaggerMs`）・1字の長さ（`letterDurationMs`。0は動きごとの既定）。1字の姿勢は時刻だけで決まる純関数`domain/media/cut-in-letter-motion`の`letterPoseAt`が決め、舞台はそれを標本にしてWeb Animationsのキーフレームを作り、リプレイ動画は同じ関数で1字ずつ描く。字の区切りは書記素（`core/util/graphemes`）。動きを減らす設定では、止まった姿で全文を出す（動画は見る人の設定によらず動かす）
- **再生した人のために流す** — チャットの発言で起動したカットインは、話者（キャラ・その行の立ち絵・名前）の写しを起動と一緒に送る（`CutInLauncher.launchSpeaker`、`domain/media/cut-in-speaker`）。画像の層に「再生した人の立ち絵を出す」（`portraitSlot`）を入れると話者の立ち絵を出し、話者がいなければ層の画像を、それも無ければ影絵を出す。テキストの`{character}`は話者の名前になり、話者がいなければ「？？？」、`{{character}}`は文字どおり`{character}`と出す。写しには起動の時刻とカットインIDを添え、両方が今回の起動と一致するときだけ使う。旧版の参加者は知らない属性もまとめて送り返すので、古い話者が次の起動に混ざらないようにするため。エディタの「誰として再生」で試せる（同期しない）。ホットバー・カード・卓からの起動は話者なしで、リプレイ動画にも話者は乗らない
- **立ち絵の位置合わせ** — キャラの立ち絵パネルの「カットイン位置」から、立ち絵ごとに枠での拡大と位置を決める（`GameCharacter.cutInPortraitFits`、版つきJSON、`domain/media/cut-in-portrait-fit`）。拡大は全体を枠に収めた大きさを1とし、位置は枠の幅・高さに対するずれで持つので、どの大きさの枠にも使える。ダイアログはドラッグ・ホイール・ピンチ・矢印キーで動かし、閉じるときに1回だけ書き込み、もう無い立ち絵の分を消し、32件までに抑える。未設定と「元に戻す」は、カットインごとの配置のまま。位置合わせも起動時の写しに入るので、流れているカットインはシートを変えても変わらない

## DJデッキ

- **開き方と並び** — ミニジュークボックスの「DJデッキを開く」で、ミニプレイヤーの下に開く（`features/media/mini-jukebox/dj-deck`）。開いているかはこのブラウザのlocalStorage（`mini-jukebox-dj-deck`）に残す。上に流れている曲の周波数ごとの強さとBPMを出し、その下に「デッキ」「パッド」「ミックス」のタブを並べる。拍・印・エフェクト・パッドを使えるのは見学以外（`canEditTabletop`）、ミックスの設定とパッドの割り当てはGMだけ（`canEditShared`）で、見学は見るだけ（`features/media/dj-console.service`）
- **曲の解析** — 部屋の音源を裏で1つずつ読み、ラウドネス（LUFS）・ピーク・前後の無音・テンポと小節の頭を求める（`application/media/audio-analysis.service`）。デコードはページで、解析はWorker（`core/audio/audio-analysis.worker`）で行う。読む順は流れている曲、再生リストと鳴っている環境音、残りのライブラリ（端末ごとに別の順）。結果は音源のタグの`AudioTag.analysis`に書いて全員に配り、部屋の保存にも入る。見学は結果を自分の画面にだけ持ち（`AudioProfile.keepLocal`）、ほかの人が先に配ることが多いので、読み始めを20秒待つ（ほかの席は3秒）。結果はこのブラウザのlocalStorage（`audio-analyses`）に音源のハッシュで400件まで残し、ほかの部屋で同じ音源に会っても読み直さない。30MBを超えるファイル（`ANALYZABLE_MAX_BYTES`）、手元にファイルの無い音源、`navigator.deviceMemory`が2GB未満の端末では読まない。解析の版（`AUDIO_ANALYSIS_VERSION`）が古い結果は読み直す
- **拍と印** — 「デッキ」タブ。拍は解析したテンポの確かさが0.3（`MIN_TEMPO_CONFIDENCE`）以上ならその拍を使う。曲の拍に合わせて押すと4回目からテンポと拍の位置をその曲に決め（`TAPS_TO_SET_TEMPO`）、テンポの半分・2倍、「いまの位置を小節の1拍目にする」、「解析したテンポに戻す」もある。手で合わせた拍は`AudioTag.beatGrid`（30〜300BPM、1小節4拍）に入る（`domain/media/beat-grid`）。印は1曲に4つ（`CUE_SLOTS`、`AudioTag.cues`、`domain/media/cue-points`）。空の印を押すといまの位置に置き、置いた印を押すとそこへ移り、右クリックで消す
- **エフェクト** — 「デッキ」タブのフィルター（左へ回すと高い音を、右へ回すと低い音を削る）・エコー（3/4拍ごと。拍が分からなければ0.375秒）・残響と、音程ごと落としながら1.2秒で止めるブレーキ（`JukeboxEngine.BRAKE_MS`）。つまみの位置は`Jukebox.fx`で全員に送り、回している間は100ms（`EFFECTS_SHARE_MS`）に1回までにする（`domain/media/dj-effects`）
- **パッド** — 8つ（`DJ_PAD_COUNT`）。GMが音源を割り当て、右クリックで外す。押すと、効果音は一度鳴らし、環境音は入切し、それ以外の音源は部屋の曲として切り替える。割り当ては`Config._djPads`に8要素のJSON配列で置き、全部空なら空文字にする（`domain/media/dj-pads`）
- **ミックスの設定** — 「ミックス」タブ。曲全体のラウドネスと補正量を見せ、自動音量・ダッキング・クロスフェード（0 / 1 / 2 / 4 / 8 / 12秒）・一時停止のフェード（0 / 0.4 / 1 / 2 / 4 / 8秒）・クオンタイズ・ビートライトをGMが部屋に決める。値は`Config._djSettings`に既定との差分だけのJSONで置き、空・読めない値・範囲外は既定として読む（`domain/media/dj-settings`）。既定は自動音量とダッキングがオン、クロスフェード2秒、一時停止のフェード0.4秒、クオンタイズとビートライトがオフ
- **自動音量** — 解析したラウドネスを種類ごとの目標へ寄せる。目標はBGMと効果音が-16 LUFS、環境音が-24 LUFS。上げるのは12dBまでで、ピークが-1dBFSを超えない所で止め、下げるのは24dBまで（`autoLevelGainDb`、`domain/media/audio-analysis`）。解析の無い音は動かさない
- **ダッキングとクロスフェード** — 部屋の曲が鳴っている間、その他の効果音（`SE`）とカットイン（`CUT_IN`）のチャンネルが鳴ると曲を9dB下げる（`core/audio/sidechain-ducker`の`DEFAULT_DUCKING`）。曲はジュークボックスのチャンネルに差し込んだ`MusicBus`（`core/audio/music-bus`）を通り、エフェクトとダッキングはそこで掛かる（チャンネルと音の経路の全体は[卓の描画・入力・音](../architecture/rendering-and-input.md#音の経路)）。クロスフェードが0より長い部屋では、曲の終わりより前に次の曲へ重ねて移る（`MixEventHandlerService`が再生中に250msごとに`JukeboxEngine.tickAutomix`を呼ぶ）。解析で分かった曲末の無音は待たず、次の曲は頭の無音を飛ばして始める。1曲リピート中は重ねない
- **クオンタイズ** — オンの部屋では曲の切り替えを鳴っている曲の次の小節の頭まで、印への移動を次の拍まで待つ。小節の頭まで4秒（`JukeboxEngine.MAX_QUANTIZE_MS`）より長ければ次の拍で切り替え、拍の分からない曲では待たない。印もいちばん近い拍の上に置く
- **ビートライト** — 曲の拍に合わせて全員の画面の縁を光らせる（`features/media/beat-light`、`domain/media/beat-glow`）。小節の頭を強く光らせ、1秒に3回（`MAX_GLOWS_PER_SECOND`）より速くは光らない。「動きを減らす」の端末と、「自分の画面ではビートライトを消す」を選んだブラウザ（localStorage`beat-light-off`）では光らない
- **旧版との互換** — タグの`analysis` / `beatGrid` / `cues`、`Config._djSettings` / `_djPads`、`Jukebox`の`fx` / `brakeCount` / `jumpCount` / `quantizeCount`は初期値を持たないので、値が入るまで欄を運ばない。旧版のピアはエフェクトを掛けずに聞く。旧版は数を送らないので、旧版からの停止はふつうの停止として、曲の切り替えは待たずにすぐ従う。印への移動は`seekCount`も進めるので、旧版はシークとして追う

## YouTubeのカットイン

- **動画の指定** — カットインの「YouTube URL」から動画のIDを読む（`CutIn.videoId`、`domain/media/cut-in`）。通常の再生ページ（`v=`）、Shorts（`/shorts/`）、`youtu.be`のURLを読み、ほかのホストは動画なしとする。開始位置はURLの`start`か`t`（秒数か`1h2m3s`の形）から、再生リストは`list`から読む
- **再生の始め方** — 頭出しが済む前に再生すると動画が最初のフレームで止まったままになるので、プレイヤーには自動再生させず（`autoplay: 0`）、プレイヤーが動画の頭出しを終えた（状態5）ときに1回だけ再生する（`features/media/cut-in-window`の`onPlayerStateChange`）
- **窓の合流と閉じる時刻** — 1回の起動で開く複数の窓（「カットインの多方向表示」）は`CutInVideoClock`を共有し、あとから再生が始まる窓は、最初の窓が再生を始めてから経った分だけ先へ進めて加わる（`features/media/cut-in-event-handler.service`が起動ごとに作る）。読み込みが再生時間より長くかかることがあるので、再生時間は動画が実際に始まったとき（状態1）から数える。再生時間のあるカットインで動画が始まらなければ、「30秒＋再生時間」で閉じる（`CUT_IN_VIDEO_START_LIMIT_MS`）。動画が終わると、ループ再生のカットインは開始位置へ戻して再生し直し、それ以外は窓を閉じる
- **音量** — 動画の音量はカットインごとの「個別音量」（`CutIn.videoVolume`、既定50）で、BGMの音量とは別に持つ。個人と部屋の音量は、[メディア / 音楽](#メディア--音楽)の「種類ごとの音のチャンネル」のとおりに掛ける

# 卓上ディスプレイの多方向表示・実寸表示

> この機能は [okamichi](https://github.com/okamichi) 氏が
> [udonarium_axe のフォーク](https://github.com/okamichi/udonarium_axe/tree/2d-multi-view) で作ったものです。
> 本家へ取り込むにあたって設定の置き場と保存先を変えていますが、機能そのものは氏の設計と実装によります。

画面を水平に置き、卓の四方から同じ盤面を見て操作するための機能です。真上からの平行投影、多方向メニュー、コマ名やリソースの周回、画面端の詳細表示、外周ティッカー、多方向カットインを、それぞれ単独で入り切りできます。ID-1規格のカードを物差しに画面を測り、1マスを25.4mm（1インチ）などの実寸で表示することもできます。

ここに挙げた機能はどれも、卓を真上から見ているあいだだけ効きます。真上から見るかどうかは、テーブル設定の「推奨ビュー」と、FABメニューの視点アイコンで決まります。視点が「自動」の人は推奨ビューに従い、自分で3Dまたは2Dを選んだ人はその選択のままです。卓上の画面だけを寝かせ、GMやプレイヤーのPCは通常の3D表示のまま、という使い方もできます。

## 設定の置き場

機能ごとに、その機能のパネルへ置いてあります。

| 機能                                                                                                                                     | 置き場                           |
| ---------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| 遠近をなくす、1マスの実寸と実寸表示、ビュー固定、コマの詳細表示、メニューの出し方、コマの多方向表示、外周ティッカー、ウィンドウの90°回転 | 部屋設定 UI の個人設定           |
| カットインの多方向表示                                                                                                                   | カットイン一覧                   |
| 画面の実測（カード校正）                                                                                                                 | 部屋設定の「ユーティリティ」タブ |
| コマの向きの示し方、コマ画像を常にカメラに向ける                                                                                         | 部屋設定 UI の共通設定           |
| 推奨ビュー                                                                                                                               | テーブル設定                     |

卓上ディスプレイの設定は、卓を囲んで見る画面のためのものです。オフラインのセッションで1台の画面を囲む使い方から生まれた機能なので、部屋には配らず、その画面だけに効きます。編集にGM権限は要りません。オンラインとオフラインが混ざるセッションでも、離れた席から参加している人の見え方は変わりません。

この画面がまだ何も言われていない項目は、いま出ているテーブルが答えます。フォーク版で作った部屋をそのまま開いても見え方が変わらないのは、このためです。「この画面の設定を消す」を押すと、全部テーブルの答えに戻ります。

画面の測定値だけは、書き留めずにそのセッション限りで捨てます。目の前のガラスを測った結果なので、別のディスプレイへ持っていくと嘘になるからです。ウィンドウごとの回転角も、そのウィンドウを開いているあいだだけの状態です。

### メニュー・ティッカーの文字サイズ

部屋設定の UI タブにある「コマの多方向表示」で、四方向メニュー、回転メニュー、外周ティッカーの文字の大きさを「小・中・大」から選べます。初期値は「小」で、従来の表示と同じ大きさです。

文字と一緒に項目の高さも広がりますが、メニューの半径や扇形の幅は変えません。「大」では、回転メニューの分類名が入りきらずに末尾を省略したり、外周へ流れるティッカーのコピー数が減ったりすることがあります。狭い画面では「中」が扱いやすいはずです。

## ID-1規格のカードで実寸を合わせる

ブラウザだけでは画面上の1ピクセルが実際に何mmか分かりません。そこで、寸法が国際規格で決まっているID-1規格のカードを物差しとして使います。ISO/IEC 7810 ID-1は85.60×53.98mmと定められており、クレジットカード、キャッシュカード、運転免許証、保険証などが同じ大きさです。手元のどれを使っても構いません。

実物のカードを画面へ直接当て、表示した枠の大きさを合わせるだけの操作です。カードの番号や名義を読み取ることも、どこかへ送ることもありません。

1. 部屋設定の「ユーティリティ」タブを開き、「実寸表示とビュー固定（この画面）」まで進みます。
2. 「実寸再調整」を押します。
3. カード1枚、または横に並べた2枚を選びます。2枚のほうが測定誤差を小さくできますが、画面に収まらない場合は選べません。
4. カードを画面へ直接当て、破線の枠がカードの外形と重なるように、右下のハンドル、スライダー、±1／±10ボタン、またはピクセル入力で幅を調整します。
5. 必要なら「1マスの実寸」を変更します。初期値の25.4mmは1インチです。
6. 「合った」を押します。実寸表示とビュー固定が同時に有効になり、盤面が指定した実寸へ移動します。

校正後は同じ場所に推定DPIを表示します。実際のミニチュアや台座をマスへ置いて確かめ、「1マスを小さく」「1マスを大きく」で微調整できます。ブラウザの拡大率を変えたり、ウィンドウを別のディスプレイへ移したりすると再調整の警告が出ます。

「ビューを固定する」を有効にすると、盤面のパン、ズーム、回転を止めます。コマの操作、選択、右クリックメニューは引き続き利用できます。実寸表示を有効にするとビュー固定も有効になります。盤面の右クリックメニューからも、ビュー固定の切り替えと、校正済みの場合の「実寸に合わせ直す」を実行できます。

画面の測定値、実寸表示、ビュー固定は他の参加者へ送信せず、ページを再読み込みすると破棄します。「この端末の設定をリセット」はこれらだけを消し、「1マスの実寸」は変更しません。

「1マスの実寸」は部屋設定 UI の個人設定にあり、その画面だけのものです。同じ設定画面の移動範囲欄にある「1マスの距離」と単位は、25.4mm＝5フィートのようなゲーム上の縮尺を表し、実寸の検算行にも使われます。

## 2D表示のコンテキストメニュー

2D表示でコマ、地形、射程範囲、光源、共有メモ、環境エフェクト、またはテーブルの何もない場所を右クリックすると、四方向から操作できるメニューを表示します。空白部分では「最初のテーブル」など、現在のテーブル名がタイトルになります。部屋設定の UI タブにある「回転メニュー表示」のON/OFFで表示方法が変わります。

コマが密集している場合は、コマから右ドラッグして任意の場所で離すと、離した場所を見かけ上の中心として同じメニューを表示できます。ドラッグ中は見かけ上の中心を小さな輪と点で示します。実際のコマ中心からメニュー中心までは点線で結ばれ、画面端ではメニュー全体が収まる位置へさらに補正されます。移動せずに右クリックした場合は従来どおりコマ中心へ表示します。テーブルの空白部分から始める右ドラッグは、従来どおり盤面の水平回転です。

### 「回転メニュー表示」が OFF の場合

1. 右クリックした位置の上下左右に4個のハンバーガーアイコンを表示します。コマの場合はコマの外側へ配置します。
2. 操作する人の側にあるアイコンを選びます。
3. 選んだ側から読める向きで、通常のプルダウンメニューを開きます。

プルダウンメニューの表示起点は右クリック位置やコマ中心ではなく、選んだハンバーガーアイコンの位置です。コマでは半径ぶん以上離れるため、メニュー上部とコマが重なりにくくなっています。

### 「回転メニュー表示」が ON の場合

メニューの分類や項目が、右クリック位置（コマの場合はコマ）の周囲を時計回りに回転します。回転速度は「回転速度」で 1～24°/秒に設定でき、初期値は 5°/秒です。

メニューの中心から円周へ伸びる水色の点線は、ウィンドウの向きが切り替わる境界です。X字の境界で区切られた各90°の範囲にある矢印が、その範囲の項目をクリックしたときに補正されるウィンドウの向きを示します。境界と矢印は画面に固定され、メニュー項目だけがその上を回転します。点線はコマの背後を通るように中央部分を隠すため、コマ画像の視認性を損ないません。

- 項目を選ぶと、下位項目がある場合は同じ位置を起点にサブメニューへ切り替わります。
- 1ページには通常項目を最大7個表示し、残りの1枠に「戻る」を表示します。
- 項目が8個以上ある場合、途中のページでは「戻る」の代わりに `1 / 2` のようなページ表示を置きます。クリックすると次のページへ進み、最終ページではページ表示に代わって「戻る」が現れます。
- 周回項目の「戻る」は、サブメニューでは一つ前へ戻り、最上位ではメニューを閉じます。前のページを見直す場合は、「戻る」からそのメニューへ入り直します。
- 中央にはメニューを表示しません。回転メニューを開いたまま右クリックすると、現在表示されている1項目ぶんだけ、短い高速回転で滑らかに時計回りへ先送りします。表示が3項目なら120°、4項目なら90°、6項目なら60°進み、割り切れない項目数では小数角を保ったまま一周の誤差を補正します。高速回転後は内部角度を0〜360°未満へ戻すため、操作を繰り返しても角度値は増え続けません。

2×2、3×3などの大きいコマでは、ハンバーガーアイコンと回転メニューの半径もコマサイズに応じて広がります。コマ名の周回表示が ON でも OFF でも距離は変わらず、コマ名の外側にメニューが配置されます。1×1のコマは従来の距離を使用します。

右クリックで回転メニューを開き、連打で強制回転、コマからの右ドラッグで表示位置を移動できます。この説明は設定項目の直下にも表示されます。

### メニューの向きと、開くウィンドウの向き

ハンバーガーアイコンから開いた通常メニューと、そこから開く共通ウィンドウやモーダルウィンドウは、コマ上・テーブル空白部分のどちらでも、選んだ四方向の向きを引き継ぎます。

回転メニューの項目から共通ウィンドウやモーダルウィンドウを開いた場合は、クリックした項目がその瞬間に向いていた方向を基準にします。表示角度は最も近い 0°、90°、180°、270°へ補正されます。手元から読みやすい向きにしたい場合は、右クリックでメニューを1項目ずつ送り、目的の項目が手元側へ来たときにクリックしてください。

## 共有メモを盤面へ寝かせる

テーブル共有の2Dモードでも、自分の席だけ寝かせた表示でも、新しく共有メモを作ると、内容を真上から読めるよう最初から盤面へ寝かせた状態で配置します。通常の3D表示で作る共有メモは従来どおり直立します。

既に配置済みの共有メモの姿勢は自動変更しません。共有メモの右クリックメニューにある「寝かせる」「直立させる」で切り替えられます。2D表示で寝ている共有メモは、端の回転ハンドルを使って盤面の水平方向へ回転できます。直立している共有メモの回転は、2D表示中は固定されます。

共有メモもハンバーガーメニューと回転メニューに対応しています。内容は通常の共有メモと同じくルームへ同期され、寝かせ方と向きも盤面オブジェクトの状態として共有されます。

## コマ名とコマ本体の回転

「コマ名を円周に沿って周回」を有効にすると、コマ名を円周に沿って表示し、コマ画像と台座も平面上で回転します。

この設定は部屋設定の UI タブ（個人設定）にあります。部屋設定の「コマの向きの示し方」が「コマごと回す」でも、周回表示のほうを優先します。卓上の画面だけ周回させ、ほかの席は従来の表示のまま、という使い分けが既定の姿です。

### 回転方法

| 回転方法                | コマ名                               | コマ本体                               |
| ----------------------- | ------------------------------------ | -------------------------------------- |
| 時計回りに連続回転      | 「回転時間（一周）」の速度で連続回転 | 「コマ本体の一周時間」の速度で連続回転 |
| 90°回転して静止         | 90°回転して静止する動作を繰り返す    | 90°回転して静止する動作を繰り返す      |
| コマだけ90°回転して停止 | 「回転時間（一周）」の速度で連続回転 | 90°回転して静止する動作を繰り返す      |

「90°回転して静止」は、コマ名だけでなくコマ画像と台座も同じように90°ごとに止まります。「コマだけ90°回転して停止」では、コマ名は連続回転し、コマ画像と台座だけが90°ごとに止まります。

### 回転設定

| 設定               | 内容                                         | 範囲      | 初期値 |
| ------------------ | -------------------------------------------- | --------- | ------ |
| 回転時間（一周）   | コマ名が一周するための回転時間               | 1～120 秒 | 12 秒  |
| コマ本体の一周時間 | コマ画像と台座が一周するための回転時間       | 5～300 秒 | 60 秒  |
| 90°後の静止時間    | 90°回転したあと、次の90°回転まで静止する時間 | 0～30 秒  | 4 秒   |

「90°後の静止時間」は「90°回転して静止」と「コマだけ90°回転して停止」で表示されます。0秒にすると停止時間がなくなり、連続して回転します。

回転方法で「時計回りに連続回転」を選ぶと、「コマ本体の一周時間」は60秒へ戻ります。「90°回転して静止」または「コマだけ90°回転して停止」を選ぶと、5秒へ戻ります。

### コマ上の表示

- 「リソースバフ回転表示（最大4つまで）」が OFF のとき、ラベルは `キャラクター名/バフ名の先頭5文字` を基本にします。バフがない場合や、コマ側でバフを隠している場合はキャラクター名だけを表示します。
- 文字列は円周に沿って一文字ずつ曲がります。短い文字列は四方に4個置き、長さに応じて3個、2個、1個へ減らします。
- 複数のラベルは `◆` と余白で区切ります。円周の継ぎ目に来た文字列も途切れないよう補完して描画します。
- すべてのコマが同時に同じ方向を向かないよう、コマごとに開始角をずらします。同じコマの開始角は参加者間で一致します。
- 「リソースバフ回転表示（最大4つまで）」を有効にすると、通常の横長リソースバーと固定バフ表示を外周表示へ切り替えます。名前とは回転レイヤーを分け、名前の1.25倍の時間をかけて少しゆっくり周回するため、頭文字やアイコンとの重なりが同じ位置に固定されません。
- リソースは台座の外周を最大4件で分割し、1件なら360°、2件なら各180°、3件なら各120°、4件なら各90°を割り当てます。2件以上では各区画の境界を黒い放射線で区切ります。各区画は現在値の割合だけ色が付き、識別用の頭文字だけを表示して数値は表示しません。5件目以降は外周へ表示しません。
- バフはアイコンだけを名前とリソースの外側へ均等配置します。数が多い場合は、アイコン同士が重なりにくいよう外周半径を広げます。「バフを隠す」が有効なコマには表示しません。
- 増減値とターゲット表示は回転させません。
- HP・MPなどのバーは、キャラクターシートを編集状態にし、対象の数値・リソース欄にある設定ボタンから「コマにバーを表示」を切り替えられます。
- コマへマウスを乗せたときの詳細表示については「コマの詳細表示」を参照してください。
- スクエアグリッドの台座は角の丸みが一定のため、1×1では円形、2×2以上では角丸の四角形に見えます。ヘクスグリッドではヘクス形状になります。

ポスター表示は多方向閲覧の対象外です。2D表示をやめるか、コマ名の周回を無効にすると、従来のコマ名表示へ戻ります。

## コマの詳細表示

コマへマウスを乗せると、名前やリソースなどの詳細が表示されます。2D表示のあいだは、部屋設定の UI タブにある「コマの詳細表示」で出し方を選べます。初期値は「コマの近くに表示（従来）」で、これまでと同じ表示です。

### コマの近くに表示（従来）

ポインタの近くへ1枚表示します。「コマ名を円周に沿って周回」が有効なときは、コマ中心から見たポインター位置を90°ごとの領域に分け、その側から読める向きへ変わります。表示した詳細はそのまま操作でき、ドラッグで動かせます。

### 画面の端に4方向表示（編集不可）

同じ詳細を画面の四辺へ同時に表示します。それぞれの辺に座った人から読める向きになり、外周ティッカーの内側（画面の端から48px）に置きます。ティッカーを使っていないときも同じ余白を空けます。

- 画面の縦横比が1.5倍以上のときは、長いほうの2辺に2枚ずつ置いて計6枚にします。横長の画面なら上下の辺を2等分し、それぞれの中央へ表示します。
- コマだけでなく、カード、ダイス、共有メモなど詳細が出るものはすべて同じように表示します。
- 閲覧専用です。値の変更もドラッグもできず、操作は下の盤面へ素通りします。編集はコマのメニューやキャラクターシートから行ってください。
- ポインターの真下に来た1枚だけ、その位置から外れるまで隠します。手元のコマが詳細で隠れないようにするためで、隠れるのは常に1枚です。ほかの辺の表示はそのまま残ります。タッチ操作では隠しません。
- 表示したまま画面の大きさや向きが変わっても、枚数と位置はそのつど合わせ直します。画像の読み込みなどで詳細の高さが変わったときも同じです。

## カットインの多方向表示

カットイン一覧の左下にある「カットインの多方向表示」で、同じカットインを卓の各席へ同時表示できます。カットインそのものの設定を変更する必要はありません。

| 設定     | 表示                                  |
| -------- | ------------------------------------- |
| しない   | 従来どおり1枚                         |
| 上下     | 画面を左右に分け、下向きと上向きに2枚 |
| 上下右   | 右席と上下席に3枚                     |
| 上下左   | 左席と上下席に3枚                     |
| 上下左右 | H字状に分け、四方向に4枚              |

各カットインは元の縦横比を保ち、割り当て領域に合わせて必要な場合だけ縮小します。隣り合う領域との境界は各側へ5%ずつ広げるため、合計で約10%まで重なることがあります。すべての表示面が再生準備を終えてから同時に開始し、準備が終わらない面があっても500msで再生を始めます。音声は重複しないよう、下向きの1面だけが再生します。音声だけのカットインは従来どおり1つの非表示パネルで再生します。

同じカットインを受け取っても、2D表示になっていないブラウザでは従来の1枚表示です。設定はブラウザごとなので、卓上の画面だけ四方向に出し、手元のPCは1枚のまま、という使い分けができます。

## 外周ティッカー

外周ティッカーは、チャットの発言を画面の四辺へ流すティッカーチャットです。専用のタブはありません。普通のタブで発言するとき、入力欄の色設定の横にある「ティッカー」ボタンを入れておくと、その発言が外周にも流れます。「コマ名を円周に沿って周回」がOFFでも、2D表示ならティッカーだけを使えます。

### 使い方

1. 部屋設定の UI タブ（個人設定）で「外周ティッカーを表示」を有効にします。
2. 速度スライダーを調整します。設定範囲は 20～240 px/秒、初期値は 55 px/秒です。
3. チャットの入力欄で、色設定の横に出た「ティッカー」ボタンを入れます。この画面でティッカーを有効にしているときだけ出ます。
4. 通常のチャットと同じように投稿します。ボタンが入っているあいだ、投稿した発言は外周にも流れます。

外周表示は2D表示のあいだだけで、まだ何も流されていない場合は何も表示しません。発言そのものは普通のチャットとして部屋に残り、ティッカーへ流す指示は全参加者へ届きますが、表示のON/OFFと速度はその画面だけの設定です。ティッカーを切っている画面には流れません。

すでに投稿してある公開メッセージも、上部の操作列にある「ティッカー」アイコンを押すと外周へ流せます。別のメッセージで同じ操作をするとそちらへ切り替わり、次にティッカー付きで投稿された発言があればそちらが優先されます。この操作では表示のON/OFFや速度を変更しません。

### 流れる向き

文字の上側を画面中央へ向けたまま、画面を時計回りに一周します。

| 辺   | 移動方向 | 文字の向き |
| ---- | -------- | ---------- |
| 下辺 | 右から左 | 通常       |
| 左辺 | 下から上 | 左向き     |
| 上辺 | 左から右 | 上下反転   |
| 右辺 | 上から下 | 右向き     |

新しい投稿が届くと、外周の表示は次の描画からすぐにその投稿へ切り替わります。新しい投稿を待つ間は最後の内容を繰り返します。

短い投稿では、発言者名と本文に `◆` を添えた同じ内容を最大8個まで複製し、外周へ等間隔に配置します。文章が長い場合は、コピー同士が重ならない個数まで自動的に減らします。外周一周の90%に収まらない文章は末尾を `…` で省略します。

表示対象は全員に公開された通常発言です。秘話、シークレット発言、システムメッセージ、空の発言には「ティッカー」アイコンを表示せず、外周にも流しません。

## ウィンドウを90°回転する

部屋設定の UI タブ（個人設定）で「ウィンドウを90°回転できるようにする」を入れると、キャラクター詳細、チャット、チャットパレット、インベントリなど、共通のウィンドウ枠で開くウィンドウのタイトルバー右上に「時計回りに90度回転」ボタンが出ます。入れていないあいだはボタンを出しません。押すたびに `0° → 90° → 180° → 270° → 0°` と切り替わります。

回転後も移動、リサイズ、縮小、全画面表示、閉じる操作を使えます。90°または270°で全画面表示にすると縦横を入れ替え、画面からはみ出さない位置へ補正します。

コマの方向メニューから開いたウィンドウは、そのメニュー項目の向きを初期角度として使用します。開いたあとは、ウィンドウ右上の回転ボタンでさらに90°ずつ調整できます。メニュー以外から通常どおり開いたウィンドウは0°で始まります。

回転角は開いているウィンドウごとの一時的な状態で、部屋には同期しません。閉じるとその角度は破棄されます。狭い画面向けのモバイル表示では回転ボタンを表示せず、通常の向きで表示します。

## ローカルで確認する

開発サーバーを起動して開き、接続情報パネルで「オフライン」を選びます。SkyWayへ接続しないまま再読み込みされます。

```sh
npm start
```

テーブル設定の推奨ビューを2Dにし、カードによる実寸調整、ビュー固定、2種類のコマメニュー、2種類のコマの詳細表示、3種類のコマ回転、多方向カットイン、外周ティッカー、ウィンドウ回転を順に確認してください。別のブラウザでも同じルームを開き、そちらが通常の3D表示のまま操作できることも確認できます。
